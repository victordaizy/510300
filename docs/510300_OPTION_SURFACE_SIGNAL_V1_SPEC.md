# 510300期权曲面风险信号V1

## 冻结目的

在首个有效前向盘口到来前，固定O1—O4的完整数学实现。复杂度来自期权定价关系，不来自对未来收益的参数搜索；候选仍只有4个，不超过10个。

## 统一输入与清洗

仅使用冻结收盘窗口内通过审计的510300标准期权。调整合约保留在原始证据中，但不与标准合约混合拟合。每个到期日至少需要7个认购/认沽配对执行价、7个有效价外点，远期价格两侧各至少3个执行价。

所有期权价使用一档买卖均价。相同到期日上，以认购减认沽对执行价的两两稳健斜率估计折现因子，再由认购认沽平价估计远期价格；折现因子或平价残差超门槛时该日输出 `NO_VIEW`。

## 波动曲面

逐到期日把价外期权均价反解为Black远期隐含波动率，以5组预先写死的初值拟合raw SVI总方差。只选择拟合残差最小的数值解，不搜索策略收益。拟合必须通过隐波均方根误差、正总方差和离散认购价格凸性检查。固定25、45和60日均只在上下两个真实到期日之间对总方差线性插值，禁止期限外推。

## 四个冻结因子

- O1：25日SVI曲面在执行价/远期价等于0.90处，由认购价格对执行价的一阶差分恢复的风险中性左尾概率。
- O2：25日固定期限的25绝对远期Delta认沽隐波减认购隐波。
- O3：25日固定期限25Delta认沽隐波减60日对应隐波。
- O4：按Cboe模型无关方差离散公式得到的25日隐含方差，减只用当时已成熟标签扩展OLS估计的HAR(1,5,22)未来20日实现方差。

HAR使用510300含分红日收益平方年化；回归因变量和三个期限自变量均取对数，方差下限固定为1e-12，至少252个已成熟训练行。任何未来价格都只可用于已经成熟的训练标签，不能进入当日预测。

## 评估边界

盘口审计达到 `DATA_GATE_PASS` 前，命令行入口拒绝计算真实O1—O4。原始因子生成后仍需至少252日建立事前经验分位，之后还需242个有分数的未见日才可运行另行冻结的预测检验。本协议不做收益回测、不生成仓位、不连接券商。

方法依据为Cboe波动率指数的模型无关方差构造、Gatheral与Jacquier的无静态套利SVI框架，以及Corsi的HAR-RV多期限波动率模型；本项目的所有工程阈值已在未见盘口前写入配置。
