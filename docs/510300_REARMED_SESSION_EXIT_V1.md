# 第32轮：日内强弱信号退出后，等待新的入场机会

## 为什么只检验这一项改动

第31轮日内强弱线性退出和两层树退出在主评价中分别出现52次、70次旧入场条件始终有效时的再次买入。两层树总买卖次数从原策略36次增至188次，额外费用约2.51万元。主评价损失还包含持仓时点改变造成的市场损益损失，不能把全部失败归为费用。

本轮只解决“提前退出后又被同一持续信号买回”的规则冲突，不改变训练、因子、模型、阈值或确认天数。第31轮其他两个入场策略同类次数很少，没有继续局部修补的依据，跳过。

## 三个新设置

|设置|继续使用的退出规则|新增加的再次进入条件|
|---|---|---|
|原退出＋等待新机会|保留原来的日内强弱、固定亏损、追踪回撤和最长持有期退出，不使用学习模型。|实际买入后关闭再次入场许可；实际卖出后，至少有一个收盘旧入场条件不成立，才重新允许后续满足条件时买入。|
|线性退出＋等待新机会|除原退出外，沿用第31轮每月已经训练完成的线性模型，连续两个收盘预测继续持有收益小于零时退出。|同上。|
|两层树退出＋等待新机会|除原退出外，沿用第31轮每月已经训练完成的两层树模型，同样连续两次负预测退出。|同上；这是本轮预定主方案，因为该旧版本重复进入次数最多。|

初始账户允许按原条件首次买入。买入未成交时，许可仍保留；只有实际买入后才关闭许可。退出后等待原入场条件消失与原本两个交易日的等待期同时满足，才允许再次进入；入场条件必须重新成立，不能在条件消失当天买入。当日卖出后的收盘若条件已经不成立，可以记为首次消失。若一般化的多模式策略切换到不同入场模式，也视为重新出现机会；本轮日内强弱只有一个模式，不涉及模式切换。

学习退出和原退出一旦触发，下一开盘请求全部卖出；受阻后保持退出意图，直到实际卖完。没有成熟模型时不增加学习退出条件，仍执行原退出和新的再次进入条件。没有模型不代表清仓或零收益预测。

## 入场和基础退出的完整条件

每日因子取日内对数涨跌减隔夜对数涨跌，六十日之和除以这六十日每日差异的样本标准差和六十的平方根。日内部分来自收盘相对开盘的变化，隔夜沿用分红一致的总回报分解。因子连续两日大于1，且当前允许再次进入、实际退出后已经经过两个交易日时，在收盘发出下一开盘买入请求。

持仓时，因子连续两日小于零、含分红持仓亏损达到6%、相对持仓最高收盘价值回撤达到8%、或者持有达到六十个交易日，任一满足就下一开盘请求退出。买入当日最早下一交易日可卖。单次进入，不追加份额。

两种学习模型继续使用持仓天数、含分红浮盈浮亏、持仓回撤、入场模式、五日涨跌、二十日涨跌、一百二十日均线偏离和二十日波动这八个因子。全部定义、训练周期成熟要求和模型计算，严格复用[第31轮中文规则](510300_LEARNED_CYCLE_EXIT_V1.md)。最新及所有历史月度实际模型规则已经保存，本轮没有新训练。

## 如何判断是否值得保留

六个新完整账户分别对应三个设置乘两档费用；对照复用第31轮原线性退出、原两层树退出、原规则及买入持有的八个账户记录。主评价和较早诊断各14条记录。模型全部复用，不能按本轮结果改训练样本、叶节点、系数、持有期或等待天数。

主评价保持2020年1月2日至2026年8月14日开盘，1604日；较早诊断为2015年1月5日至2019年12月31日开盘，1219日，分别从20万元开始。基础费用佣金万分之二、最低5元、滑点万分之五；压力费用佣金万分之四、最低5元、滑点千分之一。保留每年242日、现金和无风险收益零、100份、0.001元、方向性价格限制、分红权益及到账。

先确认重复买回确实减少，再看完整账户是否改善。减少交易次数本身不算成功；需要看费用以外的持仓损益、两个时期及压力费用。若仍没有足够改善，停止这组学习退出与重新进入机制的继续修补。完整账户净夏普1.2及稳定超额目标不变，既有历史不是独立验证。
