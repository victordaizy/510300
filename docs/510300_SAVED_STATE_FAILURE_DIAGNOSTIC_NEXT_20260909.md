# 保存结果诊断：事前市场状态能否解释改动为何失效

第151轮平均K线两种规则均未改善143，关闭固定规则。下一步先利用已有账本回答用户关于“不同时间用不同策略”的问题，避免仅凭某个历史时期更好，就添加新的切换器。这是一项保存结果诊断，不登记新的交易策略，不新增资金账户，不重新优化任何旧参数。

固定观察四个事前状态：含分红财富高于或不高于当日120日均值，交叉最近20日收益样本波动率高于或不高于最近60日波动率。趋势和波动都在前一交易日15:05已知，随后一个账户交易日的实际净收益归入这个事前状态。两档费用使用同一状态日历，主历史和较早历史分别分析，现金日和统一终点开盘收益均保留。

这两个状态维度在第9轮已被研究过；本次不重开该六机制学习家族，也不把相同状态改用新父策略就称为有效新策略。本次仅检查当前143、150只减预算和151平均K线确认的损益结构。状态不能区分后续优势时，应明确记录；出现分组差异也只产生待验证的线索，不能直接按照已经看过的年份或分组收益决定实际交易。

固定三个比较：143相对买入持有、150只减预算相对143、151平均K线确认相对143。每个比较在两个时期、两档费用、四个状态各一项，共48项。主历史2020年1月2日至2026年8月14日开盘，较早2015年1月5日至2019年12月31日开盘；全部使用保存的真实费用、原始价格和分红账户。

主要量为某状态对完整区间年化日均净收益差的贡献：属于该状态的日收益差保留，其他状态贡献为零，使用完整区间日数取均值并乘242。四个状态的贡献之和必须还原原完整区间的年化日均差。这里的零是已知不属于该分组的统计贡献，不是把缺失收益补零。另报告该状态日数、占比及状态内平均每日差，以区分状态稀少和单日优势不足。

逐日损益分别按每条账户自身前收盘净值归一化，分解为价格、已确认分红及佣金滑点。净收益差贡献必须等于价格差贡献加分红差贡献减费用差贡献；整手、仓位和分红路径变化包含在这个账户比较中。它不是把某笔交易抽掉之后的单独因果效应，更不是通过两条父净值相加得到的新可交易收益。

不输出“只留有利状态后的策略夏普”。四个状态都是交易前已知，但保存账户的当日损益仍承接此前真实库存；一个新切换账户会有自己的库存和摩擦，必须另行事前设计与建账，不能用本次分组替代。
