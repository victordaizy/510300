# 第196轮：风险窗口与预算调整时点的一次批量校准

本轮准备十四套新设置，共五十六条完整账户，零新增数据、零预测模型。候选参数在首次批量计算前一次确定。使用过的历史已参与方法选择，本轮属于历史参数校准，不能当成独立验证。

已完成的批量虚拟组合快筛复用了224条不同完整路径，32.29秒检查1080份保存账本，两个预定起点找到的最佳最弱门槛比值仅0.8931。静态混合收益没有解决联合缺口，因此不继续逐个试固定混合权重。该诊断既不是实际组合账户，也不是证明所有组合不存在解。

## 统一来源与因素

所有设置使用第174轮“任一方向确认后的辅助组合”原目标和其自己的完整账户净收益。来源中因子与进出场规则继续有效，正式文档附上全部中文说明。每个成本场景独立使用同档来源，不混用基础与压力账户。

新增调整只涉及三个因素：过去若干交易日的来源账户净收益样本标准差；将该标准差乘以二百四十二的平方根得到的年化风险；当前原目标是否处于连续正值区间。收益包括原账户现金日、价格变化、分红、佣金和滑点，使用截至当天收盘已完成的记录。

## 十四套设置

风险窗口固定为三十、六十、一百二十个交易日；风险预算固定为百分之十、百分之十二、百分之十五；调整方式为每日调整、正目标区间开始时固定。原完整网格十八套，其中每日六十日的三档预算，以及区间固定六十日百分之十，已经在181、182、194轮计算，本轮直接复用而不重跑。剩余十四套全部计算，不提前挑选表现好的设置。主候选预先指定为六十日窗口、百分之十二预算、区间固定；所有候选完整报告。

每天可用倍率等于预算除以当日历史年化风险。来源账户尚未积累足够窗口时，倍率使用一；风险确实为零时也使用一。准备期后若窗口内出现缺失，倍率未知，不把缺失当零风险。最终目标最高百分之一百股票，没有融资。

每日方式每天重新使用当前倍率乘原目标。区间方式在原目标首次明确为正时记录当时倍率，此后持续使用该倍率，直到原目标明确为零才结束区间。未知目标不结束区间、不重新选择倍率，组合目标保持未知；若起始倍率未知，整个区间都保持未知直到明确零重置。固定的是倍率，原目标变化仍会改变股票比例，不是固定买入份额。

## 完整进入、调整与退出

收盘十五时零五分确定目标，下一交易日开盘执行。空仓且目标已知为正，按自身收盘净资产乘目标、除以收盘价格，向下取整到整百份，提交模拟买入。已有股票且目标为正，实际股票比例与目标差距小于十个百分点时保留份额，否则调整到目标中心。明确零目标申请全部卖出；未知目标保持现有份额。受阻后继续按下一收盘目标重新判断，不新增退出锁或冷却期。终点开盘统一退出。

来源账户中的止损、自然退出、学习退出和再进入仍决定来源目标。本轮倍率调整不把来源账户的浮盈亏当成新组合的浮盈亏，也不新增按新组合亏损触发的止损。

## 账户与一次验收

主历史从2020年1月2日至2026年8月14日开盘；较早历史从2015年1月5日至2019年12月31日开盘，各段各档费用独立二十万元。基础佣金万分之二、最低五元、单边滑点万分之五；压力佣金万分之四、最低五元、单边滑点千分之一。现金和无风险收益假设零，年化用二百四十二日。整百份、千分之一元价位、次日可卖、现金限制、方向涨跌停、分红登记与除息应收及支付分别记账均保留。仅510300和人民币现金。
