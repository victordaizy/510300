# 板块评分卡V1.2：当前前瞻与历史赔率双轴决策层

## 1. 为什么不能把赔率直接加进总分

V1.1已经证明，胜率高不等于期望为正。但历史赔率来自2019年12月至2026年4月的无条件板块样本，当前评分来自2026年8月18日的基本面、预期差、价格阶段、资金流和估值。由于缺少可重建的历史逐月预期差台账，无法估计“当前分数条件下”的胜率和赔率。

因此，V1.2禁止把当前分数和无条件历史赔率加权成一个新的数值分数，也禁止把当前分数转换成概率。两者只作为相互独立的研究门槛。

## 2. 当前前瞻轴

- `CURRENT_FORWARD_POSITIVE`：当前分数不低于65分，沿用冻结V1的A/B等级边界。
- `CURRENT_FORWARD_WATCH`：55分至65分。
- `CURRENT_FORWARD_WEAK`：低于55分。

65分和55分不是依据历史赔率重新调出的参数，避免在看到结果后寻优。

## 3. 历史赔率轴

`FAVORABLE_POINT_ESTIMATE_UNCONFIRMED`必须同时满足：

1. 60日平均历史超额大于零；
2. Profit Factor大于1；
3. 平均赔率大于1；
4. 三条非重叠链的最低胜率高于盈亏平衡胜率。

如果移动块Bootstrap期望区间上界仍低于零，则标记`ADVERSE_IN_SAMPLE_NOT_OOS`。其余根据点估计标记为混合或不利。所有历史赔率都没有经过多重比较校正，不能称为样本外优势。

## 4. 简化后的四级矩阵

- `P1_DUAL_AXIS_ALIGN_UNCONFIRMED`：当前前瞻轴为正，历史赔率点估计也一致；只进入研究观察名单。
- `P2_ONE_AXIS_ONLY`：只有一条轴为正，说明当前证据与历史盈亏结构没有同时支持。
- `P3_NO_POSITIVE_ALIGNMENT`：两条轴都没有形成正向一致证据。
- `P4_HISTORICAL_ADVERSE_IN_SAMPLE`：历史期望的块Bootstrap上界仍低于零，作为负面对照。

四级矩阵是研究优先级，不是买入评级。所有层级均为`NO_POSITION`，禁止Kelly、交易映射和订单生成。

## 5. 真正需要积累的数据

从冻结后逐次保存当前分数、双轴状态、进入日、60日成熟日和最终超额。只有真实前瞻样本成熟后，才能估计高分条件胜率、条件赔率和条件期望；在此之前统一输出`UNAVAILABLE_AWAITING_TRUE_FORWARD`。
