# 第129轮：缩量日累计涨跌趋势

第128轮固定入场模型只改善较早历史，主历史与114相同。本轮检验一个不同的进入机会：成交量下降的日子，价格变化累计形成的方向，能否识别更适合持有510300的阶段。只用已有日线，不训练模型，不补EPS或其他慢来源。

## 因子含义与来源

只使用交易日期、当日及前一交易日实际成交份额、收盘价、前收盘价和当日每份除息现金。成交份额来自交易，不是公募净申购，也不能据此声称已经识别聪明资金。

固定采用[StockCharts负量指数说明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-indicators/negative-volume-index-nvi)的加法累计口径：从1000开始，只在成交量严格下降时加入当日价格百分比变化，配255日指数均线。没有采用累计净值的乘法版本。均线从最初完整窗口的算术平均开始，随后按照[StockCharts指数均线说明](https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/moving-averages-simple-and-exponential)递推。来源给的是指标定义，其历史胜率不是本项目证据。

本项目对现金分红、相等、缺失和实际交易的处理如下，均在新历史指标及账户计算前固定。

## 全部计算规则

一、经济简单涨跌幅：当天收盘减前收盘，加当天每份除息现金，再除以前收盘。先按保存输入的十进制数相减相加，避免正常除息留下虚假方向。此处不是对数收益，也不是仅价格跌幅。

二、缩量判断：当天实际成交份额严格小于前一交易日，才算缩量。等于或增加时，累计指标保持原值。已观察到的零成交量有效；如果从正量降到零，仍属于缩量；连续两天均为零不属于继续缩量。缺失不是零。

三、累计指标：原始行情第一天2012年5月28日设为1000，当天缺少前收盘只作为结构性起点，不编造当天收益。从第二天起，缩量时将当天经济简单涨跌幅乘100，加到前一天指标；否则保持原值。例如连续两个缩量日各涨百分之十，指标由1000变1010，再变1020，不做复利乘法。这个指标是方向统计量，不是账户净值。

四、信号均线：累计指标的最初255个值，包括起点1000，取算术平均作为第一次均线。此后每天取旧均线，加上当日指标与旧均线之差的一百二十八分之一。未满255个值没有可用均线。两段历史共用从原始起点计算的因果前缀，不为不同历史单独重新初始化。

五、缺失：除结构性首行前收盘外，必须有有限、有效的价格、每份除息现金和前后成交份额。价格为正、现金分配及成交份额非负。任一内部缺口从当天起保留无观点，不填补、跳过或在后来任意重新起算；价格即使处于增量日也不能因未计入指标而忽略其缺失。完整日历保留，已锁定退出继续执行。

## 进入、退出与再次进入

空仓且当前指标严格高于均线，在下一交易日开盘按可用资金及整手约束请求买入一次。不要求首次从下方穿越，账户首次可判断时只要当前条件成立即可进入。买入后保持实际已有份额，不追加或每天重新满仓。

持仓且指标严格低于均线，在下一开盘请求全部卖出。卖出受阻，退出意图一直保留，不能因后来指标转强撤销。指标恰等于均线时保持实际状态：已持仓继续持有，空仓继续等待。缺失时不发起新判断，保持实际份额；不能把无观点说成新现金信号。

实际卖完后，下一个已知收盘重新按相同进入条件判断；没有额外冷却天数，也不要求信号先消失。研究终点统一在最后开盘优先退出。本轮只有空仓与按可用资金买入两种动作。

本轮不使用旧百分之六止损、百分之八追踪退出或六十日持仓上限。进出场全部由以上固定指标关系以及实际成交限制决定。

必要合成测试覆盖加法与乘法区别、分红中性、255值初始化与递推、因果前缀、成交量单位缩放、零值和缺失、进入退出及受阻锁定。测试通过并冻结后，一次计算指标和四账户；核对保存指标、判断、实际周期和账户，不重复拟合旧模型。
