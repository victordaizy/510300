# 第40轮：每次进入选定策略，退出后再换

## 本轮改动的依据

第39轮每天按强趋势与其余状态改选基础策略，主评价基础净夏普为0.498，低于第32轮原候选0.705。实际账户相对原候选少赚9640.16元，其中额外佣金和滑点为8374.66元。主评价48次卖出中，有4次是市场状态变化后所选策略换了、旧策略当时仍愿意持有造成的退出。额外费用不仅来自这4次，还包括其他新增的完整交易，不能全归因于强制改选。

本轮只检验一个新方案：“每次进入选定策略，退出后重新选择”。不更改市场状态阈值、两个基础策略的因子或预测模型。

## 因子与基础策略

市场状态和两个基础策略的完整因子、参数及虚拟账户规则，沿用第39轮《按已知市场状态选择一个已有策略》。此处明确实际选择规则：当日含分红总回报水平高于一百二十日均线，而且二十日方向效率大于0.3时，选择趋势与震荡反弹策略；其余输入完整的状态选择第32轮原日内强弱、线性学习退出和等待新机会策略。

一百二十日均线偏离为当前含分红水平除以最近一百二十日平均再减一。二十日方向效率为期间总回报水平绝对净变化，除以每日变化绝对值之和。两者缺失时不新选择策略，不把缺失当成其余状态。

趋势基础策略的进入、退出使用此前二十日最高与十日最低收盘、二十日均值及样本标准差、是否当日回升、一百二十日均线和方向效率，以及原止损、追踪退出和持有期。日内强弱基础策略使用六十日日内减隔夜相对强弱分数、原价格和时间退出、八因子月度线性退出及旧入场条件消失后才能重现的许可。所有因子和阈值与第39轮相同。本轮不采用第38轮按年龄加权的失败模型。

## 进入、持有、退出和重新进入的实际规则

空仓时每天收盘按上述市场状态选择一个基础策略。如果它当前保存的虚拟状态为一，下一开盘请求买入现金可负担的100份整手。状态为零则继续空仓。请求尚未成交之前，可以在下一收盘重新选择；只有实际买入后才锁定本次采用的基础策略。

持仓期间，不因市场状态变化改选基础策略。当前已锁定基础策略的状态仍为一，就继续持有实际份额；它的状态变为零，就请求下一开盘全部退出。即使另一个基础策略此时愿意持有，也不能取消该退出请求。退出受阻则持续请求至实际卖完。已锁定基础状态缺失时保留份额和已有退出请求，不填成退出状态。

每次实际买入后只持有这批份额，不追加。实际全部卖完后的收盘，按最新市场状态重新选择策略；如新选择的基础策略愿意持有，可请求再下一开盘进入。实际选择账户不额外增加等待天数，基础策略自身的等待和重新进入许可仍包含在各自虚拟状态中。

本轮使用原已验证的持仓周期账户引擎，买入请求按信号收盘价、现金和费用估计整手，下一开盘按实际可成交和可负担情况执行；与第39轮每日目标仓位账户的份额估算结构不同，不能声称结果差异只有4次强制卖出这一项来源。每次持仓的退出依据仍是已锁定的基础虚拟状态，而不是用组合自身浮盈亏重新训练或改写基础策略。

终点统一在开盘请求退出。只研究510300与现金，不融资和卖空。基础和压力费用使用同一组基础费用虚拟状态，实际成本分别记账。

## 比较与停止

主评价2020年1月2日至2026年8月14日开盘，共1604个账户日；较早诊断2015年1月5日至2019年12月31日开盘，共1219日。分别20万元，年化242日，现金与无风险收益零，100份整手、0.001元价格间隔、方向性涨跌停、买入次日可卖及完整分红权益和未成交。

基础费用佣金万分之二、最低5元、滑点万分之五；压力费用佣金万分之四、最低5元、滑点千分之一。

每段一个新设置两档费用，共2个新账户；第39轮每日状态选择、第32轮原线性退出单策略、原趋势单策略和买入持有四项对照各两档费用，共8个复用对照。每段10条评价记录，两段4个新账户，不新增训练或参考账户。

先验证持仓期间换市场状态不会误改锁定策略，旧策略真正退出后才能再次选择，再运行账户。若无改善，不搜索等待、锁定期或重新进入阈值。净夏普1.2和稳定超额目标不变，结果仍属于已见历史上的规则比较。
