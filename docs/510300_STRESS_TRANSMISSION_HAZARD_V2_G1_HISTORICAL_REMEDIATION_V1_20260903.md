# 510300 压力传导危险率 V2：G1 历史证据修复 V1

## 权限与目的

用户在看到 GPT Pro 的 `STOP_AND_ARCHIVE_V2` 裁决后，于 2026-09-03 明确要求尝试补齐压力事件并通过 G1。本执行因此只追加开启一次历史数据修复与 G1 复裁；父版本的停止裁决、文件和收据保持不变。

本执行的目标不是保证得到 `PASS`，而是以真实、全量、结果盲的证据修复后重新回答 G1。若仍不足 30/40 个独立事件或不足 750 个非事件风险日，必须保留 `NO_VIEW`。

## 结果盲修复边界

采集器的唯一目标全集是父四态账本中全部 `source_observed=false` 的点时沪深300成员日，共 15,340 行、324 只证券。采集阶段不读取 BAD10 标签、事件 ID、事件缺口表、未来路径值或任何绩效文件，也不能按压力事件日期挑选证券。

## 准入来源

- 上交所：官网“股票和可转债停复牌信息”页面所调用的 `GW_PL_JYTS_TFPXX` 官方查询接口，按自然年和分页完整获取。接口中的可转债、转股代码、基金与 B 股在产品身份层即被排除，只准入与点时成员身份一致的 `6xxxxx.SH` A 股记录；同日起止的官方 `WH` 记录只覆盖当日，跨日起止记录的结束日按恢复交易日开盘解释。
- 深交所：官网市场统计月报索引以及每月唯一的“证券停牌情况”官方子表，覆盖 2014-12 至 2026-08；只准入 `0xxxxx.SZ` 或 `3xxxxx.SZ` A 股记录。
- 公司行动否定检查：沿用父四态执行已冻结的全历史分红候选文件；只要同一证券同一日期存在任何除权日候选，该停牌日就不得在本执行中升级。

准入必须同时满足：交易所官方来源、精确证券和日期、整日停牌、存在前一有效未复权收盘价、当日无公司行动候选。午间或盘中停牌、供应商推断停牌、前向填充行情、复权价格以及普通缺失均不准入。

## 四态和 G1

满足全部条件的缺口行才改为 `OFFICIAL_SUSPENSION`，收益严格为 0；其余行保持原 `SUPPLIER_MISSING_OR_CONFLICT` 或公司行动未决状态。随后使用原 20/5/60 窗口、98% 成员覆盖、90% 共同运动覆盖以及 30/40/750 门槛全量重建 M/F/T 和 G1。

即使 G1 通过，本执行也不训练模型、不生成概率或仓位、不读取组合结果，并停在 `G1_PASS_AWAIT_EXPLICIT_G2_AUTHORIZATION`。G2 需要新的明确授权。
