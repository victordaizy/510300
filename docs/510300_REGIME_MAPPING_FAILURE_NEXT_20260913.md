# 第179轮研究方向：按时间顺序更新的策略选择，而非固定状态映射

第178轮已经给出直接反证：在2015年至2019年表现合格的四状态固定映射，迁移到2020年至2026年后，基础费用净夏普降至1.076，压力费用净夏普降至1.012，且相对买入持有的年化收益分别为-0.001%和-0.212%。因此停止继续调整“哪个状态固定使用哪一个已有策略”的规则。

下一轮只研究一个更快、更简单的方向：状态定义固定，但每个交易日的策略选择只能使用该日以前已经实现的真实账户日收益，按既定最少样本数和既定比较窗口决定继续使用核心、相加封顶或现金。它不使用未来收益，不新增外部数据，不引入EPS、估值或公募申购因子。

进入规则：在前一交易日收盘后，先根据固定状态定义判断当日状态；仅在该状态下两个候选策略均已有足够历史已实现日收益时，比较其截至前日的风险调整表现；若胜者满足预先写明的最低条件，则将目标仓位切换到胜者，否则为现金。

退出规则：一旦当前持仓策略不再是同一状态下合格胜者，或该状态的历史样本不足、表现不达门槛，下一交易日开盘将目标仓位降为零；若新胜者不同，则同一开盘先按账户交易规则完成换仓。每次目标变化仍执行整手、最小手续费、滑点、T+1和期末平仓。

验证安排：先固定早期开发段和后续独立留出段；全部门槛、状态、窗口、候选集合和成本情景在读取留出段结果前冻结。验收要求基础和压力费用下的净夏普均不少于1.2、年化收益均不少于10%，并且年化收益相对买入持有为正；任何一项不满足即关闭该版本。
