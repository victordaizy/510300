# 金融公司报表范围与累计期间修正

这是原始数据处理，尚未进行新的投资账户评价。原始非金融课题本来就排除了金融公司，原课题事实文件、解析代码和失败结论都保留。本次检验能否将已有工具用于补齐金融公司时，发现该迁移方式不能直接采用。

已核实的招商银行2021年三季报提供一个明确实例：第20页是银行母公司利润表，单季营业利润为367.63亿元；第18页才是合并利润表，1至9月累计营业利润为1165.81亿元。原非金融解析器直接处理该银行文件时，把第20页第三个数值列标为“合并、年初累计”。该输出已拒绝，未进入任何新策略。

新识别方式先核对“未经审计合并利润表”标题，再核对人民币百万元单位、当年和上年年份顺序，以及1至9月、7至9月两组期间的位置。累计列由实际期间表头决定，不固定抓第三列或第一列。母公司表、期间不明、币种单位不明或缺少必要行的页面保留缺失。

同时核对全部四个数值列的两个会计等式：营业收入加带符号的营业支出等于营业利润；归母净利润加少数股东损益等于合并净利润。按表中百万元精度容许一百万元左右的加总尾差。每股盈利明确为元每股，不乘财务表的百万元单位。

目前仅支持有上述明确表头和行结构的版式，对首批24份已归档金融公司报告逐份尝试。未匹配的版式不假填、不宣告验证通过。当前报告中的上年比较列只用作同表核对，不能替代上一年原始公告版本；后续同比仍需找当时原始报告。合并每股盈利还须与普通股、稀释口径及其他权益工具扣除对应。

保留原始PDF哈希、页码、表头、所取列、全部原文数值与会计核对误差。确认这些字段不代表整个金融行业已覆盖，也不代表已构造完整指数EPS。
