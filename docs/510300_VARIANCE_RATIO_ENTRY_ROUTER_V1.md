# 第53轮：用五日与一日的方差关系选择进入模式

## 本轮问题和两个设置

同一种价格形态在不同市场状态下可能产生不同结果。本轮检验一个新增的状态条件：最近六十日内，五日累计涨跌是否比一日涨跌更容易同向累积。状态每天重新计算，决定下一次进入采用突破还是反弹；实际买入后，使用进入时选定模式的退出规则。

只登记两个设置：一是按方差比选择进入模式的主方案；二是不使用方差比、两种进入信号任一成立即可进入的直接对照。两者买卖时点、仓位、等待期、保护和退出完全相同。直接对照用于判断新增状态条件的实际增量。另复用原趋势与震荡切换、原学习退出、买入持有的完整账户。

旧研究有均线、趋势效率、日历、涨跌分类、滚动收益学习和宏观状态划分。检索到的旧“下行方差占比”比较下跌与总波动，和本轮比较不同时间尺度的方差不是同一因子。本轮不重建EPS，不改此前学习退出模型，不增加外部数据。

## 新方差比因子的全部计算

使用当日收盘已经可知的含分红日收益。每日总回报为“当日未复权收盘价加当天每份除息分红，除以前一收盘价”，对其取自然对数。所有计算只使用截至当前收盘的最近六十个日对数收益，含当日；五日合计块也必须全部位于这六十日内。

先求这六十个日对数收益的平均值。每个日收益减去平均值，得到六十个去均值涨跌。一日方差为这些去均值涨跌的平方之和，除以五十九。

再依次计算窗口内每连续五日的去均值涨跌之和，共五十六个可重叠的五日块。将这些五日合计分别平方后加总，除以“五乘五十六、再乘一减五除以六十”，得到换算到每日尺度的五日方差估计。最后用它除以上述一日方差，得到本轮方差比。

重叠和有限样本调整参考[arch官方方差比实现](https://arch.readthedocs.io/en/latest/_modules/arch/unitroot/unitroot.html#VarianceRatio)，背景来自[Lo与MacKinlay的方差比研究](https://www.nber.org/papers/w2168)。这里修正的是方差估计，不声称方差比本身严格无偏。

方差比大于一，本轮将其标为“较偏同向累积”；小于一，标为“较偏涨跌交替”；恰等于一，不选择新进入模式。没有完整六十日、存在缺失或非有限值、或者一日方差小到无法可靠区分数值舍入时，保留无有效状态，不产生新的进入请求。数值下限为机器精度乘“日收益平方均值与万亿分之一中的较大值”。这种缺失处理不代表要求已有持仓卖出。

本轮不计算显著性检验，不把大于或小于一描述成已经统计确认的趋势或均值回归，更不以论文结果证明510300可盈利。它仅是事先确定的交易状态条件，其价值由完整新旧账户比较判断。六十日观察和五日尺度沿用项目已有常用交易周期；不扫描窗口、尺度或阈值。

## 两种进入模式的全部因子

以含分红日总回报逐日累计相乘，形成财富指数。突破模式：当日财富指数高于此前二十个交易日财富指数的最高值，就出现突破进入信号；最高值窗口不含当日。

反弹模式：计算财富指数相对含当日最近二十日均值的标准化偏离，即当前值减均值，再除以二十日样本标准差。当偏离严格低于负一点五、且当日财富指数高于昨日时，出现反弹进入信号。零标准差沿用旧因子取零的约定，因而不满足负一点五。必要原价格因子不完整时，两种模式都不产生新进入信号。

主方案只有方差比大于一且突破信号成立，才允许突破进入；只有方差比小于一且反弹信号成立，才允许反弹进入。方差比确定可用模式后，当天没有该模式的进入信号，就继续空仓等待，不能改用另一模式凑出交易。

直接对照不读取方差比作决策。突破或反弹任一信号成立即可进入；如同时成立，预先规定突破优先。对照不是两条账户净收益的平均，也不在看到收益后再选择当日赢家。

## 买入、持有、退出及重新进入

两种设置均为单个账户，空仓且距上次实际全部卖出至少两个交易日，才按当日允许的进入模式请求下一开盘买入。使用当时可用现金和一百份整手，只买一次，持有中不追加，不融资。

买入以后锁定本周期的模式。每日变化的方差比只影响未来新的进入，不单独触发现有持仓换模式或卖出。持仓仍每天检查其价格及风险退出：

- 突破模式：财富指数跌破此前十个交易日的最低值，或者含已确认分红的持仓亏损达到百分之六，或者从本周期最高收盘持仓价值回撤达到百分之六，任一成立便请求全部退出。该模式没有额外固定持有天数或止盈。
- 反弹模式：标准化偏离恢复到零或以上，或者含已确认分红的持仓亏损达到百分之五，或者持有达到十个交易日，任一成立便请求全部退出。买入当天计为持有第一日，没有额外追踪退出或固定盈利门槛。

持仓成本为实际买入成交金额加买入佣金；当前持仓价值为实际份额乘收盘价，加本周期已确认分红。周期最高价值为买入成本及随后各收盘持仓价值的最高值。股权登记、除息确认、应收和实际到账沿用原完整账户。

全部退出请求在下一开盘执行，若未成交则逐日保留。只有实际卖完，两个交易日等待才开始计数。等待期满后，新进入按当时重新计算的状态和价格条件决定；本轮沿用简单策略账户，不额外要求旧条件先消失再出现。买入没有成交时，下一收盘重新决定，不把未成交请求当实际持仓。

## 评价、对照与停止条件

主评价为2020年1月2日至2026年8月14日终点开盘，1604个账户日；较早诊断为2015年1月5日至2019年12月31日终点开盘，1219日，两段各从20万元开始。只交易510300与人民币现金，保留全部空仓日。现金和无风险年收益假设均为零，年化为242日，夏普按全账户每日净收益均值除以样本标准差，再乘242的平方根。

基础费用为单边佣金万分之二、最低五元、滑点万分之五；压力费用为佣金万分之四、最低五元、滑点千分之一。执行0.001元价格刻度、100份整手、买入次日可卖、方向涨跌停、现金约束、未成交保留和终点开盘退出，不用当天最低价补造买入。

每段历史两个新设置、两档费用，共四个新账户；原趋势与震荡切换、原学习退出、买入持有各两档费用复用六个账户，共十个记录。没有新训练、没有新参考账户。旧趋势与震荡切换的风险参数与本轮不同，只作历史背景；新增方差条件的直接增量必须以本轮不设方差条件的相同规则账户为准。

保存全部逐日方差比、可选状态、两类原始进入信号、实际进入模式、退出和周期。核对全账户财富恒等式和完整日历，并分别统计两类模式的实际贡献。目标仍为扣费净夏普至少1.2及稳定超额。若主方案不能比相同规则对照产生两段共同改善，结束本次方法，不搜索窗口、尺度、阈值或按有利年份调方向。两段历史都已被反复观察，结果不自动构成独立验证。普通中文文档交付，不制作GPT数值包。
