# 第143轮拟研究：按趋势幅度与波动幅度连续分配来源

140全量趋势切换增加主历史风险，141固定来源损失较早有效收益，142共同确认则同时削弱机会和规模。它们提示：把另一策略全部替换或完全排除，都不一定合适。下一项只检验一个连续预算组合，保留两套策略的原目标。

来源为131普通波动乘数与139训练支持选择。两个已有市场因素为：含分红财富相对120日均值的偏离，以及20日含分红简单收益样本标准差乘242平方根得到的年化波动。正趋势幅度是前者与零中较大值；波动幅度是后者乘120除以242的平方根。这里的平方根是预算尺度约定，不保证未来120天波动，也不把预算当胜率。

每天15:05，趋势因素和波动都已知时，正趋势幅度除以正趋势幅度加波动幅度，作为131预算；139预算是剩余部分。如果两幅度都明确为零，131预算为零；正趋势为正而波动明确零，131预算为一。负波动或无穷值报错；任一因素缺失则预算未知，不补默认预测。120、20、242和零方向均固定，不搜索其他尺度或比例。

最终股票目标为131预算乘其对应费用收盘目标，加139预算乘其对应费用目标。两个父目标均已知才合成，即使某一预算是零也不隐藏另一来源缺失。预算未知或任一父目标未知，最终目标未知。任一策略退出而另一策略仍有正目标、且对应预算为正时，仍保留相应持仓；最终目标明确为零才请求全部退出。

两档费用共享市场因素和预算，但使用各自父目标。没有来源周期锁定、固定调仓比例或额外趋势进入门槛。实际账户空仓遇正目标进入，已有仓位按自身净值、整百份和十个百分点带宽调整，未知不发新调整，下一开盘执行、受阻每收盘重算、终点开盘清仓。

一项设置，主与较早各两档费用，四条新账户；对照131、139、140和买入持有十六条保存账户。零新模型、零新参考及下载。输入仅从已有完整行情和父决策获取，先核对两因素原定义，必要测试后冻结并一次运行。失败结束本连续公式，不改窗口、归一化或方向救回。旧140至142裁决保留，稳定超额与夏普目标尚未完成。
