# 上交所股票期权历史快照导入协议V1

## 目的

为510300期权O1—O4建立一条独立于新浪前向采集的权威历史盘口输入路径。该协议只冻结官方文件解析与质量审计，不授权购买、不下载受许可保护的数据，也不授权策略收益检验。

## 权威格式

依据上证所信息网络有限公司《上海证券交易所历史数据接口说明书》1.1.5：股票期权历史快照位于 `sho\YYYYMMDD\Snapshot.csv`；连续竞价阶段每秒两幅；包含合约代码、时间、成交与持仓、申买五价五量、申卖五价五量、交易阶段、均价和结算价。文件为UTF-8 CSV。

官方现行价目列示股票期权历史数据为人民币3万元/年。对于2万元交易账户，直接购买多年数据在经济上不可执行，因此本项目保持 `purchase_authorized=false`。只有用户或其机构已经合法取得数据并提供许可证明时，导入器才可运行。

导入器只接受许可根目录下 `sho\YYYYMMDD\Snapshot.csv` 的精确路径。许可JSON及许可证明原件也必须保存在该根目录内；授权产品必须明确为“股票期权历史行情”，研究用途必须被允许，有效期必须覆盖导入日，且证明原件的实际SHA-256必须与JSON一致。仅填写一个形式正确的哈希不能通过许可门槛。

## 冻结选择规则

每个交易日只保留14:59:00至15:00:00内每个合约时间最晚的一幅快照。官方文档的 `DateTime` 为14位、精确到秒，而连续竞价每秒两幅；同秒无法从该字段恢复不存在的毫秒。因此同一合约同一秒出现多行时，按CSV原始行序选择最后一行，并在规范化结果保留 `source_row_number`。不得伪造毫秒或按价格挑选。

用冻结路径的点时合约主表筛选当天全部活跃510300期权，标准合约和调整合约都保留。主表不能通过命令行替换；每个导入日记录主表实际SHA-256。不得以后来可交易、是否有成交或期权盈亏筛选合约。

一个日期必须达到活跃合约100%覆盖、买一和卖一正值比例均至少99%、零倒挂、零重复、文件日期完全一致，否则该日为 `NO_VIEW`。解析器兼容官方数组列和常见的五档展开列，但任何无法明确识别的必要列都会失败，不按列位置猜测。

规范化文件按交易日只允许创建一次。已存在的正式文件、残留临时文件或并发生成的同日文件均拒绝覆盖；协议冻结后允许按日追加，不会因为已有更早日期而错误失效。

## 研究边界

即使合法历史文件全部导入，也必须另行冻结开发期、严格时间留出期、交易成本与期权行权/到期处理规则后，才能进行收益检验。本协议本身不产生因子、仓位、订单或实盘动作。
