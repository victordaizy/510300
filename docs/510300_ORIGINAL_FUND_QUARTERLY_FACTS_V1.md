# 原始基金季报份额与可用时间识别

按已收集的56个季度候选逐份核对，保留55份上交所目录日期和1份目录日期未解决的2013年二季报。三份早期目录简称的年份只用于定位候选，必须由原始报告封面确认，不能仅根据公告年推断。

基金身份以报告封面的完整基金名称、基金主代码或交易代码510300为依据，排除联接基金；不用PDF文档属性中的模板标题判断。早期原始文件的属性标题可能沿用其他基金旧模板，这种情况与正文身份分别记录。

报告封面的年份季度、正文所述起止日期必须相符。报告送出日期必须在本季结束之后。份额表必须位于“开放式基金份额变动”一节，明确单位为份，包含期初、申购、赎回、拆分和期末五项；兼容早期“本报告期”和后来“报告期期间”的同义表述。不能从表外其他持有人数量或基金投资明细误取值。

所有份额先按原文十进制数读取，核对期初加申购减赎回加拆分等于期末，容许最多0.01份尾差。期初、申购、赎回和期末不得缺失或为负数，期初必须为正。拆分格明确横线时保留原文及无活动状态，仅在该表会计等式中按零拆分计算；其他缺失或横线不得擅自变为申购或赎回零值。随后核对每个季度期末与下一季度期初的衔接，差异必须单独列明。

可用日期取上交所目录日期和报告送出日期中较晚者，再取之后第一个A股交易日。收盘型策略只能从这一天收盘使用，下一开盘才能执行。文件夹日期不用于提前信号；PDF创建时间不能代替公布时间。当前PDF创建或修改日若晚于上述公布日期，则版本尚未证明可回填，保留无判断。2013年二季报虽然原始PDF可读，其官方目录证据暂缺，保留数值但不可作为合格历史信号。

这些证据来自现在取得的官方原始公告档案，不宣称在历史时点已经持有不可更改的文件收据。将来若发现更正或版本差异，保留原始结果并登记新的来源修正。本阶段没有训练或计算投资账户。

只输出份额申购、赎回及净变化，不把份额乘季末净值当作实际人民币现金流，也不以一只ETF代表全市场公募申购。验证策略需要另行固定经济假设、有限对照、完整日期、费用与收益计算规则。
