# 510300周线状态—日线执行V1冻结协议

状态：`PROTOCOL_FROZEN_BEFORE_RETURN_CALCULATION`  
研究标签：`HISTORICAL_DISCOVERY_ONLY`  
历史数据截止：`2026-08-14`  
真正前瞻起点：`2026-08-19`  

## 1. 研究问题与边界

检验只由明确技术指标组成的双周期策略，在20,000元510300账户中能否在计入佣金、滑点、T+1、100份整数倍和现金分红后，取得可解释的收益与回撤改善。

本研究不使用背离、波浪、人工画线、盘中主观判断、未来周线、融资、做空或其他资产。输出仅用于历史发现；真实仓位映射、订单生成和券商连接全部关闭。

## 2. 数据与执行

- 市场：510300日线OHLCV，2012-05-28至2026-08-14。
- 基准：510300含分红买入持有、H00300全收益指数、现金、同平均暴露静态组合。
- 信号价格：现金分红连续调整OHLC。
- 成交价格：信号后下一交易日原始开盘价，买入加5bp、卖出减5bp。
- 账户：初始20,000元；现金年化1.5%；每笔100份整数倍。
- 佣金：每腿`max(名义金额×0.03%, 5元)`。
- 最小正常交易：5,000元。风险性全部清仓不受此限制，否则亏损后可能无法止损。
- 仓位档位：32.5%、65.0%、97.5%；初始账户约对应6,500、13,000、19,500元。
- 所有日线信号在收盘后确定，最早下一交易日开盘执行；这天然满足510300 T+1。

## 3. 指标定义

### 3.1 周线

周线由现金分红连续调整日线按`W-FRI`聚合。只有当日为该周最后一个实际交易日时，才可使用包含当日的完整周线；其余交易日只能使用前一完整周。

- `EMA20W`：周收盘价20周期指数移动平均，`adjust=False`。
- `MACD_W`：周收盘价EMA12减EMA26为DIF，DIF的EMA9为DEA。
- `EMA20W_SLOPE4`：当前EMA20W与四周前EMA20W比较。

状态：

- `W_BULL`：周收盘价高于EMA20W、EMA20W高于四周前、DIF高于DEA。
- `W_BEAR`：周收盘价低于EMA20W、EMA20W低于四周前、DIF低于DEA。
- `W_RANGE`：指标可用但不满足以上两种状态。
- `W_UNKNOWN`：指标尚未完成预热。

### 3.2 日线

- `HH20`：不含当日的前20个交易日调整最高价最大值。
- `LL10`：不含当日的前10个交易日调整最低价最小值。
- `ATR14`：Wilder真实波幅14周期递推，首值为前14个TR的算术平均。
- `MA20`、`MA28`：调整收盘价简单移动平均。
- `BIAS28 = 100 × (调整收盘价 / MA28 - 1)`。
- `RSI5`：Wilder 5周期递推，首值由前5个涨跌额的平均涨幅和平均跌幅计算。

## 4. 趋势模块

只允许在`W_BULL`中开仓。

1. 调整收盘价严格高于`HH20`，次日开盘进入第一档。
2. 在`W_BULL`中，收盘价较上次实际买入价上涨至少一个首次入场时冻结的ATR14，增加一档。
3. 每日最多增加一档，最大第三档。
4. 以下任一条件触发次日全部退出：
   - 周线状态为`W_BEAR`；
   - 调整收盘价严格低于`LL10`；
   - 调整收盘价不高于最近一次实际买入价减去两个冻结ATR14。
5. 周线转为`W_RANGE`时保留已有趋势仓位，但禁止加仓。

## 5. 均值回归模块

只允许在`W_RANGE`中开仓。

1. `BIAS28≤-5%`且`RSI5≤25`，次日进入第一档。
2. 第一档后，`BIAS28≤-10%`且收盘价不高于上次实际买入价减一个冻结ATR14，增加至第二档。
3. 第二档后，`BIAS28≤-15%`且收盘价再次不高于上次实际买入价减一个冻结ATR14，增加至第三档。
4. 每日最多增加一档。
5. 风险退出优先级最高：`W_BEAR`、收盘价不高于首次入场价减四个冻结ATR14、或持有达到25个交易日时，次日全部退出。
6. 若同日`W_BULL`且收盘价严格高于`HH20`，优先把现有仓位无交易切换为趋势模块，并以该日ATR和次日开盘作为新的趋势锚点。
7. 若未切换，收盘价达到MA20或RSI5达到60时，次日全部退出。

## 6. 轨道与判定纪律

- `T_ONLY`：仅趋势模块。
- `M_ONLY`：仅均值回归模块。
- `SWITCH`：周线状态选择两个模块，并允许均值回归转趋势。

三个轨道必须同时运行基本成本、零成本和两倍成本。历史结果仅作描述，不预注册“通过”阈值；不得在看到结果后修改本V1参数进行救援。若任一轨道失败，只能登记为`REJECT_WITHOUT_PARAMETER_RESCUE`，新参数必须建立新的独立协议和新的真正前瞻期。

必须输出每日特征、每日账本、全部执行事件、被5,000元闸门拒绝的交易、闭合周期、分阶段收益、成本拖累和实现/输入文件指纹。
