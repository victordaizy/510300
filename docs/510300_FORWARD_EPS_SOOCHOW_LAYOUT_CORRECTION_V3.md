# 东吴旧报告第三版：补充没有总标题的财务表

2026年9月7日。第二版对固定最早250份原件已成功识别90份、264条预测EPS，其中第一版12份成功报告保持一致。其余报告的顺序、公司和时间范围没有改变，尚未读取第十九轮新模型或账户收益。

检查同一固定样本中按顺序前三份“未识别EPS”的原件后，确认三环集团、隆基股份和纽威股份均在附录财务表明确给出逐年EPS，但没有第二版要求的“财务预测表”或“盈利预测表”总标题。其表内有资产负债表、利润表或损益表标题，有带预测标记的年度列，并有每股收益或EPS行。因此增加这类附录页的选择条件，仍按左右半页读取，不从正文猜测年度和数值。

同时接受明确归母净利润行名内部的排版换行，例如“归属母公司净利”与下一行“润”。仅去除行名内部的空白以识别标签，保留原始行名和原始数值行。金额仍必须由同行单位或同半页利润表、损益表的百万元标题证明；百分比增长率不作为利润金额。

已由第二版成功识别的整份报告事实逐项保留，第一版和第二版文件不修改。本版只对第二版未成功报告应用新增版式。年度必须连续，预测列仍必须明确标为预测；精确列数、证券与机构身份、报告日期、较晚公开日期、多个表格冲突和未知EPS定义的处理均保持。缺失市盈率不从当前价格或正文倍数补造，未明确的单位和股本定义保留原状。

仍先检查相同的最早250份固定样本。完整6734份原件归档结束后才进行完整事实提取。本版是来源排版修正，不是新增交易方法，也不增加或更改第十九轮的任何进出场参数、训练样本门槛或成本。
