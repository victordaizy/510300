# 第136轮：两套参考组合的月度共同风险预算

本轮一个固定设定，复用132下行风险目标与91连续两策略预算目标。按过去已知的两条基础费用净收益共同波动分配比例，检验能否改善134固定各半和135历史收益排名。预算公式沿用82原控制器，底层不重新训练或建立新参考；新来源来自已观察历史，不能算独立验证。

两套来源都交易510300，原各参考继续保留自己的模型、持仓和退出状态。新账户有自己的现金、份额、分红和成交，不能将新账户持仓倒灌或重置参考。

## 第一来源：第132轮下行风险目标

132先按128固定入场模型参考产生进入、持有或退出意向，再用既定下行风险幅度决定规模。以下涉及持仓的八项因素属于128自己的参考账本。

### 参考使用的全部因子

进入指标是最近六十日日内含分红对数涨跌减隔夜含分红对数涨跌之差的合计，再除以这些日差值的样本标准差与六十的平方根。它衡量日内相对隔夜强弱，不是未来收益。

参考退出模型的八项因子如下，涉及持仓的数值均属于参考自己的账本：

1. 含买入日在内已经观察的持仓收盘交易日数，加一后取自然对数。
2. 实际份额市值加本周期已确认分红，除以参考真实买入金额与佣金之和，再减一，表示周期浮盈亏。
3. 同一含分红持仓价值相对周期最高价值的回撤，初始最高值至少等于买入总成本。
4. 原日内隔夜强弱进入类别，固定为一。
5. 最近五日含分红对数涨跌。
6. 最近二十日含分红对数涨跌。
7. 含分红财富相对包括当天的一百二十日平均值的偏离。
8. 最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

### 参考模型与进出场如何确定

复用原114的141条月度模型记录，其中114个成熟模型、27个支持不足；最早成熟日2017年3月1日。模型原本只纳入当时已自然完成的最近二十个参考周期，至少十周期、一百个状态。每周期总权重为一，各状态等分。目标是继续至原自然退出相对下一开盘提前退出多出的净收入，除以下一开盘参考市值，含既有费用及新增分红权益；原标签近似不等于独立成交验证。

八项因子按周期等权均值和标准差标准化，限制在负五至正五，近零标准差以一代替。各周期内减去自身平均因子和平均目标，以周期内变化求线性系数，系数平方惩罚为一、不加统一截距。各成熟周期截距不受惩罚，新参考持仓使用这些成熟截距的等权平均；不能用尚未完成周期的未来结果估计截距。

每笔参考实际买入日的第一个收盘选择当时最近的成熟模型版本，固定系数、均值、标准差及截距到实际卖完，当前八因子每天更新。第一次没有成熟模型，该笔全程没有学习预测；当前输入缺失也不补预测，连续负预测计数清零。新一笔才重新选择版本。以上均为已保存参考的原规则，本轮没有新模型拟合。

参考进入：六十日强弱连续两个收盘严格大于一、必要资料完整、空仓、有再次进入资格，且距上次全部卖出至少两个交易日，下一开盘以参考可用资金单次买入整百份。参考不追加或部分卖出。

参考退出：固定版本连续两个持仓收盘预测继续收益为负；六十日强弱连续两收盘小于零；含分红周期亏损达到百分之六；距周期最高含分红价值回撤达到百分之八；或含买入日在内已经持有六十个收盘交易日。任一成立，下一开盘全卖并锁定到实际卖完。无模型时可知价格与期限保护仍执行。卖完以后须先看到原进入条件消失，再等其重现并满足两日等待，才能再次进入。

### 下行风险规模如何计算

每天含分红简单收益是收盘价加当天每份除息分红，再除以前收盘价，减一。最近连续二十日，把负收益平方相加后除以二十，上涨及零收益贡献零，分母仍包含完整二十日；不减窗口平均收益、不删除未知日。结果乘二和二百四十二后开平方，就是既定风险幅度。

每天用百分之十除以已知正风险幅度，最多取一；零风险或窗口未知时沿用最近一次明确乘数，初始一。128参考意向为一，132目标为此乘数；明确零意向则零目标；参考意向未知则目标未知。乘二是既定理论尺度约定，不根据本轮结果改变。

132基础费用目标来自基础费用128参考，压力费用目标来自压力费用参考，二者可能因原参考浮盈亏影响退出而不同。只取保存收盘目标，不取下一开盘已成交股份。132实际账户的净值、收益或持仓不直接移入本轮。

## 第二来源：第91轮连续两策略预算目标

第91轮内部以基础费用运行急跌回升和学习退出两个连续参考，按已实现风险调整预算。以下完整原始进入、退出及八因子规则保留；这里的原模型是31的带统一截距岭回归，与上文128使用的114周期内模型不同。

### 两条策略如何产生原始信号

急跌回升策略进入须同时满足：含分红五日累计跌幅超过5%；当日含分红财富较前一日回升；收盘位于当日高低价区间至少60%的位置；最近5日含分红简单收益样本标准差高于最近60日的1.5倍。收盘位置等于收盘减最低价，再除以最高减最低价。原完整性要求保持，缺失不能伪造进入。

急跌策略在任一条件成立时请求下一开盘退出：含分红财富回到20日均值或以上；本周期含分红实际亏损达到4%；本周期含分红收益达到6%；含买入日在内已持有10个交易日。均值回复因子等于财富减20日均值，再除以20日财富样本标准差。实际退出后至少等2个交易日，不另加旧信号消失要求；原参考退出受阻仍保留退出意图。

学习策略的进入因子为60日日内对数收益减隔夜对数收益的标准化和。每日隔夜为开盘加当日每份分红相对前收盘的自然对数变动，日内为收盘加分红相对开盘加分红的自然对数变动。60日差值合计除以60个差值的样本标准差与60平方根的乘积。连续两日严格大于1、当日有效、参考账户空仓、有重新进入资格、距实际退出至少2个交易日，才请求下一开盘进入。

学习退出保留八个因子：持仓交易日数加1的自然对数；参考账户实际含分红浮盈浮亏；参考持仓价值相对本周期最高价值的回撤；固定为1的进入类别；含分红5日及20日对数涨跌；财富相对120日均值的偏离；20日含分红简单收益样本标准差乘242平方根。持仓价值为实际份额市值加本周期已确认分红，成本为实际买入金额加佣金，初始高点至少为该成本。

原模型每月收盘后只用当时已结束的最近20个参考周期、至少10周期100条记录、每周期等总权重训练。八因子按原加权均值与标准差标准化、限制在负5至5，原带截距岭回归惩罚1。预测为截距加八项标准化因子乘原系数的合计；目标为继续持有到参考自然退出相对下一开盘提前退出的含成本和新增分红价值差。本轮直接复用114个成熟模型及27个无模型时点，不重新拟合；全部逐月数值保存在原第31轮模型档案中，本轮没有重新估计。

学习策略任一条件成立即请求下一开盘全部退出：60日强弱连续两日小于零；含分红亏损6%；持仓价值从高点回撤8%；持有60交易日；原预测连续两个持仓收盘为负。没有模型时原价格和时间退出继续。退出请求受阻保留，实际卖出后须先在空仓期间看到旧完整进入条件消失，再等其重现，并满足原两日冷却。上述持仓因子属于原基础费用参考账户，不是合并账户的预测。

### 历史起点与退出学习

连续参考起点沿用第31轮已经确定的2013年6月3日，不搜索起点。该日起原急跌回升策略和原线性学习退出策略各自以二十万元、原基础费用建立参考账户，持续到2026年8月14日统一开盘终点。两条参考都记录完整现金日、实际份额、佣金、滑点和分红权益。

急跌回升使用原第26轮第六条进入退出规则；学习退出使用原第32轮线性退出及等待新机会规则。模型复用原第31轮已经保存的八因子、月度系数和成熟时点，不再训练。按判断收盘取不晚于该日的最近保存模型；此前无有效模型时保留原价格退出，不把以后模型提前使用。

已核对原线性模型在2014年12月31日只有一个成熟参考周期、59行，尚不满足十周期和一百行下限；其首次有效拟合为2017年3月1日。因此提前至2013年运行参考时，没有遗漏当时原本可用的已训练模型，也不能把2017年模型用于2015年。前置样本的成熟时间继续受原模型控制器检查。

### 因子、预算与每天的股票目标

风险估计完整沿用第82轮：每月首个交易日收盘，使用连续两参考账户最近242个完整日净收益。计算两条样本方差、样本协方差和两者收益差的样本方差。急跌预算为学习方差减协方差，再除收益差方差，限制在零至一；学习预算是一减急跌预算。

2013年参考启动时预算各半，之后只在月首更新；窗口不足、缺失、任一参考零波动或收益差零方差，保留无观点及上次预算。预算连续积累，到2015年或2020年新资金建账时不重新置为各半。没有加新因子、调整风险窗、改变协方差公式或挑选预算范围。

每个收盘，股票目标等于急跌预算乘当时急跌参考持有意向，加学习预算乘学习参考持有意向。两条参考状态也连续保留原周期、退出请求及等待新机会规则。因此相比原第82轮，本轮同时改变参考路径的历史状态和风险预算起点；不能把结果全部解释为某一个协方差因子改善。

两条参考意向有任何缺失，股票目标为无观点。没有插值、前向补齐或把缺失目标当作现金。

## 本轮新增的风险因子及预算规则

每段历史开始的准备收盘，132和91预算各为一半。每月首个交易日的完整收盘，用该段两条基础费用账户截至当日的最近242个完整日净收益估计风险，包含现金日。其余日保持预算。不得读取该段开始前尚不存在的父账户收益；终点开盘清仓收益不属于收盘窗口。

本轮新增的风险量为：第一条净收益的样本方差，第二条净收益的样本方差，两条收益的样本协方差，以及每日第一条收益减第二条收益之差的样本方差。样本方差是每日减去窗口平均值后的平方和除以241；协方差是两条各自减均值后的乘积和除以241。收益差的方差直接计算，避免近似相同方差相减出现数值误差。

132预算等于91的样本方差减协方差，再除以两条收益差的样本方差；结果限制在零至一。91预算为一减132预算。预算表示两个目标各占的权重，不是直接股票仓位。两来源收益差波动越小，必须注意分母是否为零；窗口不足、任何日缺失、任一参考零波动或收益差零方差，保留“无新风险估计”和此前预算，不补零风险、不删除缺失日。

这个解析式对应给定协方差估计下的两来源最小方差目标，不保证未来最高夏普。[CVX研究组组合优化课程](https://www.cvxgrp.org/cvx_short_course/docs/applications/notebooks/portfolio_optimization.html)说明了协方差、组合方差与无卖空预算约束。本轮没有拟合新的预期收益，也未用过去夏普排名。

两档费用共用由原基础费用净收益计算的同一组预算。每天合成目标为132预算乘对应费用的132收盘目标，加91预算乘对应费用的91收盘目标。任一父目标未知，则合成目标未知，即便其预算为零也不放松完整性要求；两个明确零目标才明确清仓。一条退出、另一条仍有正目标且其预算为正时，保留另一条相应规模。

## 实际账户的进入、持有、退出和再次进入

实际空仓且合成目标明确为正，按该收盘自己的总净值、收盘价和100份整手提出下一开盘买入请求。持仓时，实际股票市值占净值与正目标相差不足十个百分点，保持份额；达到或超过十个百分点，按自身净值重新确定整手份额并增减。最终成交仍受现金、费用和交易条件约束，不能把两条历史净收益按预算相加当成实际账户。

合成目标明确为零，下一开盘请求卖出全部份额，不受带宽限制。合成目标未知，不发起新调整。每个收盘根据最新目标重算受阻请求，外层没有额外永久退出锁定；底层参考的锁定保持。实际卖完后出现明确正目标可再次进入，不另加冷却。终点统一按开盘优先全卖，不使用末日尚未知的收盘。
