# 第44轮：预测五日内的继续持有价值

## 只修改学习目标

原第32轮线性退出候选的模型预测“继续持有到原参考周期自然退出，比下一开盘卖出能多赚多少”。原日内强弱参考数据有34个自然结束周期、1461条合格持仓状态，标签跨度从一个至五十九个开盘间隔，长周期收益对目标幅度的影响较大。跨度不同是已核实的数据事实，尚不能认定它就是失败的原因。

本轮只检验一个新设置：假设先在下一开盘决定是否退出，继续持有方案最多再经过五个开盘间隔后退出；如果原参考周期更早自然退出，就用该更早日期。这样比较的是五日以内继续持有的价值。五个间隔的上限固定，不根据结果换成三日、十日或扫描更多期限。

复用第31轮同一日内强弱策略参考状态、相同八个因子、原周期等权方式和岭回归容量，保留第32轮实际卖出后等待新机会规则。第38轮曾改变旧周期权重，第43轮曾提前模型检查时刻；这些不同设置的失败保留，本轮不修改它们。此前市场收益模型和整笔交易入场模型不等于本轮实际持仓状态下的短期退出标签。

## 新标签如何计算

以某日收盘持仓状态为例，第一种方案在下一交易日开盘立即卖出，之后持有现金。第二种方案继续持有，到“再经过五个开盘间隔”与“原参考周期自然退出”两个日期中较早的开盘卖出。

两方案按原参考份额计算净卖出所得，各自扣除基础佣金、最低费用、滑点和价格最小单位影响。第二方案减第一方案的净卖出所得，再加仅因多持有而新增的分红权益，除以第一方案开盘时该份额的未扣费市值，作为学习目标。双方共有的买入成本不重复扣除。

新增分红只包括第一方案卖出当天及之后、第二方案卖出日之前的股权登记日。第一方案卖出前已经取得的权益两边都有，不重复加入；第二方案卖出当日收盘才登记的权益不取得。是否属于新增权益取决于登记日，而不取决于现金到账日。

目标比较沿用既有假设开盘退出价格，不能证明当时真实订单可成交。实际账户另按涨跌停、次日可卖和未成交意图保留规则处理。

## 每月如何学习，何时可以使用

参考状态和原周期结束时间不改写。即使某条五日内标签已经发生，整个原参考周期尚未自然结束时，该周期仍不能提前进入训练。每月首个交易日收盘后，选择当时已自然结束、具有合格状态的最近二十个原参考周期；至少十个周期及一百条状态才训练，否则保留无模型状态。

每个周期总权重为一，周期内各条状态均分权重。对八个因子按训练权重计算均值和总体标准差，零标准差用一代替；减均值、除标准差，再限制在负五至正五。用带截距的岭回归预测新目标，系数惩罚固定为一，截距不惩罚。参考方法：[岭回归官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。

每次训练的周期名单、行数、训练可用时点、标准化均值和标准差，均须与原模型完全一致；改变的是目标值及随后学习的系数。训练完成时间记为当日15时05分，使用当时已成熟资料形成次日开盘的退出请求，不在当天开盘使用当日收盘训练结果。全部逐月实际均值、标准差、截距和系数保存为中文。

## 全部因子

|因子|中文定义|
|---|---|
|日内相对隔夜强弱|每天的日内对数涨跌减隔夜对数涨跌；六十日差值之和除以该窗口样本标准差及六十的平方根。日内和隔夜使用原含分红一致口径，用于原进入与价格退出。|
|实际持仓时间对数|从实际买入日起算到当前的交易日数，买入当天为一；再加一后取自然对数。|
|持仓含分红浮盈亏|实际持有份额乘当前收盘价，加本周期已确认分红，除以实际买入含佣金成本，再减一。|
|持仓回撤|上述持仓价值除以本周期截至当前的最高收盘持仓价值或初始买入成本中的较大者，再减一。|
|进入模式|原日内强弱模式，固定编号一。|
|五日涨跌|当前含分红总回报水平除以五个交易日前水平，取自然对数。|
|二十日涨跌|同上，比较日期为二十个交易日前。|
|一百二十日均线偏离|当前含分红总回报水平除以最近一百二十日该水平的平均值，再减一。|
|二十日年化波动|最近二十日含分红简单日收益的样本标准差，乘二百四十二的平方根。|

第一项用于原进入和原退出，后八项为退出模型的全部输入。没有新增EPS、估值、公募、分钟时刻或价格高低点因子。

## 进入、持有、退出和重新进入

日内相对强弱分数连续两个收盘大于一，账户空仓，进入许可有效，且距离上次实际卖出至少两个交易日时，在下一开盘请求买入可用现金能负担的100份整手。信号收盘估算份额，实际开盘按当时价格和费用检验可用现金，不假设跳空前后能买到相同份额。

实际买入消耗一次进入许可。持仓只买一次，不追加；买入当天为持有第一天，当天不能卖出。

任一条件成立，就请求下一开盘全部退出：原相对强弱分数连续两个收盘小于零；实际含分红持仓亏损达到6%；含分红持仓价值从本周期最高收盘价值回落8%；持有满六十个交易日；本轮新模型连续两个真实持仓收盘预测五日内继续持有收益严格为负。

预测为零或正数、模型缺失或因子不全，会使普通负预测连续计数归零，不新增模型退出条件，原价格和持有时间保护继续有效。缺失不是零预测，也不是空仓目标。

退出请求形成后，即使以后预测转正也不取消；遇方向性跌停或其他未成交情况，逐日请求直到实际卖完。实际卖完后至少等两个交易日，并在空仓期间观察到原进入条件消失、随后重现，才允许下一次买入。暂时无法成交的买单不消耗进入许可。

## 账户、比较与停止条件

主评价2020年1月2日至2026年8月14日开盘，1604个账户日；较早诊断2015年1月5日至2019年12月31日开盘，1219日。两个时期各从20万元开始，仅510300和现金；现金及无风险收益零，年化242日。

基础费用为单边佣金万分之二、最低5元、滑点万分之五；压力费用为单边佣金万分之四、最低5元、滑点千分之一。100份整手、0.001元、方向性涨跌停、买入次日可卖、分红应收和到账、实际未成交、统一终点开盘退出均不变。

每段一个新候选两档费用，共2条新账户；原线性退出、原不学习退出但等待新机会、买入持有三项对照两档费用共6条复用账户。每段8个评价记录，两段共4条新账户。没有新参考账户、没有新行情下载，只对原参考状态改写标签并重新训练。

先验证标签期限、股权登记边界、尚未结束周期不得提前训练、未来价格不得越过标签终点和原短标签不变，再冻结唯一设置并计算。无明显局部改善就停止该期限和相邻期限的细调。目标仍为完整扣费净夏普至少1.2及稳定超额，不因为更换标签降低验收要求，不以某个较好时期或历史点估计替代独立证据。
