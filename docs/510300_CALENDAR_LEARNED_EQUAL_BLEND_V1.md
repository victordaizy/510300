# 第57轮：月内两端与原学习退出各半

## 本轮只检验策略互补

只登记一个新组合。原月末月初规则与原日内强弱学习退出规则分别产生状态，各贡献一半预算，合并到一个510300与现金账户。两个原规则、日期条件、学习模型和退出参数都保持，不按本次收益选择权重。原月历、原学习退出、原急跌回升与学习退出各半、买入持有四种作对照。

前两轮增加入场筛选没有改善原基线。本轮检验不同日期机制能否补充原学习策略的空仓时间。互补只是待检验假设；两个信号都交易510300，不能称为统计独立或预先保证降低风险。既有日历定义与来源解释保留在[第6轮原协议](510300_CALENDAR_LIQUIDITY_TIMING_V1_PROTOCOL.md)，不追加行情、资金流或盈利来源，不重训六个旧日历模型。

## 日历状态的三个因子

|因子|中文计算规则|
|---|---|
|月内开市序号|在计划成交日早上九点，从本月第一次已经发生的开市日累计到当天，得到第几个开市日；只用当天及此前的日期。|
|本月剩余自然日|本月自然日总数减去计划成交日的日期号，闰月和月长用公历确定。|
|月内两端状态|开市序号不超过3，或者本月剩余自然日少于5，任一成立记为1，否则记为0。|

所以月初前三个交易日及月末最后五个自然日中的实际开市日，日历状态为1。这里不是月末最后五个交易日。日历状态在实际成交日九点形成，开盘尝试成交；不能得到进入日前一收盘到进入开盘的收益。月初第三个交易日持有的份额，在第四个交易日开盘请求退出。

使用第6轮已保存的日历因子，核对其全部价格字段与当前原价格数据相同。历史日期表可以支持日期算法重放，但没有证明旧日期接口每次历史首次交付时刻，所以不宣称严格前向服务已经运行。

## 原学习状态的进入与退出

这一状态使用第32轮基础费用完整参考账户在前一交易日收盘已经形成的记录，两档新组合共用它。它是独立维护的参考策略状态，不能假装是新组合自身半仓或满仓产生的持仓状态。原模型依照参考账户自己的实际买入成本、持仓天数和周期最高价值计算。

原入场因子为：每日含分红日内对数收益减含分红隔夜对数收益，最近六十日合计除以同六十日每日差异的样本标准差和六十的平方根。隔夜是当日开盘加每份分红相对前收盘的自然对数；日内是当日收盘加同一分红，相对当日开盘加分红的自然对数，两部分相加为每日总回报。

该因子连续两个收盘严格大于1，参考账户空仓、再入场许可开启、距离上次实际全部卖出至少两个交易日，才请求下一开盘买入。参考账户单次进入，不在持有中追加。只有实际买入才消耗再次进入许可；实际卖出后旧入场条件必须先有一个收盘不成立，以后重新成立才可再进入。

原参考账户在以下任一成立时请求下一开盘全部退出：入场因子连续两日小于零；含已确认分红持仓亏损达到6%；从本周期最高收盘持仓价值回撤达到8%；实际持有达到60个交易日；原线性模型连续两个收盘预测继续持有价值为负。退出受阻继续请求，原入场条件没有消失时不重复买回。

参考状态为1表示原规则请求买入或继续保留已有持仓；请求退出或空仓等待为0。状态与实际已经成交的库存不同，组合据此在下一开盘按自己的现金、份额和交易约束调整。

## 原退出模型的全部八个因子

|因子|中文计算规则|
|---|---|
|持仓天数|实际买入当天为第1日，累计到当前收盘，对一加天数取自然对数。|
|含分红浮盈浮亏|参考账户份额乘当前收盘，加本周期已确认分红，除以含买入佣金的实际买入成本，再减一。|
|周期回撤|上述当前价值除以周期最高收盘价值，再减一；最高值初始至少为买入成本。|
|入场模式|日内强弱的单一模式，固定为1。|
|五日涨跌|最近五日含分红对数收益之和。|
|二十日涨跌|最近二十日含分红对数收益之和。|
|一百二十日均线偏离|当前累计含分红总回报水平除以最近一百二十日均值，再减一。|
|二十日波动|最近二十日含分红简单收益的样本标准差乘242的平方根。|

原模型每月首个交易日收盘使用当时已自然结束的最近20个原参考持仓周期，至少10个周期及100条记录才有模型，各周期总权重相同。目标是继续至原参考退出相对下一开盘立即卖出后持现金的净收益差，计入两种方案新增分红权益差；完整参考周期结束后才能用于训练。

八因子减训练加权均值、除以加权标准差，零标准差用1，再限制于负5至5，乘原月度系数并加截距。线性模型惩罚强度为1，截距不惩罚。无成熟模型或因子不完整时保持无有效预测，负预测连续计数归零，只执行原保护退出。新周期重新计数。全部参考月度模型和状态已经保存，本轮不重新训练或改变其标签。

## 组合如何进入、减仓、退出和重新进入

每个计划成交日九点读取当天日历状态，以及前一交易日收盘后的原学习状态。价格仅用前一收盘；当日开、高、低、收和成交量都不参与九点目标。目标股票仓位等于两个状态各乘一半再相加。

|日历状态|原学习状态|组合股票目标|对应操作|
|---|---|---|---|
|0|0|零|请求全部退出，转为现金。|
|1|0|一半|空仓时进入半仓；已有较高仓位时减到半仓。|
|0|1|一半|同上，由原学习状态提供预算。|
|1|1|全部|进入或增加至全仓预算，不融资。|

原学习状态退出时，如果日历状态仍为1，组合只降至半仓；日历窗口结束时，如果原学习状态仍为1，也只降至半仓。只有两者都为0才请求全部退出。没有对整个组合新增一个6%或8%止损，不能把原参考账户的止损误写成组合一定清仓。

每天按新目标和最近收盘估算份额，用已有现金、库存及应收计算参考净值。非零目标与当前仓位相差不足十个百分点时保留份额，否则调整为100份整数手；目标归零、从零进入不受该带宽限制。实际09:30开盘按滑点、价格刻度、费用、现金、T+1及方向涨跌停限制尝试成交。只在开盘调整，不使用当天高低价补成交。

组合允许增加、部分卖出或全部卖出。未成交部分不保证机械延续，下一九点按当时两个状态重新计算；若两者仍为零，继续请求退出。任一状态缺失时保留无有效目标并维持已有份额，不能以零补缺失。本轮要求两段全部实际决策有完整状态，出现缺失则如实停止该评价，不能删日期。

组合自身没有另加等待天数。日历状态重新开启时可以再次获得半仓预算；学习一半的预算仍受原参考策略的等待和许可约束。各半指每次调整的目标预算，不是把两个已经算好的净值直接平均。
