# 前瞻EPS：保留原仓位计算，只改变退出条件

登记日期：2026年9月6日。此前仅前瞻EPS的月末收益风险方案，完整账户夏普为0.619；该结果已经看过，本轮属于继续研究，不能作为独立样本验证。此前满仓进场的每日退出方案还改变了入场过滤和仓位，不能把两者差异全部归因于退出。

## 本轮固定比较

只检验两个新增方案，各用基础和压力费用。另重现原月末方案与买入持有对照，共八条账户。复用已经保存的前瞻EPS预测，不重训、不改变因子、不选新的日期区间、不搜索参数。

1. **预测有效期退出。** 月末正常更新收益预测并计算仓位。持仓期间，如果最近一次有效的月末预测已经满六十个交易日、期间没有新的有效预测，则在当天收盘确定清仓，下一交易日开盘请求卖出。新的有效月末预测会重新开始六十日计时；不按最初买入日期机械清仓。
2. **预测有效期加趋势退出，作为本轮主方案。** 包含第一条，另在含分红价格连续两个收盘不高于其一百二十日均线时清仓。此处均线针对含分红总回报价格，避免把除息机械下跌当作趋势损坏。

## 入场、增持、减持、清仓、再入场

只在月末最后一个交易日收盘，使用当时已经形成的、预测未来六十个交易日收益的前瞻EPS模型。模型有有效预测时，比较维持当前份额，以及零、四分之一、二分之一、四分之三、全部资金五档目标；所有目标按一百份整手及实际可用现金计算。

比较分数为：目标股票占比乘以预测收益，减去两倍的目标股票占比平方乘以六十日收益方差，再减去本次预计交易成本占总资产比例。六十日收益方差是过去六十日含分红日收益样本方差乘以六十。以分数最高的实际份额为目标；近似同分时优先保持原份额。

目标份额比当前多，就在下一交易日开盘买入或增持；比当前少，就减持；目标为零就清仓；相同则持有。不额外要求价格在均线以上才能首次进入，保留原方案的入场逻辑。独立退出会改变实际账户财富与后续可买份额，这属于退出政策的后果，不强行锁定旧账户股数。

独立退出优先于同日月末仓位调整。清仓请求一旦形成，即使后来趋势恢复或出现新预测，也持续请求到实际卖完。退出后只能在下一个符合原月末预测条件的决策时点再入场，本轮没有另外添加五日冷静期或新的再入场过滤。重入后若趋势仍坏，可能再次快速退出；相关费用全部计入，不隐藏这种缺点。

缺失的盈利预测不当作零，不自动解释成看跌；已有份额先保留，独立的有效期限和趋势规则仍逐日检查。空仓时不因缺失而产生买入。

## 相同的账户与执行口径

初始资金二十万元，研究期为2020年1月2日至2026年8月14日开盘退出，含早期无预测的现金期。交易只用510300和人民币现金，一百份整手，下一开盘执行，遵守当日方向涨跌停和当日买入不能当日卖出。无法成交的独立退出保留等待状态，成交价格不会强行写成触发价格。

基础费用为佣金万分之二、单笔最低五元、单边滑点万分之五；压力费用为佣金万分之四、最低五元、单边滑点千分之一。计入现金、份额、分红及应收分红，现金收益与夏普参考收益均为零，每年按二百四十二个交易日年化。
