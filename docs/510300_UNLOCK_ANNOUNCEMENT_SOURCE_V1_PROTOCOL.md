# 510300解禁公告信息：原始来源取得协议

目标保持为仅510300与人民币现金，成本后复合年化至少10%、净夏普至少1.2及独立验证。本文件只约束新增来源取得，不能用来源通过代替该目标。IF、AH和EPU既有用途终态不变。

## 已完成的有限探测与方向选择

先查项目配置、研究代码、脚本、文档及旧研究对象索引。命中的现金要约、限售承诺文字、持仓减量等不是同一个510300解禁公告密度用途；未找到同输入同用途终态。该查重不代表所有可能语义都被机器证明不存在。

新浪2016-01、2020-01、2024-01三个月的公开汇总表能够返回历史记录，但其公告日期有时是多年前原股份形成公告。例如金贵银业2024-01-31解禁5,336,309股的页面公告日为2017-04-21，而2024-01-29原公告说明股份经2023年司法拍卖过户。该汇总表不能直接构成事前确认数量和日期。

东方财富RPT_LIFT_STAGE可以取得历史解禁信息，但EUTIME是可变更新时间，立昂技术2020-02-03事件的记录带2020-05-15更新时间；首次字段探测的ALL响应还包含解禁后20日涨跌字段，原始响应单独保留且不准入特征。后续请求明确排除这些行情和结果字段。该类最新状态表不能冒充完整历史发布版本。

巨潮历史公告接口直接提供公告ID、日期、标题和原始PDF路径。初步查询2016-01、2020-01、2024-01的“上市流通”分别得到190、303、348条命中。搜索会分词，必须再按固定标题规则过滤。API报告totalpages分别6、10、11，实际末页7、11、12不能漏掉；已实取2016第7页10条、2024第12页18条，确认应按ceil(total/30)而非返回的totalpages计算完整页数。

因此只推进原始公告活动信息：统计当时沪深300成分股发布限售或已发行股份上市流通公告的密度。它不声称解禁即减持、不使用最新市值、事后实际解禁量或未取得版本的历史指数权重。是否存在收益增量必须另行冻结后检验。

## 本次有界采集合同

2015-01-01至2026-08-14，按自然月独立查询公开接口，搜索词固定“上市流通”，每页30条，同时最多3个月，每个月最多100页，每页最多2次网络尝试。每次响应先原样写入独立文件并留时间、请求参数、SHA-256；失败也保留，不关闭TLS、不购买数据、不需要API密钥。

每月页面的总记录数必须一致，集合内公告ID不得重复，实得数量必须等于声明总量，最后一页不得遗漏，返回公告日期必须在请求区间。任何一个月不完整时，全历史覆盖不得记通过；不得把缺页日期当作零公告或回填旧数据。当前API分页是否稳定必须由实际完整返回验证，不能仅用首末页推断中间完整。

全部原始命中保留。处理标题只去掉HTML标签、统一空白，要求包含“上市流通”并匹配“限售|已发行股份”。核查、法律、保荐等重复意见文件以及更正、取消、延期等修订文件不计作原始解禁公告；修订类保留单独清单。没有宣称修订内容无影响，后续用途不得据此还原已确认解禁数量。

同一公司、同一公告日期的多个合格公告在后续公告密度用途只构成一个公司日，不作为多个独立信息机会。本阶段保留逐公告原始记录而不计算收益。

成分成员采用既有正式准入的2015—2026逐日300股名单，读取前核对明确SHA；公告在非交易日时只用于下一交易日的成员归属诊断。最终模型的有效时钟、使用的是公告前还是决策日成员集、训练和账户规则均须事前另行冻结。历史权重仍未准入，本阶段不会使用它们。

## 输出与停止条件

输出全部原始分页响应、逐页尝试回执、每月覆盖表、全部公告表、合格与修订标题表、成分股覆盖统计、采集完成回执和可复核代码。只有分页完整且ID、日期、成员输入一致才允许将此来源推进至有限模型协议设计；不是模型准入或策略达标。

若公开接口拒绝、声明量不稳定、重复ID或缺页，保留精确失败状态与未完成月份，不立刻把其他汇总表拼进来。先核实同一运行进程与请求凭证；观察超时不能触发重复启动。最终按默认要求提供含失败证据的GPT审阅包。整个采集阶段0新收益标签、0模型、0账户、0订单。
