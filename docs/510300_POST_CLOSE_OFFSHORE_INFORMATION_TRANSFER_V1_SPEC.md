# 510300 盘后离岸信息传导 V1

## 定位

本分支只研究 `SGX FTSE China A50 Index Futures` 在上交所 15:00 收盘后、盘后固定价格交易开始前的价格变化，是否能够前向解释 510300 从当日收盘价到下一交易日 09:35 的传导收益。

研究资产始终只有 `510300.SH` 与 `CASH_CNY`。A50 期货只作为信号，不持仓。当前阶段为 `FORWARD_ONLY_DISCOVERY`，仓位影响为零，不连接券商，不发送订单，也不假设成交。

## 制度事实与研究时钟

上交所《交易规则（2026年修订）》自 2026-07-06 生效。第 3.7 节明确：盘后固定价格交易覆盖 A 股和 ETF，15:05–15:30 以当日收盘价按时间优先连续撮合；收盘定价申报从 9:30 起即可接受，未成交申报可撤销。

因此，V1 的 15:05 意向时点是为了先观察 15:00:00–15:04:30 的 A50 信息，不是交易所最早允许申报的时间。更早申报者可能具有时间优先优势，这一差异必须反映在真实成交率中，不能被历史价格回测抹去。

冻结时钟：

```text
A50观察：15:00:00 至 15:04:30
研究订单意向：15:05:00
未来获单独授权后的撤单时点：15:29:50
理论盘后价格：510300当日官方收盘价
固定退出观察：下一上交所交易日09:35
```

## 前向边界

- 2026-07-06 至 2026-08-31 只允许检查数据格式、交易时段和时间戳，不读取策略收益。
- 权威前向起点为 2026-09-01；若当天合同不合格，起点顺延到首个合规日，遗漏日期永不回填。
- 旧制度下的分钟数据不得作为盘后可执行历史。
- 当前没有合规 A50 分钟历史输入，因此初始状态为 `NO_VIEW`，不得假定 `beta=1`。

## 传导系数

每日观测定义为：

```text
x_t = A50(15:04:30) / A50(15:00:00) - 1
y_t = 510300(next 09:35) / 510300(close_t) - 1
```

只使用此前已经成熟、合同完整的全部前向日估计 `y = alpha + beta*x + error`。至少 60 个成熟日后，使用带截距 OLS 与 Newey-West/Bartlett 协方差，取单侧 95% 的 `beta_LCB`。当日观测不进入当日估计。

只有 `beta_LCB > 0` 且 `beta_LCB * x_t >= 42bp` 时才写入信号账和零仓位订单意向账。阈值来自 3 倍 14bp 压力往返成本，不允许通过结果搜索。

## 四套记录

除传导观测账外，必须保留三套相互独立的账：

1. `SIGNAL_LEDGER`：所有达到冻结信息门的日期。
2. `ORDER_INTENT_LEDGER`：对应的 15:05 零仓位研究意向；授权数量恒为 0，绝不发送券商。
3. `ACTUAL_FILL_LEDGER`：当前为空；没有另行实盘授权时，程序拒绝写入实际成交。

未成交信号不得删除。`SIGNAL_RETURN` 只能被标为理论信息方向结果；`ACTUAL_FILL_RETURN`、`FILL_PROBABILITY` 和 `CAPACITY_ADJUSTED_RETURN` 在真实订单与成交出现前均为 `NO_VIEW_NO_LIVE_AUTHORIZATION`。

## 停用门

以下任一条件触发 `NO_NEW_ENTRY`：`beta_LCB<=0`、20 个成熟真实成交事件的净均值下界不大于零、成交率相对发现期下降至少 50%、最近 10 个有效信号全部未成交、毛边际低于 28bp、或制度/数据合同失效。

这些停止门不授权交易。任何 100 份实盘可执行性测试都必须另行书面授权并建立新版本的执行合同。
