## 因素与基准怎样确定

完整账户净资产等于现金、股票按收盘价计价的市值和已确认但尚未到账的分红之和。仅在实际从零份额转为正份额时建立新的持仓周期。周期基准是产生这次实际首次买入申请的前一收盘、新账户自己的净资产；包括那次买入成本以及随后真实损益，不能用买入后已经涨跌的当日收盘净资产重置基准。申请买入但未成交时不开始周期；再次申请则使用新的事前收盘净资产，最终以实际成交对应申请确定基准。

持仓期间部分加减仓均不重置基准，基准不跟随历史最高净值上移。周期收益为当前完整账户净资产除以该固定基准，再减一。现金、费用、分红应收和价格变化都进入本账户净资产；不使用父策略的损益或日后才能知道的完整周期利润。亏损阈值是整个账户的1%、2%或3%，不是股票价格的同等跌幅，也不是买入金额加总的收益率。

每天形成请求时保存原目标、最终执行目标、周期基准、当前周期收益、是否触发保护、是否仍等待卖完、是否等待原目标归零、调仓门槛与亏损阈值，便于核对两种空仓原因。来源未知且没有保护或等待时，最终目标仍未知；已经有明确保护时最终目标为零，不是把缺失信号补成零。判断当天不能读取次日成交、净值或价格；实际成交是否开始／结束周期由自己的真实模拟份额确认。

## 第137轮来源的合成顺序与月度预算

原137轮保存的风险因素包括：上述合成后的下行平方平均值；本次更新前旧预算在同一窗口的下行平方平均值；以及风险对第一预算的导数。导数的计算为每一天合成收益中的负值部分，乘以当天132收益减91收益，再对242天取平均后乘二。该导数随第一预算单调不减，因此可在零至一之间寻找凸目标最小点。

当旧预算的导数为零，旧预算已经最优，保持原预算。如果整个区间的风险都向同一方向增加或减少，取对应端点；其他情况在旧预算与应移动的端点之间最多二分64次，直到双精度区间无法继续区分。导数为零的一段表示多个同样优的预算，选择距离旧预算最近的点；不利用未来收益挑选并列答案。64次是数值求解精度设置，不是搜索64种策略。

完整窗口中的风险为零或多个预算平坦，是明确的最优值或并列解；窗口不足或任何日期缺失，则为无新风险观点并保留旧预算。两种状态分别保存，不补零资料，也不删除缺失日。[PyPortfolioOpt官方半方差说明](https://pyportfolioopt.readthedocs.io/en/latest/GeneralEfficientFrontier.html)说明了直接组合半方差的凸问题，以及先计算半协方差再当普通方差使用的近似局限。原137轮直接求两来源组合目标，不安装该库，也不把下行风险指标当作夏普。

6. 段数方差：分子为二乘较强个数乘较弱个数，再乘以“二乘较强个数乘较弱个数，减去非平局总数”；分母为非平局总数的平方，乘以非平局总数减一。至少要有两类且方差大于零，才定义标准化分数。

8. 六十日上涨动量：同一完整窗口的六十个含分红对数收益相加。大于零表示这段含分红价格上涨。

六十日窗口缺失时，当日状态和目标未知，内部允许状态及计数清零，恢复完整后重新确认。完整的全持平窗口属于明确非正方向，按退出计数处理；不把完整零收益误判为资料缺失。单独的风险波动缺失不修改完整方向状态，但允许状态下目标未知。

所有判断于当天十五点零五分形成，下一交易日真实开盘执行。空仓且目标为正时，按上一收盘本账户净资产和原始收盘价计算份额，向下取一百份整手；取整为零则不买入。

已有持仓且目标为正，目标与实际股票市值占净资产比例偏差不足十个百分点时保持，达到十个百分点则调至目标中心。带外正目标按整手计算为零时实际全部退出。明确零目标优先请求全部卖出，不受调仓带阻拦；固定终点开盘同样优先清算。

4. 固定历史终点按开盘优先全部清算，不继续执行前一收盘的新买入或持有目标。
5. 目标未知时保持实际份额，不能补成上述任何一种已知零目标。
