# 第九轮：按市场状态持续学习的机制组合

## 要检验的问题

用户要求解释失败，并检验能否在不同阶段使用不同策略、通过多因子判断实现稳定超额和高夏普。本轮检验新的组合学习方式：先按机制合并相似策略，再用已经结算的完整账户回报逐日更新机制权重；同时保留市场总体经验与相似状态下的经验。

八轮既有诊断发现：过去504日夏普排名与下一阶段日均收益排名没有呈现正向延续关系；原24种候选的收益协方差参与率约2.41，重复参数并不代表24份独立信息。固定实际成交份额、加回显性费用后的八轮主方案仍全部低于1.2。这些是描述既有样本的诊断，不能单独证明任何新组合有效。

本轮是用户重新授权后的独立研究方法，原第一轮切换、其他旧状态路由器及全部旧失败结论原样保留。组合中的底层规则是研究输入，不因被组合而变成已批准策略。不生成真实交易或持仓。

## 六种机制判断

| 机制 | 中文规则 |
|---|---|
| 现金 | 明确给出零股票仓位，不代表缺失判断。 |
| 买入持有 | 初始买入510300后保持份额，真实分红入账，末日退出；作为长期持有机制。 |
| 趋势组 | 将下文九种趋势规则的次日目标仓位等权平均，只占一份机制权重。 |
| 反转组 | 将下文两种超跌反转规则的次日目标仓位等权平均，只占一份机制权重。 |
| 趋势震荡混合组 | 使用下文既有趋势震荡规则的次日目标仓位。 |
| 预测模型组 | 将第一轮预先登记的十二个价格预测模型的次日目标仓位等权平均，只占一份机制权重；不挑其中历史最好的模型。 |

九种趋势规则分别为：含分红财富在六十日、一百二十日、二百日均线上方时满仓，否则现金；过去二十日、六十日、一百二十日含分红对数收益为正时满仓，否则现金；二十日、六十日、一百二十日均线投票，超过几条就持有三分之几仓位；财富突破此前六十日最高值时满仓、跌破此前二十日最低值时退出、中间保持；三均线投票仓位再乘十五个百分点除以六十日年化波动率，乘数最多为一。

两种反转规则分别为：最近两日财富正向变动之和除以正负变动绝对值之和、再乘一百，该简单两日涨跌比例低于十时满仓、高于七十时退出、中间保持；第二种要求财富在二百日均线上方且简单两日比例低于二十才满仓，跌到均线下方或比例高于七十时退出。这里不是平滑的威尔德相对强弱指标。

趋势震荡混合规则为：过去二十日财富净变化绝对值除以每日变化绝对值之和，如果高于零点三，按二十日均线方向决定满仓或现金；否则，当财富低于二十日均值一个标准差时满仓，回到均值上方时退出，其余保持。

十二个预测模型来自岭回归、浅层梯度提升、极随机树三类，各自预测五日与二十日持有总回报，分别使用全部过去样本或最近七百五十六日样本。每季只用当时已经到期的标签训练，再把预测收益、风险惩罚和交易摩擦映射为零、四分之一、二分之一、四分之三、满仓或不交易。此次只复用第一轮已经保存且有训练时钟记录的逐日输出，不重新挑选模型或改预测参数。

先把每个机制都作为一个二十万元的独立模拟账户，从2015年1月5日开始记录真实整手、费用和分红下的每日回报。四个主动组每五个交易日调整一次，现金始终为零股票仓位，买入持有按其定义执行。机制账户返回的次日目标仓位才是组合使用的信号，不能用事后账户收益直接拼成组合净值。

## 三项环境与尺度因子

| 因子 | 中文计算与用途 |
|---|---|
| 趋势方向 | 当日含分红财富是否高于过去一百二十个交易日的财富均值，高于为一类，其余为另一类。 |
| 波动变化 | 最近二十日每日含分红收益的样本标准差是否高于最近六十日，高于为波动上升，其余为未上升。与趋势交叉得到四个状态。 |
| 已知风险尺度 | 更新某日奖励时，使用前一交易日收盘已经知道的六十日每日含分红收益标准差，最低取百分之零点五，避免极低波动放大奖惩。 |

所有环境指标只用当时收盘已经形成的数据。某日结算的机制回报归入前一日决策时的市场状态，不能按知道结果后的状态给过去重新分类。当日收盘更新学习后，根据当日状态作下一开盘的判断。来源缺失不置零，不把无判断解释为现金；本轮来源准备要求2015年开始连续有效，否则停止该输入路线并记录。

## 权重如何持续学习

六种机制起始权重各六分之一。先将机制当天净收益加一后取自然对数，再除以前一日已知风险尺度；奖励限制在负三至三之间。每种机制旧权重乘以自然常数的“学习速率乘奖励”次幂，再把六项权重归一化。

每次更新后，旧权重保留一百二十五除以一百二十六，其余一百二十六分之一回到六种机制的均匀先验，使曾经表现差的机制可以恢复。学习速率固定为“两倍六的自然对数除以一百二十六”的平方根。半年的一百二十六日尺度在本轮账户收益计算前固定，不搜索其他尺度。

维护一套总体权重、四套状态权重，以及只看趋势时的两套状态权重。总体权重每天接受已结算奖励；状态权重只在前一日属于该状态时接受当天奖励，所有状态每天都向均匀先验回流。每个状态的有效观察量每天乘一百二十五除以一百二十六，当天收到对应状态回报再加一。

主方案把当前状态权重与总体权重混合：状态权重的占比为该状态有效观察量除以“有效观察量加二十”，剩余使用总体权重。相似状态经验少时，更多依靠总体经验。六种机制权重乘以各自当日公布的次日目标仓位，求和得到组合目标仓位。

该方法参考在线专家跟踪与权重回流思想。原论文讨论预测损失比较，本研究加入市场状态、波动标准化及完整交易账户，不能把论文结论改称股票夏普保证。[Herbster与Warmuth，1998](https://mwarmuth.bitbucket.io/pubs/J39.pdf)；[Adamskiy等，2016](https://jmlr.org/papers/volume17/13-533/13-533.pdf)。

## 六个预先确定的组合与对照

| 组合 | 具体方式 |
|---|---|
| 主方案：四状态与总体混合 | 按上述方式混合总体和四状态权重，连续分配仓位。 |
| 仅总体学习 | 每天学习六种机制的整体表现，不区分状态。 |
| 仅四状态学习 | 使用当时状态的六项权重，不加入总体权重。 |
| 仅趋势两状态与总体混合 | 去掉波动分类，按趋势两状态与总体经验混合，其余参数完全相同。 |
| 四状态硬选择 | 根据主方案权重，每次只选择权重最大的一种机制，观察硬切换的影响；并列时按现金、买入持有、趋势、反转、混合、预测顺序决定。 |
| 六机制固定等权 | 不学习，六种机制始终各占六分之一。 |

另完整评价现金、趋势、反转、混合、预测五种单机制与买入持有基准。因此共十一种登记候选，两档费用下共二十四条完整评价账户。现金零波动时夏普不定义，不填为零或无限大。不得在结果出来后改主方案、改状态边界、改回流速度、排除失败组或挑最好分期。

## 交易与验证

组合从2020年1月2日开始，初始20万元，2026年8月14日开盘强制退出。每五个交易日按当时已知目标决定下一开盘订单。持有股票时，如果目标与当时实际仓位相差不足十个百分点，保持份额；目标为零时不应用这条容忍带，仍按规则退出。最终订单按一百份整手和现金可买数量执行。

采用与前八轮相同的最小报价0.001元、T+1、方向性涨跌停限制、分红登记和应收到账。基础佣金万分之二、最低5元、单边滑点万分之五；压力佣金万分之四、最低5元、单边滑点千分之一。组合信号统一由基础费用下的机制历史生成；压力账户仅改变执行费用，不重新选择有利信号。现金利息与夏普参考利率按零。

夏普按完整每日账户收益均值除以样本标准差，再乘242的平方根。所有等待日保留。报告每种方案的基础与压力表现、逐年表现、2020至2021、2022至2023、2024至终点三个分期。用20日连续区块共同抽样2000次，比较主方案夏普及其相对固定等权、仅总体学习、硬选择的年化日均收益差异区间。保存完整权重、学习来源时间、机制账本及组合账本，验证未来新增奖励不改变过去权重。

目标仍为完整账户成本后夏普至少1.2，并进一步证明稳定超额。已反复观察的历史不是独立样本；点估计达标只能进入必要复核和独立验证，不能宣告研究完成。盈利、估值、股东回报和公募原始时钟的资料修复继续，本轮没有把未合格的来源加入状态判定。
