# 下一项：两套既定规则各占一半，检验是否互补

第165轮收益强弱连续段已完成，主历史夏普有所提高，但四场景仍未达到一点二。第166轮检验它与第143轮趋势波动连续预算的组合，固定各占一半。零新增学习模型，不重新计算父策略，不根据组合结果改变比例。

## 使用什么因素和来源

第一来源为第143轮趋势波动连续预算的当日收盘目标。它依据含分红财富相对一百二十日均值的正偏离与二十日波动幅度，连续分配第131轮和第139轮的预算。第131轮保留既定日内隔夜进入、固定入场版本的八因子退出参考，再使用普通波动控制规模；第139轮依据当时训练支持条件选择既定参考预算。原进入、学习退出、价格保护、期限和再次进入条件全部保留。

第二来源为第165轮收益强弱连续段的当日收盘目标。它使用六十日收益相对同一窗口中位数的强弱连续段分数、六十日上涨动量与二十日普通波动。分数严格小于负一且动量为正，联合连续两次准入；分数大于或等于零连续两次，或者动量不为正连续两次，退出。允许方向时目标为百分之十除以年化波动，上限百分之百。中位数、平局、未定义分数与缺失处理按原规则执行。

第166轮自身只增加一个固定因素：两套目标的等权平均，即第一套目标的一半，加上第二套目标的一半。例如第一套百分之八十、第二套零，合成目标百分之四十；第一套百分之八十、第二套百分之四十，合成目标百分之六十。空闲部分保持现金，不因为某一套退出就把其预算转给另一套。

两套目标均已知时才能合成；任何一套未知，整体目标未知，即使另一套为零。基础费用读取两套基础费用目录的原收盘目标，压力费用读取各自压力费用目录。完整日期、判断时钟、下一交易日开盘日期、来源身份与费用均对齐。只使用原收盘已经形成的目标，不能使用下一开盘实际成交份额、未来盈利或后来的模型版本。

这检验的是两条既定持有路径能否互补。原策略失败和未达标结论均保留；新组合单独建立实际账户，不能平均两条夏普或直接平均净值曲线当作结果。

## 完整进出场及资金规则

每天十五点零五分形成合成目标，下一开盘执行。空仓且合成目标为正，按上一收盘本账户净资产与原始收盘价计算份额，向下取一百份整手后尝试买入。不能使用父账户的资金量或持仓代替新账户。

已有持仓且合成目标为正，目标比例与实际股票市值占净资产比例相差不足十个百分点则保持份额；达到十个百分点时调至目标中心。两套目标都明确为零，才请求下一开盘全部退出。一套退出而另一套仍有正目标时，保留剩余一套的一半目标，不新增“任何一套退出就全卖”的条件。

未知目标维持实际份额。受阻后下一收盘按最新合成目标决定，不增加永久退出锁。卖完后合成目标重新为正即可进入，无额外等待期。父策略自己的市场状态、参考周期、原内部退出锁与重新进入资格各自连续保留，不接收组合账户的持仓或盈利反馈。终点开盘优先清仓。

同一ETF合并成一个实际资金账户，仅对净调整收取本账户的真实费用。完整计入现金、整手、实际开盘、可用资金、次日可卖、方向限价、分红登记除息到账和终点，不把父账户损益直接移入。

只新增四个账户，零新训练、零新增参考账户、零外部数据。保存对照为第143轮、第165轮及买入持有，每段两档费用合计两条新账户与六条保存对照。两套父目标的保存决定、原账户、设置、中文规则及已完成核对记录均在本轮冻结前绑定版本。

主历史2020年1月2日至2026年8月14日开盘，较早历史2015年1月5日至2019年12月31日开盘。每账户二十万元，二百四十二日年化，现金及无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。继续一百份整手、零点零零一元价位、原百分之十方向限价及原分红规则。
