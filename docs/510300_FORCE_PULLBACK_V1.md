# 第125轮：长短量价力度与趋势内回调交易

第124轮连续回撤预算已经完成并未达目标。它主历史平均股票敞口约百分之二点二，年化收益低于买入持有。下一项直接研究进入机会及退出，不继续扫描这两条旧参考的预算目标。EPS、公募、估值及慢来源保持暂停。

## 方法与来源边界

只登记一项固定策略：较慢的量价力度判断是否仍有上升方向，较快的量价力度判断回调开始恢复、以及反弹开始减弱。力度是价格变化与成交份额的乘积，是量价代理，不是已测得的净申购、净流入或买卖方主动成交。

基础指标使用[TA-Lib的力度指标说明](https://ta-lib.org/functions/efi.html)所述价格变化乘成交量，并取两期与十三期指数平均；该说明同时明确用最初相应期数的简单平均初始化。[TradingView的官方力度指标说明](https://www.tradingview.com/support/solutions/43000502259-elder-s-force-index-efi/)也给出同一基础构成及十三期默认平滑。以下分红处理与具体进出场属于本项目预先约定，不称完全复制Elder原交易体系，也不以指标来源证明盈利。

已对研究代码、中文协议及配置做有界名称和公式检索，没有发现已执行的力度指标同一方法。第26轮量价急跌、第101轮成交额涨跌分布、第112轮价格移动除成交量、第116轮持仓学习的成交份额因子均保留原结果；这次不调整它们的阈值或训练标签。

## 全部因子

只使用原日线的日期、收盘、前收盘、当日每份除息现金及实际成交份额。经济价格变化为当天收盘减前收盘，再加当天每份除息现金，避免把正常现金分配当成负向价格冲击。价差先按保存输入的十进制数精确相减相加，再乘当天实际成交份额，最后转为普通数值，得到原始力度；正常除息中性的零价差不会被浮点残差误判正负。不是用成交金额代替成交份额；原数据金额已经是人民币，不能再乘一千。

分别做两期和十三期指数平均。最初两条有效原始力度的算术平均作为短线起值；最初十三条作为长线起值。此后短线取当日原始值的三分之二加旧均值的三分之一；长线取当日原始值的七分之一加旧均值的七分之六。没有足够连续观察时不产生该均值，不借未来数据初始化。

首行缺少前收盘属于结构性初始空值，不造零力度。后续价格、分红或成交份额缺失则从缺口起保留无观点，不填补或任意重置指数均值；待卖请求仍按原锁定机制执行。零成交份额是已观察零值时原始力度为零，不等同数据缺失。现有输入完整性预检保存于reports/research/510300_force_pullback_preflight_20260909/result.json，预检没有计算新力度、信号或收益。

## 进入、退出与再次进入

空仓时，当前十三期力度大于零、当前两期力度小于零、且当前两期力度高于前一个收盘，三项同时成立，才在下一开盘请求按可用资金买入。意思是较慢方向仍为正，短期回调仍未完全恢复，但已经开始回升。没有必要历史时无新判断。

持仓时，当前十三期力度小于或等于零，或者当前两期力度大于零且低于前一收盘，任一成立即请求下一开盘全部退出。前者表示较慢方向消失，后者表示正向短期反弹开始减弱。其余时持有，不追加仓位。短线恰为零且长线仍为正时维持现状，不把等于零视为缺失。

退出受阻就保留退出意图直到可执行，终点开盘优先清仓。实际卖出后，下一个可判断收盘重新按同一三个进入条件处理，没有额外冷却或要求原信号先消失。不得误带入旧日内隔夜强弱进入、百分之六止损、百分之八追踪、六十日自然退出或旧重新进入门槛。复用research/joint_entry_exit_account_v1.py经济循环，自行实现此控制器。
