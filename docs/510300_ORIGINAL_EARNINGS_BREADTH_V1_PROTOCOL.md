# 第八轮：原始财报盈利改善广度

## 研究目的与边界

用户已要求持续寻找完整账户扣费后夏普率至少1.2的策略，并新增盈利、估值、股东回报和公募申购的研究方向。本轮检验：在真实历史沪深300成分股中，已经公开的盈利、营业收入和经营现金流改善是否足够普遍，能否帮助决定510300与现金的配置。

这是新的指数层面信息研究。旧研究检验个股财报后反应不足，其原始资料覆盖门槛和后续失败结论保持原状。本轮不恢复旧个股选股策略。现有原始财务事实可以按新的、事先写明的用途使用；原资料未通过旧覆盖门槛，不等于全部已经提取的原始金额无效，也不等于本轮自动合格。

本轮计算成分公司的等权改善比例和中位数，不冒充按历史市值权重汇总的指数每股盈利。市盈率、回购、基金份额尚未通过历史版本和信息时钟核对，本轮不混入。股票价格与每股盈利乘市盈率是同口径关系；持有财富还包括现金分红。回购改变股数和每股盈利，不能再把全部回购金额当作持有人额外拿到的现金重复相加。公募资产规模也不能直接当净申购。

在本轮收益读取前完成的来源覆盖检查显示：旧财报收集任务预先排除了银行与非银金融，其财报结构不满足旧研究统一的营运资本链。本轮可用事实仍以非金融公司为主，不能代表全体300家盈利。原始覆盖到2022年5月5日才首次达到240家；2017至2021年一天也未达到。维持预设240家门槛，早期不拟合、不作新判断的日子照常留在账户，不改成从2022年开始回测。补齐金融公司及新调入成分的原始财报是并行继续的来源工作；金融公司需要适合其报表结构的单独盈利定义，不能简单照搬工业企业的经营现金流质量解释。

## 原始资料和信息时间

采用巨潮资讯原始定期报告事实档案的逐份合并版本，共有原始公告标识、地址、页码、原文金额、单位和文件哈希。每项事实必须标记为原始文件金额、标签和单位已核实；本轮另算原文金额乘单位并与保存的人民币金额比较。空白栏自动补零的旧提取记录不作为有效财务数值。

将事实逐项连接到完整定期报告事件档案，公告标识、证券、报告期和公布日期均须一致。原始网址须对应主公告，或者对应既有文件选择回执已经确认的同公司、同报告期、同日配套完整报告；配套文件的地址和哈希同时核对。不能对应这两类记录的事实设为缺失，不把不同文件编号直接判成数值错误，也不未经证据承认它有效。只使用原始报告中的当期累计金额，不用后来报告重述的去年数字覆盖去年的原始版本。同比比较使用同一家公司、上一年相同报告期的原始报告；去年报告也必须已经公开。

事件只有公布日期而没有可靠日内首发时间，统一在该日期之后的第一个A股交易日开盘起可用。当天收盘15点作判断，下一交易日开盘模拟成交。即使实际可能更早看到，也不提前一天。若新公告对应的报告期早于已经知道的最新报告期，不让它覆盖更新报告。

每个历史交易日使用官方调整公告重放得到的当时300家成分股，不使用当前成分股回填过去，不使用未经版本证明的历史权重。先找到每家公司当时应该已知的最新报告，再检查其原始财务事实是否存在；最新报告缺失时，不能继续引用旧报告把覆盖率抬高。

## 公司层面的计算

需要归母净利润、扣非归母净利润、营业收入、经营活动现金流量净额、期末总资产，共五项。前四项都是年初至报告期末的累计金额；总资产是期末余额。当前和去年相同报告期五项均有效、两期总资产均大于零、最新报告期末距当前日期不超过200个自然日，才是一家有效公司。

前四项分别计算对称同比变化：当期金额减去年同期金额，再乘二，最后除以两期金额绝对值之和。两期均为明确披露的零时变化为零。这种写法能处理去年亏损、今年盈利，数值在负二至二之间；不能把它称作通常的百分比增长率。改善是当期金额严格大于去年同期，持平不算改善。

累计金额除以总资产时，另乘十二再除以报告期累计月数，使一季度、半年、三季度、全年使用同一种年化尺度。这只是累计业绩的尺度调整，不能称作未来全年预测，也不能消除季节性。经营现金流在银行等行业的含义不同，必须作为局限披露。

## 十六项新增因子

| 因子 | 完整中文规则 |
|---|---|
| 盈利变化中位数 | 有效公司归母净利润对称同比变化的中位数。 |
| 扣非盈利变化中位数 | 有效公司扣非归母净利润对称同比变化的中位数。 |
| 收入变化中位数 | 有效公司营业收入对称同比变化的中位数。 |
| 经营现金流变化中位数 | 有效公司经营活动现金流量净额对称同比变化的中位数。 |
| 盈利改善比例 | 归母净利润超过去年同期的有效公司数，除以有效公司数。 |
| 扣非盈利改善比例 | 扣非归母净利润超过去年同期的有效公司数，除以有效公司数。 |
| 收入改善比例 | 营业收入超过去年同期的有效公司数，除以有效公司数。 |
| 经营现金流改善比例 | 经营现金流超过去年同期的有效公司数，除以有效公司数。 |
| 盈利为正比例 | 当前归母净利润大于零的有效公司数，除以有效公司数。 |
| 盈利与现金流共同改善比例 | 归母净利润和经营现金流同时超过去年同期的有效公司数，除以有效公司数。 |
| 年化归母利润资产比中位数 | 每家有效公司的归母净利润除以期末总资产，乘十二再除以累计月数，最后取中位数。 |
| 年化现金与利润差额资产比中位数 | 每家有效公司的经营现金流减归母净利润，除以期末总资产，按累计月数换成年化尺度，最后取中位数。 |
| 现金与利润差额改善中位数 | 上一项公司数值减去去年相同报告期按同法算出的数值，再对有效公司取中位数。 |
| 原始财报有效覆盖比例 | 当天有效公司数除以当时300家成分股数量。 |
| 报告新鲜度 | 有效公司报告期末距当日的自然日数中位数，再除以200。数值越小表示报告越新。 |
| 最近二十天披露比例 | 有效公司的最新报告开始可用日期距离当天少于20个自然日的公司数，除以有效公司数。 |

有效公司至少240家，且全部价格和新增特征有效，才可预测或作为训练样本。缺少判断的交易日保留，不把缺失因子或收益改成零；账户保持已持有份额，继续计算真实价格波动、分红和成本。

## 固定候选与训练

三组信息：34项既有价格因子、16项原始财报因子、二者合并。既有价格因子采用独立复算已通过的同一文件，详细中文定义随交付附上。三组使用相同的有效日期，避免把数据覆盖差异误当信息增益。

每组分别使用线性岭回归和浅层极端随机树，预测20或60个交易日的持有总回报，共十二个模型。岭回归只在训练集内标准化，惩罚强度100；随机树96棵、深度最多3层、每叶至少40条样本、每次分裂使用四分之三特征，不自助抽样。随机种子为20260906加本次训练日期的年月日整数。

另登记三个60日同组两模型等权预测，以及一个20日全信息两模型等权预测，共十六个候选。主方案在本轮收益计算前固定为“价格与原始财报合并、预测60日、两模型等权”。财报变化较慢是选择60日主期限的理由；不得在结果出来后改称最好候选为主方案。

首次判断为2020年第一个交易日的前一交易日收盘，以后每季第一个交易日收盘更新模型。在每次训练时，只使用已经完成下一开盘买入、持有相应天数、退出开盘价格已知的标签；训练样本至少300条，不足时该次模型不拟合，保留无判断。使用扩展训练窗口，不通过候选收益选择起止时期。

## 持仓、成本和验收

完整评估区间为2020年1月2日至2026年8月14日，末日开盘退出；20万元初始资金，只交易510300与现金。每20日或60日按对应预测期限决策，其余日期保持份额。决策比较不交易和零、四分之一、二分之一、四分之三、满仓五个目标；使用预测收益减去风险惩罚和预计交易摩擦的评分，风险厌恶系数4，风险方差为过去60日每日总回报方差乘预测天数。相同评分优先不交易，不能加杠杆或做空。

沿用100份整手、最小价格变动0.001元、T+1、方向性涨跌停限制、现金可买数量约束，以及登记、除息、应收、到账分别记录的真实分红会计。基础费用为佣金万分之二、最低5元、单边滑点万分之五；压力费用为佣金万分之四、最低5元、单边滑点千分之一。现金利息及夏普参考利率均暂按零，不能凭加入假设利息让目标达标。

报告每个候选在两档费用下的全部账户，共34条（含两个买入持有对照）。夏普按完整账户每日收益均值除以样本标准差，再乘242的平方根；收益、回撤均保留空仓等待日。报告全段、逐年、2020至2021、2022至2023、2024至终点三个固定分期。以60日连续区块做2000次共同重采样，报告主方案夏普及相对价格对照的年化平均收益增量区间。

本轮会记录全部候选，不只展示最好结果。历史已经反复看过；即使某个点估计达到1.2，也只能进入后续验证，不等于已经证明独立、稳定的高夏普。原始来源不足、覆盖不足、因子失败和策略失败分别记清楚，不修改旧研究记录。研究不触发真实交易，不连接券商。
