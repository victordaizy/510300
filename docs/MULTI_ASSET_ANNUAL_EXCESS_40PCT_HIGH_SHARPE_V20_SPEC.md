# 40个百分点高夏普研究V20：现货低波动与月内止损

永续基差V9在2020-07-16 00:00的日度换仓中，容量约束后的实际净敞口仍超过冻结3%上限，没有形成绩效。不得通过改换仓顺序、净敞口门或容量门救回。

V20转入完全独立的现货做多机制。Kaya和Mostowfi在2022年《Finance Research Letters》的开放获取研究中发现，高度集中的低波动加密货币组合在6至12个月形成和持有期具有显著超额；三币组合的夏普在约5%止损阈值附近改善明显。V20不复用论文的结果，只固定其首个本地适配。

静态集合为原15个币种。以每日UTC 23:00现货收盘形成日收益；在每年3月1日与9月1日00:00前，用严格滞后的180个完整日收益计算实现波动率，等额买入最低波动3个现货。每个自然月重置各槽位的月度入场价；若前一日23:00收盘相对该月入场价下跌至少5%，次日00:00卖出，该槽位持有现金至下月再入场。半年选币之间不替换标的。

总目标毛敞口1倍，不使用借款、空头或衍生品。订单不超过各现货前168小时中位成交额的0.1%；基础/压力单边总成本为4/16bp；最后7日按容量清仓。目标仍为相对H00300全收益年化净超额40个百分点，基础和压力净夏普均不低于1.50。Paper、Shadow、订单、账户连接和实盘均关闭。
