# 第109轮：预测波动与已实现波动的同规则仓位比较

固定两个设置：一个条件方差预测方案，一个二十日已实现波动对照。二者使用原第91轮完全相同的股票目标和10%风险缩减水平、相同交易带宽，只比较波动估计方法。另直接复用第91轮未缩减、原线性退出及买入持有的保存账户。原第29轮普通波动缩减和第41轮入场时定预算的结论保留；本轮不声称普通波动控制是新发现。

## 新模型的全部输入、估计与每日预测

模型只使用截至当日收盘的510300含分红简单收益，即当日收盘价加当日每份股息，除以前一日收盘价，再减一。计算时换成百分数单位，仅为数值稳定，最后换回收益率单位。

下一交易日的条件方差由三部分相加：正的常数项、当日收益平方乘冲击系数、当日条件方差乘延续系数。两系数非负，合计严格低于0.999；不加入涨跌方向预测、非对称项、外部因子或杠杆。

沿用原141个准备及月首收盘拟合日程。每次最多使用截至拟合收盘的756条最近日收益，至少242条；不包含首个无前日记录。窗口任一收益缺失则整次无模型，不删行。以整个已知训练窗口的收益平方平均值作为首日条件方差，逐日递推，最小化高斯准似然：各日“方差自然对数加收益平方除以方差”的平均值的一半。忽略与参数无关的常数，均值固定为零。

三个参数从同一初值开始：冲击系数0.05、延续系数0.90，常数为初始方差的0.05倍。通过一个指数和三个归一化指数权重保持约束；常数变换参数限制在负十二至六，两个系数变换参数均限制在负十二至十二。这些是固定求解范围，不按收益结果调节。采用有界有限内存拟牛顿求解，解析梯度，最多200次迭代；相对目标容差十的负十次方、梯度容差十的负六次方、每步最多20次线搜索。单一起点，失败不换初值或求解器。

月首拟合完成后，当日已经知道的收益用于预测下一日方差。之后每天将当日新收益平方和上一日预测方差递推，直到下一次月首重估。年化预测波动等于下一日方差乘242后开方，并从百分数单位除以100。实际不是预先保证达到的账户波动。

普通对照直接使用最近二十条含分红简单收益的样本标准差，乘242的平方根。它也每天更新，只使用当日已知信息。

模型公式参考[arch项目的GARCH定义](https://arch.readthedocs.io/en/latest/univariate/generated/arch.univariate.GARCH.html)。本轮只采用其中一阶对称条件方差结构，拟合实现与初始状态按上述规则明确固定；来源不证明该方法对本策略有效。

## 如何把波动变成仓位

两种方法均用“10%除以各自年化波动”作为乘数，最多为一；乘数乘原第91轮当日股票目标得到新目标，不融资、不提高原目标。

没有波动模型、拟合失败、真实递推收益缺失或零波动时，波动预测本身仍无观点；策略沿用上次明确算出的风险乘数，初始乘数为一。之后遇到新的完整月首模型才恢复条件方差递推。这个沿用状态是事先固定的仓位政策，不能填充成一个新的预测。原策略目标为零仍全部退出；原目标缺失则无新目标，实际账户保留已有份额。

每日完整收盘判断，下一开盘执行。空仓且目标为正时买入；持仓比例与非零目标相差达到10个百分点才按自身净值调整；目标为零请求全部卖出，不受带宽限制。退出受阻，下一收盘按最新目标和真实份额重算。原底层策略负责机会的进入、退出与重新进入，波动缩减不创造新的机会。

## 原股票目标的完整含义

原第91轮的两条基础参考从2013年6月3日起连续运行，分别为急跌回升和线性学习退出。每月首收盘，用两参考最近242个完整日的实际净收益样本方差、协方差和收益差方差计算预算：急跌预算等于学习方差减协方差，再除收益差方差，并限制在零至一；学习预算为一减急跌预算。初始各半，资料不足或任一参考零方差则保持上次明确预算。原股票目标是两预算分别乘当时参考持有意向后相加。参考持有意向为进入或继续持有一、决定退出或空仓等待零，缺失保持无观点。

两条底层参考的全部输入和进出场规则随结果附入文档，复用保存记录，不重建参考。两种新风险方法共用相同参考目标，实际份额、现金、成本、股息权益各自重新记账；不把旧参考利润或股数转入新账户，不把参考收益直接加权当作新账户收益。

## 时段、成本与停止条件

主历史2020年1月2日至2026年8月14日开盘；较早历史2015年1月5日至2019年12月31日开盘。每段各两种风险方法、基础和压力费用，共八个新实际账户；不新增参考账户。每个账户二十万元现金起步，全部现金日保留，242日年化，现金及夏普无风险收益零。

基础单边佣金万分之二、最低五元、滑点万分之五；压力佣金万分之四、最低五元、滑点千分之一。百份整手、一厘报价、下一开盘价格、方向涨跌停、当日新买次日可卖、分红登记应收到账和终点开盘平仓均使用原完整账户引擎。

六项必要测试通过，先冻结两个设置再拟合和生成收益。比较预测波动、普通波动和原目标，若没有实际改善，关闭本次结构，不更换目标波动、窗口、非对称项、系数界限或调仓带宽救回。目标仍为扣费夏普至少1.2与稳定超额，历史已经被多次研究，不是独立验证。不补慢源，不准备GPT数值包，只研究510300及人民币现金。
