# 第81轮：先半仓，价格回升确认后补足

只登记一项分批进入策略，另设同执行规则的满仓对照，用来分清分批影响和执行方式差异。旧第41轮一次性半仓、第49轮先卖半仓、第50轮买入价上限等失败保留；有界查重未见同一参考路径上的本项补足机制。上一80完成真实训练、账户、关键核对与交付，属于实际进展。

## 新进入和退出规则

1. 完全复用原第32轮基础费用下已保存的逐日入场与退出判断。参考目标从零恢复到持有时，新账户先请求股票占自身完整净值50%，下一开盘按现金及整手限制买入。
2. 参考策略发生真实买入后，保存该日开盘对应的连续财富价格：前一日财富价格，乘以该日开盘加已知每份分红，再除前一日实际收盘。此基准仅在该买入已发生后可用，不能提前回填；它是价格确认基准，不是新账户扣费后的盈亏平衡价。
3. 只要原参考仍要求持有，而且参考账户当日仍实际持有，当日财富收盘严格高于该参考入场连续开盘价格，就将新目标提高到100%，下一开盘补足。等于基准不确认。参考尚未成交时维持50%目标，不能看未来的成交价提前补仓。
4. 一旦本参考周期确认到100%，随后价格回落也保持该阶段，直到参考目标归零；参考退出时请求下一开盘全部卖出。新的实际参考买入将阶段重新设为50%，重新等待确认。
5. 每个有效收盘按新目标和自身真实净值估算份额。非零目标与实际股票占比差距不到10个百分点时维持份额；目标为零时请求全卖。不借款，不卖空，不将已知分红应收当作可支用现金。半仓阶段因市场变化出现较大偏离时也可能再平衡，不能宣称每个周期必然恰好两次买入。
6. 参考判断或当前连续收盘缺失时没有新目标，保留实际份额；价格未确认时不补足。已有内部阶段保留，但已观察到的新参考买入仍标记新周期并重置半仓。恢复有效信息后继续判断。参考成交日历必须完整，不能漏掉成交后用未来基准回填。
7. 本轮按每日参考目标更新下一开盘请求，受阻后下一收盘依据最新参考状态重新请求；研究终点统一开盘退出。真实T+1、方向涨跌停、整手、费用、分红登记、除息应收及到账处理均保留。

这是一条原参考路径的分批执行账户。参考模型使用原满仓账户状态，本轮不会把半仓新账户的盈亏反馈给原学习模型。两费用共用基础参考状态，因此压力场景检验的是共同信号下新账户实际费用，不能说重新用压力持仓训练或调用了参考模型。

## 沿用的全部参考因子和规则

日内强弱因子：每日日内对数收益减隔夜对数收益，最近60日差额之和，除以最近60日差额样本标准差乘60的平方根。隔夜为开盘加当日已知分红后除前收盘、取自然对数；日内为收盘加同一分红后除开盘加同一分红、取自然对数。两者相加等于完整日总回报对数。

该强弱分数连续两个收盘大于1且原必需特征有效，原参考下一开盘买入。连续两个收盘小于零，或者含分红损失达到6%、从周期最高价值回撤达到8%、从实际买入当天算起满60个交易日，任一满足便请求下一开盘退出。原学习预测连续两个收盘为负也退出；已有参考退出请求维持到真实成交。参考退出后至少等待2个交易日，并在空仓时观察到旧入场模式消失，才允许新机会。

|参考学习输入|中文定义|
|---|---|
|持仓时间对数|真实买入当天起交易日数加1，取自然对数|
|持仓盈亏|参考持仓市值加本周期确认分红，除参考真实买入支出含佣金，减1|
|持仓回撤|上述参考持仓价值除其周期最高价值，减1|
|入场模式|参考买入时的模式，本项为1|
|五日涨跌|最近5日含当时已知分红的对数收益之和|
|二十日涨跌|最近20日同口径对数收益之和|
|一百二十日均线偏离|当前连续财富价格除最近120日简单均值，减1|
|二十日波动|最近20日总回报简单收益样本标准差，乘242的平方根|

原模型每月首收盘使用当时已自然退出的最近最多20个周期，至少10周期100状态，每周期总权重相同。学习目标为继续至参考自然退出相对下一开盘卖出的净收益差；输入按训练均值和尺度标准化，限制在负5至5，带截距岭回归、惩罚1。原标签对提前退出受阻成交的近似保留。114份原有效模型及27个早期无模型时点直接复用，全部逐月系数中文说明一并沿用，不重训，不使用第79或80轮新模型。

## 同执行满仓对照和评价

同执行满仓对照直接将原参考持有目标映射为100%、退出目标为0%，与分批账户使用同一事件账户、同一现金/分红/费用及10个百分点调整规则。对照没有分批确认，其他条件相同。这可避免把原账户和新事件账户估算份额的细微差异都归因于分批。

主评价2020年1月2日至2026年8月14日开盘终点，共1604日；较早2015年1月5日至2019年12月31日开盘，共1219日。两段各20万元，242日年化，现金及无风险收益零，完整空仓日保留。基础每边佣金万分之二、最低5元、滑点万分之五；压力佣金万分之四、最低5元、滑点千分之一。最小100份、价格最小变化0.001元。

6项关键测试通过后冻结并运行：分批策略两段两费用4个账户，同执行满仓对照4个，合计8个新账户；另复用原R32、R46各半、R76风险预算及买入持有共16个保存对照。新候选设置为1，同执行满仓是预先指定机械对照，不作为候选择优。没有新训练、参考策略重建或市场下载。
