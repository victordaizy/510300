# 前瞻EPS与报告市盈率关系的来源条件

2026年9月7日登记。国信已提取2791份报告，754份至少一个预测年度的EPS乘表列市盈率无法在显示精度下还原首页参考价；东吴固定早期样本中对应37份。它们是关系不相容的数量，不是已经确认的错误率。七份原件八页目视检查确认了侧栏证券身份混用、正文与表格市盈率冲突，以及原因尚未确认的价格基础差异。本方案在第十九轮账户结果尚未出现时固定。

原始报告、原EPS、原利润预测、市盈率和此前策略结果全部保留。第十九轮仍检验两机构原报告信息的预测价值，其中市盈率倒数是原报告所列指标，不再解释成已经核实的参考价下真实盈利收益率。另立本版来源条件，检验数值关系是否相容。

每份报告须有明确正参考价，至少两个预测年度同时列出EPS和非零市盈率；任一明确列出的市盈率为零则本报告市盈率不进入条件因子。每个数按原文最后一位的一半形成舍入区间。计算各年度EPS区间乘市盈率区间，再要求所有可比较预测年度与参考价具有共同价格交集。原文缺失市盈率的年份保留缺失，不从EPS及价格反填。

报告通过上述条件，并且当月所需的下一年度市盈率确实存在，才将它的原始倒数放入条件因子。没有通过时，仅本版该报告的市盈率指标缺失，原EPS增长和同机构利润修正仍保留。不得跳过最新报告、改取更早报告来恢复市盈率；最新报告选择、180日有效期、90日同绝对年度利润修正继续使用已固定规则。

一个公司有两家机构通过时取两者倒数平均，一家通过时取这一家，均未通过时仍缺失。不同公司再取中位数。原始EPS增长和利润修正的公司及机构汇总完全保持第十九轮因子原值。每个判断月须有至少30家公司提供EPS增长、15家提供利润修正、30家提供通过条件的市盈率；三种新模型均使用这些相同有效月份。某项公司内机构减少会改变最终中位数，因此对照同时包含信息质量与报告构成的变化，不将其全部称为纯粹估值增量。

通过条件只表明报告内部数值相容，不证明股份定义、币种、不可变历史版本、未来十二个月预测或当月实际价格都已对齐。所有报告仍是公开券商资料的部分覆盖，不称全市场一致预期，不构造精确指数EPS。条件不按股票后续收益设置，不改已有利润行或价格，也不选择看起来更有利的正文数字覆盖表格。

本版来源处理完成后，另按完整中文策略规则比较：通过条件的市盈率、原市盈率、完全不使用市盈率。来源阶段不训练、不读取新收益标签、不生成账户，不制作GPT审阅包。
