# 下一项：市场回撤解除后的恢复确认

此文为第177轮事前方案，尚未登记或计算。第176轮的六十日市场回撤条件在主历史改善、较早历史显著变差。本轮固定只研究一种不同的恢复规则：市场回撤由小于或等于负百分之五恢复到严格高于负百分之五后，连续两个收盘仍高于负百分之五，才让辅助重新加入；回撤在阈值下方时仍只保留核心。第176轮“恢复当天立即加入”读取为保存对照，不重跑，不改变其窗口、阈值或结果。

回撤因子仍是含分红累计财富相对最近六十日最高值的跌幅。六十日窗口不足为未知。连续恢复计数在回撤小于或等于负百分之五时重置为零；达到两个后允许辅助，之后只要回撤仍严格高于负百分之五就持续允许。核心和辅助目标、回撤均已知时，允许辅助的目标为两者相加并封顶百分之一百；否则只保留核心。任何输入未知时组合目标未知、实际份额保持。每个收盘十五点零五分决定，下一交易日开盘执行；整手、调仓带、分红、费用、已知零优先退出、未知持仓和终点开盘清算沿用完整账户口径。
