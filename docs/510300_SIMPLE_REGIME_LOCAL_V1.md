# 第24轮：简单切换策略局部改动与季度换规则

第23轮主方案基础夏普0.4806、压力夏普0.3778；趋势与反弹持仓分别有正损益，2022至2023年亏损。继续检验是否存在直接局部改善。本轮不补数据、不训练复杂预测模型。所有账户经济、交易时钟、分红、退出待成交、20万元及完整评价期间，沿用第23轮。

## 二十四个设置怎样组成

四个维度取以下全部组合，共二十四种，其中第一种与第23轮“趋势突破与震荡反弹切换”完全相同，作为复用对照；其余二十三种是新设置。不会只保存表现好的参数。

|维度|可选规则|
|---|---|
|趋势状态，两种|快速状态：收盘高于一百二十日均线，且二十日方向效率超过0.3；慢速状态：六十日均线高于一百二十日均线，且一百二十日累计涨幅为正|
|趋势价格退出，两种|快速退出：趋势状态消失，或收盘跌破此前十日最低收盘；耐心退出：收盘不高于一百二十日均线，或跌破此前二十日最低收盘|
|非趋势状态反弹进入限制，三种|不再限制；当前距一百二十日高点的回撤小于15%；二十日年化波动率低于六十日年化波动率|
|反弹偏离门槛，两种|二十日标准化偏离低于负1.5；低于负2|

趋势模式统一在收盘突破此前二十日最高收盘时进入。反弹模式统一要求处于非趋势状态、符合所选进入限制、标准化偏离低于所选门槛，且当日收盘高于昨日。两个模式不同时成立。

趋势模式除表中价格退出外，亏损8%或含分红持仓价值从周期高点回落8%也退出。反弹模式在趋势状态恢复、标准化偏离回到零、亏损5%、实际持有达到10个交易日任一条件成立时退出。限制只决定是否进入，不会自动作为反弹退出条件。每次实际卖完后经过两个后续交易日的收盘，才可在条件再次成立时产生新买单。所有买卖均下一开盘执行，退出受阻就继续请求。

二十日、六十日波动率分别用截至当日的相应日数含分红简单收益的样本标准差，乘242的平方根；标准化偏离、方向效率和均线定义与第23轮相同。

## 两种季度换规则方法

在2020年评价开始前一收盘以及每个季度最后一个交易日收盘，分别回看最近756个或504个交易日，计算上面二十四种设置的历史完整基础费用账户夏普。训练账户均从2015年1月5日开始，保留连续持仓、佣金、滑点、分红和整手约束；只使用换规则当日收盘及以前已经产生的损益。过去区间至少6次实际成交、收益有限且波动大于零、净夏普为正才有资格。按净夏普最高选择一个，完全相同按编号靠前优先；没有合格者则下一开盘退出并等待下季度。

换规则后的下一日起，以所选规则判断进入和退出；已持有的趋势或反弹模式保持其模式编号，但价格退出条件改用新选设置。周期亏损、最高价值、到期计数及尚未完成的退出请求继续保留。设置变化本身不强制买卖。两种费用评价账户共用基础费用训练账户给出的同一选择安排，以比较真实费用压力的影响。预定主方案回看756日，504日为对照。

本轮比较26个策略或设置及买入持有；其中1个原策略与买入持有的两种费用账户直接复用，因此新增50个评价账户、另有24个基础费用训练账户。历史已用于之前研究，本轮最优只能叫事后筛选最优；季度只用过去数据也不能恢复整个研究过程的独立性。完整时期扣费夏普1.2门槛保持不变，继续列出分年和三个固定阶段。
