# 沪深300基本面反应不足官方财务事实 V1.3

## 修订结论

V1.3 只修复 V1.2 固定 120 份样本中 11 个不完整目标所暴露的可证明版式，不改变 8,223 个目标事件、九期依赖、九项指标、公告可得时点、官方来源、同事件附件回退、覆盖门或收益禁读规则。V1.2 的 120 个检查点以及 `109/120` 完整、`11/120` 不完整结果保持只读；V1.3 使用独立的 `checkpoints_v1_3`。

固定失败样本重放后，11 个目标均可完整提取。其中一个目标使用同证券、同报告期、同公告日的完整官方附件，一个目标使用同事件完整正文附件，一个图像型合并报表使用有界 Windows OCR；其余失败来自多重附注编号、Q3 标签跨页、组合应收款拆分、年报季度表干扰、错标题报表、空白应收账款和固定标签变体。

## 文本报表新增规则

多重附注编号仅在标签后连续出现至少两个语法明确的小整数引用，且其后紧邻带千分位或绝对值至少 1,000 的金额时删除；单个疑似编号仍由原冻结规则处理，不以数值大小猜测。若旧解析结果把已证明的多重附注编号当金额，V1.3 先撤销该事实，再从同一官方行重新取值。

Q3 利润表从第一个年初至报告期末表头起，保留至下一张利润表表头之前的连续页面；只有同一表头同时具有 7—9 月与 1—9 月列时才取第三金额。年报主要财务指标与分季度指标共页时，只在“分季度主要财务指标”之前解析年度扣非归母净利润。

错写成利润表标题的两页资产负债表，只在页面同时具有固定资产、负债字段、明确单位、足够金额密度，且资产总计严格等于负债合计加股东权益合计时接纳。纯应收账款可由合并附注中的“应收票据 + 应收账款 = 合计”当前期和上期双重恒等式证明；官方表格中精确“应收账款”行的当前期和上期金额格均为空时才记零。

## 图像报表有限回退

OCR 不是通用补值。只有目录同时给出合并资产负债表、合并利润表、合并现金流量表和公司资产负债表页码，二者页码差为 4—12 页，且对应 PDF 页面形成同长度文本空白连续段时，才识别该合并报表段。单位必须在该段前 3 页至后 25 页内唯一明确出现。

每页固定以 2.25 和 3.0 两种尺度渲染，使用 Windows `zh-Hans-CN` OCR。每个接纳金额必须在两个尺度下归一化为完全相同的十进制数，并同时满足：

1. 资产总计 = 负债合计 + 股东权益合计 = 负债及股东权益总计；
2. 营业利润 + 营业外收入 - 营业外支出 = 利润总额；
3. 归母净利润 + 少数股东损益 = 净利润；
4. 官方摘要中可获得的营业收入、归母净利润、经营现金流和总资产重复值全部一致。

识别前由非报表文本误抓的非扣非指标全部撤销；任一尺度、单位、辅助行、恒等式或摘要重复值失败，整组 OCR 事实保持 `NO_VIEW_REQUIRED_OFFICIAL_FINANCIAL_FACTS_INCOMPLETE`。临时图片在单文档完成后删除，不长期保留。

## 事实、覆盖门与禁止事项

每项事实继续保存原事件公告 ID、实际 PDF 公告 ID、官方 URL、PDF SHA-256、文件字节数、页码、原始标签、原始金额、单位、定位、解析方法和验证状态。只有 11,892 份文档全部终态，且 8,223 个目标事件九期完整依赖覆盖率达到总体 90%、逐公告年度 80%、每个至少 50 个目标事件行业 75%，才输出 `PASS_OFFICIAL_PDF_VERIFIED_PIT_FINANCIAL_FACTS_V1`。

覆盖门通过前不得读取市场价格、未来收益、构造未来标签、信号、分位数组合、仓位、订单或交易授权。覆盖不足时只交付事实和缺口账本，不修改字段、样本、行业、窗口或门槛挽救。

## 精简检查范围

只执行父冻结与输入哈希、V1.2 失败收据、V1.3 代码与配置、官方主机、公告时点、PDF 文件头、字段证据、有限 OCR 恒等式、检查点终态和覆盖门检查。不执行通用安全、隐私、依赖漏洞或全项目重复审计。
