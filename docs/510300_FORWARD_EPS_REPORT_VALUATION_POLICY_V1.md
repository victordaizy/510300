# 第十七轮：前瞻EPS与研报发布时的估值空间

登记日期：2026年9月7日。目标仍为510300与现金完整账户净夏普至少1.2、稳定超额。此前全部历史结果已经观察，本轮是新信息的有限检验，不是独立验证。不准备GPT数值审阅包。

## 一、来源和检验问题

股数资料核对显示，72份明确快照覆盖2017年至2021年，55份在百万股显示精度内与更早财报相符，17份有待解释差异；相符也不证明期间没有公司行为。因此本轮不把财报期末股数直接沿用为交易日股数，不构造声称已经完成校正的当前前瞻市盈率。

固定2791份已有EPS预测的原始研报中，2714份有明确“收盘价”，402份同时有明确“合理估值”区间或单值。只取基本资料区明确字段，不从投资建议正文猜目标价，也不把缺失目标填成零。所有402份中点相对报价的空间均为正，存在单家券商公开目标的偏多倾向，不能直接把目标价当未来会兑现的价格。

研究问题是：在已有前瞻EPS因子之上，研报公开估值空间是否能改善510300未来60日收益预测及完整账户？信息是报告发布时相对自身参考价的观点，不是按每个月末新股价重新计算的估值，也不推断每份目标都采用市盈率法。

## 二、一个新增因子

每份报告把合理估值区间的上下界相加除以二，得到中点，再除以同份报告基本资料中的收盘价，最后减一。若原件只给单一合理价，上下界取相同原始单值。

每个月末，按当时真实沪深300成分和原已保存的最新可用报告选择公司。报告的信息日期严格早于判断日、报告最长180日历日，当前报告无目标价时不能沿用更早报告目标。公司须有同报告的可用前瞻EPS增长和明确目标空间，至少十家公司才取目标空间中位数。十家门槛在完整来源汇总前已经固定，不根据策略收益改覆盖要求。

原三个前瞻因子保持不变：同报告下一年度相对当年度的EPS对称增长中位数；同绝对目标年度利润预测90日对称修正中位数；报告参考价下下一年度市盈率倒数中位数。增长与估值各至少30家公司、利润修正至少15家，另满足新目标空间门槛，才有共同有效月份。现有来源形成31个这样的月末，少于原50个EPS有效月末；覆盖差异必须通过匹配对照识别。

## 三、一次登记三个候选和两个复用对照

1. **前瞻EPS加研报估值空间，主方案。** 使用原三个EPS因子加上述一个新因子，共四项。
2. **共同月份的仅EPS模型。** 使用原三个EPS因子，但只用与主方案完全相同的月份和成熟标签训练、预测，用于隔离新增估值信息的作用。
3. **主方案预测配合一致趋势进出场。** 复用主方案的预测，不训练第三个模型；增加下文明确的趋势进入、退出和再进入条件。

每个候选基础和压力费用各生成一条账户，共六条新账户。再复用原完整EPS模型与买入持有的双费用账户四条，合计十条评价账户。不能把复用对照称为新生成，也不能把样本日历缩短带来的变化说成新因子效果。

## 四、训练和普通月末进出场

每月最后一个交易日一个样本，预测从下一开盘开始未来60交易日开盘到开盘含分红收益。至少十二个共同有效、已成熟月份才训练；标签退出日不晚于判断日，不能用尚未兑现收益。岭回归强度固定10，每次标准化只用当时训练样本，保存每次模型和预测。共同月份对照与主模型共享训练起点和标签。

月末收盘有预测时，比较维持现有份额及零、四分之一、二分之一、四分之三、全部资金目标，先处理整手和可用现金。评分为股票占比乘60日收益预测，减两倍股票占比平方乘60日收益方差，再减预计交易成本占总资产比例。方差使用过去60日含分红日收益样本方差乘60。选择评分最高的实际份额，近似同分优先保持原份额。

目标比当前份额多，下一开盘进入或增加；比当前少则减少；为零则全部退出；相同则保持。清仓后等后续有效月末再按同样规则决定是否进入。缺少资料不填零，不自动解释为看跌，已有份额保持。非月末不因模型值变化交易。

## 五、一致趋势版本的完整附加规则

月末模型要求进入或增加时，只有含分红价格高于120日均线才放行；趋势没有向上时禁止新增买入，减少和清仓照常执行。再入场使用同样的判断，避免同一已知弱趋势既允许买入又立即要求卖出。

持有时每天收盘检查：连续两个收盘不高于120日含分红均线，或者最近一次有效月末预测已满60交易日且没有更新，任一条件触发就下一开盘清仓。新的有效预测重新开始60日计时，不按最早买入日机械清仓。

退出请求触发后持续到实际卖完，优先于同日新增买入，不能因价格恢复或新正预测撤回。卖完后只能在新的共同有效月末、模型要求进入、趋势已经恢复向上时再次进入。本轮没有另加五日等待，也没有另试止损和回撤阈值。

## 六、完整账户与评价

初始20万元，2020年1月2日至2026年8月14日开盘退出，包含全部早期现金时间。交易100份整手、T+1、下一开盘、按涨跌停与实际现金限制；计入分红和应收，不按触发价强行成交。基础佣金万分之二、最低5元、单边滑点万分之五；压力佣金万分之四、最低5元、单边滑点千分之一。现金收益和夏普参考均为零，每年242交易日。

评价十条账户、逐年和阶段结果，用20日与60日区块各2000次保存样本计算配对区间。主方案对共同月份EPS对照识别估值增量；共同月份对照对原EPS账户识别覆盖和训练日历变化；趋势版本对主方案识别进出场政策影响。保留所有结果，不按新成绩改目标空间口径、门槛、时间或方向。目标夏普1.2及稳定超额未被证实前保持未完成。
