# 510300 原政策公告追溯固定用途

TECH.R229登记、R230来源描述结果。目标是识别进场前真正可知的官方宣布和实施信息，支持用户要求的启动、传播、延续、失效机制研究。本用途不运行新金融策略。

准备金与资本目录按参考日及工具家族形成检索组，保存全部原参考ID；只是查源分组，不是经济信号身份。每组固定查询、官方域名、最多两个新原生来源。来源选择只用工具内容及时间关系，不读取盈亏排名。一次有限请求，真实失败保留；搜索片段仅作线索，原文才可核对内容和钟。不同事件共用来源不视为独立投票。

原正文中宣布、实施、申请或操作记录分别保留角色。公布时间有秒用秒，日期级用23:59:59上界，未知不补。当前网页不是经认证的历史首版。原政府文件gov_20190104.html页面标注2019-01-05，正文叙述01-04决定；R228相关表述需要新增事实纠正，旧正文、实验及文件均保持。
