# 原始基金申赎表相邻跨页修正

第一版识别保留不变：56份PDF中47份完整识别，9份申赎表跨页而未读取完整。逐项查看原始报告证实，2013年二季报、2016年三季报及四季报、2018年四季报、2019年二季报、2020年二季报、2021年二季报、2023年二季报及四季报属于同一问题。2020年二季报第11页拆分项目标签本身跨到第12页。

修正只对原版失败的同一报告启用：要求基金身份、季度、送出日期已经通过；“开放式基金份额变动”标题在全PDF中唯一，标题旁有单位为份；只读取标题所在页及紧邻下一页的二维表。仅保留期初、申购、赎回、拆分、期末五个明确项目，顺序必须一致、不得重复；拆分项目跨页的标签补行不作为数值。其余资产及单一投资者表不能混入。沿用原版十进制数值、符号及份额恒等式检查。

旧有47份通过记录原样保留，所有修正另写目录。份额提取成功仍要独立通过公布日期检查。2013年二季报没有可信官方公告目录，其数值即使完整也不能进入策略。来源修正在新策略标签、训练及账户收益读取前登记，未改变任何策略阈值、样本门槛或结果。
