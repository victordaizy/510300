## 1. 假设与独立性

假设是：正常化盈利收益率只有相对于同期无风险利率才具有完整估值含义；正常化EY高于10年期国债收益率越多，随后中长期收益应越高。VAL-02必须与VAL-01分别形成信号、分别计算诊断、分别下结论，不允许把两个信号组合后再判断是否有效。

本模型继承VAL-01完全相同的点时财务、公司正常化盈利、指数聚合、覆盖和历史污染规则，只增加一个预先冻结的同日利率减项。

## 2. 唯一正式信号

```text
NormalizedEYSpread_t = IndexNormalizedEY_t - CGB10Y_t / 100
```

`CGB10Y_t`是快照日同日的10年期中国国债收益率，供应商原始单位为百分数，除以100转为小数后相减。必须同日精确匹配；不得前向填充、回填、改用月均值、1年期利率、贷款利率或事后选择其他期限。缺少同日10年期收益率时当月为`NO_SIGNAL`。

不把股息率与盈利收益率相加，避免重复计算盈利分配；不登记“负利差且高估值时0%仓位”变体，因为其条件和阈值尚未形成独立预注册。

## 3. 五年分位与候选仓位

对`NormalizedEYSpread`使用包含当月的60个月连续窗口和精确经验midrank：

```text
Q_t = [#(Spread_j < Spread_t) + 0.5 × #(Spread_j = Spread_t)] / 60
```

首个允许信号日为2021-07-30，最早执行日为2021-08-02开盘。候选映射固定为`[0,.2)→25%`、`[.2,.4)→50%`、`[.4,.6)→75%`、`[.6,1]→100%`，本阶段不生成仓位。

## 4. 后续预测屏幕

主目标、T+1入场、242交易日期限、H00300确认、60/120日辅助诊断、时间前后半拆分和历史污染标签均与VAL-01完全相同。VAL-01与VAL-02的主要HAC单侧p值在家族显著性0.10下采用Holm-Bonferroni校正，禁止只保留表现更好的一个模型而隐去另一个。

## 5. 停止条件

任一输入哈希漂移、120个月不连续、任月成分数不为300、价格覆盖低于99%、正常化盈利覆盖低于90%、同日10年国债收益率缺失、使用未来财务/价格、首个分位日或执行日不符，均停止并输出`NO_VIEW`。预测屏幕失败后不得改利率期限、改分档或直接运行仓位回测。
