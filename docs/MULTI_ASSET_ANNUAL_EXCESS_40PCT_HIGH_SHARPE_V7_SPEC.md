# 多资产年化净超额40个百分点与高夏普V7扩展规范

## 已登记终态

美国杠杆多资产V1R修正了官方汇率覆盖后，在唯一正式可见期运行中触发 `FAILED_DATA_OR_EXECUTION_CONTRACT`，错误为“历史路径容量失败”。冻结信号端显示，TMF全部16次入选的单笔容量只有约5,262至31,851美元，低于50万元账户单个50%目标约35,500美元。没有形成可接受绩效报告，V1和V1R均关闭，不得删除TMF、放宽参与率或缩小账户规模救回。

## 唯一新增路线

V7只开放固定BTC-USD和ETH-USD的Coinbase现货、只做多、波动缩放时间序列动量路线。账户不得借款、使用保证金、做空或持有衍生品，毛敞口不超过100%。该路线的24小时连续交易、现货分数单位、交易费和风险来源与A股、可转债、QDII及美国杠杆ETF不同。

候选必须在任何策略结果前固定日线时区、20日趋势、56日波动、周频执行、目标波动、持仓权重、容量、费用、汇率、可见与封存日期，以及40个百分点净超额和1.50净夏普门。官方接口提示无成交的时间桶可能缺失，因此完整日历覆盖是数据门，禁止事后填价。

Coinbase研究页和其他公开材料已展示数字资产趋势策略的部分历史表现，因此结果只能是 `DISCOVERY_ONLY_DIGITAL_ASSET_SPOT_TREND_VISIBLE`。Paper、Shadow、订单、券商或交易所连接和实盘始终关闭。
