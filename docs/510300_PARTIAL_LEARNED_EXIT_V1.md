# 第49轮：学习信号先减半，余下按原自然规则退出

## 本轮只检验什么

原线性模型连续两个收盘预测继续持有价值为负时，原策略一次性全部卖出。本轮只检验将这一动作改成一次减半，剩余份额继续执行原价格、止损、回撤和时间退出。原进入、模型、训练样本、系数和确认天数不变，没有新的模型拟合。原提前退出是否错失后续行情仍是待验证的假设。

本轮按“分批退出、部分退出、先减半”等名称检索现有研究，未发现同一实际持仓中减半设计。第41轮的固定半仓在进入时就只买半份预算，和本轮先满份进入、持仓过程中减半不同。只固定一个版本，不搜索减仓比例或条件。

## 进入因子与进入条件

隔夜涨跌为“当日开盘加每份除息分红，除以前日收盘”的自然对数；日内涨跌为“当日收盘加该分红，除以当日开盘加该分红”的自然对数。两部分相加等于含分红总回报的自然对数，避免把除息直接当成负面信号。

每日取日内对数涨跌减隔夜对数涨跌。将最近六十日该差值相加，再除以同六十日差值的样本标准差及六十的平方根，得到相对强弱分数。分母为零或必要输入缺失时分数不可用。

空仓、原进入许可有效、距离最近一次全部卖完至少两个交易日，且分数连续两个收盘都严格大于一时，第二个收盘后请求下一交易日开盘买入可负担的100份整数倍。只买一次，不在持仓期间追加。买入受阻不会消耗许可，下一收盘继续按原条件检查。

沿用原数据完整性标记，不新增价格方向过滤。该标记涵盖原三十四项行情特征的完整性，最长预热是252日；本轮两个评价时期及各自前一决策日均须完整。原三十四项包括八种期限涨跌、五种均线偏离、三种波动、两种下行波动、三种回撤、六种日内与隔夜累计涨跌，以及振幅、收盘位置、成交量相对值、方向效率、两日涨跌比例、二十日标准化偏离和长短波动比。它们的有效性不构成新的方向判定，本轮实际进入方向只使用上述六十日相对强弱分数。

## 退出模型的全部八个因子

|因子|中文定义|
|---|---|
|持仓时间|买入当天计第一日；当前持仓日数加一后取自然对数。|
|含分红浮盈亏|当时实际份额的收盘市值加本周期已确认分红，除以买入成交金额加佣金，再减一。|
|持仓回撤|上述含分红持仓价值，除以本周期历史最高收盘价值与初始成本中较高者，再减一。|
|进入模式|本策略只有一个进入模式，该因子固定为一。|
|五日涨跌|最近五个交易日含分红总回报的自然对数之和。|
|二十日涨跌|最近二十个交易日含分红总回报的自然对数之和。|
|一百二十日均线偏离|含分红累计总回报水平除以最近一百二十日该水平的均值，再减一。|
|二十日波动|最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。|

模型仍使用第31轮保存的原线性模型。每月首次收盘，只允许用当时已自然结束的最近二十个原参考持仓周期；至少十个完整周期、一百条持仓状态才训练。每个周期总权重相同，周期内各状态平分权重。学习目标是继续持有到原自然退出、相对下一开盘立即卖出的净收益差，包括费用和按登记日取得的分红权益。

各因子减训练加权均值、除训练加权总体标准差，再限制在负五至正五；零标准差用一作缩放分母。带截距岭回归的惩罚强度固定为一。实际每月均值、标准差、系数和截距随交付提供原中文模型表，不重新拟合。本轮只在第一次学习减仓请求之前调用模型，此时仍持有本次原始全部买入份额。

连续两个不同的实际持仓收盘得到负预测，才触发学习减仓。预测非负、没有成熟模型或所需因子缺失都会清除连续负值计数；没有模型不等于卖出信号。模型的训练日期及最后成熟周期不得晚于当时决策日。

## 减半、剩余持有和最终退出

每个收盘先检查原自然退出：相对强弱分数连续两个收盘小于零；剩余含分红持仓收益达到亏损6%；剩余持仓价值从同比例高点回撤8%；从原实际买入日起持有达到六十个交易日。任一成立，下一开盘请求全部卖出，优先于学习减半。

尚未触发原自然退出，且本周期第一次满足连续负预测时，锁定一次减仓数量：当前份额的一半，向下取整到100份。比如持有300份则先卖100份、留200份。若仅持有100份，减半不足一手，改为全部卖出。除这一整手边界外不另外改变比例。

减仓受阻时保留第一次锁定的剩余份额，下一收盘只补足未卖数量，不把每次请求都重新计算成再减一半。在等待减仓成交期间，原自然退出成立时，立即升级为全部退出请求。全部退出一旦触发就持续保留，后续模型或价格恢复也不取消。

完成减仓后不再用学习模型作第二次减仓，也不按模型恢复而买回。继续逐日检查原自然退出，直到剩余份额全部卖完。持仓时间从最初实际买入日计算，减半后不重新计时。最后全部卖出后才开始原两个交易日等待期，并要求在空仓时先见到旧进入条件消失，再重新出现；不能在仍持有剩余份额时重新放开买入许可。

## 部分卖出后的成本、分红和风险口径

实际账户按每次真实模拟成交扣佣金、滑点，卖出款进入现金。卖出只处理满足次日可卖条件的份额。不用半仓理论收益代替现金、整手和实际成交路径。

为了让机械减仓不被误算成亏损，剩余风险账同时按“卖出后份额除以卖出前份额”的比例缩减三项：原分配给剩余份额的买入成本、已确认且分配给剩余份额的股息、剩余持仓对应的历史最高价值。后续止损和追踪回撤只比较剩余份额市值加对应股息与上述同比例成本、高点。已卖部分的成交损益和费用仍完整进入账户，不拿它们抵消剩余仓位的价格止损。

分红以登记日实际份额锁定权益。登记后再卖出，已经取得的实际权益不会消失；除息时按原登记数量确认应收，到账后按原账户时钟进入现金。剩余风险账只分配其中对应剩余份额的一部分，已卖部分应得股息保留在实际账户，因此不会为了风险分摊而删掉收益。

登记权益同时记录原持仓周期。即使一个周期已卖完、另一个周期已经重新买入，后来确认的旧股息仍计给取得该权益的旧周期，不能混入新周期浮盈。全部已结束周期的“累计卖出净款加已确认分红减原买入含佣金成本”，应等于账户相对初始现金的净变化。

## 数据、评价与停止条件

只使用现成510300日线、原分红表和已保存模型。研究范围仍为510300与现金。主评价2020年1月2日至2026年8月14日开盘，1604个账户日；较早诊断2015年1月5日至2019年12月31日开盘，1219日，各从20万元开始，保留全部空仓日。现金及无风险收益零，242日年化。

基础费用为佣金万分之二、每笔最低5元、滑点万分之五；压力费用为佣金万分之四、每笔最低5元、滑点千分之一。100份整手、0.001元价格跳动、原方向性涨跌停、买入次日可卖和研究终点开盘退出保持。两段历史均已被研究，不能作为独立验证。

每个时期只生成这个新配置的两档费用账户；复用原学习全部退出、只用原自然退出、原急跌与学习信号各半组合、买入持有四个对照的八个记录。每期10个记录，两个时期共4个新账户，无新训练或新连续参考账户。验证测试中全部卖出的比例只用于合成路径与旧账户的经济一致性检查，不算一个新历史策略。

先检查一次减半、未成交数量锁定、原保护优先、登记权益、风险成本比例、旧周期股息、最小一手、全出经济一致性及未来价格隔离，再跑全部账户。如未改善，不继续搜索减仓比例、减仓次数或负预测确认天数；保持完整净夏普1.2、费用压力和稳定超额要求。
