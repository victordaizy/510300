# 第27轮：限价等待、订单到期与原有退出规则

第23至26轮改变信号后仍未达到稳定夏普1.2。本轮改变进入方式，检验预先确定买入价格能否改善完整账户。只使用已有日线，不补EPS，不引入新资产。共12种策略设置，在两种不同成交假设下分别计算。事先指定主方案为“偏离均值后的首日回升、限价低于信号收盘0.5%、有效1日、只允许开盘符合限价时成交”。

## 三套进入信号与退出规则

以下因子和阈值保持既有第23、26轮原样，本轮只改变买入订单。含分红价格、标准化偏离、方向效率与成交量口径均保留原表。

|基础信号|何时产生买入意向|何时全部退出|实际卖完后重新进入等待|
|---|---|---|---|
|趋势突破与震荡反弹切换|收盘高于一百二十日均线且二十日方向效率超过0.3时，收盘突破此前二十日最高收盘；其他状态下，二十日标准化偏离低于负1.5且今日收盘上涨|趋势持仓：趋势状态消失、收盘跌破此前十日最低收盘、亏损8%、从持仓高点回落8%，任一成立；反弹持仓：趋势状态恢复、偏离回到零、亏损5%、持有10日，任一成立|2个后续交易日收盘|
|偏离均值后的首日回升|二十日标准化偏离低于负1.5，且今日收盘高于昨日|偏离回到零、亏损5%、持有10日，任一成立|1个后续交易日收盘|
|急跌后放量收强|截至昨日五日跌幅超过3%；今日收盘上涨；成交量至少为此前二十日均量1.5倍；收盘位置至少0.75|偏离回到零、亏损4%、盈利6%、持有10日，任一成立|2个后续交易日收盘|

标准化偏离为当前含分红价格减二十日均值，再除以二十日样本标准差；方向效率为二十日净位移绝对值除以每日位移绝对值之和；收盘位置为收盘在当日最高与最低之间的相对位置。成交量分母不含当日。上述信号均在收盘后才形成。

## 十二种订单设置

三套信号分别与“限价低于信号收盘0.5%或1%”及“有效1个或3个交易日”全部组合，共12种。限价按0.001元向下取整。信号收盘时以账户现金、预定限价及佣金确定可买的100份整数倍数量，随后不追价、不增加数量。限价单从下一交易日生效，在第1个或第3个交易日结束后到期。到期或撤销当天不再开新单，至少等下一个收盘重新判断。

挂单期间即使入场信号不再重复出现，只要对应持仓模式的价格退出条件尚未成立，订单仍可保留至到期。原模式价格退出条件成立则当日收盘撤销。跨除息日的买单在该日开盘前取消，避免把除息价格降低误算为折价买入。限价超出当日涨跌停范围则当天不参与，仍按原到期日处理。

## 两种成交假设分别报告

**只允许开盘满足限价。** 当日开盘加预定滑点、按最小价格跳动处理后，不高于限价且没有方向涨停限制，才模拟买入；否则当天不成交。盘中最低价无论多低都不能补成交。这是本轮主要口径。它仍是开盘成交模型，没有真实订单排队证明。

**允许盘中明显跌穿后的条件成交。** 开盘首先按上述规则判断。开盘不符合时，事先从限价倒推出扣除滑点后的参考价格，并按0.001元向下取整；只有当日最低价至少比该参考价再低0.002元时，才按参考价加滑点、且最终不超过限价模拟买入。仅触及限价不成交。所有这种成交标为“盘中时间未观察到的条件模拟”，不能描述为历史实际成交，也不证明有足够对手盘。更深的最低价只决定是否满足预定模型，不用于事后挑选更好的买价。

两种口径不会混合选仓位。限价申报的价格约束参见[上海证券交易所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)；成交量与队列的缺失由上述假设明确保留，不能用该网页替代实际成交证据。

## 持有和退出时钟

只有实际模拟成交后才开始持仓周期和最长持有计数。每周期买入一次，余单取消，不加仓或部分减仓。无论开盘还是盘中买入，当日都不卖出；收盘触发退出后最早下一开盘请求全部卖出。亏损和止盈以含佣金买入成本为分母，以持仓市值加该周期分红为分子；高点使用该含分红价值的历次收盘高点。退出遇跌停或可卖份额不足，继续保留退出请求。

完整账户按实际模拟成交参考价计算当日损益，再扣佣金与滑点；盘中买入不会被错算成从开盘就持有。全部订单保存信号原日、限价、数量、到期日、成交假设、撤销或到期结果。未成交不会被换成零收益预测。

## 全时期和较早时期的检验

主比较保持20万元、2020年1月2日至2026年8月14日开盘终点、510300与现金、242日年化、现金与无风险收益零。基础佣金万分之二、最低5元、滑点万分之五；压力佣金万分之四、最低5元、滑点千分之一。100份整手、当日买入次日可卖、涨跌停及实际分红权益和到账完整计入。

新增48个限价评价账户，复用三套原开盘策略及买入持有的8个对照。每种成交假设按照基础夏普选出主评价最高设置后，保持参数不变检验2015年1月5日至2019年12月31日开盘终点，并加入同一期间买入持有，共最多6个更早历史诊断账户。较早历史已被研究过，且设置由较晚历史挑选，因此这是反证诊断，不称为独立验证。净夏普1.2、成本压力、跨时期稳定性和稳定超额要求均不降低。
