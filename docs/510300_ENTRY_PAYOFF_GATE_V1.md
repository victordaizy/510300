# 第95轮：在买入前预测整次交易净收益

只登记一个设置：原六十日日内强弱条件给出机会后，用当时已知的九项市场因子预测本次进入至原自然退出的完整账户净收益；严格为正才请求买入。四条自然退出与等待旧进入条件消失的规则保持，不再学习提前退出。训练直接复用第59轮保存的假想进入路径，不新增价格来源、指数前史或参考账户。

## 九项进入因子

1. 五日涨跌：最近五个交易日含分红简单收益各加一、取自然对数后相加。
2. 二十日涨跌：同样办法汇总最近二十个交易日。
3. 一百二十日均线偏离：当日含分红财富指数除以最近一百二十日平均财富，再减一。
4. 二十日波动：最近二十个日含分红简单收益的样本标准差乘以二百四十二的平方根。
5. 相对波动：二十日波动除以六十日波动，沿用原数据极小分母下限。不是未来波动。
6. 二十日均值偏离分数：当日含分红财富减二十日平均财富，再除以同期财富的样本标准差。
7. 两日相对强弱：最近两个交易日财富上涨额之和，除以同期上涨额加下跌额绝对值之和，再乘一百；沿用原零变化时取五十的定义。
8. 收盘位置：当日收盘价减最低价，除以最高价减最低价；沿用原高低价相同时取二分之一的定义。
9. 日内相对隔夜强弱：把最近六十日“日内对数涨跌减隔夜对数涨跌”相加，除以该差值六十日样本标准差，再除以六十的平方根。ETF日内为收盘加每份分红除以开盘加分红后取自然对数；隔夜为开盘加分红除以前收盘后取自然对数。

含分红日简单收益为“收盘价加当日每份分红，除以前收盘价，再减一”；财富指数由每天一加该收益依次相乘得到。九项输入全部来自进入申请当日收盘及此前资料。原资料完整性和最长预热保持，不将未来波动、实际退出收益、信号组最终长度或未来是否成交作为进入因子。

## 训练标签与成熟规则

第59轮已保存1213次符合原条件的单次进入尝试，属于49个连续信号组。每次假想账户均从二十万元开始，只在原点的下一开盘尝试买入一次，按原基础费用和自然退出规则结算。各路径相互重叠，不代表1213个独立市场样本，也不是一只账户同时做这些交易。

新标签为这次假想账户完整自然退出后的净值除以初始二十万元，再减一。净值包含剩余现金和已确认分红应收，佣金及滑点已经扣除。分红应收转现金时不重复增加收益；如果退出之后才确认此前持股已取得的权益，补入对应权益一次，并把标签可用日期延后至确认日。首次未成交没有已完成的投资收益标签，终点强制退出和未自然结束路径也不提供成熟标签；这些记录继续保留。

一整个原信号组已经观察到进入条件消失，且组内每次登记尝试均已处理完毕后，才允许该组训练。若该组仍有未结束路径或缺失，整个组等待；组内单条路径提早退出不能提前释放整组。训练成熟日期取原组成熟日与该组全部收益标签最晚权益确认日中的较晚者。未来尚未成熟的标签绝不用于当前预测。

初始拟合时点为2014年12月31日收盘，随后每月第一个交易日收盘更新，下一开盘才可能使用。每次取当时已成熟的最近二十个信号组，至少十组且一百条自然完成路径才拟合。每组总权重一，该组各条有效自然完成路径平分；不按盈利多少、持有长短或路径条数增加组权重。

采用线性岭回归，惩罚系数一、截距不惩罚。每个因子减训练组加权均值，除加权总体标准差，标准差近于零时按一处理，标准化值截在负五至五。预测是截距加九项标准化因子乘各自系数之和。每月真实系数、均值、标准差与成熟样本日期另存中文说明。

这是完整交易收益预测，不是胜率；不同路径持有期限不同，正预测不代表已经证明高夏普。基础与压力实际账户使用同一个基础费用训练模型，压力账户按自身费用与成交计算真实结果。

## 进入、持有、退出与再次进入

每天收盘，六十日日内相对隔夜强弱分数连续两个收盘严格高于一、原因子完整，并且账户空仓、距实际退出至少两个交易日、有再次进入资格时，检查进入模型。预测完整交易净收益严格大于零，下一开盘申请用可用现金买入能负担的最多整百份510300。预测为零或负数时，本收盘不申请买入；后续收盘可以根据新市场状态重新判断。

模型尚未成熟或九项因子不完整时记录无可用判断，不发起新的买入，也不把无观点填成正预测或现金目标；实际已有份额照常执行可知的退出规则。因为新账户初始为现金，模型成熟前可能长期没有成交。这一等待阶段须计入全部账户日，并单独报告，不能解释为模型预判了当年的涨跌。

实际买入后只执行原自然退出。满足任一条，在下一开盘申请全部卖出：六十日强弱分数连续两个收盘低于零；本周期含分红价值较实际投入亏损达到百分之六；含分红价值从周期最高值回落达到百分之八；或者已持有六十个交易日的收盘。本轮不使用第31轮或第93轮的继续持有预测提前卖出。买入成本包含实际成交金额和佣金，周期价值包含实际份额市值及本周期已确认分红。

退出受阻继续逐日申请。实际买入才消耗再次进入资格，模型拒绝或首次申请未成交不会消耗资格。卖出后必须在空仓期间看到原进入条件本身消失，再等待重新出现，并满足两日冷却；模型从正变负不能冒充原价格条件消失。退出前不追加买入、不部分卖出。

## 完整评价

主历史为2020年1月2日至2026年8月14日终点开盘，较早历史为2015年1月5日至2019年12月31日终点开盘。各段各二十万元现金重新开始，基础及压力费用各跑一次，共四个新账户。原第32轮自然退出、原线性提前退出、第91轮局部候选及买入持有复用保存账本。

所有交易日、模型未成熟等待日、空仓日和未成交均保留。每手一百份、最小报价一厘、买入次日可卖、方向涨跌停与可用现金限制保持。基础费用单边佣金万分之二、最低五元、滑点万分之五；压力费用单边佣金万分之四、最低五元、滑点千分之一。按242个交易日年化，现金利息和夏普无风险收益假设为零。分红按实际登记份额取得、除息确认为应收、支付转现金；终点开盘统一清仓。

目标仍是净夏普至少1.2及稳定超额。主基础费用单区间达到不能替代压力、较早历史和独立验证。原数据已被多轮研究观察，不能称新的未见样本。本轮结果不好时结束这一完整交易收益进入模型，不在结果后改特征组合、正负阈值、成熟组数、组权重或无模型行为。
