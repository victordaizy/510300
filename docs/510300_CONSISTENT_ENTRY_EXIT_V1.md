# 第33轮：入场前检查已有退出模型的判断

第32轮“日内强弱＋线性学习退出＋等待新机会”基础夏普0.705、压力0.641，仍未达到1.2。本轮只加一条入场条件：原入场信号成立时，若当时已经训练好的线性模型预测继续持有收益为负，则暂缓买入。只登记这一种设置，不重新训练、不改变阈值或等待天数。

## 原入场、退出与再次进入全部保持

每日先计算日内对数涨跌减隔夜对数涨跌，六十日之和除以这六十日每日差异的样本标准差和六十的平方根。该值连续两日大于1时，满足原入场条件；实际卖出后至少经过两个交易日，且旧入场条件至少在一个收盘不成立过，才重新允许后续进入。初始账户有首次进入许可；只有实际买入后才关闭许可，未成交或被新条件暂缓均不消耗许可。

原退出包括：上述差异连续两日小于零、含分红持仓亏损达到6%、相对持仓最高收盘价值回撤达到8%、或者持有达到六十个交易日。学习退出沿用第31轮已经训练完成的线性模型，若同一真实持仓周期连续两个收盘的继续持有收益预测为负，也请求下一开盘全部退出。退出受阻后持续请求，直到实际卖完。持仓内不追加份额。

## 入场前的八个模型输入怎样构造

只有原入场条件、等待期和进入许可均满足时，才做这项额外检查。在当日收盘，以已知现金、当前收盘价、固定买入滑点、价格单位和佣金，计算可负担的整手买入数量。假设此刻按这份已知价格成本建立持仓，构造以下状态；真实买入仍在下一开盘。

|因子|入场检查时的值|真实持仓后的值|
|---|---|---|
|持仓时间对数|按假设持仓第一日，一加一天后取自然对数。|按真实买入日至当前的交易日数计算。|
|含分红浮盈浮亏|假设份额乘当前收盘价，除以包含买入滑点和佣金的假设总成本，再减一；新周期分红为零。|按实际份额、当前收盘价、已确认周期分红和实际买入成本计算。|
|持仓回撤|假设当前持仓价值除以“假设买入总成本和当前价值中较高者”，再减一。|按实际周期截至当前的最高收盘持仓价值计算。|
|入场模式|固定为日内强弱的单一模式1。|保持模式1。|
|五日涨跌|截至当前收盘，最近五日含分红对数收益之和。|同样使用截至判断收盘的历史。|
|二十日涨跌|截至当前收盘，最近二十日含分红对数收益之和。|同左。|
|一百二十日均线偏离|当前含分红总回报水平除以一百二十日均值，再减一。|同左。|
|二十日波动|二十日含分红简单收益样本标准差乘242的平方根。|同左。|

假设状态是收盘时可构造的入场检查输入，不能当作次日真实成交或真实持仓首日收盘的观测。下一开盘跳空、份额不足和费用可能使实际状态不同；本轮检验的正是这种事前近似能否改善完整账户。

## 新增入场规则

调用不晚于当前收盘已经训练完成的原线性模型，均值、标准差、系数、截距和输入限制全部不变。预测为负时，当次买入请求置为零，等待后续收盘重新满足全部条件；预测为零或正时，按原计划请求下一开盘买入。没有成熟模型或假设状态不完整时，不增加本项条件，沿用原入场；缺少模型的预测保持缺失，不填零。

入场检查使用独立的预测调用，不增加真实持仓的连续负预测计数，也不能影响真实持仓周期编号。实际成交后，学习退出仍完全按真实持仓状态重新判断。假设可买数量为零时不发起买入。

模型学习目标、最近20个成熟周期、至少10周期和100状态行、周期等权、每月首个交易日收盘训练及全部实际中文系数，严格复用[第31轮规则](510300_LEARNED_CYCLE_EXIT_V1.md)和保存模型。本轮没有新的训练或参数选择。
