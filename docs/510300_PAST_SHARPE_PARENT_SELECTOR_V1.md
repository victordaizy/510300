# 第89轮：按已发生的历史表现选择组合，并设现金退出

一个新设置，510300及人民币现金。两套父组合固定为第82轮两策略最小方差、第88轮三策略最小方差，全部参考路径与原进入、退出、因子和预算不变。区别仅在于本轮按月选择使用哪套完整组合，或者明确选择现金。原结果和研究终态保留；不是按已知年份划分赢家，也不修改旧数字资产资格配置器。

## 使用的全部新因子

1. 两策略父组合完整日净收益：原基础费用账户每日完整净值除以前日净值，减一；包含空仓日、费用及分红。
2. 三策略父组合完整日净收益：同一口径。
3. 两策略过去净夏普：截至月首当日收盘最近242个完整日收益的算术平均，除样本标准差，再乘242的平方根。
4. 三策略过去净夏普：使用完全相同的窗口、年化和零无风险基准。
5. 两套原组合每日下一开盘股票目标：各自已保存的交易意向，可在零至百分之百之间。
6. 当前选择：两策略、三策略、现金三种明确状态之一；资料不足是单独的无新判断状态，不能自动等同现金。

历史夏普的均值、标准差及年化定义参见[William Sharpe原文](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)。该文区分历史与预期数值；过去排名能否预测后续表现，正是本轮需要检验的问题，不能预先当作成立。

## 什么时候选择和切换

初始使用第82轮两策略父组合。仅每月首个交易日完整收盘后检查，使用当日和更早的最近242个完整日。不能借用本评价起点之前不存在的父账户收益，不删除现金日。

两项净夏普都可以计算时，若较大值严格为正，选择净夏普较高的父组合。两项都不为正时，明确选择现金。两项完全相等且为正，若此前已选择父组合则维持它；此前为现金则选择第82轮。不存在按评价结果调整的分差门槛、最短持有期或额外确认次数。

不足242个完整日、任一完整窗口缺失或标准差为零，都没有新的有效选择，维持此前选择。数据中断不填零，不将无观点自动解释成清仓。月首之间保留选择结果，但每天继续跟随所选父组合的原目标。已选现金即目标为零；已选父组合若当天目标缺失，不提出新订单并保留真实份额，不擅自改跟另一套策略。

## 实际进入、减仓、退出和再进入

每天收盘，选两策略就使用它当时的目标，选三策略就使用三策略目标；选现金则请求下一开盘卖出全部。股票目标为正且真实账户空仓时，按本账户完整净值、收盘价格和一百份整手计算买入请求。已有份额时，非零目标与实际仓位相差至少10个百分点才调整；目标零全卖不受带宽限制。

退出既可以来自所选父组合原退出条件，也可以来自月首判断两套过去夏普均不为正；更换父组合也可能直接减仓、退出或进入。后续月首重新选择正夏普组合，且该父组合股票目标为正时，才会重新进入。没有额外叠加止盈、止损或冷却，三条原底层策略自身的保护和重新进入规则继续有效。

基础与压力账户使用同样基础参考评分和父目标，各自从实际现金、份额及分红权益执行并扣费。父策略虚拟收益的拼接不能当成真实新账户。开盘受阻后，下一收盘按最新有效目标重算；保持原现金、涨跌停、T+1、最小价位约束。
