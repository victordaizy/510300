# 第149轮拟研究：每月提高近期三个子阶段中最差的增长表现

148模型更新否决在主历史没有触发，较早少量触发却降低夏普，结束该固定退出公式。下一项回到如何事前分配策略预算：保留131普通波动乘数与143连续预算这两个保存来源，根据当时已经完成的近期账户收益，选择对三个近期子阶段中最弱一段更有利的组合。旧选择器、均线准入和模型分歧的失败判断不变。

每个研究区间独立初始化，131预算为零、143为一。每月第一个交易日15:05检查一次；准备收盘也检查，但不会借用另一研究区间的收益。只用本区间已经实现到当前收盘的两条基础费用来源账户净收益。达到完整242条后，取最近242个连续交易日，按先后顺序分成81日、81日、80日三段，不删除零收益、亏损或日历行。两费用账户使用同一组基础费用训练结果，执行各自费用的父目标。

对任一零至一的131预算，其余给143。每个历史日先按预算加权两条来源的当日净收益，再加一取自然对数；在每个子阶段内取每日对数增长的等权平均。三段中最小的平均值是本轮预算目标，选择使这个最小值最高的预算。这里按等权的历史子阶段检验组合，并不是用将来的年份判断应该用哪一套策略。

求解为确定性的一维区间计算，固定80次收缩；再比较所得候选、零、一和上次有效预算。距离零或一不足一万亿分之一的求解值归到该端点，目标值差不超过一万亿分之一时优先保留上次有效预算；其余数值平局取候选中更小的131预算。这些只用于数值稳定，不搜索收益阈值。完整242条之前保持明确的初始143预算；足够日历但收益缺失时本次预算无观点，并保持到下次可完成估计的月度判断，不用零收益或旧预算掩盖缺失。

两来源当日净收益须大于负百分之百，已知无穷值或非法财富拒绝。预算在月内保持，父目标仍可每天变化。最终目标等于131预算乘对应费用131目标，加剩余预算乘对应费用143目标；双方目标和当前预算都已知才可合成，即使预算为零也保留父目标缺失。来源共享底层成分，不能视为独立证据。

实际空仓且最终目标为正，下一开盘按自身前收盘净值及原价格取100份整手进入；已有仓位与正目标相差达到十个百分点才调仓。最终明确零请求全退，未知不新增调整；受阻每收盘重算，新的正目标可再进入，无额外等待或退出锁定。终点开盘全部清仓。月度预算目标仅用于选择来源，实际收益必须由新账户重新计算，不能用两条保存账户净值简单相加冒充可交易结果。

这种按最弱情景优化对数增长的思想参考[Sun与Boyd的分布稳健增长研究](https://web.stanford.edu/~boyd/papers/robust_kelly.html)。这里用三段历史经验分布作为研究情景，未证明它覆盖未来市场分布；参考论文不证明本策略夏普或超额。131与143、242日和三段划分均为本次事先固定设定，不会因结果改变。

本轮确实会做新的月度预算优化，应单独记录次数；零新收益预测模型训练、零新参考账户及外部下载。一项设置、四新账户，保存131、143、148和买入持有共十六对照。必要测试后冻结，只运行一次；失败不改变窗口、子阶段划分、目标函数或父来源救回。完整目标仍未实现。
