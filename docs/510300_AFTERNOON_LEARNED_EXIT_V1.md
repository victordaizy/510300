# 第43轮：原线性退出模型增加一次下午检查

## 目的与范围

只检验一个新设置：昨日收盘已经预测继续持有收益为负，今天下午再次得到负预测时，提前请求卖出。希望减少原规则等到今日收盘确认、明日开盘执行之间的风险。沿用第32轮原线性候选的进入、满仓预算、价格和时间退出、重新进入许可，不新增训练，不调整进入阈值。

历史模型按收盘状态训练，下午状态与其训练分布并不完全相同。本轮是一次有限历史迁移检验，不先假定迁移有效。第41轮仓位调整和第42轮连续下跌退出的失败结果保留。

## 进入与普通退出

每天取日内对数涨幅减去隔夜对数涨幅，最近六十日之和除以这些日差值的样本标准差及六十的平方根，使用既有含分红口径。该分数连续两个收盘大于一，且账户没有持仓、进入许可有效、距上次实际卖出至少两个交易日，就在下一开盘请求买入可用现金负担的100份整手。

实际买入只买一次，不在持仓期间追加。卖完后必须在空仓时先看到原进入条件消失、随后重现，才获得新一次进入许可。买单未成交不消耗许可。

普通收盘退出保持五项：原强弱分数连续两个收盘小于零；实际持仓含分红收益亏损达到6%；含分红持仓价值从本周期已知收盘高点或初始成本中的较高者回落8%；买入日计第一天，持有达到六十个交易日；原线性退出模型连续两个持仓收盘预测继续持有收益为负。任一成立就请求下一开盘全部卖出。已形成的退出请求若受阻，继续保留。

## 新增的下午事件

每天14时31分检查一次，最多使用时间标签14时29分那条一分钟记录的收盘价。由于提供方没有承诺标签是柱首还是柱尾，额外留出间隔；即使标签表示柱首，该柱结束也早于决策。不存在当天分钟数据、观察价格缺失或无效时，不作下午预测，原收盘机制继续运行。

只检查至少前一个交易日买入、当前全部可卖的已有份额。当天新买入不能在当天下午卖出。已有等待次日开盘的退出请求继续原路径，不另加一个独立下午重试方式。

下午只读取训练完成时间不晚于14时31分的最近模型。月初当天15时05分才更新的模型不能提前使用；应使用此前最近模型。保留原无模型状态，不能把没有模型解释为预测收益零或应空仓。

昨天真实持仓收盘的连续负预测计数至少为一，且今天下午预测仍严格小于零，才形成全部退出请求。下午只查看昨天的计数，不修改它；如果仍持仓，今天收盘只更新一次普通计数。下午未形成退出或未实际成交，不得重复把同一天当成两个确认日。

请求形成后，在时间标签14时46分的记录上检验模拟成交，采用该记录开盘价作为较晚价格代理。无论标签表示柱首还是柱尾，这个价格时段都晚于信号。无法证明真实订单必能以该价成交，因此它仅为历史模拟价格。沿用基础及压力滑点、佣金、价格最小单位和方向性涨跌停。

作为成交容量约束，全部待售份额不超过该分钟实际成交量的10%，才允许一次全部模拟成交。该未来分钟成交量只影响实际成交判定，不能用于提前取消14时31分的信号。价格缺失、容量不足或方向性涨跌停时，保存未成交原因，已发出的退出意图保留，转入后续普通开盘退出。成交量字段按股计，不按手计。没有拆单或部分下午成交假设。

本轮固定上述时间和10%容量限制，结果出来后不扫描下午时刻、确认次数或容量比例。

## 下午使用的全部八个因子

|因子|中文计算规则|
|---|---|
|持仓时间对数|从实际买入日起计到今天的交易日数，加一后取自然对数。|
|实际持仓浮盈亏|实际持有份额乘下午观察价，加本周期已确认分红，除以实际买入含佣金成本，再减一。|
|持仓回撤|上述价值除以此前收盘最高持仓价值、初始成本和本次下午价值三者的最大值，再减一。下午预览不改写普通收盘峰值。|
|进入模式|沿用原日内强弱模式，编号固定为一。|
|五日涨跌|先把昨日含分红总回报水平乘以“下午观察价加今日除息金额，再除以昨日未复权收盘价”，得到下午总回报水平。用其除以五个交易日前总回报水平，再取自然对数。|
|二十日涨跌|同上，将比较日期换为二十个交易日前。|
|一百二十日均线偏离|此前一百一十九个收盘总回报水平加下午水平，除以一百二十得到临时均值。下午水平除以该均值，再减一。|
|二十日年化波动|此前十九个完整交易日的含分红简单收益，加今天截至下午的含分红简单收益，共二十项取样本标准差，再乘二百四十二的平方根。|

下午因子不引用今天完整收盘价、今天完整最高价或最低价、今天完整成交量、今天最终日收益，也不引用以后日期的数据。所需历史项缺失则保留无预测。除息金额按已有分红时点口径处理。

原模型每月从当时已结束的最近二十个参考持仓周期学习，至少十个周期和一百条持仓状态，每个周期总权重相同。标签为继续持有到原参考退出与下一开盘提前退出的净收益差，分红按权益登记日比较。每项因子减训练均值、除训练总体标准差后，限制在负五至正五，带截距岭回归惩罚为一。全部逐月系数直接复用原第31轮保存模型，不使用近期加权改版。普通收盘仍按原八个收盘因子运行。
