# 510300期权前向收盘盘口 V1

## 目的

从协议冻结后的首个未见交易日起，逐日保存510300期权全活跃合约的一档买卖盘口，为已冻结的O1—O4提供真实、不可回填的前向曲面输入。该分支只补数据证据，不改变任何因子、期限、Delta、阈值或仓位政策。

## 时间边界

- 历史污染截止日：2026-08-18。
- 最早允许采集日：2026-08-19；上交所交易日历已在冻结前确认当日开市。
- 必须显式传入预期交易日。
- 抓取开始不得早于14:58:30，结束不得晚于15:05:30，均按Asia/Shanghai记录。
- 在时间窗外运行只输出失败状态，不产生可用快照。

## 动态合约主表

每个采集日重新读取Tushare `opt_basic`，仅保留 `OP510300.SH`，并按当日上市/退市日期确定全活跃合约。标准与调整合约全部保留；不得用冻结日主表造成新合约幸存者偏差。每日主表与盘口分别按日期保存。

## 盘口质量

一个交易日只有同时满足以下条件才是合格前向日：

- 活跃合约覆盖率100%；
- `bid1`和`ask1`正值比例均至少99%；
- 买价高于卖价的倒挂记录为0；
- 合约代码无重复；
- 返回行情日期与预期交易日一致；
- 实际抓取时间位于冻结窗口；
- 日期文件此前不存在，成功后禁止覆盖。

合约自身的 `quote_timestamp` 可能是最后成交时间，不能替代采集器墙钟时间；两者均原样保留。

## 前向门槛

O1—O4在盘口日不足242、20日成熟结果不足242、60日成熟结果不足242或独立坏状态不足5次时，均不得运行策略收益检验。输入缺失、哈希漂移或质量失败时唯一结论为 `NO_VIEW`。

本协议始终禁用仓位映射、订单、券商连接和实盘交易。
