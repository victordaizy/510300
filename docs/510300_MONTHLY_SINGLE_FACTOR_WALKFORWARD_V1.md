# 历史挖掘：三个单因子的按月顺序学习

用户2026年9月14日明确允许“对过去的数据进行挖掘，减少过拟合”。这覆盖“当前只能等待新日期”的安排；允许新的有限历史研究。旧85／15版及其失败诊断保留，当前这轮不救回旧版、不重跑50／60／70窗口。

## 事前问题及三个固定方法

问题：只学习一个行情因素与下个月收益之间的关系，能否在随后月份持续改善完整账户表现？三个方法分别只使用：最近20日含分红对数涨跌；含分红财富值相对20日均值的标准化偏离；最近20日年化波动率的自然对数。三个方法分开运行、全部报告，不选最佳、不组合。

## 时间顺序与训练

每个月最后一个交易日收盘计算一次。输入只用当天及之前的完整数据。每条训练样本是过去一个月末的因子值，标签是其下一月第一个交易日开盘买入一份、再下一月第一个交易日开盘卖出的含分红普通收益。标签为“卖出价减买入价，加持有期间取得的分红权利”，除以买入价。取得权利要求登记日在买入日至卖出日前一日之间；标签需等卖出日及所涉除息日均已发生才成熟，不把尚未观察到的下个月收益用于本月拟合。训练月份之间持有区间不重叠，开盘边界可相接。

只取当前时点已经成熟的最近60个有效月份，至少24个才拟合。每个模型只有一个系数和一个截距。标准化均值、样本标准差只用这批训练数据；训练及待预测因子的标准化值限制在负3至正3。用平均平方误差加系数平方的固定岭惩罚（强度1）拟合；不搜索训练窗口、因子方向或正则强度。各月保存样本月份、标签成熟时间、均值、尺度、系数、截距和预测。

预测的是未扣账户费用的一份ETF月收益，不是实际净收益，也没有假设一份即可真实交易。实际账户另按既有资金与成交引擎计算全部费用。预测值大于事前固定的0.4%缓冲时，目标为10%除以ETF自身20日年化波动率、最多100%；否则目标为零。0.4%是统一预定缓冲，不宣称精确覆盖所有账户费用。资料不足时无新判断，空仓继续空仓、已有份额保留。

## 完整进出场与执行

月末产生正目标且原来空仓，下一交易日开盘申请买入。月末目标为零，下一开盘申请全部退出；连续正目标则按目标调整。正目标与实际收盘仓位相差不足10个百分点不调整。月内保持份额，没有额外日内止损、止盈、学习退出或最长持有规则；连续多月预测为正可以跨月持有。方向性涨跌停或现金约束导致未完全成交的申请不在月内额外追单，按下一月末重新计算；所有未成交和部分成交均报告。这是月频研究的明确执行规则。

每账户初始20万元；仅510300和现金、不借贷；242日年化、现金及无风险收益率零；整百份、0.001价格档、T+1；基础佣金万2／最低5元／滑点5基点，压力佣金万4／最低5元／滑点10基点。登记、除息与到账分开记账。复用现有模拟成交程序。两时期为2015年1月5日至2019年12月31日和2020年1月2日至2026年9月11日；各自从20万元开始、期末收盘估值，不强制末日卖出，不拼接两个账户。

## 基准、计数及淘汰标准

三方法×两时期×两费用，12份新主账户。两个同频基准为“只用已成熟月份平均收益预测、同样0.4%门槛”和“不判断收益、仅月末按10%风险配置”，共8份新基准。另复用简单核心诊断中已经对齐末日收盘的买入持有与日频波动配置，共8份基准；总计20份新账户、8份复用账户。均值基准没有因子系数，不把它列为第四个挖掘候选。

只评价从2014年12月31日起实际可用的训练和预测；此前数据用于预热。同一个月模型在基础、压力及两时期中复用，不重复拟合。实际拟合数由记录统计。模型的学习样本和完整账户分别保存。

继续研究资格事前规定为：在两个时期、两种费用的全部四场景中，年化及夏普均高于同频均值预测基准；同时在2015—2025年的11个完整年度里，至少8年的压力净收益高于该基准；按成熟预测月份评价的平方预测误差低于对应无因子均值预测。2026部分年度单独报告，不参与8／11计数。任何方法不足则本固定方法没有继续加参数的依据；不会选成绩最高者自动晋升。原夏普1.2及年化10%的四场景门槛另外逐项显示，点值通过仍不代表独立验证。

全部按月预测、完整账户、年度结果、持仓周期及失败结果一并保留。三个模型的关系方向由事前确定的单变量拟合程序学习，可以变号；不在看结果后手动反转因子。本轮没有网格、模型家族选择、收益最优配比、删除亏损年份或复算旧诊断。

## 防止过拟合的边界

20日因子窗口、60个训练月份、24个最少月份、截断3、岭强度1、入场缓冲0.4%、风险目标10%、调仓带宽10个百分点，均为研究者事前指定的固定选择；它们也构成方法设计自由度，全部披露，不能仅凭“只训练两个系数”声称没有过拟合。三个完整方法不展开参数组合。本轮不修改任何常数救成绩。

历史已被研究者看过，因此本轮是模型在时间顺序上隔离的历史开发检验，不能称为全新独立样本。按时训练能防止单次拟合偷看未来，不能消除人类此前选方法的偏差。多次试验与选择偏差会抬高历史指标，参见[Bailey与López de Prado原论文](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)。本轮不估计正式过拟合概率。

现版的盘后固定观察及用户手算表保持；本研究输出单独保存，不接入每日账户。完成这轮真实计算后更新研究索引和下一步，不再把缺少新收盘当成不能做历史挖掘的理由。
