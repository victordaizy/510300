# 510300 T_ONLY 压力测试与前瞻影子验证 V1

## 1. 研究问题

历史样本中的 `T_ONLY` 是否只是参数、成交假设或少数行情路径造成的偶然结果；在完全冻结规则后，它能否在新数据中继续产生可执行、扣费后、优于现金及同平均仓位基准的结果。

本分支不修改 `510300_WEEKLY_DAILY_TECHNICAL_V1`。其周线状态、日线唐奇安突破、ATR 加仓与止损、32.5%/65%/97.5% 目标仓位、下一开盘成交、T+1、100 股整手、单次正常交易不少于 5,000 元等定义全部继承父协议。

## 2. 冻结时点与前瞻边界

- 历史压力样本截止 2026-08-14，只用于稳健性否证。
- 2026-08-19 是第一个允许产生前瞻影子信号的收盘日；最早影子执行日是下一交易日，名义日期 2026-08-20。
- 2026-08-19 以前的信号不得带入前瞻账本。完整历史数据只用于计算因果指标的暖机值。
- 前瞻账本从 20,000 元全现金开始，与任何真实持仓无关。
- 冻结后不得依据压力测试或前瞻收益调整参数。任何新参数只能形成新的独立研究版本，不能回填 V1。

## 3. 历史压力测试

固定执行以下场景：基线逐日复现、额外延迟一个交易日、单边滑点 10bp、单边滑点 20bp、佣金与最低佣金同时为 2 倍、同时为 3 倍，以及按固定随机种子遗漏 10% 的历史趋势入场信号。遗漏只禁止被抽中的当日入场；以后再次满足规则时仍可入场。

基线专用执行器必须与父实现逐日权益、持仓和全部成交事件一致，否则所有压力结果标记 `NO_VIEW_BASELINE_REPLICATION_FAILED`。

统计安慰剂固定为 2,000 次循环位移（最小位移 60 个交易日），区块自助法固定为 2,000 次、20 日区块。它们只用于判断路径脆弱性，不构成显著性证明，也不替代真正前瞻样本。

## 4. 前瞻数据闸门

刷新数据只能写入 `data/raw/t_only_forward_v1/`，禁止覆盖父协议的冻结输入。下载后的历史重叠区间必须在 OHLC、成交量和成交额上逐值等于冻结数据；否则隔离候选数据并返回 `NO_VIEW_OVERLAP_MISMATCH`。

收益核算还要求现金分红事件覆盖日期不早于行情日期。分红覆盖不足、行情陈旧、字段异常、重复日期或冻结文件指纹变化时一律 `NO_VIEW`，不能把上一交易日状态冒充当日状态。

## 5. 影子账本与成熟门槛

影子账本只记录模型自身的现金、份额、信号、次日开盘模拟成交、佣金、滑点、拒绝原因和闭合周期。它不读取真实持仓，不输出订单，不连接券商。

前瞻结论至少需要：

1. 252 个新的交易日；
2. 3 个闭合周期；
3. 扣费收益高于现金和同平均仓位静态基准；
4. 双倍总成本下总收益为正；
5. 最大回撤不低于 -15%；
6. 最大单个盈利周期占全部正盈利不超过 50%；
7. 信号与下一交易日影子执行合规率为 100%。

成熟前统一输出 `COLLECTING`，不得使用“验证通过”“当前应买入”或任何真实仓位映射表述。
