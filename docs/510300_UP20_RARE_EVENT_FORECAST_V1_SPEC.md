# 510300 未来20日稀有上涨机会预测 V1 冻结规范

## 1. 唯一研究问题

`510300_ORACLE_INFORMATION_BUDGET_V1`已经证明，完美信息价值上界并不要求预测器完全正确：零误入时捕获14/23个大涨区间即可通过；但对大跌误入极为敏感，对抗情况下第2个大跌误入即失败。

本研究只检验一个现实候选：用信号日收盘前可得的四个低维技术机制模块，预quential地预测未来20日H00300全收益是否不低于+5%，并用大跌概率和压力模块否决高风险满仓。它不描述“当前三状态”，不搜索参数，也不做震荡T。

## 2. 数据时钟与可用边界

- 价格模块使用H00300截至T日收盘的历史全收益点位；
- H00300源表保留3457条原始记录，但所有特征、标签和模型评价严格重索引到510300的3456个可执行交易日；源表中唯一的ETF非交易日不得进入20日时钟；
- 标签为`H00300[T+20]/H00300[T]-1`，只有T+20收盘后才成熟；
- 每个T日模型只能使用成熟日期不晚于T日的历史标签；
- 2015—2026的官方PIT成分成员表只用于等权集合，不使用被上游明确阻断的历史权重；
- 成分价格面板从2019-12-23开始，故更早日期的广度模块固定为中性0并标记不可用；
- 特征预制件禁止含未来收益、标签、状态或策略结果。

## 3. 四个固定模块

### `SETUP_PRIOR`

252日高点回撤的绝对程度乘以5日低点后的修复程度，两项分别按20%回撤和5%修复截断到0—1。它表示“估值替代性的价格压缩背景已经出现，同时开始修复”，不单独触发交易。

### `BREADTH_IGNITION`

使用官方PIT成员集合和成分全收益价格，等权计算一日上涨占比与站上MA20占比相对5个交易日前的改善。两项都只保留正向变化，并以改善25个百分点为1，截断到0—1后各占50%。返回与MA20覆盖率均须不低于95%；当前日或5日前覆盖不足时为0，不以事后权重或当前成分回填。

### `PRICE_ACCEPTANCE`

20日方向效率与20日价格区间位置各50%。方向效率为20日净涨幅除以同期逐日简单收益绝对值之和，负值按0处理；区间位置使用含T日的最近20个交易日最高、最低点。两项均截断到0—1。它要求上涨具有方向性并在区间高位被接受，而不是只凭一天反弹。

### `STRESS_VETO`

取20日下行波动、5日跌幅以及可用时成分股单日跌幅不低于3%的比例三者最大值，分别按30%、8%和15%缩放并截断到0—1。风险分数高于0.80可独立否决满仓。

## 4. 固定模型

模型是三分类、`RANGE20`为参照类的多项Logistic：`UP20 / RANGE20 / DOWN20`。只有四个模块，不做交互、不做非线性扩展、不做动态选因子。

系数符号受经济机制约束：

| 模块 | UP20系数 | DOWN20系数 |
|---|---:|---:|
| `SETUP_PRIOR` | ≥0 | ≤0 |
| `BREADTH_IGNITION` | ≥0 | ≤0 |
| `PRICE_ACCEPTANCE` | ≥0 | ≤0 |
| `STRESS_VETO` | ≤0 | ≥0 |

目标函数固定为全部成熟样本的多分类负对数似然总和，加上`0.5 × 0.10 × 斜率平方和`；截距不惩罚，使用L-BFGS-B。每个评价交易日重新用当时已经成熟的全部历史标签拟合，至少需要252条成熟观察、10个UP20和10个DOWN20。若优化失败或样本不足，该日固定为现金。

日标签可以重叠以提高低维模型估计稳定性，但独立绩效评价只使用20日不重叠区间，并完整报告20种相位，不能把重叠日样本数当成独立事件数。

## 5. 固定决策与账户执行

只有同时满足以下条件才在阶段锚点产生100%目标仓位：

1. `pUP20 ≥ 0.40`；
2. `pDOWN20 ≤ 0.10`；
3. 使用Oracle冻结三类均值和25bp固定往返成本门槛计算的期望净效用不小于0；
4. `STRESS_VETO ≤ 0.80`；
5. 模型、特征与训练时钟全部有效。

否则目标仓位为0。T日收盘信号、T+1开盘执行；只允许510300和现金；初始资金20,000元、100份整手；基准/压力单边滑点为5/10bp，佣金3bp且最低5元，分红沿用正式账户引擎。

## 6. 评价与停止门

主相位从2015-01-05开始，每20个交易日决策一次；另完整报告offset 0—19。主结果必须同时通过：

- 基准与压力净夏普均不低于1.2；
- 2021年以来压力净夏普不低于1.2；
- 压力总收益为正；
- 捕获至少14个真实UP20区间；
- 大跌误入不超过1个，震荡误入不超过10个；
- 至少产生14个满仓区间；
- 20个相位的压力净夏普全部不低于1.2；
- 相对当时训练基准概率，Brier Skill与Log Loss Skill均为正。

任一门失败即冻结拒绝V1，不调整特征、惩罚、概率阈值、风险阈值、相位或持有期，也不从控制项中选择替代策略。

## 7. 结论边界

即便历史门全部通过，也只构成历史研究候选；独立前向证据仍为0，Paper、Shadow、持仓、订单、券商连接和实盘授权全部关闭。若失败，准确结论是该固定低自由度技术机制没有达到信息预算，不等于完美信息价值上界被推翻。
