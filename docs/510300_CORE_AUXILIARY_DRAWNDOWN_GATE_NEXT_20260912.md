# 下一项：核心与辅助的回撤上限分层

此文为第176轮事前方案，尚未登记或计算。保留第143轮核心和第165轮辅助的保存目标，研究市场六十日累计财富从该段最高点的回撤是否应只撤去辅助仓位。它不是账户净值止损，因此不需要依赖同一账户当日成交后的净值；核心仓位仍按原策略目标运行。

固定因子为每个收盘时的含分红累计财富、该日及此前五十九个交易日累计财富最高点、以及两者之比减一得到的六十日市场回撤。六十日窗口不足或有缺失时回撤未知。回撤严格大于负百分之五，辅助可以参与；回撤小于或等于负百分之五，撤去辅助，只保留核心。第176轮只登记这一套规则，不搜索百分之五之外的阈值、窗口、恢复门槛或权重。

核心与辅助目标及市场回撤均已知时，允许辅助的目标为两者相加且不超过百分之一百；撤去辅助时目标就是核心。任一输入未知，组合目标未知并保持实际份额。辅助正目标从零转正且市场回撤允许时，下一交易日开盘可以进入；回撤触发时下一开盘撤掉辅助，核心为正则继续按核心目标持有，核心为零则优先清仓。市场回撤恢复到严格高于负百分之五时，辅助原目标为正即可重新加入，无额外等待。辅助自身明确为零时无辅助目标，核心按原规则继续。

仍以收盘十五点零五分决定、下一交易日原始开盘执行。正目标使用本账户净资产、实际份额、百分之十调仓带和一百份整手；已知零优先退出，未知保持实际份额，终点开盘清算。基础／压力费用、分红、现金、涨跌停和次日卖出限制完全沿用既有完整账户口径。主历史及较早历史、两档费用均各自完整计算，不拼接净值。
