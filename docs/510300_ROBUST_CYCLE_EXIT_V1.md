# 第119轮：保留周期结构，用稳健误差学习退出

只登记一个联合周期截距胡伯回归。沿用第117轮八项市场路径状态、原完整周期权重、每个成熟周期单独截距和新周期平均截距，改用小误差按平方、大误差限制边际推动的学习目标。第117轮四个实际账户已与114相同；本轮用这两个保存结果以及原32、91和买入持有评价，不能只与118较弱对照比较。

第71轮是所有周期共享一个截距、无系数惩罚的绝对误差中位数目标；本轮是单独周期截距与惩罚系数共同拟合的胡伯目标，不扫描分位点。第118轮已结束，不再使用逐持仓年龄模型或倒推目标。新方法可能减少少数极端误差的影响，也可能错失重要大盈利，必须以完整账户取舍。

## 八项因子

1. 持仓时间：含买入日在内已持仓交易日数加一，再取自然对数。
2. 市场路径涨跌：当前每份收盘价值加本笔已登记并确认的每份分红，除以实际买入日原开盘价，再减一。这里的当前每份价值不含已付买入佣金或滑点。
3. 市场路径回撤：同一当前每份价值除以从买入至今的最高每份价值，再减一；初始最高值为买入原开盘价，每个持仓收盘更新。
4. 进入模式：原六十日日内相对隔夜强弱模式，单一类别为一。
5. 五日涨跌：最近五个交易日含分红日对数收益合计。
6. 二十日涨跌：最近二十个交易日含分红日对数收益合计。
7. 一百二十日均线偏离：当前含分红财富除以最近一百二十日平均财富，再减一。
8. 二十日波动：最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

含分红简单收益为收盘加当日每份分红，除以前收盘，再减一；对数收益为一加简单收益取自然对数；财富逐日连乘一加简单收益。本笔分红只认实际股权登记权益，除息应收和后续现金到账不重复。持仓路径按本账户实际份额、日期和原买入开盘恢复，必要中间收盘未知时，路径峰值保持未知至新持仓。

实际账户亏损及回撤保护仍使用包含真实买入费用的原账户价值。第117轮已经验证的市场路径和1461个原状态直接复用，不改基准价格、不混合成本、不加成交量或进入上下文。

## 成熟训练与固定初始化

沿用原141个月度训练时点：原初始2014年12月31日及此后每月首个交易日收盘。只有完整自然结束的参考周期才可纳入，取最近二十周期，至少十周期、一百状态；原114个成熟月份、27个不足月份保留。每个周期基础总权重一，各状态等分，不让长周期得到更大总量。

目标沿用原自然退出相对下一开盘提前退出的净卖出价值差，计基础佣金、滑点及新增登记分红权益，再除以参考份额乘下一开盘原价。整个周期完成后全部状态才成熟，终点强制退出及未完成周期不可用。第118轮已核这些原状态当前没有方向受阻提前退出，因此本轮保留原标签；该事实不允许今后有受阻资料时假定成交。

每个成熟月份直接使用第117轮同一月份、同一完整周期成员的保存模型作起点，不重新拟合平方误差模型。八项输入的周期等权均值、总体标准差和负五至五截断范围全部沿用。标准差不超过万亿分之一时原尺度按一；不在本轮重新选择标准化。

起点对每个训练状态的预测，使用它所属成熟周期的保存截距，加标准化状态乘保存八系数之和。残差为真实原目标减这个预测。先按原基础权重求残差加权中位数，再求偏离这个中位数的绝对值的加权中位数，除以0.6744897501960817，得到当月固定稳健尺度。加权中位数按数值递增排列，取累计权重首次达到总权重一半的数值。

尺度只由同月已经成熟的原模型和训练残差决定，在新拟合中不再更新；胡伯边界等于1.345乘该尺度。原114个月份尺度已检查为正，范围约0.004465至0.008815；仅统计旧残差，没有新账户。采用常数可见[胡伯函数官方定义](https://www.statsmodels.org/stable/generated/statsmodels.robust.norms.HuberT.html)及[中位绝对偏差尺度官方说明](https://www.statsmodels.org/stable/generated/statsmodels.robust.scale.mad.html)。本项目增加周期基础权重并固定原残差尺度，属于本次研究设计，官方定义不证明交易效果。

## 联合拟合怎样改变

对预测与真实目标之差，若绝对值不超过当月固定边界，误差损失为误差平方的一半；若超过边界，损失为边界乘误差绝对值，再减边界平方的一半。这样大误差仍有影响，其边际推动不再随误差无限增大。

把每条误差损失乘原基础权重后合计，再加八系数平方和的一半。系数惩罚固定为一，所有成熟周期截距不受惩罚。八系数和这些周期截距一起优化，不先把目标去均值后误当成联合稳健拟合。基础周期权重仍各为一，极端残差的实际边际影响会减小，不能说最终每个周期的有效影响也相同。

使用有限内存拟牛顿法和解析梯度，从同月117系数及周期截距起步，最多一千次迭代，每轮线搜索最多四十步；目标变化容差十的负十五次方，梯度容差十的负九次方。仅在求解器报告成功、系数全为有限数、全部梯度绝对值不大于十的负七次方且目标不高于起点时保留模型。求解条件可见[SciPy官方优化说明](https://docs.scipy.org/doc/scipy/reference/optimize.minimize-lbfgsb.html)。

原残差尺度不大于万亿分之一、输入缺失或求解失败的月份保留没有模型，不换损失常数、求解器、初值或窗口；必要训练输入缺失不删行补拟合。新实际周期的截距固定为该月全部成熟周期新截距的等权平均，当前周期自己的未来截距不可读。预测为这个平均截距加当前标准化八状态乘新系数的合计。

## 入场、退出、再次进入

每天计算日内对数涨跌减隔夜对数涨跌。日内为收盘加当日分红除以开盘加分红取对数；隔夜为开盘加分红除以前收盘取对数。六十日差值合计除以其样本标准差，再除以六十的平方根，得到进入强弱分数。

强弱分数连续两个收盘严格大于一，原必要资料完整、账户空仓、有再次进入资格且距上次实际退出至少两个交易日，下一开盘用自身可负担现金和真实费用买入最多整百份。

每个持仓收盘检查以下条件，任一成立则下一开盘请求全部卖出：联合胡伯模型连续两个收盘预测继续收益严格为负；原强弱分数连续两个收盘低于零；含已确认分红的实际持仓价值较真实买入投入亏损达到百分之六；从原账户周期最高价值回撤达到百分之八；含买入日在内持仓满六十个交易日。

没有有效模型、必要输入未知或预测不为负，学习连续计数归零，原已知价格风险保护继续；新持仓重新计数。退出请求一经形成就保持至实际卖完，即使以后模型转正也不取消。退出之后，空仓时先看到旧进入条件消失，再等其重现并满足两日冷却，才可重新进入。没有新增止盈、加仓、部分卖出或进入门槛。
