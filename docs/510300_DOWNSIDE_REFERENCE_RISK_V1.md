# 第132轮：下行风险与全部平方幅度的固定参考组合

只登记两个设置，主要候选是零目标下行风险，另一项是全部平方幅度构造对照。都以第128轮保存进入和退出参考决定机会，自己实际买卖。方案是在看到131分阶段差异后提出，属于事后研究选择。旧下行风险预算、估值防守风险扣减、65波动选专家、109与131的结果和判断保持原样。

## 两层状态及费用对应

第一层是已经完成的第128轮研究参考账本，按原规则使用自己的价格、股数、费用、分红和最高持仓价值产生每日持有意向。这里只复用保存收盘意向，不重新训练或运行参考。第二层是新资金账户，跟随意向并缩减规模，独立计算自己的现金、股数、费用、分红权益和净值。

基础费用资金账户对应基础费用参考，压力费用对应压力费用参考；主历史和较早历史也分别匹配。不同费用可能改变参考自身的浮盈亏及退出时间，不能混用。参考预测的持仓输入不来自外层资金账户，外层的实际利润也不能由参考利润简单加权代替。

## 参考使用的全部因子

进入指标是最近六十日日内含分红对数涨跌减隔夜含分红对数涨跌之差的合计，再除以这些日差值的样本标准差与六十的平方根。它衡量日内相对隔夜强弱，不是未来收益。

参考退出模型的八项因子如下，涉及持仓的数值均属于参考自己的账本：

1. 含买入日在内已经观察的持仓收盘交易日数，加一后取自然对数。
2. 实际份额市值加本周期已确认分红，除以参考真实买入金额与佣金之和，再减一，表示周期浮盈亏。
3. 同一含分红持仓价值相对周期最高价值的回撤，初始最高值至少等于买入总成本。
4. 原日内隔夜强弱进入类别，固定为一。
5. 最近五日含分红对数涨跌。
6. 最近二十日含分红对数涨跌。
7. 含分红财富相对包括当天的一百二十日平均值的偏离。
8. 最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

## 参考模型与进出场如何确定

复用原114的141条月度模型记录，其中114个成熟模型、27个支持不足；最早成熟日2017年3月1日。模型原本只纳入当时已自然完成的最近二十个参考周期，至少十周期、一百个状态。每周期总权重为一，各状态等分。目标是继续至原自然退出相对下一开盘提前退出多出的净收入，除以下一开盘参考市值，含既有费用及新增分红权益；原标签近似不等于独立成交验证。

八项因子按周期等权均值和标准差标准化，限制在负五至正五，近零标准差以一代替。各周期内减去自身平均因子和平均目标，以周期内变化求线性系数，系数平方惩罚为一、不加统一截距。各成熟周期截距不受惩罚，新参考持仓使用这些成熟截距的等权平均；不能用尚未完成周期的未来结果估计截距。

每笔参考实际买入日的第一个收盘选择当时最近的成熟模型版本，固定系数、均值、标准差及截距到实际卖完，当前八因子每天更新。第一次没有成熟模型，该笔全程没有学习预测；当前输入缺失也不补预测，连续负预测计数清零。新一笔才重新选择版本。以上均为已保存参考的原规则，本轮没有新模型拟合。

参考进入：六十日强弱连续两个收盘严格大于一、必要资料完整、空仓、有再次进入资格，且距上次全部卖出至少两个交易日，下一开盘以参考可用资金单次买入整百份。参考不追加或部分卖出。

参考退出：固定版本连续两个持仓收盘预测继续收益为负；六十日强弱连续两收盘小于零；含分红周期亏损达到百分之六；距周期最高含分红价值回撤达到百分之八；或含买入日在内已经持有六十个收盘交易日。任一成立，下一开盘全卖并锁定到实际卖完。无模型时可知价格与期限保护仍执行。卖完以后须先看到原进入条件消失，再等其重现并满足两日等待，才能再次进入。

## 新增风险因子的完整中文计算

先用当天收盘价加当天每份除息分红，再除以前一天收盘价，减一，得到当天含分红简单收益。使用截至当日收盘连续二十个交易日；任何一天所需资料缺失，这个窗口的风险未知，不能删除缺失日后计算。没有使用未来价格。

主要候选：每天下跌收益平方，上涨或零收益贡献为零，把二十天贡献相加后除以二十，再乘二和二百四十二，最后开平方。分母包括上涨及零收益日，不只计算下跌日数。这是以零收益为目标的下行幅度；没有减去窗口平均收益。

构造对照：把二十天全部收益逐一平方后平均，乘二百四十二，再开平方。也不减窗口均值。它用于识别只考虑下跌的方向性作用，和由131样本标准差改为零中心平方幅度的影响。

主要候选中的乘二，在零中心对称收益分布下使理论风险尺度与全部平方幅度相匹配。它是事先固定的尺度约定；有限历史样本不保证相等，实际收益也不保证对称。两个设置都登记，不能在收益出来后改称表现较好者为原主要候选。

[PerformanceAnalytics原始下行偏差实现](https://github.com/braverock/PerformanceAnalytics/blob/master/R/DownsideDeviation.R)支持完整样本作为分母、相对指定目标计算负偏差的定义。这里只核对定义，未将其视作该组合有效的证据；不采用删除未知日的处理。

## 两种风险如何转为目标仓位

分别用百分之十除以各自当日已知正风险幅度，结果最多为一。零风险或窗口未知时沿用最近一次明确乘数，最初乘数为一。这沿用131的零值与缺失风险处理，不把沿用值解释为新的风险预测。

同历史同费用参考意向为一时，目标等于这个乘数；参考明确零意向时，目标为零；参考意向未知时，目标仍未知，不产生零仓位判断。只有本段准备收盘至末日前一收盘存在参考意向，其余准备区间及末日未知收盘保留空值。两个设置都使用相同匹配费用的参考，不重训或新运行参考。

## 外层进入、增减仓、退出和再次进入

空仓且目标为正，下一开盘请求按外层自身净值配置整百份，实际成交还受现金与费用约束。已持仓时，当前股票比例与正目标之差达到十个百分点，才按新目标增减；不足十个百分点保持已有份额。目标为零直接请求全部卖出，不受带宽限制。股息到账后也只有满足相同条件才会改变份额。

每个收盘按最新明确目标和实际份额重算下一开盘请求，采用第109轮原事件账户规则。外层受阻退出不另加永久锁定；如果后续参考意向或目标改变，按新的明确目标处理。参考内部的原退出锁定仍然保留，两层不能混淆。外层目标缺失不发起新调整，保持实际股数。

实际卖完后，未来某收盘出现正目标即可按同一规则再次进入；参考自身仍执行原再次进入门槛。研究末日统一开盘优先清仓，不依赖末日尚未知道的收盘信号。

## 账户、比较及停止条件

两个固定设置，主历史与较早历史各两档费用，共八条新资金账户，零新参考、零新模型。复用128固定入场模型、131普通波动组合、91连续两策略预算和买入持有，共十六条保存对照。主评价十二条绩效记录，较早历史十二条，不把保存对照算作新策略。

主历史2020年1月2日至2026年8月14日开盘1604日；较早历史2015年1月5日至2019年12月31日开盘1219日。每账户二十万元，242日年化，现金和无风险收益均为零，空仓日保留。

基础费用佣金万分之二、每次最低5元、滑点万分之五；压力费用佣金万分之四、每次最低5元、滑点千分之一。仅510300与现金，100份整手，0.001元价位，次日可卖、方向涨跌停、分红登记权益、除息应收与实际到账保持。终点统一开盘退出。规模、盈亏、费用来自自己的完整账户，不能用加权参考净收益替代。

六项必要合成测试检查完整分母与对称尺度、分红、缺失及零风险、费用配对与未来不改过去、异常输入、两个实际账户的增减仓与分红终点；测试通过后冻结，再一次计算新因子及八条账户。只核对影响结论的目标、成交资金、日历与绩效，不重复运行旧模型和旧账户。

如未带来有效改善，结束这两个固定设置，不改变二十日、乘二、百分之十、交易带宽、费用或参考以救回。主目标继续为成本后夏普至少1.2、稳定超额与独立证据。当前历史已经用于多轮研究，不是独立验证。EPS、公募、估值和慢来源暂停，无GPT数值包、ZIP或交易权限。
