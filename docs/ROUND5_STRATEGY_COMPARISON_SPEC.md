# 第五轮策略比较规范

## 1. 当前目标

只交易`510300.SH`现货多头与现金，不使用杠杆、卖空、期货或期权。主要基准为`H00300`沪深300全收益指数，实际可交易基准为510300买入持有总收益。

验收采用两级门槛：

- 最低可行线：策略净CAGR相对H00300年化超额不低于10%，且滚动242日超额中位数不低于10%；
- 挑战线：上述两项均不低于15%。

所有策略收益必须计入现金分红，并扣除佣金、最低佣金、整手约束和滑点。目标是研究门槛，不是收益承诺。

## 2. 三个同口径策略

### 波段持仓

指数聚合估值决定20%至100%的战略仓位，60/200日趋势最多确认正负20个百分点，RV5/RV20、RV20/RV60和20日下行波动最多再扣20个百分点。普通信号每5个交易日复核，风险事件允许立即降仓，恢复仓位每次最多10个百分点。

### 固定底仓频繁做T

隔夜维持50%固定底仓与50%现金。前一交易日未复权收盘价作为当日固定锚；偏离锚达到双倍往返成本并出现分钟级反转时，在下一分钟开盘成交。每天最多一个回合，日终恢复原份额。

### 估值库存与做T组合

波段模型决定隔夜核心库存，在可用旧仓和现金范围内执行与固定底仓方案完全相同的日内T规则。核心调仓日不做T，日内交易不得改变隔夜目标库存。

## 3. T+1与资金安全

- 买低路径为“买入新份额，随后卖出等量旧份额”；
- 卖高路径为“卖出旧份额，随后买回等量份额”；
- 当日新买份额绝不计入可卖库存；
- 卖旧前按11%上涨缓冲预留回补资金，容量不足时减少份额或跳过；
- 普通单腿以100份为一手，做T每回合至少1000份、最多1500份。

## 4. 数据可得性

日线信号在`t`日收盘形成，最早于`t+1`开盘执行。分钟信号只使用当前及更早完成记录，实际模拟成交使用下一条一分钟记录开盘。折溢价层因缺少交易时刻点时IOPV而停用，不允许用昨日NAV折溢价冒充今日可执行价格优势。

## 5. 治理

第五轮参数采用一次冻结，不做历史网格搜索。全部五年历史均已被查看，没有严格未见样本。任何通过只能称为回顾性通过；任何失败不得在相同历史上通过微调相邻阈值重新包装。
