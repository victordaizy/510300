# 510300 压力传导危险率 V2：M/F/T 点时特征执行 V1

## 本阶段唯一目标

在四态成分收益与逐日覆盖账本之后，构建无行业依赖的 `M`、`F`、`T` 点时特征、来源可用性账本、新成分历史账本和完整 `NO_VIEW` 链。本阶段不读取实际 `BAD10` 标签、未来收益、AUC、Log Loss、Brier、警报结果或任何组合指标。

## 固定信息时钟

- 决策时点是每个沪深300交易日 15:00（Asia/Shanghai）。
- 沪深300官方市盈率、中国10年期国债收益率和 DR007 的观察日值，从观察日后的下一点时市场交易日 09:30 起可用；不得在同一观察日使用。
- 央行7天逆回购操作利率只按归档公告的实际 `published_at` 生效；公告晚于当日 15:00 时，当日不得使用。
- H00300 当日总收益指数收盘值只在当日收盘决策时钟使用，不得读取未来交易日收盘值。
- 每条宏观发布记录必须保存 `observation_date`、`available_at`、来源身份和冻结源文件哈希。缺失值不插值、不补零。

三个日频历史序列没有逐日独立 vintage 文件，因此本执行只使用已冻结哈希的单一版本，并施加下一交易日开盘的保守延迟；冻结之后不得用新下载值回填本版本。央行公告保留逐公告原文路径、公告时间和原文哈希。

## 新成分历史窗口

当日成员身份只来自逐日点时成员表。某证券加入指数之前已经公开的未复权价格历史可以用于其当日20日或60日价格窗口，因为这不等于把今天的成员身份回填到过去；未来价格和合成历史均禁止。

共同运动更严格：某证券只有在过去20个市场日内真实属于点时成员、并同时具有自身收益和剔除自身后的点时成员组合收益时，该日才计入相关性窗口。至少15个有效成员日才可评分；非成员日不计入。离开后重新加入也只按滚动20日内真实成员日计数。

## `NO_VIEW` 传播

以下任一条件失败即保持 `NO_VIEW`：

- 四态成分收益当日可用成员比例低于98%；
- 20日收益、左尾扩散或共同运动覆盖门失败；
- `M` 的估值缓冲或资金利差任一固定通道缺失；
- `T4` 资金冲击缺失；
- 因果分位数尚无严格更早的有效历史。

`MODEL_STATE=VIEW_ALLOWED` 必须同时具备 `M`、`F`、`T`。`NO_VIEW` 只是研究视图状态，不代表现金仓位、订单或交易指令。

## 固定经济方向

- `M1`：盈利收益率—10年国债收益率缓冲越低，风险越高。
- `M2`：DR007—7天逆回购政策利率的5日均值越高，风险越高。
- `F1`：20日正收益成员比例越低，风险越高。
- `F2`：H00300 与点时成员等权20日收益之差越高，风险越高。
- `F3`：成员与剔除自身点时组合的20日共同运动越高，风险越高。
- `T1`、`T2`、`T3`、`T4` 均按原始量越高风险越高处理。

所有分位数均为当前值相对严格更早有效观察的经验中秩；当前值不进入自己的参考集。

## G0 边界

构建完成只产生 `G0=PENDING_CLEAN_REPLAY_AND_TARGETED_TESTS`。只有全新进程按冻结输入重建、语义逐表一致、全部定向测试通过、行业字段不可进入核心且父级 manifest 均通过身份验证后，才可另行写入 G0 裁决。无论 G0 是否通过，G1—G7 在本执行中均不运行。
