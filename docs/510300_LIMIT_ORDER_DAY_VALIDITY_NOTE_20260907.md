# 第27轮限价单期限补充说明

上交所交易规则第3.3.18条规定“申报当日有效”。[交易规则正文](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)同时说明，未一次全部成交的余额继续参加当日竞价。

因此第27轮所写“有效3个交易日”，含义是研究策略的买入意向最多持续3日，研究系统每天按原限价与数量重新提交当日有效的指令，而不是一笔交易所订单天然跨日保留。已运行程序在每个执行日检查原限价、到期日、除息及当日涨跌停范围，经济计算与逐日重新申报的意图一致，本补充不改参数、成交价或任何收益。

“只允许开盘满足限价”是一种明确的开盘执行模型，未成交则取消当日后续买入机会，在有效期内下一交易日再尝试。它没有模拟券商撤改单延时或真实排队；盘中成交版本同样没有实际排队与逐笔成交证据。两个版本均为研究模拟，不能据此宣称历史真实订单一定成交。
