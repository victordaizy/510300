# 第175轮：方向确认决定辅助进入，辅助原规则决定退出

本轮仅研究510300和人民币现金。第143轮的保存目标是核心仓位，第165轮的保存目标是辅助仓位；第171轮相邻收益相关方向与第172轮上涨日优势方向共同提供“任一允许”的辅助进入资格。两种预先固定方案分别为：辅助目标从零转正的段首只判断一次；以及在该正目标段内持续等待允许方向。取得资格后，方向转弱不再撤销资格，直到辅助原目标明确为零；核心仍按第143轮原有进出场规则运行。

相邻相关方向的因子为最近六十日含分红对数收益前后五十九个相邻配对的相关系数和六十日累计对数收益；二者连续两日为正才允许，相关或累计收益连续两日不为正则不允许，退出分别计数。上涨日优势的因子为六十日上涨日减下跌日再除以六十，以及六十日累计对数收益；二者连续两日为正才允许，任一连续两日不为正则不允许。平盘日保留在分母；缺失窗口为未知。两种方向都是已经保存的历史状态，本轮只读取允许状态，不重新训练，不叠加两者独立策略的波动率目标。

核心和辅助目标已知、辅助资格已知时，取得资格的组合目标为两者之和且最多百分之一百；未取得资格时只保留核心。辅助为已知零时，直接按核心目标处理；核心或辅助未知时组合目标未知并保持实际份额。段首方案在辅助正目标段首方向未知时，该段保持未知；段内等待方案在方向未知日保持未知、方向恢复后继续等待。辅助已知零结束该段。每个收盘十五点零五分决定，下一交易日原始开盘执行；已知零优先退出、未知不卖出、终点开盘清算。

正目标采用本账户净资产、已有份额和百分之十调仓带执行，整手一百份。空仓正目标直接尝试买入；已有仓位差距不足十个百分点保持，达到或超过十个百分点才向目标中心调整。带外极小正目标整手取整为零可以清仓，带内保持。基础费用为佣金万分之二、最低五元、单边滑点万分之五；压力费用为佣金万分之四、最低五元、单边滑点千分之一。无融资、无做空，现金收益为零；分红登记、除息确认和到账分别记账，应收分红不能用于提前买入。

主历史为2020年1月2日至2026年8月14日开盘，较早历史为2015年1月5日至2019年12月31日开盘。两种方案在两段历史、两档费用下各自完整记账，不平均或拼接净值。最终检查四场景净夏普至少1.2、完整账户超额和稳定性；历史点值不构成独立验证。
