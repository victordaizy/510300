# 510300 第30轮：已有持仓的盘中保护退出

本轮只调整退出时点，检验收盘止损延后到次日开盘是否造成可减少的损失。沿用三种已经研究过的入场条件、止损幅度、最长持有期和退出后等待期；不新增数据、不训练模型、不寻找新的价格阈值。共三个新策略设置，分别在两种盘中成交情景、两档费用下计算。

## 三种策略的全部因子和进出场

所有涨跌和均线因子使用已有分红总回报序列。因子只在当日收盘后形成，入场按下一交易日开盘请求买入可负担的整手份额；一次进入，不在持有期追加份额。缺少必要历史时不发起新买入。

|策略|进入条件|收盘后的常规退出|固定保护和再次进入|
|---|---|---|---|
|趋势突破与震荡反弹切换|总回报高于一百二十日均线，且二十日方向效率大于0.3时，使用趋势模式：总回报突破此前二十日最高收盘水平时进入。其余状态使用反弹模式：总回报相对二十日均值的标准化偏离小于负1.5，且当日上涨时进入。|趋势模式在上述强趋势条件消失，或跌破此前十日最低总回报收盘水平时退出。反弹模式在转为强趋势、标准化偏离恢复至零及以上，或持有达到十个交易日时退出。|趋势模式固定亏损8%或从持仓收盘最高价值回撤8%时触发保护；反弹模式固定亏损5%时触发。实际卖出后，至少经过两个交易日才允许收盘发出下一次买入请求。|
|偏离均值后首日回升|标准化偏离小于负1.5，且总回报当日上涨时进入。|标准化偏离恢复至零及以上，或持有达到十个交易日时退出。|固定亏损5%触发保护；实际卖出后至少经过一个交易日再允许发出买入请求。|
|六十日日内强于隔夜|每日差异为日内对数涨跌减去隔夜对数涨跌。六十日差异之和，除以六十日每日差异的样本标准差和六十的平方根；这一标准化差异连续两日大于1时进入。|标准化差异连续两日小于零，或持有达到六十个交易日时退出。|固定亏损6%或从持仓收盘最高价值回撤8%触发保护；实际卖出后至少经过两个交易日再允许发出买入请求。|

二十日方向效率等于二十日总回报水平的绝对净变化，除以这段期间每日绝对变化之和。标准化偏离等于当前总回报水平与二十日均值的差，除以二十日总回报水平的样本标准差。日内对数涨跌来自收盘价相对于开盘价；隔夜部分沿用已有除息一致的总回报分解。所有滚动计算含当日，但不含未来记录。

## 本轮新增的盘中退出

每日开盘前，按已知持仓成本、此前最高收盘持仓价值、此前已确认分红，以及当天已确定的除息分红，换算固定亏损和追踪回撤对应的未复权价格。两个保护条件都有时，使用较高的触发价；向下取到0.001元最小价格单位。保护按含分红持仓价值计算，入场成本包含买入佣金；卖出费用在成交时另扣。该保护价不使用当天最高价或收盘价上调。

已产生常规退出请求的，仍优先在下一开盘卖出。没有常规退出请求时，若开盘已低于保护价，按实际开盘参考价请求卖出，不假设能卖在更高的保护价。开盘未触发、但当日最低价触及保护价时，才进入盘中条件成交模拟。盘中只卖以前交易日买入的份额，当日新买入的份额不能当天保护卖出；当日收盘仍会检查退出，并可发出下一开盘卖出请求。

任何保护触发后，若卖出因价格限制等原因未成交，保留退出意图，后续开盘持续请求卖出，不因价格暂时恢复而取消。全部卖出后按原等待期重新判断入场。最高价值只在仍有持仓的收盘更新。研究终点统一在开盘尝试退出，终点当天不再使用盘中数据。

## 两种成交情景

1. **保护价条件成交**：开盘正常而盘中触发时，以事前保护价作为卖出参考价，再扣原有滑点、价格单位损失和佣金。
2. **当日低价不利成交**：同样触发条件，以当日最低价作为不利的卖出参考价，再扣相同费用。最低价只用于成交压力假设，不参与决定当天是否进入、保护价或下单方向；这不是可实施的择时信号，也不构成所有未来账户的严格收益下界。

日线数据不能证明真实的盘中连续报价、跳价、排队和成交。本轮两种情景都是研究假设，不能据此宣称真实执行已经验证。即使历史夏普达到1.2，也须再检查盘中证据，不能把条件成交当作券商已支持的功能。基础规则继续遵循买入交收前不得卖出的约束，参见[上交所交易规则（2026年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。本轮没有券商连接和交易操作。

## 固定评价口径与退出标准

预定主方案为“趋势突破与震荡反弹切换＋保护价条件成交”。其余两个入场信号和低价成交情景同时公布，不事后更换主方案。

主评价为2020年1月2日至2026年8月14日开盘，共1604个账户日。较早诊断为2015年1月5日至2019年12月31日开盘，共1219个账户日；两段均独立从20万元现金开始，不能拼成连续实际账户。较早历史已被其他研究使用，也不属于独立验证。

保留510300与现金、每年242日、现金和无风险收益按零、100份整手、0.001元价格单位、方向性涨跌停和分红权益及到账记账。基础费用为单边佣金万分之二、最低5元、滑点万分之五；压力费用为单边佣金万分之四、最低5元、滑点千分之一。对照为原样收盘判断次日退出的三种策略及买入持有，不改变费用或评价起点。

先比较三个入场信号各自的新旧完整扣费账户，再看较早历史和费用压力。若盘中保护没有共同改善或明显依赖成交假设，停止本轮保护参数附近的继续调整，保留失败记录。目标是完整账户夏普至少1.2及稳定超额；历史筛选与独立验证分开。
