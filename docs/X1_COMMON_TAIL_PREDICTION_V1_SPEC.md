# 510300 X1 共同尾部未来风险预测 V1

状态：`DISCOVERY_ONLY`  
历史证据：`HISTORICALLY_CONTAMINATED`  
唯一候选：`X1`  
仓位、订单、券商：`DISABLED`

## 1. 研究问题

本协议不修补已经历史拒绝的慢估值 S1，也不恢复缺少历史盘口的期权分支和缺少真实 vintage 的盈利预测分支。唯一问题是：截至 t 日收盘可见的沪深300内部共同左尾，能否预测从 t+1 开盘起未来20个交易日510300显著跑输现金的少数时点。

X1 只承担“什么时候不要假装能预测”的风险识别，不预测板块收益点值，不生成仓位。

## 2. 点时信号

对 t 日指数成员 i，先计算其连续市场交易日上的5日总收益。完整个股价格历史与点时指数成员身份分开：价格缓存允许提供证券入选指数前的历史价格，但每天的信号分子和分母只能包含 t 日点时成员表中的300只证券。个股尾部阈值只使用该证券当前日前504个有效5日收益的5%分位；当前收益不得进入自身阈值。

`Tail(i,t) = 1[Return5(i,t) <= PriorQuantile5%(i,t)]`

使用 t 日之前最近一次官方指数权重快照。只有具备当前5日收益、事前尾部阈值和快照权重的证券进入可计算分母：

`X1Raw(t) = Σ Weight(i,t) × Tail(i,t) / Σ EligibleWeight(i,t)`

可计算权重低于90%时输出 `NO_VIEW`，不以等权或未来权重补齐。X1Raw 再相对其此前至少252个有效信号日做扩展经验分位，当前值不进入历史分布。风险分位不低于90%为固定最高风险组。

申万一级行业共同尾部扩散只作注册的次统计量，不参与主模型或候选选择。

## 3. 未来目标

主目标从 t+1 开盘至第20个交易日收盘，使用510300现金分红总收益减1.5%年化现金收益：

- `BAD20 = 1[X20 <= -5%]`；
- `TAIL20 = 1[未来20日相对现金路径最低值 <= -8%]`。

固定延迟压力测试从 t+2 开盘重新计算同一20日目标。延迟保留率按 `(DelayLift-1)/(PrimaryLift-1)` 计算。60日 `BAD60 <= -8%`、`TAIL60 <= -12%` 只作稳健性报告。

## 4. 走步概率与R6信息集基准

概率输出最少需要252个在信号日前已经成熟的BAD20标签。

- 无条件基准：Beta(1,1)平滑的扩展坏状态率；
- X1：固定非递减 Isotonic，只输入点时X1风险分位；
- R6信息集基准：固定L2 Logistic，`C=1`，输入盈利收益率、账面收益率、20/120日趋势和20/60日实现波动；
- R6+X1：相同Logistic与固定参数，只增加X1风险分位。

插补中位数与标准化参数全部只从当前信号日前的成熟训练窗估计。禁止超参数搜索、特征删除、交互项和树模型。

## 5. 冻结门槛

X1必须同时满足：BAD20 Lift至少2；20日移动块Bootstrap的Lift 95%下界大于1；走步Brier Skill大于0；Log Loss优于无条件概率；概率总偏差通过Poisson-binomial 95%兼容区间；一日延迟额外Lift至少保留70%；前后半段Lift均大于1。

R6+X1还必须相对R6基准同时改善Brier、Log Loss、预测概率最高十分位BAD20发生率和固定最高十分位的一单位避险贡献。最高十分位仅用于研究比较，不映射仓位。

任何一项失败，X1冻结为 `HISTORICAL_REJECTED_FROZEN`。不得修改5日、504日、5%尾部、90%风险组、20日目标或概率模型补救。

## 6. 边界

只有X1获得收益检验许可。O1—O4与E1保持阻断，C1/C2和P1保持禁用。即使历史全部通过，也只能得到 `HISTORICAL_PASS_AWAITING_TRUE_FORWARD`，不能生成仓位、订单或券商动作。
