# 第192轮事前方案：市场环境调节持仓退出

本方案尚未冻结、拟合或计算账户。只使用现有免费历史数据，检验一个固定方法、四条完整模拟账户；不补每股盈利预测等外部来源，不制作审阅数值包。第191轮和以前失败保留。先检查本轮是否已有执行记录，接续未完成步骤。

## 为什么换这个方法

第189轮周度清仓、第190轮日历补仓以及第191轮方向确认后的日历补仓均未通过完整目标。这条日历补充路线暂停，不再调整窗口或日历天数。原学习退出的八项因素主要以相加方式形成预测，意味着同样的浮盈或回撤，在不同趋势与波动环境中的影响相同。本轮只检验这一限制是否值得放宽。

前三项持仓状态与四项市场状态形成十二个乘积项。这与原第102轮浮盈与回撤相乘不同：本轮每项都跨越持仓状态和市场状态，不包含持仓状态之间的乘积。原第115轮用买入前市场状态预测周期截距、原第119轮稳健损失、原第157轮单成分等已有结果不重跑。没有查到同一十二项结构不等于证明其有效。

## 八项原始因素和十二项联合作用

1. 持仓时间：含实际买入日在内已经观察到的收盘交易日数，加一后取自然对数。
2. 浮盈浮亏：本笔实际份额按当前收盘计算的市值，加本周期已确认分红，除以买入成交金额和佣金之和，再减一。
3. 持仓回撤：同一含分红持仓价值除以本周期截至当前的最高价值，再减一；初始最高价值至少等于投入总成本。
4. 入场模式：原日内隔夜强弱入场类别，固定为一。仍保留原项，不制造不存在的类别差异。
5. 五日涨跌：最近五个交易日含分红对数涨跌之和。
6. 二十日涨跌：最近二十个交易日含分红对数涨跌之和。
7. 长期趋势偏离：含分红财富除以包括今天在内的一百二十日平均财富，再减一。
8. 二十日波动：最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

新增联合作用完整列出如下，各项都使用下文规定的标准化数值相乘：

|持仓状态|分别与其相乘的市场状态|
|---|---|
|持仓时间|五日涨跌、二十日涨跌、长期趋势偏离、二十日波动|
|浮盈浮亏|五日涨跌、二十日涨跌、长期趋势偏离、二十日波动|
|持仓回撤|五日涨跌、二十日涨跌、长期趋势偏离、二十日波动|

三行各四项，共十二项，加原八项，共二十项预测输入。没有入场模式的乘积、同组状态的乘积、平方项或新数据因子，不事后挑选其中一部分。

## 训练和预测

参考样本为第114轮保存的原八项完整参考状态，原始来源为第31轮已经自然退出的六十日日内强弱参考周期。保留原141个月度训练时点，最近二十个已结束周期，至少十个周期和一百条状态；原114个成熟时点与27个支持不足时点不变。只有自然退出日期不晚于拟合收盘的周期可训练，不删除不利周期或状态行。

目标是继续持有至原自然退出，比下一开盘提前卖出多得到的净卖出收入及新增分红登记权益，再除以下一开盘参考市值。沿用原基础费用标签及其假设成交近似，不称为真实成交或独立验证。每个周期总权重为一，各状态等分。

先按训练样本的周期等权均值和总体标准差标准化原八项，标准差不大于十的负十二次方时以一代替分母，再将数值限制在负五至正五。取上述十二个乘积；再分别按同一训练权重计算各乘积的均值与标准差，采用同样的近零分母处理与负五至正五限制。这使原项和乘积项在可比尺度上接受正则约束，处理参数全部在本轮首次运行前固定。

对二十项输入及目标逐周期减去各自周期均值，使用无统一截距的岭回归，二十项系数平方惩罚强度固定为一，沿用奇异值分解求解。周期内去均值后不再次截断。每个成熟周期的截距为其目标均值减去其二十项输入均值乘系数之和；预测新周期时使用这些成熟周期截距的等权平均。

保存训练成员、两级标准化参数、二十个系数及周期截距，并输出中文说明。模型固定于每笔实际买入日的首次收盘，使用该时点之前已经完成的最近月度模型；本笔卖完前不换版本，当前持仓及市场状态每天更新。首次无成熟模型时该笔全程无学习预测；当前必要输入缺失时预测保持未知，负预测计数清零。

为了减少重复计算，按训练成员、原点、退出日期、八项数值、标签、权重及固定设置识别完全相同的输入。只允许复用此前已经求解的相同输入，包括此前求解失败状态。既有同源研究表明114个成熟月份对应25组不同输入，预期实际只需25次拟合，另89个月复用；运行前先核实输入身份数量，禁止从未来月份借模型。拟合缓存不是25种候选策略。求解失败保持无模型，不改求解器或重新调参。

## 进入和退出

每日计算含分红日内对数涨跌减隔夜对数涨跌，最近六十日差值求和，除以差值的样本标准差与六十的平方根。日内涨跌用收盘加每份当日分红，除以开盘加同一分红，再取自然对数；隔夜涨跌用开盘加分红除以前一收盘，再取自然对数。

该分数连续两个收盘严格大于一，原必要数据完整，账户空仓且有再次进入资格，距离上次实际全部卖出满足两个交易日等待时，下一开盘申请买入按前一收盘现金及费用估计可负担的最多整百份。开盘再按实际模拟价格、费用和现金约束决定是否成交。没有成熟模型不取消原进入。

持仓不追加、不部分卖出。以下任一条成立，下一开盘申请全部卖出：

- 本轮模型连续两个持仓收盘预测继续持有收益严格为负。
- 原六十日日内隔夜分数连续两个收盘严格低于零。
- 本笔含分红浮亏达到百分之六。
- 含分红持仓价值从周期高点回撤达到百分之八。
- 含买入日在内已持有六十个收盘交易日。

退出意图保持至实际模拟卖完，受阻继续申请；以后预测转正不撤销已有退出。卖出后空仓期间先看到旧入场条件消失，再等待其重新出现，并满足两日等待。所有份额、浮盈、回撤及分红均来自本轮自己的模拟账户，不套用旧账户状态。
