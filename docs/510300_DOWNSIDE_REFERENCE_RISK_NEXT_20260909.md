# 下一项：区分下跌风险与全部涨跌幅度

第131轮普通波动缩仓在较早历史提高夏普，在主历史减少收益的比例大于降低波动的比例。下一项检验风险度量能否区分上涨与下跌；这是已观察结果之后提出的新组合，不能据此声称下行风险首次被发现或已经有效。

既有价格路径下行风险预算的简单对照，使用二十日下行半方差相对扩展中位数作四档映射；早期估值防守策略也含下行占比；第65轮以五日／六十日波动选择两个专家。其规则与失败裁决保留。本轮不重开这些旧研究，不改变第131轮已冻结结果。

第132轮预定两个设置：主要候选采用零目标下行平方平均数的两倍，再乘242并开平方；构造对照采用全部日收益平方平均数乘242并开平方。两者都用连续二十个完整交易日、含分红简单收益，均不减窗口平均收益。下行定义把上涨或零收益的平方贡献记为零，但分母仍为二十，不能只除以下跌日数。乘二只是零中心对称分布下与全部平方幅度匹配的事先尺度，不表示有限样本两者相等，也不是调参选出的倍数。

采用全部平方幅度对照，是为了区分“只计下跌”与“由样本标准差改为零中心平方幅度”的影响。两个设置都登记和计数，无收益读取后再挑主候选。

都以第128轮同历史、同费用的保存收盘进入与退出意向作参考；每天意向乘以百分之十除以上述风险幅度、最高为一的乘数。风险为零或资料缺失时沿用上一明确乘数，初始一；参考未知继续未知。采用原十个百分点带宽、下一开盘与自身实际资金账户，不新增参考和模型。参考自己的浮盈亏和退出，不由外层账户状态替换。

八条新账户，复用128、131、91和买入持有共十六条对照。先必要合成测试和冻结，再一次计算。保留二十万元、两历史、两费用、完整日历、分红、T+1和终点开盘。若无有效改善，结束两个固定设置，不调整窗口、乘二、百分之十、带宽或费用重新选优。使用现有数据，无新增下载预算和GPT数值包。
