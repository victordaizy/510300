# 第128轮：每笔持仓固定首次收盘的退出模型

只有一个设置。原114策略每天收盘选择最近完成月份的模型，本轮改为：每笔实际买入后的第一个收盘，选择当时已经完成的最近模型版本，固定使用至实际卖完；下一笔实际持仓再选择当时最新模型。保留原八因子、预测公式、进入和保护退出。

第127轮新增当前日内隔夜强弱已经关闭，本轮不带入第九因子。第40轮锁定基础策略身份的规则及其失败保留；本轮固定的是单个原114策略在一笔持仓中的预测模型参数，其使用位置不同。

## 首次选择、每日判断和下一笔更新

没有实际成交就不选择版本。实际买入当天的第一个收盘，固定当时已经完成的最近一条原模型记录。包括当天收盘已经完成的月度拟合，但不使用之后的模型；这不等于买入申请前一收盘选择，也不在开盘提前使用后来才形成的信息。

第一次选择没有成熟模型时，本笔全程没有学习预测，之后出现新模型也不补换；仍保留原可知价格、亏损、回撤及时间保护。首次调用必须位于实际买入日收盘，不能延后到第一次输入完整的日期才选择。

固定的是系数、训练均值、训练标准差、截断范围和预测截距。当前真实份额、浮盈亏、周期最高价值、交易日数及其他市场因子仍每天更新，不能把输入一起固定。当前输入缺失时不产生预测，连续负预测计数清零，所选模型版本继续保持。已经形成的退出意图也继续保留。

实际卖完之后，下一笔买入日首次收盘重新选择最新模型并重置负预测计数。记录每笔选择收盘、所选模型收盘及预测参数身份，便于逐条核对。参数身份只根据实际预测函数字段计算，不能将仅模型日期变化说成参数变化。

原114保存路径预检中，主每档3笔、16个状态，较早每档2笔、47个状态发生过相对首次模型的参数变化。四账户合计126状态；这只是旧路径的参数信息，不是本轮新预测或新收益。新模型时钟是否改善真实退出，以本轮完整账户为准。

## 全部八项因子

1. 含买入日在内已经观察的持仓收盘交易日数，加一后取自然对数。
2. 实际份额市值加本持仓周期已确认的分红，除以真实买入金额与佣金之和，再减一，得到浮盈浮亏。
3. 同一含分红持仓价值相对此前和当前最高价值的回撤；初始最高值至少等于买入总成本。
4. 原日内隔夜强弱进入类别，固定为一。
5. 最近五日含分红对数涨跌。
6. 最近二十日含分红对数涨跌。
7. 含分红财富相对包括当日在内的一百二十日平均值的偏离。
8. 最近二十日含分红简单收益样本标准差，乘二百四十二的平方根。

没有增加高点时间、隔夜风险占比、浮盈回撤交互或其他新因子。前三项来自当前账户自己的真实成本、份额和权益，不能借用参考账户状态。

## 复用模型原本怎样按月学习

保留原141个月度收盘时点，选择当时已完全自然结束的最近二十个参考周期，至少十周期、一百条状态。原计划114次成熟拟合、27个支持不足时点。每周期总权重为一，各状态等分，不删除原行、不缩窗、不提前纳入未结束周期。

目标仍为继续持有至原自然退出，比下一开盘提前卖出的净收入多多少，再除以下一开盘参考市值；包含原基础佣金、滑点和新增分红登记权益。沿用原标签对假设提前退出的近似，不把它说成独立成交验证。原周期必须完全结束才能进入训练。

先用原完整训练样本的周期等权均值和标准差，把八项因子标准化并限制在负五至正五，数值上接近零的标准差用一作分母。然后在每个周期内部，分别减去该周期的标准化因子平均值和目标平均值，得到“相对本周期均值的变化”。去周期均值后不再次截断。

用这些周期内变化求八项线性系数，系数平方惩罚仍为一，沿用原奇异值求解；这一步不加统一截距。一个周期内部不变的因子没有周期内变化，不能凭周期间差异得到有效系数。

系数求得后，每个成熟周期的截距等于该周期目标均值，减去该周期标准化因子均值乘系数的合计。周期截距不受惩罚。新实际周期尚未结束，其截距无法观察；本轮固定使用所有入选成熟周期截距的等权平均。绝不根据本次实际周期未来结果估计截距，也不因周期编号碰巧相同而套用旧周期截距。

在本笔固定版本中，实际预测是这一个平均截距，加当前八项标准化并截断后的实际输入分别乘系数的合计。全部月度系数、标准化数值、训练成员及每个训练周期截距保存为表。压力账户共用基础参考标签和月度模型，各自真实状态、成本及交易独立。

以上是原114已保存模型的训练规则，本轮直接复用141条记录，其中114个成熟模型、27个支持不足，最早成熟时点为2017年3月1日。本轮没有新拟合，不能补造无模型月份或使用更晚的成熟周期。

## 进入与全部退出规则

进入指标仍为最近六十日日内对数涨跌减隔夜对数涨跌的合计，除以这些日差值的样本标准差与六十的平方根。日内、隔夜采用原含已确认分红口径。连续两个收盘严格大于一，原必要输入完整，账户空仓、有进入资格且距离上次真实全部退出已满足两个交易日等待，下一真实开盘请求买入最多可负担的整百份510300。

持仓不追加，不部分卖出。以下任一项成立，下一真实开盘全部退出：本笔固定版本连续两个持仓收盘预测继续收益为负；原日内隔夜指标连续两个收盘小于零；实际含分红周期亏损达到6%；周期价值距最高点回撤达到8%；含买入日在内已经持有60个收盘交易日。

没有成熟模型、求解失败或当前八项输入未知时，不补预测，连续负预测计数归零，原价格、亏损、回撤和期限退出继续。每个实际新周期重新计数。退出意图一经形成就保持到卖出，后续转正不能取消。实际退出后，空仓期间须先看到原进入条件消失，再等它重现，且满足两日等待，才能再次进入。
