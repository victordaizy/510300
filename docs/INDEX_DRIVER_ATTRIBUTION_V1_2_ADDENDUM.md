# 510300 点时指数驱动归因 V1.2 修订说明

父版本：`510300_INDEX_DRIVER_ATTRIBUTION_V1_1`  
父版本状态：`FROZEN_BUILD_BLOCKED_BY_ONE_CONFLICTING_L1_OVERLAP`  
本版本状态：`ATTRIBUTION_ONLY`

## 冲突审计

V1.1 合并同一级行业的重叠区间后，全样本只剩一处跨一级行业冲突：`300442.SZ` 在 2022-09-19 至 2022-10-07 的 15 个交易日同时存在旧行业和新行业记录。

该冲突具有唯一的点时顺序：新行业区间的 `in_date=2022-09-19`，晚于旧行业区间的 `in_date=2015-05-04`；不存在同一最新生效日对应两个不同一级行业的情况。

## 唯一实现修订

V1.2 在 V1.1 归一化后增加慢变维语义：

- 同一证券出现新的不同一级行业时，旧行业区间在新行业 `in_date` 截断；
- 该规则等价于归因日只使用 `in_date <= t` 中生效日最新的一级行业；
- 若同一证券、同一最新 `in_date` 对应多个不同一级行业，继续硬失败；
- 不使用未来收益、指数收益或模型结果选择行业；
- V1/V1.1 的其他定义、门槛和安全状态全部不变。
