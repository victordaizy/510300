# 第52轮：把下一次退出选择计入继续持有价值

本轮检验一个新的学习目标，同时保留一个只改变退出确认次数的对照。只使用已经保存的510300日线、分红及原参考周期，不增加数据来源。交易范围仍为510300和人民币现金；不融资，不做空。

## 为什么做这一轮

原退出模型的训练答案是“下一开盘退出”和“继续拿到原价格或时间条件要求退出”的收益差，但实际策略每天可以重新决定退出。本轮尝试把明天仍然可以退出的选择计入今天的继续持有价值。它是对拟合价值迭代思想的线性近似应用，不保证比原模型有效，也不宣称迭代收敛。

方法出处：[Ernst、Geurts、Wehenkel，2005，Tree-Based Batch Mode Reinforcement Learning](https://www.jmlr.org/beta/papers/v6/ernst05a.html)。论文研究批量强化学习及树模型；这里的线性模型、退出问题和实际交易结果属于本项目自己的改写，论文不证明本策略盈利。

## 两个预先确定的设置

1. 动态继续价值退出：使用本轮新模型。一个收盘预测的继续价值低于零，就在下一开盘请求全部退出。
2. 原标签单次确认对照：复用原已保存的线性模型，仍预测持有到原自然退出的收益；也在一个收盘预测低于零时退出。

两者的入场、数据、月度更新时点、八个因子、成本和账户约束相同。另复用原“两天确认”的学习退出、原价格时间退出、原急跌各半组合及买入持有作为对照。原历史结果不改写。

## 进入、持有和退出

进入信号为日内表现相对隔夜表现的六十日强弱：每天用含当天分红的收盘价相对含当天分红的开盘价计算日内对数涨跌，用含当天分红的开盘价相对前一收盘价计算隔夜对数涨跌；两者相减。最近六十个交易日差值之和，除以这六十个差值的样本标准差和六十的平方根。该值连续两个收盘高于一，才形成进入条件。

空仓、已获得再次进入资格、距离上次实际卖出至少两个交易日，且进入条件成立时，在下一开盘请求按可用资金买入。买入数量向下取整至一百份；持有中不追加。实际买入后撤销再次进入资格，必须在后来空仓时观察到原进入条件消失，之后重新成立才可再次买入。未成交买入按下一次收盘状态重新决定。

持有后逐日检查，任何一项满足就全部退出：六十日强弱连续两个收盘低于零；含已确认分红的持仓价值相对买入成本亏损达到百分之六；该价值相对本周期收盘高点回撤达到百分之八；达到六十个持有交易日；或者本轮相应模型在该收盘预测的继续持有价值低于零。退出请求保留到实际成交；原价格、止损、跟踪退出和最长持有规则始终有效。没有成熟模型或当日因子不全时，保留无模型状态，沿用原价格时间退出，不把缺失预测填成零。

## 八个因子完整定义

| 因子 | 定义 |
| --- | --- |
| 持仓时间 | 对“一加从实际买入日到当前日的交易日数量”取自然对数；买入当天的交易日数量为一。 |
| 持仓浮盈浮亏 | 当前持仓收盘市值加本周期已确认分红，除以实际买入金额与买入佣金之和，再减一。 |
| 持仓回撤 | 当前含已确认分红的持仓价值，除以买入成本及此前至今各收盘持仓价值中的最高值，再减一。 |
| 入场模式 | 原日内相对隔夜强弱模式，数值为一；本轮没有增加第二模式。 |
| 五日涨跌 | 当前累计含分红财富指数相对五个交易日前的自然对数比值。 |
| 二十日涨跌 | 当前累计含分红财富指数相对二十个交易日前的自然对数比值。 |
| 一百二十日均线偏离 | 当前累计含分红财富指数，除以含当日在内最近一百二十日平均值，再减一。 |
| 二十日波动 | 最近二十个交易日含分红简单收益的样本标准差，乘二百四十二的平方根。 |

财富指数逐日乘以“当天收盘价加每份分红，除以前一收盘价”。模型使用同一批原参考持仓状态，并以参考周期中的实际买入数量形成训练收益；实际策略运行时因子由自己的真实模拟持仓计算。

## 动态标签与训练过程

每个收盘先比较两个选择：下一开盘卖出，或再多持有一个开盘到开盘的间隔。一步收益用后一个开盘卖出的净金额，减前一个开盘卖出的净金额，再加这段期间因股权登记日新增的分红权益。净金额使用基本费用、实际价格刻度、滑点和最低佣金；已经获得的旧分红权益在两边抵消。收益除以前一个开盘价乘参考持仓份额。

若再下一次仍有原参考周期内的可选择状态，则把上次迭代模型在该后继收盘预测的继续价值与零比较，取较大值加到一步收益上。后继价值按后一个开盘价与前一个开盘价的比例换算，确保两段收益以相同金额单位相加。若下一状态已到原自然退出边界，则后继价值为零。后继状态只连接本周期的下一交易日，不跨周期、不跳过缺失日。

第一次训练只用上述一步收益，即初始后继价值为零。之后固定重复到第六十次回归，复用相同输入和权重；第六十次模型作为该月的实际退出模型。六十取自原最长持有交易日设置，并非根据本轮收益挑选。不按收益选择迭代次数、不提前挑最好的一次、不拟合树或另扫参数。该过程是有限次数的函数近似，不能当作已经求得真实最优退出点；实际决策也不知道原参考周期的未来退出日期。

只有完整原参考周期实际结束后，才允许其全部状态进入训练。即使一步标签更早已可观察，也不提前收录该周期。每月第一个交易日收盘十五点零五分，沿用原月度训练时点，选择当时最近二十个已完成参考周期；至少十个周期和一百条状态才训练。每个周期总权重为一，内部各日均分。八个因子按这些权重计算均值与总体标准差，标准差过小时取一；标准化后限制在负五到五。线性回归的惩罚系数固定为一，截距不惩罚，继续价值低于零才退出。每次月度实际系数另以中文文档保存。

训练中的下一开盘价格和后继收盘因子只用于当时已经成熟的历史样本，不进入当日实际预测因子。标签是假设可按模型开盘价格卖出的价值近似；实际账户仍执行成交限制，不能把标签本身当作可交易收益。

## 账户、评价与停止条件

主评价为2020年1月2日至2026年8月14日终点开盘；较早诊断为2015年1月5日至2019年12月31日终点开盘。两段各以二十万元开始，保留完整交易日和空仓日。现金及无风险年利率假设均为零，年化使用二百四十二个交易日；夏普计算每日全账户净收益均值除以样本标准差，再乘二百四十二的平方根。不能删除空仓日或只用盈利持仓计算夏普。

基本费用为单边佣金万分之二、最低五元、滑点万分之五；压力费用为佣金万分之四、最低五元、滑点千分之一。价格刻度为千分之一元，整数一百份交易，执行买入次日可卖、方向涨跌停、现金和股息登记及到账约束。终点统一开盘退出，不假设未来收盘成交。

先核对一步收益及分红单位、终止边界、训练时间和实际账户，再比较两种设置在两段历史、两档费用的全部结果。目标仍为全账户净夏普至少一点二，并检查超额和稳定性。主评价是已经反复使用的历史，较早历史也被观察过；任何漂亮数值都不自动变成独立验证。若动态模型不能较同一次数确认的对照形成两段改善，结束这项局部尝试，不扫描迭代次数、确认次数或惩罚强度。暂不准备GPT审阅数值包。
