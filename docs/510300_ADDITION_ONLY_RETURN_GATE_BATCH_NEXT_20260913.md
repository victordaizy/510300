## 因素和明确边界

唯一新增因素是收盘已知的当天含分红简单收益：当天原始收盘价加当天每份除息分红，除以前一原始收盘价，再减一。来自已有features.parquet的close、previous_close和dividend，不使用下一开盘或未来数据。

收益为零时，“不超过零”与“至少为零”都允许；恰好为1%时，“不超过1%”与“至少为1%”都允许。价格和分红按十进制数值判断，避免浮点误差把等号分错边。除息中性日期属于零经济收益，不能把原始价格下调等同市场下跌。缺失或无效的新收益因子不允许已有持仓加仓，不额外使原合法入场或卖出失效。

## 进入、加仓、减仓和退出

在每个收盘，先用本账户自己的实际净资产、实有份额、原合并目标与本候选零或二十个百分点调仓门槛，计算原正常申请。空仓时正目标对应的整百份申请可以直接进入；已有持仓与正目标比例偏差严格小于门槛保持份额，达到门槛则调向中心。明确零和整手取整到零的退出照常计算。

只有同时满足“本账户当前实有份额大于零”和“正常申请数量大于零”，才应用本候选收益条件。不满足收益条件或该因素未知时，将这次加仓申请改为零，保留已有份额和原正目标。

当前实际份额为零时，正常正买入申请完整沿用，不受本批收益过滤影响。该判断使用新账户自己的实际份额，不能根据父策略是否持仓来决定；不能把尚未成交的申请视为已有持仓。所有正常负申请、普通减仓、明确零退出和终点清仓也完全沿用，不受加仓条件限制。

原目标未知时继续保持份额，不把未知填零。不加入第202轮亏损保护，也不延续第203或204轮对初次买入的过滤。每个收盘重新判断，当日允许且原目标需要加仓时可以再次申请，没有额外等待期、退出锁或未成交挂单延续。卖完后重新入场同样按原规则，不被新增加仓条件拦住。

收盘十五时零五分形成决定，下一真实开盘执行，下一开盘涨跌不能回改前收盘决定。被拦的加仓不代表已降低信号目标，须分别记录正常申请、实际申请、已有份额及过滤原因。固定终点开盘优先全部清仓。
