## 去重与授权解释

不能称期货持仓是项目首次接触的信息。已核对以下近邻：Round2 IF主连领先；`510300_FUTURES_OPTION_BRIDGE_V1`；`510300_IF_FORCED_FLOW_STATE_V1`；`510300_DERIVATIVE_PRESSURE_RELEASE_V2_AGGREGATE_OI`。后两者已使用真实 IF 合约聚合持仓，旧结论保留。本轮不是独立未见数据，也不能用五日期限使旧失败重新获得资格。

本轮仅补目前定向检索未发现的一个配对问题：在共同样本、同一岭回归、同一滚动训练和执行时钟下，单独加入持仓日变化及交互项是否降低可成交之后的收益预测误差。旧强制资金流测试依赖极端基差与状态转移，因每向10个事件而在读取收益前停止；旧衍生品压力版本依赖四分量和盘中确认；旧桥梁同时混入主连及期权变量。这些结果不能回答此处的独立消融问题，也不能被本轮结果覆盖。

2026-09-06 的 V6 权限及其原始续行授权允许有限新历史方法，明确不再把旧单项范围限制用于新轮。结合本轮明确附件请求，仅登记此项补充诊断，不重启旧入口、旧策略或旧账户。去重结论是“近邻已做、严格配对用途未找到”，不是证明全部历史记录绝无遗漏。

## 数据与时钟

复用中金所199个真实IF合约、15,860条日记录（2010-04-16至2026-08-12）、到期表、既有修正ETF未复权价格、沪深300现货价格、官方分红表和独立交易日历。所有直接输入先复制到本轮不可变快照，并记录SHA-256。分红价格更正沿用已有裁决。

IF相对价格仅使用2016-01-04及以后数据，排除早期不同收盘时刻；同一五日比较的分子分母必须是同一真实合约，各合约等权后减去同段现货指数收益。不得用拼接主连或收盘/结算混合。

总持仓为官方当日全部IF记录之和，保留到期日零持仓，不按事后最大持仓选择主力。模型共同加入到期周和合约集合切换/到期日控制；输出这些日期的单列诊断。总持仓变化是未平仓量变化，不能解释为净多头资金流或交易者动机。

历史档案没有逐日实时发布回执。固定假设：源交易日s的数据至下一交易日t收盘可以使用；t收盘决策，t+1开盘才入场。因此s日信息最早从s+2开盘之后计入可执行收益。此一日延迟是保守研究假设，不是对历史可得性时戳的补证。禁止另跑零延迟版本挑更好结果。若以后取得逐日真实时间证据，只能另作事前登记的前向检验。

每个t日生成五日标签：t+1开盘进入，t+6开盘退出。训练标签以20万元独立一次往返、100份整手、基础成本、向不利方向取0.001元价格刻度、分红登记权益和未支付应收计量。除息日才买入不享受此前登记权益。入场前跳空单列，不计入持有收益。标签不是连续策略账户。

## 唯一模型比较

M0：ETF当天总收益、近五日总收益、20日对数方差、延迟的IF同合约相对五日收益、延迟的IF到期周、延迟的IF移仓边界。

M1：M0全部变量，增加延迟的IF总持仓一日日对数变化，以及其乘以决策日ETF五日收益正负号的交互项。只有这两个增量变量；不添加期权、基差绝对水平、会员排名或其他筛选器。

训练原点从2016-02-01起；评价进入日从2020-01-02起，ETF标签截止2026-08-14。训练窗扩展，每个入场月份第一次预测时重估一次。只有退出日期严格早于重估原点日期的训练标签能进入，不能把重叠五日的尚未成熟结果塞入训练。至少504条合格训练观测。两个模型用相同训练行。

训练均值和标准差仅在当前训练集计算，再将标准化值裁至正负5；岭回归目标为平均平方误差加0.1倍系数平方和，截距不罚。禁止网格搜索、方向反转、挑窗口、删年份或事后全历史最终重估。评价原点保留完整日历，缺失状态为NO_VIEW，不能填零收益。

## 去留标准

唯一主检验为M0平方误差减M1平方误差的平均值，正值表示改善。按连续20交易日、2,000次、固定随机种子20260913进行成对循环区块重抽样；95%区间下界必须严格大于零，2020—2021、2022—2023、2024—2026三个预定时期至少两个正向，每时期至少252条评价原点，且所有成熟原点均取得配对预测。缺一项即不进入账户阶段。

同时报告均方误差、平均绝对误差、预测为正的覆盖率与实际持有期损失、入场前跳空和到期/换月分组。辅助结果不得代替失败的主检验。相邻五日结果重叠，原点数不是独立机会数；区块区间也未校正项目此前多轮研究选择偏差。

主门未过：`REJECTED_FROZEN_NO_INCREMENT_UNDER_REGISTERED_TEST`；弱正但区间跨零也保持未确认，不反向使用，不另开参数救援。数据或覆盖门失败：`NO_VIEW_DATA_OR_COVERAGE_FAILED`，不等于预测无效。

## 有条件的账户阶段

只有主门通过才运行。模型预测仍统一用基础成本标签，两档账户使用同一预测与同一风险规则。每五个交易日收盘决定下一开盘的份额，预测净收益大于零时，目标权重为min(1,10%/(ETF20日波动率×sqrt(242)))，否则零；不借贷、不卖空。连续正预测允许保持/调整已有仓位，避免机械多收费。首次评价开盘至最后一个完整五日边界开盘形成统一账户区间，末日清算，保存无法成交的记录。

20万元本金，现金与无风险收益均为零；基础佣金万二/单边最低5元/单边5bp滑点，压力佣金万四/最低5元/单边10bp滑点；100份、0.001元、涨跌停方向限制、T+1库存、分红登记/除息应收/到账分别处理。保存M0、M1和同成本买入持有的全部日账、交易及决定。

仅当两个成本下M1均同时达到净夏普1.2、复合年化10%，且相对M0净年化和夏普都提高，才可记“历史账户点值达标”。即使达标，研究过的历史和假定可用时刻仍不构成独立稳定验证；不得标记最终目标已实现。
