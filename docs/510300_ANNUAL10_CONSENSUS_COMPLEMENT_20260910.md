# 第七组：已有多机制共识的剩余资金增量

用户本轮目标是仅510300与现金、成本后复合年化至少10%且净夏普至少1.2。前六组389项已计算而未达标；本组是明确计入总搜索次数的后续发现性实验，不是独立验证，不改变任何旧结论。

## 假设和与前六组的区别

第二组只给核心增加十二种价格规则、六种量价规则或四种日历规则的单独输出。本组检验旧第28轮的八种固定多机制合成输出是否提供边际机会。它不是八种独立信息；同源和同时持仓的相关性保持在同一个真实资金账户里，不用平均夏普替代。

三个参考分别是原S1_TREND_REBOUND（趋势突破/均值恢复）、原D60_INTRA（日内相对隔夜强弱）、原V1_CLIMAX_RECOVERY（急跌后放量收强）。完全复用原signals、specifications、make_rule、make_rules和simulate_policy，不改入场或退出阈值。每个时期各以20万元、基础费用独立启动三个参考，共六个参考账户。两档外层费用均使用同一基础参考意向，匹配原第28轮结构。

原simple_signal_blend_v1.targets的八个公式全部运行：三者各三分之一、趋势/日内各半、趋势/放量各半、日内/放量各半、至少两票同意满仓、一票半仓两票满仓、趋势半仓其余各四分之一、三者等权再乘既定10%/20日年化波动的封顶乘数。公式或缺失语义一律不改。复算八种原主期基础账户，与已保存指标核对；不一致时停止新组合。

## 核心与组合

核心为保存的第150轮同一时期同一费用收盘目标，固定使用min(1,2*target)和min(1,3*target)两个已完成资金对照，不再搜索倍率。补充比例固定为50%和100%。两种合成均运行：

- IDLE_ONLY：核心明确为零时使用a*补充目标，否则原核心不变。
- REMAINING：核心目标+(1-核心目标)*a*补充目标。

任一必要目标未知，组合目标也未知，不自动补零。八输出×两核心×两比例×两合成=64政策；两个时期×两费用=256个新资金账户。另有八种合成输出的主期基础复算，八种合成输出在每个时期每档费用的32个诊断对照（其中八个即复算），及每时期两档成本共八条核心复算对照。对照不计为新增64政策。不得根据本轮结果再改票数、来源、阈值或比例。

## 记账与检验

资金20万元，基础佣金0.0002最低5元/单边滑点0.0005，压力佣金0.0004最低5元/滑点0.001；100份整手、0.001元价位、T+1、方向涨跌停、分红登记/应收/到账、10个百分点调仓带宽全部沿用原事件账户。收盘后产生意向，下一开盘成交，终点开盘清算。242日年化，现金与无风险收益零。

主期2020-01-02至2026-08-14、1604日；较早期2015-01-05至2019-12-31、1219日。分别以新资金开始，保留全部现金日。每个账户独立核对财富恒等式、日收益、CAGR和夏普；检查参考意向的下一开盘时钟；全部256条结果公布。同一账户同时满足两个目标才记MAIN_BASE_POINT_MET；压力、较早、两期两费用分别标记，不以不同账户拼数。

若有主期点目标，停止追加本组候选设计并完成既定四情景与独立账务检查；独立市场验证仍不能由历史点目标替代。没有点目标则如实保留未完成，不倒算信号、改成本、增加现金收益或引入杠杆填满目标。不生成Paper/Shadow或真实订单。
