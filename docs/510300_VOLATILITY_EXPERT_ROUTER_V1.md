# 第65轮：短期波动状态选择急跌或学习策略

只登记一个设置，直接用现有510300价格和第46轮两条基础费用专家状态。第64轮提高预算没有提高夏普，本轮改变的是什么时候采用哪一条信号。历史上已有其他状态选择研究，本轮只检查这两个专家与原急跌信号已有的短长波动定义；没有新模型、参考账户或数据下载。

## 选择策略的因子与边界

短期波动为最近5日含分红简单收益的样本标准差，长期波动为最近60日同类收益的样本标准差；两者均按242交易日年化。含分红简单收益等于收盘加当日每份现金分红，再除以前收盘，减一。两个窗口都包含当天已经收盘的数据。

当5日波动严格大于60日波动的1.5倍时，选择原急跌反弹专家；其余波动已知、60日波动为正的状态，选择原学习专家。恰好1.5倍属于原学习。倍数和窗口沿用急跌因子，不根据本轮收益重新选择。

任一波动缺失、长期波动为零，或已选专家的状态缺失，本次保持无观点，不调整实际份额，也不把缺失填成空仓。未被选专家的状态缺失不影响已经完整的当前选择。负波动、无穷大或非零一的专家状态属于数据错误并中止，不截断修复。原评价范围两条来源状态完整。

## 急跌反弹专家的全部进入和退出

进入同时要求：最近5日含分红累计收益低于负5%；当日含分红财富指数比昨天高；收盘在当日最高最低价格区间的位置至少60%；5日波动严格大于60日的1.5倍；原基础特征完整。财富指数每天按收盘加分红除以前收盘的比例累计。收盘区间位置为收盘减最低，再除以最高减最低；异常无有效区间沿用原基础特征规则。该专家没有成交量进入要求。

原独立专家实际退出后等待两个交易日，下一开盘请求进入。持仓含分红亏损达到4%、盈利达到6%、持有达到10个交易日收盘，或财富指数回到或高于20日平均值，任一成立就请求退出。原独立账户未成交处理和等待保留；不额外套用第32轮的原进入条件消失再出现要求。

## 学习专家的全部进入和退出

每日含分红日内对数收益减去隔夜对数收益，过去60日差额之和除以这段差额的样本标准差和60的平方根；该分数连续两个收盘大于1、基础特征完整才进入。日内对数收益由收盘加分红与开盘加分红之比取对数；隔夜由开盘加分红与前收盘之比取对数。空仓时原进入条件曾消失才能恢复下一次资格，实际买入消耗资格；实际退出后还需满足两个交易日等待。原独立专家单次进入，不追加。

差额分数连续两收盘小于零、含分红亏损达到6%、从持仓价值高点回落8%、持有达到60个交易日收盘，或者原学习模型连续两个收盘判断继续持有收益为负，任一成立就请求退出。没有成熟模型时继续原价格和时间保护，不把无预测当成退出。

原学习八因子为：持仓交易日数加一的自然对数、含分红持仓收益、相对本周期最高持仓价值的回撤、进入模式、5日含分红对数收益之和、20日同类收益之和、财富指数相对120日均值偏离、20日含分红简单收益样本标准差乘242平方根。

每月第一个收盘只用已经自然结束的最近20个原参考周期；至少10周期、100状态行才有模型，每周期总权重相同。因子用每月保存均值和尺度标准化、限制负5至5，岭惩罚1。标签比较继续持有到原参考周期结束与下一开盘退出的收益差，后者保留旧标注的费用和分红处理，但不是另外模拟受涨跌停阻碍的标签成交。原D60保存114次成熟拟合、27次无模型更新，全部逐月系数以中文附带。本轮直接使用旧专家当时形成的状态，没有重训。

## 实际组合的进入、退出及再次进入

两个专家继续各自独立的历史周期；每天收盘按当时波动选择一条，只取该专家已形成的下一开盘零一目标。状态为一就使用实际账户可负担的完整预算，为零就请求清仓。不会把专家次日真实成交后才知道的份额倒移到前一天。

空仓而有效目标为一，按当前收盘净值除以价格，向下取100份整数倍，下一开盘按实际现金、佣金、滑点和成交约束购买。持仓而目标仍为一时，若当前股票占净值与100%相差不到10个百分点，保留份额；达到10个百分点则按同一预算方式调整，小额分红无需每日追加。目标为零就请求下一开盘卖出全部实际份额。

每日可以改选专家，已有持仓的选择也可以改变。切换后目标仍为一，不要求先卖再买；切换后所选目标为零，则退出，即便原来那条专家仍想持有。专家自身从一变零也产生退出请求。组合没有额外等待，日后所选专家恢复一时可再次进入，即使它自己的独立周期已经开始多日。

未成交后，下一收盘以最新波动、专家目标和实际余额重新判断；若目标仍零继续请求退出，若变一按新目标处理，若无观点暂停新调整并保留实际份额。组合没有另外锁定退出请求或锁定进入时的专家。原独立专家的等待、止损与学习退出仍在其状态中；不能把独立专家4%、6%或8%的阈值宣称为组合硬止损或最大回撤保证。

终点统一在最后交易日开盘尝试全部退出，不读取当日收盘再改变终点。保留整手、T+1、方向涨跌停、登记日分红权利、除息应收与实际到账；按完整实际账户逐日核算，不能拼接或平均保存的专家收益。
