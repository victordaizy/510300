# 510300单标的现货Alpha规范

> **当前状态：`SUPERSEDED_BY_ROUND5_STRATEGY_COMPARISON`。** 用户已重新允许估值中枢进入战略仓位，并把目标调整为年化超额10%最低线、15%挑战线。现行规范见`docs/ROUND5_STRATEGY_COMPARISON_SPEC.md`；本文仅保留上一轮研究治理记录。

## 1. 唯一研究与交易对象

- 唯一风险资产：`510300.SH`；
- 允许资产：510300现货与现金；
- 仓位范围：0%至100%；
- 禁止：成分股、期货、期权、融资、卖空、杠杆、海外资产与其他ETF；
- H00300沪深300全收益指数仅作为业绩比较基准，不得进入信号、特征、阈值或模型选择。

“只做510300”同时约束交易域和Alpha信息域，不能因为最终订单仍是510300而引入其他资产的行情作为预测信号。

## 2. 允许的Alpha信息

只允许使用与510300基金本身直接对应、且点时可得的数据：

- 未复权日线与分钟OHLCV；
- 现金分红、除息、权益登记与支付信息；
- 单位净值、累计净值、IOPV及折溢价；
- 基金份额、申购赎回造成的份额变化；
- 510300自身的融资融券余额与交易流量；
- 基金公告、费率、跟踪误差和交易制度变化。

以下信息不得进入当前Alpha模型：

- 沪深300指数价格、估值、基本面或成分股数据；
- 点时成分、权重、行业、广度与成分股资金流；
- IF基差或任何期货数据；
- 国债利率、宏观、外汇、海外指数、商品或其他跨市场变量。

## 3. 目标与基准

主要挑战指标保持为：

`ExcessCAGR = StrategyNetCAGR - H00300TotalReturnCAGR`

目标门槛为年化超额20个百分点。策略收益必须计入510300现金分红，并扣除佣金、最低佣金和滑点。该门槛是研究目标，不是收益承诺。

同时必须报告相对510300买入持有的收益差，用于区分ETF择时Alpha与ETF/指数跟踪差异。

失败家族不得在同一五年历史上改相邻窗口、翻转方向或搜索阈值后重新包装。

## 5. 下一研究门

下一条允许的新机制仅限510300自身的一级/二级市场联动：

1. 补齐并审计点时单位净值、IOPV、折溢价与基金份额；
2. 明确各字段实际发布时间，禁止用收盘后数据在当日成交；
3. 在查看未来收益前预登记单一机制、窗口、方向、目标和验收门槛；
4. 先做方向与条件净收益检验，通过后才允许映射0%至100%仓位；
5. 所有历史只能称为伪样本外，最终候选必须接受冻结后的真正纸面前向验证。
