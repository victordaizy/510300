# 第188轮：按原策略自身近期净收益决定暂停与恢复

目标为全账户净夏普至少1.2及复合年化至少10%，基础与压力费用同时检查。只用已有510300及现金研究数据，不融资、不新增来源、不训练模型。

第187轮直接按市场波动统一分配仓位，虽收窄回撤，却明显降低年化收益。本轮保留第181轮原账户风险预算及全部仓位幅度，只增加“原策略自身近期净收益是否转弱”的进入退出条件。原策略在背景中独立继续模拟，不接受新组合的暂停、盈亏或持仓反馈，因此暂停后仍可观察其是否恢复。

## 来源与两个固定健康条件

来源为第181轮按各自费用计算的完整模拟账户净资产，以及同一来源当日收盘目标。净资产包括已扣佣金、滑点、现金、持有份额市值和应收股息。不能使用未扣费用收益，也不能用价格指数涨跌替代来源账户结果。

主方案“六十日净收益暂停恢复”：原策略当前收盘净资产不低于六十个交易日前的净资产，健康状态为允许；低于则为暂停。等于时允许。初始锚点收盘净资产为二十万元，仅使用该模拟账户开始后已经产生的历史。

比较方案“六十日净资产均线暂停恢复”：原策略当前收盘净资产不低于最近六十个交易日收盘净资产的算术均值，健康状态为允许；低于则为暂停。均值包含当前收盘。等于时允许。

两方案都在原策略尚未完成六十个交易日模拟收益前保持允许，避免虚构账户开始前的净值。达到六十日后，所需完整窗口缺失、非正或无穷净值记为健康状态未知；不以填充后的未来结果修复。

## 入场、暂停退出与恢复

1. 来源目标明确为零：下一开盘请求全部退出，不依赖健康条件。
2. 来源健康状态明确暂停：下一开盘请求全部退出，即使当日来源目标未知。这是独立的策略近期净收益退出条件。
3. 来源健康状态允许且来源目标已知：采用来源原目标，按新账户自己的净资产形成可支付的整百份请求。原目标大于零时允许进入或调整。
4. 健康状态未知且来源目标不是明确零，或健康允许而来源目标未知：保持实际已有份额等待新决定。

暂停后，每天收盘继续检查独立来源账户；只要健康状态恢复允许并且来源目标大于零，下一交易日开盘重新进入。没有固定冷静期、止损价或恢复到历史最高点的要求。两方案分别运行，不能看结果后选择年份、改六十日窗口或改变暂停阈值。

## 原策略预算及成交

第181轮的原目标来自第174轮基础目标乘以账户风险预算倍数，最多100%。倍数为10%除以第174轮相应费用完整账户最近六十日净收益的年化样本标准差，按242日年化；初始不足六十日及零波动时倍数为一。正式完整说明附入这些来源的全部中文因素及进入退出规则。

信号每天15时05分确定，下一交易日开盘模拟执行。初始资金二十万元，整百份，最小价格单位千分之一，正目标已有持仓偏差不足十个百分点时免调仓。明确零及终点全部退出优先。保留现金可支付、合法卖出、涨跌停、股息登记除息到账的原规则；不能用来源账户的盈利替代新组合独立账户的实际结果。

主历史2020年1月2日至2026年8月14日开盘，较早历史2015年1月5日至2019年12月31日开盘。基础佣金万分之二、最低五元，单边滑点万分之五；压力佣金万分之四、最低五元，单边滑点千分之一。现金和无风险收益维持零。

本轮固定两个候选、八个新模拟账户，零模型训练和零新增参考账户。复用第181轮未加健康条件的原预算、第182轮区间倍率及买入持有对照。完整报告两种历史、两种费用及所有失败，包括暂停和恢复次数、交易成本和年度收益。

所有历史都已观察，本轮仍为研究回放，不是独立验证。双门槛未完成则不宣称目标完成，禁止仅以回撤下降或某一段夏普提高替代完整目标。
