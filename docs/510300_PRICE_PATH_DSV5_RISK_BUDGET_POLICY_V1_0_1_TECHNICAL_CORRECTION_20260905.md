# V1.0.1无预测、无收益技术修正

V1.0.0的Git提交为fecb3d6。首次严格前向登记在读取任何预测数值前报错：程序要求历史截断日历与2026全年官方日历集合完全相等。

事实：历史日历的2026部分共149日，截至2026-08-14；官方全年日历242日，截至2026-12-31。历史已覆盖日期没有差异，官方多出的93日全部在历史截止日之后。

该错误属于日历覆盖区间处理错误，未生成前向登记、未运行G0/G1、未消费历史claim、未读取组合收益。追加V1.0.1，仅将日历规则修为：重叠日期必须完全相同，后续日期由已绑定哈希的官方2026日历补足。

本版本继承全部V1.0.0协议、实现和输入哈希；原始文件不改写。政策映射、B1结构、五日锚点、时代、费用、G0—G3和前向门均未改变。新增模块通过明确入口安装日期函数，其他执行逻辑完全复用冻结首版。

正式入口为scripts/run_510300_price_path_dsv5_risk_budget_policy_v1_0_1.py，支持register-forward、gates、history、shadow-tick。该程序修正须单独测试和提交Git后才能登记前向、读取预测。
