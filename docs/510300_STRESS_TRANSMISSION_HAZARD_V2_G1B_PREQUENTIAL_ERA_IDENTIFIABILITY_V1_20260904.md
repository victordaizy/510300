# 510300 压力传导危险率 V2：G1B 前序年代可识别性协议 V1

## 1. 目的

G1A 已证明修复后的 B2/B1 共同样本包含 31 个可识别独立事件、1,102 个合格非事件风险日和 1,279 个共同样本日。G1B 不检验模型表现，而是回答更早的一层问题：这些事件在严格时间顺序下，能否形成至少三个各含五个真正前序预测事件的固定年代。

本门不拟合 B0、B1、B2 或 B3，不读取任何特征值、最小路径收益或组合收益，也不运行正式、反事实或完整样本 G2。

## 2. 冻结先于实际行值读取

冻结阶段只允许核对文件路径、字节数、SHA-256、既有持久化语义摘要、Parquet 行列数和 schema 名称。实际样本行值只能在以下内容全部写入只增不改的 manifest 和冻结收据、并完成本地 Git 提交后读取：

- 精确七个物理读取列；
- 四个固定年代；
- 季度扩展式 vintage 时钟；
- 整事件成熟与整事件评价规则；
- 最低训练类别识别条件；
- 每时代五事件门与至少三个合格时代门；
- 所有禁止读取、禁止拟合与禁止收益评价动作。

实际物理读取列固定为：

```text
origin_date
horizon_end_date
bad10
event_id
b2_vs_b1_eligible
split_assignment
calendar_year_block_id
```

父 Parquet 没有物理 `era_id`。G1B 只从 `origin_date` 和冻结年代边界派生 `era_id`。禁止读取 B1 三个特征、F、M、T、T×F、T×M、模型权重、`minimum_path_return`、任何组合收益、净值、夏普、回撤或仓位字段。

## 3. 季度扩展时钟

每个模型 vintage 定义为每个日历季度结束后，在同一 G1 样本 `origin_date` 交易日序列中的第一个交易日。对正事件，评价日期固定为事件最早 `origin_date`，整个事件绑定到该日期当日或之前最近的季度 vintage；即使事件跨越下一个季度边界，也不切换 vintage。

一个正事件只有在其全部正样本的最大 `horizon_end_date` 严格早于 vintage 时，才可整体进入该 vintage 的训练历史。一个非事件风险日只有在其 `horizon_end_date` 严格早于 vintage 时才可进入。训练历史不得包含评价事件自身，不得包含尚未成熟标签，也不得用未来版本倒推过去。

## 4. 最宽松的训练识别条件

本门只计算理论可评价上界，因此采用任务卡允许的最宽松条件：

```text
TRAINING_POSITIVE_INDEPENDENT_EVENTS >= 1
TRAINING_NEGATIVE_RISK_DAYS >= 1
```

这不是模型充分性声明。它只表示当两类标签至少各出现一次时，B1 与 B2 在类别层面理论上可建立。禁止用 B0 常数概率、人工正类先验、未来系数或完整样本系数替代缺失类别。

## 5. 时代资格与逻辑上界

四个时代保持原协议不变：2015–2017、2018–2020、2021–2023、2024–2026-08-14。一个时代只有同时满足以下条件才合格：

- 至少五个真正由过去可识别训练历史覆盖的独立事件；
- B1 与 B2 的训练类别可识别；
- 没有事件拆分；
- 没有未来标签进入训练。

正式 G2 至少需要三个合格时代。读取实际行值之前，根据已冻结的 G1A 年代分布即可得到最宽松上界：

| 年代 | G1A 可识别事件 | G1B 前序事件逻辑上界 |
|---|---:|---:|
| 2015–2017 | 0 | 0 |
| 2018–2020 | 5 | 4 |
| 2021–2023 | 19 | 19 |
| 2024–2026 | 7 | 7 |

2018–2020 的第一个可识别正事件必须先成熟并成为后续 vintage 的训练历史，不能同时作为由既有正类历史产生的评价事件。因此，逻辑上最多只有最后两个时代可能达到五事件门，最多两个合格时代，小于正式 G2 所需的三个。

## 6. 裁决与权限边界

若实际审计的合格时代少于三个：

```text
G1B_PREQUENTIAL_ERA_IDENTIFIABILITY
= NO_VIEW_INSUFFICIENT_EVALUABLE_ERAS

G2_STRUCTURAL_INCREMENT
= NOT_RUN_BLOCKED_BY_G1B

HISTORICAL_BRANCH
= ARCHIVED_NO_RESCUE
```

即使 G1B 意外通过，本任务也只能写 `NOT_RUN_REQUIRES_SEPARATE_FORMAL_G2_FREEZE`，不得在同一执行中拟合模型。B3 仍因 31 小于 40 而不可识别，G3 至 G7、收益评价、Paper/Shadow、券商、仓位与订单权限均保持关闭，`POSITION_IMPACT=0`。
