# 第67轮：连续趋势与噪声的逐日估计

本轮只登记一套连续趋势模型及交易规则。以现有510300含分红价格为唯一观察资料，每季度更新参数、每天更新趋势，不使用EPS、宏观或新增外部来源。不根据整段历史收益选择季度参数，不改旧失败记录。

## 模型怎样理解价格

先把含分红财富指数取自然对数。财富指数从首条收盘的一开始，此后按“当天收盘加每份现金分红，再除以前收盘”的比例连续复合。首行没有前收盘，保留这一事实，不虚构首日收益。

模型认为观察到的对数价格由潜在水平加短期观测噪声构成。今日潜在水平等于昨日水平加昨日趋势斜率；今日斜率等于昨日斜率加一次趋势变化噪声。水平不再另加一种自由噪声，因此只有两个需要估计的噪声方差。它是平滑趋势状态空间模型的一个特例，机制参考[结构时间序列官方说明](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.structural.UnobservedComponents.html)。

每天先用上一状态推进一天，再将当天实际价格与预测水平比较。差异叫创新，用模型的不确定性决定本次修正幅度，同时更新水平、斜率和它们的协方差。只使用当日收盘及以前资料，不使用未来价格平滑过去状态。所估趋势是模型内部的每日对数斜率，不等于已经证明的可赚收益。

## 所有因子及中间数值

直接观察因子只有对数含分红财富价格。模型产生当前潜在水平、趋势斜率、水平方差、水平与斜率协方差、斜率方差。斜率不确定性为斜率方差的平方根，标准化趋势为斜率除以该不确定性。进出场只使用斜率及其不确定性，其他量用于更新与解释。

另保存趋势变化噪声方差、观测噪声方差、最近一次成功参数估计的日期、距离该次估计的交易日数、当天创新及创新方差。季度估计成功当日，收盘已经包含在窗口末端状态中，不再执行一次单日更新；其单独创新栏留空，不能解释为当天没有有效模型。

标准化趋势大于一，是本策略预定的进入边界。它没有经过收益择优，也不代表实证胜率或真实收益置信度达到某个百分比。模型可能估错趋势和噪声，必须由实际账户检验。

## 季度估计的完整规则

每个自然季度第一个已有交易日收盘，使用截至当天最近504条交易日对数财富价格，包含当天。少于504条就不估计；窗口有缺失就跳过本次新估计。日历从原全部价格开始，因此评价前已有的季度估计可在当时被使用，不是等看到评价收益以后再选择。

每个训练窗口的第一条价格只确定潜在水平初始均值，初始斜率为零，水平和斜率初始方差都为一、协方差为零。第一条不计入创新似然；之后503条逐条递推，计算高斯创新条件似然。两项噪声方差通过最小化负对数似然估计，目标里没有夏普、账户收益或某年表现。

两项方差的自然对数都限制在负三十到零，约对应9.36乘十的负十四次方至一。每次从同样方式生成初始点：训练窗503条价格差额的样本方差，若小于一亿分之一则仅对初始点取一亿分之一；趋势噪声初值为该值的千分之一，观测噪声初值为其一半，再限制在上述边界。初始点下限不等于最终方差下限，不沿用上次参数作为初始点。

固定使用有界拟牛顿优化，最多100次迭代，每次线搜索最多20步；目标相对容差十亿分之一、梯度容差十万分之一。只有优化器报告收敛、结果有限、末端协方差有效且目标没有比初始点差超过百万分之一，才接纳本次参数。达到参数边界可接纳，但必须记录边界状态。内部优化迭代和目标求值不是新增独立策略设置。

成功时保存两项方差和窗口末端的滤波状态，它已经消费当天收盘；当天不能再过滤同一个价格。失败或窗口不完整时，若已有此前成功模型，则保留此前参数及昨天的有效状态，用当天价格正常更新一次，并记录本次失败及原参数日期。没有此前成功模型就保持无观点，不能填零斜率或伪造空仓预测。每个季度的状态、收敛情况、目标值和参数都保存。

## 日常更新和缺失资料

非季度更新日，沿用最近一次成功参数，按新价格推进和更新一次。参数没有额外的日期失效门槛，保存实际模型年龄；不能将旧参数冒充本季度成功估计。

当天观察价格缺失时，若已有模型，则内部只推进一天的状态和协方差，不用一个编造的价格更新。对外目标保持无观点，保留实际份额及上一次明确目标的内部记忆。下一条真实价格恢复时，按已推进的时间继续更新。没有成熟模型时继续无观点，等以后季度有完整样本且估计成功。

无穷大、非正财富价格、非法协方差、数值运算异常或日期倒序重复，会中止该次研究，保留错误记录，不临时裁剪参数或改变规则救活结果。合成缺失和失败测试不代表真实历史一定发生过这些情况，报告须给实际覆盖数。

## 明确目标、进入、持有和退出

有效模型下，趋势斜率非正，就将目标设为零；斜率严格大于自身一倍不确定性，就将目标设为一。斜率仍正但未严格超过边界时，保持上一次明确目标。第一次出现有效模型但趋势不够强时，明确初始化目标为零；无模型时期的输出仍是无观点，不提前填成零。

恰好达到一倍边界时不改变上一目标。已有目标为一，只要斜率仍为正就可保持；斜率等于零也触发退出。目标是策略意图，实际份额另由成交决定；不能把目标一视为已经成交。

空仓且目标为一，按当前收盘净值除以价格，向下取100份整手，下一开盘按实际现金、佣金、滑点、方向涨跌停及T+1限制买入。开始评价时直接采用当时已经存在的目标状态，可能立即进入既有趋势，不伪称每次都是当天刚发生的进入信号。

持仓且目标仍为一，股票市值占净值与100%差不到10个百分点时保留份额；差额达到10个百分点才重新按预算调整。因此小额现金分红不必每天追加，足够大的现金积累可能追加。目标为零则请求下一开盘卖出全部实际份额。

没有额外固定止损、止盈、最长持有期、等待期或一次退出后重新确认的条件。实际退出后，日后目标再为一可重新进入。未成交时下一收盘按最新有效目标与实际账户重算；零目标继续请求退出，一目标按新目标处理，无观点暂停新请求、保留份额。旧退出目标不额外锁定，下一次强趋势可改变目标。进入边界、退出零边界和两者之间的保持状态共同构成完整规则。

## 账户比较与验收

主评价2020年1月2日至2026年8月14日开盘1604日；较早2015年1月5日至2019年12月31日开盘1219日。各20万元本金，242交易日年化，现金和无风险收益假设零，空仓日全部计入。基础佣金万分之二、最低5元、滑点万分之五；压力佣金万分之四、最低5元、滑点千分之一。两档费用共用同一条连续趋势状态。

100份整手、千分之一报价刻度、T+1、方向涨跌停、未成交及分红登记应收到账规则保持。终点在最后交易日开盘请求统一退出，最后收盘预测不参与该终点账户。信号财富和模型斜率不替代实际现金账的收益。

对照为原学习、原各半、原急跌与买入持有，原样复用；每段两费用10条记录，合计4个新账户和16个保存对照。没有新参考交易周期；季度参数估计数量按实际成功和失败分别报告，不把价格样本当交易次数。

必要测试通过后冻结一套设置，再一次估计全部历史状态并运行账户。若不成立，结束该方法，不根据收益调整504日、季度频率、噪声边界或一倍进入边界。净夏普1.2与稳定超额仍需完整账户及独立证据，不能只凭某年或某个参数点宣称完成。
