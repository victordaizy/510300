# 510300图形状态马丁-海龟V2冻结协议

状态：`PROTOCOL_FROZEN_DATA_GATE_PENDING`  
性质：`DISCOVERY_ONLY`  
历史标签：`HISTORICALLY_CONTAMINATED`  
真实仓位、订单、券商连接：`DISABLED`

## 1. 研究目标

本协议响应用户“两个马丁都做一遍，并根据图形与海龟切换”的要求。V1纯唐奇安协议保持原样，R5、R6和V3均不修改。

研究对象固定为六条可比较轨道：外部冻结的纯海龟T0、带顶背离退出的海龟T1、封顶马丁格尔M0、BIAS28摆荡P0、马丁格尔-海龟切换S1和BIAS28-海龟切换S2。V2注册候选为T1/M0/P0/S1/S2共5条，T0只作为既有基准，不参与重新选择。

## 2. 图形不是事后看图

“根据图形”被翻译为只使用当日及过去数据的日线状态机。价格摆动点与MACD DIF摆动点分别识别，左右各3根K线确认，因此摆动点发生后至少3个交易日才可被知道。价格摆动必须相对前一反向摆动达到1个ATR14；价格与DIF摆动允许前后3根K线错位，但每个摆动点只使用一次。

底背离要求第二个显著价格低点更低、第二个独立DIF低点更高；顶背离反向。事件从较晚确认日起生效，最长15个交易日。所有事件必须列出两个价格摆动点、两个DIF摆动点、确认日和失效日。

## 3. 状态机

- `RANGE`：ER20不高于0.30，且不处于下跌趋势或海龟持仓；
- `TREND_DOWN`：收盘低于下降中的MA60，同时跌破此前20日最低价；
- `TURTLE_LONG`：收盘严格突破此前20日最高价后，于下一开盘进入；
- `AMBIGUOUS`：其他状态，空仓时保持现金，不启动马丁。

海龟常规退出为收盘严格跌破此前10日最低价。确认顶背离也在下一开盘退出；此后必须先收盘回到MA20下方，才允许新的20日突破重新武装。

## 4. 两种马丁

### 4.1 封顶马丁格尔

只有`RANGE+确认底背离`才开第一层。三层新增目标分别为当前权益的12.5%、25%和50%，累计目标12.5%、37.5%、87.5%。每次必须从上一层实际成交价再下跌1个ATR14，并至少间隔一个交易日。第三层之后绝不继续翻倍。

收盘回归MA28、确认顶背离、进入下跌趋势、跌破背离第二低点减1个ATR或持有20个交易日，均在下一开盘退出。若先发生20日向上突破，不先卖出，直接把目标提升至100%并转海龟管理。

### 4.2 BIAS28摆荡

该轨道只冻结机械定义，不继续宣称其历史名称已经得到权威核实。入场要求`RANGE+确认底背离+BIAS28<-10%`，目标暴露50%，不逆势加仓。退出和转海龟规则与上面一致。

## 5. 执行与成本

所有信号在`t`日16:00后确定，假设`t+1`交易日开盘成交。研究账户20,000元，仅持有510300和现金，T+1、100份整数倍、不透支、不卖空、不加杠杆。每腿佣金为`max(名义金额×0.03%, 5元)`，每腿滑点5bp；现金年化1.5%。分红按登记日资格和支付日现金入账。

研究目标暴露仅用于历史账本，不输出用户当前目标份额。

## 6. 比较与门槛

每条轨道必须报告完整连续时间轴，而不是只报告适合自己的图形片段。主基准为510300含分红买入持有，次基准为H00300，同时比较同平均暴露和同波动静态组合。

通过需要同时满足：成本后年化超额为正、动态择时贡献为正、Sharpe至少0.8且改善至少0.25、最大回撤不超过买入持有的80%、242日滚动超额正值比例至少60%、四段至少三段为正、至少30笔闭合交易、两倍成本仍为正、循环平移达到95%分位。S1/S2的Sharpe还必须分别高于海龟与对应马丁单模块。

任一候选失败后不得增加窗口、修改背离阈值或只展示赢家。

## 7. 数据与顺序

顺序固定为：冻结协议 -> 补齐并审计2012-2026年完整分红 -> 冻结实现与输入哈希 -> 运行一次历史受污染检验 -> 输出逐事件和状态转换损益。

截至2026年8月14日的全部历史只能用于发现和否证。`true_forward_start`保持`null`。输入缺失或审计不通过时输出`NO_VIEW`，不计算收益。
