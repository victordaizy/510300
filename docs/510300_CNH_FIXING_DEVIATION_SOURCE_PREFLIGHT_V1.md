# 510300：离岸人民币报价相对已公布中间价偏离的来源核对

登记 TECH.R205，结果 TECH.R206。用户允许加入不同信息源、宏观和多因子评分；本次仅执行新信息的有限来源核对，不运行金融模型或账户。

假设：离岸USD/CNH报价相对同一统计日已公布USD/CNY中间价的偏离，包含单独汇率涨跌或美元／利差回归残差没有直接表达的价格差异。它是候选背景信息；是否改善点位和账户，尚未验证。

本用途与旧人民币残差研究不同：不估计美元和两国利率对离岸汇率的回归，不复用旧周首日、残差负号或五日持有规则。旧研究SOURCE_GATE_NOT_PASSED和ACCOUNT_NOT_RUN保持。本用途也不是同步在岸／离岸即期市场价差：官方中间价不是在岸成交价；离岸UTC日BID末价与中国09:15定盘不同步。不能将偏离直接称为资本净流入、外生意外或政策意外。

来源和预算先固定：复用原2808行Dukascopy USD-CNH BID报价及原CFETS中间价；只对2015和2018两个此前本地未覆盖年份各发一次相同品种年度GET。请求地址为原供应商https://jetta.dukascopy.com/v1/candles/day/USD-CNH/BID/{year}，超时20秒、TLS校验开启、不自动重试、不换域、不使用凭据或付费接口。原输入及旧失败不覆盖。

逐年响应仅使用原已保存的差分报价解析规则，验证UTC日线、同年、正报价、OHLC顺序和唯一时间；失败保留原响应及原因。以相同源日期的离岸末价和中间价计算10000×log(CNH_BID_CLOSE/CNY_FIXING)，单位为对数比的基点，不是报价点数。缺失中间价不补。两个市场实际时刻仍分别保存。

全部新派生资料统一保守到源日期后第二个自然日23:59（上海）才可使用；同时必须不早于报价柱结束和中间价原可得时钟。按原3488日历16:00观察、最长源龄7自然日；过期或缺失保持未知。五日变化仅在连续六个ETF观察槽已知时计算。不改变原金融观察时钟或策略。

在原17关键日保存同钟技术与汇率背景；核对全日历及每年覆盖，不读取首次边界标签、不生成未来收益、不根据案例选择方向、阈值、窗口或权重。只有两个年度响应合格并完成来源合同后，才另行登记完整金融用途；本核对不能将新因子晋升为可交易策略，也不能宣称独立验证或去过拟合。
