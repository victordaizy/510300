# 510300 未来20日上涨机会信息质量预算 V1 冻结规范

## 1. 研究定位

本实验承接 `510300_KNOWN_STATE_POLICY_ORACLE_V1_0_1`，但不修改、营救或重新解释原 Oracle 结果。原结果已经证明：若在区间起点完美知道未来20日是否上涨至少5%，只在大涨区间持有510300、其余时间持有现金，压力成本净夏普为1.740。

本实验只回答后续工程问题：从该完美信息上界出发，一个不完美预测器可以漏掉多少大涨、误入多少震荡和大跌、晚多少天进入、提前或延后多少天退出，以及承受多少信号反复，压力净夏普仍能达到1.2。

Oracle结果已经可见；因此本项目不是盲测。冻结对象是误差网格、随机种子、对抗排序、时序扰动、稳健性统计和晋级门。冻结后禁止根据输出修改这些定义。

## 2. 预测问题压缩

主动作空间只有两个动作：

| 真实未来20日状态 | 动作 |
|---|---:|
| `BULL_TREND`，H00300未来20日全收益不低于+5% | 100%持有510300 |
| `RANGE` | 现金 |
| `BEAR_TREND` | 现金 |

因此现实任务不是普通三分类，而是成本敏感的稀有事件预测：

\[
Y_t^{UP20}=\mathbf 1(R_{H00300,t\rightarrow t+20}\ge 5\%).
\]

区间级精确率、上涨召回率、震荡误入率和大跌误入率必须分开报告。总体准确率不进入任何晋级门。

## 3. 固定账户与执行合同

- 只允许510300与人民币现金；不卖空、不加杠杆、不使用衍生品；
- 初始资金20,000元，100份整手；
- 信号日收盘形成目标，下一交易日开盘执行；
- 单边佣金3bp且最低5元，单边压力滑点10bp，印花税0；
- 分红按原回测引擎在除息日确认应收、发放日转现金；
- 所有误差组合都重新经过完整账户回测，不以分类统计量或区间收益简单相加替代。

## 4. 随机误差预算

随机预算采用“状态内固定数量、无放回均匀抽样”，而不是独立伯努利后再接受数量漂移。每个单元重复500次，固定种子为`51030020260831`。

三个逐轴预算穷举所有整数数量：

1. 只改变捕获的大涨区间数0—23，震荡和大跌误入均为0；
2. 捕获全部23个大涨，震荡误入数从0—97，大跌误入为0；
3. 捕获全部23个大涨，震荡误入为0，大跌误入数从0—21。

联合误差网格固定为：

- 捕获大涨数：`4, 8, 12, 16, 20, 23`；
- 误入震荡数：`0, 5, 10, 20, 40, 97`；
- 误入大跌数：`0, 1, 2, 4, 8, 21`。

每个单元报告压力净夏普、总收益、CAGR、最大回撤、平均仓位、交易腿数的中位数、5%分位数和95%分位数，并报告夏普不低于1.2的概率。

随机单元只有同时满足以下条件才算通过：压力夏普5%分位数不低于1.2、达到1.2的概率不低于95%、总收益5%分位数为正、最大回撤落在原始全仓回撤80%以内的概率不低于95%。

## 5. 对抗性误差预算

对抗排序使用510300从T+1开盘到下一阶段执行开盘、含持有期分红的可执行毛收益：

- 漏判大涨时，优先漏掉可执行收益最高的大涨区间；
- 误入震荡时，优先加入可执行收益最低的震荡区间；
- 误入大跌时，优先加入可执行收益最低的大跌区间。

三个逐轴预算仍穷举所有整数数量，联合预算使用与随机实验相同的冻结网格。对抗单元必须同时满足压力净夏普不低于1.2、压力总收益为正、最大回撤不超过原全仓最大回撤的80%。

## 6. 进入、退出与反复交易预算

相邻的大涨区间先合并成连续上涨事件，再在事件边界施加误差：

- 进入延迟：事件开始后晚0—10个交易日形成买入信号；
- 提前退出：事件预定结束前0—10个交易日退出；
- 延后退出：事件预定结束后0—10个交易日退出；
- 信号反复：在真实非大涨现金窗口中插入持有1个交易日的错误往返。

随机反复交易先对全部候选窗口生成均匀随机优先序，再按该优先序贪心选择互不重叠的一日窗口；对抗反复交易按一日可执行收益从低到高贪心选择互不重叠窗口。`MAX_ACCEPTABLE_WHIPSAW_LEGS`按买入和卖出各一腿计数，并采用“从0开始连续所有更小数量均通过”的边界，防止跳跃选择偶然通过点。

## 7. 四项Oracle稳健性附件

### 7.1 二十种阶段起点

固定报告`offset=0…19`全部相位的±5% Oracle压力净夏普、总收益、最大回撤以及三态数量。不能选择最佳相位作为策略。

### 7.2 标签与可执行区间基差

逐区间同时报告H00300的T收盘至T+20收盘标签收益，以及510300的T+1开盘至下一阶段执行开盘、含分红的可执行毛收益。另报告ETF同端点收益、不可交易的入场隔夜和实际退出隔夜，用来量化标签目标、跟踪差异和执行时钟之间的基差。

### 7.3 序列相关调整

除普通日度年化夏普外，固定报告月度复合收益夏普、非重叠20日组合收益夏普，以及Bartlett权重、最大滞后20日的Lo/HAC调整夏普。

### 7.4 连续行情集中度

相邻大涨区间合并为独立上涨事件。报告事件数、各事件对总对数财富的贡献、去除最大一轮和最大两轮后的压力净夏普，并以完整上涨事件路径为抽样单位做10,000次bootstrap。现金日补零，使每次bootstrap的观测天数固定为2,823日。

## 8. 必须交付的工程预算

结果至少给出以下字段，并同时附上严格定义和对应场景：

- `MIN_UP_PRECISION_FOR_SHARPE_1_2`：冻结联合随机网格中通过95%稳健门的最低区间精确率，必须同时给出对应召回率与两类误入率；
- `MIN_UP_RECALL_FOR_SHARPE_1_2`：零误入逐轴实验中通过的最低上涨召回率，随机与对抗分别报告；
- `MAX_DOWN_FALSE_LONG_RATE`：捕获全部上涨、无震荡误入时可承受的大跌误入率；
- `MAX_RANGE_FALSE_LONG_RATE`：捕获全部上涨、无大跌误入时可承受的震荡误入率；
- `MAX_ENTRY_DELAY_DAYS`：完美区间标签下仍连续通过的最大事件入场延迟；
- `MIN_ORACLE_RETURN_CAPTURE`：通过场景相对完美Oracle的压力净对数财富捕获比例；
- `MAX_ACCEPTABLE_WHIPSAW_LEGS`：对抗性一日错误往返下仍连续通过的最大额外交易腿数。

这些值是本历史样本和冻结误差结构下的工程预算，不是未来预测器已经达到的性能。

## 9. 保守晋级门与治理边界

只有当冻结配置中的保守晋级门全部通过，结果才允许写作“存在足够宽的历史信息预算，值得启动低自由度UP20预测器”。否则只能写作“完美信息有价值，但历史可实现空间狭窄或稳健性不足”。

无论是否通过，本研究都不训练现实预测器，不实现Paper/Shadow，不生成持仓、订单或实盘授权，且整体“可交易策略夏普1.2”目标仍未完成。
