# 多资产年化净超额40个百分点与高夏普V6修正规范

## 已登记终态

美国杠杆多资产绝对动量V1在冻结清单验证通过后的唯一正式可见期运行中，于计算策略绩效前触发 `FAILED_DATA_OR_EXECUTION_CONTRACT`。冻结错误为“评价日严格滞后美元汇率超过冻结陈旧上限”：中行折算价历史镜像在2015年1月缺失至1月29日，最长陈旧32天；此外中国国庆等法定长假会自然形成约10天没有新人民币牌价的区间。V1没有形成净值、收益、夏普或超额，不得把失败解释为通过或拒绝。

## 唯一允许的修正

V6只允许一个V1R数据契约修正版。人民币兑美元来源改为中国外汇交易中心公布的官方USD/CNY中间价，仍严格使用日期早于美国交易日的最近观测；最大陈旧期由7个自然日改为14个自然日，仅用于覆盖中国法定长假。中间价不是可成交即期价，基础10bp、压力30bp的首次与期末汇兑点差保持不变。

除此之外，UPRO、TQQQ、TMF、UGL固定产品集合，2014—2019可见期与2020—2026封存期，252日动量、200日趋势、月频次日开盘、前两只各50%、整数股、拆分、30%现金分配预扣、容量、退出、17/47bp证券成本、H00300基准、40个百分点净超额和1.50净夏普硬门全部必须逐字段保持不变。

修正版必须在读取可见期策略结果前冻结。可见期未完整通过时，不得再改汇率源、陈旧期、产品、日期或信号救回，封存复验保持关闭。Paper、Shadow、订单、券商连接和实盘始终关闭。
