# 第112轮：中点移动、日内区间和成交量的固定进出场

只登记一个简易波动策略。主因子把价格区间中间位置的变化、区间宽度和实际成交份额结合，属于价格与成交量的关系；它不是公募净申购、主力流入或盈利预测。

## 因子定义

先把每日最高价、最低价转换成与已有含分红财富收盘相同的连续尺度：最高价或最低价加当日已确认每份分红，再除以当日收盘价加分红，最后乘当日财富指数。这避免原始除息价差被当成价格区间下移。交易仍用原始真实价格。

每日取转换后最高和最低位置的平均数，作为区间中点。用当日中点减前一交易日中点，再乘当日高低区间宽度，除以实际成交份额，并乘固定的一亿作为数值单位。最后取连续十四日的简单平均，就是唯一的信号指标。

中点上移贡献为正、下移贡献为负，区间越宽、成交量越小，对平均值的影响越大。固定正数缩放只改变数值大小，不改变过零信号。十四日定义参考[TradingView官方说明](https://www.tradingview.com/support/solutions/43000502256-ease-of-movement-eom/)，中点变化、区间、成交量及零线用法参考[thinkorswim官方说明](https://toslc.thinkorswim.com/center/reference/Tech-Indicators/studies-library/E-F/EaseOfMovement)。这些来源提供指标定义，不能证明本项目有超额收益；TradingView也提醒该指标通常用于辅助确认。本轮独立检验这一固定规则，不借用来源作盈利背书。

当天高低价、收盘价、分红、财富指数和成交量必须完整。成交量必须为正，价格位置必须有效；正常的零高低区间贡献为零。缺失输入保持未知，由它影响的中点差及整个十四日窗口保持缺失，不删除交易日、不跳过缺失求平均。首次完整十四日均值之前不交易。

## 进入、持有、退出

空仓时，只有前一交易日完整指标小于或等于零、当日完整指标严格大于零，才形成新的进入意图。按收盘时实际现金、买入滑点、最低佣金和整手限制，计算最大可买份额，在下一交易日真实开盘请求买入。不能把一直为正、缺失后恢复为正或准备期首个正值当作新的上穿。

持仓期间，只要指标仍为正就保留原有份额，不追加、不部分卖出。指标回到小于或等于零时，请求下一真实开盘全部卖出。退出意图一旦形成就保持，直到实际卖出完成；不能被之后转正或缺失取消。无额外止盈、止损、期限或冷却参数。

指标未知时不新进入或新退出，保留实际已有份额；原先已锁定的退出请求继续。买入请求若未成交，不因为指标仍然为正持续追买，必须等待下一次真正由非正转正。实际现金不足一手时等待。完全退出后，同样要求新的零线上穿才再次进入。
