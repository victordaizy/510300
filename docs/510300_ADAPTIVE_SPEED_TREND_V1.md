# 第48轮：均线随方向效率自动调整反应速度

## 研究问题与两个设置

检验行情单向推进时加快反应、来回震荡时减慢反应，能否改善完整账户。这一轮使用已有日线，不补数据、不训练未来收益模型。按当前研究文件中的自适应均线和考夫曼均线名称检索，没有找到同一进出场设计；既有方向效率因子和固定均线策略已有结果，本次的新变化是将方向效率放进每天的递推速度。

预定主方案为自动调整速度；对照把方向效率固定为一半，其他初始化、进出场、手续费与账户完全一致。共两个新设置，不搜索速度参数或确认天数。底层参考[TA-Lib的考夫曼自适应均线实现](https://github.com/TA-Lib/ta-lib/blob/main/src/ta_func/ta_KAMA.c)中的效率调速思路，以下零波动、缺失和交易规则是本轮明确约定，不宣称逐点等同于软件默认输出。

## 所有因子如何计算

使用510300已有含分红总回报水平作为可比收盘价。每日简单总回报为当天未复权收盘价加每份除息分红，除以前一收盘价，再减一；把每日总回报连续累乘得到总回报水平。成交仍使用原未复权价格，分红按实际权益和到账记账。

第一项是十日方向效率。取当日总回报水平与十个交易日前水平之差的绝对值，除以这十个交易日每日水平变化绝对值之和。它位于零至一之间。完全单向推进时接近一，反复往返时较低。连续十日完全不变、分母为零时规定效率为零；原始价格缺失不适用这一零值约定。

第二项是当天反应系数。最快基础速度为三分之二，最慢基础速度为三十一分之二。先用“最慢基础速度，加上方向效率乘以最快与最慢基础速度之差”，再把所得数平方。方向效率为零时反应系数约0.004162，效率为一时约0.444444。两者来自固定的快周期2、慢周期30；十日效率窗口同样事先固定。

第三项是递推均线。当日均线等于上一日均线，加上当日反应系数乘以“当日总回报水平减上一日均线”。第一次有十个完整交易日变化时，以上一日总回报水平作为递推起点。数值每日连续递推，在2015年和2020年账户起点不重置。

第四项是价格相对均线的位置：当日总回报水平高于均线、低于均线或恰好相等。这个位置只在该日收盘后可知。

固定速度对照把第一项效率始终规定为0.5，按同样公式算出一个不变的反应系数，约0.133657。它与主方案使用相同起点和价格；并不是从历史收益里挑出的最优固定均线。

输入必须包含连续十个交易日变化所需的十一条有效正价格。任一缺失会中断递推，本日因子为“资料不足”。恢复连续完整窗口后，重新以上一日价格初始化；不把缺失填成价格、零收益或仓位。两个确认收盘也必须各自有效，不能跨越缺失拼接。

## 进入、持有、退出和重新进入

空仓时，连续两个交易日的总回报水平都严格高于各自当日均线，在第二个收盘后请求下一交易日开盘买入现金能够负担的100份整数倍。每天重新检查；没有等待未来收益才决定进入。每个持仓周期只买一次，持有时不追加。

持仓时，连续两个交易日的总回报水平都严格低于各自当日均线，在第二个收盘后请求下一交易日开盘全部卖出。只有一天在均线下方，或者恰好等于均线时，继续持有。没有额外固定止损、止盈或最长持有天数。

卖出受涨跌停或可卖份额限制时，原退出请求保留到实际卖完，后来价格回升也不取消。实际卖完后的收盘，如果又满足两日上方条件，可请求再下一开盘进入；不在同一开盘卖出又根据尚未发生的收盘买回。没有额外冷静期。

因子资料不足时不新进入，已有份额保持；之前已经产生的退出请求仍执行。数据不完整不等于空仓指令。研究终点在开盘请求退出，按同一实际成交模型处理。

## 完整账户与验收

主评价固定为2020年1月2日至2026年8月14日开盘，1604个账户日；较早诊断为2015年1月5日至2019年12月31日开盘，1219日，各从20万元现金开始。只有510300和现金，年化242日，现金及无风险收益均为零。保留空仓日、100份整手、0.001元价格跳动、买入次日可卖、方向性涨跌停、实际分红权益、应收和到账。

基础费用为佣金万分之二、每笔最低5元、滑点万分之五；压力费用为佣金万分之四、每笔最低5元、滑点千分之一。不改变起止日期、年化方式和费用来达到1.2。

每个时期计算两个新设置、两档费用，共4个新账户；复用原线性退出及等待新机会、原急跌与学习信号各半、买入持有，三个对照两档费用共6个旧账户记录。每期合计10个，两个时期共8个新账户、12个复用记录。固定速度对照是新设置，计入历史尝试数量；不存在新模型拟合。

先验证未来数据不会改变过去因子、单向和来回路径的速度、缺失中断、两个不同收盘确认，再计算全部账户。逐年、分阶段和两档费用全部保存。两个时期的历史均已看过，结果属于新的方法在已有历史上的重放，不作为独立验证。

若没有跨时期改善，不继续搜索该均线的邻近效率窗口、快慢周期或确认天数。净夏普1.2与稳定超额目标保持，不能用指标名称或少数盈利年份代替完整结果。
