# 510300解禁公告密度：单次固定增量试验

目标仍是只持有510300与人民币现金，成本后复合年化至少10%、净夏普至少1.2，并取得独立验证。本研究没有杠杆、做空、期货交易或其他可交易资产。允许读取其他上市公司的免费公告作为信息。IF、AH、EPU和旧价格策略结果保持冻结，不拼接它们的好年份。

## 原始来源与唯一新变量

来源阶段先完成2015-01-01至2026-08-14的140个月查询覆盖。33,722个唯一公告中17,745个符合事前固定标题规则，128个更正/取消/延期等标题另存、不混为原始公告。分页失败、连接失败以及一秒时间元数据变化均保留。仅公告日粒度准入，不把该档案称为历史分钟首发凭据。历史成员名单已有2015—2026正式准入，使用名单不用尚未准入的历史权重。

公告可用时间假设为上海公告日加两个自然日的00:00。它在之后首个内地交易日15:00原点进入可用事件集；下一交易日09:30才可能执行。该延迟是历史研究假设，不是已经证明的过去网页到达时间。所有原始标题、日期和文件身份保留在来源包。

唯一新增变量为：在当前原点生效的300个沪深300成员中，过去20个交易原点内至少有一份合格解禁公告变为可用的不同公司数量，除以300。同公司多份公告、多次出现都只按窗口内一家公司计数。新加入指数的公司可以携带当时早已公布且仍在窗口内的公告；公司已经退出则从当日变量中移除。容器中出现未来成员代码不会授予其过去成员资格，逐日名单独立遮罩控制实际入选。

这项变量衡量披露活动集中程度，不度量解禁数量、股份出售、交易资金流或指数权重。标题筛选并未宣称涵盖所有可能的解禁事件，结论只适用于固定标题集合。

## 配对预测与时钟

2015-03-02起扩展训练，2020-01-02起评价，行情统一截至2026-08-14。M0为ETF 1/5/20日含分红收益、20日方差对数，以及当前自然月的正弦/余弦季节控制；M1只加上述公告变量。两个模型使用相同成熟训练原点，每次月首预测重新拟合。标签为20万元在下一开盘买入、五个交易日后开盘卖出的基础成本净收益；退出日必须严格早于本次模型原点。最少756个成熟训练日，训练集内标准化并裁剪至±5标准差，岭罚0.1，截距不惩罚。

不在真实标签上选窗口、选择正负方向或调罚项。连续每日五日标签有重叠，检验采用63个交易日循环分块、2000个固定随机样本，种子20260914。保留完整日历再抽样；报告2020—2021、2022—2023、2024—2026三个时期。方向准确率、正负预测下的真实净收益以及下跌识别召回率一起报告，不能把日线行数全视为独立新闻样本。项目级多轮研究选择偏差没有被这个局部区间消除。

## 完整账户与继续条件

无论预测显著性是否通过，都计算M0、M1、仅波动控制、买入持有四个基线/模型，在基础与压力成本下合计8个账户。初始20万元，100份整数手、0.001元价位、现金收益和无风险收益均假设0；不借款，遵守T+1和可成交限制。分红按登记、除息应收与到账分别记账，现金不能提前支出。基础单边佣金万二最低5元、滑点万五；压力佣金万四最低5元、滑点千一。

M0/M1预测的五日成本后收益大于0时，目标权重为min(1,10%/ETF20日年化波动)，否则现金；五个交易日才决定一次，以原点价格确定整数份额，下一开盘执行。仅波动控制永远使用同一个波动预算，不含公告或择时方向。统一在最后一个完整五日周期的开盘清算，不拿不完整尾段改善结果。

继续条件有两个固定入口：A，M1配对MSE改善的95%下界大于0，三个时期至少两个改善且覆盖充足，同时M1压力账户年化为正、相对M0的平均日收益增量为正；B，M1压力账户相对M0及仅波动控制的配对日收益增量95%下界均大于0，并在三个时期中至少两个同时优于两者。区间是实际账户日收益差，不是中性化仓位回归的alpha。

两个入口都失败即 `REJECTED_FROZEN_NO_RELIABLE_UNLOCK_ANNOUNCEMENT_INCREMENT`，不反转信号、不换五日标签、不改20日窗口、不择取年份、不调仓位救援。通过只留下历史信息候选，尚无独立未来验证；即使历史压力点估计达到两个目标，也不记总目标完成。所有实际结果、失败回执和0/未计算状态随GPT审阅包交付。
