# 510300 衍生品压力释放 V2：全 IF 合约聚合持仓量

## 裁决边界

本版本是 `510300_DERIVATIVE_PRESSURE_RELEASE_V1` 之外的独立预冻结数据构造版本，不修改、不覆盖、也不“救回” V1。V1 继续保持 `NO_VIEW_FROZEN_UNCHANGED`。

V2 最多运行一次。运行前必须存在内容哈希匹配的冻结清单；冻结后禁止修改窗口、阈值、权重、候选条件、确认条件、退出时钟或数据代理。若这次历史发现筛查没有达到冻结的历史通过门，公开日频衍生品压力代理资源族立即关闭，不得继续创建 V3/V4/V5。

## 唯一改动

持仓量定义改为当日全部尚未到期且官方持仓量大于零的 IF 合约之和：

```text
OI_aggregate(t) = sum(OI(c,t), expiry(c) > t and OI(c,t) > 0)
Delta_OI_aggregate(t) = log(OI_aggregate(t)) - log(OI_aggregate(t-1))
```

到期日的合约不进入当日聚合值；任一 IF 合约到期日硬性不产生新信号。聚合持仓缺失的日期为 `NO_VIEW`。

## 保持不变

- 四分量压力：`-z(年化基差) + z(聚合持仓变化) + z(PutSkew) + z(VRP)`。
- 每个 z 值只用此前 252 个交易日，且至少需要 252 个有效历史值。
- 极端 ETF 下跌、压力上尾、同近月合约基差走弱、聚合持仓增加的候选条件。
- T+1 的 09:30–09:44 确认，09:45 进入，T+2 09:45 固定退出。
- 20 万元、双边佣金、单边 5bp 压力滑点和单边 10bp 双压力滑点。
- 历史结果只能筛除明显不成立的分支，不能直接激活持仓。

## 评价顺序

1. 先构造聚合持仓、四个标准化分量及压力序列。
2. 只有此前 252 个有效压力值能够形成压力 95% 分位数，才允许构造候选并读取入场/退出收益。
3. 特征构造失败时输出 `NO_VIEW_FEATURE_CONSTRUCTION_FAILED`，不把零候选解释成经济结论。
4. 少于 40 个成熟事件时保留科学上的样本不足，但资源状态仍按一次性 V2 规则关闭。
5. 达到 40 个事件后，任何原冻结门不通过均为 `REJECTED_FROZEN`；全部通过也只能进入零仓位前向 Shadow。

## 交易隔离

本版本始终满足：`POSITION_IMPACT=0`、`ORDER_GENERATION=false`、`BROKER_CONNECTION=false`、`LIVE_TRADING=false`。任何历史通过都不构成实盘授权。
