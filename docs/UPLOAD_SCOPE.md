# 上传范围与原始内容保留

本次整理针对当前 `New project 8` 中关于 510300 的材料。共收录 196,577 个原始文件；精确范围以 `catalog/files-*.csv` 为准。

## 包含规则

- 路径直接涉及 510300、沪深300、CSI300、000300、H00300 或既有明确别名的研究材料；数字代码按边界匹配，避免把长编号中的偶然数字当成标的。
- 控制文件、代码和研究说明中明确涉及 510300 的资料，以及对应研究目录的完整结果。
- 510300 共用的行情、成分、宏观、期货、流动性、基金与官方来源数据。
- 已选材料明确指向的本地文件及 Python 代码导入依赖；公共模块和对应既有测试。
- 与 510300 相关的历史完整交付包及其原有上下文。原包可能包含跨市场或其他研究材料；为保持原包身份，不改写其内部内容。

汇总决策文档、历史打包脚本或研究对照中的一次提及，不会把全部其他独立研究目录作为新文件展开上传。全市场公共来源库仅按已确定的共用范围或具体依赖收录，不把整个项目硬盘镜像当作 510300 研究范围。

## 常规排除

排除 `.env` 等本机凭据文件、虚拟环境、Git 内部目录、代理应用运行目录、解释器和测试缓存、迁移残留、临时抓取文本，以及未发现 510300 关联的独立研究文件。数量与目录级原因见 `catalog/exclusions.json`。

原项目的 `data` 为指向 E 盘的 Windows Junction。本次读取其实际研究数据，并在发布目录中以普通文件及可还原归档保存；不把 Junction 本身提交到 Git。

盘点中有一个独立 A 股研究历史包的展开副本目录拒绝访问，该目录不在所选范围内；其路径记录在排除说明中。此情况没有被写成“扫描整个硬盘无遗漏”。

## 字节与状态

包含范围按本次盘点清单固定，盘点清单的保存时间见 `catalog/snapshot.json` 的 `selection_inventory_saved_at`。原始材料按字节读取；每个文件记录大小和 SHA-256，并检查读取前后文件大小、修改时间一致。索引还记录盘点后到实际读取时是否发生变动。此语义是按文件获取稳定内容的快照，不是暂停全项目进程后取得的同时点全盘镜像。盘点后由其他任务新建的材料不自动扩大这个固定快照的范围。

没有改写冻结结果、格式化历史代码或转换原始文件换行。原项目的既有 Git 历史和工作分支继续保留在本机；本仓库用一个新的明确快照导入当前相关文件。

本次执行必要的上传范围检查、文件摘要和附件结构验证；没有开展全面安全审计，也没有重新验证每一项来源权利、研究统计结论或外部审阅说法。
