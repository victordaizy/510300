# VAL-04 PB—ROE 残余收益数据可行性 V2 补充协议

## 1. V1 失败证据保持不变

V1 使用中信一级点时区间。其 120 个月中只有后 80 个月通过，2016-08 至 2019-11 的行业权重覆盖约 28% 至 33%，因此 V1 状态永久保留为 `NO_VIEW_DATA_GATE_FAILED_MODEL_FIT_FORBIDDEN`。V2 不修改 V1 配置、清单、报告或输出。

## 2. 唯一修订

V2 只把行业固定效应的数据源改为申万一级点时区间：

- 文件：`data/raw/reference/a_share_sw_industry_static.parquet`；
- 实际语义：`POINT_IN_TIME_INTERVAL`，文件名中的 `static` 是历史遗留命名；
- 来源：`tushare_proxy.index_member_all`；
- 供应商采集报告状态：行业阶段 `PASS`；
- 2019-12-23 至 2026-08-14 成员日覆盖 99.667%，重叠率 0；
- 原始区间包含 SW2014 与 SW2021 的进入、退出和分类切换，不向历史回填当前行业。

其余全部冻结不变：120 个月窗口、价格、财务 vintage、Growth 定义、覆盖门槛、设计矩阵门槛以及“120/120 全通过”要求均不变。

## 3. 验收附加条件

除 V1 的全部月度闸门外，V2 还要求：

1. 采集总报告存在且输入哈希匹配；
2. 行业阶段状态为 `PASS`；
3. 供应商成员日覆盖不低于 99%；
4. 行业区间重叠率不高于 0.1%；
5. 实际行业记录全部标记为 `POINT_IN_TIME_INTERVAL`。

这里的分析师 E1 限制与 VAL-04 无关，因为模型不使用分析师预测。

## 4. 治理边界

V2 仍然只做数据可行性审计。通过只表示允许另行冻结模型卡，不表示模型有效；本阶段仍禁止未来收益、残差信号、IC、策略收益、仓位和订单。
