# 行业预期差—ETF模型 V2：板块分层与可得数据补齐规范

## 1. 为什么必须重构板块分割

中信一级行业适合承接财务和行业景气证据，但不能单独回答“科技、先进制造、内需、地产链、顺周期”等投资问题。主题标签又天然重叠，如果直接相加，会把同一行业和同一只成分股重复计算成虚假的指数暴露。

V2因此保留三套互不替代的视图：

1. **中证CICS一级行业**：官方当前截面，互斥且合计100%，用于校验沪深300真实的大类权重。
2. **经济引擎**：将首期25个当前中信一级行业一一归入互斥大类，用于历史收益、资金流和预期差聚合；历史上出现但当前权重为零的退出行业仍保留唯一归属，不回填为当前权重。
3. **主题链**：科技、AI与数字基础设施、新质生产力等允许重叠，只报告各主题自身的核心和邻接覆盖，禁止跨主题求和。

## 2. 科技的两个口径

- **官方口径**：中证CICS的`Information Technology`与`Communication Services`分开报告；可同时展示二者合计，但必须保留分项。
- **研究口径**：核心科技为电子、计算机；科技大类主题再加入通信、传媒。这样不会把电信运营、通信设备、互联网内容和半导体硬塞成一个同质行业。

科技大类不是一个新的可交易指数，也不代表所有成分股的科技收入占比。它只是当前25行业底图上的主题覆盖。

## 3. 数据补齐边界

本次可补到2026-08-18的完整收盘数据：

- 300只成分股未复权日线与复权因子；按交易日整市场提取后筛选沪深300，避免逐股高频请求。
- 中信一级行业指数当日行情，作为成分股行业收益的独立方向交叉核对。
- 300只成分股订单分类资金流；明确不是ETF资金流，也不能推断交易者身份。
- 510300份额；份额变化只作为申赎活动代理，不等于精确现金净流入。
- 510300融资融券；按提供方实际最新日保留过期天数，不把未发布的8月18日伪造为已发布。
- 中证官网CICS一至四级当前权重快照；只把一级行业用于官方宽板块权重。

## 4. 仍不能补的字段

- 国家队实时持仓和实时交易：公开披露是季度或事件型，且账户身份需要逐条审核，不能由大单资金流反推。
- 点时一致预期历史：当前数据库或单篇研报不能回填成当时可见的一致预期快照。
- 主题成分股收入暴露：行业归属不是业务收入拆分，主题邻接权重不得解释成精确收入敞口。

上述缺失统一输出`UNOBSERVED`或`NO_VIEW`，并保留最新数据日和失败类别。

## 5. 结论边界

V2补齐的是当前板块底图、价格位置、订单分类资金流和主题覆盖，不改变V1已冻结的行业预期判断，也不把历史相似样本包装成未来预测。任何方向结论仍需前瞻记录成熟后做消融和失败检验。

全系统保持`RESEARCH_ONLY / SHADOW_ONLY / NO_POSITION_CHANGE`。
