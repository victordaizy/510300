# 第31轮：用已经结束的持仓周期学习退出

## 要解决的问题

此前第5轮直接效用模型以市场因子学习目标仓位，第9轮按市场状态学习不同机制的权重，前瞻盈利退出版本使用期限和趋势条件；这些实现没有把实际持仓天数、含分红浮盈浮亏和周期回撤作为退出学习输入。本轮保留三个固定入场策略，增加一个根据持仓状态学习的提前退出条件，不新增行情或盈利来源。

两种退出模型乘三个入场策略，共六个新设置。预定主方案为“趋势突破与震荡反弹切换＋线性退出模型”。不能按结果更换主方案。沿用旧规则的三个账户和买入持有作为对照。

## 保持不变的三个入场及基础退出规则

所有价格因子以含分红总回报水平计算；收盘后判断，下一交易日开盘请求买入现金能够负担的100份整手。持仓内不追加。模型只增加提前退出条件，以下原退出规则全部保留，退出意图持续到实际卖完。

|入场策略|进入条件|原有退出条件|卖出后的重新进入|
|---|---|---|---|
|趋势突破与震荡反弹切换|总回报高于一百二十日均线且二十日方向效率大于0.3时，处于强趋势，突破此前二十日最高收盘总回报则进入趋势模式。其余状态中，低于二十日均值1.5个样本标准差且当日回升时进入反弹模式。|趋势模式在强趋势条件消失、跌破此前十日最低收盘水平、含分红持仓亏损8%、或从持仓最高收盘价值回撤8%时退出；反弹模式在转为强趋势、恢复至二十日均值、亏损5%、或持有十个交易日时退出。|实际卖出后至少经过两个交易日，收盘再次满足进入条件才发出下一开盘买入请求。|
|偏离均值后首日回升|低于二十日均值1.5个样本标准差，且当日总回报上涨时进入。|总回报恢复至二十日均值、持仓亏损5%、或持有十个交易日时退出。|实际卖出后至少经过一个交易日，再按原条件进入。|
|六十日日内强于隔夜|日内对数涨跌减隔夜对数涨跌，六十日差异之和除以这六十日每日差异样本标准差及六十的平方根；这一值连续两日大于1时进入。|上述值连续两日小于零、持仓亏损6%、从最高收盘价值回撤8%、或持有六十个交易日时退出。|实际卖出后至少经过两个交易日，再按原条件进入。|

方向效率等于二十日总回报水平的绝对净变化，除以该期间每日变化绝对值之和。总回报标准化偏离等于当前水平与二十日均值之差，除以二十日水平的样本标准差。日内部分为收盘相对开盘的对数变化；隔夜沿用分红一致的既有分解。

## 退出模型使用的八个因子

|因子|中文计算方法|
|---|---|
|持仓时间|从实际买入日到当前收盘的交易日数，买入当天为1；对“一加天数”取自然对数。|
|含分红浮盈浮亏|当前份额乘当前收盘价，加本周期已确认的分红，除以实际买入总成本，再减一；买入总成本包含买入佣金。|
|持仓回撤|上述含分红持仓价值，除以从买入到当前的最高收盘持仓价值，再减一；最高价值初始至少为买入总成本。|
|入场模式|原策略趋势模式和单一模式记为1，趋势与震荡切换中的反弹模式记为2。|
|五日涨跌|截至当前收盘，最近五个交易日含分红对数收益之和。|
|二十日涨跌|截至当前收盘，最近二十个交易日含分红对数收益之和。|
|一百二十日均线偏离|当前总回报水平除以一百二十日总回报均值，再减一。|
|二十日波动|最近二十个交易日含分红简单收益的样本标准差，乘以242的平方根。|

## 学习目标和历史可用时间

先让三个原策略分别从2013年6月3日开始按基础费用完整模拟，形成连续参考账户；信号资料不足时不进入。这三个账户仅用于建立历史学习样本，不替代2020年开始的主评价。原参考持仓的入场、退出均按当时信息生成。

每个原参考周期内，只对“已持有、原规则尚未要求退出、且距原实际退出至少还有一个完整开盘间隔”的收盘记录生成训练样本。学习目标是：继续按原参考周期持有至其实际退出，比下一开盘立即卖出、之后持现金，能够多获得多少收益。两个卖出方案各扣基础佣金、滑点及价格单位损失；买入成本是双方共有的，不重复扣。差额除以下一开盘时该份额的未扣费市值。

两方案的分红差额只包括“下一开盘卖出日及其后、原退出日之前”的股权登记日所新增的权益。下一开盘之前已经获得的分红权益属于双方共有，不能因为除息或到账发生得晚就误加到继续持有收益中。比较标签是假设下一开盘能按规定价格卖出，不证明限价排队或真实成交；实际研究账户仍保留未成交。

一个周期的全部训练记录，只有在该原周期实际退出日的收盘之后才可使用。同一尚未结束周期中的已发生日，不能提前进入训练。因研究终点强制退出的周期不作为成熟自然退出样本。

每月首个交易日收盘重新训练；使用当时已经自然结束、且有合格训练记录的最近20个参考周期。至少需要10个周期和100条合格持仓日记录，否则该月没有模型。每个周期的训练权重总和为1，周期内每条记录均分权重，避免长周期仅因天数多而占据更大权重。训练、标准化和决策都保存日期及周期清单。

这是以既有参考策略为基础的监督学习近似。提前退出可能改变以后能进入的日期和实际资金，因此新账户可能走出不同路径；模型对参考周期以外状态的适用性需要通过完整账户结果检验，不能从训练拟合直接推出有效。

## 两种模型及新增退出规则

线性模型先按训练权重计算八个因子的均值和标准差；零标准差改用1。减均值、除标准差后，将输入限制在负5到5之间，再用带系数惩罚的线性回归预测上述继续持有收益。系数惩罚强度固定为1，截距不惩罚。每月的实际截距、系数、均值及标准差均保存，中文说明对应每个因子。方法定义参见[岭回归官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。

浅层决策树直接使用八个原始因子，最多两层判断，每个叶节点至少20条训练记录、至少占训练总权重的10%；固定随机种子20260907。每个叶节点输出该类历史状态继续持有收益的加权平均值。全部月度树规则保存为中文条件句。参数含义参见[回归树官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.tree.DecisionTreeRegressor.html)。

两种模型使用相同退出阈值：当前周期连续两个收盘的继续持有收益预测均小于零，就请求下一开盘全部退出。预测为零或正数、缺少模型或因子不完整时，负值连续计数归零，不增加学习退出条件，继续执行原规则。没有模型不等于预测收益为零，也不等于清仓。

新周期重新开始计数；每个账户按自身实际买入日期、成本、持仓和最高收盘价值形成因子。基础和压力账户共享当时训练完成的模型，但因实际账户成本和路径可能不同，预测输入及结果允许不同。退出受阻时保持原退出意图，不因之后预测转正而撤销。

## 固定账户口径与评价

只研究510300与现金。主评价为2020年1月2日至2026年8月14日开盘，1604日；较早诊断为2015年1月5日至2019年12月31日开盘，1219日，分别从20万元现金开始。较早历史已被研究过，仍不属于独立验证。保留每年242日、现金与无风险收益零、100份整手、0.001元价格单位、方向性涨跌停、买入次日可卖，以及分红权益、应收和到账。

基础费用为单边佣金万分之二、最低5元、滑点万分之五；压力费用为佣金万分之四、最低5元、滑点千分之一。两段各有12个新增完整账户及8个原样对照记录，共20个评价记录。另有三个全历史基础参考账户，单独计数。

不改变评价窗口或费用，不使用未来标签选择过去退出，不因训练显著性不足阻止完整账户检验。六个设置全部公布。若没有跨时期、费用压力的一致改善，就停止本轮邻近模型深度、惩罚和连续确认天数的细调。完整账户净夏普至少1.2和稳定超额的目标不变；历史筛选达标也不能替代独立证据。
