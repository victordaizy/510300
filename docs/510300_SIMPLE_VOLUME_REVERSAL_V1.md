# 第26轮：成交量与低点收复的六种策略

本轮直接利用已有日线、成交量和每日高低收盘，检验交易活跃程度是否有助于过滤趋势及反弹信号；不获取新数据，不补前瞻每股收益。六种规则全部在账户运行前确定。

## 因子口径

成交量倍数为当日成交量除以此前二十个交易日平均成交量，分母不包含当日，原数据单位保持一致。收盘位置是收盘减最低价占当日高低振幅的比例；振幅为零记0.5。五日涨跌、均线、前期高低收盘、两日强弱、二十日标准化偏离均采用第23轮含分红口径。年化波动率为相应交易日含分红简单收益的样本标准差乘242平方根。

当日最低价为与历史收盘比较，先将当日最低价加每份分红，除以当日收盘加每份分红，再乘当日累计含分红价格。这样只利用已经结束的当日振幅形成收盘信号；不会假设盘中预先知道最后收盘。

## 每种策略如何进入和退出

|策略|收盘后的进入条件，均需全部成立|价格退出条件|其他任一退出条件|
|---|---|---|---|
|急跌后放量收强|截至昨日五日累计跌幅超过3%；今日收盘上涨；成交量至少为此前二十日均量1.5倍；收盘位置至少0.75|二十日标准化偏离恢复到零或以上|亏损4%、盈利6%、持有10日|
|上涨趋势中缩量回调转升|收盘在一百二十日均线上方；成交量低于此前二十日均量0.7倍；截至今日五日跌幅超过2%；今日收盘上涨|收盘不高于一百二十日均线，或两日强弱指标高于80|亏损4%、持有10日|
|放量突破二十日高点|收盘高于此前二十日最高收盘；成交量至少为此前二十日均量1.5倍|收盘低于此前十日最低收盘|亏损6%、从持仓高点回落6%、持有60日|
|放量大跌后缩量回升|昨日含分红跌幅至少2%；昨日成交量至少为其此前二十日均量1.5倍；今日收盘上涨且成交量低于昨日|两日强弱指标高于70|亏损3%、持有5日|
|跌破二十日低点后当日收复|当日可比最低价低于此前二十日最低收盘；当日收盘重新高于该低点；收盘位置至少0.6|二十日标准化偏离恢复到零或以上|亏损3%、盈利5%、持有5日|
|短期高波动急跌后回升|截至今日五日累计跌幅超过5%；今日收盘上涨；收盘位置至少0.6；五日波动率超过六十日的1.5倍|二十日标准化偏离恢复到零或以上|亏损4%、盈利6%、持有10日|

预定主方案为“跌破二十日低点后当日收复”。任一退出条件成立即下一开盘请求全部卖出；止盈止损阈值不等于保证成交价。退出受阻时保持请求。每周期只买一次，卖完经过两个后续交易日的收盘后才可依据新条件再次入场。没有持仓才能进入。

20万元、510300及现金、2020年1月2日至2026年8月14日开盘终点、242日年化、现金及无风险收益零、整手100份、0.001元价格跳动、涨跌停、当日买入次日可卖及实际分红权益沿用原完整账户。基础佣金万分之二、最低5元、滑点万分之五；压力佣金万分之四、最低5元、滑点千分之一。全部判断只在收盘后使用已有信息。

六种策略新增12个评价账户，复用2个买入持有账户。完整时期扣费夏普至少1.2，且需费用压力、分阶段与独立证据；本轮仍属于已观察历史上的筛选。
