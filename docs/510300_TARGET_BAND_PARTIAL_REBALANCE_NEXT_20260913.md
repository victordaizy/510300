# 第197轮准备方案：目标偏离后的部分调仓

尚未实现、测试、冻结或计算本轮账户。第196轮十四套风险窗口与预算时点设置已经完成，未改善完整联合门槛；结束该网格，不再追加窗口或预算。本轮只改变已持仓且目标偏离较大时的调仓幅度，一次比较两套执行规则。

## 依据与共同来源

使用第181轮原每日六十日百分之十账户风险预算目标，两个费用场景分别使用同档保存来源。它的主历史基础／压力夏普1.306／1.223、年化9.66%／8.99%，较早夏普1.069／1.056、年化9.88%／9.84%。第193轮在原目标为正期间完全保持份额，减少了交易，但损失收益更大；本轮保留必要的动态调整，仅减少一次调整的幅度。

来源的全部因子、进入、退出和风险倍率规则在正式文档中附上。新增执行判断只使用原目标比例、本人模拟账户的股票份额、当日收盘价、当日收盘净资产，以及由此计算的实际股票比例。实际比例等于份额乘收盘价，再除以净资产；目标差额等于目标比例减实际比例。

## 两套预定规则

共同保留十个百分点的允许偏离带。已有股票且来源目标明确为正时，实际比例与目标的差距严格小于十个百分点，保持已有份额。当差距达到或超过十个百分点时：

- 主候选“调到区间边缘”：实际比例偏低，新的申请比例取目标减十个百分点；实际比例偏高，新的申请比例取目标加十个百分点。比例限制在零至百分之一百内。在恰好处于边缘时，可以不产生新的成交。
- 比较候选“调整一半差额”：新的申请比例取实际比例与目标比例的平均值，使一次调整只走完一半差额；比例限制在零至百分之一百内。

这两种规则只对已持仓的正目标调仓生效。申请份额使用本账户收盘净资产乘新的申请比例，除以当日收盘价，向下取整到整百份；申请买卖量等于申请份额减已有份额。不得把计算出的申请比例冒称来源原目标，也不得用下一开盘才知道的价格倒算前一收盘申请。

## 进入与退出

空仓且来源目标明确为正时，仍按原完整目标进入，向下取整到整百份，不在首次进入时扣除偏离带或减半。来源明确为零时优先请求全部退出，不对退出减半。来源未知时保持已有份额，不把未知当零。

每个收盘十五时零五分计算，下一开盘模拟执行。未成交或部分成交后，下一收盘根据当时来源目标和本账户真实模拟份额重新判断；不追加固定退出锁、冷却期或盘中判断。研究终点开盘强制全退优先于所有其他规则。原来源可以依自己的保护和自然退出条件再次给出正目标，本账户按上述规则处理。

## 统一账户与一次比较

两套规则、两段历史、两档费用，共八条新账户；不新增预测模型、来源参考账户或外部数据。主历史2020年1月2日至2026年8月14日终点开盘，较早历史2015年1月5日至2019年12月31日终点开盘；每条账户独立二十万元。

基础单边佣金万分之二、最低五元、滑点万分之五；压力佣金万分之四、最低五元、滑点千分之一。整百份、千分之一元价位、次日可卖、现金限制、方向涨跌停和分红登记、除息应收、支付到账分别记账均保留。现金与无风险收益假设零，二百四十二日年化；仅510300和人民币现金。

对照原181、193完全保持份额和买入持有，直接使用已保存账户。比较净利润差时，分开列示价格与分红利润的变化、佣金滑点的节约，不能只凭交易次数减少就宣布改善。

必要测试覆盖首次进入保持完整目标、正目标偏离带边界、两个部分调整公式、零目标完整退出、未知保持、后续实际份额和终点优先。保存核对必须根据本账户实际收盘净值与份额独立重建申请数量；旧“直接调整到目标中心”的核对函数不能原封不动套用。

两个设置一次冻结后都运行并完整报告。分别检查四个场景的夏普至少一点二和复合年化至少百分之十。本轮仍是使用过历史上的策略调整，独立验证尚未建立。两种方案若无改善，结束部分调仓试验，不再追加调仓比例或偏离带宽。
