# 第141轮拟研究：每个信号周期固定一次策略来源

第140轮的趋势选择增加了主历史仓位和交易：主两档费用都是76次成交，139都是56次，主风险增加超过收益改善。每日更换来源既改变规模，也改变持有日历，不能将失败全部归因于费用。139继续保留为四情景均衡候选；140完整结果关闭，不改变120日窗口、零门槛或选择方向。

下一项研究独立的决策时点约束：趋势只在尚未锁定来源时参与选择，选中的正目标开始一个信号周期，期间固定该策略来源，直到它明确给出零目标。该约束不是改变140均线参数，也不使用未来收益或某个获利年份选择规则。只登记一项，先固定全部进入退出规则，再运行。

来源仍是131普通波动乘数与139训练支持选择，原底层状态和模型不重跑。每段准备收盘起，锁定来源为空。每天15:05，若没有锁定来源，完整120日含分红财富均线偏离严格大于零选131，等于或低于零选139。趋势未知则目标未知。选中父目标为正时锁定该来源，且采用其正目标；为零时当日目标零但不锁定；未知时当日目标未知且不锁定。

已锁定时不再由当天趋势更换来源。所锁父目标为正就继续采用其原连续目标；未知则目标未知且保留原来源，不自动换策略；明确为零时发零目标，并在这个收盘处理结束后解除来源锁定。下一个收盘才重新判定趋势和来源。父策略原状态继续运行，与外层实际盈亏无关。

这是按保存信号的正值区间固定来源，不是按实际成交持仓周期锁定。由于整手、带宽或受阻，两种周期可能不同。外层每收盘按最新目标重算；如果前日清仓请求未成交而次日已出现新的正目标，仍按原账户规则处理，不新增永久卖出锁定。必须把该边界在中文报告中写清楚。

外层自身净值、整百份、十个百分点带宽、下一开盘、明确零目标全退出、未知不发调整、终点开盘清仓、费用分红及两段起止均保持。两档费用分别使用对应的父目标，因此来源锁定结束时点也可能不同；不要求强行共用来源状态。

四条新账户，保存对照131、139、140和买入持有共十六条；零新模型、零新参考账户和下载。必要测试覆盖进入固定、期间趋势反转、明确零释放、未知保留、费用状态分离、未来隔离及实际账户。失败结束这一固定设置，不延长锁定或更改释放门槛救回。保留所有旧研究结论；目标仍未完成。
