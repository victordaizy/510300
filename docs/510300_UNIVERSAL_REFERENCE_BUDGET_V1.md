# 第97轮：按全部固定混合比例的累计增长汇总预算

只登记一个新设置，不训练收益预测模型。使用第91轮已经保存的连续急跌策略与学习退出策略，考察所有零至百分之百的固定混合比例。每个比例起始地位相同，按截至当日的累计混合增长加权求平均，得到下一开盘的资金比例。这与第84轮只按两条单独参考净值比例分配不同，原失败与固定规则保留。

## 全部新增输入及预算规则

每天使用四项输入：急跌参考账户当日完整净收益、学习参考账户同口径净收益、急跌原收盘持有意向、学习原收盘持有意向。日净收益为当日完整净值除以前日净值再减一，现金日、实际佣金、滑点和分红应收均包含；持有意向为原规则请求进入或继续持有记一、请求退出或等待记零，缺失保留。

对每一个固定比例，急跌使用该比例，学习使用剩余比例；当天混合增长为急跌的一加净收益乘急跌比例，加上学习的一加净收益乘剩余比例。每天的增长连续相乘，得到该固定比例截至今天的混合财富。急跌新预算为所有固定比例乘各自混合财富后在零至一之间的积分，除以各混合财富在相同范围的积分；学习预算为一减急跌预算。不挑单个赢家，不拟合收益系数，不扫描比例，不引入学习率。

连续参考从2013年6月3日开始，之前一个准备收盘为各半。每天收盘更新，包括当日已实现结果；主历史与较早历史都沿用当时已经存在的同一连续参考资料，实际评价账户则各从二十万元现金开始。实现以非负多项式系数递推计算精确积分，共同比例缩放防止溢出，不用网格寻找权重。原点以后或终点开盘清仓收益不能参与过去预算。

一旦连续参考收益出现缺失、无穷或净值失效，累计增长链不完整，之后预算无观点，不能跳过那一天或填零后继续。仅持有意向缺失时，当日股票目标缺失，预算仍可按完整收益更新。当前资料按完整日历检查，不下载或重跑参考。

该混合增长只是预算计算对象，尚未计入动态汇总资金的额外整手交易与费用，也不是各潜在混合比例的真实可交易子账户。最终合并账户独立计算自身费用和成交，不能把理论增长作为本策略收益。方法参考[Cover原始论文](https://isl.stanford.edu/~cover/papers/paper93.pdf)；其渐近财富结论不保证本轮有限样本、实际摩擦下的收益，更不保证夏普1.2。

## 两条原策略的因子与全部进出场规则

急跌策略同时满足四项才在下一开盘请求进入：含分红五日累计跌幅超过百分之五；当日含分红财富较昨日回升；收盘在当日高低区间的位置至少百分之六十；五日含分红简单收益的样本标准差高于六十日的1.5倍。收盘位置为收盘减最低，再除以最高减最低。原完整性要求保持。

急跌策略满足任一条件，下一开盘全部退出：财富回到二十日均值或以上；本周期含分红亏损达到百分之四；收益达到百分之六；含买入日在内持有十个交易日。实际退出后至少等待两日。受阻退出继续请求。

学习策略进入因子为六十日日内相对隔夜强弱：日内为收盘加每份分红除以开盘加分红后取自然对数；隔夜为开盘加分红除以前收盘后取自然对数。六十日“日内减隔夜”之和除以该差值样本标准差与六十平方根的乘积。连续两个收盘严格高于一、资料有效、原参考空仓且有再次进入资格、距实际退出至少两日，下一开盘请求进入。

学习退出的八项输入依次为：持仓交易日数加一的自然对数；参考实际含分红浮盈亏；参考周期价值相对最高价值的回撤；固定为一的进入类别；最近五日含分红对数涨跌；最近二十日同口径涨跌；财富相对一百二十日均值的偏离；二十日含分红简单收益样本标准差乘二百四十二平方根。周期价值包括实际份额市值与本周期已确认分红，成本包括买入金额和佣金，初始高点至少为该成本。

沿用已保存的114个月度成熟模型与27个无模型时点。原模型只用当时已结束的最近二十周期、至少十周期一百条记录，周期等总权重；八项输入按原加权均值和标准差标准化，限制在负五至五，岭回归惩罚一并保留截距。预测为截距加八项标准化输入乘原系数，学习继续持有到自然退出比下一开盘提前退出多得的含成本、分红价值。本轮不重新训练或改变系数。

学习策略满足任一条，下一开盘全部退出：六十日强弱连续两收盘低于零；周期含分红亏损百分之六；从周期价值最高点回落百分之八；持有六十个交易日收盘；原继续持有预测连续两个持仓收盘为负。无模型仍执行价格和时间退出。退出受阻保留，卖出后需在空仓期间看到原进入条件消失，再等重现并满足两日冷却。

含分红简单日收益为收盘加当日每份分红除以前收盘后减一；财富指数为每日一加该收益连续相乘。原两条参考的持仓和盈亏仅决定各自信号，不把合并账户状态反灌原模型。

## 合并账户的进入、加减仓与退出

每天收盘股票目标为急跌预算乘急跌持有意向，加学习预算乘学习持有意向。两条都持有时目标全额，一条持有时用其预算，两条都退出或等待时目标为零。真实空仓且目标为正，按自身现金、份额市值及分红应收组成的完整净值和收盘价计算整百份，下一开盘按可负担现金与实际费用成交。

非零目标与自身实际股票占比相差至少十个百分点才重新估算整手并加减仓；不足则维持股数。零目标直接请求全部退出。目标缺失则保留实际份额，不等于清仓。未成交保留真实状态，下一收盘按最新目标重算。原参考内部退出锁定、两日冷却和学习分支再次进入资格保持；组合不另加冷却或止损线。
