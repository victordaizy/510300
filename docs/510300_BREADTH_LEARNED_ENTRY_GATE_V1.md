# 第63轮：广度仅筛选原学习策略的进入

本轮只登记一个新设置。使用第62轮已经核对的独立上涨广度，附加于原第32轮学习退出策略的进入，不补来源、不重新训练、不改变学习退出，不增加广度退出。原基线、急跌回升与学习各半、买入持有作为三个保存对照。

## 全部因子与来源

原进入信号比较过去60个交易日日内与隔夜的强弱。每天的日内对数收益为“当日收盘加现金分红”除以“当日开盘加现金分红”后取自然对数；隔夜为“当日开盘加现金分红”除以前一收盘后取自然对数。每日先用日内减隔夜，再将最近60日差额求和，除以同一段每日差额的样本标准差和60的平方根。连续两个收盘的标准化差额都严格大于1，且原基础特征完整，形成原进入条件。

附加广度为当日点时沪深300成员里，过去20交易日总股东回报为正的数量，占20日回报完整可计算成员数量的比例。使用原始价格与已解决公司行为的四态收益，官方确认停牌按原记录，缺失和未解决行为不填零。成员300名，至少294名完整，比例与数量一致，当日四态覆盖允许使用，广度处于零至一之间，才认为有效。原字段自身已按98%覆盖门处理，不取屏蔽前列、不前填、不设为50%。原F/T组合状态不替代这个独立字段状态。

原成员收盘后生效规则、2015扩展时钟及分红实施公告早于除息日规则全部保留。第62轮已从1,347,235条缓存四态回报及点时成员核对2823日广度，2350有值、473缺失，数值与覆盖完全一致，本轮直接复用，不再次补历史。缓存是历史重建，不是当年实时采集证明。

学习退出保留八个输入：持仓交易日数加1后取自然对数；含分红持仓价值相对含买入佣金成本的收益；相对本周期最高持仓价值的回撤；进入模式（本轮固定为1）；最近5日与20日含分红对数收益之和；财富收盘相对含当天120日均值的偏离；最近20日日含分红简单收益的样本标准差乘242的平方根。

每个收盘只使用当时已完成训练的原岭回归模型。原模型按月更新，使用已自然结束的原参考周期，周期等权，每个周期内状态等权；不会用本次新账户结果重新拟合。预测前按该模型保存的均值和尺度标准化，每项限制在负5至5，再乘保存系数并加截距。原学习目标比较自然退出与提前下一开盘退出的净收益差，提前退出标签有未另模拟受阻成交的原近似，本轮没有修改。完整逐月系数单独用中文附带，114个旧模型、27个无模型月份；不是第59轮重新扩充参考路径训练的模型。

含分红财富指数用于跨除息比较，实际现金账户另按登记、除息应收、到账维护，不把前复权价格直接当实际成交价。

## 进入与重新进入

先检查原60日日内强弱进入条件。若广度有效，必须严格超过一半才保留进入信号；若有效但不高于一半，暂停新的买入请求，尚未使用的进入资格仍保留。若广度缺失，保留其无观点状态，沿用原学习策略当时本来已有的进入决定，明确标记基线回退；不假造广度数值、不把缺失解释为看多或看空。广度不会使原条件不成立的日期变成进入日。

账户空仓、原进入资格有效，并满足距离上次实际全部卖出至少两个交易日的等待，才在收盘请求下一交易日开盘单次买入。按前收盘估计可负担的100份整数倍，下一开盘按实际现金、费用和成交限制执行。不追加。实际买入才消耗资格；未成交且下一收盘仍满足完整条件可继续请求。

实际卖出后，只有原60日日内强弱进入条件在空仓时消失，才恢复进入资格；单纯广度未过半或广度缺失不能恢复资格。新资格有效后，原条件可以在广度暂缓期间持续存在，后来广度超过一半或缺失触发基线回退时，只要等待期满足即可请求买入，不要求重新发生第一天穿越。

## 持有与退出

持仓后不再由广度作任何退出决定。每个持仓收盘照常更新实际周期状态，原以下条件任一成立，就请求下一开盘全部卖出：

- 最近60日日内减隔夜的标准化差额连续两个收盘严格小于零。
- 实际持仓含分红收益相对含买入佣金成本下降至少6%。
- 含分红持仓价值相对本周期最高值下降至少8%，最高值初始为买入成本。
- 已持有60个交易日收盘，实际买入当天为第一个。
- 原岭回归连续两个持仓收盘预测继续持有收益严格为负；缺失模型或缺失预测保持无观点，并按原逻辑重置连续负值计数，不自动退出。

卖出因涨跌停或次日可卖约束未成交时，继续请求直到实际卖出，不因广度恢复、缺失或学习预测改变而撤销。研究终点仍统一尝试开盘退出，所有未成交和分红权益保留。
