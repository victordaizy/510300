# 年化净超额40个百分点高夏普研究V4扩展规范

## 1. 继承与停止

V4完整继承V3的50万元账户、H00300全收益基准、单边用户费率0.0001、基础和压力双情景，以及年化净超额至少40个百分点、净夏普至少1.50的硬门。A股涨停后延续V1已经冻结拒绝，2024—2026复验未读；不得改变持有期、持仓数、流动性门或成本救回。

## 2. 唯一新增路线

V4只允许一条新的 `CHINA_CONVERTIBLE_BOND_RELATIVE_VALUE` 路线：在包含已退市债券的可转债二级市场全历史中，按“债券收盘价＋当日转股溢价百分点”的传统双低分数排序，在下一交易日开盘成交并等权轮动。

这与既有“新债股东优先配售一手”研究不同：前者是已上市债券的二级市场相对价值组合，后者是发行配售事件。V4不得改造成新债申购、负溢价转股套利、股票卖空、ETF轮动、涨停延续或旧A股因子的参数变体。

## 3. 数据先行但不得看结果

候选冻结前可以采集和规范化以下原始字段：完整发行清单、已退市债券日线开高低收量、逐日纯债价值、转股价值和转股溢价。采集阶段不得计算双低排名、后续收益、组合净值或任何参数比较。

候选只有在确认已退市债券覆盖、点时转股溢价、日期主键和可交易日线足够后才能冻结。当前来源没有不可变供应商历史版本链，任何历史结果只能作为公式族发现证据，不能验证未来目标。

## 4. 不变边界

候选必须在任何可见期收益计算前冻结公式、调仓频率、持仓数、价格与溢价范围、流动性门、交易单位、成本、日期分区和停止规则。可见期未通过全部40个百分点和1.50夏普门时，封存复验保持关闭，并转向新的独立机制。

全程只做研究。Paper、Shadow、订单生成、券商连接、股票转股套利和实盘均关闭。
