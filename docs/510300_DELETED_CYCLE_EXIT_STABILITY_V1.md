# 第72轮：逐个删除完整旧周期的退出稳定性

本轮只检验一个改动：原来的平均继续收益模型提示提前卖出时，依次拿掉一个已结束的旧交易周期后，其他模型是否也同意卖出。只有全部同意、并连续两天成立，才增加学习退出。目标是减少过度依赖单次旧行情的提前卖出。更晚退出也可能扩大亏损，因此直接比较扣费后的完整账户。

## 固定范围与目标

只使用510300和人民币现金，使用已有免费日线、已确认分红、已保存原模型和参考交易周期。暂停每股收益、财报、估值、公募及其他慢数据补齐，不新增参考账户。夏普目标为1.2；本轮登记一个完整策略设置，不能把每个删除模型当成一种策略。历史反复研究的结果不能当作新独立样本证明。

本轮不改变原月度时点、原进入信号、再次进入条件、原价格与时间退出、八项输入、回测区间和费用。不重新拟合全样本原模型，只使用其已保存值。预先从原训练成员数量统计：141个时点中114个具备原成熟条件，共需要2055次删除模型拟合；其余27个时点保留没有学习模型的状态。

## 进入规则

每天收盘后计算日内相对隔夜强弱。隔夜收益是当天开盘价格加当天每份现金分红后，除以前一天收盘价格，再取自然对数；日内收益是当天收盘价格加同一分红，除以当天开盘价格加同一分红，再取自然对数。

每天的差值为日内收益减隔夜收益。将最近60个交易日差值相加，除以“这60个差值的样本标准差与60的平方根的乘积”。连续两个收盘的这一指标都严格大于1，而且原基础数据预热条件完整，才形成原进入条件。

空仓、具有再次进入资格、距离上次实际卖出至少两个交易日时，按已有现金和上一收盘估算费用后，申请下一交易日开盘买入可负担的最多100份整数倍。持仓期间不加仓。实际买入后关闭再次进入资格；卖出后，必须先观察到原进入条件消失，才能等待新的进入信号。不会在同一段持续信号中反复买回。

## 退出规则与执行顺序

任何一项原退出条件成立就请求下一开盘全卖：日内相对隔夜强弱连续两个收盘严格小于零；本次持仓含已确认分红的价值相对含买入佣金的成本亏损达到6%；相对本次含分红价值最高点回撤达到8%；或者持有达到60个交易日。原策略没有固定止盈目标。

本轮另外增加学习退出：先计算原全样本平均继续收益，再计算每个删除周期模型的平均继续收益。原模型和所有删除模型必须全部严格小于零，本日才计一次负值确认；连续两个收盘都成立，请求下一开盘全卖。任意一个预测等于零、为正，或当日没有完整模型或输入，都将本日学习计数归零。换一个实际持仓周期时计数也归零。

逐日文件中的“全部模型预测最大值”，是以上所有预测中最大的一个。它小于零等价于全部为负；这个最大值不是置信区间的上界，不表示收益概率。

一旦任何退出请求形成，即使后来某个预测转正，也继续保留卖出请求直到实际成交。执行保留次日可卖、涨跌停、整手、现金约束、手续费和滑点；没有成交就不虚构成交。固定历史终点开盘清仓，整个空仓日历也进入夏普计算。

## 八项模型输入

| 因子 | 每个实际账户每天收盘后的中文计算规则 | 作用 |
|---|---|---|
| 持有时长 | 实际买入当日记为第1天，将已持有交易日数加1后取自然对数 | 区分新持仓与持续持仓 |
| 本周期含分红收益 | 实际持有份额乘收盘价格，加本周期已经确认的现金分红，除以实际买入金额加买入佣金，再减1 | 反映自己的实际浮盈亏 |
| 本周期含分红回撤 | 当日上述持仓价值除以该周期此前及当日最高价值，再减1；最高值至少为含佣金买入成本 | 反映盈利回吐或损失扩大 |
| 进入类别 | 沿用原策略类别，本轮只有日内相对隔夜强势一种，固定为1 | 保持原模型输入定义 |
| 五日动量 | 最近5个交易日含分红总收益的自然对数之和 | 短期方向 |
| 二十日动量 | 最近20个交易日含分红总收益的自然对数之和 | 较长短期方向 |
| 一百二十日均线偏离 | 含分红累计财富指数除以最近120个交易日财富指数的算术平均，再减1 | 中期位置 |
| 二十日波动率 | 最近20个交易日含分红简单收益的样本标准差乘以242的平方根 | 当前年化波动水平 |

不同费用账户用自己的成交成本、份额、分红、周期起点和最高价值计算前三项，不借用基础费用账户的持仓轨迹。每个模型的均值、标准差、截距和全部八项系数均保存并生成中文说明。

## 学习目标、成熟条件及逐周期删除

学习目标完全沿用原参考周期：在某一历史持仓收盘，继续持有至原价格或时间退出的净卖出价值，加继续持有额外取得的分红权益，与下一开盘提前退出的净卖出价值比较；差额除以参考份额乘下一开盘价格。目标表示继续持有相对提前退出的增量，不是下一天涨跌，也不是用未完成周期猜一个标签。标签沿用原基础费用口径。

月度训练时钟是原定交易日收盘后15时05分。只有此时已经完全自然结束的参考周期及其完整状态记录可以进入训练；沿用最近最多20个周期，原主样本至少10个完整周期且至少100条状态记录。原成熟条件不足时，当月不启动删除拟合，原价格及时间退出仍正常运行。

对每个已经合格的原训练集合，依照原周期结束顺序，每次删除其中一个完整周期的全部状态记录，保留其余原成员。每一种删法都必须计算，不根据结果挑选删除对象，不补入更旧的第21个周期。删除后的9至19个周期是对已合格主样本的扰动，不另开一个成熟窗口，也不改变主样本最低支持条件。

每个保留周期的总样本权重为1，其中每一条记录平分这1份权重。用删除后记录和这些权重计算八项输入的训练均值与标准差；标准差不大于万亿分之一时按1处理。每项输入先减训练均值、再除训练标准差，之后限制在负5至正5之间。用原岭回归求解加权平方误差，系数平方惩罚强度固定为1，截距不惩罚，沿用奇异值分解求解器。

必须尝试当月全部删除模型，完整保存成功与失败。任何一个数值求解失败，则当月整组学习判断缺失，继续原价格与时间退出；不挑剩余成功模型、不换求解器或惩罚值补救。原全样本模型保持原保存内容完全一致。

## 固定历史和账户比较

主评价为2020年1月2日至2026年8月14日终点开盘；较早历史为2015年1月5日至2019年12月31日终点开盘。各从20万元开始，只做多或持有现金，无杠杆。每年242交易日，现金利息和无风险利率假设均为零；夏普由完整账户全部交易日的净收益计算。

基础费用为单边佣金万分之二、每笔最低5元、单边滑点万分之五；压力费用为单边佣金万分之四、最低5元、单边滑点千分之一。价格按最小变动单位0.001元取整，份额为100的整数倍。沿用原分红登记日、除息日、支付日和应收款处理。

新运行四个账户，重用16个已保存对照：原平均继续收益退出、原价格时间退出、原急跌与学习退出各半、买入持有，各覆盖两段历史和两档费用。报告净夏普、年化、最大回撤、交易周期、持仓比例及价差、分红、费用贡献，不以单一年份或删除亏损日宣称达到目标。

检验只针对本轮预先固定的全部同意规则。失败后不把全部同意改成多数同意、不调整删除比例、阈值或确认次数救回；不恢复上一轮中位数模型。不做预测显著性门槛来阻止完整账户运行，也不制作GPT数值审阅包。

分组删除方法的定义可参见[官方按组留出文档](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html)。它只支持按完整组留出的含义，不为本策略的盈利或稳定性背书。
