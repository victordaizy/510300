# 前瞻每股收益历史目录与连续来源第一轮

用户指定前瞻每股收益为主线。本轮承接五份研报试验，实际补连续历史，而不把历史实现利润当作预测。

## 固定范围

采用上一轮金融原始报告清单中的十二个证券代码，名称变更保留别名。查询2015年1月1日至2026年8月14日，按公司和自然年分别取得免费公开生产接口的全部分页。机构不筛选，预测字段是否为空也不筛选；同一报告出现多次保留原始出现记录。目录的完整性只指本次公开接口在该范围返回的分页，不代表所有历史券商研报均被平台收录。

保存每次请求的参数、返回内容、获取时间及文件指纹，检查公司、日期、分页数量、跨页重复和机构。接口中的当年、下一年等相对预测数字只随原件保存，不提取为历史因子。

十二家公司沿用财报来源建设的固定观察范围，不代表完整沪深300。历史成分序列只读取日期、证券代码，用于标记当时是否在指数及覆盖比例；不读取股票价格、策略收益或未来标签来选择研报。

## 本轮原件提取队列

目录完成后，登记这十二家公司在上述期间的全部国信证券研报，机构代码为既有原件核对的80000007。沿用该机构是为了复用上一轮已验证的表格版式，不按盈利预测数值或回测结果选择机构。包括目录中没有每股收益预测字段的报告，失败和无预测表的原件也保留。

从原PDF明确的年度列提取预测，历史实际值和预测值分开。按同公司、同机构、同目标年度、同收益口径比较；内部落款、平台发布时间和录入时间保留，研究可用日期采用三者较晚日期之后的交易日。当前取得的历史元数据不是当年不可变快照，这项限制保留。

这一机构的连续序列用于建立来源与金融子样本因子，不能称为市场一致预期或完整沪深300预测。未来十二个月预测尚未形成时不能用年度值冒充。后续增补其他机构、其他行业及历史成分权重，实际检验对510300账户的增量作用。

## 运行及恢复

公开目录使用正常浏览器公开生产地址，免费、正常TLS验证。单次连接错误可同地址重取一次；401、403、429立即停止该次采集，不更换身份或绕过限制。已完成分页不重复下载，失败有独立记录，恢复时保持原有请求范围。只核对来源、数值和必要运行结构，不做额外安全审计。

本轮不修改旧十轮结果，不产生交易指令，夏普1.2目标仍须完整成本账户和稳定性证据验证。
