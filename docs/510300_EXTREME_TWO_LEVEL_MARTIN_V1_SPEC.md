# 510300极端两级类马丁V1冻结协议

## 1. 核心想法

本候选不是无限翻倍马丁。它用更少、更大的两级仓位解决2万元账户的小单最低佣金问题：

- 确认底背离且处于RANGE时，下一交易日开盘建立50%目标；
- 只有价格相对第一层实际复权成交价再下跌2个固定入场ATR14，下一开盘才提升到100%；
- 满仓后不再加仓，不使用杠杆。

“跨度更大”固定解释为层间价格距离由旧候选的1ATR扩大到2ATR，而不是事后扩大或缩小时间区间。

## 2. 风险边界

第一层成交时冻结ATR14。硬失效线固定为第一层实际复权成交价减3个入场ATR14。顶背离、确认下跌趋势、硬失效、回归MA28或持有满60日均触发下一交易日退出。卖出不受小单成本门限制。

若持仓期间出现20日向上突破，组合版本不先卖出，而在下一开盘把目标提升到100%并交给海龟管理。

## 3. 固定候选

- `XM0_EXTREME_TWO_LEVEL_ONLY`：只运行两级均值回归；
- `XS1_EXTREME_TWO_LEVEL_TURTLE_SWITCH`：空仓时也运行海龟，类马丁持仓突破后转海龟。

分别与旧M0、旧S1比较，并以T1图形海龟作为第二基准。参数不搜索，结果不回填旧协议。

## 4. 必须报告

必须逐笔报告第一层、第二层、满仓次数、下一交易日执行、成本、失效退出、闭合周期及回撤。少于10个闭合周期只能判为证据不足。

## 5. 研究边界

该候选是在V2结果之后提出，证据标签为`POST_V2_HISTORICALLY_CONTAMINATED_CANDIDATE`。真实仓位映射、订单生成、券商连接和实盘授权全部关闭。
