# 第34轮：趋势与学习退出状态固定各半

本轮只检验一个组合，不扫描权重。原“趋势与震荡反弹切换”占一半，第32轮“六十日日内强于隔夜＋线性学习退出＋等待新机会”占一半。复用已经保存的收盘状态，不重新训练。

## 两个基础状态如何形成

趋势与震荡状态：总回报高于一百二十日均线且二十日方向效率大于0.3时，突破此前二十日最高收盘水平进入趋势模式；其余状态中，低于二十日均值1.5个样本标准差且当日回升，进入反弹模式。趋势模式在强趋势消失、跌破此前十日低点、亏损8%或从最高收盘价值回撤8%时退出。反弹模式在转为强趋势、恢复二十日均值、亏损5%或持有十个交易日时退出。实际卖完至少经过两个交易日，再按条件进入。

方向效率是二十日总回报水平的绝对净变化除以该期间每日变化绝对值之和。标准化偏离是当前总回报水平与二十日均值之差除以二十日水平样本标准差。

日内强弱状态：每日计算日内对数涨跌减隔夜对数涨跌，六十日之和除以六十日每日差异的样本标准差及六十的平方根。该值连续两日大于1时进入；连续两日小于零、含分红持仓亏损6%、从最高收盘价值回撤8%或持有六十日时退出。另用既有月度线性模型预测继续持有收益，真实持仓周期连续两个收盘预测为负也退出。实际卖出后至少经过两个交易日，而且旧入场条件曾在收盘消失，再重新满足，才允许买回。

线性模型八个因子为：持仓天数加一的自然对数、含分红浮盈浮亏、持仓收盘回撤、入场模式、五日含分红对数涨跌、二十日含分红对数涨跌、一百二十日均线偏离、二十日年化波动。每月首个交易日收盘，只用当时已经结束的最近20个参考持仓周期训练；至少10周期和100条状态，周期等权，标准化后限制在负5至5，系数惩罚为1。预测目标比较继续持有至原周期结束与下一开盘退出后的收益差，分红按登记日新增权益比较。没有成熟模型时不增加学习退出条件。全部精确定义和逐月实际系数复用第31、32轮中文说明。

## 组合怎样进入、持有、退出和重新进入

每个基础策略独立维护其模拟持仓周期。收盘愿意进入或继续持有，状态为一；已决定退出，或空仓等待，状态为零。基础策略退出受阻仍保留自身退出请求。组合使用基础费用下两个虚拟策略已经保存的状态，不能使用次日收益。基础和压力组合使用相同状态，实际调仓费用分别计算。

|两个基础状态|组合下一开盘目标|执行含义|
|---|---|---|
|都为零|现金，股票目标为零|请求全部退出。|
|只有一个为一|股票目标为账户净值的50%|空仓时进入半仓，满仓时减为半仓。|
|都为一|股票目标为账户净值的100%|空仓时进入，半仓时增加至可负担的满仓。|

每天收盘按两个状态重新确定目标，下一开盘执行。用当时账户净值与价格换算100份整手；实际已有仓位与非零目标相差不足10个百分点时保持份额，目标为零仍请求全部卖出。组合没有额外的止损幅度或等待期，原保护与等待规则用于基础状态的各自周期。

未成交时，下一收盘按新的组合目标重新决定请求；不假设必然成交，也不额外锁定旧组合退出目标。某一基础状态缺失时，本次不形成新目标，保留已有份额，不把缺失当零仓位。终点统一在开盘请求退出。实际账户只持有510300和现金，禁止融资或卖空。

本轮会重新模拟组合现金、份额、分红和费用，不能把两条账户收益平均当作组合收益。基础状态的虚拟账户只是信号来源，不代表真实账户的两笔独立资金。

## 固定比较与停止条件

主评价2020年1月2日至2026年8月14日开盘，1604日；较早诊断2015年1月5日至2019年12月31日开盘，1219日，各自20万元起点。较早历史已被研究过，不是独立验证。

两段分别比较本轮新组合、原趋势与未学习日内强弱各半的组合、第32轮线性退出单策略、原趋势单策略以及买入持有。每段两档费用共10个记录，其中2个新账户、8个复用对照。两段共4个新账户，不增加模型训练。

保持每年242日、现金和无风险收益零、100份、0.001元、方向性涨跌停、买入次日可卖，以及分红权益和到账。基础费用佣金万分之二、最低5元、滑点万分之五；压力费用佣金万分之四、最低5元、滑点千分之一。

先看组合是否比单策略与旧组合同时改善，再看两个时期与费用压力。如果未改善，不继续围绕这两个状态扫描组合权重。净夏普1.2及稳定超额仍是目标，历史点估计不替代独立证据。
