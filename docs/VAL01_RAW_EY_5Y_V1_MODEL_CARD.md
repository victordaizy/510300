## 1. 研究问题与本阶段终点

本候选只回答一个问题：使用当月沪深300官方权重、当时已公告财务版本和当时可用未复权收盘价，能否形成一条可复算的“指数原始盈利收益率五年分位”输入序列。

本阶段只构造月度原始EY及60月分位，不拼接任何未来收益标签，不计算IC、分位单调性、策略收益或仓位绩效，也不输出当前目标仓位、份额或订单。数据闸门通过只代表“定义可计算”，不代表存在有效Alpha。

## 2. 不可变输入与点时规则

1. 成分及权重：使用`000300_historical_weights.parquet`中以`trade_date`标识的官方月度权重，每月应为300只，权重单位为百分数。
2. 财务版本：对每只证券、每个报告期，只允许选择`available_at <= 快照日`的最新已知版本。公告日在快照日之后的版本不得进入计算。
3. TTM归母净利润：
   - 年报：直接使用当年累计归母净利润；
   - 一季报、半年报或三季报：`本期累计 + 上年年报 - 上年同期累计`；
   - 从最新报告期向前寻找首个可完整计算的TTM报告期。
4. 总股本：使用截至快照日最新非空且大于零的总股本。
5. 价格：使用快照日当日未复权收盘价；停牌时只允许向前延用最后真实成交日收盘价。禁止向后取价。价格年龄完整报告，不在看到结果后增设年龄上限。
6. 历史档案限制：权重、财务和价格历史均在2026年8月统一或补充回取。`available_at`可以阻止显式前视，但缺少逐日不可变供应商存档，故全部历史输出仍为`HISTORICALLY_CONTAMINATED`，不是严格样本外证据。

## 3. 公司与指数原始盈利收益率

公司层定义：

```text
TTM_EPS_i,t = TTM_Parent_Profit_i,t / Total_Shares_i,t
RawEY_i,t = TTM_EPS_i,t / RawClose_i,t
```

亏损公司的`RawEY`保留为负数，不剔除、不置零、不缩尾。这样可以防止只保留盈利公司造成事后样本选择，也明确区别于中证或供应商PE常见的盈利公司聚合口径。

指数层定义：

```text
Valid_t = 同时具有正价格、可计算TTM_EPS和正官方权重的公司集合
Coverage_t = Σ(i∈Valid_t) Weight_i,t
IndexRawEY_t = Σ(i∈Valid_t) Weight_i,t × RawEY_i,t / Coverage_t
```

价格覆盖不得低于99%，TTM覆盖和价格财务联合覆盖均不得低于90%。这些门槛沿用V1.0/V1.1数据审计，不因本次计算结果而提高或降低。缺失公司只在当月有效权重内重新归一，同时必须保留覆盖率，禁止把低覆盖月份伪装成完整指数。

## 4. 60月精确分位

窗口固定为连续60个官方月度快照，包含当月。窗口内必须60个EY均通过当月数据闸门；否则该月无分位信号。

```text
Q_t = [#(EY_j < EY_t) + 0.5 × #(EY_j = EY_t)] / 60
```

比较使用未预先四舍五入的`float64`值。并列使用midrank；不调用可能随库版本改变默认并列规则的百分位接口。唯一最小值为`0.5/60`，唯一最大值为`59.5/60`。本地120个月快照的第60个月应为`2021-07-30`，这是首个允许出现分位的观察日。

## 5. 信息时点与候选执行规则

信号只在快照日收盘后可得，最早执行日是严格晚于快照日的下一个沪深300交易日开盘。首个有效观察日`2021-07-30`对应的最早执行日应为`2021-08-02`。

## 6. 独立交叉核验

中证官方PE和乐咕供应商PE只用于数据诊断，不进入正式信号。两者通常按盈利公司或市值口径聚合，与“官方权重平均且保留亏损公司”的本模型没有逐点相等关系。

冻结的诊断门槛为：在截至`2021-07-30`的60月暖机窗中，每个来源至少48个同日观测，`IndexRawEY`与`1/PE`的Spearman相关不低于0.50。该门槛只检查方向和时间序列一致性；绝对差异必须报告，但不为追求贴合而改变模型公式。两类PE文件同样是事后下载且没有逐日版本证明，不能解除历史污染标签。
