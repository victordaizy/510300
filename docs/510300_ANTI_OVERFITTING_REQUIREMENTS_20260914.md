# 510300减少过拟合：现版处置与后续研究要求

2026年9月14日，用户要求：“我们需要同时减少过拟合，比如我们最新的，其实就是过拟合”。本要求优先于此前以历史夏普1.2、年化10%为目标持续修改参数的安排。1.2和10%继续作为最终独立验收目标，不能成为看到回测不达标便追加规则的理由。

## 对现版的判断

当前 SELECTED_MIX_BAND10_SIMPLE2 保持“高过拟合风险、局部稳健性未通过”的处置，只作固定研究对照。历史成本后点值确实来自实际模拟账户；它们没有证明稳定的未来收益，也不能作为预期年化或预期夏普宣传。

“两来源85比15”只描述最外层。来源内部仍包含多次合成、不同风险窗口、趋势过滤、等待规则、加仓门槛和学习退出；不能把两个来源称为只有两个自由度。机械计算节点和账本数量也不等于统计意义的独立参数数量。

本次直接读取已有记录，没有重新回测：

- 截至第216轮的索引累计为583个不同设置、599个已评价来源版本；该字段不是全项目所有试验次数，不能直接当成599个相互独立试验计算过拟合概率。
- 第210轮固定区间的现版主历史压力账户，最大盈利周期占总净利润42.97%，前五盈利周期占86.83%。这是收益集中性的警讯，单独不能证明过拟合。
- 同一旧固定区间的20日区块重采样，夏普2.5%至97.5%分位为0.5458至1.7773；该重采样没有校正此前策略和权重选优，不能用作未来成功概率。
- 已完成的简单核心50／60／70日诊断，2020年初至2026年9月11日压力夏普分别0.223／0.286／0.075，年化分别1.22%／1.77%／0.28%；较早历史压力夏普分别0.314／0.839／0.166。邻近窗口没有一致改善。不能选60日之后再搜索58日或62日。
- 简单核心同时移除了多个模块，所以其与现版之间的差额不能单独归因于学习退出、仓位倍率或任一模块；也没有由此估计出正式过拟合概率。

## 从现在执行的要求

1. 停止现版和日内—隔夜信号主导路线的追加优化。不再修改85／15权重、1.15倍率、进出场门槛，或新增过滤器救回历史指标。原算法中已固定的月度训练可照原规定继续，训练方法和特征不再改变。
2. 所有已经看过、筛选过的历史统一标为开发及校准材料。事后切成训练集和测试集、改用滚动训练或重新抽样，都不能消除研究者已利用这些历史选策略的事实。滚动训练本身仍须避免未来信息泄漏。
3. 当前只保留原版固定研究观察。新数据逐日完整记账，现金日、亏损日和迟到决定均保留；不把简单核心接入原净值，也不拼接不同版本。检查时点、成交可行性和未来盈利能力分别判断。
4. 将来提出新的、可否证的经济机制时，先用中文写明为何可能赚钱、什么观察会否定它、全部进出场规则及已有历史使用范围。基础版本限一项主要信号和一层直接风险控制，禁止用其他内部策略账本反复放大和套配比；默认至多三个由研究者选择的可调参数、至多三套事前列明的完整设置。这是研发复杂度预算，不是统计有效性的证明。固定常数、条件分支、模型系数、训练方法选择和所有失败尝试也要公开记录，不能靠改名绕过预算。首版不新增学习退出或嵌套组合。
5. 主设置、邻近设置、基准、费用、比较指标及淘汰标准必须在看该轮结果前写完，一次报告全部。邻近设置用于检验敏感性，不能再从中选一个最漂亮的重启搜索。新增复杂规则必须有事前问题及可重复的增量证据；本次不据此批准新候选或重跑已失败的简单核心。
6. 需要训练时，按时间先后评价，只使用当时已完整成熟的标签。训练持仓标签的退出时点不得跨入评价段；跨界标签须排除或等待成熟。拟合、标准化、选特征和选参数均只能使用允许的训练区间。已经被用于选方法的评价段仍属于开发历史。
7. 已完成的费用、邻域、年度及利润集中检查直接引用。未来研究在事前固定的比较中同时呈现基础与压力完整账户、两个历史区间、收益、风险和资金占用；不因低仓位回撤浅就宣布有择时优势。集中盈利和留一年分析用于定位风险，禁止删掉年份或周期再拼出新的业绩。
8. 独立验收依靠策略确定之后按事前规则积累的新观察；在开始新研究前固定评价时点、样本长度或信息量设计、区间估计及停止规则。不得每天窥看累计夏普，一碰到1.2就宣布通过。新期间用于改策略后，该期间转为开发材料，新版本另立起点。少量现金日和少数盈利周期不构成稳定夏普证明。
9. 如以后计算多重试验修正夏普或回测过拟合概率，先确认完整可比的候选收益、试验范围与相关性是否足够。当前没有计算这两项，不能把583或599直接塞进公式并给出貌似精确的过拟合概率；不能用统计校正恢复受污染历史的独立性。
