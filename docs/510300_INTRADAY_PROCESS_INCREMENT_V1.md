# 510300盘中过程对日线的增量研究V1

依据2026-10-02新目标，主线改为现有分钟数据的有限历史代理研究。旧M1/M2同步估值、盘口队列与实际成交研究保留为储备，其blocked不阻止本实验。仅交易510300.SH/CASH_CNY；零费用、不采集新数据，不使用较长NBS缓存替换当前原文件。历史早已被多轮观察，结果只能称为滚动伪样本外。

## 数据及质量规则

主分钟文件为291,851行、1,211日，2021-08-12至2026-08-12。元数据单位为份和元；第三方代理，trade_time无柱首/柱尾承诺。信号统一盘后15:05，执行不早于下一交易日。此延迟设计避免利用尚未结束的分钟，仍不证明历史实际送达。数据许可只能确认已有项目研究使用，未取得再分发或可重新免费获取全部历史的合同。

直接核验241条/日的完整时标、OHLC、负量额、重复、日线聚合及VWAP范围。保存每根严格越界，允许的主代理精度容差固定为一档0.001元；更大异常使所涉B窗口或C当日及前60日归一化失效。一个价位内的异常仍列出，不能称全部错误修复；另报告严格口径可用覆盖，不用不足的严格样本伪造验证。全日量额匹配不是单根分钟真实准确性的证明。异常规则在新模型标签及账户结果计算前登记。

开盘09:30仅用于开盘执行容量代理。09:31—11:30、13:01—15:00分别按相邻5根组成5分钟描述窗口，不跨午休。2026-07-06前后分别建立历史分布和训练；新制度不足60日/504训练日时保留NO_VIEW，单独报告日期和已持仓账户。

## 过程定义及旧实验查重

冲击为5分钟开收盘对数收益低于此前60个同制度同窗口日的5%分位，且低于-5bp。只登记有完整随后30分钟观察机会的固定时间窗口：上午冲击结束不晚于11:00、下午不晚于14:15。触发后固定观察6个5分钟窗口，之后再隔2个5分钟窗口；期间的再次触发属于同一事件。每个被登记事件均保留，包括未修复与再次下跌。日内事件等权汇总，每日为统计单位。

- A：冲击幅度、5分钟修复比例、30分钟修复比例、后续30分钟高于半幅修复价的分钟占比，以及发生修复后又跌破冲击末价的比例。并设A_CONTROL只包含事件有无、幅度及5/30分钟修复，用于单独回答持续性是否超越“已经反弹”。比例可负或大于1，未按未来表现裁剪；模型仅使用训练标准化后的统一±5裁剪。
- B：冲击窗口与随后相邻5分钟窗口，成交额比在[0.8,1.25]时，比较下跌推进的变化除以原冲击幅度。记录相近活跃度占比与推进减弱值；不符合活跃度条件是已知不适用，异常/缺失窗口是未知。它是量价代理，不识别买卖方或机构。
- C：复用旧`CLOSE_PRESSURE_30M_60D`特征值：14:30至15:00收益，乘14:31—15:00成交额占比相对此前60日中位数。旧单特征Logistic两日预测已失败（AUC约0.515、Brier skill为负），读取旧结果并保留失败；不重跑旧独立预测。新用途仅是用户要求的、同一日线基准下的条件增量归因，C参数和方向均不调。其他尾段收益、占比和位置变化保存在过程表作解释，不能临时进入模型。

旧RV20切换以盘中5分钟确认后立即进入、下一日早盘退出，没有本次日线条件对照及30分钟持续性检验，保持其失败记录；旧午后43/75时钟修改、日内相对隔夜分解和日频EMV也不重开。

## 三组比较与时间边界

日线基准D包含当日含分红收益、日内收益、振幅、收盘区间位置、对数成交额、成交额相对20日、对数20日波动和20日动量。D+A、D+B、D+C分别只加入对应一组过程信息；A_CONTROL为预登记解释对照，不参加选优或账户选择。

同一共同完整样本、相同日期、相同标签。模型为标准化岭回归，alpha=1；至少504个成熟训练日，每20交易日重估。均值、尺度及模型只来自当时已经完成退出的历史标签；不划出已被观察的历史作为所谓全新独立验证。主要目标为次日开盘至再下一交易日收盘、含登记权益分红的毛收益。另保留买入当天收盘路径（新份额不可合法退出）及第5日路径，只解释持续时间，不用于调持有期。

主要统计为预测平方误差相对D的减少，按交易日20日分块重抽2,000次，三组比较使用Bonferroni校正的区间；同时报告时间前后半段。A相对A_CONTROL的持续性增量单列95%区间。制度变化后不足样本明确列出，不混作稳定性通过。

## 账户合同

四种模型均运行2万元/20万元、基础/压力费用，共16条完整账户，金融结果差时也完成诊断。仅在实际空仓、输入合格且预测毛收益大于事前预计往返费用时，于次日开盘请求固定份额；100份整手、价格0.001元，现金不足可部分成交，不借款。

基础为单边佣金万二、最低5元、5bp滑点；压力为万四、最低5元、10bp滑点，均为研究假设。事前费用另考虑每边最多一个价位舍入。请求份额在信号日收盘确定；执行日价格、方向涨跌停、09:30/15:00记录成交量10%容量仅约束模拟成交，不能倒过来取消请求。保留未成交、部分成交及原因；这些是条件模拟状态，不是验证过的成交概率。

买入后下一交易日收盘固定退出，满足股票ETF T+1；退出不成则保持库存，于随后收盘重试，不靠亏损或盈利改时间。全部现金日、跳空、浮亏与费用记账。登记日收盘持仓获得分红权益，除息确认应收，付款转现金，卖出不取消既得权益。最后分钟日为统一终点；不足完成固定持有期不再新开仓，受阻库存继续按收盘计价并标记未完成周期。

评价净期望、胜率/盈亏比、尾部、成本、占用、年化、夏普与回撤；20万元基础为主。已执行路径的未扣费损益仅用于解释成本，不改变原决策。历史缺失导致不交易、容量导致低仓位不能作为净优势证据。日线比较和账户结果均不构成真实填单或独立金融验证。
