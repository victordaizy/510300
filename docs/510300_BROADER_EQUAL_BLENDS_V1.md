# 第47轮：加入更频繁的第三个信号

## 两个预定组合

第46轮原学习退出与急跌回升各半，主评价夏普0.944，但急跌回升只有三次主评价持仓，较早表现弱。本轮分别加入一种原已存在、触发更频繁的策略，检验更多机会是否能改善组合。

主方案为“原学习退出、原急跌回升、原放量突破”三个信号各三分之一；第二方案把第三项换成“原偏离均值后首日回升”，同样三等份。原放量突破主评价有二十次完整持仓，普通均值回升有二十五次。选择这些信号时已经知道其旧结果，因此是有记录的历史再研究，不宣称未经选择的独立检验。

原第28轮三信号包含旧日内强弱、趋势切换及放量收强，第34轮为趋势与学习退出各半，均不同于本轮组合。两个新增方案提前固定，不搜索权重，也不更改原信号参数。

## 第三个信号的全部因子与进出条件

|信号|进入条件|退出条件|再次进入|
|---|---|---|---|
|放量突破|当前含分红总回报水平突破此前二十个交易日最高收盘水平，同时当前成交量至少为此前二十日平均成交量的1.5倍。两个窗口都不包括当天。|含分红水平跌破此前十个交易日最低收盘水平；或本次含分红持仓亏损6%；或从持仓最高收盘价值回撤6%；或持有六十个交易日。任一成立即请求下一开盘全部卖出。|实际卖出后至少两个交易日，再满足原条件才能买入。|
|普通均值回升|当前含分红总回报水平低于二十日均值1.5个样本标准差，且当天总回报水平较前一日回升。|总回报恢复至二十日均值；或本次含分红持仓亏损5%；或持有十个交易日。任一成立即请求下一开盘全部卖出。|实际卖出后至少一个交易日，再满足原条件才能买入。|

两种参考策略均为收盘判断、下一开盘执行，买入日计持有第一天，只买一次不追加。持仓价值按实际份额、买入含佣金成本、已确认分红和实际收盘价值计算；高点至少为初始成本。原退出请求未成交时保留。成交量直接沿用既有同单位数据，不把成交金额当份额。

普通均值回升的二十日均值和样本标准差包含当天；标准化偏离等于当前水平减均值，再除以该标准差。突破的二十日高点、十日低点和成交量均值则明确使用此前日期，不能把当日最高价混入“此前收盘高点”。

## 两个原核心信号的全部规则

急跌回升须同时满足：五个交易日累计跌幅仍超过5%；今天总回报较昨日回升；收盘位置至少在当日高低价区间的60%；五日含分红简单收益年化波动率超过六十日波动率的1.5倍。收盘位置是收盘减最低价、再除以最高减最低；区间为零时原值为0.5，不能达到60%条件。波动率均为样本标准差乘二百四十二的平方根。

该参考策略在含分红总回报恢复至二十日均值、持仓亏损4%、盈利6%或持有十个交易日时，请求下一开盘全部退出。实际卖出后至少两个交易日才能再次按四条件进入，不额外要求原进入条件先消失。

原学习退出的进入因子，是六十日日内相对隔夜强弱：每天日内对数涨跌减隔夜对数涨跌，六十日之和除以该窗口样本标准差及六十的平方根，沿用含分红一致口径。该值连续两个收盘大于一，空仓、进入许可有效、距离实际卖出至少两个交易日时，才请求下一开盘进入。

其原退出模型八个因子为：持仓交易日数加一的自然对数；实际份额市值加本周期已确认分红相对买入含佣金成本的浮盈亏；上述持仓价值相对周期最高收盘价值或初始成本中较高者的回撤；固定为一的进入模式；含分红五日对数涨跌；二十日对数涨跌；一百二十日均线偏离；二十日含分红简单收益样本标准差乘二百四十二的平方根。

原线性模型每月在当时已自然结束的最近二十个参考周期上训练，至少十个周期及一百条持仓状态，周期等权。因子减训练均值、除总体标准差后限制在负五至正五，带截距岭回归惩罚一。学习目标仍为持有到原自然退出相对下一开盘卖出的净收益差；本轮直接复用第31轮保存的原模型，不用第44轮五日内标签改版。

原学习退出参考策略在任一条件成立时请求下一开盘全部退出：相对强弱分数连续两日小于零；含分红持仓亏损6%；从最高收盘持仓价值回撤8%；持有六十个交易日；模型连续两个真实持仓收盘预测继续持有收益为负。没有模型时不新增模型退出，原价格时间保护保留。实际卖完后，至少两个交易日，并在空仓时见到原进入条件先消失再重现，才能得到新一次进入许可。

## 组合如何进入、持有和退出

每个参考策略各自维护实际模拟持仓、退出等待及重新进入条件。每天收盘取得三个原基础费用参考策略的状态，愿意买入或继续持有记为一，空仓等待或请求退出记为零。三个状态相加再除以三，作为下一开盘目标股票比例。

因此零个信号为一时目标空仓，一个时约三分之一，两个时约三分之二，三个时满仓。任何必要状态缺失都不能填为零，本轮须先核对全部评价日状态完整。三个模型状态来自各自参考账户，不能误称为组合实际持仓因子的预测。

使用一个统一实际组合账户，每个收盘根据目标、当前净值、实际股票份额及可用现金计算请求，下一开盘以整手、费用、方向性涨跌停和次日可卖条件执行。目标为零时请求全部卖出；目标非零时，目标与实际股票比例相差至少十个百分点才调整。另一个信号加入或离开时，组合允许加减仓，也可能因价格变动达到偏离限制而再平衡；这些费用均进入账户。

组合未成交请求在下一个收盘按最新目标和实际份额重新计算，不添加永久组合退出锁定；三个原参考策略内部仍保留各自退出等待。退出后重新进入由三个参考状态共同决定，不另加一个未声明的冷静期。相同证券统一管理现金和分红，不能把三个单策略收益简单平均当成实际组合结果。
