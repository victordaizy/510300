# 40个百分点高夏普研究V10：期末容量减仓

V3将日常目标和订单限制在20日中位成交额的0.05%以内，但只在评价期最后一天启动期末清仓，UPRO剩余持仓无法单日退出，因此在绩效形成前失败。V3保持关闭，容量线不放宽。

V10授权一个期末执行版本：信号、产品、日期、成本、50%单资产权重上限、容量感知目标、H00300基准和40个百分点/1.50夏普硬门全部保持不变；在可见期最后20个共同美国交易日的第一个开盘停止新开仓，将全部持仓标记为强制待退出，并继续按每日0.05%容量切片，直到可见期末。期末仍有持仓即失败。

20日窗口在结果前固定，不根据实际所需切片数调整。Paper、Shadow、订单、经纪商连接和实盘全部关闭。
