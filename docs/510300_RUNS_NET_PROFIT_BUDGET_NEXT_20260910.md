# 下一项：每月按过去完整净收益的正值分配预算

第168轮直接合并父目标提高了历史收益，但较早历史夏普仍不足一点二。第169轮作为单独的新方法，检验过去完整账户净收益能否帮助分配两套父策略的预算。它使用收益信息，不沿用第167轮的最小方差目标；已关闭的各半、最小方差和进场合并结果均保持。

## 全部因素和唯一预算规则

第一父策略仍为第143轮趋势波动连续预算，第二父策略仍为第165轮收益强弱连续段。两套内部规则、因素、模型、入场版本、周期和退出锁均不修改，不接收新组合账户反馈。零新训练、零新增参考账户、零外部资料。

每段评价分别读取两套对应基础费用父账户的完整逐日净收益，包括现金日、佣金、滑点及分红确认。每天净收益等于当日净资产除以前一日净资产再减一；首日以前值二十万元计算。两段历史分别初始化，不能借用另一段账户补足窗口。终点开盘清算收益不能提前用于收盘决定，两个父账户必须与市场交易日历一致。

在评价开始前的准备收盘，两套预算各为一半。每月首个交易日十五点零五分，取包括当天收盘在内的最近二百四十二个完整日净收益，分别计算简单平均值。不是只统计持仓日，也不是只统计盈利交易。

将两套平均值各自与零比较：正值保留，零和负值取零。两项正值之和大于零时，第一套预算等于第一项正值占两项之和的比例，第二套预算等于第二项占比；只有一套平均净收益为正时，预算全部分配给该父策略。两套平均净收益都不大于零时，两预算均明确为零，组合目标为现金。

若月首窗口不足二百四十二日或任一日净收益缺失，则不作新收益判断，保留上次已知的两套预算；不能把缺失填成零收益。月中预算保持，不在每年或每次入场时重置。先前预算为双零时，窗口缺失同样保留这一已知预算。均值恰好为零按零处理，不增加显著性筛选或临时容差。

基础及压力两档费用共用上述基础账户收益得到的预算，但每天分别读取各自费用的两套父收盘目标。两套父目标都明确时，合成目标等于各自预算乘各自目标再相加；任何父目标未知，合成目标仍未知，即使当时预算为零也不掩盖缺失。

每次月首保存窗口起止、样本数、两项平均日净收益、正值部分、旧预算、新预算和状态。历史平均收益仅用于该固定预算公式，不解释为已证明的未来收益预测。

## 进入、退出、调整及再次进入

判断在当天十五点零五分，下一真实开盘执行。空仓且目标为正时，使用上一收盘本账户净资产与原始收盘价算出目标份额，向下取一百份整手；取整仍为零则不买入。

已有持仓且目标为正，目标与实际市值占净资产比例偏差不足十个百分点时保持实际份额；达到十个百分点则调至目标中心。带外正目标按整手算成零份时全部卖出。合成目标明确为零时优先请求全部卖出，不受调仓带阻拦；这包括父目标归零，以及月首两套历史平均净收益都不为正的现金预算。固定终点开盘也优先清算。

未知目标保持实际份额；受阻后下一收盘依据最新目标重新决定。实际全部退出后，新的可执行正目标可以再次进入，不增加等待期或永久退出锁。父策略的内部退出及再入场规则始终独立运行。

## 固定范围与验证

仅一套二百四十二日、月首更新、平均净收益取正值的规则；不搜索窗口、系数、更新频率、阈值、年份或费用。新增四个实际账户。保存对照为第168轮相加封顶、第167轮月度风险预算、第166轮固定各半、第143轮、第165轮及买入持有；每段两费用合计十四条指标记录。

主历史2020年1月2日至2026年8月14日开盘；较早历史2015年1月5日至2019年12月31日开盘。每账户二十万元、二百四十二日年化、现金和无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。一百份整手、零点零零一元价位、原百分之十方向限价、次日可卖、真实下一开盘、资金约束、登记除息到账及终点清算均保留。

必要测试包括均值和预算手算、单边正值、双边非正及恰好零、窗口不足和缺失保持、月首和月中、两段初始化、未来与终点隔离、费用及父目标未知、实际进入退出再入场、分红和终点清算。通过后纳入全部中文父规则，一次冻结，再运行四个新账户并独立重算每次预算和完整账户。

完整目标仍是成本后夏普至少一点二、稳定超额及独立证据。未达到则关闭这一固定方法，保留全部历史记录。此文为第169轮事前方案，尚未登记、实现、测试、冻结或计算新账户。
