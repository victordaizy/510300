## 改动目的与四套固定方案

继续使用第201轮没有新增亏损保护的简单合并目标，本次只检验在形成买入申请时是否避免追随当日上涨。具体机制是“收盘已知的当天涨幅决定是否允许新增买入”，不是下一开盘的限价单；不承诺下一开盘一定能买得更便宜，也不需要新增盘中或券商功能资料。

第201轮零个百分点和二十个百分点调仓门槛各比较两档涨幅上限：当日含分红简单收益不得大于零，以及不得大于1%。共四套新设置、十六条新账户，原两套没有买入过滤的账户直接复用。上限只影响正的买入申请，不影响卖出、原信号退出或终点清仓。

## 唯一新增因素

每天收盘用当天原始收盘价加当天每份除息分红，除以前一交易日原始收盘价，再减一，得到当天含分红简单收益。只读到决定收盘为止的数据；收盘以后或下一开盘的涨跌不能影响该决定。前收盘无效或必要值缺失时，此因素未知。

主数据为reports/research/510300_adaptive_allocation_v1/features.parquet，其中原始收盘、previous_close和dividend已有保存。本轮从价格和分红明确计算，不把数据文件中某个名称相似但口径不同的收益列直接混用。分红除息导致的原始价格下降不能被误当成等额市场亏损。

涨幅上限为零时，完整的下跌或持平日允许买入，上涨日暂缓；上限为1%时，涨幅不超过1%允许买入，严格超过1%才暂缓。等于上限允许。因素未知时不产生新增买入，已经持有的股票仍可按原目标减仓或退出。

## 进入、调整、退出和再次尝试

在每个收盘先按照本账户自己的净资产、实有份额、原合并目标与本候选零或二十个百分点门槛，计算正常申请量。目标份额向下取整到整百份，已有正目标偏差严格小于门槛保持份额，达到门槛则调至目标中心；空仓初次正目标直接计算买入，不能被已有持仓的调仓门槛拦住。

正常申请量大于零，且当天含分红收益在本候选上限内，才提交该买入申请。正常申请量大于零但当天涨幅超过上限，或收益因素未知，则本次申请量改为零，保持现有份额。正常申请量为零或小于零，保持原正常申请，不受涨幅上限限制。这包括降低正目标所需的部分卖出、整手取整为零造成的全部卖出及明确零目标退出。

原合并目标未知时保持已有份额，不把未知补成零。被买入条件拦住的原正目标仍记录为正目标，另记录申请被抑制的原因；不能把“暂不新增”写成“要求空仓”。

下一收盘根据最新原目标、当日本账户实际净资产和份额、当天含分红涨跌重新计算。没有挂单延续，没有固定等待日数，也没有保护退出后的归零锁。允许条件恢复即可重新尝试买入，部分买入未成交不会假装已达目标。既有退出规则不增加第202轮亏损保护。

决定时点为收盘十五时零五分，执行仍使用下一真实开盘及原基础／压力费用假设。下一开盘即使跳涨，也按已经决定的申请和原规则执行；本过滤不是开盘价上限，也不能在看见开盘价后回改前收盘申请。终点开盘优先清仓。
