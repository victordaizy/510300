# 510300原始季度申购赎回资料：来源收集规则

只收集510300本体的原始定期公告，不把联接基金或其他沪深300ETF误作本基金。此次为资料工作，尚未登记投资策略、读取新策略收益或改变既有账户。

上交所基金公告网页公开使用基金公告查询接口，类别为定期报告，代码为510300。按2012年至2026年逐年查询，2026年截至8月14日，采用网页默认25条分页。每页保存完整请求、返回内容、抓取时间和哈希。响应声明的总数与实际唯一文件数量必须相等；同一页不足但声明更多不得当作完成。保留全体定期公告，包括年报、中报、季报及更正，之后按标题识别季度。

季度数据预期范围为2012年第三季度至2026年第二季度，共56期。基金成立初期2012年第二季度仅作可得资料记录，不用它决定后续样本。若缺少任何预期季度，明确列出缺口，不能静默删期。出现同季更正或多版文件，保留版本及各自公布时间，未解决关联前不准覆盖原值。

公告目录日期是主要公布日期证据；与PDF封面送出日和文件名日期比较。网站目录中的文件夹日可能是前一天的文件准备日期，不能把它当作提前可用的依据。只有日期时，最早可用时点保守地放在公告日期之后第一个A股交易日开盘。PDF创建或修改元数据用于识别版本线索，不独立证明公开时间。无法对应日期或身份的报告保留无判断。

原始PDF逐份读取：核对基金主代码510300、报告封面季度、期间起止日；在“开放式基金份额变动”节下识别期初份额、申购份额、赎回份额、拆分变化和期末份额，并核对单位为“份”。每个数值保留所在页、行或单元格、原文金额和文件哈希。份额数值按十进制定点数处理，避免大额份额浮点尾差被当成真实变化。

会计衔接为期初份额加申购、减赎回、加拆分变化，等于期末份额。拆分格横线须保留原文状态；表格明确无活动时可以在该表会计衔接中按无拆分处理，不能把缺失报告或不明格填零。连续季度期末与下一季度期初应对应；不对应时记录具体差额及原因，不能自行平滑。

申购、赎回和净申购分别保存。净申购份额除期初份额属于份额扩张或收缩强度，并不等于人民币现金流，更不等于全市场公募申购。ETF还可能涉及实物申赎或套利，不能事先宣称份额增加就代表未来价格上涨。是否含可预测信息，留待数据完成后另行冻结有限策略和完整账户检验。

仅使用公开免费来源，保留成功分片，失败可从检查点恢复。普通网络短暂错误最多三次尝试；服务器明确限流或拒绝时停止该来源，不绕过访问限制。来源完整性及数值核对是必要检查，不开展额外安全审计。
