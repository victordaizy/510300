# 第189轮：周四收盘决定下一开盘清仓

目标仍为全账户净夏普至少1.2及复合年化至少10%，基础与压力费用都需检查。只使用已有510300及现金数据，现金收益为零，不融资、不增加外部数据或模型训练。

第188轮来源账户自身的收益暂停条件没有改善结果。新完成的时段归因显示，第181轮主历史收益主要来自日内，含股息隔夜合计为负；但较早第182轮的隔夜含股息为正，不能将隔夜全部删除。直接使用ETF日线收盘价假设收盘成交也缺少覆盖整个历史的依据。本轮保持原下一开盘执行，只研究一个事先固定的星期条件。

## 唯一候选和完整进出规则

1. 每个交易日收盘后15时05分，读取第181轮对应费用下已保存的目标仓位，读取当日自然日期的星期。
2. 如果当前已结束的交易日是星期四，新组合目标为零，下一次开盘请求全部退出。这个日历退出条件独立于来源目标是否未知。
3. 如果当前交易日不是星期四，完全采用来源目标：明确正目标下一开盘进入或调整；明确零下一开盘退出；未知保持实际已有份额。
4. 普通周内通常表现为周五开盘退出、周五收盘产生新目标后下一开盘恢复。星期四后的下一交易日遇节假日推迟，仍在实际下一开盘执行该清仓指令；不利用未来休市天数、未来行情或事后修正的假日日历提前调整。
5. 如果星期四没有开市，就没有星期四收盘决定，也不把退出提前到星期三。该规则不保证所有周末与节假日前都空仓。它也会放弃正常周五的日内持仓收益，不能只计算少承受的隔夜亏损。

选择星期四，是为了在沿用下一开盘时钟下检验一个固定的周末前降低持仓规则；尚未计算按星期细分的择优组合。本轮只登记这一个候选，不轮流试星期一到星期五后挑选最优日，也不改变旧日历研究的记录。
