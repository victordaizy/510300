# 第122轮：不同历史周期的相似状态退出

2026年9月9日，只登记一个固定设置。目标仍为完整账户扣费净夏普至少1.2及稳定超额。用现有免费价格、分红和已经成熟的参考周期，检验相似行情的后续结果能否改善退出。没有新增收益数据来源或交易标的。

## 八项状态因子

1. 持仓时间：本笔已持仓的交易日数加一，再取自然对数，包含实际买入日。
2. 市场持仓涨跌：当前每份价值除以买入日原始开盘价，再减一。每份价值等于当前收盘价，加本笔已经取得并确认的每份分红，不包含已经支付的买入费用。
3. 市场持仓回撤：当前每份价值除以本笔市场每份价值的最高值，再减一。最高值从实际买入日原开盘价开始，逐个持仓收盘更新；中间日期缺失或跳过，峰值持续未知直到下一实际新持仓。
4. 入场模式：保留原六十日日内相对隔夜强弱策略的模式标记。本次只有一个进入模式，这一列恒定，不能将其当作有额外变化的信息。
5. 五日涨跌：最近五个交易日的含分红日对数收益之和。
6. 二十日涨跌：最近二十个交易日的含分红日对数收益之和。
7. 长期均线偏离：当日含分红财富除以最近一百二十日平均财富，再减一。
8. 二十日波动：最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

含分红简单收益为当日收盘加当日每份分红，除以前收盘，再减一；一加该简单收益取自然对数为日对数收益，逐日连乘一加简单收益形成市场财富。市场财富用于公共价格因子；本笔持仓的涨跌和回撤只取得其实际登记权益。分红除息确认应收、以后到账，只计一次。

## 训练样本与相似状态选择

复用原基础费用、自然退出参考周期的保存继续收益标签：比较原规则较晚退出与本收盘后下一开盘提前退出的净卖出所得及新增登记权益，差额除以参考份额乘下一开盘原价。整个参考周期自然结束后，全部状态才成熟。未结束或仅终点强制退出的周期不能用作标签。这里没有重生成新收益目标。

初始2014年12月31日及此后每月首个交易日收盘后，读取当时已经完整结束的最近二十个参考周期；至少十个周期、一百行完整状态。原一百四十一个时钟中一百一十四个满足支持，另外二十七个不足保留，没有观点。已有一千四百六十一行、三十四个参考周期的输入支持检查已完成，不再重复补齐数据。

每个周期总训练权重为一，内部状态平分。用这些权重计算八项训练均值和总体标准差；标准差不超过万亿分之一时置一，标准化后截在负五至正五。训练行先按周期编号和起点日期排序，保证均值、距离以及平局处理可重复。任一必要输入或标签缺失则整月不可用，不能删掉不利行补齐。

预测时，当前八项状态用保存均值和尺度进行相同标准化，计算它与每个成熟历史状态的八项差值平方之和。先在每个不同历史周期内取距离最小的一行，再从这些代表点中取最近五个不同周期。每个入选周期一票，预测继续收益为这五个保存标签的简单平均。

固定五个邻居，不扫描数量、窗口、特征、距离权重、半径、截断或目标。周期内精确等距时较早起点优先；不同周期精确等距时周期编号较小优先，再按较早起点。不能根据标签正负或收益选择平局胜者。不会让同一个长周期的五个相邻交易日占满五个邻居；也不把五个近邻或各月重复样本当作独立验证。

方法参考[scikit-learn官方近邻回归说明](https://scikit-learn.org/stable/modules/neighbors.html)。每个周期限制一个代表点是本研究的具体设计。该方法保留成熟实例并按距离预测，不拟合线性系数；月度模型建立包含标准化和实例保存。八维距离只是相似性近似，不能声称选出的行情必然重演，也没有根据历史表现添加距离拒绝阈值。

## 进入、退出与再次进入

进入条件沿用原规则：每日计算日内对数涨跌减隔夜对数涨跌，将最近六十日差值之和除以这六十日差值的样本标准差，再除以六十的平方根。日内涨跌按收盘加分红除以开盘加分红取对数；隔夜涨跌按开盘加分红除以前收盘取对数。

强弱分数连续两个收盘严格大于一、原资料完整、账户空仓、有再次进入资格且距离实际退出至少两个交易日时，下一开盘按自身可用现金、真实费用及整百份限制请求买入。请求数量根据收盘已知信息确定，不能提前用下一开盘价选择数量。

实际持仓每个收盘更新市场路径。满足以下任何一个条件，即请求下一开盘全部退出：

1. 相似周期模型连续两个收盘预测继续收益严格为负。
2. 原六十日强弱分数连续两个收盘低于零。
3. 实际含分红持仓价值相对真实买入金额及佣金亏损达到百分之六。
4. 实际持仓价值相对以真实投入为初值的账户周期最高值回落达到百分之八。
5. 已持仓满六十个交易日。

第三、第四项使用含真实费用的账户风控价值，与学习用的不含已付买入费用的市场路径分开。学习输入缺失、没有成熟模型或预测非负，连续负预测计数清零；原可知退出条件继续有效。已经锁定但受阻的卖出逐日延续，后续模型转正不撤销。

实际卖出后，必须在空仓时先见到旧进入条件消失，再等待重新出现并满足两交易日冷却。实际新买入重置学习确认和市场路径高点。没有新增止盈、加仓、部分退出或第121轮联合动作表。未成交、现金日及无模型持仓日都保留，不把没有观点转换成虚构的现金收益。
