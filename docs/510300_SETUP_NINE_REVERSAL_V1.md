# 第130轮：九次相对弱势反弹与强势退出

本轮只登记一项简单反弹策略：连续九次相对四日前走弱时进入，连续九次相对四日前走强时退出。只用原日线和现金分红，不训练模型，直接检验完整账户。第129轮缩量累计趋势的失败保留，本轮不改其公式或均线周期。

## 来源与含义

[DeMARK官方说明](https://demark.com/sequential-indicator/)公开的准备阶段，使用当前收盘与四个交易日前的比较，并对连续九次强弱作标记。完整体系还包括倒计时等阶段。本项目将这个准备阶段作为一项简化反弹假设，分红、首次事件及以下交易规则由项目预先明确，不称复制完整Sequential，也不把九次弱势当作已经证明的底部。

已完成代码、协议和配置查重；第26轮六项量价急跌与低点收复策略均不是本次四日比较的九次首次事件。旧结果保留，研究输入和方法检查在新序列、信号及收益读取前记录。

## 全部因子与计算规则

使用每个交易日的收盘、前收盘、当日每份除息现金及日期。每一天的经济涨跌倍数，是当天收盘加每份除息现金，再除以前收盘。最近四个交易日的倍数相乘，与一比较：小于一为四日经济变化负，大于一为正，等于一为零。

该比较把正常现金分配纳入价格变化。计算时把保存的十进制价格转换为精确分数，按分数结果判断正、负或零，再保存普通数值形式的四日涨跌幅，避免正常除息或价格恰相等被浮点残差误判。未使用成交量、公募净申购或前瞻EPS。

弱势连续计数：当天四日变化为负，则在前一天弱势计数上加一，并将强势计数清零。当天四日变化为正，强势计数加一、弱势清零。恰为零，两者都清零。因此这里不是连续九天下跌，而是连续九个收盘各自相对四日前为弱势。

计数可以超过九。只有某个连续段第一次恰好到九当天发出事件：弱势到九为进入事件，强势到九为退出事件。第十次、第十一次等不重复发事件。方向中断后从新的连续段重新计数。

原始行情第一天2012年5月28日没有前收盘，最初四行保留准备不足状态；第五个收盘才有完整四日比较，从这里开始计算观察到的连续段。主和较早历史共用同一完整因果前缀，不因账户开始日期而重置计数。

首行的结构性前收盘空值之外，必要价格和分红必须完整有限，价格为正、分红非负。内部缺口从当天起保留无观点及未知计数，不用零替代、不跨缺口拼接，也不在后续自行重启。无观点时保持实际份额，已经锁定的退出照常执行。

## 进入与再次进入

实际空仓且当天弱势计数恰到九，下一交易日开盘请求按可用资金买入可负担的最多整百份。持仓时遇到同向事件不加仓、不每日重新满仓。

买入因涨停等原因未成交，如果后续收盘没有新的九次事件，就回到等待，不凭之前的事件反复补买。实际卖完后也要等待下一次新的弱势九次事件，没有额外冷却天数或旧信号重新出现的要求。

## 退出与持有

持仓且当天强势计数恰到九，下一开盘请求全部卖出。卖出受阻就一直保留退出请求，后续计数变化、缺失或新的进入事件都不能取消已经锁定的退出。

其余时候保持实际已有份额。研究终点统一在最后开盘优先清仓，不使用终点未知收盘。没有加入日内隔夜强弱、百分之六止损、百分之八追踪、六十日持仓上限或额外止盈，避免混入其他策略规则。

## 账户、验证与裁决

一项固定设置，主历史2020年1月2日至2026年8月14日开盘、较早历史2015年1月5日至2019年12月31日开盘；分别1604和1219个交易日，每账户20万元。两段两费用，共四个新实际账户。复用第114、32、91及买入持有的16个保存对照，不重复生成或计作新策略。

仅510300与现金，242日年化，现金和无风险收益零。基础费用佣金万分之二、每次最低5元、滑点万分之五；压力费用佣金万分之四、每次最低5元、滑点千分之一。100份整手、0.001元最小价位、次日可卖、方向涨跌停、登记分红权益、除息应收和实际到账全沿用原经济账户。

七项必要合成测试覆盖四日精确比较、首次九次与超过九次、中断和相等、未来不改过去、缺失、实际次日交易、买入不重复和卖出锁定。测试通过并冻结后一次运行四账户；保存结果用独立等价公式和共用账户核对程序检查，不重跑旧模型或账户。
