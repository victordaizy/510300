# CSI300 PIT 基本面低反应：官方财务事实 V1.7 补齐协议

## 1. 协议状态

- 协议编号：`CSI300_PIT_FUNDAMENTAL_UNDERREACTION_OFFICIAL_FACTS_V1_7`
- 解析器：`CSI300_PIT_OFFICIAL_FINANCIAL_FACTS_ADJACENT_NOTE_EXTENDED_PROFIT_QUARTERLY_IMAGE_IDENTITY_V1_11_0`
- 时区：`Asia/Shanghai`
- 研究边界：仅采集与核验官方定期报告中的九项财务事实。
- 冻结时点：V1.6 全量缺口复解析完成之后、V1.7 缺口复解析与任何未来收益读取之前。
- 交易边界：`DISCOVERY_ONLY / NO_TRADE`；不创建信号、组合、仓位、订单或券商连接。

## 2. 继承与隔离

V1.7 继承 V1.6 的目标事件、官方公告队列、PIT 发布时间约束、九项指标、单位规则、成本与覆盖率门槛。V1.6 检查点、事实表、依赖表、收据与报告均不可修改。

V1.7 使用独立检查点目录、事实表、依赖表、收据和报告。迁移仅允许复制 V1.6 的 `PARSED_COMPLETE`、九项唯一且无缺口的检查点；V1.6 的 `PARSED_INCOMPLETE` 检查点不得迁移，必须从冻结的官方 PDF URL 重新解析。

## 3. V1.7 新增、且仅新增的补齐路径

### 3.1 相邻附注页净应收账款

仅当同一合并财务报表附注的相邻页面能同时证明当前期和上期以下恒等式时，才接纳纯应收账款：

`应收票据 + 应收账款原值 - 坏账准备 = 资产负债表“应收票据及应收账款”合并行`

禁止把“应收账款及合同资产”或其他混合口径直接当作纯应收账款。中国联通 2018 年一季报固定为拒绝负例；若纯应收账款不可从官方原文唯一拆出，必须保持 `NO_VIEW_REQUIRED_OFFICIAL_FINANCIAL_FACTS_INCOMPLETE`。

### 3.2 扩展扣非归母净利润标签

只接纳主财务摘要中明确指向“归属于母公司/上市公司股东的扣除非经常性损益后的净利润”的完整或相邻页跨页标签。Q3 必须由同页/同表头证明累计列；不得把单季列、百分比列或相邻指标列拼接为累计值。

### 3.3 扩展归母净利润标签

支持“归属于母公司所有者/股东的净利润”“归属于本公司股东的净利润”及标签末尾“利润”跨页的版式。只有当前期和上期均满足以下合并利润表恒等式时才接纳：

`净利润 = 归母净利润 + 少数股东损益`

单位只能来自同一合并利润表标题页或其延续页；不得从其他报表或附注借用单位。

### 3.4 季报图片附录 OCR

仅适用于页数不超过 80 页、明确出现“附录/财务报表”锚点、且锚点后存在连续低文本图片页直到接近文末的 Q1/Q3 公告。

- 使用两种固定渲染比例独立 OCR。
- 目标行必须由精确财务标签定位。
- 两个比例的标准化金额必须一致；唯一允许的字形补偿是同页同值下经实样本固定的“存货”OCR 字形差异。
- 单位必须由既有归母净利润双比例锚定，并由“资产总计 = 负债和所有者权益总计”再次唯一核验。
- 总负债只能在资产、权益与负债合计恒等式成立时接纳。

### 3.5 文本总负债恒等式

文本路径必须排除“归属于本公司股东权益合计”等归母权益小计，只允许精确的总权益。当前期和上期均须同时满足：

`资产总计 = 负债合计 + 所有者权益合计 = 负债和所有者权益总计`

且当前期资产总计必须与已经接纳的 `TOTAL_ASSETS_END` 一致。

## 4. 固定回放门

冻结前只运行定界的 37 份官方 PDF 回放：

- 25 份 V1.6 固定权威样本：九项完整、逐值不变；
- 11 份 V1.7 可补齐正例：原 V1.6 已接纳指标逐值不变，新增指标逐值符合固定契约，文档补齐为 9/9；
- 1 份 V1.7 拒绝负例：仍只缺纯应收账款，不得错误补齐。

每份 PDF 必须绑定官方 URL、字节数与 SHA-256。回放过程不得读取市场价格、未来收益或未来标签。

## 5. 全量运行与覆盖率门

全量队列和事件依赖仍沿用冻结的原始项目协议：

- 全部目标文档必须达到终态；下载失败必须为 0；
- 总事件完整率至少 90%；
- 每个发布年份完整率至少 80%；
- 目标事件不少于 50 的行业完整率至少 75%。

任一门不满足，状态必须为 `BLOCKED_OFFICIAL_PDF_FACT_COVERAGE_BELOW_FROZEN_GATE`，并保持 `RETURN_EVALUATION=NOT_ALLOWED`。不得通过替换数据源、填充缺失值、改变指标定义、筛选年份/行业或读取收益来救援。

## 6. 必须保留的核验

仅保留以下与研究结论直接相关的核验：

- 官方来源主机、PDF 文件头、字节数与 SHA-256；
- 公告发布时间与报告期的 PIT 时序；
- 九项指标的页码、标签、原始值、单位和定位器；
- 双期会计恒等式、OCR 双比例一致性及覆盖率门；
- 独立检查点、原子 gzip JSON、迁移收据和冻结清单哈希。

不执行泛化安全、隐私、漏洞、依赖供应链或全工作区扫描。

- `future_label_created = false`
- `portfolio_return_calculated = false`
- `trading_authorization = false`
- `return_evaluation = NOT_ALLOWED`
