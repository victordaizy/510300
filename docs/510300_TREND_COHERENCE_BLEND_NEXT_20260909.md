# 第145轮拟研究：按上升趋势的连贯程度分配预算

144的继续持有预测幅度组合提高较早历史夏普，但主历史恶化、四情景最低夏普下降，该公式结束。143仍为当前均衡比较候选，未完成全目标。下一项独立计算价格路径的上升方向和线性连贯程度，不改变144预测方向、期限或映射来救回结果。

每天15:05，取当日及此前完整120个交易日的含分红财富，逐日取自然对数。将这些对数财富按时间从第一日至第一百二十日配对，计算带常数项直线的斜率及拟合优度。时间和对数财富各自减去窗口内均值；斜率为两者偏差乘积之和除以时间偏差平方和；拟合优度为两者偏差乘积之和的平方，除以时间偏差平方和与对数财富偏差平方和的乘积。

窗口完整且对数财富完全相同，斜率和拟合优度均按已知零处理。任何财富缺失使整个需要它的120日窗口无观点；非正财富或无穷值非法。拟合优度只允许浮点边界截在零至一，不把未知补零。

当斜率为正，131预算等于该拟合优度；斜率为零或负，131预算零。143得到其余预算。两个父目标均已知才合成为最终目标，即使一方预算零也保留父目标缺失。两档费用使用相同市场预算，但各取对应费用的父目标。这个预算是待检验的机制：上升越连贯，更多依赖131；其余情形更多保留143。拟合优度不是预测上涨概率，高值也不证明未来有效。

此项不拟合新的收益预测模型，但确实逐日计算滚动线性趋势统计；不将两者混称完全没有计算。保持120日这个现有趋势尺度，仅一项公式，无候选窗口、阈值、方向或比例搜索。131、143共享底层成分，不算独立模型确认。NIST说明拟合优度的含义和局限，不提供本策略的投资有效性证明：[NIST模型拟合说明](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm)。

实际进入、十个百分点调仓带宽、明确零目标全退、未知不调整、下一开盘、受阻后每收盘重算、再次正目标可重入及终点开盘清仓保持。保留原父策略各自内部退出条件。仅新生成四账户，保存对照131、143、144和买入持有共十六条；零外部数据下载、零新参考账户及零收益预测模型训练。先完成必要测试、冻结，然后只运行一次。失败不改变本项窗口、趋势方向、拟合优度定义或父来源救回。
