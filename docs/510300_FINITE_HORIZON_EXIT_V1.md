# 第118轮：按持仓天数倒推后续退出

登记两个设置：主要设置按持仓天数从后向前学习继续持有价值，并更新成熟训练路径的后续退出选择；对照在同样每个持仓日学习一直持有至原自然退出的价值。两者使用相同八项信息、逐日样本支持、岭回归和当日一次负值退出确认。对照用于区分倒推更新目标的贡献，不能事后挑一个设置冒充事前主要策略。

方法参考[Longstaff与Schwartz的逐期继续价值估计](https://people.math.ethz.ch/~hjfurrer/teaching/LongstaffSchwartzAmericanOptionsLeastSquareMonteCarlo.pdf)。原论文讨论期权定价，本研究改用已经完整成熟的真实历史参考周期，不生成随机价格；论文不构成510300盈利证据。这与第52轮把所有年龄合并、反复自举同一模型不同，与第96轮空仓买入或等待迭代也不同。

## 八项因子与当时可知信息

1. 持仓时间：本笔已持仓交易日数加一后取自然对数。
2. 市场路径涨跌：当前每份价值除以实际买入日的原开盘价，再减一。当前每份价值是收盘价加本笔已经取得并确认的每份分红，不含已付买入佣金和滑点。
3. 市场路径回撤：当前每份价值除以本笔市场每份价值的最高值，再减一。最高值从原买入开盘价开始，每个实际持仓收盘更新。
4. 入场模式：原六十日日内相对隔夜强弱策略的模式标记。
5. 五日涨跌：最近五日含分红日对数收益之和。
6. 二十日涨跌：最近二十日含分红日对数收益之和。
7. 一百二十日均线偏离：当日含分红财富除以最近一百二十日平均财富，再减一。
8. 二十日波动：最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

日含分红简单收益为收盘加当日每份分红，除以前收盘，再减一；对数收益为一加简单收益取自然对数；财富逐日连乘一加简单收益。第二、第三项只计本笔实际登记并确认的分红，除息应收和到账不重复。实际账户的风险退出仍使用真实已付费用及持仓价值。

每个持仓日独立建模，因此第一项在同一个小模型内是常量，本次单一进入模式也为常量；它们保留状态身份，不能宣称贡献横截面解释力。复用第117轮已验证的完整持仓路径及1461个原训练状态，不能从缺了中间日期的训练行计算峰值。必要中间收盘未知则峰值保持未知至下一笔实际持仓。

## 每月成熟样本和逐持仓日支持

沿用原初始2014年12月31日及此后每月首交易日收盘训练时钟。先选当时已完整自然结束的最近二十个参考周期，整个月窗口至少十周期、一百状态；原141个时点中114个满足，27个不足，最早有效月份2017年3月1日。终点强制平仓及未结束周期不能提供标签。

再按持仓第一日至第五十九日拆分；每个年龄至少十个独立完整周期，一个周期在该年龄只能一行、权重一。每个年龄最多二十行，原一百行门槛只属于整个月，不能宣称每个逐日模型也有一百行。已有支持统计确定6726个成熟月份与年龄组合，其中5685个可拟合、1041个不足。不改十周期支持，不借邻近年龄，不用未来月份。

最早有效月只有持仓第一天满足十周期；最后有效月的第一至四十二天满足。该限制原样保留。整月八项训练输入缺失时整月没有模型，不删除缺失周期或行。逐年龄解算失败时该年龄没有模型，不改求解器、惩罚或参数。

## 可成交的历史退出现金流

每个原完整参考周期，从买入之后首个交易日到原自然退出日，使用原账户成交函数检查每个开盘能否全部卖出。保留整百份、次日可卖、方向涨跌停、价位取整、基础卖出佣金和滑点。原自然退出必须仍可成交，否则不能沿用原成熟边界。

任一训练收盘的“立即退出”指该收盘之后第一个可全部卖出的开盘。请求之后因方向限制受阻则持续等待，不因之后信号变化取消。退出经济价值等于实际净卖出收入，加买入日及之后、卖出日之前登记取得的分红权益；以前已取得的共同权益在早晚退出差中抵消，未来到账不再次计收益。

分红权益必须最迟在原完整周期终点已经除息确认，才能沿用原月度成熟时点；否则该原成熟口径无效，停止，不提前读取尚未确认权益。使用未来开盘和分红仅构造已经完整成熟周期的训练目标，不作为当前账户预测输入。现金流表不是新的参考买入策略，没有新增全程参考账户。

每个比较目标以原参考份额乘立即可成交开盘原价为分母，将较晚退出经济价值减立即退出经济价值转为相对值。若立即退出已等于自然退出，差为零并保留该行。两个设置完全共用现金流、分母和基础训练费用；压力实际账户仍独立扣压力费用。

## 倒推、对照及共同拟合

每月先把每条成熟路径的后续退出日设为原自然退出日。从第五十九个持仓日向第一日依次处理：

1. 对该年龄每条路径，主要目标是目前已选后续退出的经济价值，减当前立即可退出经济价值，再除以相同分母。对照目标是原自然退出经济价值减当前立即可退出经济价值，再除以该分母。
2. 两个目标共用该年龄八因子的训练均值与总体标准差。标准差不超过万亿分之一时按一处理，标准化值限制在负五至五。所有独立周期等权。
3. 两个目标共同求解一套设计矩阵的线性岭回归，八系数惩罚一，公共截距不惩罚。每个目标有自己的系数和截距，不在不同周期另拟截距；同年龄每周期一行，周期固定截距会吞掉全部变化。
4. 用主要模型在该年龄训练状态上的预测决定是否更新后续退出：预测严格为负则改为当前立即可成交开盘，否则保留已选后续退出。决定依据是预测，不是每条路径实际未来利润正负，更不能选择未来最高价。
5. 没有足够周期或模型不可用的年龄不增加新的学习退出，保留已经估计的更晚年龄选择及原自然退出边界。对照始终以原自然退出为目标，不随主要模型选择而改变。

计划5685次共同矩阵求解，产生11370个标量目标模型，不能将其说成只有114次拟合；114是有效训练月份数。共同矩阵只节省计算，不让两个目标相互污染。

部署时，每个实际持仓收盘只取当时已完成的最近月份、当前准确持仓日的模型。主要设置读取主要模型，对照读取固定自然目标模型；不使用其他年龄或以后月份。模型或当前必要输入未知时预测保持未知，不填零，不产生新增学习退出，原可知保护及已锁定请求继续。

## 进入、退出和再次进入

每日计算日内对数涨跌减隔夜对数涨跌。日内为收盘加分红除以开盘加分红取对数，隔夜为开盘加分红除以前收盘取对数。六十日差值之和除以六十日样本标准差，再除以六十的平方根，得到强弱分数。

强弱分数连续两个收盘严格大于一、原资料完整、账户空仓、有重新进入资格且距离实际退出至少两个交易日时，下一开盘按自身可用现金、真实费用和整百份限制请求买入。

持仓每个收盘检查以下条件，任一成立则下一开盘请求全部退出：当日该设置模型预测继续收益严格为负；原强弱分数连续两个收盘低于零；含已确认分红的实际持仓价值较真实买入投入亏损达到百分之六；从原账户持仓价值高点回落达到百分之八；持仓满六十个交易日。

两个设置均只需当日一次负值确认，以符合逐期倒推的退出选择。原价格进入及价格退出仍需各自两日确认。模型不适用的第六十日仍执行原期限保护。亏损与回撤保护包含真实交易费用；模型两项市场路径不包含已付买入费用。无新增止盈、加仓、分批退出。

受阻退出逐日继续请求，后续预测转正不取消。退出后在空仓时必须先见旧进入条件消失，再等重新出现且满足两日冷却；模型更新不授予重新进入资格。新实际持仓重新建立自己的路径高点和预测计数。

## 固定评价和停止条件

主历史2020年1月2日至2026年8月14日终点开盘1604日；较早历史2015年1月5日至2019年12月31日终点开盘1219日。各自二十万元起始现金，242日年化，现金及夏普无风险收益假设零。基础单边佣金万分之二、最低五元、滑点万分之五；压力万分之四、最低五元、滑点千分之一。

保留100份整手、0.001元价位、次日可卖、方向涨跌停、现金限制、分红登记及应收到账、全部现金日、未知状态和终点清仓。两个设置各跑主与较早、基础与压力，共八个新的独立完整账户；复用114、32、91及买入持有对照。零新参考。

八项必要测试通过后冻结，随后构造现金流、拟合并回测。目标仍为扣费净夏普至少1.2及稳定超额，反复研究过的历史不作为独立验证。若倒推没有跨费用、跨历史的有效增量，结束该有限比较，不改年龄分箱、十周期门槛、窗口、特征、惩罚、确认次数、目标单位或训练费用挽救。仅研究510300与现金，EPS、公募及慢源暂停，无GPT审阅包和额外安全审计。
