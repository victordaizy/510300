# 下一项：合并两套既定策略的进场机会

第167轮每月风险预算提高了主历史夏普，但较早历史约零点九三，未解决跨阶段表现问题。第168轮检验进场机会合并：当只有一套父策略有正目标时，使用该策略既定目标规模；两套同时有正目标时，采用以下事先列定的两种合并法。它们各自计算独立实际资金账户，不选择历史最优年份拼接，也不修改父策略。

## 全部因素与两套有限规则

第一来源仍为第143轮趋势波动连续预算策略，第二来源仍为第165轮收益强弱连续段策略。逐日只读取它们已经保存的收盘目标，不读下一开盘成交结果作为当日因素，不重新训练预测模型或运行父账户。两套父策略的内部因素、周期、入场模型版本、退出锁和再次进入资格保持原样，不接收新账户反馈。

两档费用各自读取对应费用的父目标。每个父目标本身已在零至百分之一百之间。此轮不计算历史风险预算，不依据已观察收益决定两者比例。

1. 较大目标合并：两套目标都明确时，合成目标等于较大的那个。只有一套目标为正时，使用这一目标；两套同时为正时，使用较大目标，避免把同一标的的两次信号直接累加。
2. 相加封顶合并：两套目标都明确时，将两目标相加，超过百分之一百则取百分之一百。只有一套为正时，仍使用它原有的目标规模；两套同时为正时增加持有比例，但不融资、不做空。

任何父目标未知，则相应合成目标未知，不能因另一套为零或为百分之一百而隐藏缺失。这两种方法只改变新组合的目标形成方式；第166轮固定各半和第167轮月度最小方差规则及失败记录保持不变。

## 进入、退出、调整与再次进入

所有判断在当天十五点零五分，下一交易日真实开盘执行。空仓且合成目标为正，按上一收盘本账户净资产、原始收盘价计算目标份额，向下取一百份整手；取整为零则不买入。新账户的净资产和份额独立计算，不复制父账户份额。

已有持仓且目标为正，当目标与实际股票市值占净资产比例的偏差不足十个百分点时保持实际份额；达到十个百分点则调至目标中心。带外正目标按整手计算为零时同样全部卖出。两套父目标均明确为零时，合成目标为零并优先请求全部卖出，不受调仓带阻拦；固定终点开盘也优先清算。

目标未知时保持实际份额。交易受阻后，在下一收盘依据最新目标重新决定，不使用额外永久退出锁。全部退出后，新的可执行正目标可以再次进入，不额外等待。原有次日可卖约束、资金不足、限价与真实费用均由实际账户执行。

## 有限计算、对照和口径

只有上述两套新设置，共八个新资金账户：每套两段完整历史、每段基础及压力两档费用。零新模型、零新增参考账户、零外部资料。保存对照为第167轮月度风险预算、第166轮固定各半、第143轮、第165轮以及买入持有，五条保存对照加两条新策略，每段两档费用合计十四条指标记录。

主历史为2020年1月2日至2026年8月14日开盘；较早历史为2015年1月5日至2019年12月31日开盘。每账户二十万元，二百四十二日年化，现金和无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。一百份整手、零点零零一元价位、原百分之十方向限价、下一开盘执行、登记除息到账分开、终点开盘清算均保持。

必要测试覆盖两种目标的手算、百分之一百上限、单边有信号、双边零目标、任何父目标未知、费用来源和日期身份、未来与前缀隔离、实际资金进入退出和再次进入、整手及调仓带、分红与终点清算。通过后把两套父策略全部中文因素和进出规则纳入完整文档，一次冻结后运行八个账户，再独立重算全部合成目标和实际账户。

不搜索其他系数、窗口、阈值、年份或费用。无论这两套方案的结果如何，完整目标仍为成本后夏普至少一点二、稳定超额和独立证据；历史试验中的较高数值不代表已取得独立统计证据。未达标的固定方案关闭并保留原结果。
