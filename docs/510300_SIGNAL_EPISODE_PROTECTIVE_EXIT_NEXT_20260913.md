# 第184轮事前方案：满仓资格加入固定波动尺度的保护退出

第183轮取消仓位幅度只保留满仓资格后，主历史基础／压力夏普为0.979／0.913，较早约0.817／0.816；主历史回撤约10.5%，较早约13.9%。从已保存账户按前一收盘来源资格分组，核心与辅助对应阶段的整段净利润都为正，不能仅凭归因直接删除一项来源。下一轮停止继续改变同一信号的预算幅度，转而检验额外的保护退出。

## 固定因素

方向来源仍为第174轮“任一方向确认辅助”的对应费用原目标。风险因素为510300最近二十日含分红简单日收益的样本标准差，不年化；一个连续正目标区间首次出现时固定该值，乘以三得到区间保护回撤距离。三倍为本轮事前固定的一项设置，不搜索其他倍数或窗口。

价格观察采用510300含分红累计财富序列。每个原目标由零变为正的收盘，建立新信号区间，以该收盘财富初始化区间高点；之后只用截至当前收盘已经出现的财富更新最高值。当前财富相对这个高点的回撤达到或超过固定保护距离时，触发保护退出。高点不使用未来日，不在区间中重新放宽保护距离。

这里的锚是正信号开始时的收盘财富，而非声称当时已经以该价实际成交。买入仍只能在下一开盘，真实开盘跳空、费用和T+1按账户处理；不能按保护价或信号收盘价假设卖出。

## 进入和两种退出

原目标严格为正且当前区间未触发保护退出，保护资料完整时，新目标100%。原目标明确零，新目标零，并结束区间。若触发保护退出，下一开盘请求全部卖出，本区间后续都维持零目标；必须先看到原目标明确零，随后新的正目标区间出现，才允许再次进入。

若区间开始时波动缺失或不大于零，该区间保护距离未知，新目标保持未知，不能在中途用新数据补出有利距离；等原目标归零后再判断新的区间。原目标未知时保持实际份额和已有区间状态；若完整价格已经明确触发保护退出，则已知保护退出可独立给出零目标。源头未知不自动变成现金。

本轮保护信号为收盘判断，下一开盘执行。实际持有不足一百份、受限价格、可用资金、佣金、滑点、分红与终点清算都由原完整账户规则处理；不新增盘中数据或假设盘中止损成交。

## 比较和验收

一套设置、两段历史、两档费用，共四条新模拟账户；对照为原第174轮、每日账户风险预算、第182轮区间预算、第183轮满仓以及买入持有。先测试保护距离固定、仅过去高点、等于门槛触发、触发后锁定、归零后重启、未知边界与下一开盘时钟，再一次冻结运行。

记录被提前关闭的区间及其后续真实账户差异，不能只列节省的亏损而隐藏错过的上涨。联合门槛仍为净夏普至少1.2且复合年化至少10%，两档费用分别检查，同时显示较早历史、各年表现和回撤。已有历史归因为描述性证据，不能用它证明保护门槛有效；保护退出是否改善必须由这项固定规则的完整账户检验。
