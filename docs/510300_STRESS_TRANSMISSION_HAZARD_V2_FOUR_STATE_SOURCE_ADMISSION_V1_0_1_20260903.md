# V2 四态来源准入附录 V1.0.1：可选字段修正

## 裁决

V1 有界探测失败并保持关闭。两个项目允许的代理节点均可返回 `dividend`，但没有返回 `base_date` 和 `base_share`；官方节点不接受当前凭据。没有写入数据快照，也没有读取绩效。

Tushare `dividend` 文档把 `base_date` 和 `base_share` 标为非默认输出字段，而四态财富恒等式并不使用这两个字段。因此，V1 将它们列为必填属于 schema 过度约束。

V1.0.1 只做一项修正：

```text
base_date、base_share：必填 -> 可选
```

以下内容完全不变：

- 实施公告日必须严格早于除权日；
- 现金使用税前每股分配 `cash_div_tax`；
- 股数比使用 `1 + stk_div`；
- 配股或认购现金流缺失时失败关闭；
- 重复条款冲突时失败关闭；
- `daily.pre_close` 必须完成理论除权参考价对账；
- `suspend_d` 不是交易所官方证明，不能授权停牌日记 0；
- `adj_factor` 不能直接生成收益；
- 禁止批量下载、模型、绩效、仓位和交易。

本修正不扩大探测的证券、日期、接口或节点范围。修正探测通过后，也只允许冻结下一步历史采集与账本执行契约，不直接授权批量运行。
