# 第102轮：浮盈与回撤的交互退出

只登记一个小改动。原八项线性退出因子保留，增加“浮盈的正数部分乘当前周期回撤”。这允许同样回撤在已有浮盈时产生不同的预测影响，不预先规定新系数方向，不改变原训练样本、时间、成本或进入条件。使用原保存数据，不重新建立参考账户。

## 全部九项因子

一、持仓时间：含买入日在内已经持有的收盘交易日数，加一之后取自然对数。二、实际含分红浮盈浮亏：实际份额市值加本周期已经确认的分红，除以实际买入金额与佣金之和，再减一。三、当前周期回撤：上述含分红价值除以本周期此前及当前最高价值，再减一；初始最高价值至少为买入成本。四、进入类别：本轮只有原日内隔夜强弱进入，固定为一。

五、最近五个交易日含分红对数涨跌。六、最近二十个交易日同口径涨跌。七、含分红财富相对过去一百二十日均值的偏离。八、最近二十日含分红简单收益样本标准差乘二百四十二的平方根。

九、新交互：第二项若为正，乘第三项；若第二项为已知的零或负数，交互为零。例如浮盈10%、回撤5%，交互为负0.005。第二或第三项有任何未知，交互仍未知；不能把缺失浮盈填零。训练样本与每次实际持仓判断使用同一计算。没有把浮盈归类门槛作为额外买卖信号，也没有新价格窗口。

## 每月怎样学习

直接使用原第31轮保存的“六十日日内强于隔夜”自然退出参考样本：1461条状态、34个已结束周期。每次训练只选择当时已经完全结束的最近二十个周期，至少十个完整周期和一百条状态；日程沿用原2014年12月31日准备时点及之后每月首交易日收盘。预计与原来同为141个时点，其中114个具有足够成熟样本、27个无模型，第一次成熟模型是2017年3月1日。

每周期总权重为一，该周期各状态平分权重。九项都用本次成熟训练样本的加权均值、标准差标准化，再限制在负五至正五；标准差数值不超过万亿分之一时只为标准化采用一，不把缺失输入填零。带截距岭回归惩罚为一。任一原选中训练行的新旧输入缺失，则整月无模型，不通过删行改变原样本。

预测目标仍是继续持有到原自然退出，相比在下一开盘提前退出的价值差，再除以下一开盘参考市值；包含两种退出的原佣金、滑点，以及晚退出额外获得的股息登记权益。该目标只能在完整参考周期自然结束后进入训练。预测为截距加九项标准化输入分别乘当月系数的合计。全部系数、标准化数值和样本成员保存为表，中文说明不展开成逐月长报告。

## 进入、持有、退出和再次进入

原进入指标为最近六十日日内对数涨跌减隔夜对数涨跌的合计，除以这些日差值的样本标准差及六十平方根。隔夜为开盘加当日每份分红相对前收盘的自然对数变化；日内为收盘加分红相对开盘加分红的自然对数变化。

进入指标连续两个收盘严格大于一、原必需输入完整、账户空仓、有重新进入资格且距实际退出至少两个交易日时，下一开盘请求用自身可用现金买入最多可负担的整百份510300。进入后不加仓、不部分卖出。

以下任一条件成立时，下一开盘全部退出：进入指标连续两个收盘小于零；实际含分红周期亏损达到6%；周期价值从最高点回落达到8%；含买入日在内已持有60个收盘交易日；或本轮九项模型连续两个持仓收盘预测继续持有价值为负。

没有成熟模型或当前输入缺失时，预测保持无观点，连续负预测计数清零，原价格与期限退出继续。新实际周期的负预测计数重新开始。已提出退出但受阻时持续请求全卖，后续模型转正也不能取消已经锁定的退出。实际退出后，须在空仓期间先看到原完整进入条件消失，再等其重现，同时满足原两日冷却。
