# 510300图形状态策略V2.1小单成本门协议

## 1. 研究性质

本分支是V2结果产生后，由用户明确提出的执行成本敏感性研究。它不修改V2历史账本，不把新结果冒充预注册样本外证据，也不允许根据结果搜索成本阈值。

证据标签固定为：`POST_RESULT_EXECUTION_OVERLAY_HISTORICALLY_CONTAMINATED`。

## 2. 固定成本门

V2使用单边佣金 `max(成交金额×0.03%, 5元)`，另计单边5bp滑点。V2.1只允许单边显式成本率不超过10bp的买入或加仓：

`10000 × [max(0.0003, 5 / 买入金额) + 0.0005] <= 10`

因此，按基础成本模型推导出的最低买入金额固定为10000元。该阈值来自成本上限代数推导，不通过历史收益寻优。

## 3. 因果执行规则

- 使用100股整数倍取整后的拟买数量和当日原始开盘价计算买入金额。
- 成本门只拦截买入及增加风险敞口，不拦截任何卖出或减仓。
- 被拦截的小单不放大到10000元，不与未来信号合并，也不生成虚拟成交。
- 被拦截的底背离事件视为已经消费，避免在15日活动窗口内每日重复申报同一小单。
- 被拦截的海龟突破必须先重新武装，之后才能响应新的突破。
- 已持有马丁或BIAS28仓位时，如果突破后的增量买单被拦截，现有份额仍切换为海龟管理，但不补足到100%；状态切换本身不需要制造一笔小额成交。
- 所有未被拦截的信号仍在下一交易日开盘执行；T+1、现金、分红、整手、佣金和滑点规则保持V2不变。

## 4. 固定比较

成本门统一应用到V2六条轨道，逐轨道与原始V2比较：

- 被拦截买单及原因；
- 节省的显式成本；
- 闭合交易数、期末权益、CAGR和最大回撤变化；
- 马丁到海龟的实际状态转换次数。

本研究只回答“小账户是否应跳过高成本小单”。即使结果改善，也不能直接进入真实仓位或订单系统。
