# 第191轮：日历补充机会需要此前二十日上涨确认

目标仍为成本后净夏普至少1.2、复合年化至少10%，基础和压力费用、主历史和较早历史完整检查。只用已有510300及现金数据，不融资、不重新训练或等待外部来源。

第190轮不加市场方向条件的日历补充，主历史基础年化超过10%，但夏普下降、较早历史明显恶化。本轮研究日历进入机会是否需要价格方向确认。此前日历条件及失败记录不变，本轮单独登记一个有确认条件的组合，不改月初月末天数，不改方向阈值或月份选择。

## 唯一新增因素

使用前一交易日收盘时已经知道的含分红累计财富，与二十个交易日前的含分红累计财富比较。当前财富严格更高，上涨确认成立；相等或更低，确认不成立。两端财富均须有限且大于零，所需历史不足或无效则确认未知。不能使用执行日开盘或收盘价格形成确认。

财富比值与一的差不超过万亿分之一时，按浮点舍入误差视为未上涨。该数值容差只用于处理理论相等，不是根据收益选择的方向门槛，也不得在看结果后调整。

## 日历和完整进入退出规则

日历状态与原第57轮已保存状态一致：执行日属于当月前三个已开市交易日，或距该自然月末不足五个自然日，即为日历有效。日历在执行日9时确定。原第181轮目标和二十日方向都取前一交易日15时05分及之前已知资料。

原第181轮目标明确大于零时，采用原目标，不因日历或新增确认条件调整该仓位。原目标未知时组合目标未知，保持已有份额。

只有原目标明确为零时，才考虑补充：日历有效且上涨确认成立，目标100%，开盘尝试进入；日历无效或上涨确认明确不成立，目标零，开盘请求退出；没有明确否决但所需条件未知，则目标未知，保持已有份额。100%按实际现金能支付的整百份为上限。

补充期间日历到期或上涨确认消失，且原目标仍为零时退出。原策略恢复正目标时转为其目标仓位；原目标转未知时保持实有份额，不以缺失冒充清仓。日历条件或确认条件中任一明确为否，即足以停止补充，不受另一条件是否未知影响。

来源账户及来源模型独立继续运行，不接受新组合盈亏、仓位或退出反馈。第181轮六十日账户风险预算及第174轮全部基础因素、进入退出规则在正式报告完整附入。

## 成交和验收

最终决定为执行日9时，市场信息来源仍为上一交易日收盘。开盘模拟执行，委托份额使用前一收盘净资产及价格，保留原费用、整百份、千分之一价格单位、十个百分点免调仓区间、合法卖出、现金约束、涨跌停、股息和终点开盘退出。未知目标保持实有份额。

主历史2020年1月2日至2026年8月14日开盘，较早历史2015年1月5日至2019年12月31日开盘；初始二十万元。基础佣金万分之二、最低五元，单边滑点万分之五；压力佣金万分之四、最低五元，单边滑点千分之一。现金和无风险收益为零。

本轮一个候选、四个新模拟账户，零训练、零新增参考账户。复用第181轮、190轮无确认主方案及买入持有对照。核对二十日方向确实在前一收盘已知，以及两种独立否决、缺失、时间边界及全账户费用。报告所有场景；未达标不将主历史基础年化单独过线称为成功。全部历史已观察，本轮不是独立收益验证。
