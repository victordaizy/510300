## 当前有效合同

`config/510300_stk_mins_source_admission_v2.yaml` 仍是有效合同。其逐分钟 VWAP 硬门要求：每根分钟的成交额除以成交量必须落在该分钟 low/high 加减 0.001 元之内。

新增加的五分钟聚合检查仅是诊断。五分钟检查通过不会自动将原逐分钟硬门改为通过，亦不授予读取事件收益、训练 NBS B0/B1 或计算账户收益的权限。

## 复核方法

1. 验证 V2 已冻结的原始响应、规范化数据、官方事件日程和时钟证据哈希。
2. 重新执行 V2 原有全部来源硬门。
3. 将全部正成交逐分钟越界行逐一对应到原始 JSON 响应，检查 time、vol、amount、low、high 的本地转换有无改变。
4. 检查同源独立采集批次中的重叠异常行，不将独立采集批次称为独立供应商。
5. 将 vol=0 且 amount=0 与有成交但隐含价格越界分开报告，不为无成交柱生成虚构价格。
6. 检查金额取整是否足以解释异常，仅报告敏感性诊断，不扩大有效合同容差。
7. 对原定主实验和已授权安慰剂 B 的八个五分钟窗口执行全日期检查：五个标签完整、量额有限非负、零量零额配对、窗口量额为正、聚合 VWAP 位于窗口最低 low 与最高 high 加减 0.001 元以内。
8. 检查八窗口与既有同源独立采集批次的重叠 VWAP，沿用原容差。
9. 在已有临时凭据仍有效时，仅重取 2017-01-04、2020-02-03、2026-09-03 三个预先选择的异常日，各一次。同一已授权 `stk_mins` 接口，出现供应商错误即停止。凭据过期则不联网，不索取或输出凭据内容。

## 可供明确授权的合同修订草案

状态：`PROPOSED_ONLY_NOT_ACTIVE`。

本草案不是数据已经更正的声明。它属于将准入对象改为策略实际使用的固定五分钟量额测量，必须显式接受原逐分钟异常仍存在这一限制。

仅提出以下两项用途处理：

- 正成交单分钟 VWAP 越界保留为失败诊断；八个固定五分钟窗口的完整性、正量额及相同 0.001 元价格容差改为用途准入硬门，覆盖全部开放日，从而同时覆盖事件、60 日基线和两类安慰剂。
- vol=0 且 amount=0 视为无成交；保留原始零量额参与窗口求和，不单独定义该分钟 VWAP。零量与零额不配对、非有限数据及整窗零量额仍失败。

其余来源硬门全部保留，原始 time/vol/amount/OHLC 不修剪、不插值、不改写，不挑选日期。主实验与安慰剂 B 窗口不变；不根据收益结果进行选择，当前未读取事件收益。

若获授权，另立用途合同及不可变审核回执，并在源审核、样本账本和代码冻结提交完成后才领取新的事件收益读取 claim。原 V2 失败回执不会被覆盖。若未获授权，该草案不生效，下一步仍需供应商更正或可核验的原始成交证据使原逐分钟硬门通过。
