# 东吴“最新股本摊薄”字段修正

2026年9月7日登记。使用已经完成的6734份免费研报原件，不重新下载，不新增机构，不改变历史账户起止时间。本次是来源字段修正，不是新择时方法。

第三版共提取4490份报告、13459条年度预测。完整第一版的11363条年度EPS、净利润、PE、原文行、页码、文件及信息日期在第三版全部保留，所谓“新版丢掉旧成功报告”的疑点已排除。但是第三版2023年没有提取出报告，固定目录中这一年有864份原件。最早三份2023年原件都出现此前没有识别的“每股收益-最新股本摊薄（元/股）”和“P/E（现价&最新股本摊薄）”字段，属于明确的程序覆盖遗漏。

本版把第三版已经成功的4490份事实逐项原样保存；只对原未成功报告尝试新字段。新识别要求前三页明确盈利预测与估值摘要表、唯一连续年度标题、明确预测标志、唯一完整EPS数值行、正确证券机构身份和可确定的报告落款。仅输出预测列，历史实际列不用作预测。EPS原文定义和原文数字保留；净利润与市盈率缺失时仍为空。净利润原标签“归属母公司净利润”保留，同时记录与第三版相同的归母净利润规范名称。不得把目标价市盈率当作现价市盈率。

信息可用日仍取原件落款、供应商公告日、供应商录入日与目录发布日期的最晚日期。历史不可变快照仍未证明；当前价格与当前股本仍未校正。本修正不会自动证明报告PE数值关系成立，后续仍需沿用已经确定的EPS、PE和报告参考价格之间的关系条件。

完整修正后逐项检查旧事实不变、新事实原行与年度列相符、EPS和可选净利润及PE一致、报告年份覆盖变化。第十九、二十轮已经完成的旧来源账户保留，后续同方法来源重放单独登记，不能覆盖旧结果，也不能把增加的来源版本计成独立成功方法。每次重放仍报告进入、加仓、减仓、清仓、重新进入和无观点处理；目标仍是扣除费用后的完整账户夏普不低于1.2。
