连续参考起点沿用第31轮已经确定的2013年6月3日，不搜索起点。该日起原急跌回升策略和原线性学习退出策略各自以二十万元、原基础费用建立参考账户，持续到2026年8月14日统一开盘终点。两条参考都记录完整现金日、实际份额、佣金、滑点和分红权益。

急跌回升使用原第26轮第六条进入退出规则；学习退出使用原第32轮线性退出及等待新机会规则。模型复用原第31轮已经保存的八因子、月度系数和成熟时点，不再训练。按判断收盘取不晚于该日的最近保存模型；此前无有效模型时保留原价格退出，不把以后模型提前使用。

已核对原线性模型在2014年12月31日只有一个成熟参考周期、59行，尚不满足十周期和一百行下限；其首次有效拟合为2017年3月1日。因此提前至2013年运行参考时，没有遗漏当时原本可用的已训练模型，也不能把2017年模型用于2015年。前置样本的成熟时间继续受原模型控制器检查。

## 因子、预算与每天的股票目标

风险估计完整沿用第82轮：每月首个交易日收盘，使用连续两参考账户最近242个完整日净收益。计算两条样本方差、样本协方差和两者收益差的样本方差。急跌预算为学习方差减协方差，再除收益差方差，限制在零至一；学习预算是一减急跌预算。

2013年参考启动时预算各半，之后只在月首更新；窗口不足、缺失、任一参考零波动或收益差零方差，保留无观点及上次预算。预算连续积累，到2015年或2020年新资金建账时不重新置为各半。没有加新因子、调整风险窗、改变协方差公式或挑选预算范围。

每个收盘，股票目标等于急跌预算乘当时急跌参考持有意向，加学习预算乘学习参考持有意向。两条参考状态也连续保留原周期、退出请求及等待新机会规则。因此相比原第82轮，本轮同时改变参考路径的历史状态和风险预算起点；不能把结果全部解释为某一个协方差因子改善。

两条参考意向有任何缺失，股票目标为无观点。没有插值、前向补齐或把缺失目标当作现金。
