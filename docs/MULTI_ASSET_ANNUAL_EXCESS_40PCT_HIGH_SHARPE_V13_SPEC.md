# 40个百分点高夏普研究V13：BTC+ETH双资产长周期趋势

BTC容量感知V3已形成完整结果，但基础/压力年化净超额30.21%/29.46%、净夏普1.134/1.105，未达到40个百分点和1.50硬门，因此冻结拒绝且不修改。

V13授权一个独立的双资产机制：固定BTC-USD与ETH-USD；每个完整UTC周日分别判断收盘高于200日均线且126日收益为正。合格资产先按60日实现波动率倒数分配，再用60日协方差把组合缩放到40%年化目标波动率，单资产和组合毛权重均不超过100%。下一UTC周一开盘执行。

候选从第一版即采用0.3%历史中位成交额容量目标、逐日容量退出和最后30个UTC日历日清仓。基础/压力单边现货成本固定76/106bp，人民币换汇点差另计。无杠杆、做空、衍生品、质押或借贷。失败后不得改变产品、200/126/60日窗口、40%波动目标、容量或成本救回。
