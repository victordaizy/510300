## 拟定的有限统计模型

只使用含分红日对数收益这一观察量，假定一个未变化阶段内均值和方差相对稳定，但阶段长度未知。初始在第一条收益之前认为持续时间为零。每观察一个新收盘，全部旧持续时间分支可以延续一天，或者进入下一阶段；保留全部可能持续时间，不根据回测效果截断长尾或选择窗口。

主要设置拟固定每日阶段结束概率为二百四十二分之一；它是约一年尺度的先验假设，不是从收益最大化估出来的参数。对照的结束概率固定为零，一直积累现有全部历史，其余先验、观察和交易规则相同。此对照用于判断允许阶段变化是否有实际增量，不扫描先验持续天数。

每个阶段拟采用未知均值、未知方差的正态模型，均值在给定方差下的先验为正态，方差先验为逆伽马。固定初始均值零、均值强度一、方差先验形状二、方差先验尺度万分之一。这里尺度按密度指数中的“负尺度除以方差”约定；不能把它当作精度的倒数后再重复倒置。该先验下方差期望为万分之一，条件均值方差等于该分支方差除以均值强度。

新观察到来时，按观察前的各分支Student t预测密度更新概率，再按新观察更新延续分支的均值强度、均值、形状和尺度；重置分支保留初始先验。下一日均值预测是所有分支后验均值的概率加权平均。对照可用全部历史的单个共轭更新作为独立闭式校验。用对数概率和稳定求和，禁止用未来状态平滑当前预测，不用随机采样或根据新业绩选择先验。

必须避免一个常见错误：按原论文算法一、固定阶段结束概率的时钟定义，归一化后的持续时间零概率等于该固定先验概率；因此不能把它自己当作“今天发生变化的信号”再设阈值买卖。这是从该递推式得到的数学结论，应写成必要测试。本方法使用全部持续时间的加权预测，保存持续时间分布只是供核对，不靠持续时间零这一项生成信号。
