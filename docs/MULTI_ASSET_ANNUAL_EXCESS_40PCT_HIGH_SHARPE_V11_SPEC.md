# 40个百分点高夏普研究V11：BTC长周期时序趋势

V11保留V4的正式拒绝：基础/压力年化净超额4.72%/3.90%，净夏普0.604/0.579，远低于40个百分点和1.50硬门。也保留数字资产V1在冻结前176小于180的关闭结果，不放宽该门槛、不运行其绩效。

下一条独立机制只持有BTC-USD现货或美元现金。每个完整UTC周日，用当日及以前收盘计算200日简单均线、126日收益和60日实现波动率；仅当收盘高于200日均线且126日收益为正时，下一UTC周一开盘目标权重为`min(100%, 40%/年化实现波动率)`，否则为零。周频再平衡、无杠杆、无做空、无衍生品、无质押或借贷。

可见期固定为2017-01-02至2022-12-31，2023年以后仍封存。成本保留Coinbase吃单费、用户单边万分之一、滑点、冲击和人民币换汇点差，基础/压力现货单边总成本76/106bp。冻结前覆盖只判断BTC原始日历、行数、汇率和基准输入是否完整，不以信号方向或未来收益作为数据门。

V11只授权一个预先冻结的候选。可见期失败后不得改200/126/60日窗口、40%波动率目标、成本或产品救回；历史结果不授权Paper、Shadow、订单、交易所账户连接或实盘。
