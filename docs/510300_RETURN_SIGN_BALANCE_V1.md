# 第172轮：上涨日占优与累计方向的独立价格状态

第171轮相邻收益相关规则四场景夏普均不足，固定方法关闭。第172轮检验另一套简单的每日价格状态：过去一段时间上涨日是否多于下跌日，同时累计收益是否为正。规则按实际零收益划分上涨、下跌与持平，不更改已关闭的相关或连续段方法。

## 全部因素

每天收盘取最近六十个完整含分红日对数收益。单日收益由当天原始收盘价加当天每份除息分红、除以前一原始收盘价后取自然对数得到。

分别统计六十日中严格大于零、严格小于零、恰好为零的天数。上涨日数量减下跌日数量，再除以六十，得到上涨日优势，范围为负一至一。持平日仍占六十日窗口的一天，但不计入上涨或下跌；完整六十日全部持平时，优势明确为零。任何日收益缺失，则整个窗口未知，不能把缺失计作持平。

第二项因素为同一六十日的对数收益之和，作为累计方向。正值表示该窗口含分红累计收益为正，零和负值均不算正方向。上涨日优势描述发生频率，累计方向描述涨跌幅合计，两项共同用于固定进入条件。

第三项因素为普通风险规模：最近二十个含分红日简单收益的样本标准差，乘二百四十二的平方根，得到年化波动率。方向允许且波动完整大于零时，目标为百分之十除以年化波动，上限百分之一百；方向完整但不允许时，目标为零。允许状态下波动缺失或为零，则目标未知。

## 状态、进入、退出及再次进入

从完整市场数据最早日期起，内部允许状态初始关闭，三个连续计数均为零。状态不按评价开始、每年或实际入场重置。

上涨日优势严格大于零且累计方向严格大于零，两项同时成立连续两天，开启允许持有状态。任意一天联合条件不成立，进入计数归零。

上涨日优势不大于零连续两天，或累计方向不大于零连续两天，任何一项成立，关闭允许持有状态。两个退出计数分别记录，不能把交错出现的一天非正优势和一天非正累计方向合并为两天。相应条件不成立时，该退出计数归零。完整数据下其余情况保持原状态。

六十日窗口缺失时，当日状态和目标未知，内部允许状态及计数清零，恢复完整后重新确认。完整的全持平窗口属于明确非正方向，按退出计数处理；不把完整零收益误判为资料缺失。单独的风险波动缺失不修改完整方向状态，但允许状态下目标未知。

所有判断于当天十五点零五分形成，下一交易日真实开盘执行。空仓且目标为正时，按上一收盘本账户净资产和原始收盘价计算份额，向下取一百份整手；取整为零则不买入。

已有持仓且目标为正，目标与实际股票市值占净资产比例偏差不足十个百分点时保持，达到十个百分点则调至目标中心。带外正目标按整手计算为零时实际全部退出。明确零目标优先请求全部卖出，不受调仓带阻拦；固定终点开盘同样优先清算。

未知保持实际份额。受阻后下一收盘按最新目标重新决定；实际退出后，新的可执行正目标可以再次进入，不额外增加等待期、固定持仓天数、永久退出锁或另一层止损。

## 固定范围和必要验证

仅一套六十日上涨日优势、六十日累计方向、两日联合进入及分别两日退出、二十日普通风险规模规则。四个新账户，零新模型训练、零新增参考账户、零外部资料。保存对照为第143轮、第165轮和买入持有，每段两档费用合计八条指标记录。

主历史2020年1月2日至2026年8月14日开盘；较早历史2015年1月5日至2019年12月31日开盘。每账户二十万元、二百四十二日年化、现金和无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。一百份整手、零点零零一元价位、原百分之十方向限价、次日可卖、资金约束、真实下一开盘与分红登记除息到账分开保持。

必要测试包括上涨下跌持平计数手算、同频不同幅度的累计方向、全持平和缺失的不同语义、完整六十日窗口、进入联合连续与退出分别连续、状态保持和恢复、风险仓位、未来与前缀隔离、两费用共用市场状态、实际进退与再进入、整手调仓带、分红和终点清算。通过后冻结一次，计算四账户，再独立核对全部计数、累计方向、状态、实际资金与费用。

不搜索其他窗口、阈值、确认天数、年份或费用。历史上涨频率不是已证明的下一日胜率，也不替代独立收益证据。完整目标仍为成本后夏普至少一点二、稳定超额和独立证据；不达标则关闭固定方法。此文为第172轮新账户计算前确定的完整规则，六项必要测试已通过，尚未冻结或计算新账户。
