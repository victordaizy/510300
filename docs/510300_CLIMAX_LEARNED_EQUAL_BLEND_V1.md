# 第51轮：放量收强回升与原学习退出各半

## 固定比较与原组合的区别

本轮只检验一个固定组合：原“急跌后放量收强”信号与原“日内相对隔夜强弱进入、线性学习退出并等待新机会”信号，各占一半预算。原参数、模型和时间规则保持，不搜索权重。

现有代码中，放量收强回升用于第26轮单策略、第27轮其他信号限价研究、第28轮原三种信号组合。第28轮虽有日内强弱与放量回升各半，但其日内强弱未加入后来的学习退出与等待新机会，本轮不是同一来源组合。该旧各半结果也纳入对照。

第46轮的另一个回升信号是五日跌超5%、短期波动显著放大的急跌回升，本轮则使用截至昨日跌超3%、今日放量收强的回升，不能把两者混同。第46轮原组合继续作为直接对照。本轮选择放量信号时已知道它的旧结果，属于历史再研究，不宣称独立验证。

## 放量收强信号的所有因子与进出场

空仓时，四项条件须同时成立：截至昨日的五个交易日含分红累计跌幅超过3%；今日含分红总回报水平较昨日上升；今日成交量至少为此前二十个交易日平均成交量的1.5倍；收盘在当日最高最低区间中的位置至少为0.75。四项成立后在收盘请求下一开盘进入，只买一次，不追加。

含分红简单日收益为当日未复权收盘价加每份除息分红、除以前一收盘价，再减一；累计相乘形成总回报水平。五日累计跌幅使用截至昨日的五个日收益，不能把今日回升算进此前急跌门槛。成交量比率的分母不含当日，成交量与平均量沿用相同单位。

收盘位置是收盘减最低价、除以最高减最低。全天区间为零时，原约定取0.5，因而不会满足0.75条件。二十日标准化偏离，是当日总回报水平减含当日的二十日均值，再除以二十日样本标准差；原零标准差约定取零。必要原行情特征缺失时不产生新进入信号。

以下任一成立，下一开盘请求全部退出：总回报水平恢复到二十日均值或以上；本次含分红持仓亏损4%；盈利6%；持有达到十个交易日。买入当天算持有第一日，盈亏以买入成交金额加佣金为成本，以实际份额收盘价值加本周期已确认股息为当前价值。

退出请求未成交时持续保留，直到实际卖完。实际卖完后至少两个交易日，再满足上述四条件才允许进入；该原放量信号不额外要求进入条件先消失再出现。

## 原学习信号的全部规则

隔夜对数涨跌为当日开盘价加每份除息分红，除以前一收盘价，再取自然对数。日内对数涨跌为当日收盘价加同一除息分红，除以当日开盘价加同一分红，再取自然对数。每天取日内减隔夜，最近六十日加总，除以这六十日差值的样本标准差与六十的平方根，得到相对强弱分数。

空仓、进入许可有效、距实际卖出至少两个交易日，且相对强弱分数连续两个收盘都严格大于一，才请求下一开盘买入可负担的整手，只买一次。实际买入后关闭重新进入许可。最终全部卖完后，在空仓时见到旧进入条件消失、后来重新出现，且同时满足两个交易日等待，才允许再次进入。买入未成交不消耗许可。

原退出模型使用八项因子：实际持仓日数加一的自然对数；实际份额市值加本周期已确认分红相对买入含佣金成本的浮盈亏；该持仓价值相对最高收盘价值或初始成本中较高者的回撤；固定为一的进入模式；含分红五日对数涨跌；二十日对数涨跌；总回报水平相对一百二十日均值的偏离；二十日简单日收益的样本标准差乘二百四十二的平方根。

原模型每月使用当时已经自然结束的最近二十个参考周期，至少十个周期、一百条状态，周期总权重相等。各因子减训练加权均值、除训练加权总体标准差，零标准差用一，再限制在负五至正五；带截距岭回归惩罚强度为一。目标为继续持有到原自然退出、相对下一开盘卖出的含费用与新增登记股息权益净差。本轮直接复用原已保存模型的输出，不重新训练，也不使用第44轮短期标签模型。

任一条件成立便请求下一开盘全部退出：分数连续两个收盘小于零；本次含分红持仓亏损6%；从最高收盘持仓价值回撤8%；持有达到六十个交易日；模型连续两个不同的实际持仓收盘预测继续持有价值为负。没有成熟模型或模型因子缺失时，不新增模型退出并清除连续负预测计数，其他原退出照常执行。已经产生的退出请求保留至实际卖完。

## 组合的进入、增减仓、退出与重新进入

两个原策略在各自独立维护的参考账户中运行。每天收盘，愿意进入或继续持有的参考状态记一，空仓等待或已经请求退出的状态记零。这里“各自维护”是计算方式，不代表两个信号在统计上相互独立。

将两个基础费用参考状态相加再除以二，决定统一组合下一开盘的股票目标：都没有信号时为零，一个时为50%，两个时为100%。两种费用的组合都使用同一组基础费用信号，不在压力结果出来后更换来源。

组合用自己的实际现金、净值和份额计算整手请求，不能把两个原净收益直接平均。零目标请求全部卖出；非零目标与实际股票比例相差至少十个百分点时才调整，否则保持份额。新信号进入或旧信号退出可产生加减仓，实际交易费用完整扣除。

组合未成交后，在下一个收盘按两个最新状态和实际份额重新计算请求，不另加永久组合退出锁定；每个原参考策略内部仍保留自己的退出等待。重新进入由两个原参考状态共同决定，组合没有额外未声明的冷静期。模型持仓因子属于原学习参考账户，不能称为根据组合的实际浮盈所作预测。

任何必要状态缺失都不是零仓位指令。本轮须先核对全部评价日和各自前一决策日的状态完整，再计算账户。另逐日统计放量回升、原学习和第46轮高波动急跌三种状态的交集，显示新来源在原组合之外究竟出现多少天；天数不等于独立事件数。
