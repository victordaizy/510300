# 前瞻EPS原文识别修正第二版

旧版沪深300采集已完成3,352份原件，但仅503份通过EPS提取，产生1,510条预测；2,376份因每股收益行未识别而缺失。全部139个月末均未达到原因子覆盖条件，导致四个候选各两档账户全程现金，夏普无法计算。此结果保留，不能解释为EPS策略经济上有效或无效。

逐页检查发现两类明确实现问题：不少原文写作“每股收益（元）”，同表附注明确“摊薄每股收益按最新总股本计算”，旧版只接受“摊薄每股收益”；另一些表格标题中包含解释性年份，旧版将其误计为年度列。

本版只从独立的年度标题行识别三至六个连续年度，预测标记仍须明确且排列在实际年度之后。说明性文字中的年份不当作列。保留具体年度标题原文及前置说明。

在同表仍有“摊薄每股收益按最新总股本计算”附注的前提下，接受“摊薄每股收益（元）”“每股收益（元）”“每股收益（摊薄）”三类明确原文。数值列数仍须与年度列一致，不能取下一指标补齐缺失。最后一种没有在该行明示金额单位时，记录“金额单位未明确”，不自动写成人民币元每股；同份报告的增长比率保持原单位一致。

证券身份、机构、前三页唯一预测表、原文数字、同年度利润口径、日期取较晚者、最新报告覆盖旧报告和180日历日有效期均保持。所有3,352份原件统一按新版本处理，不能按策略收益选择修复哪些公司、年份或报告。旧代码和旧结果保留，新事实另存。

这是来源布局适配修正，不改变任何策略阈值、费用、时间区间、入场退出规则或结果。新的事实文件形成后，后续研究必须登记输入版本的明确接续，不覆盖旧账户。本轮不准备GPT审阅数值包。
