# 40个百分点高夏普研究V19：多币种永续基差因子

小时横截面反转V8在2021-01-15 23:00因容量切片后的旧仓随价格变化，使实际毛敞口越过冻结的2倍上限而终止，没有形成绩效。V8不得通过调整杠杆、容量切片、标的数或风险门救回。

V19转入独立的日频横截面基差因子。Chi、Hao、Hu和Ran在2023年《Journal of Futures Markets》的同行评审研究中，使用现货与当季期货构造基差、仅交易期货；日频高基差做多、低基差做空组合显著优于周频与月频。V19只把该结论用作候选机制依据，不把当季期货结果当作Binance永续结果，也不预设本地样本会复现。

静态集合仍为2020-02-10前已上线的15个币种，不按收益或基差筛选。每日UTC 23:00读取同时完成的现货与永续1小时收盘，计算`spot_close/perpetual_close-1`；做多最高3个基差、做空最低3个基差，以代码升序破同值，多空不重叠，于下一日00:00永续开盘执行并持有一天。现货只用于信号，不持有现货。

按原研究的零成本因子尺度，多头与空头目标毛敞口各0.5倍，总毛敞口1倍、绝对净敞口上限3%。订单上限为永续前168小时中位成交额的0.1%，最后7日停止新仓并按容量清零。基础/压力单边总成本为4/16bp；实际资金费率计入，压力情景将资金收入乘以75%、支出乘以125%。

目标仍为相对H00300全收益年化净超额40个百分点，基础和压力净夏普均不低于1.50，并保留滚动、Bootstrap、年度块、容量、敞口和保证金门。采集阶段只确认官方现货K线覆盖与哈希，不计算基差、排序、方向、目标或绩效。Paper、Shadow、订单、账户连接和实盘均关闭。
