# 第四阶段：全日历的可执行机会收益分布

前三阶段都未实现主期净CAGR>=10%且净夏普>=1.2。第三阶段训练样本依赖18项旧规则已经挑出的机会，本轮改变采样与学习目标：对每一个具备完整特征的历史收盘，模拟下一开盘买入后的完整交易，学习这种行动的条件盈亏分布，不更改前三阶段参数或结果。

## 唯一自然交易定义

初始资金20万元，下一开盘买入当时可负担的整百份。单笔买入不追加，不部分退出。收盘含分红累计亏损达到2%、盈利达到4%、或已持有20个收盘日，任一触发即下一开盘卖出。T+1、方向涨跌停、原实际滑点、最低佣金、分红权益和终点清算全部保留。退出受阻按原simulate_policy函数继续请求。训练期间的假设交易各自独立，不能当作可同时投资的组合。

每一假设交易直接调用原资金账户函数，入场信号只在该原点发生一次；前瞻切片最多保留21个收盘检查后的开盘。若在最终期限不能卖出则标签无观点，不虚构成交。标签=实际净周期收益，分类为实际ROI>0与<=0；分类目标并不将0.04/-0.02当作实际成交盈利亏损，跳空后的损益进入真实标签。

## 特征与训练

使用第三阶段已列明的31个当日市场特征；额外固定加入weekday的五个哑变量、当月前三已发生交易日标记、距自然月末少于五日标记。月末由自然日历可知，不使用未来交易日价格。没有日期序号、未来价格、未来退出原因、全样本排名或事后行情标签。

每季度首个交易日收盘训练。仅使用退出日不晚于拟合日之前5个交易日、特征完整的已结束假设交易，至少400笔、每个盈亏类别至少30笔。窗口扩展，不改变截止期。为减少重叠标签重复计权，每个已成熟交易的权重为其真实入场至退出区间每日并发交易数倒数的平均；并发数只用当时可训练交易计算。未知输入不生成新预测。未来数据不参与当期拟合或标准化。

固定三种分类器：标准化LogisticRegression(C=1,max_iter=1000)；HistGradientBoostingClassifier(max_iter=120,learning_rate=0.05,max_leaf_nodes=7,min_samples_leaf=30,l2_regularization=1,early_stopping=False,random_state=20260910)；ExtraTreesClassifier(n_estimators=128,max_depth=5,min_samples_leaf=20,max_features=1,bootstrap=False,random_state=20260910,n_jobs=1)。第四种是三者预测概率的等权平均，不事后调权重。

当期赢/亏幅度为当期可训练标签中按相同权重计算的正ROI均值与非正ROI均值。预测期望净ROI=p*正类均值+(1-p)*非正类均值。它是待验证的简化条件分布模型，不是已经校准的收益保证。

## 固定候选及账户

四个预测器；两个期望净ROI进入阈值0与0.5%；两种持仓规模（FULL=1，VOL10为入场当日min(1,0.10/vol20)，单笔期间固定）。每一预测器阈值先独立运行自己的基础或压力参考账户：预测合格时请求买入，使用上面的固定自然退出；两个交易日冷却，不根据未来成交成功或未来退出时间选取进入。压力账户使用基础训练模型，但自己的成本、权益及退出独立核算。

三种外层用途：独立；在第150轮固定两倍核心为零时补充；使用核心剩余资金，目标=核心+(1-核心)*补充。未知必要意向不补零或一。外层使用自己的真实账务，不把参考利润拼接成净值。

4预测器*2阈值*2规模*3用途=48项固定候选，两时期两档成本=192项完整账户。基础/压力/较早指标全量保存。旧档案中已经拒绝的微观结构高收益序列不用于候选、不作达标替代，原审计状态保持。

## 边界

仍属于已观察历史上的前序回放；即使代码严格因果也不消除多轮选择偏差。全部48项同时登记，不根据本轮结果追加阈值、止损、止盈、期限或树参数。如有主期点达标，停止新增候选并复核；如无，完整报告未达标，不伪造成功、不授权实盘。
