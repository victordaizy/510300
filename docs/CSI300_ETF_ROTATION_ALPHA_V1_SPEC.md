# CSI300 ETF 跨资产轮动 Alpha V1 冻结说明

## 目的

以 H00300 全收益指数为基准，检验一个普通证券账户、20,000 元可执行的境内 ETF 轮动策略，目标为扣除成本后几何年化超额不低于 20 个百分点。本分支仅为历史研究，不生成实盘仓位或订单。

## 宇宙与因子

资产池在下载行情前固定为沪深300、中证500、创业板、黄金、纳指、标普500、恒生七个风险 ETF，以及国债 ETF。仅在已有 252 个交易日历史后纳入选择，避免上市前回填。

恰好使用八个、全部只依赖信号日及此前数据的技术因子：252日跳过近21日动量、126日跳过近21日动量、63日跳过近21日动量、20日动量、20日低波动、60日低波动、252日回撤位置、相对200日均线距离。每日横截面百分位按冻结权重合成分数，不训练、不搜索参数。

每 20 个交易日产生一次信号。风险资产必须同时满足收盘价高于200日均线、126日跳过近21日动量严格为正。原持仓仍满足条件且排名不低于第二名时保留，否则换成第一名；没有风险资产合格时持有国债 ETF。

## 执行与否证

信号次一交易日开盘成交，100份整数，单腿名义金额至少5,000元，最多持有一个 ETF，执行 T+1。佣金每腿 `max(成交额×0.03%, 5元)`；ETF 印花税为零；基础/压力滑点分别为每腿5/15bp。

正式评估为2015-01-05至2026-08-14。通过要求：基础与压力成本年化超额均不低于20个百分点、20日区块 Bootstrap 95%下界大于0、三个预定义时期至少两个正超额、所有成交不低于5,000元。首次读取结果后禁止修改资产池、权重、趋势门、周期或保留排名补救。
