三个组件定义为：

- `V`估值：`0.20 + 0.80 × raw_continuous_valuation_position`；
- `T`趋势：无估值时为`0.60 + 0.40 × trend_score`；有估值时为估值仓位加`0.20 × trend_score`；
- `R`风险：从方向组件仓位扣除`risk_penalty`，无方向组件时只从100%扣除，最多减20个百分点。

八路固定为：买入持有、V、T、R、V+T、V+R、T+R、V+T+R。没有风险组件的分支关闭危机日即时降仓，防止风险执行逻辑泄漏到估值或趋势分支。报告各分支相对买入持有结果及V/T/R对年化主动收益的Shapley归因。

## 3. 第一批技术模型

### TECH-01 多期限时间序列动量

- 信号：H00300全收益收盘相对年化1.5%现金的63、126、252日累计超额；
- 三个符号和为-3/-1/+1/+3时，仓位为0%/25%/75%/100%；

- 每5个交易日复核，T日收盘、T+1开盘执行。

### TECH-03 唐奇安突破

- 主模型55日合成全收益最高价进入、20日最低价退出；
- 单独登记并运行25%底仓的55/20版本，不与主版本混同；
- 固定稳健性100/50；
- 使用已冻结的H00300收盘比例缩放000300 OHLC方法；
- 20/10旧协议继续计入试验数但不运行收益；本统一技术家族累计登记7次、本次运行6个候选；
- 本次在统一五年窗口重放同一冻结规则，不回选参数。

### TECH-05 上涨趋势中的回撤进入

- 长趋势：H00300全收益收盘高于MA120，且过去60日对数价格OLS斜率为正；
- `Z20=(Close-MA20)/Std20(Close)`；
- 空仓首次进入`Z20<-1`且长趋势有效时建立25%；
- 已持有25%且`Z20<=-2`时下一信号日增加到50%；直接跳到`Z20<=-2`的首日也只建立25%；
- `Z20>=0`、持有满10个交易日或长趋势破坏时退出；
- 总仓位不超过50%，禁止翻倍和下跌趋势摊低。

### TECH-08 点时宽度确认趋势

- 宽度：当日点时官方权重下，成分股站上MA60的权重比例；
- 上涨趋势定义：H00300全收益收盘高于MA60，且MA60的20日变化为正；
- 上涨趋势且宽度≥55%：100%；40%—55%：75%；低于40%：50%；
- 非上涨趋势：0%；宽度改善只记录，不触发买入；
- 仅在目标档位改变时执行，T+1开盘成交。

## 4. 估值模型与硬数据闸门

### VAL-01 标准化盈利收益率

工程定义沿用R5已存在的盈利标准化：

```text
ImpliedEPS_t = IndexClose_t / PE_TTM_t
Growth_t = median_252(clip(ImpliedEPS_t / ImpliedEPS_{t-242} - 1, -30%, 30%))
NormalizedEPS_t = ImpliedEPS_t × (1 + Growth_t)
NormalizedEY_t = NormalizedEPS_t / IndexClose_t
RawEY_t = 1 / PE_TTM_t
```

预登记原始/标准化盈利收益率各自的5年、7年、扩展窗口，共6个试验；按20日复核映射25%/50%/75%/100%。还需验证未来60/120/242日收益的分位单调性。

### VAL-02 盈利收益率利差

```text
EYS_t = NormalizedEY_t - CGB10Y_t / 100
```

预登记5年窗口主版本和扩展窗口稳健性版本，共2个试验；使用同一仓位映射和20日复核。
