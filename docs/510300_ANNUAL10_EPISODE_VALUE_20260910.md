# 第三阶段：学习完整机会的净收益价值

前两阶段均未达到主期净CAGR10%且净夏普1.2。现登记新的学习对象：不同固定自然交易机会的净收益，而非预测全部交易日的平均涨跌，也不是再改旧模型窗口。

## 数据与来源

沿用2012-05-28至2026-08-14的原日线特征及原分红。12项原价格规则和6项原成交量规则，从原允许参考起点2013-06-03分别连续运行；基础和压力各18条参考，阈值与原自然退出不改。来源真实买入、原规则自然退出及分红/费用形成完整周期标签。训练只用基础参考。压力候选使用相应压力参考的当时入场意向和持有/退出状态。

训练标签=完整自然周期净利润/实际入场成本。尚未退出的周期不得进入训练。拟合每个自然季度首个交易日收盘进行；只纳入退出索引<=拟合索引-5的完整周期，至少150周期。最初无模型则无新增机会，不能把以后模型提前使用。相同入场日期的周期在训练中总权重为1，避免同日多个旧规则重复计权。标签固定截断[-0.20,0.30]供学习，真实账户利润不截断。所有被截断数量公开。

特征只来自机会入场意向当日收盘：mom1/2/5/10/20/60/120/252；sma5/20/60/120/200；vol5/20/60；downvol20；dd20/60/120；overnight_log_5/20；intraday_log_5/20；range、close_location、volume_ratio、efficiency20、rsi2、z20、vol_ratio；另加18个来源固定哑变量。训练样本缺失不默默补未来数据；该预测无观点。

## 固定模型

RIDGE：训练窗口自身均值/标准差标准化，alpha=10。
HGB：HistGradientBoostingRegressor，squared_error，max_iter=120，learning_rate=0.05，max_leaf_nodes=7，min_samples_leaf=20，l2_regularization=1，early_stopping=False，random_state=20260910。
EXTRA_TREES：128棵，max_depth=4，min_samples_leaf=15，max_features=1.0，bootstrap=False，random_state=20260910，n_jobs=1。
ENSEMBLE：上述三个预测的固定算术平均，不按后验成绩改权重。

采用全部已经成熟周期的扩展训练，不调参、不过度依赖单一时间切片。四种模型全部保留，模型选择本身计为多次研究。拟合记录保存训练样本索引、最晚退出、特征和参数、样本摘要以及预测适用区间；不得全历史拟合后回填。

## 行为与48个固定候选

每种模型比较两个净机会阈值0和1%。只有当日某参考发出新的买入请求且预测ROI严格高于阈值时才可以选择；不根据次日是否真的盈利或成功成交过滤入场。多个合格来源取预测ROI/预定最长持有日数最高者；最长日数为空则60，来源名稳定排序解决并列。不能用未来实际持有长度排名。

选中后跟随该参考的当日持有/退出意向至明确退出，不用未来退出日期提前操作。期间不换来源、不重新选择最赚钱来源；缺失为未知；退出后的两个交易日不新增此补充机会。所有真实交易继续经同一账户引擎。

两个规模：FULL=1；VOL10=入场意向当日min(1,0.10/vol20)，该笔固定规模，不因以后变动反复增加。

三个用途：STANDALONE独立交易；IDLE_ONLY只在150固定两倍核心明确零时接受新机会，核心转正终止补充；REMAINING允许补充，最终目标=核心+(1-核心)*補充目标。独立或补充目标未知按原未知语义处理。核心固定两倍是上一轮对照，不再搜索倍率。

4模型*2阈值*2规模*3用途=48条政策，两时期两成本共192条完整资金账户。零杠杆，原成本、整手、T+1和分红全部保持。所有48种主期基础结果读取前即固定，不能基于结果换特征、树深、阈值或规模救援。

## 证据及停止

训练先后时钟严格不读取未来；但整个2012—2026历史已在项目中观察，所以本轮仍是DISCOVERY_ONLY历史前序回放。阶段完成公布全部候选、全部成本及时期。若出现主期10%/1.2，停止追加候选，进一步验证，不以反复搜索的成功点代替独立证据；若未达到，如实保存失败，再决定不同机制的下一项研究。无实盘、前向自动服务或任何持仓授权。
