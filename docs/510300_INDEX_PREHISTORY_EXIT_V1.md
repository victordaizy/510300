# 第93轮：用上市前指数价格周期补充退出学习

本轮只登记一项改变：把沪深300指数在510300上市前已经发生、已经自然结束的价格周期加入原线性退出模型。目的是检验早期经验不足是否影响退出；原第31、32轮及其他失败记录保留。模型算法、最近周期数量和实际进入退出规则均沿用原设置，不另搜参数。

## 新增资料的范围

使用已保存的免费新浪沪深300价格指数日线，限定官方发布日2005年4月8日至2012年5月25日，共1733个交易日。2005年4月8日以前的回溯编制资料、ETF上市后重叠的指数行、成交量均不参加新增训练。原ETF历史评价范围及价格、分红、费用资料不变。历史版本逐日接收凭据缺失，所以这是历史因果模拟，尚无独立样本证明。

指数没有可交易ETF份额。本轮新增部分只计算价格周期状态，以及“以后自然退出开盘价除以下一交易日开盘价，再减一”的价格继续持有标签；不虚构上市前ETF成交、佣金、分红或账户收益。原ETF训练标签仍含实际买卖费用及应得分红，两类标签存在口径差异，迁移是否有效要由原ETF完整账户检验。

## 八项学习因子

1. 持仓时间：从进入开盘到当前收盘所经过的持仓交易日数加一，再取自然对数；买入当日为二的自然对数。
2. 周期浮盈浮亏：ETF当前持仓市值加本周期已确认分红，除以含买入佣金的实际投入，再减一；指数类比为当前收盘价除以进入开盘价，再减一。
3. 周期回撤：当前持仓价值除以进入后历史最高持仓价值，再减一；ETF使用含分红价值，指数使用收盘价格，峰值初始为进入成本或进入开盘价。
4. 进入模式：本轮只有日内强弱一种模式，数值固定为一，仍是原模型八项输入之一。
5. 五日涨跌：最近五个交易日的每日含分红总收益取自然对数后相加；指数仅按价格涨跌计算。
6. 二十日涨跌：按同样办法汇总最近二十个交易日。
7. 一百二十日均线偏离：ETF含分红财富指数除以过去一百二十日平均值，再减一；指数使用价格及其均值。
8. 二十日波动：最近二十个日简单收益的样本标准差乘以二百四十二的平方根；ETF收益含分红，指数只用价格收益。

新增指数先积累252个既往日收益，沿用原ETF完整因子最长期预热。八项因子不使用未来价格，也不用指数成交量。

## 进入与自然周期

每天收盘计算“日内涨跌减去隔夜涨跌”的强弱分数。指数日内涨跌为收盘价除以开盘价后取自然对数，隔夜涨跌为开盘价除以前收盘价后取自然对数。ETF遇分红时按原口径把每份分红分别加到日内比值的分子、分母及隔夜比值的分子，避免把除息当作信号。将最近六十日差值相加，除以同期差值的样本标准差，再除以六十的平方根。

连续两个收盘分数高于一，且因子完整，下一开盘申请买入。训练参考周期沿用第31轮：自然退出后经过两个交易日的等待，只要进入条件成立就可开始新周期。实际评价沿用第32轮：除两个交易日的等待外，必须在空仓期间观察到旧进入条件消失，再等新的进入条件出现。实际每次按可用现金买入能负担的最多整百份510300，不追加持仓。

自然退出满足任一条即在下一开盘退出：连续两个收盘强弱分数低于零；周期含分红价值较实际投入亏损达到百分之六；周期价值从历史最高值回落达到百分之八；或者已经历六十个持仓交易日的收盘。指数训练参考中的后两项价值概念相应使用纯价格。源资料截止时仍未自然结束的指数周期不给成熟标签，不用强制截止价代替自然退出。

## 学习和实际退出

指数周期只有在自然退出开盘已经发生后才算成熟。原ETF参考样本直接复用第31轮保存记录。按真实成熟日期合并两类周期，给不同来源设置不同周期编号；不比较两套资料各自的本地下标来决定先后。

在2014年12月31日收盘建立首个拟合时点，随后每月第一个交易日收盘更新。每次只取当时已成熟的最近二十个完整周期，至少十个周期、一百条继续持有状态才训练。每个周期总权重为一，该周期所有状态平分权重；两种来源均采用此规则，不另设指数加权参数。旧指数周期会在后续ETF周期增加后自然移出最近二十个周期。

每项因子减训练样本加权均值，再除加权总体标准差，绝对值最多取五；标准差近于零时按一处理。使用原线性岭回归，惩罚系数一、截距不惩罚。拟合出的八项系数、均值、标准差及截距逐月保存中文说明。原模型为八维，其中进入模式是常数，没有独立变化信息。

持仓后，每个收盘用最新已训练模型预测继续持有相对于下一开盘卖出的增量收益；连续两个收盘预测为负，就在下一开盘请求全部退出。原四条自然退出条件继续有效。没有成熟模型或因子缺失时记录无可用预测，继续使用原价格退出规则，不把缺失当作看涨、看跌或现金指令。退出受阻则次日继续请求。

## 评价与验收

原主历史为2020年1月2日至2026年8月14日开盘，较早历史为2015年1月5日至2019年12月31日开盘，各自用二十万元现金重新开始。所有交易日、空仓日、未成交请求和实际分红权益均计入账户。每手一百份，最小报价一厘，保留买入次日可卖、涨跌停及现金约束。现金利息及夏普无风险收益假设均为零，年化按242个交易日。

基础费用为单边佣金万分之二、最低五元，单边滑点万分之五；压力费用为单边佣金万分之四、最低五元，单边滑点千分之一。新策略跑两时期各两档费用的四个账户；原第32轮线性退出、原第91轮局部候选及买入持有使用已保存对照。

净夏普1.2仍为目标。主基础费用一点达到，不代表压力费用、较早历史、稳定超额及独立验证同时通过。本轮只检验上述单项机制，不在结果后改变指数时间范围、周期数、样本权重、确认天数或费用来抢救结果。
