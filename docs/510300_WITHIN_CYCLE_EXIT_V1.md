# 第114轮：用周期内部变化学习退出

只登记一个设置。原模型让一个自然持仓周期的总训练权重为一，但该周期的很多状态目标共享同一个最终退出结果。本轮为每个已经结束的训练周期单独估计一个截距，让八项因子系数主要反映同一周期内部的变化；新实际周期使用已成熟训练周期截距的平均值。

首次原成熟训练窗口为2017年3月1日，共十个周期、438行。按原等周期权重分解，目标变动中周期间差异占约50.48%，周期内差异占约49.52%。这只说明该窗口的信息结构，不证明周期间差异都是运气，也不证明新模型能改善收益。分解只读取旧样本，没有计算新账户。

分组去均值与单独组截距的对应关系可见[linearmodels官方固定效应说明](https://bashtage.github.io/linearmodels/panel/examples/examples.html#including-fixed-effects)。本项目的周期等权、系数惩罚和新周期截距规则另行固定；不以固定效应这个名称声称得到了因果效应。

## 全部八项因子

1. 含买入日在内已经观察的持仓收盘交易日数，加一后取自然对数。
2. 实际份额市值加本持仓周期已确认的分红，除以真实买入金额与佣金之和，再减一，得到浮盈浮亏。
3. 同一含分红持仓价值相对此前和当前最高价值的回撤；初始最高值至少等于买入总成本。
4. 原日内隔夜强弱进入类别，固定为一。
5. 最近五日含分红对数涨跌。
6. 最近二十日含分红对数涨跌。
7. 含分红财富相对包括当日在内的一百二十日平均值的偏离。
8. 最近二十日含分红简单收益样本标准差，乘二百四十二的平方根。

没有增加高点时间、隔夜风险占比、浮盈回撤交互或其他新因子。前三项来自当前账户自己的真实成本、份额和权益，不能借用参考账户状态。

## 每月怎样学习

保留原141个月度收盘时点，选择当时已完全自然结束的最近二十个参考周期，至少十周期、一百条状态。原计划114次成熟拟合、27个支持不足时点。每周期总权重为一，各状态等分，不删除原行、不缩窗、不提前纳入未结束周期。

目标仍为继续持有至原自然退出，比下一开盘提前卖出的净收入多多少，再除以下一开盘参考市值；包含原基础佣金、滑点和新增分红登记权益。沿用原标签对假设提前退出的近似，不把它说成独立成交验证。原周期必须完全结束才能进入训练。

先用原完整训练样本的周期等权均值和标准差，把八项因子标准化并限制在负五至正五，数值上接近零的标准差用一作分母。然后在每个周期内部，分别减去该周期的标准化因子平均值和目标平均值，得到“相对本周期均值的变化”。去周期均值后不再次截断。

用这些周期内变化求八项线性系数，系数平方惩罚仍为一，沿用原奇异值求解；这一步不加统一截距。一个周期内部不变的因子没有周期内变化，不能凭周期间差异得到有效系数。

系数求得后，每个成熟周期的截距等于该周期目标均值，减去该周期标准化因子均值乘系数的合计。周期截距不受惩罚。新实际周期尚未结束，其截距无法观察；本轮固定使用所有入选成熟周期截距的等权平均。绝不根据本次实际周期未来结果估计截距，也不因周期编号碰巧相同而套用旧周期截距。

实际预测是这一个平均截距，加当前八项标准化并截断后的实际输入分别乘系数的合计。全部月度系数、标准化数值、训练成员及每个训练周期截距保存为表。压力账户共用基础参考标签和月度模型，各自真实状态、成本及交易独立。

原选中训练行有任何必要因子或目标缺失，则整月没有新模型；求解失败也保留无模型，不换求解器或删行完成拟合。没有预测显著性前置门，没有搜索平滑参数、周期权重或截距混合比例。

## 进入与全部退出规则

进入指标仍为最近六十日日内对数涨跌减隔夜对数涨跌的合计，除以这些日差值的样本标准差与六十的平方根。日内、隔夜采用原含已确认分红口径。连续两个收盘严格大于一，原必要输入完整，账户空仓、有进入资格且距离上次真实全部退出已满足两个交易日等待，下一真实开盘请求买入最多可负担的整百份510300。

持仓不追加，不部分卖出。以下任一项成立，下一真实开盘全部退出：新模型连续两个持仓收盘预测继续收益为负；原日内隔夜指标连续两个收盘小于零；实际含分红周期亏损达到6%；周期价值距最高点回撤达到8%；含买入日在内已经持有60个收盘交易日。

没有成熟模型、求解失败或当前八项输入未知时，不补预测，连续负预测计数归零，原价格、亏损、回撤和期限退出继续。每个实际新周期重新计数。退出意图一经形成就保持到卖出，后续转正不能取消。实际退出后，空仓期间须先看到原进入条件消失，再等它重现，且满足两日等待，才能再次进入。

## 账户、比较与停止条件

主评价2020年1月2日至2026年8月14日开盘，较早诊断2015年1月5日至2019年12月31日开盘。每期20万元现金起步，基础及压力各一个实际新账户，共四个；零新参考账户。原八项统一截距学习、原无学习退出、第91轮连续参考最小方差和买入持有作为四个保存对照，每期十条指标记录。

基础单边佣金万分之二、最低5元、滑点万分之五；压力单边佣金万分之四、最低5元、滑点千分之一。保留100份整手、0.001元价格刻度、隔日可卖、方向涨跌停、不可透支、实际分红登记、应收与到账。保留所有交易日和现金日。年化242日，现金收益与无风险收益假设为零。收盘判断，下一开盘实际成交，终点优先开盘结算。

六项必要测试通过后冻结，再训练和计算新账户。比较新方法与原统一截距是否改变实际进出场并改善两时期、两档成本的收益和风险；既有历史不是独立验证。失败后关闭本次固定周期截距方法，不改变去均值程度、截距平均规则、系数惩罚、样本窗口或退出阈值挽救。目标仍为净夏普至少1.2和稳定超额，仅研究510300与现金，不补EPS及慢源，不制作GPT数值包或新增安全审计。
