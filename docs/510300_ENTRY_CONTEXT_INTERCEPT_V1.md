# 第115轮：买入前市场状态与周期内继续价值

只登记一个两层退出方法。保留第114轮全部已经保存的周期内八因子系数和标准化参数；第二层用当月已成熟参考周期的买入前市场状态，估计这些周期的已保存截距。它预测持仓期间的继续价值，不改变原进入条件。第95轮整笔净收益进入筛选和第90轮组合相对收益预测的失败保留。

## 两层因子和学习办法

第一层八因子为：持仓交易日数加一后取自然对数；自身实际份额含已确认分红的周期浮盈亏；同一价值较周期最高值的回撤；原入场模式；最近五日、二十日含分红对数涨跌之和；含分红财富较一百二十日平均财富的偏离；二十日含分红简单收益样本标准差乘二百四十二的平方根。实际投入包含成交金额及佣金；周期最高值从实际投入开始逐日更新。

第一层训练仍来自原自然退出参考周期：比较当时下一开盘卖出与按原规则较晚退出的净卖出收入及新增登记分红之差，再除以参考份额乘下一开盘原价。终点强制退出、尚未结束的周期不提供成熟目标。每个周期总权重一；原八因子按加权均值和总体标准差处理，标准差近于零按一，标准化值限制负五至五。每周期内部减去本周期因子和目标的均值，使用系数惩罚一、没有统一截距的线性岭回归。该周期截距为目标均值减去标准化因子均值乘八项系数之和。本轮直接复用这些已保存数值，不重拟合第一层。

第二层只有三项因子：实际买入申请前一收盘已经知道的二十日涨跌、一百二十日均线偏离、二十日波动；定义同上。必须取实际成交日前一交易日，不能取买入后收盘、更晚市场条件、最终持仓收益或最终周期长度。原36个参考周期的三项输入均可用；114个成熟月份的入选周期均具备这些信息，前置核对没有拟合候选或计算其收益。

每月使用第一层本月入选的完全相同的成熟周期，最近二十个、至少十个且原状态至少一百行。第二层每周期一行、权重一，目标是第一层本月保存的这个周期截距，周期状态行数不会增加权重。三因子按这些周期的等权均值和总体标准差处理，近零标准差按一，标准化值限制负五至五。固定带截距岭回归，三项系数平方惩罚一，统一截距不惩罚，奇异值分解求解。保存全部三系数、截距、标准化和成熟成员。

当前持仓的继续价值等于第二层用本笔买入前状态预测的截距，加当前八项状态按第一层标准化后乘保存系数的合计。只使用该收盘已完成的最近月度模型，更新日程沿用初始2014年12月31日和此后每月首个交易日；第一层实际最早成熟为2017年3月1日。月内系数不重训；跨月更新模型后仍代入本笔原买入前状态。当前周期未知的最终截距绝不参与预测，周期编号相同也不套用旧周期真实截距。

原支持不足月份保留；任一必要训练周期的输入缺失则整月无模型，不删周期。当前买入前或持仓因子缺失、求解失败时不产生学习预测，连续负预测计数清零，既有价格保护和已锁定退出继续。没有第二层预测时不自动填入第114轮平均截距。

## 进入、持有、退出与再次进入

原六十日日内相对隔夜强弱保持：每天日内含分红对数涨跌减隔夜含分红对数涨跌，把最近六十日差值相加，除以差值的六十日样本标准差，再除以六十的平方根。日内涨跌按“收盘加当日每份分红”除以“开盘加同一分红”取对数；隔夜按“开盘加分红”除以前收盘取对数。

该分数连续两个收盘严格大于一、原完整性条件成立、账户空仓且具有再入场资格，并距实际退出至少两交易日时，下一开盘申请按自身现金及费用买入可负担的最多整百份。模型未成熟不取消原进入。只有真实买入才消耗再入场资格。

买入后每个收盘检查，满足任一条则下一开盘全部卖出：两层预测连续两个收盘严格为负；原六十日强弱分数连续两个收盘低于零；含分红周期价值较实际投入亏损达到百分之六；从周期最高值回落达到百分之八；持有达到六十个交易日。没有新增止盈、加仓或部分退出。学习预测非负或缺失会清零连续负计数，不取消此前已锁定的退出请求。

卖出受阻继续逐日申请直到实际卖出。卖出后须在空仓时看到旧进入条件消失，再等重新出现，并满足两日等待。新模型变化不能冒充原价格进入条件消失；新实际持仓重置负预测计数。
