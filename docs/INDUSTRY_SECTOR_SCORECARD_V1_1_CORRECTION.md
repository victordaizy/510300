# 板块评分卡V1.1：胜率依赖修正与赔率补充

## 1. V1的问题

V1将77个月末60日结果用于Wilson区间。点估计本身可以作为“月末观察频率”，但相邻月末的60日持有窗口大幅重叠，Wilson区间隐含的独立二项试验假设不成立，容易低估不确定性。

V1还只报告胜率。任何判断都必须同时看赔率：低胜率配高赔率可能有正期望，高胜率配低赔率也可能是负期望。

V1文件和冻结清单保持不变；V1.1替代其胜率区间及赔率解释。

## 2. 修正后的胜率

- 月度重叠胜率仍保留为描述性频率：胜出次数/77个成熟月末。
- 主置信区间改为3个月移动块Bootstrap，固定5,000次、随机种子20260819，同时重采样胜负和超额收益。
- 另外从前三个月分别起步，按“下一次进入日晚于上一次成熟日”贪心选择三条互不重叠链；报告三条链的胜率中位数、最小值和最大值。
- 独立机会频率按非重叠链的中位样本数除以历史年数；独立胜出频率按中位胜出次数除以历史年数。

## 3. 赔率与期望值

相对沪深300的60日理论板块组合毛超额收益`x`：

- 平均赔率 = `mean(x | x>0) / abs(mean(x | x<=0))`。
- 中位赔率 = `median(x | x>0) / abs(median(x | x<=0))`。
- 盈亏平衡胜率 = `1 / (1 + 平均赔率)`。
- Profit Factor = `sum(x | x>0) / abs(sum(x | x<=0))`。
- 期望超额 = `mean(x)`，并核对其等于`胜率×平均盈利 - 败率×平均亏损`。

同时报告期望超额的移动块Bootstrap 95%区间以及10%、90%、最好和最差尾部。

这些赔率不是ETF交易中的止盈/止损比。它尚未扣除ETF费率、冲击成本、跟踪误差和税费，也没有解决可交易ETF对理论板块组合的复制误差，因此不能直接用于Kelly公式或仓位映射。

## 4. 解释边界

只有当“期望超额Bootstrap下界大于零”且“三条非重叠链最低胜率高于盈亏平衡胜率”同时成立，才标记`HISTORICAL_EXPECTANCY_ROBUST_TO_DEFINED_GATES`。即便通过，也只是受当前分类和研究过程污染的历史描述，不是样本外预测优势。

主题定义是当前主题成员回看历史，存在定义后见性；多个板块并列比较没有做多重检验校正。禁止称为模型胜率、禁止Kelly仓位、禁止交易映射。

移动块Bootstrap区间只描述历史样本在保留三个月局部依赖下的不确定性，不是“当前分数出现后”的条件预测区间。高分条件胜率和触发频率都必须等待冻结后的真实前瞻台账。
