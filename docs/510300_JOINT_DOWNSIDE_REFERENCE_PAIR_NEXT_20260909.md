# 下一项：直接最小化两参考合成收益的下跌幅度

第136轮共同方差预算的主基础及压力净夏普为1.275和1.219，年化收益分别4.02%及3.82%，均高于同期买入持有；但较早夏普仅0.731及0.755。主22个周期中最大的三个盈利周期贡献约61%及63%的净利润，区块抽样仍不能证明稳定超过1.2，逐年超额也不稳定。保留该主历史改善，不把目标标为完成。

第137轮固定一个不同的风险目标：直接计算两个参考收益先合成后的下行平方平均值，然后选择使它最小的无卖空预算。两参考仍为132下行风险目标与91连续两策略预算目标，窗口仍242个完整基础费用日收益，月首收盘更新，初始各半，预算零至一并合计一。使用同一组来源有利于辨别风险定义的作用，不改变136的方差方法及其结论。

对每个候选预算，先把132每日净收益乘第一预算，加91每日净收益乘剩余预算。所得合成日收益若为负则平方，否则记零；把242天合计后除以242。下行基准固定零，不减去样本均值，全部现金日保留。不能先各自截取负收益再把两套损失相加，那会遗漏一条正收益对另一条负收益的抵消。

这个目标为一维凸函数。用其关于第一预算的导数在零至一之间寻找最小点，固定最多64次区间二分，仅用于双精度计算，不做参数搜索。若原预算已是最小点则保留；存在多个最小点时取距离上一预算最近的点。端点为最优则取端点。整个窗口完整但风险函数平坦，是已知的并列解，保持预算；不足或缺失属于无新风险观点，同样保留之前预算但明确区分状态。

[PyPortfolioOpt官方半方差说明](https://pyportfolioopt.readthedocs.io/en/latest/GeneralEfficientFrontier.html)区分了用半协方差矩阵近似与直接求组合半方差，并说明后者可以写成凸问题。本轮仅有两条参考，直接计算合成后的下行目标，不安装该库或调用大型优化器，不把下行风险指标称作夏普。

两费用共用基础收益得到的预算，目标仍按各自费用的原收盘目标合成。任一父目标未知则合成目标未知，明确零目标全退；完整自己的净值、10个百分点带宽、100份整手、次日开盘、每收盘重算请求及可再次进入规则保持。只读当时已知收益，开始前不补父账户收益，末开盘不作为收盘风险样本。

四条新账户一次运行，对照132、91、134、136及买入持有直接复用。先验证凸目标的边界、抵消、平坦解和真实账户，再写完整中文底层因子及进出规则并冻结。现有136已核对来源足够，不重复做外部补齐。若无改善，关闭本次目标定义，不更改风险基准、窗口、预算边界或来源救回。选择后研究不算独立验证，旧研究全部保留。
