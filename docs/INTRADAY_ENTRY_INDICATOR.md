# 510300 十五分钟日内进场指标

## 1. 定位

该指标回答“当前15分钟K线结束后，下一根可交易K线是否出现加仓或减仓候选”，不负责自动下单、目标仓位、止盈或止损。估值模型决定目标仓位，技术指标只优化执行时点。信号分轨输出，禁止合成一个大杂烩总分：

- 趋势突破：仅使用510300自身的VWAP、VWAP斜率、EMA8/EMA21、ADX14、前30分钟ORB和Time-of-Day RVOL共同确认；
- 震荡低吸：ADX、VWAP斜率、VWAP偏离ATR倍数和RSI7共同确认。
- 趋势跌破：趋势突破条件的严格镜像，要求价格、VWAP斜率、EMA、ADX、前30分钟ORB下沿和RVOL共同确认；
- 震荡高位减仓：震荡低吸条件的严格镜像，要求价格高于VWAP至少0.8ATR且RSI7高于70。

## 2. 信号定义

趋势突破核心候选要求：

```text
Close > 当日VWAP
最近3根VWAP斜率 > 0
EMA8 > EMA21
ADX14 > 20
Close > 前30分钟最高价
当前15分钟成交量 / 过去20日同一时点成交量中位数 > 1.3
```

当前范围只研究和交易510300 ETF，成分股盘中广度已禁用，不作为确认条件，也不允许因为未来接入成分股数据而悄悄改变本指标。

震荡低吸要求：

```text
ADX14 < 18
最近3根VWAP斜率绝对值 <= 3bp
Time-of-Day RVOL < 1.3
(Close - VWAP) / ATR14 < -0.8
RSI7 < 30
```

ADX处于18到20之间，或VWAP斜率与ADX互相冲突时，状态记为过渡区，不生成进场候选。

趋势跌破减仓要求：

```text
Close < 当日VWAP
最近3根VWAP斜率 < 0
EMA8 < EMA21
ADX14 > 20
Close < 前30分钟最低价
当前15分钟成交量 / 过去20日同一时点成交量中位数 > 1.3
```

震荡高位减仓要求：

```text
ADX14 < 18
最近3根VWAP斜率绝对值 <= 3bp
Time-of-Day RVOL < 1.3
(Close - VWAP) / ATR14 > 0.8
RSI7 > 70
```

这些卖出条件是买入条件的对称定义，不从回测结果搜索新阈值。普通估值减仓最多等待固定交易日；危机强制减仓直接执行。

## 3. 时点与数据质量

- 当日VWAP在每个交易日重置，使用截至当前K线的累计成交额除以累计成交量；
- ORB在前两根15分钟K线结束后冻结，信号最早从第3根K线开始；
- 分时RVOL严格排除当日，只比较过去20个交易日的同一根15分钟K线；
- 信号在当前K线收盘后形成，只允许从下一根可交易K线开盘执行；
- 第16根收盘K线不生成新进场候选；
- ORB、ATR和ADX依赖high/low，只在原生15分钟OHLCV区间且完成预热后使用。
- 当前主输入已切换为五年Tushare代理1分钟K线聚合的15分钟OHLCVA；1211日的日OHLCVA均与独立日线逐日完全对账，因此不再把High/Low类指标机械限制到2024年7月以后。该来源仍有第三方代理与时间戳语义警告，且不得假设能在柱内最高/最低价成交。

## 4. 运行

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m research.intraday_entry_indicator
```

主要产物：

- `data/features/510300_intraday_entry_indicator.parquet`：逐K线特征、判定条件与信号；
- `paper/510300_intraday_entry_latest_signal.json`：最新K线和最近一次历史进场候选；
- `reports/research/510300_intraday_entry_indicator.json`：参数、信号计数与限制说明。

逐K线文件同时保留`is_entry_candidate`与`is_entry_event`：前者表示该根K线仍满足条件，后者只在每个交易日第一次满足时为真，供“一天最多一次新进场”的回测或纸面信号使用。

## 5. T+1约束

510300当天新买份额不能当天卖出。因此该指标适合选择建仓时点并隔夜持有；若用于日内差价，只能显式使用可卖旧底仓，不能把当天新买份额作为日内平仓库存。
