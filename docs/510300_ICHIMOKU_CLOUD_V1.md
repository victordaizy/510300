# 第120轮：固定云图进入与退出

只登记一个无需拟合的价格规则。用最近不同长度区间的中点和过去计算的云线判断趋势，直接规定何时买入、何时卖出。不使用第118、119轮模型，不扫描指标窗口或持仓阈值。

云图的一般构造和绘图位移见[TradingView官方云图说明](https://www.tradingview.com/support/solutions/43000589152-ichimoku-cloud/)，九、二十六、五十二期组合见[其官方筛选器指标说明](https://www.tradingview.com/support/solutions/43000475547-what-do-the-ratings-in-the-screener-mean/)。本轮交易条件、分红转换及账户约束是本项目固定研究设计，官方指标说明不证明本策略盈利。

## 因子及价格口径

所有窗口按交易日计数，包含当前日，使用区间内最高高价与最低低价的中点，不用每日价格的算术平均代替。

1. 转换线：最近九日最高高价加最低低价，再除以二。
2. 基准线：最近二十六日最高高价加最低低价，再除以二。
3. 当日计算的先行甲：当日转换线加基准线，再除以二。
4. 当日计算的先行乙：最近五十二日最高高价加最低低价，再除以二。
5. 当前云上沿：取二十六个交易日前计算的先行甲、先行乙，选择两者较高值。
6. 当前云下沿：取同一二十六个交易日前计算的两值，选择较低值。
7. 当前含分红收盘财富：用于与上述线条比较的当前价格尺度。

高价、低价、收盘均转为同一含分红财富尺度：以前一交易日财富乘当日原价格加当日每份分红，再除以前收盘价。前日财富只由此前已发生收益递推。该转换已在原价格研究核对，本轮直接复用。首行缺前收盘，保留为未知，不能凭空补出前一日价格。

分红日原价格下降不应被误当成相同幅度的经济损失。这个价格尺度只用于信号；账户仍按未复权价格成交，实际股权登记、除息应收和支付到账独立记账，只计一次。

当前云使用完整二十六个交易行之前的计算值。本轮不采用包含当前根后再减一的绘图记法，不声称逐位复制外部软件。当前计算甲乙使用截至当前的数据，不能把以后价格前移。把当前收盘画到过去的迟行线不参与本次规则，更不能据此给过去产生买卖信号。

严格高于或低于只排除浮点误差：差值绝对量需超过两数绝对值较大者的万亿分之一。该固定数值保护远小于交易价格刻度，不是搜索出来的突破幅度。

## 买入条件与冲突处理

当日收盘同时满足三项条件，形成进入条件：收盘高于当前云上沿；转换线高于基准线；当日计算先行甲高于当日计算先行乙。所有进入所需信息必须完整。

账户空仓、有再次进入资格、距上次实际退出至少两个交易日，且当日没有成立的价格退出条件时，下一开盘请求买入最多可负担的整百份510300。请求预算使用判断收盘的已知现金、价格及费用；未来开盘只在实际撮合时用于成交价格、现金约束和滑点。

退出条件优先。如果当日三项进入条件和任何退出条件同时成立，空仓账户不买入，也不消耗原有进入资格。当前预检中主历史有五十七个、较早有四十二个这样的收盘，因此必须明确此行为，不能让账户先买入又立即要求退出。

## 退出、锁定及再次进入

实际持仓后，每个收盘只要出现以下任一条件，下一开盘请求全部退出：收盘低于基准线，或者收盘低于当前云下沿。单次收盘确认，不额外增加学习预测、固定亏损、追踪回撤、止盈或最长持仓期限。没有加仓、部分卖出或融资。

退出请求形成后持续到实际卖完；涨跌停等原因阻挡时，逐日继续请求。之后条件恢复或信号缺失，不取消已经锁定的卖出。初始空仓具有进入资格，实际买入后消耗该资格；买入没有成交则不消耗。

实际卖出之后，须在空仓时观察到原三项进入条件已不再同时成立，才重新获得进入资格；之后再等三项重新成立，且满足两个交易日冷却、退出不优先，才能重新买入。持仓期间见过条件消失，不能代替卖出后空仓时的观察。

## 缺失信息怎样处理

进入信息缺失保留为未知，不当作进入条件为假，不重新授予进入资格，也不继续请求此前尚未成交的买入。已有份额继续保留，已锁定退出继续执行。

退出是两项条件的“或者”：其中任何一项资料完整且明确触发，就可以退出；若两项都完整且都没有触发，才判为不退出；否则保留未知。不能把缺失基准线或缺失云线直接变成卖出信号。真实成交或估值价格缺失时不能编造现金收益，账户计算须停止并保留原因。

原账户的现金、份额、成本、分红和退出锁定流程复用，只增加明确的未知信号及退出优先处理。全知且没有进入退出冲突的测试路径与原账户逐项相同。首个完整云图为2012年9月14日，全3456行中前78行进入信息未知；两段实际评价区间及其前一判断收盘没有进入或退出缺失。

## 冻结评价

主历史2020年1月2日至2026年8月14日终点开盘，共1604日；较早历史2015年1月5日至2019年12月31日终点开盘，共1219日。每期二十万元现金起步，242日年化，现金与夏普无风险收益假设零。基础单边佣金万分之二、最低五元、滑点万分之五；压力佣金万分之四、最低五元、滑点千分之一。

保留100份整手、0.001元价位、次日可卖、方向涨跌停、现金限制、全部空仓日、实际分红权益和终点开盘清算。四个新独立账户，零新拟合、零新参考；复用114、32、91及买入持有对照。八项必要测试通过、定义和日历预检完成后一次冻结，再运行新账户。

目标为完整账户扣费净夏普至少1.2及稳定超额。已有历史经过多次研究，不作为独立验证。若该有限设置没有跨历史及费用的有效改善，就关闭，不改九／二十六／五十二、云位移、进入组合、退出线、冷却、确认、浮点容差或费用挽救。只研究510300与现金，EPS、公募及慢源暂停，无GPT审阅包或额外安全审计。
