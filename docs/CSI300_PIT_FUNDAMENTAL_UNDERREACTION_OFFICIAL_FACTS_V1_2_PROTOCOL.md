# 沪深300基本面反应不足官方财务事实 V1.2

## 修订结论

V1.2 只修复 V1.1 正式代表性运行暴露的跨页表格识别，不改变目标事件、九期依赖、九项指标、公告时点、官方来源、同事件回退、覆盖门或收益禁读规则。V1.1 的 120 个新检查点和 `43/120` 完整、`77/120` 不完整的正式结果保持只读；V1.2 使用独立的 `checkpoints_v1_2` 目录重新采集。

V1.1 不完整文档中有 66 份未定位现金流量表、19 份未定位利润表、4 份未定位资产负债表；49 份仅缺经营现金流。定点原文显示，常见真实版式是：主体表标题、单位、项目列头和首批行位于起始页，而经营现金流净额或利润表关键行延续到紧邻下一页。V1.1 为排除经营分析中的“合并利润表项目”假标题，错误要求全部标记同页，因此被正式代表性运行否决。

## V1.2 唯一新增规则

真实主体报表起点仍必须包含合并报表标题，并满足以下二者之一：

1. 标题之后、首个主体表字段之前出现明确人民币单位或“单位”表头，起始页至少出现一个必需主体字段，其余固定标记全部出现在紧邻下一页；
2. 标题位于上一页末尾，项目列头与单位位于标题页或紧邻下一页，全部固定标记位于下一页。

没有明确单位表头的目录、经营分析、附注说明或“合并利润表项目”叙述继续被拒绝。资产负债表、利润表、现金流量表仍必须形成页面顺序一致的三联；相邻续表标题仍合并到首次真实表头。

Q3 扣非归母净利润的列组判断改为表格局部表头，不再用整份 PDF 中其他表的“本报告期”字样推断本表结构。如果局部表头只列“年初至报告期末”和上年同期，固定读取第一金额；只有局部表头同时列本报告期与年初至报告期末时，才读取后半组首个金额。标签跨页时，允许在同页或下一页向后最多四个表格行寻找续接标签，从而跨过重复表头；数值必须留在原始标签行，续接行不得提供替代金额。

## 事实、证据与禁止事项

其余口径完全继承 V1.1：只接受合并口径人民币绝对金额；金额前附注号必须由列位证明；单位优先绑定标签—金额短窗口；扣非净利优先采用官方主要财务数据表格坐标；只有明确横线当前金额格或严格双空白存货格可以按零；“应收票据及应收账款”不能冒充纯应收账款。

每项事实保存原事件公告 ID、实际 PDF 公告 ID、官方 URL、PDF SHA-256、文件字节数、页码、原始标签、原始金额、单位、定位和解析方法。最终准入状态固定为 `PASS_OFFICIAL_ORIGINAL_PDF_LABEL_VALUE_UNIT_VERIFIED`。OCR、供应商快照、人工填值、跨日修订版和未来收益均不得用于补齐。

## 覆盖门和停止规则

只有 11,892 份文档全部终态，且 8,223 个目标事件的九期完整依赖覆盖率达到 90%、每个公告年度达到 80%、每个至少 50 个目标事件的行业达到 75%，才输出 `PASS_OFFICIAL_PDF_VERIFIED_PIT_FINANCIAL_FACTS_V1`。否则交付事实和缺口账本，收益评价保持 `NOT_ALLOWED`，不得修改字段、样本、行业、窗口或门槛挽救。
