# 第134轮：下行风险与连续两策略目标各半组合

只登记一个固定各半组合：第132轮下行风险目标占一半，第91轮连续两策略风险预算目标占一半。不重新训练、估计新权重或运行新参考，直接将两个已保存的已知收盘目标合成为一个实际资金账户。选择这两个来源用了已观察历史，不能作为独立验证。

两套来源仍交易510300，合并检验的是不同时点和规模的互补，不增加交易标的。132中的128参考、91中的两个连续参考，均保留自己的模型、持仓、盈亏和退出状态；本轮实际账户有独立现金、份额和分红权益。新账户进出不能倒灌或重置任何参考状态。

## 第一来源：第132轮下行风险目标

132先按128固定入场模型参考产生进入、持有或退出意向，再用既定下行风险幅度决定规模。以下涉及持仓的八项因素属于128自己的参考账本。

### 参考使用的全部因子

进入指标是最近六十日日内含分红对数涨跌减隔夜含分红对数涨跌之差的合计，再除以这些日差值的样本标准差与六十的平方根。它衡量日内相对隔夜强弱，不是未来收益。

参考退出模型的八项因子如下，涉及持仓的数值均属于参考自己的账本：

1. 含买入日在内已经观察的持仓收盘交易日数，加一后取自然对数。
2. 实际份额市值加本周期已确认分红，除以参考真实买入金额与佣金之和，再减一，表示周期浮盈亏。
3. 同一含分红持仓价值相对周期最高价值的回撤，初始最高值至少等于买入总成本。
4. 原日内隔夜强弱进入类别，固定为一。
5. 最近五日含分红对数涨跌。
6. 最近二十日含分红对数涨跌。
7. 含分红财富相对包括当天的一百二十日平均值的偏离。
8. 最近二十日含分红简单收益的样本标准差，乘二百四十二的平方根。

### 参考模型与进出场如何确定

复用原114的141条月度模型记录，其中114个成熟模型、27个支持不足；最早成熟日2017年3月1日。模型原本只纳入当时已自然完成的最近二十个参考周期，至少十周期、一百个状态。每周期总权重为一，各状态等分。目标是继续至原自然退出相对下一开盘提前退出多出的净收入，除以下一开盘参考市值，含既有费用及新增分红权益；原标签近似不等于独立成交验证。

八项因子按周期等权均值和标准差标准化，限制在负五至正五，近零标准差以一代替。各周期内减去自身平均因子和平均目标，以周期内变化求线性系数，系数平方惩罚为一、不加统一截距。各成熟周期截距不受惩罚，新参考持仓使用这些成熟截距的等权平均；不能用尚未完成周期的未来结果估计截距。

每笔参考实际买入日的第一个收盘选择当时最近的成熟模型版本，固定系数、均值、标准差及截距到实际卖完，当前八因子每天更新。第一次没有成熟模型，该笔全程没有学习预测；当前输入缺失也不补预测，连续负预测计数清零。新一笔才重新选择版本。以上均为已保存参考的原规则，本轮没有新模型拟合。

参考进入：六十日强弱连续两个收盘严格大于一、必要资料完整、空仓、有再次进入资格，且距上次全部卖出至少两个交易日，下一开盘以参考可用资金单次买入整百份。参考不追加或部分卖出。

参考退出：固定版本连续两个持仓收盘预测继续收益为负；六十日强弱连续两收盘小于零；含分红周期亏损达到百分之六；距周期最高含分红价值回撤达到百分之八；或含买入日在内已经持有六十个收盘交易日。任一成立，下一开盘全卖并锁定到实际卖完。无模型时可知价格与期限保护仍执行。卖完以后须先看到原进入条件消失，再等其重现并满足两日等待，才能再次进入。

### 下行风险规模如何计算

每天含分红简单收益是收盘价加当天每份除息分红，再除以前收盘价，减一。最近连续二十日，把负收益平方相加后除以二十，上涨及零收益贡献零，分母仍包含完整二十日；不减窗口平均收益、不删除未知日。结果乘二和二百四十二后开平方，就是既定风险幅度。

每天用百分之十除以已知正风险幅度，最多取一；零风险或窗口未知时沿用最近一次明确乘数，初始一。128参考意向为一，132目标为此乘数；明确零意向则零目标；参考意向未知则目标未知。乘二是既定理论尺度约定，不根据本轮结果改变。

132基础费用目标来自基础费用128参考，压力费用目标来自压力费用参考，二者可能因原参考浮盈亏影响退出而不同。只取保存收盘目标，不取下一开盘已成交股份。132实际账户的净值、收益或持仓不直接移入本轮。

## 第二来源：第91轮连续两策略预算目标

第91轮内部以基础费用运行急跌回升和学习退出两个连续参考，按已实现风险调整预算。以下完整原始进入、退出及八因子规则保留；这里的原模型是31的带统一截距岭回归，与上文128使用的114周期内模型不同。

### 两条策略如何产生原始信号

急跌回升策略进入须同时满足：含分红五日累计跌幅超过5%；当日含分红财富较前一日回升；收盘位于当日高低价区间至少60%的位置；最近5日含分红简单收益样本标准差高于最近60日的1.5倍。收盘位置等于收盘减最低价，再除以最高减最低价。原完整性要求保持，缺失不能伪造进入。

急跌策略在任一条件成立时请求下一开盘退出：含分红财富回到20日均值或以上；本周期含分红实际亏损达到4%；本周期含分红收益达到6%；含买入日在内已持有10个交易日。均值回复因子等于财富减20日均值，再除以20日财富样本标准差。实际退出后至少等2个交易日，不另加旧信号消失要求；原参考退出受阻仍保留退出意图。

学习策略的进入因子为60日日内对数收益减隔夜对数收益的标准化和。每日隔夜为开盘加当日每份分红相对前收盘的自然对数变动，日内为收盘加分红相对开盘加分红的自然对数变动。60日差值合计除以60个差值的样本标准差与60平方根的乘积。连续两日严格大于1、当日有效、参考账户空仓、有重新进入资格、距实际退出至少2个交易日，才请求下一开盘进入。

学习退出保留八个因子：持仓交易日数加1的自然对数；参考账户实际含分红浮盈浮亏；参考持仓价值相对本周期最高价值的回撤；固定为1的进入类别；含分红5日及20日对数涨跌；财富相对120日均值的偏离；20日含分红简单收益样本标准差乘242平方根。持仓价值为实际份额市值加本周期已确认分红，成本为实际买入金额加佣金，初始高点至少为该成本。

原模型每月收盘后只用当时已结束的最近20个参考周期、至少10周期100条记录、每周期等总权重训练。八因子按原加权均值与标准差标准化、限制在负5至5，原带截距岭回归惩罚1。预测为截距加八项标准化因子乘原系数的合计；目标为继续持有到参考自然退出相对下一开盘提前退出的含成本和新增分红价值差。本轮直接复用114个成熟模型及27个无模型时点，不重新拟合；全部逐月中文数值随结果提供。

学习策略任一条件成立即请求下一开盘全部退出：60日强弱连续两日小于零；含分红亏损6%；持仓价值从高点回撤8%；持有60交易日；原预测连续两个持仓收盘为负。没有模型时原价格和时间退出继续。退出请求受阻保留，实际卖出后须先在空仓期间看到旧完整进入条件消失，再等其重现，并满足原两日冷却。上述持仓因子属于原基础费用参考账户，不是合并账户的预测。

## 本轮唯一新增规则：两个目标固定各半

取同一历史区间、同一费用目录中两条来源的收盘目标。两条都明确时，最终目标为第132轮目标的一半加第91轮目标的一半；任一未知则最终目标未知，不补零，也不把另一条重新扩成全部预算。两条明确零目标时才使最终目标为零。一条退出、另一条仍有正目标时，组合保留后一条对应的一半规模。

第91轮内部基础费用参考和月度预算保持原样；外层仍读取对应费用目录的91保存目标，没有新做压力费用参考。第132轮保留自身费用对应设计。不能把两个保存净收益各半相加充作实际账户结果。

实际空仓且最终目标为正，下一开盘按自己当前净值、收盘价与100份整手提出买入请求，实际成交受当时现金和费用约束。实际持仓时，股票市值占净值与正目标之差不足十个百分点则保留股数，达到或超过十个百分点才按自己的净值增减。明确零目标请求卖出全部份额，不受带宽限制；未知目标不发起调整。

实际卖完后，新收盘出现明确正目标即可再次进入，不加等待。本轮每个收盘按最新目标重算受阻请求，没有额外永久退出锁定；原参考内部的退出锁定仍保留。只有下一开盘可执行，终点统一开盘优先清仓，未知末日收盘不得改变终点。
