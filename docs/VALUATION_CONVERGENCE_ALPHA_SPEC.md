# 510300长期估值收敛现货Alpha规范

> **当前状态：`SUPERSEDED_OUT_OF_510300_ONLY_SCOPE`。** 用户已将研究对象收紧为510300基金本身；本文件涉及的沪深300指数基本面、点时成分、广度、IF基差与宏观折现变量均不得进入当前Alpha模型。现行规范见`docs/510300_ONLY_ALPHA_SPEC.md`。本文件仅保留历史研究审计用途。

## 1. 目标与边界

本体系只交易`510300.SH`现货多头与现金，目标是在不使用期权、期货、融资融券、卖空或任何杠杆的前提下，研究能否实现相对H00300沪深300全收益指数年化超额20个百分点。

本文件中的旧信息域定义已失效，以`docs/510300_ONLY_ALPHA_SPEC.md`为准。

主要验收指标为：

`ExcessCAGR = StrategyNetCAGR - BenchmarkCAGR`

其中策略收益必须包含现金分红，并扣除佣金、最低佣金和滑点。20个百分点是挑战性研究门槛，不构成未来收益保证。

## 2. 模型链路

体系固定为五层：

1. 预测指定未来时点的指数基本面；
2. 预测该时点的条件合理估值倍数；
3. 形成Bear、Base、Bull合理价格分布并计算当前价格偏离；
4. 独立预测短周期方向概率与未来波动率；
5. 将长期赔率、短期胜率和风险映射为0%至100%的510300现货目标仓位。

长期层决定潜在收益空间，短期层判断是否正在向长期中枢收敛。波动率只描述未来波动幅度和风险预算，不直接代替方向预测。

## 3. 长期合理价值标签

每个信号日`t`必须指定明确目标日`T`，而不是统一写成模糊的“未来12个月”。第一版支持月末和年末目标日。

模型输出至少包括：

- `target_date`：目标交易日；
- `fair_value_bear`：悲观情景合理价格；
- `fair_value_base`：基准情景合理价格；
- `fair_value_bull`：乐观情景合理价格；
- `probability_bear/base/bull`：三个情景概率，合计为1；
- `expected_fair_value`：概率加权合理价格；
- `expected_total_return`：含预计分红的目标日前预期总收益；
- `downside_to_bear`：相对悲观情景的下行空间；
- `forecast_dispersion`：合理价值分布宽度；
- `model_asof_date`：模型所使用信息的最晚可得日期。

目标日价格不是沿线性斜率外推。核心恒等式为：

`FairIndex_T = Fundamental_T × FairMultiple_T`

基本面与估值倍数必须分别建模，避免盈利上升但估值压缩时仍机械预测价格上涨。

## 4. 基本面层

第一版以指数整体口径建模，不要求逐家公司DCF。候选状态变量包括：

- 指数聚合EPS及其同比、环比和修正趋势；
- ROE及其变化；
- 每点股息或股息率；
- 净资产与盈利质量；
- 一致预期变化；
- 已披露财报与宏观变量的点时可得版本。

任何财务或一致预期数据必须保存`publication_date`或`available_at`。报告期结束日不能代替真实发布时间。

### 4.1 数据优先级

长期估值MVP开始前，以下数据按优先级建设：

1. 沪深300价格指数与H00300全收益指数；
2. 历史点时成分股及生效区间；
3. 历史权重或可审计的自由流通权重重构输入；
4. 个股财报报告期、真实公告日期、归母净利润、归母净资产和营业收入；
5. 总股本、自由流通相关股本、除权除息与分红；
6. 1年期和10年期中国国债收益率；
7. 个股不复权价格、复权因子、停牌与交易状态；
8. 指数级一致预期及其历史快照，若无法获得则明确降级为仅使用已公告财务数据。

截至2026-08-13，工作区已补齐2016-08以来的官方月度权重和中国国债1年/10年收益率，并建立2015Q3以来带真实`available_at`的成分股PIT财务事件。逐股基本面月度面板从2021-08开始，共60个官方权重快照。外部估值交叉验证必须匹配口径：乐咕PE按盈利公司总市值除以TTM归母利润核验；指数经济暴露另保留自由流通权重加权、包含亏损公司的盈利收益率，二者不得混名。

成分股增强四个月模型已通过首轮配对增量筛选，但前后阶段不稳定且移动区块Bootstrap区间跨零，状态为`SCREENING_PASSED_ROBUSTNESS_INCONCLUSIVE`。该结果只允许进入后续方向/波动研究，不授权现货仓位。

### 4.2 历史权重降级方案

完整历史官方权重不可得时，允许使用“前十大官方披露＋其余成分重构”，但必须显式标记来源：

- `OFFICIAL`：官方披露权重；
- `RECONSTRUCTED`：依据调整自由流通市值重构；
- `APPROXIMATED`：关键输入不完整时的近似值，只能用于敏感性分析。

设前十大官方权重合计为`W_top10`，其余成分的调整自由流通市值为`AdjustedCap_i`，则：

`weight_i = (1 - W_top10) × AdjustedCap_i / Σ AdjustedCap_rest`

重构权重不得静默混入官方权重。每次重构必须验证：

- 每日权重和为1；
- 前十大权重与官方披露一致；
- 由重构权重生成的模拟指数日收益与000300日收益相关系数原则上不低于99%；
- 累计跟踪误差和单日误差分位数低于预先登记阈值；
- 成分调整、自由流通股本调整和公司行为只在其真实生效日进入计算。

## 5. 条件估值层

合理PE/PB不能只使用无条件历史分位数。第一版条件估值模型至少评估：

- 中国10年期国债收益率；
- 股权风险溢价代理；
- 指数ROE与盈利增速；
- 通胀、信用与流动性状态；
- 市场风险和未来波动率状态。

允许保留滚动历史分位数作为基准模型，但不得把它直接命名为最终合理估值。复杂模型只有在滚动样本外显著优于该基准时才能进入组合。

## 6. 短周期双模型

截至2026-08-13，首版固定参数20日方向Logistic与未来波动Ridge均已完成pseudo-OOS检验但未通过门槛。方向模型AUC低于0.5且概率校准方向近乎反转；波动模型虽降低平均绝对误差，但与实际波动的相关性不足。两项输出只保留为失败基准，不得进入仓位映射，也不得在看见结果后直接翻转概率方向。

独立登记的两日收盘压力挑战者也已失败：整体AUC为0.5149、Brier技能为负，前后半段均未达到稳定性门槛，且最高概率组的平均净收益低于最低组。该结果关闭现有OHLCV分钟特征继续变换的研究路径；分钟数据只用于执行审计，除非未来获得独立的新数据域或冻结后的真正前向样本。

### 6.1 方向模型

主目标为下一交易日开盘可执行后的20个交易日净总收益为正的概率：

`P(exec_total_return_20d_net > 0 | information_t)`

候选特征包括趋势、广度、动量、均值回归、成交结构、IF基差和权重股扩散。模型必须报告概率校准、Brier Score、AUC、分箱命中率与条件净收益，不能只报告方向准确率。

### 6.2 波动率模型

独立预测未来20个交易日实现波动率及其区间。候选特征包括历史实现波动率、ATR、上下行波动、波动率聚集和可获得的现货市场风险代理。

波动率预测只用于仓位缩放、风险预算与止损治理。没有独立方向证据时，波动率上升不能生成看多或看空信号。

## 7. 现货仓位映射

目标仓位必须位于`[0, 1]`，并满足：

- 长期预期收益不足以覆盖成本和不确定性时降低仓位；
- 长期上行空间大且方向概率经过校准时提高仓位；
- 悲观情景下行、预测分散度和未来波动率共同约束最大仓位；
- 短期方向与长期估值冲突时允许等待，不强迫交易；
- 所有信号最早在下一可交易时点执行，并遵守510300的T+1和整手约束。

不得仅为改善历史收益而自由搜索仓位阈值。仓位函数、阈值和再平衡周期必须在验证前登记。

## 8. 验证协议

所有现有历史数据均已被反复查看，因此当前历史结果只能称为回顾研究或`pseudo-OOS`。验证必须至少包含：

- 扩展窗口或滚动窗口walk-forward；
- 每一折只用训练期拟合、选择特征和校准概率；
- 重叠与非重叠20日标签；
- HAC/Newey-West与移动区块Bootstrap；
- 基础5bp和压力15bp单边滑点；
- 相对H00300全收益的净CAGR差；
- 最大回撤、Calmar、换手率、平均仓位和现金占用；
- 自然年度与滚动242日超额分布；
- 按长期估值、短期方向、波动率缩放和执行成本进行收益归因。

只有在pseudo-OOS达到20个百分点且结果不依赖单一年份、单一参数或少数交易时，才允许进入冻结后的纸面前向验证。纸面前向达到足够样本前不得宣称目标已经实现。

## 9. 研究顺序

研究顺序固定如下，不允许因后续模块更容易产生好看的回测而倒置：

1. 验证非抵消的动态估值中枢对未来60、120、242日收益是否具有单调预测能力；
2. 验证指定目标日Bear/Base/Bull价格分布的覆盖率与校准度；
3. 独立验证20日方向概率和20日未来波动率；
4. 冻结现货仓位映射并执行统一成本回测；
5. 长期层和短期层均通过后，才评估FVG是否能改善执行价格。

FVG、分钟线和订单流不参与长期估值模型的选型，也不得被当作弥补长期Alpha不足的收益来源。

## 10. 当前旧模型的定位

现有`valuation_fvg_engine.py`中的12个月合理价值带保留为基准模型，但存在以下限制：

- 目标期限固定为12个月，不是指定未来日期；
- 基本面预测来自历史隐含EPS/BPS增速中位数；
- 合理PE/PB来自无条件历史滚动分位数；
- 三档区间没有显式情景概率或概率校准；
- 短周期`wave_z`是均值回归规则，不是方向概率模型；
- 尚无独立未来波动率预测。

因此旧模型不得直接作为本规范的最终实现，但可作为所有后续模型必须战胜的简单基准。
