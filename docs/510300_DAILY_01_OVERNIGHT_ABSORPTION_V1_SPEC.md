## 1. 唯一研究问题

本协议只检验一个新机制：510300过去5个交易日出现分红修正后的隔夜负贡献，同时日内贡献为正时，是否代表隔夜抛压被交易时段持续吸收，并提高从下一交易日开盘开始的未来20日成本后收益分布。

本协议不使用分钟线、沪深300指数、成分股、期货、期权、估值、宏观或其他ETF。唯一行情输入是510300自身的日线OHLCV、成交额和完整现金分红事件。

## 2. 与既有研究的区别

既有H001检验的是过去5日510300含分红总收益反转。DAILY_01不把它重新命名：总收益相同的两个5日窗口，如果一个由隔夜下跌和日内修复构成，另一个由日内持续下跌构成，DAILY_01必须给出不同分值。

正式结果必须在控制H001后报告DAILY_01的增量系数。如果增量方向不为正，即使单变量结果有利，也按`REJECT_AS_RELABELED_5D_REVERSAL`处理。

## 3. 精确收益贡献定义

设T日未复权开盘、收盘和每份现金分红分别为`O_t`、`C_t`和`D_t`，前一交易日收盘为`C_{t-1}`：

```text
R_t  = (C_t + D_t) / C_{t-1} - 1
ON_t = (O_t + D_t - C_{t-1}) / C_{t-1}
ID_t = (C_t - O_t) / C_{t-1}
R_t  = ON_t + ID_t
```

`ON_t`和`ID_t`是同一日总收益的加法贡献，不是两条可以独立复利的策略。除息日的现金分红只能计入一次；不得把未修正的低开误判为隔夜抛压。

## 4. 唯一冻结因子

```text
ON5_t  = sum(ON[t-4:t])
ID5_t  = sum(ID[t-4:t])
RV20_t = sample_std(R[t-19:t])
RAW_t  = (ID5_t - ON5_t) / (RV20_t * sqrt(5))
PCTL_t = RAW_t在此前252个有效RAW中的经验百分位
```

- 百分位历史严格截止T-1，不包含T日；
- 至少需要252个完整历史RAW；
- 分母非正或输入缺失时输出`NO_VIEW`；
- 只有`ON5_t < 0`且`ID5_t > 0`时允许形成进入候选；
- 禁止测试3日、10日、60日或其他聚合窗口；
- 禁止对RAW取反、改用复合隔夜收益或搜索其他标准化方式。

## 5. 冻结研究状态机

- 初始研究状态为现金；
- 空仓且符号条件满足、`PCTL_t >= 80%`：T日收盘形成`ENTER`；
- 研究持有状态且`PCTL_t < 50%`：T日收盘形成`EXIT`；
- 研究持有满20个交易日：T日收盘强制形成`EXIT`；
- 等于80%允许进入，等于50%不退出；
- 所有状态变化最早只能在T+1开盘执行；
- 0%/100%只是冻结的研究状态，不是当前账户仓位。
