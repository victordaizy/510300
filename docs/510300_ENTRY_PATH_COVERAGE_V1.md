# 第59轮：扩大进入路径的线性退出

本轮只检验一个新设置：进场条件、自然退出、再次进入条件及八个学习因子沿用原方案，扩大退出模型能够学习的历史进入路径。先写定规则和通过必要测试，再生成本轮路径收益、训练模型和计算账户。每股盈利预测、估值、申购资料等补齐工作继续暂停。没有新增数据采购、其他证券或交易权限。

## 要回答的问题

旧日内强弱退出模型的参考标签只来自34个自然结束的原持仓周期。即使保持相同的价格进入条件，不同进入日期面对的后续路径也可能不同。本轮检查扩大覆盖后，简单线性退出是否改善完整账户表现。相邻进入日期重叠，不能把路径数当成独立行情数。

只比较一个新设置与原学习退出、原自然退出、原急跌回升及学习退出各半、买入持有四个对照。原对照采用保存的账户，不重新选参数。

## 每个因子的中文定义

日内强弱入场因子：先把当天含分红的开盘到收盘对数涨跌，减去前收盘到当天含分红开盘的对数涨跌。最近60日的这些差值相加，再除以最近60日差值的样本标准差及60的平方根。分母为零或所需数据不完整时，没有可用信号。含分红隔夜涨跌使用“开盘价加当日每份分红”相对于前收盘价的比值取自然对数；日内涨跌使用“收盘价加当日每份分红”相对于“开盘价加当日每份分红”的比值取自然对数。这保持既有分红拆分口径。

退出学习使用以下八个输入，全部只读取当日收盘及之前的信息：

|因子|具体定义|作用|
|---|---|---|
|持仓时间对数|买入当天记第1个持仓交易日；持仓日数加1后取自然对数|区分刚买入和已经持有较久的状态|
|含分红浮盈浮亏|当前份额乘收盘价，加持仓期间已确认分红，再除以买入成交金额及佣金之和，最后减1|判断当前盈利或亏损程度|
|持仓回撤|上述含分红持仓价值，除以本周期此前及当前最高值，再减1；最高值初始为买入成交金额及佣金之和|判断利润回吐或亏损加深|
|入场模式|本轮始终为日内强弱这一种模式，数值固定为1|保留旧模型输入结构；常数本身没有区分作用|
|五日涨跌|包含现金分红的财富指数，相对5个交易日前的比值取自然对数|刻画短期方向|
|二十日涨跌|同一财富指数，相对20个交易日前的比值取自然对数|刻画较长短期方向|
|一百二十日均线偏离|当日财富指数除以含当天的120个交易日均值，再减1|刻画价格相对中期水平的位置|
|二十日波动|最近20个交易日含分红简单收益的样本标准差，乘242的平方根|刻画近期风险水平|

财富指数按每天“收盘价加当日每份分红”除以前收盘价的比值连乘。此指数只用于因子计算；实际账户分红仍按登记、除息和到账分别处理。

## 正式评价账户什么时候进入

连续两个收盘的日内强弱入场因子均严格大于1，并且原基础因子数据完整。账户空仓、再次进入资格有效、距离上次实际卖出已满足2个交易日等待时，收盘决定买入，下一交易日开盘按当时现金可负担的100份整数倍尝试成交。

只有实际买入才消耗再次进入资格。已经持有时不追加份额；买入因涨停等原因受阻，资格保留。一次实际卖出以后，必须先在空仓时观察到旧进入条件不成立，才恢复下一次进入资格。随后还需再次满足连续两个收盘强于1和等待期。不会因学习模型提前卖出而在同一段未消失的原进入条件中反复买回。

## 正式评价账户什么时候退出

以下任一条件在收盘成立，下一开盘请求全部卖出：

1. 日内强弱因子连续两个收盘严格小于0。
2. 含分红持仓价值相对含买入佣金的成本，亏损达到6%。
3. 含分红持仓价值从本周期最高值回撤达到8%。
4. 持有到第60个交易日收盘，买入当天计第1日。
5. 本轮线性模型连续两个实际持仓收盘预测“继续持有相对下一开盘退出的优势”严格为负。

多个条件可以同时成立，没有独立止盈线。卖出受跌停或次日可卖规则阻挡时，后续开盘持续请求退出，后来的正预测不会撤销已经发出的退出请求。新持仓的负预测累计次数从头计算。缺少成熟模型或完整因子时，预测为缺失，累计次数清零，继续执行前四项自然退出。缺失预测不是零收益预测。

## 扩大参考路径的方法

从2013年6月3日起，每个满足原日内强弱进入条件、信息完整且资料中存在下一开盘的收盘日，都登记一次假想进入。每次假想进入单独从20万元开始，只在紧接着的开盘尝试买入一次；首次不成交便结束该尝试，不重试。这些路径用来构造训练状态，不是1213个可同时持有的实盘账户；登记前仅清点过合格原点数量，未读取新路径收益。

买入后只使用上文前四项自然退出，成交、费用、滑点、限价、100份整数单位、次日可卖以及分红权益与正式账户使用同一套原语。自然退出实际成交时停止该参考路径。退出后的空仓现金尾部不另行延长，记录的终值可能含已确认但未支付的应收分红；它不是可用于评价夏普的完整统一日历组合。终点强制退出、到终点仍未自然退出、下一开盘已经是资料终点的路径均标为未自然成熟，不用于成熟组训练。

连续的有效原进入条件归为一组，原条件首次在完整数据下不成立时才确认这组信号结束。数据缺失不能冒充已确认结束；直到资料终点仍连续的信号组也未结束。每一组必须同时满足“信号已确认结束”和“组内全部登记进入尝试都已自然退出或首次买入已确认未成交”，才整体成熟。成熟日取信号结束日与该组所有尝试处理完成日中的最晚日期。任何一条路径尚未成熟，该组较早结束的其他路径也不能提前训练。

如果一组开始于2013年6月3日以前，只登记该日及以后的合格原点，保留左侧截断标记；仍须等待原信号实际结束以及所有已登记路径处理完成。没有把边界之前未知的路径补为零收益。组间也可能存在后续持有时间重叠，分组等权只能限制重复路径权重，不能证明组间独立。

## 标签与每月学习

只使用自然退出已成交路径中的继续持有状态：自然退出请求尚未发出，八个输入完整，而且下一开盘早于后来实际自然卖出日。学习目标等于“按该路径后来自然退出”相对于“该状态的下一开盘立即卖出”的净收益差，再除以下一开盘按原数量计算的未扣费市值。

两种退出都计算卖出滑点、最小价格单位取整和卖出佣金；额外分红权益由股权登记日比较。下一开盘之前已经获得的权益在两边抵消。这个标签沿用第31轮定义，假定比较中的提前退出可以在下一开盘全部卖出，没有独立模拟提前退出遇到跌停后的延迟。这一标签近似不能代替正式账户的实际可成交检验；正式评价仍按成交约束处理。

2015年评价开始前一个收盘做首次学习检查，此后每月第一个交易日收盘更新一次。每次只选当时已经整组成熟且有有效标签的最近20个组；不足10个组或100条状态时，不拟合模型。每组总权重为1，组内有标签的路径等权，每条路径的状态再等权。因此同一段长行情不会仅因可模拟的进入日期更多而占据更大的组权重。

模型为与旧方案相同的线性岭回归：各因子用当前训练样本及上述权重计算均值和总体标准差，减均值、除标准差，限制在负5至5。标准差不大于万亿分之一时设为1。惩罚系数固定为1，截距不惩罚，不再寻找更好参数。保存每次实际拟合的均值、标准差、截距、八项系数、训练日期和最后成熟组日期，并输出完整中文规则。基础费用标签训练出的同一串模型用于基础及压力费用评价。

官方算法定义参见[岭回归文档](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.Ridge.html)。这是计算方法依据，不是收益有效性的证据。

## 统一比较和结束条件

主评价为2020年1月2日至2026年8月14日，较早诊断为2015年1月5日至2019年12月31日。两段均从20万元开始，最后一天统一在开盘按原流程清算。包括所有空仓日，年化使用242个交易日，现金收益和无风险收益暂按零。净夏普为完整账户每日扣费收益的算术均值除以样本标准差，再乘242的平方根；同时报告复合年化、最大回撤、仓位、交易次数、佣金和滑点。

基础费用每边佣金万分之2、最低5元，滑点万分之5；压力费用每边佣金万分之4、最低5元，滑点千分之1。统一使用0.001元价格单位和原10%方向限价、次日可卖规则，不改变评价窗口或现金收益假设。

只有主评价扣费净夏普达到1.2才进入达标候选检查；较早历史、压力费用和稳定超额仍须检验。即使局部超过1.2，反复查看过的这些历史也不能被称作独立验证。若扩大覆盖不能在两段及两档费用下改善原学习退出，结束这项局部改动，不继续扫描进入间隔、组数、权重、岭惩罚、标签定义和确认天数。输出普通中文说明和全部保存结果，不制作GPT数值审阅包，不开展额外安全性审计。
