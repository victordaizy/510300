# 510300官方分红覆盖维护规则

本维护只更新“已核对到哪一个交易日”的凭证，服务于已有B1风险观察器。它不修改分红事件、价格历史、训练种子、风险模型或仓位规则。

## 如何确认覆盖

1. 实际访问华泰柏瑞官网的510300产品页，保存完整原文。基金身份必须匹配，分红表的分页必须使用已经完整返回的行。
2. 官网按每10份基金份额列示分红，统一除以10后，与既有14次分红的权益登记日、发放日和每份金额逐项比较。官网这张表不列除息日；除息日继续以原已保存的官方公告为准。
3. 实际查询上交所510300自2026年1月1日至本次访问当天的全部基金公告，按网站提供的分页总量取全，核对代码、日期和重复记录。查询必须返回已经确认的2026年1月12日分红公告，防止将错误查询的空结果解释为没有新分红。
4. 如出现新的分红、收益分配、折算、拆分或份额合并公告，或者官网出现新事件、旧金额变化，停止更新，等待官方事件逐项核实。不能猜除息日，也不能自动追加或改写事件。
5. 只覆盖到本机实际时间之前已经收盘、且官方日历明确列出的交易日。两处官方响应的服务器日期必须能支持该收盘时点。周末不能提前覆盖下一个交易日，盘中不能覆盖当天收盘。
6. 将官网原文、上交所全部查询响应、实际访问时间、请求参数和核对结果保存到独立目录。原覆盖凭证先另存，事件表和原14份官方证据保持原字节；全部条件通过后才原子更新供观察器读取的覆盖凭证。

这里的覆盖是截至实际检索时官方已发布资料的完整性，不代表能够知道将来的公告、追溯更正或其他尚未公开信息。覆盖凭证中保留的旧新浪交叉核对会注明原核对日期，不能冒充本次重新抓取的结果。

## 何时运行

日常随现有B1观察任务运行。仅在原定五交易日预测原点、北京时间19:30至23:59:59的窗口内，先维护官方分红覆盖，再运行原观察器。非原点不访问来源，也不更新凭证。

本次修复阶段可以单独维护至最近已收盘交易日，不生成预测。原观察器的第一个新预测日仍是2026年9月11日，不能把本次维护算成一个预测样本。

## 失败时的处理

来源访问失败、表格口径变化、公告没有取全、时间不足或新事件未核实，都保持原覆盖日期，并留下“无法确认覆盖”的结果。已有预测原点、缺失样本及52、104个原点的审查规则不改变。成本后夏普1.2与稳定净超额仍须由完整研究和独立样本验证，分红维护通过不构成策略达标。
