# 510300 趋势生命周期图谱 V1 冻结规范

## 1. 研究对象与边界

`510300_TREND_LIFECYCLE_ATLAS_V1`只研究一个问题：H00300全收益路径中的上涨开始、上涨衰退、下跌开始和下跌结束，是否伴随可在事件日前观察到的价格接受度、成分参与度、行业扩散、压力流动性和慢变量变化。

本阶段是`MECHANISM_DISCOVERY_ONLY`。它不输出策略净值、净夏普、UP_CAPTURE、DOWN_CAPTURE、当前状态概率、Paper/Shadow信号、仓位、订单或实盘授权。510300仅是未来可能的执行资产；标签资产固定为H00300全收益指数。

旧ADX三态路由、旧状态转移路由、旧压力图谱、旧VWAP/做T和PCF/IOPV分支均不得被改名营救。震荡状态在V1中的动作仍是`NO_NEW_TRADE`。

## 2. 冻结顺序

1. 冻结本规范、YAML协议、实现、测试、运行脚本和输出审计脚本。
2. 只审计输入身份、时钟、覆盖、历史权重快照方向和上游拒绝状态，不读取本研究新建的未来路径标签。
3. 写入不可覆盖的冻结清单和冻结回执。
4. 冻结成功后才允许生成Label B未来路径、事件轨迹和领先性结果。
5. 结果出现后不得修改标签、窗口、阈值、特征、来源、事件选择或时期划分进行营救。

## 3. 数据证据层级

- H00300：负责趋势标签，固定为全收益路径。
- 成分与行业截面：负责内部结构，正式图谱期从2019-12-23数据开始，先预热120个交易日，评价从2020-06-23开始。
- 月度历史权重：只使用快照日不晚于观察日的最近快照；但此前119个月缺少同期中证官方归档，因此证据类别固定为“回顾性、历史污染”。不得称为严格点时官方权重。
- 等权广度：作为历史权重敏感性，不得被描述为官方指数权重。
- 国债曲线：仅作慢变量先验。盈利修正广度和完整宏观修订版本继续保留`NO_VIEW`。

即使双标签结构通过，只要历史成员/权重来源证明门仍失败，也不得冻结下一阶段路由器。

## 4. 双标签

### Label A：波动标准化方向变化

用过去60个交易日的日收益波动率构造20日参考阈值，乘数固定为1.25，阈值裁剪在6%至18%的对数变化之间。方向变化算法在上涨或下跌得到确认后，将事后局部极值日记为`UP_START`、`UP_END`、`DOWN_START`或`DOWN_END`。阈值只使用确认时点以前的波动，不读取未来波动。

Label A是事后事件标签，不是可交易信号；局部极值日与确认日必须同时保存，避免把确认滞后隐去。

### Label B：未来20日/60日路径

对每个观察日独立计算未来20日和60日标准化收益、60日方向效率、MFE与MAE，并按YAML中冻结阈值分为：

- `SUSTAINED_UP`
- `SUSTAINED_DOWN`
- `LOW_TREND_RANGE`
- `MIXED_TRANSITION`
- `CENSORED_FUTURE_60D`

连续至少5日、内部缺口不超过2日的同类路径构成一个事件区间；同类转移之间强制20个交易日冷却。Label B与点时特征物理分离。

## 5. 四层机制变量

点时特征面板只使用观察日及以前数据，禁止任何`future_`、`forward_`或目标字段：

1. `PRICE_ACCEPTANCE`：20/60/120日波动标准化趋势、20/60日方向效率、60日回撤、5日突破接受度。
2. `PARTICIPATION_BREADTH`：快照权重与等权MA广度、5日广度扩散、60日新高减新低权重、行业20日正收益权重。
3. `STRESS_LIQUIDITY`：20日贡献集中度、20日平均相关性、5/20日下行波动比、极端下跌权重、流动性价格冲击分位。
4. `SLOW_PRIOR`：10年国债63个曲线观测变化的因果分位。盈利修正和修订版宏观数据不完整，继续`NO_VIEW`。

## 6. 事件对齐和领先性

每个事件等权，对齐区间固定为`[-120,+60]`交易日。事件自己的`[-120,-61]`作为基线，使用`1.4826 × MAD`标准化。主要事前窗口为`[-20,-1]`；领先起点在`[-60,-5]`内搜索，要求连续5日越过预先冻结的0.5个基线稳健标准差。

变量只有同时满足以下条件才在某一标签、某一转移中标记为通过：

- 至少6个独立事件；
- 事前变化方向一致率不低于65%；
- 单侧符号检验`p <= 0.10`；
- 事前中位变化绝对值不低于0.5；
- 中位领先起点不晚于事件前5日；
- 单一事件绝对贡献占比不高于50%；
- 早期和晚期各至少3个事件时，中位方向不得相反。

进入双标签候选还要求Label A和Label B对同一转移、同一变量都通过。`UP_START`、`UP_END`和`DOWN_START`每类至少需要两个变量且来自至少两个机制模块。仅靠未严格证明的快照权重变量不能通过来源门。

## 7. 七状态参考图

七状态面板只是事后解释图，不是点时预测：

- `U0_EARLY_UP`：上涨开始后0至20日。
- `U1_BROAD_UPTREND`：Label B持续上涨、MA60广度至少55%、下行波动比低于1。
- `U2_FRAGILE_LATE_UP`：上涨结束前20日至结束日。
- `R_LOW_STRESS_RANGE`：Label B低趋势震荡且压力因果分位不高于60%。
- `D0_EARLY_DOWN`：下跌开始后0至10日。
- `D1_MARKDOWN_PANIC`：下跌开始后11至60日且压力因果分位至少70%。
- `X_TRANSITION_NO_VIEW`：冲突、缺失或其余情况。

若多个状态重叠，风险状态优先级为`D1 > D0 > U2 > U0 > U1 > R > X`。这个优先级只用于图谱着色。

## 8. 裁决

本阶段可能得到三类非数据失败结果：

- 双标签结构不通过：`ATLAS_COMPLETE_NO_DUAL_LABEL_LEADING_STRUCTURE_NO_ROUTER_PROMOTION_NO_RESCUE`。
- 结构通过但来源证明失败：`ATLAS_STRUCTURE_FOUND_SOURCE_PROVENANCE_BLOCKED_NO_ROUTER_FREEZE`。
- 结构和来源均通过：`ATLAS_DUAL_LABEL_STRUCTURE_PASS_PHASE_2_PROTOCOL_FREEZE_ELIGIBLE`。

第三种状态只允许另建并冻结下一阶段协议，不等于Alpha验证，更不等于Paper、Shadow或实盘授权。
