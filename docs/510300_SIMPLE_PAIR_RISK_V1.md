# 第29轮：两个固定信号的权重与风险缩减

保持“趋势与震荡反弹切换”“六十日日内强于隔夜”两个基础信号及其原进出场规则不变，仅调整它们在组合中的权重和组合层风险缩减。此前等权方案在两个时期基础夏普约0.534和0.517，但择时增量区间跨零；本轮不把它视为已确认有效策略。共12个设置，包含原样等权对照1个、新增11个。

## 两个信号各怎样判断

趋势信号：收盘高于一百二十日均线、二十日方向效率超过0.3时，二十日突破进入；其余状态下，低于二十日均值1.5个样本标准差且当日回升进入。趋势持仓按趋势条件消失、十日低点、8%亏损、8%追踪回撤退出；反弹持仓按趋势恢复、均值收复、5%亏损、10日到期退出。实际卖完后经过两个后续收盘才能重新进入。

日内强弱信号：每日取日内对数收益减隔夜对数收益，累计六十日，除以最近六十日每日差异的样本标准差乘六十的平方根。连续两日大于1进入，连续两日小于零、亏损6%、从持仓高点回落8%、持有60日任一成立退出。实际卖完后经过两个后续收盘才能重新进入。

两个基础策略分别产生收盘持有意愿状态，愿意进入或继续持有为一，已决定退出或空仓等待为零；组合使用基础费用下已保存的状态，主评价与较早时期分别沿用对应账户判断，不能查看次日收益。

## 十二个设置

趋势状态权重分别为25%、50%、75%，日内强弱状态权重分别为75%、50%、25%。每种权重都与以下四种风险规则组合。

|风险规则|目标仓位怎样改变|退出与恢复|
|---|---|---|
|不额外缩减|两个零或一状态按固定权重相加|状态变化使目标降为零时全部退出，重新为正时进入|
|按10%波动水平缩减|基础目标乘以“10%除以最近二十日年化波动率”，乘数最多为一|风险上升时减仓；风险回落后按当日状态和新比例恢复|
|按15%波动水平缩减|基础目标乘以“15%除以最近二十日年化波动率”，乘数最多为一|同上|
|短期波动冲击时退出|五日波动率超过六十日波动率的1.5倍，且五日含分红累计下跌时，目标直接为零；否则保留基础目标|冲击条件成立则下一开盘退出；条件消失且基础目标为正时，下一开盘重新进入，不另加等待期|

二十日、五日和六十日波动率均为对应交易日含分红简单收益的样本标准差乘242的平方根。五日涨跌只使用截至当日收盘的累计收益。预定主方案是两个信号各50%，并按15%波动水平缩减；50%且不缩减为既有对照。

## 完整组合账户怎样执行

每天收盘确定目标，下一开盘按账户净值转换为100份整手买卖，不能融资或卖空。持仓与非零目标相差小于10个百分点时不调整份额；目标为零仍请求全部卖出。旧单未成交时，下一收盘按新目标更新，不假定必然成交。当天买入份额最早次日可卖。

原始亏损、追踪退出与到期规则用于基础信号的独立状态；组合层按上述风险规则与每日目标执行。本轮不把基础账户收益平均成组合收益，而是重新模拟实际组合现金、份额、分红和调仓成本。

主时期为2020年1月2日至2026年8月14日开盘终点，更早时期为2015年1月5日至2019年12月31日开盘终点，各自从20万元开始。现金及无风险收益零，年化242日；基础佣金万分之二、最低5元、滑点万分之五；压力佣金万分之四、最低5元、滑点千分之一。保留0.001元价格跳动、涨跌停及实际分红权益与到账。

两时期均完整计算全部设置，不按结果挑选年份。主评价26个记录中22新增、4复用；更早诊断同样26记录中22新增、4复用。历史已经被研究过，最优结果属于筛选，不能作为独立验证。净夏普1.2、稳定超额要求不变。
