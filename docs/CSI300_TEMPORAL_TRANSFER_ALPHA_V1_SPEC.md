# 沪深300十因子时间迁移 Alpha V1

状态：`DISCOVERY_ONLY_TWO_STAGE_FREEZE`  
训练期：2015-01-05至2021-07-12  
评估期：2021-08-12至2026-08-14  
本金：20,000元  
目标：评估期基础与15bp压力成本年化超额均不低于20%

## 核心隔离

训练脚本只能读取2014—2021外部数据，不能导入2021—2026的成分行情或收益。训练完成后，模型文件、训练报告、十因子顺序和近期评估输入再次哈希冻结；只有第二次冻结完成后，评估脚本才能读取近期行情。模型不在评估期更新。

## 十因子

固定使用：120日至20日前中期动量、60日动量、20日动量、5日反转、20日低波、60日低波、60日回撤位置、20/120日成交额冲击、指数相对MA120距离、点时成员站上MA60广度。个股因子按当日点时成员做截面排名，市场因子保留连续值。

模型为固定参数直方图梯度提升回归，目标是t+1开盘至t+21开盘的个股总收益减同期H00300收益。训练期旧样本按1095个日历日半衰期衰减；不搜索学习率、叶数、正则、周期或因子。

## 组合与交易

每20个交易日收盘预测一次，最高3只为目标。为降低2万元账户换手，旧持仓若仍在预测前10名则保留，再从最高名次补足3只。保留规则在近期收益读取前冻结。

下一交易日开盘执行，最多3只，每一腿至少5000元，100股整数手，T+1；停牌、近似涨停买入和近似跌停卖出不假设成交。费用为佣金万三最低5元、卖出印花税历史税率、单边5/15bp滑点。

## 验收

基础与压力成本年化超额均至少20%，20日移动块Bootstrap的95%下界大于0，三个预定义评估段至少两个正超额。失败后禁止修改模型、因子、20日周期、前三持仓或前十保留门槛补救。无论结果如何，不生成纸面仓位、订单或券商动作。
