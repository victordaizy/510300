# 第171轮：相邻日收益相关与累计方向的独立价格状态

第170轮成熟周期预算在主历史到2024年6月才首次满足两父各五个周期的要求，较早历史从2018年2月才开始更新；完整结果仍未达标。第171轮改为直接从每日市场收益形成独立状态，不再依赖父策略交易周期积累。已有父策略和已关闭方法的规则、来源及结果保持。

## 全部因素

第一项因素为相邻日收益相关度。每个收盘取最近六十个完整含分红日对数收益。单日对数收益由当天原始收盘价加当天每份除息分红、除以前一原始收盘价后取自然对数得到。

把这六十个收益中的第二个至第六十个，与第一个至第五十九个逐一配对，共五十九对。分别计算两条配对序列的平均值，各自减去自己的平均值。对应偏差的乘积相加，再除以“两条序列各自偏差平方和乘积”的平方根，得到配对的皮尔逊相关系数。

相关系数为正，表示该窗口中相邻收益倾向同向变化；为负表示更倾向反向变化。这是历史描述，不作显著性检验，也不宣称已经证明下一日可预测。任何收益缺失或两条配对序列任一没有波动，则相关度未知，不能补成零。数学范围为负一至一，只有浮点舍入造成的轻微越界才收回该范围。

第二项因素为六十日累计方向，等于上述同一完整六十日对数收益相加。正值表示该窗口含分红累计收益为正，零和负值均不算正方向。

第三项因素为普通风险规模：最近二十个含分红日简单收益的样本标准差，乘二百四十二的平方根，得到年化波动率。方向允许持有且年化波动完整大于零时，目标比例等于百分之十除以该年化波动，上限百分之一百。方向不允许持有且方向信息完整时，目标为零。允许状态下波动缺失或为零，目标未知，不能补为无风险满仓。

## 状态、进入与退出

从完整市场数据最早日期开始，内部允许状态初始为关闭，三个连续计数均为零；不按评价开始、每年或每次实际入场重置市场状态。

相关度大于零且六十日累计方向大于零，两项同时成立的连续天数达到两天，开启允许持有状态。任意一天不满足联合进入条件，进入计数归零。

相关度不大于零连续两天，或累计方向不大于零连续两天，任何一项成立就关闭允许持有状态。两个退出计数分别记录，不把交错出现的一天弱相关与一天弱方向相加成两天。相应条件不成立时，该退出计数归零。完整数据下其他情形保持原允许状态。

六十日窗口缺失或相关度未定义时，当日状态信息与目标未知，同时内部允许状态和连续计数清零；恢复完整后重新满足连续条件才进入。实际账户面对未知目标保持实际份额。单独的风险波动缺失不修改已有完整方向状态，但允许状态的目标仍未知。

收盘后的十五点零五分形成目标，下一交易日真实开盘执行。空仓且目标为正，按照上一收盘本账户净资产和原始收盘价计算目标份额，向下取一百份整手；取整为零则不买入。

已有持仓且目标为正，目标与实际股票市值占本账户净资产比例偏差不足十个百分点时保持，达到十个百分点则调至目标中心。带外正目标按整手算成零时实际全部卖出。完整方向关闭形成明确零目标时，优先全部退出，不受调仓带阻拦；固定终点开盘也优先清算。

未知保持实有份额。受阻后下一收盘依据最新目标重新决定；退出后新的可执行正目标可再次进入，不额外增加等待期、永久退出锁、固定持仓天数或另一层止损规则。

## 有限评价与固定账户口径

只有一套六十日相邻收益相关、六十日累计方向、两日进入退出确认和二十日普通风险规模的固定规则。只计算四个新账户，零新预测模型、零新增参考账户、零外部资料。保存对照为第143轮、第165轮和买入持有，每段两档费用共八条指标记录。

主历史2020年1月2日至2026年8月14日开盘；较早历史2015年1月5日至2019年12月31日开盘。每账户二十万元、二百四十二日年化、现金及无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。一百份整手、零点零零一元价位、原百分之十方向限价、次日可卖、真实下一开盘、资金约束和分红登记除息到账分开均保持。

必要测试覆盖五十九对相关的手算、正负及边界、缺失和常量未定义、累计方向、进入联合连续及退出分别连续、允许状态保持和恢复、风险规模、未来与前缀隔离、费用共用市场状态、实际资金进退再入场、整手调仓带、分红和终点清算。通过后冻结一次，运行四账户，再独立核对相关与状态路径、实际份额和净资产。

不搜索其他窗口、相关阈值、连续天数、年份或费用，不把历史高值解释为新的独立证据。完整目标仍为成本后夏普至少一点二、稳定超额和独立证据；不达标则关闭该固定方法。此文为第171轮新账户计算前确定的完整规则，六项必要测试已通过，尚未冻结或计算新账户。
