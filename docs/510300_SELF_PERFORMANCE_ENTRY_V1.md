# 第45轮：策略自身过去一年赚钱，才接受新进入

## 核心想法

不假设一套策略在所有时期都有效。先持续计算原第32轮线性退出候选的参考账户，再检查它过去一年的完整扣费收益。如果过去一年为正，允许考虑新机会；如果为零或负，暂缓新买入。

这是对原策略自身近期表现的一项进入过滤，不是按市场涨跌判定牛熊，也不训练一个新的预测模型。第9轮曾按状态学习多个旧机制权重，第24轮曾季度选择旧价格规则，第39和40轮曾切换两个策略；本轮只对后来形成的第32轮单一候选判断是否接受新进入，不改写旧失败。

## 连续参考账户如何形成

使用已有日线、分红及第31轮保存的原线性模型，从2013年6月3日起，完整模拟一次原第32轮规则的连续参考账户。初始20万元，基础费用、100份整手、买入次日可卖、分红权益与未成交处理均同原规则。参考模型每月也只能在实际训练完成后使用，之前没有模型时仍保留无模型状态，执行原价格与时间保护。

参考账户从2013年一直连续运行到2026年研究终点，中间不在2019年底或2020年初清仓、重置资金或重新发放进入许可。不能把两个独立评价账户首尾拼接，否则交界处的持仓和现金变化会污染近期收益。

这个账户用于计算历史表现，持续按原规则运行。新的过滤账户即使暂缓买入，参考账户仍继续模拟原策略的新机会；这样原策略表现改善时，过滤条件仍有机会恢复，不会因为过滤账户一直空仓而永远没有新收益记录。它不是实际账户，也不构成新增模拟交易或券商权限。

## 新增因子的精确定义

取参考账户截至当前收盘最近242个交易日的净日收益，逐日把“一加收益”连乘，再减一，得到过去一年的累计净收益。它包括原策略的空仓日、所有基础佣金及滑点、实际持仓价格变化和分红，不使用指数收益或未扣费理论收益代替。

必须有完整连续242个收盘账户日。缺少日期、收益无效或尚未拥有足够历史时，记为资料不足，不填成零，也不新买入。研究最终日的统一开盘退出记录不是收盘观察，不用于形成新进入条件。

该累计净收益严格大于零，才通过进入检查。恰好为零也暂缓进入。窗口242日、门槛零均提前固定，不扫描半年、两年、不同夏普或收益门槛。主评价和压力账户共享基础费用参考账户的同一历史表现因子。

## 原因子和完整进出场规则

原进入因子是日内相对隔夜强弱：每天日内对数涨跌减隔夜对数涨跌，最近六十日之和除以这些差值的样本标准差及六十的平方根；沿用含分红一致口径。

模型退出使用八个因子：实际持仓交易日数加一的自然对数；实际份额市值加本周期已确认分红相对买入含佣金成本的浮盈亏；上述持仓价值相对周期最高收盘价值或初始成本中较大者的回撤；固定为一的进入模式；含分红五日对数涨跌；二十日对数涨跌；一百二十日均线偏离；二十日含分红简单日收益样本标准差乘二百四十二的平方根。

这些原模型按月在当时已结束的最近二十个参考周期上训练，至少十个周期、一百条持仓状态，周期等权；因子减训练均值、除总体标准差后限制在负五至正五，岭回归惩罚一。目标仍为继续持有到原自然退出相对下一开盘卖出的净收益差。本轮使用原模型，不使用第44轮五日内标签模型。

空仓时须同时满足：原相对强弱分数连续两个收盘大于一；进入许可有效；距离上次实际卖出至少两个交易日；原策略自身过去一年净收益有完整资料且严格为正。随后在下一开盘请求买入可用现金所能负担的100份整手，按实际开盘价格、费用及方向性涨跌停处理。

过去一年收益未通过时，只暂缓本次新买入，不改变原始相对强弱条件。尚未实际买入的进入许可保留；不把暂缓买入误当作原始机会已经消失。持仓期间不因该过滤因子转负而追加一个新的强制卖出规则，本轮只隔离进入过滤的影响。

已有持仓仍在以下任一条件成立时请求下一开盘全部卖出：原相对强弱分数连续两个收盘小于零；持仓含分红亏损6%；从本周期收盘最高持仓价值回落8%；买入日算第一天，持有满六十个交易日；原线性模型连续两个持仓收盘预测继续持有收益为负。缺模型时保留原价格和时间退出，不将缺失变成零预测。

一笔持仓只实际买入一次，不在持仓中追加。已有退出请求受阻时持续保留，不能因为后续模型预测转正而撤回。实际卖完后，至少过两个交易日，并在空仓期间观察原始相对强弱进入条件先消失、再出现，才能重新进入；过去一年收益转正本身不重置进入许可。

## 账户与停止条件

主评价2020年1月2日至2026年8月14日开盘，共1604日；较早诊断2015年1月5日至2019年12月31日开盘，共1219日。两个实际评价段各20万元，仅510300及现金，现金与无风险收益零、年化242日。

基础费用为单边佣金万分之二、最低5元、滑点万分之五；压力费用为佣金万分之四、最低5元、滑点千分之一。整手、价格最小单位0.001元、方向性涨跌停、次日可卖、分红应收和到账、未成交和统一终点开盘退出都保持。

每段一个候选两档费用共2条新账户，原第32轮候选与买入持有两档费用共4条复用对照，每段6个记录，两段4条新评价账户。另新增1条连续参考账户，单独计数；没有新模型、没有新数据下载。

先验证完整窗口、空仓日、未来收益不能影响过去过滤、缺失不填零、未买入许可保留及全通过时恢复原账户，再冻结唯一设置并运行。没有明显跨时期改善就停止该历史表现窗口和门槛的细调。过去赚钱不保证未来赚钱，历史筛选也不等于独立验证；完整扣费净夏普至少1.2及稳定超额的目标保持。
