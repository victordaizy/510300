# 510300 大盘压力传导、卖盘吸收与耗竭机制研究 V1

`PROJECT_ID = 510300_STRESS_TRANSMISSION_AND_EXHAUSTION_ATLAS_V1`

## 研究问题与证据等级

本项目只回答一个问题：在大盘风险事件中，哪些点时可观察变量对应压力来源、压力传导和卖盘吸收/耗竭；它们是在价格路径改变之前出现，还是只与价格同步或落后。

本研究是受到既有历史研究污染的回顾性机制发现，不是策略回测，也不是旧状态路由器的修正版。`510300_REGIME_TRANSITION_ROUTER_V1`继续保持`REJECTED_FROZEN_STATE_IDENTIFIABILITY_GATE_FAILED_NO_PHASE_2_NO_RESCUE`。它的61个完整压力区间只作为等权事件采样单位，旧状态含义、0.70阈值、恢复规则、仓位和收益结论一律不得复用或改名。

即使四道机制门全部通过，也只允许另建新的冻结策略研究；不自动获得Paper、Shadow、订单、券商连接或实盘资格。

## 点时时钟

- ETF、份额、两融、广度和价格：T日15:00后；
- IF原始期限结构：T日15:15后；
- 中债曲线：T日17:30后；
- 统一观察时点：T日18:00后；

机制面板不得包含未来收益、未来回撤、事后低点或未来修复标签。未来路径单独写入结果面板。事件内“加速日”和“最大价格冲击日”允许使用完整事件路径，但必须标记为`RETROSPECTIVE_ONLY`，不得进入两个预测问题或任何通过门。

## 三个经济量

### 压力来源

只使用两个全期有合同的点时分量：

1. 510300份额与两融变化形成的杠杆/流动性压力；
2. 中债10年收益率变化形成的折现率压力。

两项等权形成`pressure_source_score`。事件起点按0.67活跃阈值和0.15主导差异分类为`LEVERAGE_LIQUIDITY`、`DISCOUNT_RATE`、`MULTI_SOURCE`、`MIXED_BALANCED`或`UNRESOLVED`。2015年以来完整的点时盈利预期合同不存在，因此基本面持续恶化来源固定为`NO_VIEW_INCOMPLETE_CONTRACT`；不得用年份、新闻叙事或事后收益补标签。

### 压力传导强度

四个分量各自只相对于此前252个交易日计算因果分位，参考分布不含当前日：

1. 沪深300点时等权MA60广度水平和5日恶化；
2. 510050、510500、159915三只跨指数ETF的同步下跌扩散；
3. IF持仓量加权原始年化基差3日恶化；
4. H3下行压力。

四项等权形成`transmission_score`。IF没有完整点时股息与融资carry，只能称`RAW_ANNUALIZED_BASIS`，不能称公平基差。

早期等权广度从2014-07-01开始，五日广度变化还需要5个自身历史观察。固定保留2015年最初最多5个交易日为机制特征`NO_VIEW_WARMUP`前缀，不降低126个严格在前观察的因果分位门槛，也不以单一可用分量替代缺失分量。该前缀不得进入预测模型或事件通过门；第6个交易日起主要机制量必须完整。

### 卖盘吸收与压力耗竭

`exhaustion_score`由四项点时信息等权后，再乘最多过去10日的可用传导强度峰值；样本开端允许至少1个已有效观察，之后自然扩展到10日：

1. H3相对此前20日峰值的缓解；
2. 510300三日价格韧性的因果分位；
3. 广度5日稳定化的因果分位；
4. 单位传导强度对应的边际负价格冲击下降：先用严格在前252日的三日绝对收益中位数标准化当期三日负收益，再除以传导强度；吸收分量固定为`1 / (1 + 标准化边际负冲击)`，不再对这个二阶量重复计算另一层历史分位。

在每个压力事件内，过去10日传导峰值不低于0.80、耗竭分数不低于0.60且当日上升时，首次满足日才是点时耗竭候选。每个事件最多一个候选，失败后不得改阈值增加样本。

## 独立事件

### 旧压力区间事件

61个完整上游压力区间逐事件等权。每个事件只在首日进入问题A，最多只有第一个点时耗竭候选进入问题B；长区间不会获得更多权重。

### 独立价格损害事件

当510300总回报指数相对过去20日峰值首次跌至或低于-5%时触发。触发只使用当前和历史价格；相邻事件至少间隔20个交易日，并要求之后20日结果完整。它们只用于领先/同步/滞后判断，不用于选择特征或阈值。

每条通道从损害锚点前20日至后10日按时间顺序寻找第一次向上穿越0.80。穿越日在锚点前、当日、锚点后时，有符号时差分别为正、零、负，并固定解释为`LEADING`、`SYNCHRONOUS`、`LAGGING`。若窗口起点已在阈值之上且无法观察真正首次穿越，则记为左截尾并排除，不把它当成领先。

耗竭时序不再采用“先找耗竭候选、再向后找修复”的机械正时差。独立修复锚点定义为：从压力事件起点到结束后20日，修复条件首次由不满足转为同时满足“三日收益为正、广度五日变化为正、总回报指数高于MA20”。再将它与事件起点到结束后20日的第一个耗竭候选比较；候选早于、同日或晚于锚点分别记为领先、同步或滞后。该对齐只用于回顾性时序检验，修复锚点不进入问题B特征或候选触发。

事件形态另作回顾性描述：最大冲击距事件起点不超过5日且独立修复锚点在冲击后0至10日，标为`FAST_SHOCK_THEN_REPAIR_RETROSPECTIVE`；事件至少10日且后3日平均传导不低于前3日，标为`PERSISTENT_TRANSMISSION_RETROSPECTIVE`；其余为`MIXED_OR_UNRESOLVED_RETROSPECTIVE`。这些名称描述路径形态，不证明经济因果，也不进入任何模型或通过门。

## 两个预测问题

### A：未来10日重大左尾

每个完整压力事件首日一行。输入只有压力来源和传导强度；标签为T+1开盘后10日内最大不利幅度不低于5%。使用无惩罚逻辑回归、1000次事件自助法和留一时期交叉验证，不搜索超参数。

### B：未来20日持续修复

每个事件第一个点时耗竭候选最多一行。输入只有传导强度和耗竭分数；持续修复必须同时满足T+1开盘后20日终值收益至少3%、正财富路径天数比例至少60%、MAE不高于5%。同样不搜索超参数。

## 四道冻结门

### 1. 领先门

传导强度必须在独立价格损害事件前至少提前一个交易日达到其严重证据阈值；至少12个非左截尾有效事件、中位领先不少于1日、正领先比例不少于60%，单侧符号检验p值不高于0.10。点时耗竭候选相对独立修复锚点也必须满足同一方向，而不是使用候选后强制搜索得到的正时差。问题A的传导系数和问题B的耗竭系数都必须有正的90%自助置信区间下界，且至少三个可评价留一时期的AUC中位数不低于0.60。

### 2. 事件门

至少50个完整压力事件；每个问题每个事件最多一行且等权；删除任一单一事件后，问题A传导系数与问题B耗竭系数的方向都不得反转。

### 3. 机制门

逐事件检验三个固定方向：事件开始时传导强度高于前5日；事件后段耗竭分数高于前段；单位传导的边际价格冲击后段低于前段。全样本至少40个事件、方向比例至少60%、单侧符号检验p值不高于0.10；五个冻结时期中，传导方向至少四个时期复现，耗竭方向至少三个时期复现。

### 4. 外部复制门

分别检查跨指数ETF、同指数另一只ETF、沪深300点时成份广度和IF原始基差是否在价格损害前达到严重证据阈值。至少三条通道通过，且跨指数ETF与成份广度必须通过。IF语义限制必须保留。

任一门失败，不改变事件、阈值、标签、时期或变量。领先门失败时，状态固定为`EXPLANATORY_ONLY_SYNCHRONOUS_OR_LAGGING_NO_STRATEGY_PROMOTION_NO_RESCUE`；其他门失败为`DISCOVERY_COMPLETE_MECHANISM_GATES_FAILED_NO_STRATEGY_PROMOTION_NO_RESCUE`。
