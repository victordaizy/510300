# 第60轮：原学习退出加持仓累积转弱退出

本轮只登记一个新设置。原进入、原自然退出、原线性学习退出及再次进入条件均保留，增加“持仓内累积转弱达到固定标准后退出”。不训练新模型、不补EPS或其他来源。必要测试通过后才冻结和读取本轮账户收益。

## 进入与再次进入

先计算每天日内对数涨跌减隔夜对数涨跌，再将最近60个交易日的差值相加，除以这60日差值的样本标准差及60的平方根，得到日内相对隔夜强弱。隔夜比值为“开盘价加当日每份分红”除以前收盘价；日内比值为“收盘价加当日每份分红”除以“开盘价加当日每份分红”，分别取自然对数。

连续两个收盘的强弱因子严格大于1，原基础数据完整，账户空仓、具有再次进入资格，且距离上次实际卖出满足2个交易日等待期时，下一开盘按现金可负担的100份整数倍尝试买入。请求份额由前一收盘估计，实际成交仍受下一开盘价格、费用和限价约束，不把下一开盘事后价格用于前一日决定。

实际买入后消耗再次进入资格，持仓期间不追加份额。买入未成交保留资格。实际卖出后，必须在空仓时先观察到原进入条件消失，才恢复资格；随后还须重新满足原进入条件与等待期。

## 新增的累积转弱因子

|输入或状态|明确的计算方式|
|---|---|
|当天含分红收益|当天收盘价加当日每份现金分红，除以前收盘价，再取自然对数|
|本次入场前平均收益|实际买入前一个收盘及其之前，共60个交易日含分红日对数收益的平均值|
|本次入场前波动|相同60个交易日含分红日对数收益的样本标准差，不做年化|
|当天标准化转弱程度|固定的入场前平均收益减当天含分红日对数收益，再除以固定的入场前波动|
|累积转弱值|上次累积值加当天标准化转弱程度，再减0.5；结果低于0时归零|
|报警状态|累积转弱值达到5时触发，下一开盘请求全部退出；一旦触发，本周期不撤销|

每次实际买入时固定基准，持仓期间不更新均值和波动。买入当天记录累积值为0，不累积该日收盘对收盘收益，因为其中包括买入之前的隔夜变化；从买入后的下一个交易日收盘开始，每个完整持有的收盘区间更新一次。买入当天的亏损仍由原止损和原学习退出检查。

不足60个完整历史收益、标准差不大于万亿分之一，或基准不完整时，本周期累积检测没有观点。持仓期间任何一个日收益缺失，本周期停止新增检测，不跳过缺失后继续拼接；已经发出的退出请求保留。缺失的累积值保持缺失，不补零，不代替账户持有或退出决定。原自然退出和原学习退出继续按各自规则处理。

0.5是每天扣除的小幅偏离容忍，5是报警阈值。使用双精度运算，按保存的实际累积数值与5比较，不加临时容差或改变阈值。必要合成测试最初将理论值恰好5写为报警，实际浮点数为4.999999999999999；冻结前把该测试案例改为明确超过阈值的5.2。正式计算逻辑和阈值没有改变，测试修正发生在本轮收益读取之前。

方法来源：[美国国家标准与技术研究院累积和控制图](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc323.htm)。该说明给出单侧累积量以及容忍0.5、阈值4或5的常用设计思路。本轮只固定使用5，不测试4或其他邻近值。工业过程方法不能直接证明金融收益独立、正态或可预测；本轮效果须由完整账户检验。

旧“事件策略生命周期”研究以40个完成的前向事件建立基准，报警后禁止新进入，已有仓位按旧规则退出。本轮以单个当前持仓的逐日收益请求退出，两者的对象、时钟和动作不同。旧研究与其失败记录保留。

## 原学习退出使用的全部八个因子

|因子|具体定义|
|---|---|
|持仓时间对数|买入当天计第1个交易日，持仓交易日数加1后取自然对数|
|含分红浮盈浮亏|当前份额乘收盘价，加本周期已确认分红，再除以买入金额及买入佣金之和，减1|
|持仓回撤|上述含分红持仓价值除以本周期最高值，再减1；最高值初始为含佣金买入成本，并逐日更新|
|入场模式|固定为日内相对隔夜较强这一模式，数值1；它是常数，不提供区分信息|
|五日涨跌|含分红财富指数相对5个交易日前的比值取自然对数|
|二十日涨跌|含分红财富指数相对20个交易日前的比值取自然对数|
|一百二十日均线偏离|当前财富指数除以含当天的120日平均值，再减1|
|二十日波动|20日含分红简单收益的样本标准差乘242的平方根|

这里的财富指数按每日“收盘价加每份分红”除以前收盘价的比值连续相乘。实际账户分红仍分别处理股权登记、除息确认应收及到账。

采用第31轮原日内强弱岭回归已保存的月度模型，共114次成功拟合、27次无模型检查。不是第59轮新训练后失败的模型。原模型只使用当时已经自然结束的参考持仓周期，每周期总权重相同；最近20个周期、至少10周期100条状态，按月更新。八个输入减当次训练均值、除当次标准差，截断于负5至5，岭惩罚固定1。当前日期只可调用此前及当日收盘已经完成训练、标签已成熟的模型，不使用未来月份模型。

原标签比较“继续持有到自然退出”相对“下一开盘立即卖出”的净收益优势，包含两种卖出的佣金、滑点及按登记日取得的新增分红。标签沿用原提前开盘全部卖出的近似，没有单独模拟提前退出跌停延迟；正式账户仍保留成交约束。本轮不重算标签、不拟合模型、不用第59轮扩展路径修补。全部实际系数另保存为《原学习模型逐月中文规则》。

## 全部退出规则

持仓中出现以下任一条件，在下一开盘请求全部卖出：

1. 日内相对隔夜强弱连续两个收盘严格小于0。
2. 含分红持仓价值相对含买入佣金的成本亏损达到6%。
3. 含分红持仓价值从本周期最高值回撤达到8%。
4. 持仓达到第60个交易日收盘，买入当天计第1日。
5. 原学习模型连续两个持仓收盘预测继续持有优势严格为负。
6. 本轮新增的标准化累积转弱值达到5。

多个退出条件可以同时记载。缺少原学习模型或八因子时，收益预测保留缺失，连续负预测计数清零；新增累积检测只要自身基准及收益完整仍可独立工作。新增检测无观点也不会改变原规则。没有独立止盈线。

跌停、次日可卖或其他成交约束导致退出未成交时，继续在后续开盘请求退出，后来的正预测或累积值下降不撤销请求。日志必须把“累积转弱退出”与“连续两个负预测退出”分开，不能把新报警冒充旧模型预测。新账户只在原引擎增加携带真实原因的额外退出回调，原冻结引擎不改；关闭新增回调时，原账户的净值、成交、分红、周期和决定必须逐项一致。

## 账户、比较与停止条件

主评价2020年1月2日至2026年8月14日开盘，较早诊断2015年1月5日至2019年12月31日开盘。每段20万元，包含全部空仓日，现金收益及无风险收益按零，年化242日，终点按原开盘清算。基础费用每边佣金万分之2、最低5元、滑点万分之5；压力费用每边佣金万分之4、最低5元、滑点千分之1。使用100份整数单位、0.001元价格单位和原10%方向限价及次日可卖、分红记账规则。

只新增一个“原学习退出加累积转弱退出”设置，保留原学习退出、原自然退出、原急跌回升及学习退出各半、买入持有四个原样对照。每段两档费用共10条比较记录，其中2条新账户、8条复用对照。报告净夏普、复合年化、回撤、仓位、成交、费用及逐年表现；额外报告每次基准和首次报警是否真正改变退出。
