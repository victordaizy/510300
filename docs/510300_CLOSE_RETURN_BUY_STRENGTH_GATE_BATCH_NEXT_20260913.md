## 唯一新增因素和精确边界

收盘已知的当天含分红简单收益，等于当天原始收盘价加当天每份除息分红，除以前一交易日原始收盘价，再减一。原始价格和分红取reports/research/510300_adaptive_allocation_v1/features.parquet的close、previous_close和dividend，明确重算，不使用下一开盘或未来收益。

零门槛允许完整的持平或上涨日，不允许下跌日；1%门槛允许恰好上涨1%或更多的日期，严格不足1%暂缓新增。除息后经济收益恰好零要按零处理，不能将原始价格除息下跌误作弱势。必要资料缺失时新增买入不允许，但不禁止原规则要求的卖出。

按原始十进制价格计算边界，避免二进制舍入把恰好为零或1%的收益分到错误一边。该处理只解决数值表示，不增加容忍区间或调整策略阈值。

## 进入、调整、退出、再次进入

先按新账户自己的收盘净资产、实际份额、原正目标及零或二十个百分点调仓门槛，算出正常整百份申请。空仓正目标直接计算买入；持仓与正目标的比例偏差严格小于门槛则保持，否则调向目标中心。目标取整为零时按原规则卖出。

只有正常申请为正且当天收益达到本候选下限时，才提交原买入数量。正常正申请遇到当天收益不足或未知，则改为零，保留原正目标和已有份额。正常申请为零或负值完全沿用，不受新增买入条件限制。明确零目标、减仓、整手取整清仓和终点退出都照常执行。

原目标未知时保持实有份额，不能补成零；原目标已知但涨幅未知时，只禁止新增买入。每个收盘重新判断，当条件恢复且原目标仍为正时，可以再次尝试进入或加仓，没有额外等待天数、退出锁、挂单延续或亏损保护。

收盘十五时零五分决定，下一真实开盘执行原费用与成交规则。这是收盘信号准入，不是开盘价上限或保证更优成交。下一开盘价格不影响前一收盘决定，未成交后按下一收盘最新账户状态重新计算，固定终点开盘优先清仓。
