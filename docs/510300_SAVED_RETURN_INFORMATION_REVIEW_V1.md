# 已保存收益信息的配对检查

本次承接上一轮风险信息通过、完整账户未达标的结果。目标仍为完整账户成本后夏普1.2、年化10%；本次只检查已做过的收益信息证据，不恢复旧失败策略、不新拟合、不选最高夏普。

## 范围及事先写明的配对

对研究索引前期17个指定研究读取原始结果状态与保存记录的位置，区别有预测记录、有训练记录和是否有独立验证。指定原轮次为1至11、14、25、31、32、86、116。本表不是全项目所有策略清单，也不将旧预测当成新预测。

进一步对用户关注的逆回购总量与公募申赎做四项固定配对：

1. 各期限及买断式公开量的原主预测，对原仅价格预测。
2. 同一各期限及买断式公开量主预测，对原七天披露量预测。
3. 原常规逆回购全期限预测，对原七天披露量预测。
4. 原价格加季度申赎预测，对原仅价格预测。

逆回购的各组均沿用已经保存的岭回归与极端随机树平均预测，不挑选其中一类模型。申赎沿用原主模型与原匹配价格模型。不改任何学习规则、方向、期限、数据值或账户。

## 时间、标签及口径

使用原研究截至2026年8月14日保存的数据，不向后延长。逆回购预测目标是从判断日下一交易日开盘到其后第20个交易日开盘的含分红收益；原标签文件名为20日收益，实际索引为判断日加1至判断日加21。申赎目标对应60日，索引为判断日加1至判断日加61。只有在原截止日前已成熟、有候选及基准预测的同一行才配对。

申赎检查限原季度报告唯一训练起点对应的已保存标签。2019年12月31日的账户初始化事件不是新的季度报告起点，没有同一起点的原季度标签，本次单列为未配对，不为它新造标签。其余没有成熟标签或没有预测的行全部记录排除原因。

保存预测开始于2020年账户初始化附近，2015—2019年没有对应预测覆盖，明确列为无此段预测证据；不会重新训练填出这一段。整体2020年至截止日都报告，另分别检查2020—2022年和2023年至截止日。跨分段边界的持有期仅进入整体、不进入任一分段，因此分段样本之和可以小于整体。

先直接复核已保存标签与原开盘价格及分红规则一致；检查每个预测使用的最近训练记录不晚于预测时点、其末个训练标签已经成熟。此检查复核已有标签，不构成新训练或新预测。原文件对分红登记权利和除息的定义保留，不重新解释原回测。

## 增量和不确定性

主要比较平均平方预测误差。改善比例为一减候选误差除以基准误差，正数表示候选误差减少。整体和两分段全部报告，不以其中较好的部分替代整体。

逆回购每日预测的20日收益标签大量重叠，不能把所有行当作独立试验。因此先按预测起点所在自然月，对基准平方误差减候选平方误差取月度平均；申赎也按起点月聚合。对这些时间排序的月份进行连续区块重采样，逆回购每块6个观测月，申赎每块4个公告观测月，固定5000次、种子20260915，保存第5与95百分位。申赎的4个观测月是4次公告所在月份，通常跨度接近一年，不能叫作4个自然月。

本检查将“两分段误差都改善、整体月均误差改善的第5百分位大于零”称为历史配对增量较一致。还需两分段各至少8个公告观测月或12个逆回购观测月，整体至少24个观测月。没有通过则不能声称发现稳定增量；通过也不代表旧账户被救回、四场景达标或独立验证。

这四个配对是已见结果后的诊断选择，不是事前独立试验。重采样仅描述已保存误差序列的不确定性，未校正全部研究选择，也不证明真实实时可用。

## 需要保留的数据边界

原逆回购资料包括7、14、21、28、63天常规操作及另列的买断式计划、月度实际披露；公开披露量不是已经还原的每日实际净投放。原资料缺少全部实际操作日与到期证据，本次不补造净现金流。原季度申赎是基金报告披露的份额申赎，不能直接称为全市场公募净现金流。

本次只输出原研究证据位置、同日起点预测差、成熟样本与未配对原因、分时期误差及历史不确定性。新增策略数、拟合数和账户数均为零；不准备GPT审阅包，不更新实盘或每日固定策略。
