# 第152轮准备方向：修正同一持仓周期内重复误差的退出学习

151两种平均K线规则失败，随后48项事前状态归因也没有得到同时区间不跨零的稳定分类证据。因此不把151改成只在某个历史分组启用，不继续为旧四状态机制替换父来源。下一步回到已有退出学习样本的结构：同一自然持仓周期的多个状态共用最终退出结果，即使每周期总权重相同，邻近状态的预测误差仍可能连续相似。

第114轮用周期内变化学习、第128轮每笔进入固定模型版本，这些来源和结果保留。拟新增一种明确不同的误差协方差模型：仍用原八因素、原成熟周期和每周期总权重一，但在训练时考虑同一周期相邻误差的一阶相关。它不增加新的行情指标，也不以回测收益选择相关系数。对相关误差使用广义最小二乘的基本依据可见[statsmodels官方说明](https://www.statsmodels.org/stable/examples/notebooks/generated/gls.html)；本项目的周期等权、岭惩罚、分组截距和进入时固定版本另行定义，不以统计方法名称证明交易有效。

先作一次保存输入核对，不拟合新退出模型或建立新账户。复用114保存的141个月度记录、1461条原自然周期状态及既有模型参数；应保留原114个成熟月份和27个不足月份。只用每个月当时已经自然结束的最近20周期，至少10周期、100状态。原始标签、周期成员、可用时钟、标准化均值尺度、负五至五裁剪都按保存记录核对。原八因素为持仓日数加一的自然对数、实际含费用浮盈亏、周期回撤、进入类别、五日与二十日含分红涨跌、120日均线偏离、20日波动。

在每个成熟月份，以该月114保存的每周期截距和八系数计算原训练残差。只配对同一周期、原点索引相差一个交易日的残差，不跨周期或缺失日拼接。每周期内各有效相邻对等权、该周期对的总权重一。相关系数为全部加权“当前残差乘上一残差”之和，除以全部加权“上一残差平方”之和；分母没有正信息时记为无法识别，不补零模型。相关系数固定限制在负0.99至正0.99，以保证拟采用的平稳相关矩阵条件；原值及是否触及边界全部保存，这个界限不按后续收益调整。

准备核对只报告相关系数覆盖、范围、边界次数、相邻对数量和是否存在日历缺口。这不能证明相关误差是交易失败的原因。若输入可直接复用，才实施一项新设置；不补EPS或外部来源，不做多阶误差、相邻相关界限、样本窗口或确认日数的搜索。

拟定新拟合保留每个周期全部状态，包括首行。对标准化八因素、标签及对应周期截距列作同样的变换：首行保持；后续一行减去前一已保存状态乘“相关系数的两状态交易日距离次方”，再除以“一减该乘数平方”的平方根。这样等价于同一周期相关矩阵的逆平方根变换，并能明确处理真实索引间隔；不同周期不相连。基础状态权重仍为该周期状态数的倒数。

同时求八系数与每周期截距，使加权变换残差平方和加八系数平方和最小；截距不受惩罚，八系数惩罚为一。可通过消去周期截距后解八维正定线性系统完成，不需要反复训练大型模型。预测新周期时用成熟周期截距的等权平均，加当前标准化八因素与新系数的乘积之和。不估计当前实际周期的未来截距，也不读取尚未结束周期的真实残差来修正预测。

每笔实际进入的首个持仓收盘选择当时最近可用新模型并固定至本笔退出，保留128的版本时钟。没有成熟模型、该月相关无法识别或求解失败则该笔保留无学习状态；原自然退出仍可执行，不用旧114预测冒充新模型。模型身份必须使用新类型，不能把广义最小二乘结果标成原114固定截距岭模型。

进入仍为原六十日日内相对隔夜强弱分数连续两收盘大于一，空仓、输入完整、已经重新获得进入资格且满足退出后两交易日等待，下一真实开盘用可负担现金买入整百份。退出仍取任一：新固定模型连续两持仓收盘预测为负；原强弱连续两收盘低于零；含费用和已确认分红的本笔亏损达到6%；相对本笔高点回撤达到8%；含买入日持有满60个收盘。退出请求保持到实际卖完；之后先看到原进入条件消失，再等重现且满足等待，方可再进入。每笔不加仓、不部分卖出。
