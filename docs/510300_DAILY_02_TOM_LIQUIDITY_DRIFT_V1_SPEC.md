# 510300月末—月初流动性漂移 V1 冻结规范

状态：`DISCOVERY_ONLY / HISTORICAL_OUTCOME_NOT_YET_READ`  
候选：`DAILY_02_TOM_LIQUIDITY_DRIFT_V1`  
冻结日：2026-08-19

## 1. 研究问题

检验510300自身是否在“上月最后一个交易日开盘至下月第四个交易日开盘”存在足以覆盖小账户成本的正收益漂移，并判断50%常态仓位、98.5%事件仓位能否在扣费后提高相对静态60%仓位的夏普率。

这不是收益承诺。历史数据已经被其他510300研究使用，因此全部历史证据标记为`HISTORICALLY_CONTAMINATED`；协议冻结后才能计算本候选的历史收益。

## 2. 信息域

- 唯一风险资产与交易标的：`510300.SH`；
- 信号只使用交易日序号，不使用价格方向；
- 收益核算只使用510300未复权日线、现金分红和现金；
- 禁止分钟线、沪深300指数行情、成分股、权重、广度、IF、期权、估值、宏观和其他ETF；
- 禁止趋势、波动率、春节、星期、季末、止盈止损或其他结果后过滤器。

历史交易日序列由经过双源核验的510300日线日期提供。交易日历在实际执行前由上交所公布；历史回测以真实交易日期复现，不把价格信息用于判断日历位置。

## 3. 唯一事件定义

设`L_m`为月份`m`最后一个交易日，`F_(m+1,k)`为下月第`k`个交易日：

- `L_m`开盘进入事件状态；
- 持有`L_m`以及下月前三个交易日；
- `F_(m+1,4)`开盘退出事件状态；
- 事件区间为`[Open(L_m), Open(F_(m+1,4)))`；
- 每月恰好一个事件，不对季末和长假月区别处理。

前一交易日收盘记录下一开盘目标，因此不存在同一收盘价形成信号并成交。事件至少跨一个交易日，符合T+1；卖出数量不得超过当日开盘前旧库存。

## 4. 仓位与成本

- 初始资金：20,000元；
- 普通状态：50%；事件状态：98.5%；现金最低保留1.5%；
- 买入份额为100份整数倍；目标份额按执行开盘和方向性滑点向下取整；
- 普通调仓名义金额不足5,000元不成交；
- 佣金：每腿`max(成交额×0.0003, 5元)`；
- 基础/压力滑点：单边5bp/15bp；
- ETF卖出印花税率按冻结成本模型为0；
- 现金年收益1.5%，一年242个交易日；
- 仅权益登记日收盘已持有的份额确认分红应收，支付日前应收股利计入净值。

事件盈利因子使用9,700元独立增量袖带，逐月以相同起始资本计算一次完整开平仓净损益，避免50%长期底仓损益污染事件方向。

## 5. 对照与指标

对照固定为：

1. `STATIC_60`：首次建立60%仓位后不主动再平衡；
2. `BUY_HOLD_98.5`：首次建立98.5%仓位后不主动再平衡；
3. `RANDOM_4DAY`：在每个对应月份中随机抽取不与真实换月事件重叠的连续四个交易区间，重复5,000次。

主指标：

- 事件虚拟变量对开盘到下一开盘含分红超额收益的HAC系数；
- 9,700元增量袖带的基础/压力成本盈利因子；
- 完整策略扣现金基准的年化夏普；
- 相对`STATIC_60`的夏普改善和CAGR差；
- 六个月循环区块Bootstrap；
- 四个冻结子区间、随机窗口分位和年度贡献集中度。

盈利因子定义为正事件净超额损益之和除以负事件净超额损益绝对值。夏普率按完整日度资金曲线计算，不能只对事件日计算。

## 6. 一次性通过门槛

必须同时满足：

- HAC事件系数为正且单侧`p≤0.05`；
- 基础事件净超额收益均值Bootstrap 95%下界大于0；
- 基础/压力盈利因子分别不低于1.25/1.10；
- 基础策略夏普不低于0.80，且比`STATIC_60`至少高0.15；
- 基础和压力CAGR均高于各自`STATIC_60`；
- 四段至少三段事件净贡献为正；
- 真实窗口位于5,000次随机窗口前5%；
- 单一年份占全部正年度贡献不超过35%。

任一门失败即`REJECT_HISTORICAL_STOP_NO_RESCUE`。禁止改成最后两日、月初五日、季度加权、春节过滤、趋势过滤或其他窗口救援。
