# 第70轮：海外九天与30天预期波动关系

本轮只登记一个简单规则，直接检验完整账户。不补EPS，不训练模型，不另做GPT数值包。目标仍为扣除交易费用后的夏普1.2；一个历史点估计达标不等于未来已经有保证。原有研究失败记录保留。

## 全部因子及其含义

| 项目 | 中文定义和用途 |
| --- | --- |
| 九天预期波动 | Cboe九天波动指数的收盘值，反映美国股票期权价格对应的短期预期波动，采用文件中的已公布数值。 |
| 30天预期波动 | Cboe波动指数的同一美国日期收盘值，反映约一个月的预期波动。两个都是年化指数水平，不能当作510300的预测收益率。 |
| 期限比值 | 九天预期波动除以同日30天预期波动，用于展示；交易判断直接比较两项水平，避免不必要的舍入。 |
| 资料年龄 | 中国执行日北京时间上午九点，减去该对数据假定可用时刻，按秒换算自然日；不超过七天才可使用。 |
| 完整性 | 同一源日期的两项必须同时存在。先保留两个来源全部日期，再找当时最新行；最新行缺一项时不能跳回旧的完整一对。 |

经济假设是短期预期波动超过月度水平时，海外紧迫风险较高，暂时退出；反之持有。这只是待检验的风险状态假设，没有预先断言它能预测中国股票收益。两项指标基于美国标普500期权，不能视为中国指数的直接估值，也不是波动率期货价差交易。

## 完整进出场规则

1. 每个中国执行日北京时间上午九点，只使用届时已完成的最新美国源日期。美国东部源日期下午五点视为该日收盘完成，使用时区库处理夏令时，转换为北京时间。通常对应次日凌晨五点或六点。下午五点是历史市场完成时刻假设，取得CSV不能证明历史上每一天文件实际何时送达。
2. 最新一对数据完整且年龄合格时，九天预期波动严格低于30天预期波动，目标为全部可用股票预算。若此前为空仓，进入；若此前已有持仓，继续持有。初始遇到这一状态也直接进入。
3. 九天预期波动达到或超过30天预期波动，目标为零。若有持仓，发出退出请求；若已为空仓，保持现金。相等明确归入退出，不额外设灰区。
4. 退出后，今后某个有效早晨再次满足九天低于30天，即可重新进入。不设等待期、连续确认天数、止盈止损价、最长持有期或额外价格条件。
5. 最新行缺一项、超过七天或尚无历史来源时，资料不足，当天不产生新买卖请求，保留实际份额。次日重新判断；不会把缺失填成零、补成旧数，也不保留一笔待执行的退出指令。已有持仓在缺失日可能继续承受风险。
6. 上午九点先用前一中国收盘价格和该时点已形成的账户资产确定请求份额，按一百份向下取整。目标持有且实际股票权重距离目标小于十个百分点时保留原份额；目标退出则申请卖出全部可卖份额。目标为全仓也可能留下零碎现金。
7. 本次实际开盘价格不参与信号或请求预算，在九点半开盘撮合时才用于滑点、手续费、现金约束和实际成交。遵守一百份整数单位、千分之一价格单位、日内新买不可卖及方向涨跌停限制。遇到不能成交，保存真实未成交结果，下个早晨依据新状态决定，不假定成交。
8. 账本沿用前一中国收盘日作为预算原点，同时另存真实九点决定时刻、海外源日期、假定可用时刻和执行日。不能把隔夜美国信息说成在前一中国收盘已经知道。
9. 主评价在2026年8月14日开盘结算；较早诊断在2019年12月31日开盘结算。末端开盘清算覆盖常规信号，不借用终点收盘。各自终点之后没有新决定，不借后一历史段的日期生成末行因子。

## 固定评价与停止条件

只交易510300及人民币现金。主评价2020年1月2日至2026年8月14日开盘；较早诊断2015年1月5日至2019年12月31日开盘。每段初始二十万元，每年二百四十二个交易日，现金和无风险年利率都保持原来的零假设。基础佣金万分之二、单笔最低五元、单边滑点万分之五；压力佣金万分之四、单笔最低五元、单边滑点千分之一。费用、时钟、分红权益及现金支付、整手、成交约束和评价窗口均不为新规则改变。

本轮四个新完整账户，复用十六个既有对照账户；零新模型、零新参考周期。检查净夏普、年化、回撤、持有期、成交、分红、费用及逐年贡献。达不到目标即记录失败，不改变方向、阈值、平滑天数、时期或退出方式救回同一规则。历史已被多轮研究看过，即使达到1.2，也只是已有历史上的候选，需要另有未使用数据验证。

两个官方文件已于2026年9月8日取得并保存，不重新下载。原始文件尾部到9月4日，构造数据仅允许到固定历史终点8月14日。文件外连接后的共同支持从2011年1月4日开始。首次历史实际送达证据尚未建立，结论仅属于按约定时钟的历史可行性研究。
