## 3. FVG/三柱价格不平衡目标

FVG统一使用中性名称“三柱价格不平衡”，只描述：

- 看涨事件：`low_t > high_t-2`；
- 看跌事件：`high_t < low_t-2`。

信号在第`t`根15分钟柱结束时形成，以下一根柱开盘为观察起点，研究1、4、8根柱后的收益、命中率、MAE、MFE和回补时间。日内目标必须在同一交易日内结束，不跨午间边界时仍按真实交易时钟解释。

该目标首先是事件研究，不直接视为可交易策略。510300新买份额受T+1限制，若统计优势只能在当日存活，必须另行证明已有底仓调整或多日持仓入场的可执行性。

## 5. 标签重叠处理

5日和20日目标高度重叠。每项研究必须同时报告：

- 每日滚动重叠样本；
- 按目标周期错位抽样的非重叠样本；
- HAC/Newey-West标准误；
- 移动区块Bootstrap区间；
- 近似独立样本量。

任何只在重叠样本中成立、在非重叠样本中消失的结果均不得评为强证据。
