# V2 四态账本执行 V1.0.1：新日线证券选择器修正

## 失败保留

V1 执行在发出任何网络请求之前停止：配置预期 493 个证券，但代码按“2019-12-01 以后出现过的全部点时成员”选出 505 个证券。没有写入断点，没有读取绩效。

## 根因

V1 把“新日线查询的重叠起点”误当成了“必须由新来源补齐的覆盖边界”。多出的 12 个证券只在 2019-12-02 至 2019-12-13 属于指数，并已被截止 2020-02-28 的旧未复权日线种子完整覆盖。为它们再次发出全历史查询没有数据必要。

## 唯一修正

```text
旧选择器：membership_date >= 2019-12-01
新选择器：membership_date > 2020-02-28
```

新接口仍从 2019-12-01 开始查询，以保留约三个月的新旧来源重叠对账；证券身份只从不可被旧种子覆盖的点时成员并集产生。正确数量为 493。

输出写入新的 V1.0.1 命名空间，不覆盖 V1。端点、字段、线程、请求间隔、公司行动规则、四态、覆盖门、缺失不补零、绩效关闭与交易关闭均不变。
