# 第六轮：事先可知的日历资金节奏

目标仍为只交易 510300 和人民币现金、完整账户成本后夏普率至少一点二。此前五轮的价格切换、回归分类、海外价格、央行操作量及直接学习风险收益方案均未达到目标。本轮增加事先可知的日期条件，检验月初、月末、季度和休市后是否存在可以执行的收益差异。

旧研究“沪深个股同月收益季节性”使用第二至第五年前相同月份的个股收益排序，已有终结失败记录；本轮不使用那个历史收益信号，不恢复其参数或结论。本轮只研究 510300 的月内日期条件及其与已有价格信息的交互。

## 为什么提出这一轮

跨月收益差异在既有研究中被检验过，例如 [McConnell 与 Xu 的原始论文](https://business.purdue.edu/faculty/mcconnell/publications/Equity-Returns-at-the-Turn-of-the-Month.pdf)。按期支付和资产配置资金流是文献提出过的一种解释，可参见 [Ogden 的原始研究](https://doi.org/10.1111/j.1540-6261.1990.tb02435.x)。这些文献的样本、交易时刻与本研究不同；跨月差异的存在也不等于资金流因果解释已经确立，前一篇论文没有用成交量或股票基金净流量解释掉该现象。

因此本轮把“资金节奏”作为待检验机制，不预先宣布中国市场一定存在该收益，不照搬其他市场的夏普，也不以文献代替完整账户。

## 全部十八个日历因子

每个信号在计划成交日北京时间上午九点形成，使用该天已知的公历日期和此前已经发生的开市日。没有使用当日开盘价、成交量或收盘价来决定这些日期条件。

|因子|数量|完整中文规则|
|---|---:|---|
|星期标记|五个|分别标记计划成交日是否为星期一、二、三、四、五，满足为一，否则为零。|
|月内周期|两个|当天日期号减一，除以本月自然日总数，再乘以一个完整圆周的弧度；分别取这个角度的正弦、余弦。闰年和月长由公历确定。|
|年度月份周期|两个|当天月份减一，除以十二，再乘以一个完整圆周的弧度；分别取正弦、余弦。|
|月内开市序号|一个|从本月第一次开市累计到计划成交当天，所得序号除以二十二，上限为一。只累计已经到来的开市日。|
|本月剩余自然日|一个|本月自然日总数减当天日期号，再除以三十一。该因子不计算未来实际开市日。|
|月初三日|一个|计划成交日属于本月前三个开市日时为一，否则为零。|
|月末五个自然日|一个|本月剩余自然日少于五天时为一，否则为零。包含该月最后一个自然日，但只有实际开市日才有成交。|
|季度初三日|一个|月份为一、四、七、十月，并且属于本月前三个开市日时为一。|
|季度末五个自然日|一个|月份为三、六、九、十二月，并且属于该月最后五个自然日时为一。|
|距上次开市的时间|一个|计划成交日减上一个已经发生的开市日，得到自然日间隔，加一后取自然对数。普通周末的间隔一般为三天。|
|长休市后第三日以内|一个|若本次开市与上次开市相隔至少四个自然日，定义本次为长休市后的第一天；该天及随后的两个开市日取一，其余为零。若又发生新的长休市则重新计数。|
|月内两端|一个|满足月初三日或者月末五个自然日中的任一项时为一，否则为零。|

日历使用项目已经核对的沪深共同开市日期表。表中包含整段历史，但每个因子的算法只读取当天和之前的日期。文件起点的第一行没有此前开市日，为计算边界将间隔记为一天；研究从多年后的二〇二〇年开始，这项起点约定不会影响评价期。不把历史日期表的取得时间解释为历史时点接口实时可用的证明。

## 五个确定规则

1. **主方案：每月前三个交易日。** 在当月第一个交易日开盘买入，前三个交易日目标为满仓，第四个交易日开盘退出，其余时间目标为现金。月底是否将跨越长假不参与判断。不能把买入前、从上月最后收盘到本月第一开盘的涨幅记入本策略。
2. **月内两端。** 当天处于本月最后五个自然日，或当月前三个交易日时，目标为满仓；其余目标为现金。这里固定的是自然日边界，不把它偷偷替换成最后五个实际交易日。
3. **季度初三日。** 只在一、四、七、十月的前三个交易日目标满仓；其余目标为现金。
4. **长休市后三日。** 从与前次开市相隔至少四个自然日的重新开市当天起，连续三个开市日目标满仓；其余目标为现金。买入发生在重新开市的开盘，不能获得此前休市期间已经反映在开盘价里的跳涨。
5. **四类条件等权。** 将以上四个规则当天目标仓位取平均，得到零、四分之一、二分之一、四分之三或满仓，不按过去或本次表现改变权重。

五个规则每天判断条件。目标为现金是规则明确给出的结果，与资料不足造成的“无有效判断”不同。后者保持已有份额并留空目标，不伪造清仓信号。

## 六个预测模型和三个共识

预测模型用于区分日历信息本身、价格信息本身和两者的结合。三个输入组分别为上述十八个日历因子、既有三十四个价格因子、合并后的五十二个因子。每组固定两种算法，得到六个模型；每组再将两个模型的预测收益取算术平均，得到三个共识。加上五个确定规则，总计十四个登记候选。

第一种算法为岭回归。每次训练先用当时训练样本的均值、标准差标准化各因子，正则化强度固定为一百。第二种算法为极随机树：九十六棵树，最大深度三，每个叶子至少四十个样本，分裂时考察四分之三的因子，不做自助抽样，单线程执行；随机种子由既定基准种子和拟合日期确定。不尝试更多窗口、深度、正则化强度或种子。

首次拟合在二〇一九年最后一个交易日，之后每季度第一个交易日收盘重训，逐步扩展此前全部有效训练样本。三个输入组采用相同训练日期。每次至少三百个成熟样本。预测对象为下一开盘买入、再下一个交易日开盘退出的一日总收益，按该段实际取得分红权益计算。只有退出日不晚于拟合日的训练样本可以进入；未发生的收益不能用于标准化、训练或选择模型。

这些模型每天上午九点作下一开盘计划。动作从保持已有份额以及零、四分之一、二分之一、四分之三、满仓中选择。比较预测收益，减去固定风险系数四对应的方差惩罚，再减去本次调整的估计费用；净效用最高的动作入选，同分优先不交易。方差统一使用此前六十个交易日的日收益样本方差。“只用日历”指预测收益模型的输入，风险与执行模块仍统一使用已知价格、库存、资金和该波动估计。

## 账户、费用和时钟

与前五轮同口径：起始资金二十万元，区间为二〇二〇年一月二日至二〇二六年八月十四日开盘，共一千六百零四个完整交易日，现金参考利率为零。只做 510300 多头，不借款，不卖空。

上午九点使用已知日期条件、上一收盘价、现金、库存和应收权益计算数量，九点半在实际开盘尝试成交。普通交易按一百份整手；执行价包含滑点并按千分之一元价格单位取整，遇到资金不足、尚不能卖出的当天买入份额或方向涨跌停，按共同账户规则部分成交或不成交。每天只有开盘这一次调整。

确定规则按目标仓位算份额；已有持仓距离非零目标不足十个百分点时维持现有份额，归零和从零进入不受该限制。预测模型按上述费用后净效用比较动作。

基础费用为单边万分之二佣金、最低五元、万分之五滑点；压力费用为单边万分之四佣金、最低五元、千分之一滑点。分红根据登记日库存取得权益，除息日确认为应收，真实到账日转成现金。所有现金等待日和无有效判断日都进入账户净值。终点开盘退出并支付费用；如不能退出则如实标记。

## 冻结的验收与诊断

每个候选在两种费用下都计算完整账户，再加两种费用的买入持有基准，共三十条评价账户。最终夏普使用完整交易日净收益平均值除以样本标准差，再乘以二百四十二的平方根。另报告累计收益、复合年化、年化波动、最大回撤、成交数量与费用，以及逐年和二〇二〇至二〇二一、二〇二二至二〇二三、二〇二四至终点三个分期。

主方案两种费用的夏普都至少一点二，才记为“两种费用历史点估计达标”。披露所有候选中的事后最好者以及其他候选是否达到同一门槛，但不以事后最好者替换主方案。

采用二十个连续交易日的区块重抽样，两千次，报告主方案夏普区间、主方案相对买入持有的年化日均超额区间，以及“日历加价格共识”相对“价格共识”的增量区间。区间没有校正历次全部重复研究。历史已经被多次观察，不能把本轮换名字后称作独立未见样本。

额外固定计算两条零费用诊断：月初三日主方案，以及日历加价格共识。它们只用于费用归因，不作为目标验收成绩。

真实收益运行前冻结代码、资料、规则、模型及费用。失败后保留全部结果，不把三天改成两天或五天，不倒转方向，不增补特殊年份、择时条件或更多日期窗口。未来的新研究必须有实质区别。只做必要的时间、账户和文件结构核对，不额外进行安全审计。

本轮为历史研究和模拟，不授权券商连接、实际持仓或真实订单。
