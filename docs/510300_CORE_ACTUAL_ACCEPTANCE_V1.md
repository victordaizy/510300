# 原A进入后的接受、保护与新增信息延续：唯一开发实验

TECH.R235登记、R236结果。2026-10-06建立，收益计算前固定；全部历史截至2026-09-30均为已看开发资料，独立验证未建立。R234的后验组盈亏不能作为本策略预期概率。

研究问题：保留原A全部来源权重和进入请求，通过实际买入后才形成的价格接受、完整新周、参与及真正新增宏观信息改变持有，能否提高20万元完整净收益与夏普。它不同于R232的新政策入场，不修改任何旧冻结策略。

## 全部动作及未知规则

1. CORE完全沿用保存的CORE_AUXILIARY_DRAWDOWN_GATE源权重，最大50%、原10个百分点调仓带及原风险预算，原零退出、未知保持。没有新入场过滤、重新训练或新技术窗口。
2. 实际进入日的现金平移高低只能在该日收盘建立。严格后来的收盘超过其高点且日MACD柱为正，一次进入ACCEPTED，启用进入日低点保护。接受前破低不额外退出，不能根据后来不修复的后验身份判断当前。
3. 严格过去的上一完整自然周，所有原观察日均不早于实际进入日、周低高于进入日低、周收盘高于进入日高，并且当前仍满足价格接受，才可能晋CARRY。主政策另需原已知行业视图、过去五日上涨成交量余额大于0、原行业五日上涨比例严格过半、原领先行业五日均收益为正。余额是ETF价量代理，非真实净流入；行业是原逐点集合，不认证固定成员扩散。未知不能晋级，保持原动作。
4. CARRY保护位为进入日低与后来每个已知完整买后周低的累计最大值，只升不降。价格触及或跌破已启用保护位，次可成交开盘退出。CORE/ACCEPTED仍沿原权重动作；CARRY在原权重为正时也保持原权重，原权重为零或未知时允许保持、只作风险减仓，不补买。
5. 主政策只有买入开盘之后真正新公布且当前已知的PMI新订单环比为负，或同样在买后公布并首次原ETF观察的保存操作利率上调，才永久撤销本持仓的延续资格。退回ACCEPTED及原权重动作，已经抬高的保护位不降低；不必直接退出原正目标。旧负背景、空政策记录、每日融资统计新行不触发。撤销后本真实周期不再晋级，下一真实周期才重新判断。
6. 额外结构保护的真实清仓消费首次强制退出决定对应的原正目标段。该原段内不得立即重复旧正目标；原明确零之后的新正目标产生新身份，未知不重启。受阻退出保持原强制理由与消费身份；账户回撤停买具有最高优先级。延长持有会改变后续进入和资金占用，不能宣称所有交易逐笔配对。
