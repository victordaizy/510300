# 美国多资产容量感知绝对动量V3冻结规范

## 不变部分

固定UPRO、TQQQ、TLT、UGL，继续使用2014年1月2日至2019年12月31日可见期和物理隔离的2020年后封存期。252日总收益动量、200日趋势门、60日波动排序、月频前两名、每资产50%权重上限、整数股、公司行动、17/47bp证券成本、10/30bp汇兑点差、官方严格滞后汇率、H00300基准、50万元本金、用户费万分之一、40个百分点净超额和1.50净夏普硬门全部不变。

## 容量感知目标

每只入选资产的目标名义金额为两者较小值：一是基础/压力账本中较小的上一收盘人民币净值，经当日严格滞后汇率折成美元后乘50%，再预留压力成本；二是该资产上一信号日20个观测日中位美元成交额乘0.05%。按执行日原始开盘价向下取整为整数股，未使用资金持美元现金。由此产生的任何买单不得超过冻结容量线。

## 分日退出与减仓

失去入选资格的持仓成为强制待退出状态，即使之后再次入选也不得取消。若全部卖出会超过单日容量，则在每个后续有效开盘按容量向下取整到整数股逐日卖出；减仓超出容量时采用同样切片并连续执行。强制退出的最后零股可低于1000美元最低普通交易额，但仍不得超过容量。评价期末若无法在当日容量内完成全部剩余清仓，候选失败。

该版本不放宽0.05%容量线，也不把容量受限订单记为通过。可见期只运行一次；失败后不得改变容量、权重、产品或信号救回。封存期、Paper、Shadow、订单、经纪商连接和实盘全部关闭。
