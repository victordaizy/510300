# 实际训练结果导航

本轮根据“不用那么严格，直接进入训练”的最新授权，已完成56个事件月标签、204次逐期拟合、5个期末模型及14条完整账户情景（含现金、买入持有基准）。取消原36训练月/24评价月数量门，不回写旧研究。

**主要结果：调查票数模型相对实际LPR基准的MSE改善5.84%，但比历史均值预测差7.66%；降息幅度模型未改善。5种模型都没有达到预先固定的误差加费用入场阈值，完整账户保持20万元，夏普未定义。目标尚未达到。**

建议阅读顺序：

1. `训练结果.md`：方法、结果及结论。
2. `用户要求.md` 与 `protocol.json`：当前指令、实际训练设定、费用和账户规则。
3. `results/预测指标.csv`、`results/同月增量比较.csv`、`results/入场门槛诊断.json`：预测质量与未入场原因。
4. `results/逐期预测.csv`、`models/逐期模型.json`、`models/期末已训练模型.json`：204个逐期预测和参数。
5. `results/完整逐日账户.csv`、`results/逐事件交易判断.csv`、`results/机会成交账簿.csv`、`results/账户指标.csv`：1068个交易日，2022-04-21至2026-09-11，空仓日全部保留。只有买入持有基准发生交易。
6. `inputs/ledger.json` 与 `inputs/market.parquet`：训练的直接输入；`inputs/source_extension_v2.zip`为核对过SHA-256的原调查来源包，包含84个月母集及56个月调查事实。
7. `01_GPT_REVIEW_PROMPT.md`：可复制的审阅要求。

数据范围为2020-05至2026-07的56个已保存调查月，其中49月幅度上下界完整；28个月资料缺失。行情截止2026-09-11，不是2026-09-22实时信号。历史来源及行情曾经被研究，逐期预测不等同全新盲样本。

保存结果复算入口为 `python code/lpr_expectation_exploratory_training_v1.py verify --root .`。在Windows PowerShell的解压目录中运行即可；库版本记录于`runtime.json`和`requirements.txt`。这个命令只读取保存的输入、模型和账户，不重新拟合或下载。

`FILE_INDEX.csv`覆盖包内所有其他文件。结构校验与保存输出复算不表示外部GPT已审阅，也不建立独立科学有效性。账户模拟没有券商或订单操作。
