# 消费、制造与医药：因子变化的原因及未来兑现条件

记录于2026年9月29日。本轮补齐既定十大权重中的贵州茅台、美的集团、药明康德，三者2026年8月末权重合计6.17%；十大权重合计23.18%。美的属于指数可选消费组，经营中的制造业务不能另计为指数工业权重。研究对象仍只有510300与人民币现金，个股仅用于解释传导。

**当前工作判断：盈利分化仍比全面修复更符合已取得的经营证据。** 茅台、美的的毛利率承压，药明的持续经营收入和毛利率明显改善。三者的预收款、扣非利润、现金流、订单都不能用同一规则解释。这里主要核对2026年上半年及4至8月已公开材料，建立未来比较基准；没有把旧材料当作9月新发生的市场冲击，也没有据此宣称已预测指数涨跌。

**茅台：销售体系改变，使预收款和经营现金流的含义同时变化。**

半年报合同负债从2025年末80.07亿元降至2026年6月末31.78亿元，下降60.31%。公司解释涉及市场化改革、销售模式及预收政策调整。8月21日业绩说明会进一步说明，代售模式下货权不转移，同时根据终端动销调整产品价格、结构和投放；公司称销量增长、综合吨酒单价下降。因此，预收款减少兼有渠道制度变化和需求适配背景，不能单独判为终端需求同比减少60%。公司关于渠道库存健康的说法仍是管理层表述，本轮没有独立渠道库存量。来源：[半年报第7—9页](https://static.cninfo.com.cn/finalpage/2026-08-15/1225475868.PDF)、[8月21日说明会](https://wwwhy.moutai.com.cn/mtjt/2026-08/21/article_2026082123484650788.html)。

经营现金流净额同比增长438.84%，增量575.72亿元。合并现金流表第33—34页可以拆出：

| 现金流项目 | 对同比增量的算术影响，亿元 |
| --- | ---: |
| 存放央行及同业款项的净流出变化 | +473.06 |
| 客户存款和同业存放款项的净流入变化 | +99.00 |
| 销售商品、提供劳务收到的现金变化 | +33.35 |
| 其余经营现金流项目合计 | −29.69 |
| 经营现金流净额变化 | +575.72 |

前两项合计占净增量约99.36%；这是现金流恒等式的分解，不是需求的因果贡献。销售收现同比仅增长3.51%。不能从合并现金流大增推导消费强劲复苏，也不能把剔除这两项后的余额称为独立白酒业务净现金流。公司库存含在产品、自制半成品等，不等同于经销商库存。

**向前看**，真正的约束是终端支付意愿、产品结构和渠道可持续利润。若销售量改善仍依赖降低综合售价，收入增长未必带来利润改善；若在投放恢复时，终端成交和渠道利润同步稳定，需求修复的解释才会增强。现金流中的同业存款若再配置，合并经营现金流也可能回落，不必然代表卖酒变差。今后优先比较同口径终端销售、净实现价格和销售收现，降低预收款与合并现金流单项信号的权重。

**美的：扣非下降有分类影响，但经营压力也不能一并抹去。**

H1归母净利润增长1.66%，扣非归母下降25.31%。公司在第7页解释，人民币走强形成的外币货币性项目损失进入经常性损益，相关风险管理衍生工具收益进入非经常性损益。直接把扣非下降等同于家电需求崩塌，会漏掉经济上的对冲关系。来源：[美的半年报](https://disc.static.szse.cn/disc/disk03/finalpage/2026-08-29/df25443f-d67a-4cc5-8bd6-6c3e681a9575.PDF)。

第173—174页同时表明，不能把所有非经常性收益都当成外汇对冲：

| 税前损益项目，亿元 | 2026H1 | 2025H1 |
| --- | ---: | ---: |
| 汇兑损益 | −59.76 | +27.63 |
| 衍生工具公允价值变动 | +23.12 | −4.54 |
| 处置衍生金融资产及负债的投资收益 | +14.21 | −3.50 |
| 上述三项合计 | −22.43 | +19.59 |
| 另列：权益工具投资公允价值变动 | +26.78 | −8.92 |

三项合计同比少42.02亿元，权益工具公允价值收益同比多35.70亿元。三项合计只是相关项目的观察窗口，尚未按币种、期限、风险类型逐笔匹配，不称为准确的外汇对冲净损益；权益工具估值也不等于主营产品竞争力。若投资收益来自市场价格变化，不能再把它当成独立预测市场上涨的第二条根证据。

真实经营方面，第52页显示智能家居收入增长4.27%、毛利率下降0.57个百分点；商业及工业解决方案收入增长3.30%、毛利率下降0.41个百分点。内部又有楼宇科技改善、工业技术收入与毛利率下降的分化。原材料总耗用增加同时受数量和产品组合影响，本轮不把它直接解释为原材料单价上涨。

经营现金流增长0.73%。第177页的调节表显示，经营性应收增加形成的现金占用为240.89亿元，上年同期为169.27亿元；经营性应付增加的现金支撑为254.84亿元，上年同期为115.75亿元；库存释放现金则从136.81亿元降至90.63亿元。这说明现金流稳定有多项抵消，不能仅看净额就说回款效率改善，也不能未经付款条款资料就断言拖欠供应商。

**向前看**，汇率转向可能使货币项目与衍生工具损益反向变化，扣非改善未必等于主营改善。优先观察同类产品净售价、毛利、订单兑现和应收回收是否同步；确认真实海外业务变化时，还要区分汇率折算与数量增长。对原材料和汇率因素，先追净敞口及调价能力，再判断利润方向。

**药明：项目进入后期、已有产能释放，提供了更具体的增长原因。**

H1持续经营收入增长48.00%，化学业务增长53.28%。公司将改善联系到临床后期及商业化项目推进、去年新产能陆续释放、生产工艺与产能效率提升。持续经营毛利率从46.11%升至53.91%，提高7.80个百分点；包含已终止业务的总口径提高9.46个百分点，多出的1.66个百分点体现比较基数的业务范围差异。来源：[半年报第11—13页](https://static.cninfo.com.cn/finalpage/2026-08-04/1225455027.PDF)。

这里更有用的因子是项目阶段、交付进度、产能效率和单位利润。生物医药融资会影响客户研发预算，但不能只用融资环境解释已经进入后期和商业化的订单。新增项目、现有项目放量和生产效率也不能重复当作互不相关的三张支持票。

公司在4月材料中维持的全年收入指引为513—530亿元，8月3日提高至585—605亿元，中点提高14.09%；资本开支从65—75亿元提高至75—85亿元，经调整自由现金流从105—115亿元提高至135—145亿元。[4月原件第17页](https://officialsite-static.wuxiapptec.com/upload/2026_FIRST_QUARTERLY_RESULTS_PRESENTATION_a5a7717323.pdf)、[8月公司发布](https://www.wuxiapptec.cn/en/news/wuxi-news/wuxi-apptec-delivers-strong-h1-2026-results-and-raises-full-year-guidance-driven-by-greater-success-of-multiple-customers-products-and-crdmo-model)。

扣除H1实际收入288.97亿元，最新指引已经要求H2收入约296.03—316.03亿元，较H1增加2.44%—9.36%。这是指引的条件算式，不能当研究者的新预测，也不是市场一致预期。H2经调整自由现金流同理需64.79—74.79亿元。季节性没有被调整，不能仅凭上下半年比值认定加速或减速。

第139页列示剩余履约义务664.35亿元，未给逐年兑现安排，不能全部算成H2收入或现金。法定经营现金流增长30.52%，经调整口径增长41.3%，二者分开使用；应收与库存仍占用现金，订单多不免除回款问题。

**向前看**，决定下一轮修正的是交付与单位利润能否超过8月已经上调的基准，以及新增产能是否按时形成有效供给。客户采购约束也是另一条传导链：[6月政府列名通知](https://www.govinfo.gov/content/pkg/FR-2026-06-10/pdf/2026-11571.pdf)与[公司网页中的8月7日初步禁令更新](https://wuxiapptec.com/news/wuxi-news/an-open-letter-to-customers)需区分。后者是公司披露，本轮未取得法院裁定原件；不能把初步禁令当诉讼终结，也不能把经营增长当全部政策风险消失。这些是既知背景，未被当作9月新增冲击。

**把原因落实为阶段中有用的观察项。**

| 主导变化 | 下一阶段优先观察 | 何种事实会改变判断 |
| --- | --- | --- |
| 销售模式与投放主动调整 | 同口径终端动销、净售价、渠道利润、销售收现 | 放量伴随价格和回款改善，才增强真实需求修复的解释；预收政策再变时重新解释预收款 |
| 汇率、衍生工具与估值损益交错 | 净币种敞口、对冲期限、主营毛利与回款 | 主营盈利改善仍需毛利和现金支持；仅扣非反弹不够 |
| 后期项目与产能释放 | 已上调指引之上的交付、单位利润、回款和新增订单 | 项目延迟、客户采购变化或现金持续跟不上交付，会削弱增长兑现判断 |

经营兑现主要在Q3与H2；未来1至4周可交易的变化来自新信息对这些路径的修正，而不能提前把未公布的季报当事实。公司指引只是预期比较基准之一，是否已被价格充分吸收还需当时价格和同口径市场预期。

**对510300的用途及本轮边界。**

这三家补充了6.17%的旧时点权重经营分析，不能代表全部消费、制造或医药。十大权重经营线索已覆盖23.18%，剩余76.82%没有因此完成公司盈利覆盖。前轮的行业价格量级分析与本轮的经营原因分析也不是同一种覆盖。

本轮结果支持保留“需求和盈利分化”的工作假设：不能用局部订单增长或现金流大增就推导宽基普涨。若后续需求改善同时传到净售价、单位利润和可支配现金，且超过既有预期并扩散到足够权重，指数盈利修复的依据才增强；若科技外需、成本和风险补偿的压力仍占主导，这三家经营改善也可能被抵消。这里没有给无依据的涨跌概率或将利润增幅直接映射为股价增幅。

收住既定公司范围，下一阶段集中比较几个共享驱动：终端需求与定价能力、汇率及风险补偿、订单交付与现金兑现。原F1/F2/F3、FIN1、BATT1不改；新增账户0、策略收益测试0、预测卡0。**夏普1.2尚未实现，目标继续active。** 本轮完成的是因子变化原因与既有兑现基准，下一步需要把新信息变成当前价格下的指数收益赔率。
