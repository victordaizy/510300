**把旧仓库一起纳入后，我会修正上一轮建议：趋势与反转切换、连续状态评分、动态风险预算，我们都已经做过。下一步应当从旧研究中提取仍值得验证的信息，和最新形态研究做增量比较，避免换个名称再走一遍。**

我的优先选择是：

> **用价格形态发现机会，用指数内部结构判断上涨或下跌的参与情况，用日内／隔夜结构判断持有风险；估值、盈利、宏观和资金数据逐项提供额外证据。最终所有判断只落实为一个 510300 账户的仓位。**

这是一条综合现有工作的候选路线，目标仍为成本后夏普至少 1.2、复合年化至少 10%。目前不能把它当成已经验证的交易系统。

## 一、旧仓库确实改变了下一步的取舍

重新核对后，有几项工作不能遗漏：

| 已做工作                | 已有证据                                              | 对下一步的约束                       |
| ------------------- | ------------------------------------------------- | ----------------------------- |
| **趋势、超跌、突破与反转切换**   | 第 23 轮已经采用不同入场、退出和持有期限，包含趋势／反弹切换                  | “双策略＋不同退出”只能算结构思路，不能再当作新发现。   |
| **连续条件评分与动态仓位**     | 一版完整模型压力夏普约 0.351；相对静态仓位的收益增量区间跨零                 | 自动评分和连续仓位本身没有证明优势。            |
| **日内／隔夜收益结构**       | 一版固定条件增量模型基础／压力夏普为 0.018／0.167，训练与评价中的关系方向反转      | 不能继续把“日内强、隔夜弱”直接当成普遍买入规则。     |
| **成分股广度**           | “多数成分上涨＋二十日趋势”的基础夏普约 −0.100，虽比对应价格对照好，仍未建立可用策略    | “上涨家数多就买”已经不足以支持下一轮。          |
| **盈利预测、增长分歧**       | 一个增量实验有 33 个成熟评价原点，加入变量后 MSE 增加约 5.97%，未运行账户      | 原始研报整理值得保留，但该预测用途不能晋升。        |
| **逆回购、公募季度申赎**      | 保存预测的四组比较均未确认一致增量                                 | “资金面”不能仅靠变量名称获得更高权重。          |
| **旧 85/15 组合与最新形态** | 旧组合有历史达标点值，但局部稳健性失败；最新仅形态近期压力夏普 1.185，较长区间约 0.491 | 接近或达到 1.2 的历史结果，仍需解释收益来源和脆弱性。 |

**这些结果表明，继续增加一个技术指标、一个模型或一个仓位公式，已经很难算实质进展。**

不过，失败也有不同原因。某些实验确实没有信息增量；某些受限于时点、覆盖和样本；还有一些包含决策映射问题。例如，连续评分诊断发现，原模型的可达评分范围使“20 分退出”无法触发。以后研究必须先检查规则能否产生预想的行为，不能只看最终夏普。

## 二、我最想重新利用的旧成果，是“指数内部驱动”

这一部分在仓库 `CONTEXT.md` 中已经定义得比较完整：

**核心驱动组、身份持续性、内部广度、向其他行业传播、衰竭和终止。**它还明确要求：确认后固定核心成员，不能每天换成当天涨得最好的行业。

这比单纯看 510300 的一根 K 线，提供了更具体的问题。

例如，假设两个时点的 510300 都上涨 1%，波动率和突破形态也接近：

**情形 A：**原先推动上涨的行业持续贡献，组内参与股票没有明显减少，其他行业开始加入。

**情形 B：**少数权重股维持指数，原先贡献上涨的股票陆续转弱，参与范围收缩。

我们不能事先断言 A 一定延续、B 一定下跌。集中上涨也可能持续。真正值得检验的是：

> **控制指数已经发生的涨幅和波动后，内部参与结构的变化，是否能区分后续持有价值？**

这才是我会优先投入的具体假设。

它与已经失败的“多数成分上涨就买”有区别：关注的是**同一组驱动力能否持续，以及参与结构如何变化**。但必须先与旧代码逐项核对；相同定义、相同用途已经失败的部分，不重新包装。

### 为什么这条路线适合结合现有成果

最新形态研究可以确定观察起点，例如突破确认或急跌修复。旧的指数内部研究则可以描述这个起点背后发生了什么。

**形态负责提出交易候选，内部结构负责接受检验的额外判断。**

第一轮只加入一个预先定义的内部变量即可，不同时堆上行业轮动、盈利、资金、宏观和多个广度指标。缺少合格历史权重的日期，不能伪造精确板块贡献；使用等权参与指标时，也应明确标为等权指标。

## 三、第二项重点，是已有持仓的“继续持有价值”

你希望捕捉一段行情，也希望上涨后避免较大的利润回吐。旧仓库的日内／隔夜归因，为这个问题留下了一条重要线索。

第 181 轮主历史压力账户的保存归因是：

| 收益组成      |            金额 |
| --------- | ------------: |
| 日内价格损益    | ＋195,637.60 元 |
| 隔夜价格损益及股息 |  −16,104.10 元 |
| 佣金与滑点     |  −25,592.68 元 |
| 全账户净利润    | ＋153,940.82 元 |

这些是旧账户的损益分解，**没有证明可以交易一个“只保留日内收益”的策略**。较早历史的另一套账户，其隔夜贡献还为正，不能统一删掉所有隔夜。

但它值得提出更准确的问题：

> **已经持仓之后，哪些可观察变化表明：继续承担下一段风险，得到的收益补偿正在下降？**

我会把它与指数内部结构结合起来研究。例如，原有核心贡献走弱、参与范围收缩，同时 ETF 的日内承接也下降，是否比单纯“回撤达到某个百分比”更早、更可靠地提示持有价值降低？

这里讨论的是待验证的条件关系，不能直接设成卖出规则。仓库已经做过大量学习退出和风险退出，下一轮需要证明新增信息来自哪里，不能再搜索一个最漂亮的止盈点。

另外，股票 ETF 的 T+1 约束仍须保留：当天新买入的份额无法通过普通同日卖出来规避第一晚风险。旧份额可以如何减仓、新份额需要承担什么风险，应分别模拟。([SSE][1])

**这一方向的目标是改善既有机会的收益路径，降低损失；它需要与“根本不入场”的判断分开。**

## 四、急跌修复保留为辅助机会，宏观和资金暂不成为全部交易的门槛

### 急跌修复：可以独立存在，但不能靠补仓制造高胜率

最新包中，急跌修复分支的 11 个完整周期，7 个盈利，原账户净损益合计约 1.50 万元。这个结果只够支持继续观察，尚未证明稳定优势。整个仅形态账户的利润仍高度集中于最大一笔交易。

我会保留两种不同的收益路径：

**延续型机会**研究突破后的持续参与，主要希望抓住较完整的上涨。

**修复型机会**研究急跌之后的有限恢复，达到修复目标或失效时结束，不自动升级成长期持有。

两者共用风险限额和真实账户。它们都买同一只 ETF，同时出现信号时，不能把两份各自满仓的回测收益相加。

### 估值与盈利：保留信息，降低短线决策权重

旧仓库的“慢估值先验”本来就用于描述中长期剩余收益空间，并没有把“估值便宜”等同于短线买点。这个分工可以保留。

但鉴于已有具体预测实验失败，我不会现在就让估值和盈利修正自动扩大仓位。先检验它是否能够改善某个明确决策，例如相似趋势条件下的持有期限或风险判断。

### 宏观与政策：记录新信息，检验更新价值

M1/M2 的失败实验继续保留。政策和宏观信息可以成为重新评估的原因，但“发生新消息”与“应该买卖”之间仍有一步。

我不建议每笔交易都等到宏观、资金、形态完全一致。这样会增加大量条件，也可能错过价格已开始变化的阶段。每加入一类信息，都应单独证明它对决策有贡献。

### 资金与期现：免费、连续、时点合格，才进入模型

此前 PCF、IOPV、份额、IF 和资金资料的整理都应复用。但日线归因、季度申赎、期货总持仓和真实订单流，不能混为同一类“主力资金”。

**没有合格时点证据的资料留在观察层，已有本地数据能够完成的研究先继续。**无需为了一个可选变量，再把整个项目停在数据补齐阶段。

## 五、综合起来，下一轮应当检验什么

我会把主问题收敛为：

> **在既有价格机会出现后，指数内部结构与日内／隔夜结构，能否改善“是否进入、是否继续持有”的判断？**

这既复用旧仓库，也连接最新形态；它仍是一项假设，不能因组合了多个熟悉概念就默认有效。

下一轮可以保留四组有限比较：

| 组别 | 内容                      |
| -- | ----------------------- |
| A  | 原已冻结的价格／形态基准            |
| B  | A 加入一个指数内部结构变量          |
| C  | A 加入一个日内／隔夜持有风险变量       |
| D  | 两类变量共同使用，仅保留一个事先规定的交互关系 |

四组使用相同数据区间、成本、资金、账户规则和预先规定的评价方法。第一轮不同时改变形态窗口、风险目标、止盈止损和策略配比。

**每个新增变量都必须写出与旧实验的实质差异。**若旧研究已经覆盖，就直接沿用原裁决，不运行重复回测。

评价重点应是实际决策增量：扣费后有没有改善，是否只靠更多仓位，是否集中在同一轮行情，是否对少量邻近设置极度敏感。预测误差、胜率和条件收益可作诊断，不能单独代替完整账户。

允许个别形态阶段性有效，但启停规则也要接受时间顺序检验。反复筛选历史后保留最高夏普，会使结果偏乐观；多重试验校正和冻结后的新数据仍然必要。([DOI][2])

## 我的最终取舍

**综合全部旧工作，我最看好的候选结构是：**

**指数内部持续参与的行情作为主要机会；急跌修复作为独立辅助；日内／隔夜与下行风险帮助决定持有多少、何时减少；估值、宏观和资金信息逐项验证后再加入。**

它的优势在于，每个部分都有明确任务，也都能追溯到已经做过的工作。它的难点是，我们仍需证明这些信息的组合真正提高决策质量，而非增加筛选历史赢家的自由度。

**夏普 1.2 应继续作为整套账户的验收要求，不需要每个分支单独达到，也不能靠组合几个失败策略自动得到。**下一步最有价值的结果，是确认一项可重复的进入或持有优势，再扩大它的应用范围。

本次重新核对的是上述原始报告、定义及最新复核记录，没有重跑全仓库，也没有新增策略回测。
