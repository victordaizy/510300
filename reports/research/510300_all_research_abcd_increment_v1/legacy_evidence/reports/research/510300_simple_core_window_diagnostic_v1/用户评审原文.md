## 一、为什么现在应当明显降低对现版的信任

### 1. 最有力的新证据：邻近窗口的表现明显下降

以下都是**压力成本**结果，其他规则和原来保存的退出模型参数保持不变：

| 日内—隔夜因子窗口2020—2026年化净夏普最大回撤2015—2019年化／夏普 |            |           |            |                  |
| ----------------------------------------- | ---------- | --------- | ---------- | ---------------- |
| 50日                                       | **5.36%**  | **0.824** | −12.08%    | 7.94%／0.858      |
| **60日，现版**                                | **10.31%** | **1.220** | **−6.51%** | **11.21%／1.258** |
| 70日                                       | **4.24%**  | **0.686** | −9.58%     | 5.08%／0.649      |

主历史为2020年1月2日至2026年9月11日。较早历史在这次比较中统一使用最后一天收盘估值，因此60日结果与此前“末日开盘清仓”的版本略有不同，不能混用。窗口对照报告原文

**问题不是50日和70日必须也达到夏普1.2，而是：现版从60日向两侧各改变10天，收益显著下降，回撤还变深了。**

这不足以单独证明过拟合，但已经反对“60日附近存在一片稳定有效的参数区域”这个说法。

更重要的是，这并非抽象的数字变化。2024年那笔最大盈利交易，在三个窗口下完全不同：

**50日版本**在9月25日至10月8日全程空仓；**60日版本**持有68,300份，直到10月8日开盘卖出；**70日版本**虽然参与，但9月27日已经全部退出。三个版本2024年的压力收益分别为\*\*−4.13%、＋26.55%、＋3.39%\*\*。窗口对照报告原文

这说明，现版的一个重要优势依赖于：

> **具体窗口触发的入场时点，恰好与模型退出、上层等待和随后行情相配合。**

它可能包含真实的交易能力，但目前还没有把这种能力与历史上的有利巧合分离开。

### 2. 高收益又恰好集中在少数周期

按保存的完整周期表重新汇总，压力成本下，最大盈利周期贡献了**42.30%的总净利润，前五个盈利周期贡献了85.48%**。

与此同时，学习退出模型在主历史的17个成熟可比周期中，平均改善约**0.556个百分点**，但配对区间约为\*\*−2.298至＋3.353个百分点\*\*，仍然跨零。诊断报告原文

**利润集中本身不是错误，区间跨零也不证明模型无效。** 但将它们与窗口脆弱性、多轮历史筛选放在一起，我对“现版已经找到了稳定高夏普优势”的信任就必须下降。

原说明书也明确承认：最终组合是在观察过历史表现后选出来的。这种**研究者层面的选优偏差**，不会因为模型每个月只用当时的数据训练，就自动消失。 多次尝试后保留最好的回测，正是回测过拟合研究所强调的问题。

### 3. 还有一个必须保留的限定

这次50／70日实验**没有针对各自窗口重新训练退出模型**，而是沿用60日体系的月度模型参数。因此它严格证明的是：

**在现有模型与其他规则固定的条件下，当前系统对入场因子窗口变化很敏感。**

它尚未证明“50／70日各自完整训练后也一定不好”，更没有证明所有日内—隔夜信息都没有价值。窗口对照报告原文

所以，我不会下“100%已经证明全部无效”的结论；但也不会以这个限定为理由，继续相信原来的10%／1.2。

## 二、现在首先要停的，是“围绕达标数字继续修补”的工作方式

**我的建议不是马上把整个项目推倒重来，而是停止继续优化现版，保留现版作为固定研究对照。**

具体说，不要接着尝试55日、58日、62日；不要因为取消等待的夏普更高，就立即换成取消等待；也不要发现只用来源乙的历史夏普更高，就再去寻找能把它收益放大到10%的倍率。

这些结果可以用于理解机制，**不能自动成为下一版策略的选拔赛**。否则研究会变成：

> 找到一个历史赢家 → 检查发现脆弱 → 增加规则修补 → 再找到一个历史赢家。

反复使用同一段历史筛选规则，即使每次都重新划分训练期和测试期，也不能把已经参与设计的数据恢复成真正未见的数据。

当前最合理的调整是：**保留数据、账本、执行引擎和已完成的工程工作；暂停增加策略复杂度及实盘投入的依据。** 这不是要求你立即调整任何真实持仓，而是停止用这份回测支持新增交易授权。

## 三、下一项研究：先验证“简单的原始信号”，不要先救复杂组合

**我建议最多再做一次范围固定的拆解诊断，问题只有一个：**

> **不依靠学习退出、内部账户风险放大和上层延迟退出，日内相对隔夜较强这条入场思路，是否仍有值得研究的经济优势？**

这是我的下一步建议，不是包内已经完成的实验，也不是一个新的“已验证策略”。

### 把对照缩到三条，不继续搜索参数

三个窗口仍然只取**50、60、70日**，全部保留，不选表现最好的一条。对照定义如下：

| 环节固定诊断规则 |                                                      |
| -------- | ---------------------------------------------------- |
| 入场       | 各自窗口的日内—隔夜分数连续两日大于1；保留原来的空仓、重新入场许可和等待间隔              |
| 退出       | 保留原价格退出：分数连续两日小于0、持仓亏损达到6%、从持仓高点回撤达到8%、持有满60日；下一开盘执行 |

**这项实验同时移除了多个模块，因此只能回答“简单核心是否值得继续”，不能把与原版的差额归因于某一个模块。**

三窗口、两种成本、两个历史区间，一共12份账户结果；不是12个独立机会，也不是再从12条曲线里挑一个最好的。

### 这次看什么，而不是只看有没有1.2

重点是三件事：三个窗口的优势方向是否大体一致；相对于包内已有的买入持有和简单波动配置对照，是否仍有扣费后的改善；改善是否又主要依赖同一笔最大盈利交易。比较时同时展示实际波动和仓位，不能只比最大回撤。

这里要**把“存在优势”和“达到最终目标”分开**。一个简单核心即使暂时达不到10%／1.2，也可能值得研究；反过来，只有某个精确参数达标，不足以证明优势可靠。

我的研发去留建议是：

\*\*如果简单核心在邻近窗口下仍有一致的改善迹象：\*\*继续研究这个核心，下一步才允许增加一个模块，并检验它是否提供增量。先证明核心，再证明附加规则。

\*\*如果仍然只有60日漂亮，或者改善仍主要来自同一笔特殊交易：\*\*停止为这条信号主导的复杂化路线追加优化预算。不是宣布数学上不存在任何规律，而是承认现有证据不足以支持继续投入。

\*\*如果结果仍不确定：\*\*保留研究观察，不新增过滤器来“解决不确定性”，也不把它包装成可实盘候选。

这是一次有明确问题和终点的拆解，不是开启新一轮无限回测。

## 四、学习退出先降为次要研究，不要把整个项目押在“再等20个周期”上

因此，我建议：
