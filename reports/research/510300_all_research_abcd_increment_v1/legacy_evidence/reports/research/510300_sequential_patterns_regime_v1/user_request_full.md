## 一、你提出的规律，应当研究成“连续发生的过程”

例如，单独研究“波动率低，接下来涨不涨”，会遗漏你真正关注的结构。更接近你意思的研究是：

> **波动收缩 → 价格试探边界 → 试探失败或成功 → 买卖压力变化 → 后续延续或反转。**

第一轮可以限定为以下三类。**下面是待验证的研究定义，不是已证明有效的买入信号。**

| 形态在当时能够观察到的过程要检验的机会主要失败情况 |                           |                 |               |
| ------------------------- | ------------------------- | --------------- | ------------- |
| **低波动整理后突破**              | 振幅收窄，形成事前可确定的区间，随后价格突破上沿  | 突破确认后是否仍有延续收益   | 重新回到区间、向上突破失败 |
| **跌破前低后重新收复**             | 跌破事前已知低点，在固定观察时间内重新站回     | 下破失败后是否形成反弹或反转  | 重新破低，并继续下行    |
| **短时急跌后的修复**              | 短时间明显下跌，随后下跌速度减缓、价格收复部分跌幅 | 初始修复之后是否仍有可交易空间 | 只是下跌中继，继续创新低  |

这里有两个必要区分。

\*\*低波动能够描述整理状态，不能单独确定突破方向，也不能保证马上变盘。\*\*布林带收缩后的扩张可能向上，也可能向下。因此可以用低波动筛选观察对象，再由后续行为决定是否交易。([Fidelity](https://www.fidelity.com/viewpoints/active-investor/bollinger-bands?utm_source=chatgpt.com))

\*\*“先去前低再向上”可以单独成为一种形态，不宜作为所有向上突破的必要条件。\*\*直接突破、抬高低点后突破、跌破前低后收复，应分别统计。否则，我们会只注意符合叙事的成功路径。

研究时还要保留那些“收缩后一直没突破”“破低后没有收复”的案例，不能等后来上涨了，才回头把前面的动作命名为成功形态。

这些问题可以逐项测量。至于“主力故意下杀洗盘”，仅凭价格形态无法确认行为者及其目的。即使不知道是谁在交易，也可以检验这段价格过程是否提供优势。

## 三、“当前有效”可以接受，核心是能否在失效之前识别出来

我赞成改变验收方式：**允许某种形态只在部分阶段有效，但需要验证我们能否在当时识别这些阶段。**

例如，假设同一种突破形态在震荡阶段连续失败，后来在趋势阶段连续成功。可以研究“趋势状态满足时启用”，但不能看到后半段赚钱后，才把后半段圈出来称为适用期。

因此，需要同时研究两件事：

\*\*形态本身的优势。\*\*在同类条件下，它相对简单买入、随机时点或相近风险暴露，是否改善扣费后的结果？

\*\*形态的启停能力。\*\*使用当时已经知道的信息，能否比“始终使用该形态”更好地决定何时启用、何时暂停？

第二项尤其重要。我们最终交易的是整套选择与执行规则，不能只把每一种策略各自最赚钱的月份拼起来。

### 时间范围可以缩短，验证方式仍须保留时间顺序

我建议：

\*\*近期数据负责适应。\*\*预先规定用多长的近期历史估计波动、趋势、成交活跃程度，以及形态最近的表现。窗口长度可以研究，但不要每次亏损后重新寻找最漂亮的一段。

\*\*较早数据负责认识失败。\*\*主要检查类似形态在持续下跌、跳空、流动性冲击中怎样亏损，不要求它在所有年份都盈利。

\*\*随后发生的数据负责检验选择。\*\*在每个历史时点，仅使用此前信息决定启停，再记录之后的真实结果。规则修改后应另记版本，不能把不同版本接成一条从未失败过的曲线。

缩短到近期，并不会自动消除过拟合；如果同时筛选很多形态、窗口和条件，仍然会产生选择偏差。([DOI](https://doi.org/10.2139/ssrn.2460551?utm_source=chatgpt.com))

还有一个实际限制：\*\*优势持续时间，需要足以容纳识别和执行的延迟。\*\*如果一种形态只有效几天，而我们要等几个月才能判断它有效，就很难利用。反过来，一年只出现十几次的形态，也不能因为最近两次成功，就确定它已经恢复有效。

这不要求无限等待。可以先进入前瞻模拟，依据证据强弱分级评价，同时承认识别会有迟滞和误判。

## 四、下一轮应该怎样改，才能真正对准你的目标

**先做三类形态的识别与启停，暂时不继续堆宏观变量，也不一次展开十几套策略。**

已有技术因子可以按功能使用：波动指标描述压缩程度，均线斜率描述方向，前高前低定义位置，成交量描述活跃程度。每个功能先选少量指标。布林带创始人的规则也提醒，多项高度相关的指标不会自动提供多份独立确认。([bollingerbands](https://www.bollingerbands.com/bollinger-band-rules?utm_source=chatgpt.com))

每次触发应保存一份当时记录：\*\*所处状态、形态进展到哪一步、入场依据、失效条件，以及之后的实际结果。\*\*特别要比较：

- 仅有形态时的表现，与加入市场状态后是否不同。
- 第一轮动作已经发生后，从可成交价格开始是否还有收益。
- 启停规则能否改善完整账户，而不只是提高被挑中交易的胜率。

执行上仍要适配 510300。若所谓优势主要发生在当天买入后的几十分钟，股票 ETF 新买入份额的 T+1 限制就可能阻止按原设想卖出；研究必须从实际可执行条件出发。([Shanghai Stock Exchange](https://big5.sse.com.cn/site/cht/www.sse.com.cn/lawandrules/guide/jjznlc/c/c_20200722_3986154.shtml?utm_source=chatgpt.com))
