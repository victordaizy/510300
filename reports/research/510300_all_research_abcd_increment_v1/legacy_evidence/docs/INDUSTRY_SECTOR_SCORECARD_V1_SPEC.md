# 板块评分、胜率与频率 V1 规范

## 1. 三个必须分开的量

1. **当前评分**：0–100分的研究排序，由基本面、预期差、价格阶段、五日订单分类资金流和盈利收益率组成。
2. **历史胜率**：同一板块在历史月末开始、未来60个交易日跑赢沪深300的比例。
3. **历史频率**：历史胜出次数除以全部合格月末数，并同时列出次数、样本数；互斥经济大类另列未来超额收益位居前三的频率。

当前评分不是概率，历史胜率也不是当前评分的条件胜率。由于历史上没有可重建的逐月预期差台账，禁止把当前评分倒灌到过去。

## 2. 当前评分

总分100分：

- 基本面30分：经济大类或主题核心行业的权重加权60日基本面分数，截断在[-2,2]后线性映射。
- 预期差25分：中性基准12.5分，加上预期差方向乘有效覆盖率；缺失覆盖不能得到虚假的正负分。
- 价格阶段20分：弱基底初步恢复20分、中段趋势16分、混合10分、弱势尚未转折8分、尾段或过热5分。
- 资金流15分：当前五日订单分类资金流强度在同类板块中的横截面分位。
- 估值10分：当前盈利收益率在同类板块中的横截面分位。

等级：A≥75，B为65–75，C为55–65，D为45–55，E<45。边界左闭右开，A包含100。

## 3. 历史胜率口径

复用已冻结的板块60日目标：信号日为月度官方权重快照日，从下一交易日开盘进入，到第60个交易日收盘成熟；行业身份和指数权重固定在信号日。

经济大类收益等于其成员行业贡献之和除以该经济大类信号日权重。主题只聚合核心行业，邻接行业不进入收益。相对胜利定义为板块60日收益严格大于同一快照的沪深300快照收益；绝对胜利定义为板块收益大于零。

历史数据共有77个成熟月末，但60日持有期相互重叠；数据可行性报告给出的等效非重叠时间块只有24个。因此必须同时展示月末样本数、Wilson 95%区间和24个有效时间块警告。

## 4. 失败模型边界

既有S1板块基本面Ridge模型历史方向准确率39.47%，已冻结为`HISTORICAL_REJECTED_FROZEN`。本评分卡不得复用S1、不得把无条件历史胜率称为模型胜率，也不得据此生成仓位。

真正的“高分条件胜率”从本评分卡冻结后的前瞻记录开始积累；在样本成熟前输出`UNAVAILABLE_AWAITING_TRUE_FORWARD`。

全系统保持`RESEARCH_ONLY / SHADOW_ONLY / NO_POSITION_CHANGE`。
