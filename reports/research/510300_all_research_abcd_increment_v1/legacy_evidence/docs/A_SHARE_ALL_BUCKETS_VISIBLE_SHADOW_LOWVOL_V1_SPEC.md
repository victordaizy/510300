# 沪深五桶扩张低波公式可见Shadow V1

## 1. 扩张假设

本项目按用户要求，暂时假设桶2观察到的固定低波效应可以迁移，创建独立项目 `A_SHARE_ALL_BUCKETS_VISIBLE_SHADOW_LOWVOL_V1`。原桶2项目及其拒绝结论保持不变。本项目不是参数救援，不回写原桶2成绩，也不获得严格盲测等级。

扩张只改变候选覆盖：从哈希桶2扩大为哈希桶0、1、2、3、4，即TuShare母表中的SSE和SZSE股票。北交所因交易规则不同不在本版本内。哈希桶不作为投资因子。

## 2. 固定公式

1. 每60个交易日收盘后，在全部允许桶中统一横截面排名。
2. 候选必须具备旧实现所需十个原始特征，等价于至少约120条完整历史记录。
3. 最近20日平均成交额不低于10亿元；信号日价格不低于10元；100股成本不超过6500元；信号日成交量大于0；按点时上市、退市状态过滤。
4. 唯一分数是20日总收益对数收益波动率的反向百分位排名，波动率越低越优；相同值按股票代码升序。
5. 机械目标始终是第1名，只持有1只。额外展示前5名仅用于核对和解释；人工从中选择会产生新策略身份，不计入本项目。
6. t日收盘产生信号，t+1交易日开盘模拟成交；开盘总收益跳空绝对值超过9.5%时阻止该腿。

## 3. 账户与成本

初始资金2万元，100股整数手，单腿名义金额至少5000元。佣金万三且每腿最低5元，卖出印花税万五，单边滑点5bp，现金年化1.5%。基准为H00300沪深300全收益指数。

## 4. 暖启动证据

暖启动面板来自四个互不重叠的冻结面板，覆盖桶0、桶1、桶2、桶3/4。每只股票仅保留最近140条记录，用于覆盖最长120日资格窗口并控制每日运行内存。来源文件、哈希、桶覆盖、派生面板哈希写入独立来源清单。

## 5. 证据边界

这是可见Shadow，不是严格盲测。首次全池结果出现前冻结实施文件，但组成数据均已在其他研究中出现，因此不得称为新样本盲测。至少完成10个60日周期后才生成统计摘要；此前只报告运行、成交、成本和逐日净值。

实盘仓位映射、订单文件、券商连接和实盘交易全部关闭。任何窗口、门槛、成本、持仓数、候选人工选择或交易所范围变化都必须建立新项目ID。
