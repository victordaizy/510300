# 第71轮：以继续持有收益的条件中位数学习退出

本轮只检验一个新学习目标，不补EPS或其他数据。原线性模型学习平均继续价值；本轮改用最小加权绝对误差，估计继续价值分布的中间位置。它可能减少极大盈亏对模型的牵引，也可能丢掉少数重要的大盈利，必须以完整账户检验，不能把中位数为正直接当成稳定赚钱。目标仍是完整账户扣费净夏普至少1.2及稳定超额。

## 全部因子

| 因子 | 中文定义 |
| --- | --- |
| 进入用的日内相对隔夜强弱 | 每天以“收盘加当天每份分红”除以“开盘加当天每份分红”，取自然对数，得到日内部分；以“开盘加当天每份分红”除以前一收盘取自然对数，得到隔夜部分。两者相减，将最近六十个交易日的差值合计，除以这六十个差值的样本标准差和六十的平方根。 |
| 持仓时间对数 | 从实际买入日到当前收盘的交易日数，买入当天为一；对“一加该天数”取自然对数。 |
| 含分红浮盈浮亏 | 当前份额乘当前收盘价，加本周期已确认的分红，除以实际买入金额加买入佣金，再减一。 |
| 持仓回撤 | 当前含已确认分红的持仓价值，除以从入场至今的最高收盘持仓价值，再减一；最高价值初始至少等于买入总成本。 |
| 入场模式 | 本轮沿用单一日内相对隔夜进入模式，数值为一，不在不同模式间另作选择。 |
| 五日涨跌 | 当前含分红累计财富水平，除以五个交易日前的同一水平，再取自然对数。 |
| 二十日涨跌 | 当前含分红累计财富水平，除以二十个交易日前的同一水平，再取自然对数。 |
| 一百二十日均线偏离 | 当前含分红累计财富水平，除以含当日在内最近一百二十个交易日的平均值，再减一。 |
| 二十日波动 | 最近二十个交易日含分红简单收益的样本标准差，乘以二百四十二的平方根。 |

上述后八项进入模型。财富水平逐日乘以“当天收盘加每份分红，除以前一收盘”，只按过去和当前信息递推。实际账户用未复权交易价格，并单独登记分红权益、应收及现金支付，不能重复计息或分红。

## 进入、持有、退出与再次进入

1. 收盘后判断日内相对隔夜强弱。该值连续两个收盘严格高于一，形成进入条件。当前空仓、已具有再次进入资格、且距上次实际退出至少两个交易日，才请求下一开盘买入。
2. 买入预算只使用判断收盘已知现金、价格与该档交易成本，计算可负担的一百份整手。本次未来开盘不参与信号或请求预算，在撮合时才用于滑点和现金约束。持仓中不追加买入。
3. 实际买入后取消再次进入资格。卖出之后必须先在空仓收盘观察到原进入条件消失，再等其重新成立，同时满足原来的两个交易日等待条件，才能重新买入。未成交的买入不消耗进入资格。
4. 每个持仓收盘使用当时可用的中位数模型。连续两个收盘预测继续持有收益的中位数小于零，下一开盘请求全部退出。预测等于零、大于零、缺少成熟模型或当天任一模型输入不全，连续负值计数归零。新持仓周期重新计数。
5. 以下原退出条件继续有效，任何一项触发即请求全部退出：日内相对隔夜强弱连续两个收盘小于零；含分红持仓损失达到百分之六；含分红持仓价值相对本周期高点回撤达到百分之八；从买入当天算起持有达到六十个交易日。没有单独止盈条件。
6. 退出请求一旦形成，保持到实际卖完。即使以后模型转正、缺失或进入条件恢复，也不撤销已经形成的退出意图。遇到涨跌停或交易约束不能成交时，保存真实未成交，按原规则以后继续请求。
7. 缺少模型时仍执行原价格、止损、回撤和持有期退出，不把缺失预测填成零，也不自动清仓。持仓输入必须来自该模拟账户自己的实际入场日期、份额、成本、分红和最高持仓价值。
8. 所有常规判断在当日收盘信息形成后作出，月度训练在该日十五点零五分完成的历史假设下，当日随后可以使用新模型；成交统一下一开盘。评价终点统一在指定终点开盘清算，覆盖原信号，终点收盘和之后资料不参与收益。

## 训练答案与成熟时钟

直接复用已保存的原日内强弱参考账户样本，不重新构造参考持仓。对一个原自然结束周期内的每个合格持仓收盘，比较“下一开盘立即卖出，之后持有现金”和“继续持有到该原周期自然退出”的净卖出金额差，加入后者额外获得的分红权益，再除以下一开盘时的未扣费持仓市值。

两个卖出方案都扣除各自的基础费用、滑点和价格单位损失。买入成本为共同成本，不重复扣除。分红只比较两个退出时点之间新增的股权登记日权益；已经获得但尚未到账的共同权益相互抵消，不能因除息或到账较晚就算成继续持有新增收益。因研究终点强制结束的原周期不进入训练。

只有一个原周期已经实际自然退出，该周期全部状态才可使用，不提前收录其中已发生的部分日子。每月第一个交易日收盘按原模型时点更新，使用最近二十个已经完整结束且有合格记录的周期；至少十个周期、一百条记录才拟合。每个周期训练总权重为一，其内部各日均分；长周期不因天数多而获得更高总权重。本轮与原模型逐次核对训练周期、记录数和生效日期相同。

## 唯一模型与规则数值

八个输入按当次训练权重计算均值与总体标准差，标准差极小时仅为避免除零取一。每个输入先减均值、除标准差，再限制在负五到五。预测值由一个截距加八个标准化输入乘各自系数得到，所有实际月度系数另存中文说明。

训练选择使“各条记录预测误差绝对值乘样本权重后的合计”最小的线性关系，估计条件中位数。分位位置固定为二分之一，这是中位数的定义；不加额外系数惩罚，不搜索分位点或惩罚强度。使用既有软件库的线性规划求解器；不收敛、数值无效或求解失败则记录无模型，沿用原退出，不试其他算法救回该月结果。输入有缺陷等程序错误则如实停下修正实现，不依据收益改规则。

方法依据：[分位数回归官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.QuantileRegressor.html)。文档说明中位数与求解方法，不证明本交易策略有效。平均数与中位数代表不同分布信息，本轮不声称只改变了原岭回归的一个系数，原模型的平方误差和系数惩罚均已被无惩罚绝对误差目标替换。

## 固定评价和完成条件

主评价为2020年1月2日至2026年8月14日开盘；较早诊断为2015年1月5日至2019年12月31日开盘。各从二十万元开始，完整保留全部交易日和空仓日。现金及无风险年收益率沿用零，年化使用二百四十二个交易日。基础单边佣金万分之二、最低五元、滑点万分之五；压力佣金万分之四、最低五元、滑点千分之一。保留一百份整手、千分之一价格单位、买入次日可卖、方向涨跌停和完整分红记账。

一个新模型策略、四个新完整账户；复用原平均收益学习退出、原不学习退出、急跌与原学习各半和买入持有的十六个保存账户作为对照。报告净夏普、年化、回撤、成交、费用、逐年贡献及新旧退出差异。预先冻结后才拟合或读取新策略收益；不因预测显著性不足阻止完整账户评价。若不能形成跨历史及费用压力的改善，结束本轮，不扫描分位点、惩罚、确认次数或训练窗口。已有历史经过多轮研究，即使历史净夏普达到1.2也不能替代独立验证。

本轮仅510300与现金的历史研究，保持实际交易影响为零，不构造GPT数值包。EPS、财报、股数、估值和公募慢来源补齐继续暂停。
