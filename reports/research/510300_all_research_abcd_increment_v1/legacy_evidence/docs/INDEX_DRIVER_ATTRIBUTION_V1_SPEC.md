# 510300 点时指数驱动归因 V1 规范

状态：`ATTRIBUTION_ONLY`  
预测目标：`NOT_DEFINED`  
未来收益读取：`FORBIDDEN`  
仓位映射：`DISABLED`  
订单生成：`DISABLED`  
券商连接：`DISABLED`

## 1. 研究目的

本阶段只回答一个会计归因问题：在每个交易日，沪深 300 的快照加权成分收益由哪些一级行业贡献。

本阶段不回答以下问题：

- 板块驱动是否会延续；
- 当前是否属于“鱼中”；
- 当前是否接近“鱼尾”；
- 是否应该持有、买入、减仓或卖出 510300；
- 哪个窗口、阈值或组合能获得更高未来收益。

只有本归因底座通过后，才允许另建协议冻结“鱼中确认”和“鱼尾预警”的预测目标。

## 2. 信息域与交易边界

唯一潜在交易标的仍为 `510300.SH`。沪深 300 点时成员、官方权重、成分总收益价格和点时行业区间只作为解释 510300 所跟踪指数内部驱动的研究信息，不是可交易资产池。

本协议重新授权指数内部板块信息用于归因研究，但不授权：

- 交易成分股或行业基金；
- 使用期权、期货、融资融券、卖空或杠杆；
- 自动生成 510300 仓位；
- 连接券商或生成订单。

## 3. 点时规则

### 3.1 官方权重

交易日 `t` 只使用 `trade_date <= t` 的最新官方月度权重快照。权重快照年龄超过 45 个自然日时，当日输出 `NO_VIEW`。

不得把未来月末权重回填到月内，也不得使用当前权重重写历史。

### 3.2 成分总收益价格

成分收益使用 `total_return_close`。只有同一证券在全局相邻两个交易日均有记录时，才计算一日收益；证券退出后重新进入时，不得跨越日期缺口计算伪一日收益。

停牌日保留记录并延用总收益价格，因此停牌日收益为零。

### 3.3 一级行业

V1 主分类固定为中信一级点时行业区间：

- 输入：`data/raw/reference/a_share_citic_industry_point_in_time.parquet`；
- 生效区间：`in_date <= t < out_date`，空 `out_date` 表示仍有效；
- 同一证券同一日最多匹配一个一级行业；
- 不允许用申万静态标签、申万不完整点时表或当前分类补洞；
- 缺失行业形成“未归因贡献”，不会被改名为“其他行业”。

选择依据：2019-12-23 至 2026-07-31 的 80 个官方权重快照中，中信一级最低权重覆盖约 97.86%；现有申万点时表最低覆盖约 71.73%，不足以作为主分类。

## 4. 冻结归因恒等式

对证券 `i`、行业 `s` 和交易日 `t`：

`ComponentContribution(i,t) = SnapshotWeight(i,t) × TotalReturn(i,t)`

`IndustryContribution(s,t) = Σ_i∈s ComponentContribution(i,t)`

`AttributedContribution(t) = Σ_s IndustryContribution(s,t)`

必须满足：

`AttributedContribution(t) = Σ_(i有有效行业) ComponentContribution(i,t)`

允许的绝对浮点误差不超过 `1e-12`。

月度快照权重并非中证逐日精确自由流通权重，因此：

- `Σ_i ComponentContribution(i,t)` 命名为“快照加权成分收益”；
- 不得将其冒充中证官方指数日收益；
- 不用真实指数收益反推或校准成分贡献；
- 行业贡献之和只需要与同口径成分贡献恒等。

## 5. 输出表

### 5.1 点时指数截面

每个交易日、每只快照成员一行，至少保存：权重快照日、权重年龄、成分代码、权重、总收益价格、一日收益、点时行业、行业来源、成分贡献及数据可用标记。

### 5.2 板块贡献表

每个交易日、每个一级行业一行，至少保存：行业权重、收益覆盖权重、行业收益、行业对指数的快照加权贡献、行业上涨权重占比及成分数。

### 5.3 每日归因摘要

每个交易日一行，至少保存：成员数、权重和、权重年龄、价格/收益/行业覆盖、快照加权成分收益、已归因贡献、未归因贡献、恒等式误差、当日板块驱动、正贡献集中度、输出状态和失败类别。

## 6. 数据门槛

归因有效日必须同时满足：

- 快照成员数恰为 300；
- 快照权重和位于 98% 至 102%；
- 权重快照年龄不超过 45 个自然日；
- 总收益价格权重覆盖不低于 99%；
- 一日收益权重覆盖不低于 95%；
- 中信一级行业权重覆盖不低于 95%；
- 行业贡献恒等式绝对误差不超过 `1e-12`。

任一门槛失败时，当日输出必须为 `NO_VIEW`，并列出精确失败类别。`NO_VIEW` 不得映射为任何交易动作。

## 7. 首版中性描述量

V1 只输出以下同期描述量：

- 当日贡献最大的一级行业及其贡献；
- 正贡献行业总贡献；
- 负贡献行业总贡献；
- 最大正贡献行业占全部正贡献的比例；
- 前三大正贡献行业占全部正贡献的比例；
- 正收益行业所覆盖的指数权重；
- 行业收益离散度。

这些量不带预测方向，不允许在本协议内搜索持续天数、动量窗口、分位数或未来收益阈值。

## 8. 验收测试

实现至少通过：

- 最新但不晚于当日的权重快照测试；
- 行业区间右端开区间测试；
- 未来行业生效信息不可进入当日测试；
- 跨日期缺口不得计算一日收益测试；
- 成分贡献与行业贡献恒等式测试；
- 行业覆盖不足输出 `NO_VIEW` 测试；
- 权重快照过期输出 `NO_VIEW` 测试；
- 输入重复证券日期和重复有效行业区间拒绝测试。

## 9. 后续研究顺序

1. 冻结并构建本点时归因底座；
2. 审计覆盖、恒等式、数据日期和 `NO_VIEW`；
3. 与用户共同定义“鱼中确认”的可观测条件和未来收益目标；
4. 新建协议后才读取对应未来收益；
5. 独立定义“鱼尾预警”，不得用鱼中结果反向挑选风险阈值；
6. 两者分别通过预测门槛后，才讨论纸面信号；
7. 仓位、订单和券商连接继续禁用，除非用户另行明确授权。

## 10. 版本规则

V1 冻结清单生成后，配置、定义、实现、输入指纹或测试发生变化时不得覆盖原清单，必须创建新版本。生成新历史数据不能改写 V1 的证据标签。
