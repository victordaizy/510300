# 第十轮：原始季度申购赎回是否改善510300判断

## 经济问题与完整目标

用户要求考虑公募申购。本轮使用510300本体原始季度报告，检验已披露的份额需求、赎回压力和申赎活动是否提供价格以外的信息。ETF份额变化可能包含实物申赎、套利和机构配置，所以同时保留需求顺向与反向规则，不能事先把净申购称为股票买入现金或看涨保证。全市场公募申购另行补齐。

完整账户成本后夏普至少1.2仍是目标，同时报告相对买入持有超额、压力成本、分期稳定性和不确定性。旧九轮结果保持不变。本轮只做510300与现金的研究模拟，不产生真实交易。

## 来源和六项输入因子

原始来源覆盖2012年第三季度至2026年第二季度56份PDF；55份有上交所公告目录，2013年二季报的官方公布目录仍缺，不能作为合格信号。原始表金额、身份、期间、会计等式及相邻期衔接先核对。当前收到的新报告若不合格，不退回旧报告凑特征。

| 因子 | 中文定义 | 用途与边界 |
|---|---|---|
| 本季净份额需求 | 本季申购份额减赎回份额，再除以本季期初份额 | 正数代表份额净增加，负数代表净减少；不是人民币资金流。 |
| 净份额需求变化 | 本季净份额需求减上一季度同口径数值 | 上季资料也须有可信公布日期和合格原始值；缺少时不计算。 |
| 申赎活动强度 | 本季申购加赎回份额，再除以本季期初份额 | 区分净额相同但双向活动不同的情形，不把总活动称为净流入。 |
| 六十日价格动量 | 决策日过去六十个交易日含分红对数收益之和 | 与份额信息同时对照，控制此前价格涨跌。 |
| 一百二十日均线偏离 | 当日含分红财富除以过去一百二十日财富均值，再减一 | 描述当前价格趋势。 |
| 六十日波动 | 过去六十日含分红日收益的样本标准差，乘242的平方根 | 描述当时已知风险；实际决策另用对应每日方差。 |

只在每期原始季报公布后的第一个交易日收盘形成新判断，下一开盘执行；新账户2020年首个交易日之前的收盘另设一次初始化，用当时最新合格报告和当时价格。公告目录日期与封面送出日不同时取较晚者，禁止使用较早的文件夹准备日期。没有新公告的交易日只保持既有份额，不能每天拿同一份季报重复换仓。

## 三个滚动学习方案

主方案为“价格加份额需求的岭回归”，另有“仅价格”和“仅份额需求”两组匹配对照。三组都使用同一批全部六项输入有效的历史季度起点，避免覆盖和样本数量不同影响比较。

训练每份季报只取一个起点，不把一份季报复制几十次充当几十份新资料。预测标签为起点之后下一开盘买入、六十个交易日后开盘卖出的持有总收益，正确处理分红权益。训练时只纳入退出开盘已经发生的样本，至少需要12份已到期季度观察；观察的标签可能部分重叠，不宣称统计独立。

每次新季报或初始化时，用此前全部合格成熟样本重新拟合。各输入按训练集均值和标准差标准化；岭回归惩罚强度固定为10，不尝试其他数值。初始化可以使用此前最新季报以及初始化当日价格，仍只用过去季度样本训练。标准化和拟合不读取未来资料。

将模型预测收益，减去固定风险厌恶系数4的持有期风险惩罚，再减去调仓估计费用，在保持已有份额、零、四分之一、二分之一、四分之三和满仓之间选择净效用最高的动作。同分优先不交易。六十日方差以当时六十日日收益方差乘六十估计。模型标签为固定六十日，而实际两次公告间隔可略长或略短，本轮如实保留该差异，不事后调整窗口。

## 四个可解释规则对照

| 规则 | 完整中文动作 |
|---|---|
| 净申购顺向 | 本季净份额需求大于零时满仓，否则现金。 |
| 净赎回反向 | 本季净份额需求小于零时满仓，否则现金，用于检验申赎与价格可能反向的机制。 |
| 同公告节奏的趋势 | 含分红财富高于一百二十日均线时满仓，否则现金。 |
| 需求与趋势共同确认 | 净份额需求为正且含分红财富高于一百二十日均线时满仓，否则现金。 |

四个规则也只在上述公告或初始化时点判断，使用相同有效来源范围。资料缺失时记录无判断，保持账户已有份额；已有份额为零属于账户事实，不把缺失预测写成现金目标。下次合格公告再判断。买入持有按原完整账户定义另列为基准。

总共7种事先规定的候选，加买入持有基准，两档费用共16条评价账户。不得根据结果改变主方案、阈值、训练最少数量、回归惩罚、持有期或排除某个时期。所有候选及无判断记录完整披露。

## 账户、对照和判定

初始20万元，2020年1月2日至2026年8月14日开盘退出，共1604个交易日。100份整手、最小价位0.001元、T+1、方向性涨跌停限制；分红按登记、除息应收、支付到账记账，应收不可提前买入。实际目标与持仓相差不足十个百分点时沿用原容忍规则，退出至零不受此限制。

基础佣金万分之二、每笔最低5元、单边滑点万分之五；压力佣金万分之四、最低5元、单边滑点千分之一。模型预测在两档费用下相同，效用决策受各自费用影响，因此实际份额可以不同。现金利息与夏普参考利率为零。夏普为完整日收益均值除样本标准差，乘242的平方根。

保存全部每日账户、公告起点、训练样本、最晚成熟标签、模型文件和新信息时钟。验证公告外没有主动换仓、无判断没有被改成清仓、买入持有与原基准逐日一致。报告全年、逐年、2020至2021、2022至2023和2024至终点三个分期。用20日连续区块共同抽样2000次，给出主方案夏普及相对仅价格模型、同公告趋势规则的年化日均收益增量95%区间。

历史已经多次观察，本轮不是独立样本验证，也不完成所有历史尝试的多重选择校正。点估计达到1.2只意味着进入后续必要复核，不直接证明稳定超额或结束持续研究。
