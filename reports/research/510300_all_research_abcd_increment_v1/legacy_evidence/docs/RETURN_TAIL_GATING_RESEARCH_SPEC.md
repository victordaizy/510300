# 510300_RETURN_TAIL_GATING_DISCOVERY_V1 研究协议

状态：`DISCOVERY_ONLY`  
历史证据标签：`HISTORICALLY_CONTAMINATED`  
仓位映射：`DISABLED`  
订单生成：`DISABLED`  
券商连接：`DISABLED`

## 1. 研究问题

本项目不继续优化 R6 的估值、趋势和实现波动参数，也不建立 R7。唯一问题是：期权、指数内部共同尾部和点时盈利预测修订等新信息，能否在信号形成时识别未来 20 个交易日 510300 显著跑输现金的少数时点。

R6 已于 2026-08-16 正式历史拒绝。其 25 个候选、失败族观察数据和历史排名不得用于本项目选择期限、阈值、权重或模型。R5 只作为冻结的信息集基准，不是短期方向预测器。

## 2. 目标与可交易时点

信号使用 `t` 日 16:00 前可得的信息，最早从 `t+1` 交易日开盘执行。日期只有“日”而没有发布时间的数据统一延迟一个交易日，不能假设它在当日收盘前已经可得。

从 `t+1` 开盘到第 `h` 个交易日收盘的 510300 含分红总收益减同期现金收益记为 `X(t,h)`。现金年化收益固定为 1.5%，按 242 个交易日复利；首版不得根据结果更改。

- `BAD20 = 1[X(t,20) <= -5%]`；
- `TAIL20 = 1[min_j X_path(t,j) <= -8%]`，路径使用每日含分红调整低价；
- 稳健性目标为 `BAD60 <= -8%` 与 `TAIL60 <= -12%`。

收益从下一交易日开盘开始，避免把信号形成前或不可成交的收盘价纳入择时收益。

## 3. 候选预算

首轮候选总数固定为 9：6 个单变量、2 个固定组合、1 个仓位政策。完整机器可读定义见 `config/return_tail_hypothesis_registry.yaml`。

| ID | 原始信息 | 固定主定义 |
|---|---|---|
| O1 | 期权左尾 | 25 日风险中性分布下 `P(S_T/F_t <= 0.90)` |
| O2 | 认沽偏斜 | 25 日 25 Delta 认沽 IV 减认购 IV |
| O3 | 下行期限结构 | 25 日认沽 IV 减 60 日认沽 IV |
| O4 | 方差风险溢价 | 25 日隐含方差减 HAR(1,5,22) 事前实现方差预测 |
| X1 | 共同尾部 | 权重加权的成分股 5 日收益跌入各自事前 5% 尾部的比例 |
| E1 | 盈利下修 | 权重加权的 FTM EPS 下修比例减上修比例 |
| C1 | 固定组合 | 通过单信号的等权概率平均 |
| C2 | 约束组合 | 非负系数、无交互的 Logistic |
| P1 | 固定政策 | 正常 100%，防御 50%，40% 退出、20% 恢复，恢复需连续 3 日 |

所有原始信号使用滞后一期、至少 252 日历史的扩展经验分布做标准化，数值越大统一表示风险越高。最高风险组固定为事前分位不低于 90%，不搜索其他分位。

## 4. 数据先行门控

在任何收益标签、条件收益、策略曲线或候选排名运行前，必须执行：

```powershell
.\.venv\Scripts\python.exe scripts\audit_return_tail_gating_data.py
```

审计分别输出期权曲面、成分股共同尾部和盈利预测 vintage 报告。只有某一分支的状态为 `PASS`，该分支候选才允许进入原始预测检验；`PARTIAL`、`BLOCKED` 和 `TERMINATED` 均不允许计算收益结果。

期权分支必须证明：完整历史链、买卖一档、成交量、持仓量、合约状态、标准/调整合约、行权价、合约单位、市场时间戳、无套利曲面覆盖和固定期限插值均可复验。仅有收盘价或网页当前行情不通过。

X1 必须证明：每日点时成员恰为 300、成员总收益价格覆盖、历史权重年龄、行业分类时点和首尾日期满足协议。静态行业分类不能支持行业扩散的次统计量。

E1 必须具有逐日或逐事件保存的真实历史一致预期快照、来源 vintage ID 和发布时间。公司财报公告不是分析师一致预期；用当前一致预期回填历史将直接终止 E1。

## 5. 原始预测能力

发现层不生成仓位。每个单信号只报告无条件事件率、最高风险组事件率、Lift、Precision、Brier Skill Score、Log Loss、校准曲线、20 日相对收益分布和最大不利路径。ROC AUC 只作辅助。

概率校准只能使用信号日前已经成熟的标签。例如 20 日标签在完整 20 个后续交易日出现前不得加入训练窗。

单信号必须同时满足：

- BAD20 Lift 至少 2；
- 分块 Bootstrap 的 Lift 下界大于 1；
- 样本外 Brier Skill 大于 0；
- Log Loss 优于无条件概率；
- 一日延迟保留至少 70% 效果；
- 前后样本方向一致；
- 相对冻结 R6 信息集有增量。

## 6. 增量信息与组合

基准模型固定为 R6 的信息集合：估值、历史趋势、实现波动。每个新信号比较“基准”与“基准加新信号”，必须在严格历史伪样本外同时改善 Brier、Log Loss、BAD20 识别和成本前单位择时贡献。

只有至少两个单信号独立通过后，才能构造 C1 和 C2。禁止随机森林、XGBoost、深度学习、HMM、自动交互和超参数搜索。组合失败不得反向修改单信号定义。

## 7. 单位择时贡献与固定政策

先计算每减少一个单位 510300 暴露的成本后动态择时贡献，不用低平均仓位美化回撤。必须同时优于同平均仓位静态组合和同波动静态组合，循环平移位于 95% 分位以上，两倍成本仍为正，四个预定义时期至少三个为正，单一事件贡献不超过 35%。

只有单位贡献通过后才允许评估 P1。P1 的 40% 退出阈值来自固定损益假设：可规避损失 5%、错误退出损失 3%、单位往返成本 0.16%，得到 39.5% 后上取整。这个阈值不得根据历史曲线移动。

## 8. 多重选择与停止条件

Reality Check 和 PBO 对完整 9 配置统一计算。不能只检验最终第一名。参数邻域符号反转、效果集中于单一危机、延迟后消失、只预测波动不预测相对现金收益、不能超越 R6 信息集、或必须追加期限/Delta/分位才转正，均终止对应分支。

E1 在没有真实历史 vintage 时立即终止。期权链无法可靠识别调整合约时，O1—O4 全部停止，不用标准合约幸存样本替代。

## 9. 历史污染与真正前向

截至 2026-08-14 的收益历史全部标记为历史污染，只可用于发现和否证。真正前向起点必须晚于以下事项全部完成的时间：协议、候选、实现代码、输入合同和文件哈希冻结并提交；数据可行性通过；前向采集器可以只追加且不会回填。

因此配置中的 `true_forward_start` 初始为 `null`。不能仅因 2026-08-17 是下一个交易日就自动填入。前向批准还需同时满足：有效信号日、成熟 20 日结果、成熟 60 日结果均至少 242，独立坏状态事件至少 5 个。

## 10. 研究边界

该项目只做研究和纸面前向记录，不连接券商、不下单、不自动映射仓位。输入缺失、日期不一致、哈希变化或审计未通过时唯一允许的输出为 `NO_VIEW`。
