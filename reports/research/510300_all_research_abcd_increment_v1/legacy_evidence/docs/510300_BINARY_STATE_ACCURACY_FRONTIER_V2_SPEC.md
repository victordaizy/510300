# 510300 满仓/空仓短周期识别精度前沿 V2

状态：`PREFREEZE_IMPLEMENTATION_COMPLETE`  
证据：`HISTORICALLY_CONTAMINATED_PERFECT_FORESIGHT_DIAGNOSTIC_ONLY`  
对象：只持有 `510300.SH` 或现金，目标仓位只能为 `100%` 或 `0%`

## 1. 为什么只研究1日与5日

V1已冻结检验1、5、20、60、121和242个交易日的完美方向块。压力成本下，只有1、5和20日神谕在全部日历错位上具有达到两项20%门槛的数学空间；60日及以上即使提前知道未来方向也不能达标。20日误差前沿进一步显示，零误退出时也需要100%坏块召回，出现10%误退出后即使100%坏块召回仍不达标。

因此V2不新增指标、不搜索参数，只补齐1日和5日两个尚未量化的预测能力门槛。

## 2. 冻结目标、状态与成本

唯一目标保持不变：

`StrategyNetCAGR - H00300TotalReturnCAGR >= 20%`

且242个交易日滚动年化超额中位数不低于20%。账户初始资金50万元，T日收盘后形成状态，T+1开盘执行；每条成交腿扣1bp佣金，V2仅使用每腿15bp滑点的压力成本；现金年化收益1.5%，股票按100份整手交易。状态严格属于 `{0, 1}`，不允许中间仓位、杠杆、卖空、期货、期权或其他证券。

## 3. 随机等数量错误前沿

对1日和5日完整非重叠块遍历全部日历错位。每个块的真实神谕状态沿用V1：若块内510300含分红毛终值高于现金终值则应满仓，否则应空仓。

每个“坏块召回率 × 误退出率”网格中，每次重复严格抽取相同数量的坏块作为正确退出，并严格抽取相同数量的好块作为错误退出；四舍五入采用 `ROUND_HALF_UP`。随机性只决定错误发生在哪些块，不改变错误数量。每格固定100次，随机种子 `20260828`。

主门槛要求每个日历错位的100次模拟中位数同时满足全样本年化净超额20%和242日滚动超额中位数20%。另报“日历错位中位数”作为次要诊断，但不得用它替换主门槛。

## 4. 损失严重度神谕

普通召回率把每个坏块等权，但真实策略若能优先识别最危险的下跌，可能不需要覆盖全部坏块。因此V2另建一个更强、也更不可实现的上界：使用未来结果把坏块按 `现金毛因子 - 510300含分红毛因子` 从大到小排序，只退出最严重的一部分，所有好块均保持满仓。

该曲线回答两个问题：稀有崩跌退出是否足以达到滚动20%目标；若足以，需要提前准确锁定多少坏块、捕获多少坏块机会损失。它使用未来排序，绝不是策略候选或可交易信号。

## 5. 运行与停止边界

V2实现、测试、V1依赖和三项原始数据必须在首次生成V2历史结果前写入不可覆盖的SHA-256清单。运行器发现任何清单漂移或既有输出时立即失败。

V2只决定下一候选应瞄准1日还是5日、需要怎样的事件频率和精度。它不生成当前状态、Paper/Shadow、仓位映射、订单、券商连接或实盘授权。下一策略候选必须在读取其自身历史收益前单独冻结，禁止把V2神谕结果当作策略表现。
