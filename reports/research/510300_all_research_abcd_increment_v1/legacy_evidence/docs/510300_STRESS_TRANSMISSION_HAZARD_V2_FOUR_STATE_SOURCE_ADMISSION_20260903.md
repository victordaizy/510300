# 510300 压力传导危险率 V2：成分收益四态来源准入附录 V1

## 1. 本阶段结论

本附录是已冻结 V2 主协议的追加式来源契约，不修改主协议，也不解锁模型、绩效、仓位或交易。

当前只允许两步：

1. 冻结四态来源、字段、可得时钟、公司行动对账和失败规则；
2. 对四个供应商接口做一次有界的小样本可用性探测。

探测通过只表示接口和字段可取得，不表示历史四态覆盖通过，更不表示 G0、G1 或任何预测/组合门通过。

## 2. 文档核对后的来源语义

Tushare `daily` 文档明确说明：它提供未复权日线，停牌期间不提供数据；`pre_close` 是除权后的昨收。因此：

- `open/high/low/close` 可作为未复权价格候选；
- 缺少 `daily` 行不能自动等同官方停牌；
- `pre_close` 只能作为当日除权参考价和内部一致性字段，不能直接替代行动前的未复权收盘价。

Tushare `suspend_d` 是供应商维护的每日停复牌表。本项目没有把供应商身份升级为交易所身份，因此它仅用于定位待核验日期，不足以生成 `OFFICIAL_SUSPENSION=0`。

Tushare `dividend` 提供实施进度、实施公告日、除权除息日、每股送转和现金分红字段。只有实施公告日严格早于除权日、条款完整、重复记录不冲突，并且理论除权参考价与 `daily.pre_close` 对得上的记录，才可进入已解决公司行动账本。

Tushare `adj_factor` 是供应商自行生产的复权因子，且当前历史值不被假设为不可修订。它只能触发公司行动候选和交叉核对，不得用于直接生成 V2 成分收益或后复权价格。

## 3. 四态的证据边界

### `TRADED_VALID`

必须同时满足：当日未复权行情存在；`close/pre_close` 与 `pct_chg` 恒等式通过；公司行动被明确判定为无行动或已解决；前一有效未复权收盘价存在。

### `OFFICIAL_SUSPENSION`

必须有交易所官方停牌证据，并且公司行动已经核对，才允许收益为 0。当前附录没有准入交易所级历史停牌源，因此供应商 `suspend_d` 命中仍不能进入这一状态。

### `CORPORATE_ACTION_UNRESOLVED`

出现除权参考价变化，但没有可用且可得时间合格的实施条款；条款重复冲突；缺少配股/认购现金流；或理论除权参考价无法与行情字段对齐时，收益保持缺失。

### `SUPPLIER_MISSING_OR_CONFLICT`

行情缺行、价格字段缺失、供应商内部恒等式失败、跨来源冲突、首次观察缺少前收盘价，均进入此状态。不得填 0。

## 4. 公司行动财富恒等式

所有金额按行动前每股计：

```text
期末财富 = 未复权收盘价 × 行动后/行动前股数比
         + 税前现金分配
         - 认购现金流出

日总股东收益 = 期末财富 / 前一有效未复权收盘价 - 1
```

理论除权参考价按分为单位四舍五入，并与 `daily.pre_close` 比较。绝对容差冻结为 0.011 元。当前 `dividend` 契约不提供配股认购条款，所以任何需要认购现金流的日期都失败关闭为未解决公司行动。

## 5. 新成分历史窗口

新纳入成分在纳入前已经公开的自身行情可以用于其 20 日个体收益窗口，但不得把它倒填为当时的指数成员。共同运动的同伴组合始终由每个历史交易日真实的点时成员组成；保守基线要求新成分纳入后至少积累 15 个有效成员交易日，才进入共同运动可评分集合。
