# 510300单标的五年低成本研究规范

## 1. 研究范围

本项目只研究华泰柏瑞沪深300ETF（510300）作为实际交易标的，历史数据范围固定为最近五个日历年：

- 计划起始日期：2021-08-12
- 计划结束日期：2026-08-12
- 实际首个和最后一个日期：以数据源返回的有效交易日为准

H00300沪深300全收益指数只作为业绩比较基准，不进入Alpha信号。沪深300价格指数、指数估值、成分股、权重、广度及IF基差均不再是当前辅助研究对象。

当前因子研究只保留四条510300自身轨道：

- 日线/多日择时：510300自身的趋势、波动率、价格与普通价量状态；
- 15分钟独立日内Alpha：三柱价格不平衡（FVG数学定义）、VWAP和分时状态；
- 1分钟执行优化：只在已有明确交易任务后研究；
- 基金一级/二级市场联动：单位净值、IOPV、折溢价、基金份额、申赎与510300自身融资状态。

日内Alpha研究不必等待日线策略成功，但不能自动转化为违反510300 T+1约束的日内买卖策略。第一轮不购买全量历史Level-2，不接入自动下单。

## 2. 研究目标

验证以下问题：

1. 510300的收益主要来自隔夜还是盘中；
2. 简单择时是否能在扣除交易成本后改善风险收益比；
3. 510300自身的净值折溢价、份额变化、趋势和波动率是否分别提供稳定的增量信息；
4. 分钟级信号既可作为独立日内Alpha事件研究，也可在方向模型成立后用于改善执行，两者必须分开评价。

## 3. 成功标准

只有同时满足以下条件，才进入纸面交易：

- 原始数据可重复获取并通过质量审计；
- 回测严格执行T+1、交易单位、手续费和滑点；
- 策略在滚动样本外测试中仍有稳定表现；
- 结果不依赖单一年份、单一参数或单一数据源；
- 相对510300买入持有有清晰的风险控制或风险调整收益改善；
- 纸面交易与回测的成交和收益差异可解释。

## 4. 研究顺序

1. 固定规范和数据字典；
2. 建立原始数据仓库；
3. 做数据质量审计；
4. 做510300收益结构研究；
5. 建立买入持有和简单择时基准；
6. 先冻结Target，再预注册因子、变换、窗口、方向和目标周期；
7. 用时间序列检验、非重叠样本、HAC/Newey-West、区块Bootstrap和统一成本回测筛选因子；
8. 分轨研究510300净值折溢价、份额变化、趋势、波动率、普通价量和FVG，不直接合成总分；
9. 补齐510300点时单位净值、IOPV与基金份额，并审计实际发布时间；
10. 获得510300真实Level-2并冻结数学定义后研究PV/LC；
11. 候选冻结后的新数据才算真正前向样本；
12. 纸面交易通过门槛后再考虑小额实盘。

历史点时权重尚未到位，但Weighted Breadth处理器和数据合同已经准备完成。处理器只产生中性特征，不预设方向；行业、市值信息必须带不晚于信号日的`asof_date`，当前快照禁止回填历史。Tushare历史权重接口使用`399300.SZ`，需要有效Token及至少2000积分。

## 5. 不允许的做法

- 用未来数据生成当前信号；
- 使用同一根K线收盘价生成信号并在同一收盘价成交；
- 忽略510300的T+1约束；
- 没有真实Level-2时用K线伪造PV/LC；
- 用供应商加工指标替代原始数据；
- 为了得到更好结果反复挑选回测区间和参数；
- 在数据质量失败时继续使用高频特征。
