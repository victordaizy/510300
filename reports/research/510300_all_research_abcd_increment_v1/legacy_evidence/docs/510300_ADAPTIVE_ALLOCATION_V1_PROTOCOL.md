# 510300 条件切换与滚动模型研究：预先规定的第一轮方案

## 目标与读数

目标为完整账户、基础费用后的年化夏普率达到 1.2。另行报告费用加倍压力、相对买入持有的年化超额、分阶段表现、回撤和不确定性；这些指标不与夏普率混为一谈。现金收益按零计算。所有旧历史已被研究过，本次为严格按时间推进的历史重放，不宣称独立样本验证。

主方案是“过去两年筛选三种策略，再合成一个账户”。预先固定 24 个底层策略：12 个可解释规则、12 个机器学习模型。另比较过去一年选三种、过去两年选一种、24 种固定等权三个组合。不根据本轮结果追加参数，不按每段事后赢家拼接。主方案和事后最好候选分别报告。

## 数据、时间与实际账户

使用已有核验的 510300 未复权日线，2012 年 5 月 28 日至 2026 年 8 月 14 日；14 次现金分红及交易日历由现有记录提供。特征需要最多 252 日历史。2015 年起建立各底层策略的影子账户，2020 年首个交易日起以新账户进行统一评价，终点固定在 2026 年 8 月 14 日开盘，并计入退出费用。影子账户只为当时可见的历史选择提供资料。

初始资金 20 万元，每次买卖为 100 份整手。只做多、不借钱，未投入部分留在现金。使用前一交易日收盘信息确定次日固定份额，次日开盘只进行成交与资金裁剪，不回头修改信号。当日买入份额不允许当日卖出。分红在登记日确定权益、除息日确认应收、支付日进入现金；应收分红不允许提前买入。

基础费用：双边分别收取万分之二佣金、每笔最低 5 元，买卖分别计 5 个基点滑点。压力费用：佣金万分之四、最低 5 元，单边 10 个基点滑点。成交价格按 0.001 元最小价位向不利方向取整；方向性涨跌停限制不能成交。现金参考利率假定为零，夏普按 242 个交易日年化。期末未能清仓必须单独披露，不删除该账户。

## 所有因子如何计算

价格趋势使用从过去向前累积的含分红财富指数：当日收盘价加当日除息金额，除以前日收盘价，再逐日累乘。这样未来分红不会改写以前信号。它只用于观察价格变化；实际账户单独处理分红权益。

| 因子组 | 中文定义与使用窗口 |
| --- | --- |
| 动量 | 过去 1、2、5、10、20、60、120、252 个交易日含分红对数收益之和 |
| 均线偏离 | 当日财富指数与过去 5、20、60、120、200 日平均值的比值减一 |
| 波动率 | 过去 5、20、60 日含分红日收益的标准差，乘以 242 的平方根 |
| 下行波动 | 把上涨日收益记作零后，过去 20、60 日平方收益均值的平方根，再乘以 242 的平方根 |
| 阶段回撤 | 当前财富指数相对于过去 20、60、120 日最高值的跌幅 |
| 日内与隔夜 | 当日开盘加除息现金相对前收盘的对数变化，以及收盘加除息现金相对开盘加除息现金的对数变化；分别保留单日值、5 日及 20 日累计值 |
| 日内振幅与收盘位置 | 最高价减最低价除以前收盘；收盘在当日高低区间的位置，零振幅日定义为中点 |
| 成交量变化 | 当日成交份额除以过去 20 日平均成交份额，取对数 |
| 趋势效率 | 过去 20 日财富变化绝对值，除以这 20 日逐日财富变化绝对值之和；没有变化时为零 |
| 两日强弱指标 | 两日上涨幅度总和占两日上涨及下跌幅度绝对值总和的百分比；没有变化时为 50 |
| 二十日标准化偏离 | 财富指数减去 20 日均值，再除以同窗口标准差；没有变化时为零 |
| 波动比 | 20 日波动率除以 60 日波动率，分母仅作数值稳定性保护 |

## 12 个规则策略

所有规则均在收盘形成目标，下一开盘执行；普通再平衡须与当前仓位相差至少 10 个百分点，归零和由零进入不受该限制。

| 策略 | 完整中文规则 |
| --- | --- |
| 六十日趋势 | 财富指数高于 60 日均线时满仓，否则现金 |
| 一百二十日趋势 | 财富指数高于 120 日均线时满仓，否则现金 |
| 二百日趋势 | 财富指数高于 200 日均线时满仓，否则现金 |
| 二十日动量 | 过去 20 日含分红收益为正时满仓，否则现金 |
| 六十日动量 | 过去 60 日含分红收益为正时满仓，否则现金 |
| 一百二十日动量 | 过去 120 日含分红收益为正时满仓，否则现金 |
| 三周期趋势投票 | 分别判断是否高于 20、60、120 日均线，每满足一项分配三分之一仓位 |
| 六十日突破 | 财富指数突破此前 60 日最高值后满仓持有，跌破此前 20 日最低值后转现金；两者都未出现时维持之前目标 |
| 两日超跌反弹 | 两日强弱指标低于 10 时满仓，高于 70 时转现金，中间状态维持之前目标 |
| 上涨趋势中的超跌反弹 | 高于 200 日均线且两日强弱指标低于 20 时满仓；指标高于 70 或跌到 200 日均线以下时现金；其他时候维持之前目标 |
| 趋势与震荡切换 | 20 日趋势效率高于 0.3 时，按是否高于 20 日均线决定满仓或现金；效率不高于 0.3 时，20 日标准化偏离低于负 1 买入，高于零卖出，其他时候维持之前目标 |
| 风险约束趋势投票 | 三周期趋势投票仓位再乘以“15% 除以 60 日年化波动率”和 1 中的较小值 |

## 12 个滚动训练模型

三种算法、两种预测期限、两种训练范围构成 12 个模型，参数不随本轮结果改变。

- 算法一：岭回归。各因子按当时训练样本的均值和标准差标准化，惩罚强度为 100。
- 算法二：浅层直方图梯度提升回归。80 轮、学习率 0.05、每棵树最多 7 个叶节点、每叶至少 60 个样本、正则化强度 10，禁止使用随机内部提前停止。
- 算法三：极随机树回归。96 棵树、最大深度 3、每叶至少 40 个样本，每次分裂考察四分之三因子，不进行自助抽样。
- 预测期限：下一开盘买入、5 或 20 个交易日后的开盘卖出的含权益总收益。除息日才买入不能取得前一登记日分红。
- 训练范围：使用此前全部可用训练样本，或只使用此前最近 756 个交易日的起点；至少需要 300 个已成熟样本。
- 训练日：2015 年起每季度首次决策收盘，整个季度使用该次模型。只能使用退出开盘已发生的样本；标签跨过训练时点的样本一律排除。模型的标准化参数也仅在训练资料上拟合。
- 仓位决策：从保持现有份额及零、四分之一、二分之一、四分之三、满仓中选择。按预测收益，减去固定风险厌恶系数 4 对持有期方差的惩罚，再减去本次调整的估计费用，取净效用最大者。同分优先不交易。持有期方差用过去 60 日日收益方差乘以预测期限。5 日预测每 5 日决策，20 日预测每 20 日决策。

## 四个组合方案

每个费用情景都为底层策略保存从 2015 年开始连续运行的影子账户。每季度在首次决策收盘，使用截至当日的过去 504 个交易日完整账户净收益，计算各策略夏普；只有该段平均收益为正、波动率非零的候选可以入选。选择排名前三者等权合成目标，若只有一或两种合格则在这些策略间等权；没有合格策略则持有现金。并列按固定策略名称排序。季度中每 5 个交易日按已选策略当日收盘目标的平均值调整主账户，不拼接影子净值，不沿用影子账户资金。

上述为主方案。三个预先规定的比较方案为：同规则只选第一名；把选择窗口改为 252 日并选前三；24 个底层策略始终等权。比较方案的优劣不自动改变主方案身份。

## 检查与结论边界

每个底层策略和每个组合都实际计算完整账户，输出每日现金、份额、应收、收益、费用、交易与决策。输出基础及压力费用下的全年和分年度指标；2020—2021、2022—2023、2024—终点分段使用同一连续账户的切片。用 20 日循环区块、2,000 次重抽样计算主方案夏普与年化日均超额的 95% 区间，不把该区间当作重复搜索校正。

还要报告所有 28 个候选中的事后最好者，并明确它是选后结果。过往试验总数无法准确还原时，不虚构“已完全校正多重试验”的显著性。全现金导致夏普无定义时写“无定义”，不能记为零或达标。所有方案未达目标，则保存完整失败证据，下一轮必须提出新的可检验机制；不能静默改本方案窗口或费用。
