# 沪深300基本面反应不足官方财务事实 V1

## 任务边界

本程序只为 `CSI300_PIT_FUNDAMENTAL_UNDERREACTION_ENHANCEMENT_V1` 构建公告当时可核对的财务事实。它读取无收益目标事件清单、官方定期报告事件档案和 `static.cninfo.com.cn` 原始 PDF；不读取价格、未来收益或未来标签，不计算分数、IC、分组收益、组合、夏普、仓位或订单。

现有 2026 年统一回取的供应商财务数值不能证明历史 vintage，因此不进入事实库。每个入库金额都必须在对应证券—报告期首份时序有效的官方原始完整定期报告中找到页码、行标签、当前期原始数值和单位，并绑定完整 PDF SHA-256。

## 目标与依赖

主预检确定了 8,223 个非金融沪深300目标事件。每个目标事件固定要求当前报告及之前 8 个标准季度，共 9 个报告期；这足以构造单季度同比加速度、最近三期连续性、当前与上年可比 TTM 以及资产平均值。相同公告只下载、解析一次。依赖报告发布日期晚于目标公告时视为不可用，不能以后来报告回填。

## 唯一事实口径

只接受合并口径人民币绝对金额：累计营业收入、累计营业利润、累计归母净利润、累计扣非归母净利润、累计经营现金流、期末应收账款、期末存货、期末总资产和期末总负债。

解析器先定位“合并资产负债表”“合并利润表”“合并现金流量表”及旧版“合并及公司”同表标题，再按固定行标签读取合并口径当前期金额；紧邻标签的三位以内纯整数附注号会被跳过。Q3 利润表若同时明确列示 7—9 月单季列与 1—9 月累计列，营业收入、营业利润和归母净利润固定读取第三个金额，即本年累计值；只有累计两列时读取第一个金额。Q3 的扣非归母净利润在主要财务数据表同时列示“本报告期”和“年初至报告期末”时读取第二个非百分比金额；旧版主要财务数据表若只列年初至今与上年同期，则读取第一个金额。两种情形都必须有明确的年初至今表头，禁止把单季值或上年同期值误作本期累计值。当前金额单元格明确为独立横线时按零值入库；线性文本中的空白或不能确认列位置的横线不得推断为零。唯一例外是合并资产负债表的官方表格坐标同时满足：行标签精确为“存货”、标签后的当前期与上期金额单元格全部明确为空、页面单位唯一；此时按零值入库并保存页码、表号、行号和完整单元格证据。任一金额格出现数字、横线或其他字符，仍保留缺失。旧准则报表若只在资产负债表列示“应收票据及应收账款”，禁止把合计值冒充应收账款，必须转到同一 PDF 的合并财务报表附注提取纯应收账款，否则保留 `NO_VIEW`。单位只允许元、千元、万元、百万元和亿元，并兼容“金额单位为人民币百万元”等旧版明确表述；单位不唯一、标签歧义、合并表缺失或任一必需指标缺失时，该报告保留 `NO_VIEW`。

若事件档案中的首个同日报告 PDF 不含完整财务报表，采集器只允许查询同一证券、同一报告期、同一官方发布日期的巨潮同事件 PDF。候选仍须排除摘要、取消、更正、修订、英文等版本；逐份按固定解析器验证，选择官方时间戳与公告 ID 顺序中首份九项完整的 PDF，并同时保存原事件公告 ID、实际 PDF 公告 ID、URL 与哈希。不得跨发布日期寻找后来版本，也不得因未来收益选择文件。

## 检查点与覆盖门

完整 PDF 不长期保留；永久保存 PDF 哈希、文件字节数、页数、九项事实、证据片段和解析状态的原子 gzip JSON 检查点。解析版本不变时复用成功或事实不完整的检查点；网络失败可在下一轮重试，不能把失败静默改成零值。

只有目标事件完整依赖覆盖率达到 90%、每个公告年度达到 80%、每个至少 50 个目标事件的行业达到 75%，才输出 `PASS_OFFICIAL_PDF_VERIFIED_PIT_FINANCIAL_FACTS_V1`。低于门槛时仍交付事实与缺口账本，但收益评价继续为 `NOT_ALLOWED`，不得根据缺失或未来收益修改字段、样本、行业或门槛。
