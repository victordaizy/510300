# 510300 点时板块未来收益数据可行性 V1

状态：`DATA_FEASIBILITY_ONLY`  
未来收益读取：`FORBIDDEN`  
预测模型拟合：`FORBIDDEN`  
仓位映射、订单、券商：`DISABLED`

## 1. 目的

本阶段只证明能否在每个月度官方权重快照日，构造当时真实可得的中信一级板块估值与盈利截面。它不评价任何板块未来收益，也不选择模型、特征或阈值。

## 2. 点时拼接

每个快照日只允许使用：

- 当日官方沪深300成分与权重；
- 当日成分股未复权收盘价；
- `available_at <= 快照日` 的最新公司财务版本；
- `in_date <= 快照日 < out_date` 的中信一级行业；
- 真实公告后的财务更正可以从更正日开始生效，不得回写更正日前历史。

公司级 TTM 盈利、收入、ROE、同比增长和每股净资产沿用已经测试的点时基本面口径。板块聚合使用官方指数权重，不用当前市值或当前行业重写历史。

## 3. 板块特征

每个板块至少输出：指数权重、成分数、价格/行业/盈利/净资产/ROE/增长覆盖率、权重加权盈利收益率、账面收益率、ROE、盈利增长、收入增长，以及盈利公司总市值口径 PE。

板块是否可用于未来预测只由数据覆盖决定，不由未来收益决定。

## 4. 冻结数据门槛

- 月度快照不少于72个；
- 对60交易日目标至少形成24个互不重叠的潜在时间块；
- 每期成员恰为300；
- 每期权重和在98%至102%；
- 全指数价格权重覆盖不低于99%；
- 行业权重覆盖不低于95%；
- 盈利、净资产和ROE权重覆盖分别不低于90%；
- 单板块至少2只成分，核心特征覆盖不低于80%才是数据合格板块；
- 每期数据合格板块覆盖的指数权重不低于90%。

任一快照失败时输出 `NO_VIEW` 及精确失败类别。只有全部窗口层门槛通过，才允许另建板块未来收益预测协议。

## 5. 治理

本阶段不得读取未来20/60日收益、不得拟合回归、不得做IC、不得搜索特征组合。数据通过只表示 `READY_FOR_TARGET_FREEZE`，不表示存在预测能力。
