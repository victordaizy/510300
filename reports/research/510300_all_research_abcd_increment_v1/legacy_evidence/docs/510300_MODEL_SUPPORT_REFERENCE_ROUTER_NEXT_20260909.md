# 下一项：按退出模型当时是否具备训练支持选择已保存策略

第138轮对最终目标设普通波动上限，主基础及压力夏普降至1.093和1.040，较早0.789和0.802。四条账户的持股日期和周期边界与137完全相同；主仅29个目标触及上限，后续资金和股数变化仍让基础净利少16637.55元。较早回撤下降，但夏普仅小幅提高，三项整段年化收益低于买入持有。本次上限设定结束，不调整风险水平救回。

第139轮检验另一种有明确信息依据的条件选择：在退出学习尚未满足原训练支持时使用131普通波动乘数策略；具备成熟训练记录时使用137合成下行预算。使用原114的月度模型记录判断，零新训练。记录已经用于128、131和132的底层退出逻辑，不引入估值或EPS资料。

每天收盘后15:05做研究判断，只读取当时已经形成的最近一条原模型记录。原记录的拟合日期、15:05拟合时点和最近训练周期退出日都必须不晚于判断。最近记录为拟合完成、模型非空，且仍满足原至少十个已结束周期、一百行状态、无缺失训练因素等完整性要求，才选择137；没有记录或最近记录明确支持不足，选择131。未知或损坏的记录不自行判成熟。原拟合时间是历史研究设定，不能当作真实当年运行证据。

两费用使用同一份训练支持状态，但被选目标读取各自费用目录。选择131时也保留它原来的128参考、原价格保护和普通波动乘数；选择137时保留它的两个父来源和月度下行预算。不重置任何参考持仓、周期、锁定模型或已确认盈亏。所选父目标未知则组合目标未知，不替换另一父，也不当作现金。

实际账户每天按所选目标、自身净值和100份整手在下一开盘执行；正目标可进入，持仓按原十个百分点带宽增减，零目标全退，未知无新调整，每个收盘重算请求，卖完后正目标可再进入，末日开盘优先清仓。规则从首次准备收盘就执行，不挑起点、不按事后年份切换。

已观察的原141条模型记录中，27条支持不足、114条拟合完成，首次成熟记录为2017年3月1日15:05。因此此历史样本主要检验一次训练准备阶段到成熟阶段的转换，不能将结果夸大成已证明反复识别牛熊环境。我们是在见过历史后提出这个条件选择，仍是选择后研究；即便改善也不算独立验证。
