# 510300 压力传导危险率 V2：四态历史账本执行 V1

## 1. 执行目的

本执行包只把已经通过有界探测的来源扩展到点时成分所需的历史范围，并构造成分收益四态与日度覆盖账本。它不训练模型，不选择概率门，不计算策略净值，也不生成仓位或订单。

## 2. 有界采集范围

- 点时成员母表：2015-01-05 至 2026-08-14，共 668 个历史证券身份、每日 300 个成员；
- 旧日线种子：只重验未复权 OHLC、`pre_close`、`pct_chg`、成交量和成交额，禁止读取旧 `total_return_*`、链接复权因子和停牌标记；
- 新日线：仅查询 2019-12-01 以后曾属于点时成分的 493 个证券，截止 2026-08-14；
- 公司行动：先由 `daily.pre_close` 与前一有效未复权收盘价的差异定位候选证券，再只查询这些证券的 `dividend`；
- 不批量查询 `suspend_d`，因为它不是交易所官方证据，无法改变四态结果；
- 不批量查询 `adj_factor`，因为当日日线字段已能定位行动候选，而且复权因子不允许直接生成收益。

采集最多使用 2 个工作线程，每个请求至少间隔 0.5 秒，逐证券落不可覆盖的断点文件。失败后可以复用已经验证的断点，但不能覆盖。

## 3. 日线准入

每个观测必须满足：

- 证券日期键唯一；
- 未复权 OHLC 和 `pre_close` 为有限正数；
- 成交量、成交额为有限非负数；
- 高低价包络开收盘价；
- `(close/pre_close-1)*100` 与 `pct_chg` 的绝对差不超过 0.011 个百分点。

旧种子与新日线的重叠区由新日线优先；任一价格差超过 0.011 元或涨跌幅差超过 0.011 个百分点，该证券日进入供应商冲突态，不得产生收益。

## 4. 公司行动对账

若 `daily.pre_close` 与同证券前一有效未复权收盘价相差超过 0.011 元，该日是公司行动候选。只有以下条件全部满足才标记 `RESOLVED`：

1. 恰有一组不冲突的已实施条款，且 `ex_date` 等于当前行情日；
2. `imp_ann_date` 严格早于 `ex_date`；
3. `stk_div` 与 `cash_div_tax` 为有限非负值；
4. 以 `1 + stk_div` 为行动后/行动前股数比；
5. 理论除权参考价按分四舍五入后，与 `daily.pre_close` 相差不超过 0.011 元。

配股认购现金流在当前来源中不可得，因此相关候选一律保持 `CORPORATE_ACTION_UNRESOLVED`。停牌区间中发生多项行动但无法逐项复原时也失败关闭。

## 5. 四态与覆盖

- `TRADED_VALID`：日线和公司行动均通过；
- `OFFICIAL_SUSPENSION`：当前没有准入交易所官方历史源，预期数量为 0；
- `CORPORATE_ACTION_UNRESOLVED`：行动候选无法完整对账；
- `SUPPLIER_MISSING_OR_CONFLICT`：缺行、首次观察、行情恒等式失败或跨来源冲突。

缺失成员可以在日度可用成员比例达到 98% 时被排除，但绝不填 0；低于 98% 的日期进入 `NO_VIEW`。新成分纳入前公开的自身行情可用于其个体窗口，但指数成员身份不得向历史倒填。

## 6. 停止门

四态账本构建后，只报告字段、状态数量、覆盖比例、`NO_VIEW` 日期和对账失败原因。任何 AUC、未来收益、夏普、回撤、净值、仓位与订单仍为 `NOT_ALLOWED`。

本执行包只做约定的数据结构与研究逻辑核验，不进行安全、隐私、恶意软件、密钥或全仓审计。
