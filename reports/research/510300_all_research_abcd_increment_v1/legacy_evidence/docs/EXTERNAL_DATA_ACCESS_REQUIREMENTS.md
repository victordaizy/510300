# 外部许可数据接入要求

审计日期：2026-08-16  
范围：510300尾部风险门控研究，仅限研究与模拟，不连接券商、不生成订单。

## 已通过公开来源解决的缺口

1. 申万点时行业：按申万一级行业拆分调用 `index_member_all`，沪深300成员日覆盖率达到99.667%，区间重叠为0，已通过冻结协议99%门槛。
2. 已到期合约残留五档：取得362个合约的最后五档行情，其中2026年已到期合约覆盖280/280；该数据不是逐日历史。
3. 合约最后五日分钟成交：取得全部2,874个510300期权合约的3,432,883条分钟记录；该数据没有买卖盘字段，也不是连续全历史。

## 缺口一：510300期权历史收盘盘口

目标文件：`data/raw/return_tail/options/510300_eod_chain.parquet`

必须由获得交易所授权的历史Level-1/Level-2或Tick数据交付生成，时间范围为2019-12-23至2026-08-14。至少包含：

- `trade_date`
- `contract_code`
- `option_type`
- `expiry_date`
- `strike`
- `contract_unit`
- `contract_status`
- `is_adjusted`
- `bid1`
- `ask1`
- `close`
- `volume`
- `open_interest`
- `underlying_close`
- `quote_timestamp`
- `source`

验收条件：交易日覆盖不低于98%，必要字段空值率不超过1%，倒挂报价比例不超过0.1%，且调整合约和退市合约不得被幸存者筛选删除。

当前公开日线、风险指标和新浪分钟端点均不提供历史买卖一档。可行来源是上交所授权行情产品或具备上交所历史期权Tick许可的数据商。未取得许可前，不得用收盘价、理论价、估计价差或最后一笔残留盘口合成该文件。

## 缺口二：不可变的一致预期历史vintage

目标文件：`data/raw/return_tail/earnings/csi300_consensus_vintages.parquet`

必须是供应商逐日或逐事件保存的历史快照，至少包含：

- `asof_timestamp`
- `con_code`
- `forecast_fiscal_year`
- `consensus_eps`
- `analyst_count`
- `dispersion`
- `source`
- `source_vintage_id`

验收条件：覆盖不少于1,210个交易日；`asof_timestamp`和预测发布日期能够证明当时可得；交付文件或批次应有不可变供应商ID及文件哈希。

现有581,309条 `report_rc` 单篇研报记录是在当前数据库中回溯取得，其中37.07%的记录创建时间比报告日期晚30天以上，不能证明过去某日数据库中实际可见的完整集合。因此不得用这些记录重建后冒充真实供应商vintage。

可行来源是包含历史盈利预测快照的数据许可，例如Wind盈利预测历史或通联/优矿一致预期加购数据。接入前必须确认交付包含上述时间和vintage字段；只有“当前一致预期”或单篇研报明细仍不合格。

## 接入后的固定动作

1. 将原始许可数据只读保存，并记录供应商、许可范围、交付时间和SHA-256。
2. 通过独立转换脚本生成目标Parquet，不手工修改历史记录。
3. 运行 `scripts/audit_return_tail_gating_data.py`。
4. 只有分支状态明确为 `PASS` 后，才允许执行该分支预注册的原始预测检验。
5. 当前E1已经按首轮停止条件终止；即使以后采购到数据，也必须建立新的独立接入协议，不能静默恢复首轮E1。
