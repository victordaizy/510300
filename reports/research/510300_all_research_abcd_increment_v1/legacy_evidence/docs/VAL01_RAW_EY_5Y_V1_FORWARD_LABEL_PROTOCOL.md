# VAL01_RAW_EY_5Y_V1 未来收益标签与预测屏幕协议

状态：`RESEARCH_ONLY / HISTORICALLY_CONTAMINATED`  
版本：`1.0.0`  
协议日：`2026-08-19`  
数据截止：`2026-08-12`  
历史仓位、当前仓位、份额、订单和券商连接：`全部禁用`

## 1. 本阶段目的和物理隔离

本阶段只检验已冻结的`raw_ey_percentile_60m`是否与随后可交易的510300含分红收益同向，并用H00300全收益作独立确认。未来收益标签表与信号输入表物理分离：标签表只保存观察日、期限、入场、到期、成熟状态和收益，不保存EY或分位值。统计程序运行时才以内存连接两表，报告只输出聚合统计。

本阶段不计算任何历史仓位路径、策略净值、目标份额、当前建议或订单。主要预测屏幕失败时正式停止，不允许用仓位回测掩盖预测关系失败。

## 2. T+1可捕获标签

每个信号只在月度快照日收盘后可得。入场日固定为观察日之后第一个同时存在510300、000300和H00300数据的共同交易日，入场价格为510300当日未复权开盘价。入场日计为第1个持有交易日，第`H`个持有交易日收盘为到期点：

```text
EntryDate = first common trading date strictly after SignalDate
MaturityIndex = EntryIndex + H - 1
H ∈ {60, 120, 242}
```

这排除了信号日收盘至次日开盘不可捕获区间，也避免常见的期限差一日错误。

## 3. 510300含分红收益

入场日从开盘持有到收盘，不享有入场日恰逢除息日的分红；以后每个交易日使用：

```text
EntryFactor = Close_entry / Open_entry
DailyTotalReturnFactor_t = (Close_t + CashDividendPerShare_t) / Close_t-1
ETF_Total_Return_H = EntryFactor × Π DailyTotalReturnFactor_t - 1
```

现金分红在除息日进入总回报并按当日收盘价隐含复投。标签另报不含分红的`ExitClose / EntryOpen - 1`及两者之差。预测标签不扣佣金和滑点；成本只属于未来获准的策略执行层。

## 4. H00300全收益标签

H00300只有收盘序列，因此沿用统一模型层已经冻结的合成全收益OHLC规则：

```text
SyntheticTRI_Open_t = H00300_Close_t × 000300_Open_t / 000300_Close_t
H00300_Total_Return_H = H00300_Close_maturity / SyntheticTRI_Open_entry - 1
```

合成收盘必须与H00300收盘在浮点误差内完全一致。H00300独有而510300/000300没有的日期不进入共同交易日历，并必须在审计报告中披露。

## 5. 成熟与右删失

统一数据截止日为`2026-08-12`，不得因为本地文件后来延长到8月18日而移动评价边界。到截止日不足`H`个共同交易日的记录只标记`RIGHT_CENSORED_DATA_CUTOFF`，其收益字段保持缺失，禁止缩短期限或使用未到期部分收益。

在只检查日历、不查看收益后预先确定：61个有效信号中，60/120/242日应分别成熟58/55/49个，右删失3/6/12个。

## 6. 冻结统计口径

主要目标唯一固定为242交易日510300含分红毛收益；60和120日只作辅助诊断，不可在看到结果后升级为主要目标。

每个期限分别报告510300与H00300的：

1. Spearman IC，平均秩处理并列；
2. 成熟样本前后半段IC；
3. 使用冻结边界`[0,.2)、[.2,.4)、[.4,.6)、[.6,1]`的样本数、均值、中位数和正收益比例；
4. 最高分位档减最低分位档的均值和中位数差；
5. 对`rank(return)`回归`rank(percentile)`的Newey-West HAC斜率、t值和单侧正向p值。

收益窗口高度重叠，普通独立样本p值无效。HAC月度最大滞后固定为60/120/242日对应2/5/12个月，Bartlett核，不做结果后调整。

## 7. 242日主要预测硬门槛

以下条件必须全部满足：

- 510300成熟样本不少于36；
- 四个冻结分档各不少于5个样本；
- 510300 Spearman IC严格大于0，HAC单侧`p≤0.10`；
- 成熟样本的前后半段IC都严格大于0；
- 四档平均收益随分位非递减；
- 最高档减最低档的平均收益和中位收益都严格大于0；
- H00300的Spearman IC和最高档减最低档平均收益都严格大于0。

全部通过时只能得到`HISTORICAL_PREDICTIVE_SCREEN_PASS_STRATEGY_EVALUATION_NOT_RUN`；任一失败即得到`REJECT_PREDICTIVE_SCREEN_STOP_NO_STRATEGY_BACKTEST`。由于全部记录来自事后历史重建，两种状态都不能成为`ALPHA_PASS`。

## 8. 禁止的结果后操作

禁止把60/120日改为主要期限、改分档边界、删除亏损或陈旧价格月份、使用信号日收盘入场、只报告表现更好的收益来源，或在主要屏幕失败后直接运行仓位回测。任何变体必须作为新试验重新登记。
