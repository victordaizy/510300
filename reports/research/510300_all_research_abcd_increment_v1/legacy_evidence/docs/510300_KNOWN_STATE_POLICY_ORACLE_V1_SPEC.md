# 510300 状态已知条件策略 Oracle V1 冻结规范

## 1. 唯一研究问题

本研究只验证一个条件命题：如果上涨、下跌、震荡状态已经被正确且及时告知，在不同状态采用不同动作，能否在完整执行约束下实现净夏普率 1.2。

它不检验如何预测状态。Oracle 明确使用未来信息，因此即使条件命题通过，也不构成历史策略通过、Paper/Shadow 信号或交易授权。

## 2. 三状态 Oracle

从 2015-01-05 开始，以 20 个未来交易日为一个不重叠阶段。每个阶段锚点为信号日 T：

- Oracle 在 T 日收盘时揭示 `H00300[T+20] / H00300[T] - 1`；
- 未来 20 日全收益不低于 +5%：`BULL_TREND`；
- 未来 20 日全收益不高于 -5%：`BEAR_TREND`；
- 其余：`RANGE`；
- 末尾不足 20 个未来交易日的区间标记为 `CENSORED`，保持现金。

固定同时报告 ±3% 和 ±7% 两个稳健性口径，不从三者中选择最好结果。

## 3. 固定策略映射

主映射 `STATE_ROUTER_RANGE_NO_T`：

| 已知状态 | 目标仓位 |
|---|---:|
| `BULL_TREND` | 100% |
| `BEAR_TREND` | 0% |
| `RANGE` | 0% |

对照映射包括：只规避熊市、始终满仓、反向在熊市满仓。震荡做 T 不进入本检验；如果震荡不交易已经达到 1.2，就足以证明“状态已知后的差异化策略映射存在高夏普可行性”。做 T 的增量价值是另一问题，需要完整分钟数据和底仓库存合同。

## 4. 执行合同

- T 日收盘获得 Oracle 状态，T+1 开盘执行；
- 初始资金 20,000 元；
- 100 份整手，只允许 510300 与现金；
- 不透支、不卖空、不加杠杆、不使用衍生品；
- 基准成本：单边佣金 3bp、最低 5 元、单边滑点 5bp；
- 压力成本：佣金相同、单边滑点 10bp；
- 现金收益率为 0；
- 分红按除息日持仓确认应收、支付日转为现金。

## 5. 条件命题通过门

主 ±5% 口径必须同时满足：

- 基准和压力成本净夏普均不低于 1.2；
- 压力成本总收益为正；
- 最大回撤不高于始终满仓的 80%；
- 三个完整状态各不少于 10 个区间。

此外，±3% 和 ±7% 两个稳健性口径的压力成本净夏普也必须都不低于 1.2。

通过时只能写作：`状态完美已知条件下，差异化策略映射具有高夏普可行性`。禁止写作：`已经找到可交易高夏普策略`。

## 6. 两层结论必须分开

```text
LAYER_A_CONDITIONAL_POLICY_VALUE
    假设状态已知，策略映射是否有效？

LAYER_B_STATE_IDENTIFICATION
    现实中能否在不使用未来信息时足够准确地识别状态？
```

本研究只允许 Layer A 得出 PASS/FAIL。Layer B 固定为 `NOT_EVALUATED`。
