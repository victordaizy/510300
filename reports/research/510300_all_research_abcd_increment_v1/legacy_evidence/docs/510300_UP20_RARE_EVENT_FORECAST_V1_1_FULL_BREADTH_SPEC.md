# 510300 UP20 稀有上涨机会预测 V1.1 全期广度覆盖冻结规范

## 1. 研究定位

父版本`510300_UP20_RARE_EVENT_FORECAST_V1`已经正式拒绝：主相位压力净夏普为-0.230，只捕获1/23个UP20区间。该负结果已知且永久保留。

V1.1不是阈值救援，也不是新模型搜索。它只检验一个在V1结果前已经明确存在的数据限制：2015—2019没有成分价格面板，`BREADTH_IGNITION`被固定为中性0。现在本地已有2014—2021个股全收益价格历史，并可与后来修复的官方PIT逐日成员表逐行连接，因此可以隔离检验“早期广度缺失是否解释V1失败”。

## 2. 唯一允许变化

只允许把官方PIT等权广度的可用起点从2020-01-20前移到2015-01-05。以下内容全部继承父版本且禁止变化：

- 四个模块的定义、缩放与符号；
- 三分类符号约束多项Logistic；
- 斜率L2惩罚0.10；
- `pUP≥0.40`、`pDOWN≤0.10`、期望净效用不低于0；
- 压力否决阈值0.80；
- 20日持有期、offset 0—19；
- 510300/现金、T日收盘信号和T+1开盘执行；
- 20,000元、100份整手、基准和压力成本；
- 捕获至少14个UP20、最多1个DOWN20误入、最多10个RANGE20误入；
- 主相位、近期、概率技能及全部20相位夏普门。

## 3. 成员和价格来源边界

成员集合只使用官方修复表：

`000300_daily_pit_membership_20150101_20260814.parquet`

外部面板的`is_index_member`及历史权重全部禁止使用。外部面板只提供`date / con_code / total_return_close`三列价格事实。

外部面板有500条2014-07-01至2014-11-21的空价格，均早于评价起点且与官方PIT当日成员相交为0条。该数量及输入哈希必须写入合同，只允许在原生收益计算前剔除这500条；2015-01-05以后任何空值或非正价格都触发停止。当前面板对应无效价格必须为0条。

早期外部面板覆盖2014-07-01至2021-08-11；当前面板原生覆盖2019-12-23以后。重叠期个股原生日收益必须满足相关系数不低于0.9999、差异99%分位不高于1e-8、至少99%的收益差异不超过1bp。

两个来源的后复权价格绝对尺度可能不同，因此严禁直接拼接价格水平。必须先在各自来源内计算原生一日全收益，再以2021-08-11/12为界选择收益，最后按股票和连续交易段累乘重建归一化全收益价格。MA20只能在该重建序列上计算。

## 4. 因果时钟

所有广度输入只使用T日及以前价格。标签仍为H00300从T到T+20的全收益，只有T+20收盘后成熟。模型在T日只能使用成熟日不晚于T日的历史标签。

冻结前特征文件不得含未来收益、UP20/DOWN20标签、预测概率、目标仓位或策略收益。先完成价格来源兼容性、官方成员覆盖、日收益覆盖、MA20覆盖和特征范围审计，再冻结模型结果计算。

## 5. 停止规则

正式运行只有一次。若任一父版本验收门失败，则状态为：

`REJECTED_FROZEN_UP20_RARE_EVENT_FORECAST_V1_1_FULL_BREADTH_NO_RESCUE`

这将否证“V1主要因为2015—2019广度缺失而失败”的解释。不得再修改广度缩放、概率门、压力线、惩罚、相位或持有期；后续只能建立信息来源正交的新机制候选。

即便全部历史门通过，也只进入独立前向阶段；Paper、Shadow、仓位映射、订单、券商连接和实盘授权仍然关闭。
