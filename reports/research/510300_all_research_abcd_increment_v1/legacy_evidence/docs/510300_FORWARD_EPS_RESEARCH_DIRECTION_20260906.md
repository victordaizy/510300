# 510300研究主线：前瞻每股收益、估值与资金需求

用户已明确“主要看的是前瞻每股收益”。后续以未来盈利预期和预期变化为主线；历史季报、年报及滚动盈利用于解释预测、构建当时可用的输入和检验预测兑现情况，不能把历史盈利直接改名为前瞻盈利。

## 前瞻盈利究竟指什么

优先研究未来十二个月普通股每股收益，同时保存当年、下一年、再下一年的完整会计年度预测。免费券商研报通常提供年度预测；有年度预测不等于已经拥有精确的未来十二个月预测。只有季度预测及同口径股数充分时，才可按未来四季构建；年度预测按剩余月份加权只作为明确标注的近似值，不能掩盖季节性、稀释和股数变化。

用同一目标年度的预测比较上调或下调。例如观察“对2026年每股收益的预期”如何变化，不能把去年的下一年预测与今年的下一年预测直接相减，因为目标年度已经变了。

## 主要因子用中文定义

| 因子 | 中文定义 | 需要防止的误读 |
|---|---|---|
| 预期每股收益水平 | 当时已公开、目标期间一致的普通股每股盈利预测 | 后来真实利润不能提前用作预测；基本、摊薄及调整后收益分开 |
| 预期盈利增长 | 下一目标年度预期每股收益相对当年预期值的变化；两者使用同一时点与口径 | 损益为负或接近零时不用不稳定的增长比率，另列状态 |
| 盈利预期修正 | 同机构、同公司、同目标年度最新预测与此前预测的差额；连续记录齐备后按固定窗口汇总 | 不把年度滚动、机构新增退出、稀释口径改变当作上调 |
| 上调与下调覆盖 | 有效覆盖机构中上调、下调、维持预测的比例，并记录覆盖数 | 一家机构的多份报告不能当成多家机构，一家预测也不是市场一致预期 |
| 预测分歧 | 同一时点、同一目标期间、同一收益口径的机构预测离散程度 | 先去重、去除过期观点，并保留缺失；不能默认分歧越小必然收益越高 |
| 前瞻盈利收益率 | 预期普通股每股盈利除以对应股票价格，或匹配口径的预期普通股利润除以市值 | 低市盈率可能伴随盈利继续下修，需要与修正及质量一起检验 |
| 预期与价格变化 | 比较盈利预期上调与价格、估值倍数变化，研究价格是否已反映新预期 | 以股价倒推盈利再乘回股价的恒等式不能当预测能力 |
| 股东现金回报 | 普通股分红、回购现金及融资摊薄分别记录，并区分计划与实际发生 | 每股收益已反映的股数影响与现金回报不能重复相加；优先股回报不是普通股现金收益 |
| 公募净需求 | 申购减赎回，结合资金实际可投权益的比例、份额变化与净值变化解释 | 基金规模上涨不自动等于资金净流入，净申购也不等于同额立即买入510300 |
| 总量流动性 | 逆回购各期限实际投放、到期及可证明的净变化分别累计 | 只取七天或把操作总额当净投放都会失真；买断式月度汇总另列 |

以上是研究定义，不先指定“满足几项就买入”来宣称有效。连续来源完成后登记有限组合、信息时钟、滚动训练和完整账户成本，再实际检验夏普至少1.2及超额稳定性。旧十轮结果保留，不因解释框架变化就视为达标。

## 免费来源与历史可用时间

优先保存带落款日期的券商原始PDF以及公开页面的机构、证券、预测年度、发布时间和附件地址。当前汇总页可以证明现在有这些预测，不能反推以前每天的预测。公司业绩预告属于公司口径，券商预测属于分析师口径，自建盈利预测属于模型口径，分别记录，不混作同一条一致预期序列。

首批固定五份公开的国信证券平安银行研报进行来源和表格试验。它们由公开搜索定位，摘要和部分数值已经看见，不宣称盲选；不能据此证明完整历史、市场一致预期或有效交易因子。试验保留原文的摊薄每股收益及“按最新总股本计算”注释，不自行替换成财报基本每股收益。

研报落款日与平台日期可能不同，分别保存，取较晚日期作为后续保守时钟依据。真正用于回测前，还需检验元数据覆盖和历史可用性；当前网页保存不是当年不可变快照。网站记录的日期要与原件和附件身份核对，不能只相信文件名年份。

## 已有财报工作的用途与下一步

新增年报事实及普通股利润分解用于发现普通股收益口径和标签偏差；固定一季报、三季报连续原件继续完成，供前瞻盈利模型的解释变量及日后实现值校验。主研究优先级转到历史年度预测、同一年度修正、机构覆盖与前瞻估值，而不是继续单独扩展历史滚动盈利作为主要择时信号。

这十二家金融企业和单家券商样本都不代表沪深300整体。扩展时必须按历史成分与明确权重汇总，记录覆盖比例；不能简单相加公司每股收益或简单平均市盈率。保留只交易510300与人民币现金、免费来源、完整账户成本和不接入券商的现有范围。
