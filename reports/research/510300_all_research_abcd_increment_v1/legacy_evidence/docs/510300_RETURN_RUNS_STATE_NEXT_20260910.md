# 下一项：较强收益与较弱收益是否连续成段

第164轮价格顺序分布完成，四项净夏普均不足一点二。下一项检验收益强弱在时间上是否集中成段，并同时要求总价格动量向上。只使用已有完整日行情，固定一套规则，零模型训练和外部数据。

## 全部因素及口径

1. 每日含分红对数收益：当天收盘价加每份分红，除以前收盘价，再取自然对数。
2. 六十日收益中位数：取包括今天在内的最近六十个完整日对数收益，由小到大排序，第三十与第三十一个值的平均数为中位数。
3. 窗口内强弱分类：用这同一个中位数重新比较窗口内全部六十个收益。高于中位数记为较强，低于中位数记为较弱；保存值精确等于中位数的观察不参与连续段计数。较强可能仍为负收益，较弱也可能仍为正收益，不能把它们称为上涨天数或下跌天数。
4. 实际连续段数：保留强弱分类原有的时间顺序，去掉精确中位数平局后，第一个类别算一段，之后每次强弱类别改变就增加一段。记录较强个数、较弱个数、非平局总数、平局数和实际段数。不删除缺失值凑满六十日。
5. 预期段数：二乘较强个数乘较弱个数，除以非平局总数，再加一。这是在固定两类个数、随机安排顺序的假设下的预期。
6. 段数方差：分子为二乘较强个数乘较弱个数，再乘以“二乘较强个数乘较弱个数，减去非平局总数”；分母为非平局总数的平方，乘以非平局总数减一。至少要有两类且方差大于零，才定义标准化分数。
7. 标准化连续段分数：实际段数减去预期段数，再除以段数方差的平方根。负值表示强弱较集中成段，正值表示强弱切换较频繁。不使用连续性修正，不将它直接称为交易成功概率。
8. 六十日上涨动量：同一完整窗口的六十个含分红对数收益相加。大于零表示这段含分红价格上涨。
9. 三个连续计数：连续段分数严格小于负一且上涨动量严格大于零的联合进入计数；连续段分数大于或等于零的退出计数；上涨动量小于或等于零的退出计数。三个条件分别累计，不满足当天条件即分别清零。
10. 普通风险仓位：最近二十个含分红简单收益的样本标准差乘二百四十二的平方根，得到年化波动。方向允许持有且波动完整大于零时，目标为百分之十除以年化波动，上限百分之百；方向不允许持有时目标为零。

连续段数均值、方差及标准化定义参考[NIST连续段检验说明](https://www.itl.nist.gov/div898/handbook/eda/section3/eda35d.htm)。本轮按收益相对窗口中位数分类，只采用上述描述性分数。负一与零是本轮事先固定的交易门槛，不使用概率或宣称已通过金融收益随机性检验；强弱成段也不等于未来可获利。

## 进入与退出

完整市场日历从不允许持有及三个零计数开始。联合进入条件连续两个收盘成立，转为允许持有；两个退出条件中的任意一个单独连续两个收盘成立，转为不允许持有。不同退出条件交替出现不能凑成两次。其他完整收盘延续原方向，不在实际入场或评价边界重新初始化。

六十日有资料缺失、非平局分类不足两类或段数方差不大于零时，连续段分数未知；当天方向与目标也未知，内部方向和计数清零，完整恢复后重新起步。实际账户在未知目标时保持已有份额，不能把未知补成零。全部六十日收益相同属于统计分数未定义，不人为补成强趋势分数。风险波动缺失或为零只使允许方向的目标未知，不修改完整市场方向。

收盘后决定，下一开盘实际成交。空仓可执行正目标，按上一收盘本账户净资产与原始收盘价计算份额，向下取一百份整手后直接买入。已有持仓且目标为正时，目标比例与实际股票市值占净资产比例差不足十个百分点则保持，达到十个百分点才调至目标中心。零目标及终点开盘优先请求全部清仓。

退出后再次具备允许方向及可执行正目标即可进入，无额外等待期。受阻后下一收盘按最新目标重新决定，未知保持实际份额。不设置学习退出、入场版本锁定、固定止盈止损、最长持有期或每笔退出锁。

## 计算范围与停止条件

建议第165轮，只新增四个完整资金账户，零训练模型、零新增参考账户、零外部来源。对照读取保存的第143轮趋势波动连续预算、第131轮普通波动预算和买入持有，每段两档费用合计两条新账户及六条保存对照。

主历史2020年1月2日至2026年8月14日开盘，较早历史2015年1月5日至2019年12月31日开盘。每账户二十万元，二百四十二日年化，现金及无风险收益零。基础佣金每边万分之二、最低五元、名义滑点万分之五；压力佣金万分之四、最低五元、名义滑点千分之一。保留一百份整手、零点零零一元价位、原百分之十方向限价、次日可卖、真实下一开盘、买入现金约束、分红登记除息到账分开和终点开盘清算。

必要测试覆盖手算连续段数及标准化分数、同样强弱个数但不同排列、精确中位数平局、常数与缺失、严格进入与退出门槛、两个退出分别确认、前缀及未来隔离、普通风险和真实进出场。先测试和完整中文规则，再一次冻结运行四账户。独立核对重新排序求中位数，按逐段分组的另一种算法重算段数与分数，核对实际份额及全部账户损益。

本轮比较收益高于或低于局部中位数的时间连续性；第162轮比较日内隔夜差值的幅度排序，第164轮比较三日价格顺序的频率。原固定方法和失败结论保留。本轮不修改旧门槛或来源，也不在看到结果后改变中位数平局精度、六十日窗口、负一和零门槛或两日确认。完整目标仍为净夏普至少一点二、稳定超额和独立证据；未达标即关闭这一固定结构。此文为第165轮事前方案，尚未实现、测试、冻结或计算新账户。
