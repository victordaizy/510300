# 510300 MACRO-02：AAA信用利差压缩 × 长期趋势确认

## 1. 研究边界

本协议继续执行“抓大放小”：检验国内信用融资条件是否能为510300提供月度级别的风险状态，而不是研究分钟线、局部形态或小样本事件。交易风险资产仍只有`510300.SH`；中债曲线只作为外部状态变量。本研究与现行系统隔离，不生成Paper信号、仓位或订单。

本协议在读取完整信用利差历史与510300未来收益关系之前，于2026-08-19预先固定下述变量、窗口、执行和否证门槛。看到结果后不得改为1年/5年期限、20/126日变化、周频或其他阈值补救。

## 2. 冻结假设

经济机制只有一条：同期限AAA中短期票据相对国债的收益率差收窄，代表企业融资风险溢价和信用条件边际改善；若510300本身也处于长期上升趋势，改善更可能转化为大盘权益可捕捉收益。

冻结定义：

- `CS3Y(t) = [中债中短期票据收益率曲线(AAA,3年) - 中债国债收益率曲线(3年)] × 100`，单位为基点；
- `COMPRESSION63(t) = CS3Y(t-63个曲线观测日) - CS3Y(t)`；数值大于0表示信用利差收窄；
- `TREND200(t) = 510300含现金分红总回报指数(t) > SMA200(t)`；
- `RISK_ON = COMPRESSION63 > 0 且 TREND200 = True`；
- 风险开启目标98.5%，否则25%。

只在每个自然月最后一个同时存在510300行情和中债曲线的交易日形成信号。不得用不同期限、期限插值、滚动均值、分位数阈值或信用等级替代。

## 3. 点时与成交

中债官方说明收益率曲线每个工作日北京时间17:30发布。因此月末日期`t`的曲线只能在收盘后使用，目标在`t`日17:30后形成，于510300下一个交易日开盘成交。评价区间固定为2017-06-30至2026-08-14；最后一个可用完整月度决策日预计为2026-07-31。

回测使用日线，不使用分钟线；执行510300 T+1约束的保守长仓/现金引擎、100份整手、至少5000元成交金额、每笔佣金`max(成交额×0.03%, 5元)`、基础5bp及压力15bp滑点，现金年化1.5%。

## 4. 比较对象

同一起点同时比较：

1. 信用利差压缩与200日趋势同时确认；
2. 仅200日趋势确认；
3. 仅信用利差压缩；
4. 静态60%持仓；
5. 98.5%买入持有。

信用因子必须相对“仅趋势”提供增量，不能把长期趋势效果记到信用利差名下。

## 5. 否证门槛

预测层在`TREND200=True`月份，比较压缩与未压缩状态下一完整月度区间的510300超现金收益。完整区间不少于100期，两组各不少于15期；均值差必须为正，6个月循环区块Bootstrap的95%下界必须大于0；HAC回归中每1bp压缩对应的系数必须为正且单侧`p<=0.05`；两个时间半样本都必须为正。

策略层必须同时满足：基础/压力超现金夏普不低于0.80/0.60；相对静态60%的月度超额盈利因子不低于1.25/1.10；基础夏普至少比仅趋势高0.10；基础和压力CAGR都高于静态60%；三个子期至少两个跑赢静态60%；单一年份正贡献占比不高于50%。

任一门槛失败即`REJECT_DISCOVERY_STOP_NO_RESCUE`。不得在结果后修改期限、63日窗口、200日趋势、暴露、成本、起点或增加过滤器。

## 6. 数据限制与通过后的边界

官方曲线是日终发布，点时规则明确；但本机访问官方历史接口时可能经过未验证TLS的降级传输。正式数据必须通过固定日期官方数值核对，并与既有国债下载批次逐日核对。后者仍是同源核对，不是独立供应商验证。

即使全部门槛通过，也只得到`DISCOVERY_PASS_REQUIRES_INDEPENDENT_SOURCE_VALIDATION`：必须另立协议完成独立来源核对和前向Shadow观察。本版本不连接券商、不下单、不启用仓位映射。
