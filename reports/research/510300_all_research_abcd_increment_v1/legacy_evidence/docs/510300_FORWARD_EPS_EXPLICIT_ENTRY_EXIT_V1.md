# 第十三轮：前瞻EPS的明确进场与退出规则

## 入场、持仓和重新入场

每个自然月最后一个交易日收盘后判断。只有当时的三项前瞻盈利因子均满足原有覆盖要求，且以下三项同时成立，才在下一交易日开盘买入510300：下一年度EPS相对当年度的预期增长为正；同一个目标年度的预测净利润九十日修正为正；510300含分红财富水平高于一百二十日均线。

使用当前可用现金买入整手份额，保留费用所需现金。一次持仓周期内保持原份额，不追加买入；本组退出采用清仓，以便先检验完整进出场规则。入场无法成交时，等待下一次符合条件的月末，不按过期信号每日追买。

卖出之后，至少经过五个交易日，且再次遇到符合上述条件的月末，才允许重新入场。不得因价格反弹立即买回。

## 五项退出条件

持仓后每天收盘检查，只要下面任意一项成立，下一交易日开盘请求卖出全部份额。

| 退出条件 | 明确规则 |
|---|---|
| 入场后亏损退出 | 当前持仓市值加本周期已确认的分红权益，相对本次实际买入总成本下跌达到8%。买入总成本包含成交价格中的滑点与佣金。 |
| 从高点回落退出 | 同一持仓周期的“市值加已确认分红权益”，相对该周期已观察到的最高收盘价值回落达到12%。最高值初始至少为买入总成本，不能用未来高点。 |
| 趋势退出 | 连续两个交易日收盘的含分红财富水平不高于一百二十日均线。 |
| 盈利或月末条件退出 | 到月末有完整有效观点时，原三项入场条件中任一明确不成立。信息缺失保留缺失，不自动解释为看空；每日风险条件与到期规则仍继续生效。 |
| 持有期限退出 | 从实际买入日算起，到第六十个交易日收盘仍未退出，则在下一开盘卖出，即持有六十个开盘到开盘交易间隔。 |

分红按原账户权益登记、除息确认和应收处理，避免除息导致虚假止损。风险规则每天运行，不等待下一月末，也不依赖当天是否出现新EPS报告。

退出一旦触发即进入待成交状态。若下一开盘因跌停、T+1或其他原成交约束未能卖出，后续交易日继续请求退出，直到实际清仓；期间价格恢复也不撤销已触发退出。触发价不是保证成交价，跳空和无法成交可能使实际亏损超过8%。

## 固定对照和完整账户

主方案采用以上全部退出条件。对照复现第十一轮“盈利与趋势同时确认”的原账户，只在月末调整；另保留买入持有。基础和压力费用各三条账户，共六条。主方案的两档新账户完整运行，两个旧对照逐值核对与原记录一致。

固定阈值为8%、12%、六十个交易日、五个交易日冷静期，不做阈值网格或事后选择。原研究20万元、2020年1月2日至2026年8月14日开盘退出、整手、费用、T+1、涨跌停、分红应收和零现金收益口径保持一致。研究只包含510300与现金。

逐笔记录实际买入、退出触发、未成交、实际退出、退出原因、持有天数、分红和费用。同时保存完整日账、年度、三阶段及二十日和六十日区块各两千次区间，检验退出是否减少损失，还是因过早卖出与反复买卖损害收益。
