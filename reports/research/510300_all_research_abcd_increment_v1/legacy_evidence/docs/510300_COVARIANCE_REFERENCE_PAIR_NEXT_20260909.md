# 下一项：两条已保存组合按共同波动分配预算

第135轮的历史夏普择一在四个情景都弱于第132轮及第134轮。核对显示，主基础相对固定各半少赚20818.36元，其中价格及分红收益少21038.30元，费用少219.94元；较早基础少赚9757.58元。过去收益排名没有在本次记录中实现有效的阶段适应。这一月度择一设定结束，不改变窗口、费用或现金门槛救回。

第136轮只登记一个新来源组合，参考固定为132的下行风险目标与91的连续两策略预算目标。沿用82既有两来源最小方差预算公式，用完整的最近242个基础费用账户日收益，在每月首个交易日收盘计算两方方差、协方差及收益差方差；初始各半，第一来源预算为第二来源方差减协方差，再除以收益差方差，限制零至一，另一预算为剩余部分。窗口不足、缺失、任一零波动或收益差零方差，保留无新风险观点及此前预算。月中保持预算，每日乘对应费用的原收盘目标。两目标任一未知则合成目标未知。

该公式在给定协方差估计下最小化两条收益线性组合的方差，并不保证未来最高夏普。实际外层仍要经过整手、带宽、交易成本和自己的资金账本，不能把线性组合收益代替可执行账户。[CVX研究组的组合优化课程](https://www.cvxgrp.org/cvx_short_course/docs/applications/notebooks/portfolio_optimization.html)说明了组合方差、协方差及无卖空预算约束。本轮使用该一般目标的两来源解析解，不增加预期收益拟合。

评分资料只读原基础费用账本中已发生的收盘净收益，首次建账以前保留缺失，末日开盘清仓收益不进入收盘估计。两档费用共用风险预算，但各自使用原对应费用的132与91收盘目标。不存在新的连续参考账本或模型训练；132的入场固定版本与91的连续参考状态保持。
