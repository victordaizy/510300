# 不完整覆盖条件样本分析 V1.0.1 价格字段兼容补充

冻结 V1 后的第一次价格面板检查只读取了 Parquet 架构、行数、文件大小和哈希，没有读取任何价格值或未来收益。检查发现原父协议列出的拆分 H00300 面板只有 `date` 与 `close`，无法机械实现已经冻结的“首个共同交易日开盘至第五个共同交易日收盘”基准反应窗口。

因此在读取任何价格值之前，固定改用已经存在且质量收据为 `PASS` 的 `data/raw/market/H00300_total_return_daily_2015_v2.parquet`。该文件是同一 H00300 沪深300全收益指数，覆盖 2015-01-05 至 2026-08-25，无重复日期，含 `开盘` 与 `close`；本研究仍硬截断于 2026-08-14。

本补充只解决同一冻结基准的开盘字段可用性，不改变基准身份、共同交易日、反应窗口、形成时点、60/120 日期限、样本、特征、分组或通过门。股票面板、原覆盖门失败状态和 `NO_TRADE` 边界均不变。
