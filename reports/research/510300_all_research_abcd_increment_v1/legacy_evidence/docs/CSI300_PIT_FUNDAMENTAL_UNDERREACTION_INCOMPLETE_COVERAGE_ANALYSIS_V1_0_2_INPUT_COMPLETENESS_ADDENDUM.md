# 不完整覆盖条件样本分析 V1.0.2 输入完整性补充

V1.0.1 冻结后、尚未计算任何信号、分数或未来收益时，字段完整性检查发现 H00300 全收益文件的“开盘”列有 2,486/2,831 行为空，因此 V1.0.1 的首日盘中实现不可执行。

固定修正如下：首个共同交易日的盘中基准收益使用 `000300_daily_feature_warmup.parquet` 的沪深300价格指数 `close/open-1`；从首日收盘到第五日收盘使用 H00300 全收益指数 `close_day5/close_day1-1`。两段复合后即为首日开盘到第五日收盘的基准反应。开盘买入不会获得开盘前发生的隔夜移动或除息，因此首日盘中使用价格指数、开盘后使用全收益指数具有一致的收益归属。

该修正只解决冻结窗口的输入缺失，不改变窗口、信号、样本、期限、分组或通过门，也不是根据结果作出的救援。H00300 仍用于共同交易日和全部形成后 60/120 日相对收益。

股票面板还缺少 `000671.SZ`，影响 14 个已就绪事件；这些事件严格记为价格 `NO_VIEW`，不使用其他代码或代理价格。
