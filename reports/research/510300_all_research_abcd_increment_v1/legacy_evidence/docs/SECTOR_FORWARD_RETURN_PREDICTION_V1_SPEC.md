# 510300 点时板块未来贡献预测 V1

状态：`DISCOVERY_ONLY`  
历史证据：`HISTORICALLY_CONTAMINATED`  
候选预算：`1`  
仓位、订单、券商：`DISABLED`

## 1. 预测问题

本协议不再用已经发生的板块贡献替代预测。唯一问题是：截至月度官方权重快照日可得的板块估值与盈利，能否预测从下一交易日开盘起未来60个交易日各板块对指数收益的贡献，并在求和后改善510300未来收益预测。

## 2. 未来目标

对信号日 `t` 的成分 `i`、板块 `s`：

`ComponentReturn(i,t,60) = TotalReturnClose(i,T60) / TotalReturnOpen(i,t+1) - 1`

`SectorContribution(s,t,60) = Σ_i∈s SnapshotWeight(i,t) × ComponentReturn(i,t,60)`

`SnapshotIndexReturn(t,60) = Σ_s SectorContribution(s,t,60)`

行业身份和权重固定在信号日。缺少端点价格的证券保留为缺失权重，不对其余证券重新归一化；端点覆盖低于95%的信号日输出 `NO_VIEW`。辅助可交易目标为同期510300含分红总收益减1.5%年化现金收益 `ETF_X60`。

## 3. 唯一模型 S1

候选：`S1_SECTOR_FUNDAMENTAL_RIDGE_V1`。

固定输入只有：板块权重、盈利收益率、账面收益率、ROE、TTM盈利同比、TTM收入同比。每项基本面先乘信号日板块权重，因此模型直接预测指数贡献。模型同时包含全市场共享系数和按中信一级行业收缩的相对系数。

- 线性 Ridge；
- `alpha=10`；
- 不搜索正则强度；
- 不加入价格动量、驱动周期、X1、FVG、分钟量价或宏观变量；
- 不做特征选择和行业删除；
- 只用在当前信号日前已经完整成熟的60日标签训练；
- 最少36个成熟月度快照才允许预测。

聚合基准 `B0_AGGREGATE_VALUATION_RIDGE` 使用同日指数加权的五项基本面，采用相同 `alpha=10`。S1 必须相对 B0 和扩展历史均值同时具有增量，避免把聚合估值旧结论包装成板块模型。

## 4. 概率分布

每个伪样本外信号保存点预测。只有至少12个更早、且其60日结果已经成熟的伪样本外误差后，才用这些先前误差形成10%、50%、90%预测区间和正收益概率。不得用当前或未来误差校准当前预测。

## 5. 冻结验证期与门槛

- 构造期：2019-12-31至2022-12-30；
- 历史伪样本外：2023-01-03至2026-07-31；
- 最少30个成熟伪样本外预测；
- S1 与 `SnapshotIndexReturn60` 的 Spearman 不低于0.20；
- 5,000次、3个月移动块 Bootstrap 的 Spearman 95%下界大于0；
- S1 MAE 相对 B0 至少改善10%；
- S1 MAE 相对扩展历史均值至少改善10%；
- 方向准确率严格大于55%；
- 前后半段 Spearman 均大于0；
- S1 与 `ETF_X60` 的 Spearman 大于0；
- 有概率输出的样本不少于12，Brier Skill 大于0；
- 80%预测区间覆盖率位于65%至95%。

任何门槛失败均冻结为 `HISTORICAL_REJECTED_FROZEN`，不得修改期限、alpha、特征或行业交互补救。

## 6. 与驱动周期、X1的关系

S1 必须独立通过后，才允许另立协议检验驱动周期是否提高价值兑现概率。M1/T1历史失败结果不得参与S1参数选择。X1只保留为独立未来尾部候选，不进入本模型。

即使S1历史通过，也只得到 `HISTORICAL_PASS_AWAITING_TRUE_FORWARD`；真正前向起点在代码、协议、输入和哈希冻结提交前保持为空。本协议不生成仓位或订单。
