# 510300_R6_REGIME_ALLOCATION 统一研究协议

状态：`FROZEN_RESEARCH_PROTOCOL`  
冻结日期：2026-08-16  
交易边界：只持有510300与现金；只做多；不加杠杆；不卖空；不连接券商；不自动下单。

## 1. 研究问题与基准

R6只回答一个问题：在上述交易边界内，市场状态和风险预算能否在真实成本、小账户约束及样本外检验后，相对以下两个主基准稳定改善风险调整收益：

1. 510300含现金分红买入持有；
2. H00300沪深300全收益指数。

上证指数只允许作为辅助报告，不参与参数选择。选择顺序固定为样本外Sharpe、最大回撤、滚动242日超额稳定性、成本后年化超额、换手和小账户可执行性，不直接优化最高CAGR。

## 2. 数据面板与点时规则

- 长历史面板：510300、000300、H00300，目标覆盖ETF成立以来，用于实验A和B。
- 共同样本面板：在长历史面板上加入点时估值，供实验C使用；不得为加入短历史字段而截短A、B。
- 信号日只使用当日收盘及此前已公开数据；下一交易日开盘成交。
- 原始数据、配置、代码与结果均保存SHA-256。任何供应商修订必须保存新版本，不允许静默覆盖前向记录。
- PCF、IOPV、分钟领先、Top50广度和MACD只作观察或执行诊断，不参与R6仓位。

## 3. 固定候选

候选总数固定为25个，详见 `config/r6_experiment_matrix.yaml`：

- 实验A共9个：8%、10%、12%目标波动率，分别搭配RV20、RV60、70% RV20 + 30% RV60。
- 实验B共8个：固定状态矩阵与三条连续映射，分别使用504日、756日滚动标准化。
- 实验C共8个：删除估值、估值只作边界、估值20%低权重、完整R5底仓，各搭配基础乘数和无强状态加成版本。

冻结后禁止根据结果新增候选或改变阈值。流动性和机器学习不属于首轮候选；只有A/B/C至少一个通过全部门槛后，才可建立新版本逐项检验。

## 4. 信号与执行

统一信号链：日频点时数据 → 趋势/风险状态 → 风险预算或状态乘数 → 连续目标 → 10%研究档 → 25%小账户档 → 下一交易日开盘。

- 普通仓位每5个交易日复核；
- 风险评分显著恶化或危机条件触发时，下一交易日立即降仓；
- 恢复仓位每次最多增加10个百分点；
- 连续仓位先检验，随后检验10%档；历史候选领先者再检验2万元、25%档、100份整手、普通调仓至少1000份、最低5元佣金和滑点；
- 当日新买份额与旧仓分账，卖出不超过可卖旧仓；
- 所有输出必须保留信号日期、执行日期、目标、许可、成交、成本与输入哈希。

## 5. 时间切分与模型选择

当前历史已被反复查看，因此只标记为开发、验证和“受污染的历史伪样本外”，不能冒充严格锁定样本外。`true_locked_oos_start`在历史领先模型与代码版本提交后才填写；锁定样本外结果只能计算一次。

第一轮固定切分：

- 开发：2016-08-12至2020-12-31；
- 验证：2021-01-04至2023-12-29；
- 历史伪样本外：2024-01-02至当前数据末日；
- 同时按自然年输出锚定式walk-forward片段，所有特征只从过去滚动计算。

验证样本按预注册优先级排序。历史伪样本外只提供审计和淘汰证据，不产生可直接启动前向的“已验证冠军”。

## 6. 指标与硬门槛

统一报告CAGR、年化波动、Sharpe、Sortino、最大回撤、Calmar、年化超额、Information Ratio、平均仓位、年换手、交易次数、显式成本、滑点拖累、最长水下期、滚动242日超额分布、年度集中度、三等分子区间、邻近参数稳定性和Deflated Sharpe。

候选必须同时满足：

- 相对510300买入持有和H00300年化超额均为正；
- Sharpe不低于0.8，且比买入持有至少高0.25；
- 最大回撤绝对值不超过买入持有的80%；
- 滚动242日超额中位数为正，正超额窗口至少60%；
- 三个主要子区间至少两个为正超额；
- 单一年份不贡献超过全部正超额的50%；
- 成本翻倍后超额仍不为负；
- 邻近参数大多数保持同方向；
- 25%小账户映射后超额不翻负；
- 多重试验修正后仍有意义。

只在单一年份有效、主要依赖一次逃顶、参数邻域失效、成本后转负、25%映射失效、复杂模块Sharpe增量小于0.1或锁定样本外为负者直接淘汰。

## 7. 前向激活条件

只有一个候选在真正锁定样本外、双倍成本和小账户映射中全部通过后，才允许创建 `R6_FORWARD_1`。届时冻结数据字段、参数、仓位公式、复核频率、成本、哈希、代码版本和失败规则。

前向仍依次为Shadow连续仓位、2万元纸面执行、人工小规模执行评估。任何阶段均不自动下单；当前 `R6_FORWARD_1` 未激活。
