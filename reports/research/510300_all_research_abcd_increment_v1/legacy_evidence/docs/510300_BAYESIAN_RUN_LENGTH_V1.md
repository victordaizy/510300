# 第123轮：逐日判断行情持续时间并决定进出场

2026年9月9日，固定登记两个设置：允许行情阶段变化的预测，以及始终累积全部历史的对照。目标保持扣费净夏普至少1.2及稳定超额。两个设置使用相同免费日线、先验和交易规则，只比较允许阶段变化是否带来实际改善。

## 一、使用的观察与交易因子

唯一原始观察是每日含分红对数收益：当天收盘加当天每份分红，除以前收盘，再取自然对数。保存数据从2012年5月28日至2026年8月14日，共3456日；首行没有前收盘收益，其后3455条完整有限。不增加EPS、公募申购或其他慢数据。

模型假设，在一个未变化的行情阶段内，日收益的均值和方差相对稳定；阶段可以在下一观察前结束，但不知道已经持续多久。每个可能持续时间都有一份当前概率和一组均值、方差参数。它们是统计假设，不代表已证明市场必然按这些阶段运行。

实际用于买卖的因子是下一日对数收益均值预测，即所有持续时间分支的均值按当前概率加权求和。另保存预测方差、平均持续时间、最大概率持续时间和完整概率，供核对；它们不再另外生成交易条件，也不会根据回测结果选择最有利的阶段。

## 二、固定先验与逐日更新

主要设置每日阶段结束先验为二百四十二分之一，约一年尺度，固定不变。对照为零，即全部历史属于同一阶段。该差异是两种预先登记方法，不扫描阶段长度或选择表现最好的先验。

开始时持续时间为零。每个新阶段采用相同先验：收益均值为零，均值强度为一，方差先验形状为二、尺度为万分之一。方差采用逆伽马分布，约定密度指数为负尺度除以方差；均值在给定方差后为正态，方差等于该分支方差除以均值强度。先验下分支方差的期望为万分之一。

对每条新收盘收益，先用观察之前的分支参数计算它的预测密度。预测分布为Student t分布，自由度是两倍形状，中心是该分支均值，尺度平方是“方差先验尺度乘均值强度加一，再除以形状乘均值强度”。尺度平方不等于预测方差，必要测试单独区分。

对主要设置，将旧分支概率乘这一新观察的预测密度，再乘未结束概率，得到延续一天的分支权重；将这些旧分支概率与预测密度乘积求和，再乘固定结束概率，得到持续时间零的权重。所有分支一起归一化。计算使用对数概率及稳定求和，保留所有可能持续时间，不按概率或收益删掉长尾分支。

随后更新每个延续分支：均值强度增加一；旧强度乘旧均值，加新观察收益，再除以新强度，成为新均值；形状增加二分之一；尺度增加“旧强度乘新收益相对旧均值的差值平方，再除以两倍新强度”。新出现的持续时间零分支保留初始先验。最后混合更新后的均值，得到下一日预测。

对照只保留一个一直增长的阶段，按同样共轭公式加入每条收益，概率始终为一。可以用截至当日全部收益之和、平方和及观察数的闭式结果检查，无需随机采样或拟合线性系数。每个方法是一套完整在线滤波器，逐日更新次数和内部概率分支数量另行报告，不把分支当作独立策略。

按本次采用的时钟和固定结束先验，主要设置归一化后的持续时间零概率等于固定先验概率。因此该数值不是额外的当日变点信号，本轮不对它设置买卖阈值。必要测试检查这一恒等式，防止把常数误解为随行情变化的预测。

逐日持续时间递推参考[Adams与MacKay原论文算法一](https://arxiv.org/pdf/0710.3742)；正态与逆伽马参数形式参考[Murphy的共轭分析](https://www.cs.ubc.ca/~murphyk/Papers/bayesGauss.pdf)。本项目的先验数值、均值方向和交易规则均为待检验设计，来源并未证明它们能提高510300夏普率。所有更新只用当前及过去观察，不进行利用未来数据的回看平滑。

## 三、什么时候买入、持有和退出

先完成252条完整收益观察，才公开有效预测。参与同号确认的当前与前一收盘预测都必须已完成该准备期。

1. 两个连续收盘的下一日均值预测都严格为正：若空仓，下一开盘请求按真实可用现金买入整百份；若已持仓，继续保留已有份额，不加仓补齐。
2. 两个连续收盘的下一日均值预测都严格为负：若持仓，下一开盘请求全部退出；若空仓，继续现金。
3. 两次预测正负不一致，或者任一次等于零：保持实际已有资产类别，不发起新的买卖。
4. 当前或前一预测缺失：没有观点，不发起新交易，已有份额继续承担真实涨跌。
5. 先前卖出受阻而已经锁定待卖：逐日继续申请卖出，即使随后预测转正、为零或缺失，也不撤销。

买入请求只根据当日收盘价格、真实可用现金、整手和费用预算决定，下一开盘再处理实际价位、方向限制及现金不足的部分成交。卖出遵守次日可卖。持仓不再平衡、不借款和不卖空，研究终点统一优先在最后交易日开盘清仓；不能成交时保留未清仓状态。

该方法不套用旧六十日日内强弱入场、固定止损、追踪回撤、最长六十日、两日冷却或旧进入条件消失后重置。预测确认次数固定为二，不能在看过结果后改为一次或更长。前次退出已经成交后，若新的两个收盘预测同为正，可按同一规则再次进入。

## 四、缺失、数值问题与真实账户边界

首行缺收益是已知数据起点。之后一旦出现缺失或非有限收益，该方法从该日直到本次研究终点均没有新预测；不补零、不删除日期，也不在缺口之后另选重启时点。数值更新无效时同样保留剩余区间没有观点的状态，不更换算法或松容差挽救。该处理对各方法独立记录；实际持仓与待卖始终由连续账户维护。现有数据首行之外全部完整。

收盘到次日收盘的预测均值不能当作实际赚到的收益。实际买卖从下一开盘执行，空仓账户不取得执行前的隔夜上涨；原持仓仍承担这段隔夜变化。完整账户连续记录现金、实际份额、分红登记权益、除息应收和付款，分红只确认一次，不每日重置名义资金，也不将市场财富指数的全部分红自动计给账户。

两个方法共用同一市场观察。压力账户使用相同保存预测，自己按压力费用、现金、整手和真实成交结算。没有直接把预测均值累加成净值，全部绩效来自账户保存的逐日净收益。

## 五、一次评价与取舍

主历史2020年1月2日至2026年8月14日终点开盘，较早历史2015年1月5日至2019年12月31日终点开盘；每段二十万元初始现金。两个方法乘两历史乘两费用，共八个新独立账户回测；第114轮、第32轮、第91轮及买入持有复用保存对照，没有新全程参考账户。

基础单边佣金为成交额万分之二、最低五元，滑点万分之五；压力佣金万分之四、最低五元，滑点千分之一。一百份整手、零点零零一元价位、次日可卖、方向限制、现金约束保持。年化242交易日，现金收益及夏普无风险收益均假设为零。全体现金日、无观点日、亏损日及未成交都进入账户，零波动时夏普未定义。

先通过八项必要测试，再冻结并计算新预测和八账户。保存每日预测、完整压缩概率、终点参数和全部成交；按保存概率核对递推及下一日均值，按真实账户核对进出场与财富。没有改善则关闭这两个固定方法，不调整先验、持续时间、准备期、符号阈值、确认或费用挽救。两段历史已被反复研究，不能改称独立验证；即使有单个夏普点值达到1.2，也需继续核实稳定超额与独立证据。

仍只研究510300与现金，EPS、公募和慢源暂停，不生成GPT审阅数值包或额外安全审计，不扩大到其他标的、券商、订单或实盘权限。
