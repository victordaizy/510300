# VAL-04 PB—ROE 残余收益模型数据可行性协议 V1

## 1. 目的与边界

本阶段只回答一个问题：在 2016-08-31 至 2026-07-31 的 120 个沪深300官方月度权重快照上，是否能用当时已经可得的价格、财务和中信一级行业数据，构造足以支持预注册横截面回归的完整样本。

本阶段禁止读取未来收益、拟合残差模型、生成估值分位、计算 IC、回测仓位或连接券商。数据闸门失败时输出 `NO_VIEW`，不得删去早期月份后继续。

## 2. 唯一候选定义

后续模型若获准，唯一公式为：

```text
log(PB_i,t)
  = a_sector,t
  + b1,t × clip(TTM_ROE_i,t, -0.5, 0.8)
  + b2,t × clip(TTM_RevenueGrowthYoY_i,t, -1, 1)
  + epsilon_i,t
```

其中：

- `PB = 快照日未复权收盘价 / 经交叉校验的每股净资产`；只接受正 PB；
- 行业为快照日有效的中信一级点时区间，不允许用当前行业静态回填；
- ROE 为当时已知 TTM 归母净利润除以当时已知正归母权益；
- Growth 固定为 TTM 营业收入同比，不使用利润同比；
- 后续负残差表示相对 ROE、增长和行业更便宜；本阶段不计算残差。

选用营收同比是模型冻结前的定义选择。利润同比在上年利润非正时无稳定经济含义，容易引入符号翻转和事后缺失处理自由度。

## 3. 点时规则

1. 成分和权重使用每月官方快照，每月必须恰好 300 只。
2. 财务记录必须满足 `available_at <= snapshot_date`；同一证券、同一报告期只保留当时最新已知版本。
3. 早期价格使用专用历史权重快照价格，重叠时优先；后期使用当期成分股日线。两者均为未复权收盘价。
4. 行业区间使用半开规则 `in_date <= date < out_date`。新一级行业生效时截断旧区间；同一证券同日起存在多个一级行业时硬失败。
5. 不允许当前成分、当前行业或未来修订向历史回填。

## 4. 预冻结数据闸门

每个快照同时满足以下条件才算通过：

- 成分数 300，权重和在 0.98 至 1.02；
- 价格权重覆盖不低于 99%；
- 点时行业权重覆盖不低于 95%；
- 正 B/P、ROE、TTM 营收同比各自权重覆盖不低于 90%；
- 五项字段同时完整的权重覆盖不低于 90%，公司数不少于 200；
- 完整样本覆盖至少 20 个一级行业；
- 行业固定效应、ROE、增长构成的设计矩阵满秩后的残差自由度不少于 150；
- 不存在重复权重证券、重复有效行业或未来财务事件。

整体必须 120/120 个快照全部通过。任何一个月失败，状态为 `NO_VIEW_DATA_GATE_FAILED_MODEL_FIT_FORBIDDEN`，不得通过缩短窗口或降低门槛救援。

## 5. 后续路径

只有本闸门通过后，才能另行冻结模型卡、60 月扩展分位、T+1 可得时点、未来收益标签和预测淘汰标准。预测屏幕通过之前，不得运行策略收益或仓位映射。
