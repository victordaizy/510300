# 510300 压力传导危险率模型 V2 冻结研究协议

协议 ID：`510300_STRESS_TRANSMISSION_HAZARD_V2`  
版本：`2.0.0`  
冻结阶段：`PROTOCOL_FREEZE_AND_DATA_CONTRACT_REPAIR_ONLY`  
研究权限：`DISCOVERY_ONLY`  
收益读取：`NOT_ALLOWED`  
仓位影响：`0`

## 1. 当前裁决与研究边界

本协议是 2026-09-03 外部全量复核后的唯一 510300 主线。它不改写 V1：

```text
CURRENT_VALIDATED_HIGH_SHARPE_STRATEGY = NONE

510300_ASYMMETRIC_STRESS_HAZARD_V1
ORIGINAL_OUTPUT = PRESERVE_IMMUTABLE
G2_AUTHORITATIVE_RESULT = INVALIDATED
ECONOMIC_HYPOTHESIS = NOT_CLEANLY_ADJUDICATED
PORTFOLIO_EVALUATION = NOT_ALLOWED

510300_STRESS_TRANSMISSION_HAZARD_V2
AUTHORIZATION = PROTOCOL_FREEZE_AND_DISCOVERY_ONLY
POSITION_IMPACT = 0
```

V1 的正式 G2 与严格来源准入使用了不同的历史时点契约，且成分收益链把多种
缺失状态统一填成 0。因此现有 G2 既不能作为有效预测结果，也不能干净证伪经济
机制。V2 不是对 V1 结果取反，也不是修改参数后的救援版本；它是数据语义和机制
结构均重新冻结的新协议。

本阶段允许：协议、输入身份、时钟、四态收益、覆盖门、无行业特征、事件账本、
固定模型接口、测试和哈希清单。G0—G4 全部通过前，不得生成或读取新 AUC、策略
收益、夏普、回撤、净值、仓位或订单。

## 2. 经济目标与 BAD10

模型估计：

```text
P(
  从 t 日收盘后下一可交易开盘开始，
  未来 10 个交易日内，
  510300 一股总财富路径损失达到 -4%
  |
  t 日收盘时全部可得信息
)
```

标签固定如下：

- 信息原点：t 日收盘；
- 执行：下一交易日 510300 实际未复权开盘；
- 路径计价：510300 实际未复权收盘加已经享有的现金分红应收；
- 期限：10 个交易日；
- 阈值：小于或等于 -4%；
- 标签中不计交易成本，成本只属于未来组合门；
- 期限不完整的原点为 `CENSORED_NOT_AN_ORIGIN`；
- H00300 不得代替 510300 执行路径。

禁止在同一历史上搜索 -3%、-5%、15 日或 20 日标签，也禁止因方向不理想而反转
标签或信号。

## 3. 独立事件与有效样本

连续、重叠且指向同一实际下跌过程的 BAD10 正样本，按闭区间
`[entry_date, horizon_end_date]` 的传递重叠关系合并为一个事件。该操作规则在读取
V2 模型结果前冻结。

- 每个事件内所有正样本的训练权重之和固定为 1；
- 每个非事件风险日权重固定为 1；
- 同一事件必须整体进入训练、校准或评价区间，不能拆分；
- Bootstrap 同时保存事件块和日历年块；
- 预测评价以事件命中、提前量和警报负担为核心，重叠正样本日数不能冒充独立
  成功次数；
- 协议冻结时不分配训练、校准和评价区间，统一为
  `UNASSIGNED_PRE_MODEL_FREEZE`，防止在看见特征结果后移动边界。

## 4. 成分收益四态

每个证券—交易日必须落在且只落在以下状态：

| 状态 | 数值规则 | 特征资格 |
| --- | --- | --- |
| `TRADED_VALID` | 使用未复权价格与当时已知、已经核对的公司行动账本计算 | 可用 |
| `OFFICIAL_SUSPENSION` | 有官方停牌证据且公司行动已核对时记 0 | 可用 |
| `CORPORATE_ACTION_UNRESOLVED` | 保持缺失 | 不可用 |
| `SUPPLIER_MISSING_OR_CONFLICT` | 保持缺失 | 不可用 |

收益的经济恒等式按行动前每股定义：

```text
期末财富
= 未复权收盘价 × 行动后/行动前股数比
  + 现金分配
  - 认购现金流出

日总股东收益
= 期末财富 / 前一日未复权收盘价 - 1
```

`NONE_CONFIRMED` 也必须有当日公司行动核对证据。证券首次出现而缺少前收盘价时，
不得从首次出现之后开始统一补 0；该日为 `SUPPLIER_MISSING_OR_CONFLICT`。未来公司
行动信息写入后复权历史价格的序列不得进入本模型。

V1 两个旧成分行情文件只登记为
`QUARANTINED_PENDING_FOUR_STATE_RECONCILIATION`。在历史停牌、公司行动、供应商
冲突和首次出现状态无法逐日证明前，不得直接用于 V2 特征或产生“修正后的 G2”。

## 5. 覆盖门与 NO_VIEW

普通缺失成员不能填 0，但覆盖充分时可以排除：

- 广度和成分等权收益：可用成员至少占当日点时成员的 98%；
- 若存在已经证明可靠的点时权重：可用权重覆盖至少 99%；
- 共同运动：至少 90% 的当日点时成员在过去 20 日中有不少于 15 个有效的“成员
  收益—剔除自身的点时等权成员组合收益”配对观察；
- 任一核心模块不通过时，对应模型状态为 `NO_VIEW`；
- `NO_VIEW` 不是现金目标，不是用户持仓，也不是订单。

点时成员以当日真实 CSI300 成员为准，不得用当前成分回填历史。

## 6. 固定特征

所有风险分位数只使用严格早于当前日的有效观察，以经验中秩计算；当前值不进入
自己的参照集，缺失不插值。

### 6.1 宏观脆弱性 M

```text
EY_RATE_BUFFER
= 沪深300盈利收益率 - 中国10年期国债收益率

FUNDING_SPREAD
= DR007 - 7天逆回购政策利率

M
= median(
    risk_percentile(-EY_RATE_BUFFER),
    risk_percentile(FUNDING_SPREAD_5D_MEAN)
  )
```

该估值量只称“盈利收益率—利率缓冲”，不称预期 ERP。每条宏观记录必须携带
`observation_date` 与 `available_at`；t 日只选择 15:00 前已经可得的最新参考期及其
当时版本。

社融信用脉冲、PMI、M1/M2、汇率、北向、政策文本和一致预期不进入 V2 核心。
它们可以建立单独观测账本，但不能救援本版本。M 不能在 T 低时单独触发退出。

### 6.2 指数内部脆弱性 F

```text
BREADTH20
= 点时可评分成员中过去20日总股东收益为正的比例

LEADERSHIP_GAP20
= H00300过去20日总收益
  - 点时成员过去20日总股东收益的等权平均

COMOVEMENT20
= median_i corr(
    成分i日总股东收益,
    当日点时成员中剔除i后的等权组合日收益,
    过去20个市场日
  )

F
= median(
    risk_percentile(-BREADTH20),
    risk_percentile(LEADERSHIP_GAP20),
    risk_percentile(COMOVEMENT20)
  )
```

H00300 在这里用于指数内部结构比较和未来基准，不是 510300 执行价格。

### 6.3 快速风险传导 T

```text
BREADTH_DROP5
= BREADTH20_(t-5) - BREADTH20_t

TAIL_i,t
= 1[
    成分i过去5日总股东收益
    < -1.5 × 成分i过去60日日波动率 × sqrt(5)
  ]

TAIL_DIFFUSION5
= 点时成员中满足 TAIL 的比例

COMOVEMENT_ACCEL5
= COMOVEMENT20_t - COMOVEMENT20_(t-5)

FUNDING_SHOCK5
= FUNDING_SPREAD_5D_MEAN - FUNDING_SPREAD_20D_MEAN

T
= median(
    risk_percentile(BREADTH_DROP5),
    risk_percentile(TAIL_DIFFUSION5),
    risk_percentile(COMOVEMENT_ACCEL5),
    risk_percentile(FUNDING_SHOCK5)
  )
```

行业代码、行业名称、行业收益、行业扩散和行业相关性均不在核心字段集合中。现有
行业资料只允许带披露的描述性研究；未来必须从公告、公布时间、生效日和内容哈希
开始前向积累，再以独立 challenger 协议评估。

## 7. 固定模型与嵌套裁决

```text
B0 = 无条件 BAD10 基础率

B1 = 510300自身价格风险
     20日实现波动、20日回撤、5日下行收益

B2 = T + T×F

B3 = T + T×F + T×M
```

最终模型：

```text
logit P(BAD10_t=1)
= alpha + beta1*T + beta2*(T*F) + beta3*(T*M)

beta1, beta2, beta3 >= 0
```

固定优化目标为“样本权重平均负对数似然 + 0.5 × 1.0 × 风险系数平方和”；截距
不惩罚，L2 固定 1.0。禁止超参数网格、自动变量选择、树模型、Boosting、神经
网络、符号反转及 AUC 小于 0.5 后取反。

裁决顺序在运行前固定为 B0 → B1 → B2 → B3。B2 必须在事件加权 Log Loss 上
优于 B1，成分结构才有资格保留；B3 必须进一步优于 B2，宏观才有资格进入最终
模型。为避免运行后从 Brier 和 Log Loss 中择优，本协议把事件加权 Log Loss 冻结
为唯一增量裁决指标，Brier 必须报告但不能替代失败的主门。ROC-AUC 仅描述。

## 8. 研究门

| 门 | 冻结通过条件 |
| --- | --- |
| G0 工程与契约 | 干净环境可重放；代码、配置、测试、结果与 manifest 有哈希；行业字段不能进入核心；四态、停牌和公司行动测试通过 |
| G1 数据与事件 | 机制发现至少 30 个独立事件；完整三系数模型和组合至少 40 个；非事件风险日至少 750 个 |
| G2 结构增量 | B2 相对 B1 的事件加权 Log Loss 改善大于 0；至少 3/4 时代同方向；事件与年份块 Bootstrap 单侧 90% 下界大于 0 |
| G3 宏观增量 | B3 相对 B2 的事件加权 Log Loss 改善大于 0；至少 3/4 时代同方向；beta3 不反转；Brier 同时报告 |
| G4 决策能力 | 事件召回至少 80%；中位提前量至少 1 个完整交易日；警报日不超过 15%；独立警报不超过 8 次/年；误报连续期中位数不超过 3 日 |
| G5 组合价值 | 现实成本后净夏普至少 1.2；最大回撤降低至少 30%；上涨捕获至少 80%；下跌捕获不超过 55%；年往返不超过 8 |
| G6 稳健性 | 3/4 时代净超额为正；同平均暴露基准超额为正；单事件贡献不超过 30%；10bp 单边压力滑点后仍为正 |
| G7 严格前向 | 初审至少 252 日且至少 5 个独立事件；正式资格至少 504 日且至少 10 个独立事件；期间不改模型 |

当前冻结动作本身不宣称 G0 已通过。只有在冻结文件提交后从干净环境重放并生成
独立收据，才可把 G0 写为通过。

固定四个时代：2015—2017、2018—2020、2021—2023、2024—2026-08-14。
事件若触及分割边界，必须整体归入一个样本区间，不能按日期拆开。

## 9. 第一次组合实验（当前禁止运行）

只有 G0—G4 全部通过后，才允许单独冻结一个概率阈值并进行唯一一次组合读取：

```text
正常：100%持有510300
有效警报：下一可交易开盘全部退出到现金
防御期：固定10个交易日
期满：下一可交易开盘无条件恢复100% 510300
防御期内新警报：只记录，不延长
```

当前概率阈值为 `null`；不得依据最终夏普选择阈值。第一次实验不得训练恢复模型。

账户契约预先冻结为 200,000 元、单边佣金万分之二、每笔最低 5 元、100 股一手、
T+1、下一开盘执行、基准单边滑点 5bp、压力单边滑点 10bp、现金收益 0、分红进入
现金账本。

主要基准为 510300 总回报买入持有、H00300 总收益指数、同平均暴露的固定或随机
现金期基准以及 B1。上证指数只作背景。组合结果还必须做项目全体历史试验次数的
Deflated Sharpe、月份或事件块 Bootstrap、leave-one-stress-event-out 和单事件贡献
分析。

任一组合门失败时冻结为：

```text
HISTORICAL_REJECTED_FROZEN_NO_RESCUE
```

## 10. 严格前向与权限

只有历史 G0—G6 全部通过后，才能启动 `SHADOW_ONLY` 严格前向；其
`POSITION_IMPACT` 仍为 0。协议冻结、历史发现、Paper、Shadow、券商连接、订单和
实盘是彼此独立的权限层。本协议不授予后三者任何权限，也不描述用户实际持仓。

## 11. 当前明确停止的路径

- 再次关闭行业时点门运行 V1 G2；
- 用当前分类或仅凭历史生效区间回填预测行业；
- 把成分缺失收益统一填 0；
- 把低 AUC 信号反转；
- 修改 BAD10 阈值或期限；
- 加入 PMI、M1/M2、汇率、北向、新闻等救援；
- 搜索几何平均权重；
- 同时优化退出与恢复；
- 依据最终夏普选择概率阈值；
- 在预测门通过前生成组合净值；
- 把历史高夏普描述成严格样本外有效；
- 生成仓位、订单、券商连接或实盘动作。

## 12. 0—7 日交付定义

本阶段完成条件仅包括：

1. V1 原始输出保留并有单独漂移检测清单；

4. V2 核心代码和配置不存在行业依赖；

6. 协议、YAML、代码、测试、清单和 SHA-256 收据冻结；
7. 状态继续为 `DISCOVERY_ONLY / RETURN_EVALUATION=NOT_ALLOWED /
   POSITION_IMPACT=0`。

这组交付只证明协议和工程底座建立，不证明预测门、组合门、夏普门或前向门通过。
