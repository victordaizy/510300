# 第152轮：修正周期内相邻误差，重新学习何时退出

本轮一套策略、四个新资金账户，只改变退出模型训练中的误差相关结构。进入仍沿用六十日日内相对隔夜强弱，学习退出仍保留每笔进入时固定版本。原114、128和143结果不修改。规则在新模型拟合和新收益读取前确定。

## 全部因子及含义

|用途|因子|完整中文定义|
|---|---|---|
|进入及自然退出|六十日日内相对隔夜强弱|每日含分红日内对数涨跌减隔夜对数涨跌，最近六十日合计，除以这六十个每日差值的样本标准差与六十平方根的乘积；分母为零或所需数据未知时没有有效强弱分数。|

|学习退出之四|进入类别|原日内强于隔夜类别，值固定为一。它在周期内部没有变化，不能凭周期间差异得到有效方向系数。|

## 月度成熟样本、标签和标准化

保留原141个月度收盘检查，时点为当日15时05分。每个月只允许已经自然完全退出的最近二十个原参考周期进入训练，至少十个完整周期、一百条状态。每个周期总权重一，内部全部状态均分。保持1461条原参考状态、原周期成员、原标签；其中114个月有成熟模型，27个月没有成熟模型，首次成熟为2017年3月1日。

每条状态的目标，是继续持有至原自然退出相对于下一开盘提前卖出的净收入差，再除以下一开盘参考市值；包括原基础佣金、滑点和新增分红登记权益。沿用既有假设提前退出标签的近似，不把这些标签当成已实际完成的独立成交。只有原周期完全退出后才能读取其训练目标。

标准化均值、标准差与截断完全复用当月原114保存模型。它们来自原完整训练样本的周期等权均值和总体标准差；标准差不大于万亿分之一时用一作分母。标准化后限制在负五至正五。训练时所有状态、标签和权重都保留，不通过删行改样本。

## 怎样减少同一周期中重复误差的影响

先用原114当月保存的八个系数和每个训练周期自己的截距，还原该月原训练残差。只把同一周期、交易日索引恰好相差一的两条残差配成相邻对；不跨周期或跳过缺失交易日。每周期内各有效相邻对等权，各有相邻对的周期总对权重一。

一阶残差延续系数等于加权“当前残差与上一残差的乘积”之和，除以加权“上一残差平方”之和。它是误差延续的回归系数，并非直接把普通样本相关系数代入。分母不能提供正信息时该输入没有可识别模型，不补零。系数限制在负0.99至正0.99，固定边界用于保证平稳相关矩阵，不按收益调整。原值、限制后值和边界状态全部保存。

同一周期两个状态的误差相关设为上述系数的“交易日索引距离”次方，不同周期不相连。对八个标准化因子、训练标签和对应周期的截距列作完全相同的转换：首行保持；后续一行先减前一保存状态乘相关系数的距离次方，再除以“一减这个乘数的平方”的平方根。首行不删除，也不作另一个缩放。这与完整相关矩阵的加权最小二乘目标等价。[统计方法依据](https://www.statsmodels.org/stable/examples/notebooks/generated/gls.html)

同时选择八个系数和各周期截距，使转换后误差平方的加权合计，加八个系数平方和，达到最小。状态权重仍为所在周期状态数的倒数，系数惩罚固定为一，各周期截距不惩罚。先消去周期截距，再用正定矩阵分解求解八个系数。没有反复调参；求解失败保存无模型状态，不换求解器挽救。相关为零时，应还原原114训练目标和系数，已用合成数据检验。

预测新实际周期时，各成熟训练周期截距取等权平均，加当前八项标准化并截断的实际因子与新系数的乘积合计。不得用尚未结束的实际周期未来残差修正预测，也不套用编号相同的旧周期截距。

## 相同输入只拟合一次，时钟全部保留

输入核对确认114个成熟月份只有25种不同的“原参数与有序训练成员”组合。按照141个月份顺序前进，首次遇见一种组合时拟合；之后同一组合复用此前成功或失败的结果。失败不在同一输入下重试。每个月仍记录月度时点、成熟成员、输入身份、首次计算月份及是否复用。

最多25次不同输入拟合，预期89个成熟月份复用已有结果。月份数与拟合次数分别报告；不同输入组合、重叠月份均不能当成独立证据。保留27个支持不足月份，不向前填充模型。

## 进入、持仓和全部退出

连续两个收盘六十日强弱分数严格大于一、原必要输入完整、账户空仓并具备重新进入资格，且距上次真实全部退出至少两个交易日，在下一真实开盘请求买入可负担的整百份510300。申请数量按申请收盘的现金、价格和费用确定，实际开盘仍受现金、价格和交易限制；不保证达到恰好百分之百仓位。

实际买入当天首个持仓收盘，选择当时最近一条已经可用的本轮月度记录，固定参数直至本笔全部退出。允许使用该日15时05分已经完成的月度记录，用于下一开盘的退出判断。不能在买入开盘提前使用当天收盘模型，也不在持仓中换入后来的版本。

首个收盘没有成熟模型或所选模型失败，本笔全程保持无学习预测，原自然退出仍有效；后来出现模型也不补换。当前八因素缺失时不产生预测，连续负预测计数归零，已选择的参数继续固定。每个实际新周期重新选择和计数。

持仓不追加，不部分卖出。以下任一项成立，下一真实开盘请求全部退出：

1. 本笔固定新模型连续两个持仓收盘预测继续持有的净收益为负。
2. 原六十日日内相对隔夜强弱连续两个收盘严格小于零。
3. 实际含费用和已确认分红的本笔亏损达到6%。
4. 含分红持仓价值从本笔最高点回撤达到8%。
5. 含买入日在内已持有60个收盘交易日。

退出请求一旦形成就持续到实际卖完，随后预测转正也不能撤销；受阻逐日继续请求。实际退出后，空仓期间先等旧进入条件消失，再等新条件形成，并满足两交易日等待，才能再次进入。
