# 510300波动压缩是否为变盘点：冻结事件研究V1

## 1. 要回答的两个问题

“波动变小”不能直接等同于“要涨”或“要跌”。本研究分开检验：

1. 波动压缩后，未来5、20、60个交易日的振幅或实现波动是否扩大；
2. 压缩时点是否能提前判断向上、向下或趋势反转。

只有第一个问题成立时，它最多是“变盘准备区”。方向仍需由随后发生的价格突破确认。

## 2. 两个固定定义

### 2.1 对话字面规则

日振幅定义为 `(复权最高价-复权最低价)/前一日复权收盘价`。

事件日要求：最近20日平均日振幅位于0.5%至1.0%，紧邻的此前20日平均日振幅位于1.5%至2.5%。该规则直接对应用户提供交流中的数值，不根据结果调整。

### 2.2 尺度无关规则

用复权收盘对数收益计算年化RV5、RV20、RV60。事件日同时满足：

- `RV5 < RV20 < RV60`；
- RV20不高于此前756个交易日RV20历史分布的20%分位；
- 分位数只使用事件日前已经知道的数据，至少需要504个历史观测。

该规则用于避免固定百分比受到510300长期波动水平变化影响。

## 3. 事件和结果

- 条件连续成立时只取第一天；事件之间至少间隔20个交易日。
- 主结果窗口为未来20个交易日，并补充5日和60日。
- 报告未来平均振幅相对当前20日平均振幅的倍数、扩张比例、绝对收益、最大上下行、首次突破方向和前后20日方向反转。
- 向上/向下突破以事件日之前20日最高价和最低价为边界，事件当日不进入边界计算。

## 4. 匹配对照

每个事件只与当时20日平均振幅相差不超过10%的普通日期比较，排除事件附近20日。固定随机种子进行5000次逐事件匹配，避免把单纯的低波动均值回归误认为“压缩形态”有额外信息。

如果任一事件少于20个匹配日期，则匹配对照输出证据不足，不临时放宽范围。

## 5. 固定判定

波动准备状态同时要求：

- 成熟事件不少于10个；
- 未来20日振幅比中位数大于1；
- 至少60%的事件出现振幅扩张；
- 相对匹配对照的分位数不低于95%。

方向信号要求未来20日有符号收益相对匹配对照达到双侧5%显著性。未达到时，不得把波动压缩直接翻译成买入或卖出。

## 6. 边界

这是历史污染的事件研究，不修改现有策略，不生成目标仓位、订单或券商连接。参数邻域和替代阈值不得在看到结果后追加。
