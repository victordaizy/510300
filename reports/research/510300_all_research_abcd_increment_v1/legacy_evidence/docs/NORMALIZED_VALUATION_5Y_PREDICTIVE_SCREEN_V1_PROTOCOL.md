# VAL01/VAL02 五年正常化估值预测屏幕协议

状态：`RESEARCH_ONLY / HISTORICALLY_CONTAMINATED`  
版本：`1.0.0`  
主要期限：`242个共同交易日`  
仓位、策略净值、当前建议、订单与券商连接：`全部禁用`

## 1. 目的与物理隔离

本协议分别检验`VAL01_NORM_EY_5Y_V1`和`VAL02_NORM_EY_SPREAD_5Y_V1`的冻结60月分位，是否与随后T+1开盘可捕获的中长期收益同向。两个模型共享同一张已经冻结的标签表，但使用各自物理隔离的信号文件，分别输出完整诊断与结论。

标签表共183行：61个观察日乘60、120、242三个期限。标签表不含任何EY、利差或分位值；程序只在内存中按观察日连接。不得重新生成标签、移动2026-08-12数据截止日或使用本地后来新增行情。

## 2. 可捕获收益标签

信号在月度快照日收盘后可得，入场为严格晚于信号日的第一个510300、000300和H00300共同交易日开盘；入场日计为持有第1日，第H个共同交易日收盘到期。主目标是510300含现金分红隐含复投的242日毛收益，H00300全收益作确认。60和120日只作诊断，不能在看到结果后升级。

到截止日应分别有58、55、49个成熟样本和3、6、12个右删失样本。任何数量漂移都停止评价。

## 3. 单模型冻结诊断

每个期限分别报告：Spearman IC、时间前后半段IC、四个冻结分档的样本数/均值/中位数/正收益率、最高档减最低档的均值与中位数差，以及对收益秩回归分位秩的Newey-West HAC斜率、t值和单侧p值。HAC滞后固定为2、5、12个月，收益重叠时不得引用普通独立样本p值。

242日主屏幕除家族p值外还必须全部满足：成熟样本不少于36、每档不少于5、ETF全样本与前后半段IC均严格为正、四档均值非递减、最高减最低档均值和中位数均为正、H00300 IC及均值档差均为正。

## 4. 两模型家族校正

VAL01和VAL02各贡献一个主要HAC单侧p值，家族显著性水平固定0.10，采用Holm-Bonferroni：先按p值升序排列，最小p必须不高于0.05；若通过，第二个p必须不高于0.10。报告同时给出Holm调整p值，单模型只能在调整p值不高于0.10且其他全部硬门槛通过时获得预测屏幕通过。

不得因为两个信号相关而只报告较好者，也不得用未校正p值替代家族结论。

## 5. 终点与停止条件

通过状态只能是`HISTORICAL_PREDICTIVE_SCREEN_PASS_STRATEGY_EVALUATION_NOT_RUN`，允许后续另行冻结策略评估协议；失败状态为`REJECT_PREDICTIVE_SCREEN_STOP_NO_STRATEGY_BACKTEST`，必须停止该模型，不得改分档、改主要期限、改正常化公式或用仓位回测补救。

全部证据来自事后重建，预测屏幕通过也不能成为`ALPHA_PASS`。真实前向起点保持为空。
