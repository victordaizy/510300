# 第162轮：按日内相对隔夜强弱的排序，决定进入与退出

第161轮持续回撤双风险上限已完成，四项净夏普仍不足一点二。第162轮改检验日内相对隔夜强弱的持续性：将最近六十日差值的大小转成排序，再按正负方向汇总，减少单个极端幅度对信号的影响。只做一套无需训练的规则，仍使用已有免费行情。

## 全部因素

1. 当天隔夜对数变化：开盘价加当日每份分红，除以前收盘价，再取自然对数。
2. 当天日内对数变化：收盘价加当日每份分红，除以开盘价加当日每份分红，再取自然对数。
3. 当天相对强弱差：日内对数变化减去隔夜对数变化。
4. 六十日带符号排序分数：取包含今天在内的最近六十个完整差值。精确为零的差值保留为已知平局，但不参与非零值的排序；非零差值按绝对值从小到大排第一、第二直至最后，绝对值精确相同者共享其所占位置的平均名次。将正差值的名次相加，减去负差值的名次合计，再除以所有非零名次平方合计的平方根。六十日全部为零时，分数定义为已知零。
5. 连续确认状态：分数连续两个收盘严格大于一点九六，方向转为允许持有；分数连续两个收盘严格小于零，方向转为不允许持有。其余已知分数延续原方向，并分别更新或清零相应连续计数。
6. 当前二十日年化波动：最近二十个含分红简单日收益的样本标准差，乘二百四十二的平方根。
7. 目标持有比例：允许持有且普通波动完整大于零时，取百分之十除以年化波动，上限百分之百；不允许持有时目标为零。

初次具备完整六十日差值窗口时，从不允许持有和两个零计数开始，当天参与第一次计数。每日使用完整市场日历递推，不在实际入场日或评价起点重置方向。缺失窗口当天分数及目标未知，清除内部方向和计数；恢复完整六十日窗口后重新起步。窗口中已知零差值与资料缺失不是一回事，不得删除缺失行凑满窗口。

分数只在非零差值内部排名。绝对值相近但在保存数值上不同的差值，不临时合并或四舍五入成平局。因子来源版本和数值精度固定，全部非零个数、正负名次和、名次平方和及分数均保存。

排序定义参考[SciPy的Wilcoxon带符号秩说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.wilcoxon.html)，该文说明绝对差排序、零差和平局的处理。本轮使用明确的标准化带符号秩分数，零差不排序、平局平均名次、无连续性修正；不是把库的双侧统计量或概率直接用作仓位。一点九六只是本轮事先固定的进入门槛，不宣称金融日收益独立、对称，也不把它称为已证明的百分之九十五交易置信度。

## 进入、退出、加减仓与再次进入

每天收盘后确定目标，下一开盘实际成交。空仓遇到正目标，按上一收盘本账户净资产与原始收盘价计算目标份额，向下取一百份整手，直接尝试买入。

已有持仓且目标为正时，目标比例与当前股票市值占净资产的比例相差不足十个百分点则维持份额；达到十个百分点则调至目标中心。方向因连续两次负分数转为不允许持有后，零目标请求全部退出。正目标因整手取整可能为零；终点开盘优先清仓。

退出后，市场方向再次满足允许持有、且正目标可执行即可进入，没有额外等待期。已有持仓不锁定入场版本，不设置学习退出、固定止盈止损或持仓期限。买卖受阻后，下一收盘根据最新目标重新决定；未知目标保持现有份额，不能补为零目标或未来信号。

## 与原方法的关系

原六十日日内隔夜强弱使用实际差值之和及其波动标准化，大幅异常变化能直接改变信号。本轮使用差值的正负和大小排序，改变实际进入与退出依据，不继承原自然参考周期或学习模型，也不修改原冻结差值方法的窗口、阈值或来源。旧成分广度统计同一天有多少成分上涨，本轮统计同一ETF跨日的日内与隔夜差值；对象不同。

本轮不使用第161轮趋势与持续回撤上限，不改变第160轮累积触发阈值救回失败。一次固定的排序规则，不能随后选最有利的平局精度、零差处理、方向、阈值或确认天数。
