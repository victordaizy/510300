# 第166轮实际退出口径补充

本说明补充中文表述，不修改已冻结策略、目标、执行程序或已保存收益。

原说明中的“两套目标都明确为零才全部退出”只完整描述了信号目标归零的情况，还需要结合既定一百份整手和调仓带理解。完整实际执行有以下情况：

1. 合成目标明确为零，请求下一开盘全部卖出，不受调仓带阻拦。
2. 合成目标为正，已有持仓与目标相差达到十个百分点，执行调至目标中心；若目标份额向下取一百份整手后为零，也会卖出全部。若仍在已有持仓调仓带内，则保持原份额。
3. 空仓时，正目标对应份额不足一百份，不会买入。
4. 固定历史终点按开盘优先全部清算，不继续执行前一收盘的新买入或持有目标。
5. 目标未知时保持实际份额，不能补成上述任何一种已知零目标。

保存结果中，2021年1月19日合成目标约百分之零点零二三六八三，触发调至中心后取整为零。1月20日开盘基础账户实际卖出一万一千份，压力账户卖出一万零九百份。当天属于正目标但实际清仓的整手边界，已经计入本轮结果，没有新增或重跑账户。

因此主历史每档费用有四百四十五个正目标收盘，但只有四百四十三个实际持仓收盘：一处来自上述整手取整清仓，另一处来自2026年8月14日终点开盘清算。较早历史正目标比持仓收盘多一，则来自2019年12月31日终点开盘清算。
