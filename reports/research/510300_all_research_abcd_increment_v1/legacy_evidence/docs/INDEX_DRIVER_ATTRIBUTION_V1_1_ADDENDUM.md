# 510300 点时指数驱动归因 V1.1 修订说明

父版本：`510300_INDEX_DRIVER_ATTRIBUTION_V1`  
父版本状态：`FROZEN_BUILD_BLOCKED_BY_DUPLICATE_SAME_L1_INTERVALS`  
本版本状态：`ATTRIBUTION_ONLY`

## 修订原因

V1 在首次真实构建时发现：中信行业源可能因二、三级行业变更，对同一证券保存多条时间重叠记录；这些记录在一级行业上完全一致。2019-12-23 有 51 只证券出现这种情况，但没有证券同时属于两个不同的中信一级行业。

V1 把任何重叠记录都视为一级行业冲突，因此在读取收益或生成归因结果前安全停止。V1 冻结文件和清单保持不变。

## 唯一实现修订

V1.1 在进入 V1 归因 module 前增加中信一级区间归一化：

- 同一证券、同一一级行业、同一来源和同一分类用途的重叠或相邻区间合并；
- 空 `out_date` 视为持续有效；
- 不同一级行业的重叠区间绝不合并；
- 归一化后若同一证券同一日仍匹配多个一级行业，继续硬失败；
- 权重、收益、行业覆盖、贡献恒等式、日期范围和全部治理状态与 V1 完全相同。

本修订不读取未来收益，不改变任何门槛，不增加预测变量，也不定义鱼中或鱼尾。
