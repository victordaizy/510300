# 510300 MACRO-01：M2增速加速度 × 长期趋势确认

## 1. 研究边界

本协议响应“抓大放小”，检验总量货币环境，而不是继续寻找510300局部交易拥挤指标。它是与现行`510300_ONLY`系统隔离的扩展发现研究：只交易510300，但使用外部宏观信号；不修改现行策略，不生成Paper信号、仓位或订单。

数据不是逐月公告原始快照，而是当前历史版本，虽经人民银行8个数值抽查，但仍可能含事后修订。因此本版本最高结论只能是“值得重建历史快照”，不能直接授权任何交易用途。

## 2. 冻结假设

经济机制只有一条：M2同比增速持续加快，代表总量货币环境边际扩张；若510300自身也处于长期上升趋势，流动性更可能进入大盘权益定价。只有宏观加速而价格仍在长期下降趋势时，不假定政策已经转化为可捕捉收益。

冻结变量如下：

- `M2_ACCEL_6M(t) = M2同比(t) - M2同比(t-6个月)`；
- `TREND200(t) = 510300含现金分红总回报指数(t) > SMA200(t)`；
- `RISK_ON = M2_ACCEL_6M > 0 且 TREND200 = True`；
- 风险开启目标98.5%，否则25%；
- 不检验3个月、9个月或12个月M2变化，不检验120日、250日均线，不改变阈值0。

## 3. 点时与成交

每个统计月的M2统一视为次月20日才可用，不使用真实公告更早发布所带来的优势。次月20日或之后首个510300交易日收盘，结合当日已知的总回报指数与200日均线形成目标；再于下一个交易日开盘成交。

该规则使用日线，不使用分钟线。回测执行510300 T+1约束的保守长仓/现金引擎、100份整手、至少5000元成交金额、每笔佣金`max(成交额×0.03%, 5元)`、基础5bp及压力15bp滑点。现金年化1.5%。

## 4. 比较对象

同一起点比较四类路径：

1. M2与趋势同时确认的冻结策略；
2. 仅200日趋势确认的同暴露策略；
3. 仅M2加速的同暴露策略；
4. 静态60%与98.5%买入持有。

M2必须相对“仅趋势”带来增量，而不能把已有趋势效果误记为宏观因子。

## 5. 否证门槛

预测层先在`TREND200=True`月份比较M2加速与未加速的下一完整信号区间510300超现金收益。两组各不少于15期，总完整区间不少于80期；差值必须为正，6个月区块Bootstrap的95%下界必须大于0，HAC回归中M2加速度系数必须为正且单侧`p<=0.05`，两个时间半样本均应为正。

策略层还必须同时满足：基础/压力夏普不低于0.80/0.60；相对静态60%的月度超额盈利因子不低于1.25/1.10；基础夏普至少比仅趋势高0.10；基础和压力CAGR均高于静态60%；三个子期至少两个跑赢静态60%；单一年份正贡献占比不高于50%。

任一门槛失败即`REJECT_DISCOVERY_STOP_NO_RESCUE`。不得在看到结果后修改M2窗口、均线、暴露、数据起点或增加过滤器。

## 6. 通过后仍禁止的事项

即使全部统计门槛通过，当前历史版本也不满足逐月原始快照要求，结论只能是`DISCOVERY_PASS_REQUIRES_VINTAGE_RECONSTRUCTION`。下一步必须另立数据协议恢复逐月公告值与公告时间，再独立冻结Paper观察协议；本版本不连接券商、不下单、不启用仓位映射。
