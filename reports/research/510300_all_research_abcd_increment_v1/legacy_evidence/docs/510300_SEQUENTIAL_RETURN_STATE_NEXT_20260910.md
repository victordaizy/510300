# 下一项：用每天累积的上涨和下跌证据决定进入与退出

第159轮八曲线退出已经算完，四个净夏普仍未达到一点二。第160轮转向同时建立新的进入、退出和风险仓位：从完整市场每日收益持续识别方向，方向转强进入、转弱退出，持有比例受当时波动约束。只做一套固定设置，不训练收益模型，不补外部数据。

## 全部因素和状态

1. 当天含分红简单收益：当天收盘价加当日每份分红，除以前一交易日收盘价，再减一。
2. 前二十日波动：只用昨天及其之前连续二十个交易日的上述收益，计算样本标准差，不年化。今天的涨跌不进入这个分母。
3. 当天标准化涨跌：当天含分红简单收益除以前二十日波动，基准收益为零，不减去滚动平均收益，不截断极端值。
4. 累积上涨证据：昨天的累积上涨值加今天标准化涨跌，再减零点五；若结果低于零，则取零。
5. 累积下跌证据：昨天的累积下跌值减今天标准化涨跌，再减零点五；若结果低于零，则取零。
6. 方向状态：上涨证据达到五时转为上涨，下跌证据达到五时转为非上涨；没有新触发则延续原状态。初次具备完整输入时从非上涨状态和两个零累积量开始，当天即计入更新。每次任一方向触发后，将两个累积量同时归零，再从下一天积累；同方向再次触发也执行归零。
7. 当前二十日年化波动：包含今天的连续二十日含分红简单收益样本标准差，乘二百四十二的平方根。
8. 目标持有比例：上涨状态下，百分之十除以当前二十日年化波动，上限百分之百；非上涨状态为零。

每天保存触发前的两项累积证据、是否触发上涨或下跌、触发后的两项累积量、方向状态、两个波动值以及目标比例。百分之十是仓位计算的固定波动预算，不是账户实现波动或收益保证。

前二十日波动必须大于万亿分之一，收益与窗口均须有限且完整；不完整、零波动或无效时，当天方向和目标未知，清除内部方向及累积量，不能跨缺失拼接证据。恢复完整有效输入后重新从非上涨与零累积量开始。上涨方向若当前仓位波动缺失或不大于零，目标未知；明确非上涨状态仍对应已知零目标。未知目标交给原账户的无新目标处理，不能伪造为零仓位或填入旧数值。

每天标准化涨跌为实数，两项累积量在上次触发后均低于五，因此同一天不应同时触发两个方向；出现这种矛盾按程序错误处理，不能临时择取有利方向。

## 进入、加减仓、全部退出与再次进入

收盘后形成当天目标，在下一交易日真实开盘执行。目标严格大于零时，按本账户上一收盘净资产计算希望持有的份额；目标等于零时请求全部退出。持仓中，目标因市场方向或波动改变而更新，不固定在首次买入日。

沿用已保存目标账户的百分之十绝对仓位调仓带：比较目标比例和本账户当前股票市值占上一收盘净资产的比例，偏差达到十个百分点时调至目标中心；小于十个百分点时维持份额。明确零目标或终点开盘仍请求全部退出。具体整手、资金与买卖约束由原账户统一处理。此处没有原日内隔夜强弱进入条件、学习退出、固定持有期限、固定止盈止损线，也不复用任何旧策略的目标路径。

目标由市场状态持续形成，空仓时出现可执行的正目标便可重新进入，不额外等待进入条件先消失。退出受方向跌停或次日可卖等约束而未成交，下一收盘按最新已知目标重新决定请求；本方法不设置每笔不可撤销的退出锁。未知目标不产生新的仓位指令，终点真实开盘优先清算。

## 与已经做过的方法的区别

第60轮在实际买入后固定入场前六十日平均收益和波动，只监测单笔持仓的累积转弱，并保留原进入和学习退出；旧事件生命周期方法监测已经完成的事件收益，决定是否禁止新进入。本轮在完整市场日历上持续使用每天更新的、前二十日波动与零收益基准，双向触发市场方向，直接决定进入和退出，不以实际持仓周期或已完成策略事件为检测对象。旧失败记录保持关闭。

累积量采用[美国国家标准与技术研究院的累积和控制图说明](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc323.htm)中的上下两侧递推结构。零点五容忍和五的阈值在本轮事前固定。将工业过程检测用于市场方向属于本研究假设，来源不提供交易获利结论。不另试邻近阈值、波动窗口、基准均值、重置方法或仓位预算。

## 四个完整账户与必要验证

主历史为2020年1月2日至2026年8月14日开盘，较早历史为2015年1月5日至2019年12月31日开盘。因素均从共用完整历史起点顺序计算，较早阶段只读取当时历史前缀，不能在评价起点人为选择趋势状态或清除不利信号。

每账户二十万元本金，年化二百四十二日，现金收益与无风险收益为零。基础费用为每边佣金万分之二、最低五元及名义滑点万分之五；压力费用为每边佣金万分之四、最低五元及名义滑点千分之一。保留一百份整手、零点零零一元价位、原百分之十方向限价、次日可卖、下一开盘真实价格、买入资金不足约束、分红登记与除息及到账分别处理、终点开盘清算。

只新增四条账户，复用143趋势波动连续预算、131普通波动预算和买入持有的完整账本，每段共八条比较记录。不训练新模型、不新建参考账户、不重跑旧研究。必要测试覆盖可手算双向递推、恰好达到阈值、触发重置和状态延续、缺失中断、波动仅用此前二十日、未来数据隔离、目标和调仓带、真实次日执行及分红。

先完成必要测试，再一次冻结、计算全历史因素和四账户。核对保存的每日方向、目标与真实净值，只报告实际得到的夏普、年化、回撤、交易和费用。完整目标仍为净夏普至少一点二、稳定超额与独立证据；不通过则关闭这套固定结构。此文为第160轮事前方案，尚未实现、测试、冻结或计算新账户。
