## 2. 风险比率

定义：

$$
q_t=
\frac{
\widehat{DSV5}^{B1}_t
}{
\widehat{DSV5}^{B0}_t
}
$$

解释：

* \(q_t=1\)：B1认为未来下行风险与扩展历史均值相近；
* \(q_t>1\)：价格路径显示未来下行风险高于正常水平；
* \(q_t<1\)：预测风险低于正常水平。

连续风险预算：

$$
w_t^*
=
\operatorname{clip}
\left(
q_t^{-1/2},
0.25,
1.00
\right)
$$

之所以使用平方根，是因为DSV5是方差尺度。目标仓位应与预测下行标准差成反比，而不是与方差直接成反比。

---

## 3. 离散仓位

将 \(w_t^*\) 映射到最近的仓位档：

```text
25%
50%
75%
100%
```

距离相等时选择较低仓位。

等价风险比边界为：

|        B1/B0预测风险比 \(q_t\) | 目标仓位 |
| ------------------------: | ---: |
|        \(q_t \le 1.3061\) | 100% |
| \(1.3061 < q_t \le 2.56\) |  75% |
| \(2.56 < q_t \le 7.1111\) |  50% |
|          \(q_t > 7.1111\) |  25% |

这避免“预测风险只比正常值高1%就立刻减仓25个百分点”。

第一版不允许0%仓位，因为B1只证明了风险预测，不证明高风险时未来收益一定为负。

---

## 4. 调仓时钟

使用父实验主网格的固定五交易日原点：

```text
t日收盘后：
读取已冻结B1预测，计算目标仓位

t+1下一可交易日开盘：
执行至目标仓位

随后持有：
直到下一个五交易日原点
```

第一版采用**对称调整**：

```text

50% → 100%：一次完成
```

不加入“快速减仓、慢速恢复”，因为这会引入新的路径参数。若对称风险预算本身不能创造价值，不能靠恢复速度救援。

`NO_VIEW`时：

```text

不自动回到100%
不自动转为现金
不前值填补预测
```
