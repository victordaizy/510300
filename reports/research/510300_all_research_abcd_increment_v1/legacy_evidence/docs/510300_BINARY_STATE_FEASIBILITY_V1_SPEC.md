# 510300 满仓/空仓二元状态可行性前沿 V1

状态：`PREFREEZE_IMPLEMENTATION_COMPLETE`  
证据：`HISTORICALLY_CONTAMINATED_PERFECT_FORESIGHT_DIAGNOSTIC_ONLY`  
对象：只持有 `510300.SH` 或现金，目标仓位只能为 `100%` 或 `0%`

## 1. 本研究只回答一个问题

在 50 万元、不加杠杆、不卖空、不使用期货或期权、T 日收盘决策并于 T+1 开盘执行的条件下，二元择时要达到相对 `H00300` 沪深300全收益指数年化净超额 20 个百分点，究竟需要多接近完美预知。

本研究不是策略候选，不寻找历史最佳指标，不生成当日状态，不生成 Paper、Shadow、仓位、订单或券商动作。它只建立后续候选不得回避的经济可行性前沿。

## 2. 冻结目标与成本

主指标沿用 `510300_ANNUAL_EXCESS_20PCT_FORWARD_V1`：

`StrategyNetCAGR - H00300TotalReturnCAGR >= 20%`

同时要求 242 个交易日滚动年化超额中位数不低于 20%。每条成交腿扣万分之一佣金；基础滑点为每腿 5bp，压力滑点为每腿 15bp；现金年化收益固定 1.5%。目标状态严格限定为 `{0, 1}`，满仓状态收到现金分红后在下一可交易开盘按 100 份整手重新投入。

## 3. 完美方向块神谕

固定检验 1、5、20、60、121、242 个交易日六种决策块。每个完整块只允许一个状态：

- 若从块首日开盘到块末日收盘的 510300 含分红毛终值高于同期现金终值，整块满仓；
- 否则整块空仓。

标签选择故意忽略交易成本，但实际组合路径完整扣除佣金和基础/压力滑点，因此结果是“完美方向信息在真实成本下的诊断前沿”，不是可实现收益。每个周期遍历全部日历错位，末尾不完整块统一排除，不允许挑选最有利起点充当主结论。

## 4. 20日识别精度前沿

以 20 日块、首个日历错位为固定基准，分别扰动两类错误：

- 坏块召回率：真实应空仓的块中，被正确识别并空仓的比例；
- 误退出率：真实应满仓的块中，被错误识别为空仓的比例。

固定召回率 `{50%,60%,70%,80%,90%,100%}`，误退出率 `{0%,10%,20%}`，每格 50 次，随机种子 `20260827`，只使用压力成本。输出每格年化超额和滚动超额中位数的中位数、10%与90%分位，以及同时达到两项 20%门槛的比例。

## 5. 数据与边界

历史输入固定为 2012-05-28 至 2026-08-14 的 510300 日线、H00300 全收益收盘和 510300 完整现金分红。该历史已经被反复查看，所有结果只能解释为可行性诊断。

若连完美方向块神谕在压力成本下都不能达到目标，对应决策周期直接排除；若神谕可以达到，结论也只能是“数学上仍有空间”，不能把神谕收益当作候选业绩。后续独立候选必须在首次读取历史结果前另行冻结，且不得反推修改本研究的周期、成本、错位或标签。
