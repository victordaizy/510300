**我的判断是：下一阶段最值得集中研究的，是“新信息出现后，资金调整是否仍在持续，以及这段调整能否带来尚未兑现的收益”。**

宏观信息、资金行为和技术分析可以围绕这个问题组织起来。我们需要回答的是：

> **在现在能够成交的价格上，未来继续持有 510300，相比持有现金，是否仍有足以覆盖成本和风险的优势？这个优势来自什么，会被什么新证据推翻？**

这能把你说的提前定价、突发消息、市场逻辑变化、主力行为和支撑位，放进同一套可检验的研究框架。

## 一、仓库已经揭示：问题不只是因子失效，也包括信息重复和检验尚未完成

这次核对仓库，有三项记录特别重要。

**第一，策略名称很多，实际承担的风险可能高度重复。**早期 24 个底层候选的日收益相关系数中位数为 **0.5221**，收益协方差的参与率约 **2.41**。后者是样本内的线性维度诊断，不能直接解释为“只有 2.41 个独立策略”，但已经说明：增加指标、窗口和模型名称，不一定增加独立的信息来源。

**第二，市场会变化，并不意味着“自动选择最近表现好的策略”就能适应变化。**仓库对 27 个选择区间的诊断发现，过去 504 日夏普排名与下一阶段收益排名的平均相关系数约为 **−0.0398**。原来的切换规则没有找到可靠的延续性。继续叠加一个“智能选择器”，仍需要重新证明它的作用。

**第三，有些方向根本还没有完成收益检验。**例如 `NBS_1000_NEGATIVE_INFORMATION_DRIFT_V2` 已整理出合格事件，但在分钟数据质量检查阶段终止，尚未构造收益目标、训练事件模型或运行账户。它的状态是“数据未通过原定准入条件”，不能归入“宏观信息延迟反应已经被证伪”。

因此，已有研究需要按失败原因区分：信息本身无增量、交易成本吃掉优势、数据不合格、实现有问题、证据不足。把它们全部解释成“量化机构把因子做失效了”，会误判下一步。

公开因子在被发现、传播后发生收益衰减，确实有研究支持。McLean 与 Pontiff 对 97 个股票横截面预测变量的研究发现，样本外和发表后的收益明显下降。但这项历史研究不能直接证明当前 510300 的每一种失败，都来自机构竞争。([Wiley Online Library][1])

## 二、你真正关注的，是“消息之后还剩下多少行情”

你提出的几种情形，需要分开处理：

| 当时的情况               | 应当检验的问题                       |
| ------------------- | ----------------------------- |
| 消息基本符合预期，价格此前已经明显变化 | 公布之后是否还有新增信息或持续资金需求？          |
| 消息明显超出事前预期          | 第一轮反应之后，是否还有延续？               |
| 消息方向与价格反应相反         | 是预期已兑现、其他信息抵消，还是我们对消息含义的判断有误？ |
| 同类消息在不同阶段产生相反反应     | 当时哪些可观察条件，能够区分这些阶段？           |

**“利好没涨”不能直接认定为低估，“利空不跌”也不能直接认定为主力吸筹。**这些现象需要竞争性解释，随后用数据区分。

以降息为例，同一次公告可能同时包含融资条件变化和对经济前景的新信息。Jarociński 与 Karadi 的研究正是利用公告窗口中利率与股价的联合变化，区分货币政策冲击和央行信息冲击；两类冲击的经济含义不同。([AEA Publications][2])

对应到我们的研究，我建议先观察两个层次：

**消息层：**实际公布了什么，相比有时间证据的事前预期改变了什么。

**市场反应层：**利率、汇率、相关股票和 510300 如何反应；反应是否扩散，还是很快被抵消。

然后只预测**这两个层次已经可以观察之后**的走势。

例如，晚上公布数据，第二天市场完成第一轮交易，我们在第二天收盘形成判断，第三天开盘执行。那么前面的跳空和第一天上涨，只能作为输入，不能再计入策略赚到的收益。

**能够解释公告后为什么涨，与能够在看到公告和初始反应后继续赚钱，是两项不同的检验。**

这正是你现在那六次事件分析需要继续推进的一步。

## 三、“主力的想法”应转化为资金约束和可观察行为

我建议把研究问题写成：

> **哪些参与者可能需要继续调整风险敞口？这种调整为什么无法立即完成？我们能观察到哪些证据？**

这样才有机会从解释过去，推进到预测下一段买卖需求。

Gabaix 与 Koijen 的“非弹性市场”研究提供了一个相关机制：机构受到配置比例、投资授权等约束时，资金流动可能对价格产生较大影响。这里的关键是资金需求与约束，研究本身并没有证明我们能够实时识别 510300 的下一段资金流。([National Bureau of Economic Research][3])

据此，我会保留两条明确、方向不同的假设：

| 假设             | 为什么可能有后续行情               | 什么结果会削弱它                        |
| -------------- | ------------------------ | ------------------------------- |
| **信息更新后的持续调整** | 新信息引发配置或盈利预期调整，实际买卖分阶段完成 | 延迟到可成交时点后，收益消失；或加入消息信息后并不优于单纯趋势 |
| **暂时买卖压力后的回归** | 价格受到阶段性资金压力影响，压力缓解后部分恢复  | 所谓“压力”无法在当时识别；或后续变化更符合持续基本面恶化   |

这两条需要分别检验。不能在上涨时解释成持续调整，下跌反弹时解释成压力释放，让任何结果都支持同一个故事。

资金数据也有明确边界。ETF 实物申购可以通过交付股票篮子创造份额，所以份额增加本身不能确定新增资金的来源或最终方向性意图。期货持仓量记录未平仓合约数量，单独增加也不足以判断净看多意愿。([Shanghai Stock Exchange ETF][4])

因此，“份额增加＋价格上涨＋基差变化”等组合可以成为待检验的观察条件，但不能直接贴上“主力准备拉升”的标签。

## 四、仓库里的因子应重新分工，避免全部参与一次投票

仓库已有价格动量、均线偏离、波动、回撤、隔夜与日内收益、海外市场、盈利预测、资金来源和多种退出规则。下面是我建议的用途划分，**不代表这些用途已经被验证有效**。

| 信息类别               | 主要回答的问题                 |
| ------------------ | ----------------------- |
| M1/M2、盈利预测修正、公告内容  | 经济预期发生了什么变化？            |
| 事前共识、利率与相关市场变化     | 哪部分变化超出了此前预期？           |
| 动量、均线、市场广度、隔夜与日内结构 | 价格是否已经响应，响应是否继续扩散？      |
| 份额、申赎、折溢价、期货相关数据   | 是否存在可观察的持续买卖压力？         |
| 波动、下行波动、振幅、回撤      | 这次判断需要承担多大风险？           |
| 支撑、阻力、回踩、突破结构      | 在什么价格执行，什么变化意味着原判断需要重审？ |

**同一段价格上涨产生的均线突破、MACD 变化和动量增强，不能自动算成三份独立证据。**这些变换可能帮助模型表达不同形态，但并没有凭空增加三条新的经济信息。

### 支撑位可以保留，但必须具备事前定义

例如，只选择一种已经固定的支撑定义：事件发生前某个固定窗口的低点。记录当前价格与该位置的距离，再用当时已知波动幅度进行标准化。

真正需要研究的是：

> 在相似消息、趋势和波动条件下，接近这个位置后，从实际成交价开始计算的收益和下行风险，是否得到改善？

不能用后来反弹成功的谷底倒画支撑，也不能把“碰到支撑”直接等同于值得买入。

**消息提供条件，价格结构提供执行和失效信息。两者各自需要证明增量。**

## 五、适应市场变化，应当包含“暂时没有可靠判断”

你说市场逻辑会改变，这要求系统能够更新判断，也要求它允许出现“当前证据不足”。

我建议把变化分成两类。

**冲击含义变化。**同样的利率变化，在不同的股票、汇率和信用市场反应下，可能对应不同的经济解释。研究时记录这些联合反应，并检验它们是否改善后续预测，避免事后给每段行情换一个解释。

**原有关系失去预测能力。**观察模型已经成熟的预测误差、方向偏差和风险低估情况，并与固定基准比较。退化时先降低对该信号的依赖，不立即切换到最近净值最好看的另一个模型。

这里必须保留识别延迟。任何声称能在市场转折当下准确知道“旧逻辑结束、新逻辑开始”的回测，都需要检查是否使用了事后划分的牛熊区间、全样本状态识别或未来数据。

你的政策数据还有一个相关问题：作者明确说明公开因子由全样本 PCA 估计，而且因子使用公告日期的金融衍生品价格变化构造。交易研究既要解决逐期估计，也要确保收益预测从输入价格已经可观察之后开始。直接把全样本因子与同时段股价反应关联起来，无法证明可交易预测能力。([Harrison Shieh | Vassar College][5])

## 六、下一轮应做一个可以明确判输赢的实验

我建议把主问题固定为：

> **在控制已经发生的价格变化与波动后，新增信息及资金行为，能否改善随后五个交易日的净收益判断？**

这是一项具体的研究问题。五日是建议预先冻结的主期限，没有证据说明它天然最优。

### 1. 固定事件和观察时点

事件应来自事前确定的公告类别和完整清单，不能只挑后来出现大行情的日期。缺少合格共识的月份保持缺失。

你目前六次 M1/M2 配对共识适合继续做案例核对，样本不足以同时训练消息方向、市场状态、资金确认和退出阈值。其他事件类型可以分别研究，但不能为了扩大样本，把经济含义不同的事件未经处理直接混在一起。

执行上，先采用容易审计的时钟：**公告后第一完整交易日收盘观察，下一交易日开盘执行**。这会主动放弃第一轮反应，也能直接检查我们寻找的延迟收益究竟还剩多少。

### 2. 只做四组对照

| 组别 | 使用信息                 | 要证明什么           |
| -- | -------------------- | --------------- |
| A  | 截至观察结束的价格与波动         | 简单基准能做到什么       |
| B  | A＋新增消息信息             | 消息是否提供价格之外的信息   |
| C  | A＋一种合格资金变量           | 资金变量是否提供增量      |
| D  | A＋消息＋资金，并仅保留一个预定交互关系 | 信息与资金结合是否具有额外价值 |

资金变量未通过时点和来源检查时，C、D 暂不运行。不能用成交量冒充真实申赎或订单流。

最重要的比较是 **B 对 A、C 对 A，以及 D 对 B/C**。若 D 只是因为承担更多股票仓位而收益更高，还需要与相近平均仓位、相近风险的简单基准比较。

这样可以回答：我们究竟找到了消息增量、资金增量，还是重新包装了价格趋势。

### 3. 提前写清楚什么情况判失败

关键判据应包括：延迟成交后优势是否仍在；费用提高后是否仍有经济意义；收益是否过度集中于少数事件；去掉消息或资金变量后，结果是否基本不变。

同一轮消息产生的重叠持有期不能当作大量独立样本。统计不确定性应按事件群或时间块处理，历史已经反复看过的事实也应保留。多重试验校正可以辅助判断，但需要纳入上游方法和参数选择，不能只校正最后留下的几个模型。Deflated Sharpe Ratio 研究针对的就是这类选择偏差与绩效膨胀。([DOI][6])

**这一步的成果应当是一项能明确保留或淘汰的信息增量，而非又一条恰好越过目标线的净值曲线。**

## 七、“上涨后回撤退出”与最终账户目标，需要最后接上

先固定入场规则，再用相同入场记录比较固定期限退出和一项预先设定的回撤退出，才能看清退出规则贡献了什么。

退出判断需要同时考虑“从高点跌了多少”和“原有的持有理由是否还在”。单纯见到浮盈回吐就卖，会形成一种可以测试的价格规则，但不能默认它提高收益风险比。

执行模拟必须保留跳空、滑点和可卖份额约束。股票 ETF 的 T+1 规则意味着当天新买入的份额无法因为盘中跌破某条线而立即卖出，止损价也不等于保证成交价。([Shanghai Stock Exchange ETF][4])

最终验收仍然是你要求的**完整账户成本后夏普至少 1.2、复合年化至少 10%**。这要求同时处理两个问题：单位风险上的优势，以及足够的可交易机会。少量事件中方向正确，无法直接推出全年账户达标；长期空仓也需要进入完整净值计算。

实际账户规模同样重要。你此前讨论过 2 万元，而仓库不少实验按 20 万元运行。仅作成本示例：一笔 5,000 元买入再卖出，若每边最低佣金 5 元，往返佣金已经是 **0.2%**，还未计滑点。最终规则要在真实本金下重新核算，不能按比例缩放收益。

**我对下一阶段的明确取舍是：优先验证“信息更新后的持续资金调整”，把“暂时压力后的回归”作为独立备选机制；技术指标负责描述价格反应和执行条件，波动率负责风险预算。**

你要找的优势，应该能回答一句具体的话：

> **别人现在为什么愿意以这个价格成交，而我们有何可核验的依据，认为未来几天的收益分布对持有者更有利？**

只要这句话能被数据支持，并在实际成交和费用之后成立，就值得继续投入研究资源。仅仅能解释过去、拟合曲线或猜测主力意图的部分，应当留在观察层。
