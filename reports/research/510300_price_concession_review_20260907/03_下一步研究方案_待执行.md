# 第一类价格让步：下一步研究方案（未执行、未登记策略）

**研究问题：收盘时可独立辨认的510300局部折价，是否在确认以后仍有可取得的份额，且优势可以保留到T+1合法退出？**

这是一份候选设计。它没有冻结新的交易时钟、价差阈值、持仓数量、退出规则或统计接受门，没有创建采集调度、信号账本或订单引擎。具体参数需依赖来源合同与经济依据制定，而不能从已看到的结果倒推。

**先交付一个最小来源可行性说明。**

| 问题 | 需要保存的直接证据 | 当前状态/失败含义 |
| --- | --- | --- |
| 能否及时确认510300官方收盘价与交易状态？ | 原始载荷、代码、收盘价、状态、源时间、本机到达时间、校时证据、纠正记录 | 本轮未抓取行情；未证实不能写成不存在折价 |
| 收盘参考是否包括股票集合竞价？ | PCF版本、现金项和单位、公司行动、底层价格所属时点、发布时间与到达时间、估值公式与误差来源 | 未提供新制度下合格同步样本；未过关时不能使用收盘前IOPV替代 |
| 免费源能否提供第3.7.9条字段？ | 15:05之后盘后成交量额、买卖实时申报量、单位和更新频率、源时间与接收时间、原始消息 | 规则字段存在，当前接口可用性未验证；不预设一定需要付费L2 |
| 能否区分竞价与盘后量额？ | 15:00保存量额、盘后量额、15:30日终量额及各自时间语义 | 无法区分时，不使用日终总量额作为盘后前决策特征 |
| 能否观测自身的成交可得性？ | 未来合法取得的订单接收、交易所确认、部分成交、撤单、拒单、费用明细 | 当前无券商连接授权；公开行情只能说明市场活动，无法确认本账户成交 |

首次可行性工作只判断字段是否真实存在、时钟与量纲是否可用，不计算折价后的收益分布。已有V6允许新方法研究；这里的先后顺序是节省无效工作的研究建议，并未新增全项目预测显著性前置门。

**随后明确共同价值与局部偏离的分解。**

为第一类保留两个互不替代的参考：以15:00收盘经济时点定义的参考价值V_close，以及截至实际决策截止时已收到的输入集合。后到的信息可以改善对15:00的估计，但必须明确它只是已发生价格的延迟到达，还是15:00以后新增的经济信息；后者不能混入第一类并在结果出来后切换解释。

主参考尽量从可核对的底层资产和现金出发，避免用510300自身价格拟合“合理值”。误差范围应包含现金替代、缺失与陈旧价格、公司行动、PCF与实际持仓差异；范围不能证明时保留NO_VIEW。所谓保守下界首先是有依据的估值误差边界，不自动等于统计95%置信下界。

只有保守估值仍显示价格让步超过适用费用，才值得研究它是否提供入场优势。这个条件并未处理掉隔夜市场风险，不能直接转成买入规则。是否增加同指数ETF交叉核对，需按可授权观察范围与可用数据选择固定集合，不从未来表现择优挑ETF。

**将观察、可执行报价和实际成交分成三个结果。**

每个观察记录至少应具备以下字段；这是一份字段要求，不是已生成的样本。

| 字段组 | 字段与语义 |
| --- | --- |
| 身份与时间 | 交易日、510300代码、来源原文标识、内容哈希、经济时点、源时间、到达时间、决策截止时间 |
| 参考与折价 | 官方收盘价、估计价值区间、各误差分量、输入覆盖、公司行动、申赎状态、参考可用状态 |
| 盘后市场 | 分阶段累计量额、申报量、快照间隔、字段缺失、撤单是否可见；不填未知的个人队列位置 |
| 未来自身执行 | 仅在另行授权后保存申报数量、确认时点、每笔成交数量/价格、订单状态和费用 |
| 合法退出 | 预先确定的下一交易日退出规则、可执行卖方报价与深度、分红、未能退出原因 |
| 结果口径 | 理论参考变动、可执行报价变化、实际成交净收益、计划资本贡献、完整账户每日净值分别保存 |

公开快照不能识别队列时，可以如实给出可识别数量范围，范围很宽甚至下界为0也应保留；不得把下界0写成实际未成交，更不能用盘后总量乘任意参与率制造成交率。模拟排队若以后实施，必须明示撤单、延迟和顺序假设，结果仍属于模拟。

**仅在可行性证据足够时，提出一次明确的候选验证。**

在新候选读取后续收益前，记录该候选与既有分支的实质区别、市场制度区间、来源/时钟、估值误差方法、唯一主要事件定义、数量与费用口径、合法退出、完整账户基准和接受/停止规则。新制度之前的数据可以支持独立的估值测量研究，不能冒充ETF盘后成交样本。

主报告需要同时说明：局部价差是否真实、收敛由ETF回升还是锚下跌造成、报价优势能否留到合法退出、未成交和部分成交对经济结果的影响。反复使用的历史数据要标记为历史重放；45个制度后交易日上反复筛选出的规则，不能声称经过独立验证。日内多个快照不增加相同数量的独立事件。

若研究完整账户，现金等待、跨日持仓、已有底仓（若设计包含）、分红应收/到账、最低佣金、未成交及异常退出都必须保留。净夏普目标仍为1.2。V2的60/120/180日、42/72bp和库存安排是V2自己的冻结设计，不直接移植成第一类的接受门，也不因本次建议而修改。

**建议停止或暂缓的情形。**

- 同步参考无法建立、误差范围大于所谓折价：保留NO_VIEW，停止方向和收益解释。
- 免费源不提供合格盘后字段：记录具体缺项和所试来源，暂缓成交可得性判断，不循环新增指标。
- 局部偏离主要由共同资产价格延迟造成：否定这一份测量定义，不把方向反转称作修复。
- 完整、可识别样本中折价经济量级不足：该候选停止，不通过删费用或缩短至无法合法退出的期限救援。
- 成交只能靠未知队列假设成立：结果限于报价诊断，不能称为实际成交优势。
- 新提案仅改写旧V1窗口、成本或代理以重新挑选事件：回到旧裁决，要求说明实质新增的制度或数据识别依据。

下一轮首先应交付来源样例、时间/量纲说明、误差可识别性和继续/停止结论。是否发展成完整账户策略由这些证据决定；本文件本身不授权券商连接、Paper/Shadow、订单或实盘。
