## 直接执行

只需要现有Python 3.10或更新版本。程序只使用标准库，不联网、不安装依赖、不购买数据、不接券商。

1. 解压本启动包。
2. 把原文件 `510300_第二轮两项结构比较_results_run2_20261002.zip` 放在 `run_closeout.py` 同一目录，原ZIP无需解压。
3. 在这个目录运行：

```powershell
python .\run_closeout.py --out .\results_closeout
```

程序自动先做合成自检，不需要另跑自检。源文件不在当前目录时：

```powershell
python .\run_closeout.py --source 'C:\完整路径\510300_第二轮两项结构比较_results_run2_20261002.zip' --out .\results_closeout
```

不允许覆盖非空输出目录。正常结束自动生成 `results_closeout_review.zip`，不用手工挑文件。失败保留FAILED.json及部分输出，部分输出不能称完成。

## 特别注意：延迟的确切含义

这次延迟的是目标信息。某天收盘用前一交易日目标，按当前已知价格/现金形成原合同订单，之后实际交易。行情和分红不移动，不能提前使用未来开盘。

它与“原订单价格数量完全冻结，多等一天才提交”不同。本程序按前者固定实施，报告单列，不把两者混为同一测试。额外延迟影响的也包括再平衡时钟和路径，不能将全部差额叫纯延迟成本。

同波动匹配系数使用完整已见历史，固定于重采样；这些是理想统计路径，没有额外模拟实际费率、整手及现金再平衡，匹配系数估计误差未纳入区间。它们不构成可执行收益证明。

历史净收益区块抽样未重演策略状态机，也不模拟未来制度变化，所得范围是条件近似，不是未来成功概率。没有规则能保证不返工；本包仅确认已在这一精确输入上跑通。
