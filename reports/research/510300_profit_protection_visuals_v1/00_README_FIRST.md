# 510300 图形补充：先上涨、再根据回撤退出

用户已明确选择“结合判断：涨幅较大后，再根据回撤决定退出”。本补充将这个想法画成可读的状态过程，并展示本轮 A、C 与 510300 买入持有的完整历史路径。

1. 先看 `01_先上涨后回撤退出_机制示意.png`：这是人工价格路径，解释启动保护、更新高点、收盘触发、次日开盘执行四个动作。
2. 再看 `02_实际历史_完整日度净值回撤仓位.png`：这是三个既有账户的实际历史模拟输出，每条曲线保留 1,624 个交易日。
3. 对照 `方法与规则说明.md`、`账户指标.json`、`完整日度净值回撤仓位.csv` 和 Parquet；人工路径另存在 `人工路径与逐日状态.csv`。
4. `来源与数值复核.json` 记录输入文件、哈希与数值对齐；`图形检查记录.json` 记录图形目视检查。
5. 外部评阅可直接复制 `GPT审阅提示词.md`。

机制图采用买入价 100、上涨 10% 启动、从滚动收盘高点回撤 5% 触发的示例。这些数值没有预注册为研究参数，没有进行优化，也没有证明收益增量。新的退出规则账户状态为 `NOT_RUN`。

历史图中的 A 是 `MONTHLY_VOL10`，C 是 `LOG_RISK_RIDGE`，均为主样本基础成本情景。两者尚未加入本次讨论的退出规则。三组独立账户均以 200,000 元开始；净值包含现金、股票、应收分红和交易成本，242 日年化，现金与无风险收益率为零，期末不强制平仓。

| 组别 | 年化收益 | 净夏普 | 最大回撤 | 平均股票仓位 |
| --- | ---: | ---: | ---: | ---: |
| A：简单目标波动率配置 | 5.49% | 0.482 | −31.11% | 65.43% |
| C：下行风险预测配置 | 2.28% | 0.276 | −25.89% | 52.99% |
| 510300 买入持有 | 3.12% | 0.261 | −40.95% | 95.26% |

历史图的直观结论是：C 承受的最大回撤较小，但同时放弃了部分上涨收益。单凭回撤较小，不能判断配置更好。该图也不能证明新的退出规则有效。

本补充没有新建账户、重新拟合、下载行情或改变已有策略。此前因过拟合被用户终止的 85/15 策略维持终止状态。宏观研究中的 B、D 继续为 `NOT_RUN_PREDICTION_GATE`，新口径 M1 的数据不足状态也没有改变。

解压图形补充包后，包根目录中的 `research/visualize_profit_protection_and_monthly_baselines_v1.py` 可用 Python 及 numpy、pandas、pyarrow、matplotlib 重画。加 `--verify-only` 可只核对保存数据；需要 Windows 微软雅黑或其他可用中文字体。具体依赖版本见 `运行环境.json`。包内包含全部直接绘图输入，但不含原账户引擎与宏观研究的全部原始资料，因此本包承诺的是图形和保存结果复核，不是完整重跑上游研究。
