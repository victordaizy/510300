# 私募操作意向与可加仓空间实际训练

**本轮已完成43个意向月、34个联合月的实际训练，104次逐期预测、4个期末模型、20条含费用与基准的账户情景。仍未达到20万元账户净夏普1.5、最大回撤10%的目标。**

意向单独加入价格后，MSE恶化0.70%。加入意向、可加仓空间及交互后，相对同月价格基准MSE改善8.68%，相对成熟历史均值改善3.33%。但剔除2022年的保存预测后，相对均值恶化3.15%，增量还不稳定。

预先固定的两种入场规则已经一起计算：

- 只要求预测超过压力费用：联合模型6次完整机会，基础净夏普-0.306、最大回撤8.43%，20万元变为188,544.51元；压力净夏普-0.329、回撤8.67%，期末187,759.81元。
- 再要求超过过去成熟逐期误差的RMSE：4模型均零入场，全现金，夏普未定义。

阅读顺序：

1. `训练结果.md`：全部模型、两种规则、两档成本及结论。
2. `用户要求.md`、`protocol.json`：本轮取消旧数量门，训练与账户参数事先固定。
3. `results/逐期预测.csv`、`results/同月增量比较.csv`、`results/保存预测逐年剔除诊断.csv`：预测增量及其局限。
4. `models/逐期模型.json`、`models/期末已训练模型.json`：已拟合参数及逐次训练成员。
5. `results/逐事件交易判断.csv`、`results/机会成交账簿.csv`、`results/完整逐日账户.csv`、`results/账户指标.csv`：完整账户证据。
6. `inputs/`：直接源数据、行情和核对过哈希的父级资料ZIP。
7. `01_GPT_REVIEW_PROMPT.md`：外部审阅提示词。

在解压目录运行 `python code/private_manager_exploratory_training_v1_fixed_verifier.py verify --root .` 可复算已保存结果。此入口只修正CSV空白备注被读取为NA的比较问题；原训练代码、输入、参数和账户未改动，记录见`verification_fix.json`。复算不重新训练或运行账户，不访问网络。
