# 本轮交付导航

先阅读[研究报告](研究报告.md)，再按下面三类文件核对。所有仓位、现金和成交均为历史模拟账户。

| 交付内容 | 入口 | 说明 |
|---|---|---|
| 每日决策 | [每日决策表.csv](每日决策表.csv) | 完整模型基础和压力路径的五项分数、总分、目标与实际暴露、未交易原因 |
| 开发与冻结 | [全部内层结果](development/all_inner_results.csv) | 九组配置在两个模型和三个验证年的全部54次拟合结果 |
| 开发与冻结 | [配置排名](development/configuration_ranking.csv) | 固定跨年评价标准及入选配置 |
| 开发与冻结 | [模型冻结记录](model_freeze.json) | 2015—2019最终系数、主评价读取前开发产物哈希 |
| 经济比较 | [经济比较表](evaluation/economic_comparison.csv) | 四模型×两成本的收益、夏普、回撤、暴露、换手和费用 |
| 经济比较 | [年度贡献](evaluation/annual_contributions.csv) | 各年度连续账户贡献，2026年为部分年度 |
| 经济比较 | [全部结果](result.json) | 验收、成本归因、区块区间和Newey-West诊断 |
| 经济比较 | [连续账户比较图](连续账户比较.png) | 两成本下净权益、回撤和完整评分暴露 |

`evaluation/`中的`*_ledger.csv`和同名Parquet是八条完整逐日账本；`*_trades.csv`是冻结请求及成交，`*_decisions.csv`保留每次收盘决策；`*_fixed_path_costs.csv`用于把纯费用和账户路径变化分开。

`freeze_manifest.json`、`run_claim.json`和`stage_events.jsonl`分别记录运行前冻结、唯一一次历史运行声明和阶段时序。`frozen_sources/`和`frozen_inputs/`保存本轮小型代码/协议/原始输入副本。`pre_freeze_validation.json`记录35项测试，`execution_receipt.json`记录实际完成状态，`delivery_verification.json`记录交付前从已保存账本复算和核对的结果。

主评价数据固定至2026-08-14。主评价是既往观察历史中的冻结回放；评分不是上涨概率，模拟持仓不是实际账户建议。未来样本不能用于修改冻结系数、公式或交易规则。
