# 解禁公告来源：仅公告日粒度的归档准入

原V1月度分页不完整、V1.1三个月连接失败和V1.2合并程序失败均保留原状态。V1.2的三个月网络取得本身已成功，使140个月分区查询的唯一公告编号达到33,722，原已见33,536个编号无一丢失，另外补回186个原分页漏掉的编号。

跨批次逐字段核对发现一处真实接口元数据变化：公告1225030021的announcementTime在两次响应中分别为1774429571000和1774429572000，相差1秒。它的证券、机构、公告编号、标题、PDF路径、上海公告日完全一致。精确时间相等的旧合并合同因此失败，不能改写为通过；也不能删去该差异。本次另外准入日期粒度档案，使用已有原始响应完成离线合并，0新增网络请求。

日期粒度准入仍要求每月完整、编号唯一、声明量与实得量相等、旧编号不丢失，以及证券/机构/编号/原始标题/PDF路径完全一致。仅允许同一个上海自然日内的时间字段差异，而且全部差异、两次原始响应路径和哈希必须单独保存；不同日期或其他身份字段的差异立即停止。表内保留其实际所选原始响应的时间字段，不制造一个声称确定的首发时刻。

这一用途只支持当日档案记录和以后另行固定延迟的历史研究。不得使用这些时间戳声称过去分钟级可得、首次HTTP到达或严格未来观察。来源准入也不是解禁数量/实际减持量准入；四份原始PDF案例已确认二者可能有明显差异。

沪深300成员只用于来源覆盖诊断：公告日非交易日时映射到之后首个开市日，看该日名单是否包含证券。这个日期映射不是交易可用时钟，不能直接拿来下单或生成研究账户。最终模型如果推进，必须事前另外冻结公告日后的使用延迟、计算窗口、决策时点和成员归属规则。
