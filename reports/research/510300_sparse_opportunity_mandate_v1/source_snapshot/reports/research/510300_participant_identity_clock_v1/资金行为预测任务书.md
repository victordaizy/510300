# 资金行为预测任务书

状态：研究任务定义完成，尚未冻结或拟合新数值模型。本任务书不把一月已知案例当成未见样本，不产生交易指令。

用户的最新要求：很多信息延后披露，只能验证；应灵活地根据当时行为预测大资金怎么想、怎么操作，再跟随。目标继续是 510300/CNY、20 万元主账户及 2 万元成本对照，净夏普 1.2 且年化 10%，或单列净夏普 1.5 的完整账户结果。

## 主问题与输出

**当前资金的约束和操作迹象，是否意味着未来供给/需求还会持续？市场承接的变化，是否足以改变此后可成交价格开始的持有价值？**

保持两个独立预测对象：未来五个交易日资金行为是否继续（有可测资金标签时），以及未来二十个交易日 510300 的收益与下行风险。五日是资金行为子任务，不能再次把整个宏观/微观研究缩成五日收益预测。每日收盘更新；公开的重要政策或资金公告触发额外判断。日频实施只在更新完成后的下一可成交开盘评价，不回领公告前或观察期间已经发生的涨跌。

每次工作卡必须输出：信息截止时间、可知事实、主要行为假说、竞争解释、预测的资金方向/持续性、价格影响判断、反证条件、下次更新点。没有训练校准时只给有依据的定性倾向，不生成“国家队卖出概率 80%”这类虚构精度。

## 输入如何分工

| 输入 | 角色与使用原则 |
| --- | --- |
| 已公布政策及其实际约束变化 | 区分支持、降温、约束不变与未知；记录宣布和生效。没有同期预期不填“超预期”。不能按后来涨跌倒填政策方向 |
| 当日价量与最近路径 | 描述异常交易、上涨/下跌推进、回撤与承接。成交额两面相等，不能单独识别净买方或国家队 |
| 实际公开的份额、申赎和融资 | 有方向的行为线索；份额、现金流、净值估算仓位分列。统计日不冒充公开日；缺少原始时钟的字段只限制自身，不阻断价量政策判断 |
| 当时已经公开的大持有人库存 | 约束潜在操作空间与身份假说。实名只是置信依据，不是预测必需字段；半年末尚未披露的库存不能提前使用 |
| 同期操作意向调查 | 独立候选，检验意向是否转成行为、行为是否被价格提前反映。不能把管理人表示看多直接转成未来买量 |

## 三个必须相互竞争的行为解释

1. **持续供给并且承接减弱。** 放量之后上涨难以推进，随后同等交易伴随更大跌幅、反弹更弱；可知赎回或资金约束持续。候选用途是减小持有风险或配合“已有涨幅后出现回撤”退出。反证是供给回落且价格恢复、或供给虽继续但价格有效突破。
2. **供给被承接、随后逐渐耗尽。** 大额减持期间价格冲击有限；之后量能/赎回减少而价格不再下探。候选用途是撤回先前过度看跌判断，检验恢复持有的价值。反证是供应继续放大且冲击转强。不能只凭“跌不动”立刻宣布有人完成吸筹。
3. **需求持续，但交易已经拥挤。** 新需求推动价格后，要检查后续增量是否还能跟上，而不是把刚发生的买入永久外推。候选用途是在需求衰减、价格回撤得到确认时退出；如果需求与价格持续增强，就不因“已涨很多”机械卖出。

这些条件目前是机制语言；形成数值规则时必须一次写明变量、窗口、状态阈值或估计方法、缺失处理和模型容量。不能先看所有账户收益再把这份任务书冒充预注册，也不能围绕一月结果调到最好。

## 具体研究顺序和比较

先对照仓库已完成的日频份额方向、季度申赎、融资压力及跨 ETF 流量研究，标明新增信息到底是“独立意向/约束资料”，还是“旧变量的新状态交互”。后者应计入同一家族的历史选择，不能因改名重新清零试验次数。

下一项数值协议优先选择一个边界清楚的资金约束通道和一个承接交互。逐期只用已经成熟的标签训练，同时报告：简单无条件基准、只看价格的基准、加入资金行为、再加入预先指定的资金与承接交互。若缺少合格的份额时钟，可独立开展只依赖当日价量与公开政策的子研究；应明确它没有验证真实主体交易预测。

对资金持续性，比较真实未来行为与“当前方向继续”和“成熟历史频率”基准；对于收益，保留成熟历史均值/零收益，以及受约束的反转/动量简单基准；对于风险，比较同期限的简单风险预测。不同目标各自设门，不在收益失败后临时改成风险成功。完整记录每次判断翻转和当时理由，尤其检验供给减弱后是否及时撤销看弱判断。

时间相邻的日度输出不当成独立事件。经济评价按预先冻结的非重叠锚点或事件簇组织，区块方法处理序列依赖；同时看跨时期、去除单一事件后的表现。1 月案例已经被用户和研究人员看到，单列为开发案例。整个现有历史也不重新命名为未见样本。

## 如何落实“跟随”和退出

预测先形成收益/风险倾向与失效条件，随后才映射到 510300 和现金的仓位。不能默认同一投资人永远正确，也不能按国家队有无买入直接做二元仓位。跟随的是尚未完成、对价格仍有影响的需求/供给，不是事后披露的上一轮成交。

账户阶段先固定入场与风险预算，再比较固定持有和“有一定上涨后，回撤且供给/承接恶化”的退出。上涨、回撤的阈值以及是否分批退出都要在读取评价账户结果前写清；本轮不从已知一月高低点估计最佳卖点。每次新政策或资金事实改变假说，应从下一可成交时点更新，记录与不更新的同起点对照。

完整账户统一 T+1、整手、最低佣金、滑点、分红登记/到账、现金及成本；20 万元主结果与 2 万元并列，基础和压力成本并列，242 日口径一致。分别报告净收益、夏普、回撤、实际暴露、换手、持有期与贡献集中度，不能只报告最好一年或有仓位期间的收益。
