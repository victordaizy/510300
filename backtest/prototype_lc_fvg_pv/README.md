# LC + FVG + PV 分钟策略原型

这是可删除的逻辑原型，用来回答一个明确问题：

> 510300.SH 出现流动性扫高/扫低后，如果随后产生一分钟 FVG，等待价格回踩该 FVG，并获得相同分钟时点的相对成交量和当日 VWAP 确认，下一分钟开盘入场，是否存在覆盖佣金和滑点的方向性优势？

规则在查看结果前冻结，不进行参数网格搜索。策略使用历史分钟 OHLCV，因此这里的 PV 仅指可验证的价量确认；它不冒充 Level-2 逐笔委托、撤单或真实主动买卖 Delta。

运行交互原型：

```powershell
.\.venv\Scripts\python.exe .\backtest\prototype_lc_fvg_pv\app.py
```

输出一次报告：

```powershell
.\.venv\Scripts\python.exe .\backtest\prototype_lc_fvg_pv\app.py --report
```

关键约束：

- 只使用当前及历史分钟数据；
- 信号在当前分钟收盘后确认，下一分钟开盘成交；
- 相对成交量使用过去 20 个交易日同一分钟位置的中位数；
- 每日最多一笔交易，不隔夜；
- 同一分钟同时触发止损和止盈时，按止损优先处理；
- 空头结果仅用于检验方向信号，不代表普通 A 股现货账户可以直接卖空。
