# 510300：稳定可实盘10%／1.2目标的本轮实际研究

## 结论

**截至本轮完成，仍没有找到足以称为稳定可实盘的年化10%、夏普1.2策略。**

旧10.0781%／1.2357候选在原主期基础口径下的数值已经逐字段复算一致，但它不是实盘合格结论。本轮加入逐日滚动三年、较长区块重抽样和完整新方法检验，没有把一个回测点的成功当作稳定性证明。

本轮新建的跨年度条件分布方法实际失败：主模型主期基础年化-1.7554%、夏普-0.5133；压力年化-2.0259%、夏普-0.5937。不是因为审计手续未通过而停止收益计算。已保存失败版本，不反转信号、不更改近邻数量、窗口或成本挽救。

## 新方法：不是再叠加历史赢家

研究编号 `510300_STABILITY_FIRST_DISTRIBUTION_20260910`。在读取新策略收益前，先提交协议 `a4ebe512744f930ee4f6246980094fd803441eaa`，再本地冻结执行代码和16份输入摘要，随后执行。执行代码在结果后发布到分支，Git blob与实际执行文件一致；没有把事后提交代码伪称为事前提交代码。

假设：状态相近的历史持有期若跨年份都有正向风险补偿，可能支持更稳健的下一阶段仓位。只研究两项固定政策：PRIMARY_YEAR_ROBUST和POINT_CONTROL，不进行参数网格搜索。

从2012-05-28开始的原始3456日特征表第252个索引起，每隔5日产生一个标签。标签为下一开盘买入、再过5个交易日开盘卖出的价格与合规分红毛收益，并按原点60日波动归一化。相邻持有段不重叠，但不声称统计独立。共640个完整标签；只在结束后再等5个交易日，才可用于训练。

每次只使用过去1260交易日内至少80个成熟标签，且至少三个年份各有10个。12项特征是风险归一化动量、回撤、日内与隔夜强弱、波动与下行风险比例、成交参与、日内区间和路径效率。训练集自身中位数/MAD标准化，近邻数量固定为ceil(2*sqrt(N))且至少20；Gaussian距离权重不调优。

POINT_CONTROL使用条件均值；PRIMARY_YEAR_ROBUST使用原均值与逐个剔除一个年份后的均值之最小值，避免某一盈利年份单独主导判断。留年均值不是统计置信下限。预定0/25/50/75/100%候选权重受基于20日已实现波动的10%风险尺度上限约束，以包含压力费用近似的均值—方差效用选择，每5日决策。实际账户按自己的现金、股份、佣金、滑点、T+1与分红重新核算。

共553个有条件分布估计的原点、16743条近邻来源审计记录。2015年初有13个更新原点因历史支持不足保持NO_VIEW；第一个可用估计是2015-04-13，标签87个。现金起步下的这些无观点日仍保留在收益分母中。主期已经有完整预热，没有缩短主评价日历。

## 可实盘资格不等于工程能执行

当前没有本轮最终冻结之后的新样本验证，也没有本轮核验的券商真实成交证据。用户实际持仓未知。即使某个历史点过线，也不会自动设置LIVE_READY=true。

当前状态：GOAL_ACHIEVED=false；INDEPENDENT_VALIDATION=NOT_ESTABLISHED；LIVE_READY=false；POSITION_IMPACT=0；LIVE_TRADING_AUTHORIZED=false。

需要的证据是冻结后事前留痕的数据与信号、真实可成交性及费用核验，以及新样本下重新评价收益风险和不确定性。单纯等待一定天数、再做很多相关回测或让程序可以连上券商，都不能代替这项证据。没有证据不等于目标不可能，本轮仍未完成用户目标。

多重选择偏差的参考：Bailey与López de Prado，The Deflated Sharpe Ratio，Journal of Portfolio Management，2014，DOI 10.3905/jpm.2014.40.5.094。本轮未虚构完整研究次数或据不完整候选集输出一个“已经校正”的DSR。
