## 策略到底是什么

### 原核心保持冻结

原核心是前一轮已保存的`CORE2__V1_CLIMAX_RECOVERY__IDLE_ONLY__A100`：第150轮原目标固定乘二并封顶100%；该核心明确为零时，使用原V1放量急跌回升的独立参考意向。各时期、各费用匹配自身原参考。该核心是既有多轮研究后的选择，本次不是把它重新说成独立发现。

本次复用核心的已保存收盘目标，而不是使用下一开盘实际股份作为当天信号。四条核心账户已按新执行工作区逐字段重算一致。未重新拟合旧学习模型，也未改变核心进入、退出或风险预算。

### 新增正向序贯证据机会

使用已有含分红日行情。令r_t为当日含分红对数收益，sigma_t为截至前一交易日的60日对数收益样本标准差，z_t=r_t/sigma_t。

序贯正向证据：`S_t=max(0,S_(t-1)+z_t-0.5)`。累计值达到5，发出报警并立即清零；即使当天未满足后面的参与度筛选，报警后也清零，不累计等待更漂亮的日期。必要数据缺失时清零，不产生新进入事件。

当日报警还必须同时满足：成交量至少为此前20日均量的1.5倍，且`(close-low)/(high-low)>=0.75`。所有计算只使用当天收盘已知数据，收盘产生意向、下一开盘买入。

新增源参考按自己的200000元账户维护实际成本、持仓、已确认分红及周期高点。持有最多5个收盘交易日；含成本周期亏损达到4%，或含分红周期价值从高点回撤6%，或期限到达，任一成立在下一开盘全部退出。没有日内触价成交假设。实际退出后冷却2日，退出受阻保持原退出请求。

CUSUM只借用了序贯均值偏移检测的统计结构，正向价格冲击后的继续收益仍然是待检验金融假设。k=0.5与h=5来自NIST常见控制图设定，不代表这些阈值具有已证明的市场收益含义。

### 合成为一个实际账户

新增源参考进入或持有意向为1，退出或空仓为0；其满额意向与固定核心目标取最大值：`最终目标=max(核心目标,新增源意向)`。

不能把两个满仓账户的收益直接相加。最终账户仍只有自己的20万元、现金、实际股数与分红权益，按下一开盘独立执行，最高目标100%。某条源发出退出并不保证最终账户清仓：若核心仍有正目标，最终账户回落到核心目标。

`FULL__REMAINING`模式在源目标只能为0/1时，与MAX完全相同。两种配置的四情景逐日DataFrame均一致，故**两个通过配置只有一条不同的历史路径**。
