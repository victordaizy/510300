# 510300：年化10% / 夏普1.2实际执行报告

## 结论

**本次没有实现成本后复合年化收益至少10%、净夏普至少1.2的联合目标。**

在统一20万元、仅510300与现金、无杠杆、零现金利息、实际佣金与滑点、完整交易日的口径下，已完成六个事前登记阶段，389项政策 × 两时期 × 两费用，共1556条情景资金账户。主期基础成本同时达到两个目标的候选数量是0，不是“已经达标但只是验证不足”。两个目标没有出现在同一条新账户上。

本次主期夏普至少1.2的候选中，年化收益最高为7.8150%，夏普1.212503；压力成本下年化7.3778%、夏普1.150536，较早基础年化3.2210%、夏普0.402305。主期年化最高为10.1706%，对应夏普只有0.852216，压力情景年化降至8.3119%、夏普0.711043。不能混用两条净值曲线的指标来宣布成功。

这次结果不证明10%/1.2目标不可能，也不宣称已经穷尽所有机制；它只说明本次固定候选集没有完成目标。项目不被标记为成功，不创建实盘或自动交易服务。

## 资金、学习和源信息分别告诉了什么

第一阶段固定放大、开方、全信号预算和月度风险尺度都未达标。第143轮四倍主期年化8.2556%、夏普1.122567；第150轮四倍年化8.0407%、夏普1.107811。正目标撞到100%上限后，风险和收益不能保持理想等比例关系。

第二阶段曾出现10%以上年化，但日历补充增加了波动、成本敏感性和较早时期损失。第三、第四阶段的严格成熟标签学习没有产生足够的收益改善；代码因果时钟通过不等于策略有效。第六阶段“盈利后再增加仓位”的假设也未改善到目标水平，不能将已有浮盈自动解释为更高的未来期望收益。

第五阶段原ETF数据有下载时间，却没有逐条历史首次发布与未修订版本证明。全部源值延迟两个交易日仅是明确的代理假设。PRICE_FLOW与PRICE使用同一源有效日和成熟标签作匹配对照；最佳主期ETF增量候选年化7.0038%、夏普1.246674，仍低于10%。所有该阶段输出保留`UNVERIFIED_PUBLICATION_VINTAGE`，既不证明真实PIT，也不具备实盘资格。
