## 关键归因

原32与128主期基础成本的逐日风险暴露归因：两者均承担ETF风险243天，对ln(128终值/32终值)贡献-0.015872；只有128承担风险90天，贡献-0.031937；只有32承担风险33天，贡献+0.146665；两者均空仓1238天，贡献0。

卖出日包含隔夜风险，风险日按当日或前日股份是否大于零判断。以上是可加总的对数财富贡献，不是简单收益率或年化，更不是因果alpha。**128改善主要来自避开旧策略的亏损暴露，不能简单解释成多持有赚得更多。**不得用事后挑出的33天制造新过滤器。

E主期基础的累计净利润110,750.37元，相比原150多44,215.37元；年化波动由3.3041%变为5.5709%。前三个盈利周期占净利润64.44%，不是平滑收益。2023年该路径全年空仓、年度收益0。
